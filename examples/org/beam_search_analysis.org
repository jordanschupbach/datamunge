* Mathematics and algorithm
Beam search expands one depth layer, ranks candidates by heuristic \(h\), and
retains only the best \(B\).  It bounds memory by \(O(Bd)\) but may discard the
only solution and is therefore incomplete.
#+begin_example
beam <- {start path}
repeat: expand all beam paths; return a goal if found
sort children by h(endpoint); retain first B
#+end_example
