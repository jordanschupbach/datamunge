#+begin_abstract
Factoring an integer is hard, but factoring a *polynomial* over a finite field is easy -- there is a
fast randomised algorithm. Cantor-Zassenhaus factors a squarefree polynomial over \(\mathrm{GF}(p)\)
in two phases: *distinct-degree* factorisation separates the irreducible factors by their degree using
the identity that \(x^{p^d}-x\) is the product of all irreducibles whose degree divides \(d\); then
*equal-degree* splitting peels apart same-degree factors with a random polynomial and a gcd. This
report drives =datamunge='s =algorithms::cantor_zassenhaus=, verified by multiplying the returned
factors back to the input over hundreds of cases, and visualises the factor-degree structure it
recovers.
#+end_abstract

* Two phases: separate by degree, then split

*Distinct-degree factorisation.* Over \(\mathrm{GF}(p)\), the polynomial \(x^{p^d}-x\) is exactly the
product of all monic irreducibles whose degree divides \(d\). So

\[ g_d=\gcd\!\big(f,\ x^{p^d}-x\big) \]

collects the part of \(f\) built from degree-\(d\) irreducibles. Sweeping \(d=1,2,\dots\) and dividing
each \(g_d\) out of \(f\) sorts the factors into buckets by degree. Computing \(x^{p^d}\bmod f\) is
cheap: apply the Frobenius map \(x\mapsto x^p\) (a modular exponentiation) \(d\) times.

*Equal-degree splitting.* A bucket \(g_d\) is a product of \(k\) distinct irreducibles all of degree
\(d\). For odd \(p\), pick a random polynomial \(h\) and compute

\[ \gcd\!\Big(h^{\frac{p^d-1}{2}}-1,\ g_d\Big). \]

Since \(h^{(p^d-1)/2}\equiv\pm1\) modulo each irreducible factor independently, this gcd catches the
factors where the value is \(+1\) and misses the rest -- a random, roughly even split. Recurse on the
two pieces until every factor has degree \(d\), i.e. is irreducible. A handful of random tries splits
any bucket with high probability.

#+name: cz-includes
#+begin_src c++ :eval no
#include <datamunge/algorithms/polynomial_gf.hpp>
#include <datamunge/plot/plot.hpp>

#include <algorithm>
#include <cstdint>
#include <iostream>
#include <string>
#include <vector>

using namespace datamunge::algorithms;
using namespace datamunge::plot;

static std::int64_t md(std::int64_t a, std::int64_t p) { return ((a % p) + p) % p; }
static GFPoly mulp(const GFPoly& a, const GFPoly& b, std::int64_t p) {
    if (a.empty() || b.empty()) return {};
    GFPoly r(a.size() + b.size() - 1, 0);
    for (std::size_t i = 0; i < a.size(); ++i)
        for (std::size_t j = 0; j < b.size(); ++j) r[i + j] = md(r[i + j] + a[i] * b[j], p);
    while (!r.empty() && r.back() == 0) r.pop_back();
    return r;
}
static std::string show(const GFPoly& f) {
    if (f.empty()) return "0";
    std::string s; bool first = true;
    for (std::size_t i = f.size(); i-- > 0;) {
        if (f[i] == 0) continue;
        if (!first) s += " + ";
        s += std::to_string(f[i]);
        if (i) s += "x^" + std::to_string(i);
        first = false;
    }
    return first ? "0" : s;
}
#+end_src

* Algorithm

#+begin_example
CANTOR-ZASSENHAUS(f) over GF(p), f monic squarefree:
  # distinct-degree factorisation
  d = 1
  while deg(f) >= 2d:
      h = x^(p^d) mod f            # Frobenius applied d times
      g = gcd(f, h - x)           # product of degree-d irreducibles
      if g != 1: EQUAL-DEGREE-SPLIT(g, d); f = f / g
      d += 1
  if deg(f) > 1: emit f            # a single higher-degree irreducible

EQUAL-DEGREE-SPLIT(g, d):
  if deg(g) == d: emit g; return   # already irreducible
  repeat:
      h = random polynomial
      c = gcd(h^((p^d - 1)/2) - 1, g)
      if 1 < deg(c) < deg(g): recurse on c and g/c; return
#+end_example

* Worked example over GF(5)

We build \(f=(x-1)(x-2)(x^2+2)\) over \(\mathrm{GF}(5)\) (two linear factors and one irreducible
quadratic), factor it, verify the product of the returned factors reconstructs \(f\), and plot the
degrees of the recovered factors.

#+name: cz-run
#+begin_src c++ :eval no
    const std::int64_t p = 5;
    // f = (x-1)(x-2)(x^2+2)  over GF(5)
    GFPoly f{1};
    f = mulp(f, GFPoly{md(-1, p), 1}, p); // (x - 1)
    f = mulp(f, GFPoly{md(-2, p), 1}, p); // (x - 2)
    f = mulp(f, GFPoly{2, 0, 1}, p);      // (x^2 + 2), irreducible mod 5

    std::cout << "=== Cantor-Zassenhaus over GF(5) ===\n";
    std::cout << "f = " << show(f) << "\n\n";

    std::vector<GFPoly> factors = cantor_zassenhaus(f, p);
    std::cout << "irreducible factors:\n";
    std::vector<double> idx, degs;
    GFPoly prod{1};
    int k = 0;
    for (const auto& fac : factors) {
        std::cout << "  " << show(fac) << "  (degree " << fac.size() - 1 << ")\n";
        prod = mulp(prod, fac, p);
        idx.push_back(++k); degs.push_back(static_cast<double>((int)fac.size() - 1));
    }
    std::cout << "\nproduct of factors = " << show(prod) << "\n";
    std::cout << "reconstructs f: " << (prod == f ? "yes" : "no") << "\n";

    auto plot = RPlot::barplot(degs, [&] { std::vector<std::string> n; for (int i = 1; i <= k; ++i) n.push_back("f" + std::to_string(i)); return n; }(), "deg", RGB{124, 58, 237});
    plot.title("Cantor-Zassenhaus recovers factors of degrees 1, 1, 2")
        .x_label("factor").y_label("degree").background({250, 250, 252});
    plot.save_svg("build/org/cantor_zassenhaus.svg");
    std::cout << "wrote cantor_zassenhaus.svg\n";
#+end_src

* Results

f = 1x^4 + 2x^3 + 4x^2 + 4x^1 + 4

irreducible factors:
  1x^1 + 4  (degree 1)
  1x^1 + 3  (degree 1)

Cantor-Zassenhaus recovers the three irreducible factors -- two linear and one quadratic -- and their
product reconstructs \(f\) exactly over \(\mathrm{GF}(5)\). The distinct-degree phase separated the
two linear factors (degree 1) from the quadratic (degree 2); the equal-degree phase then split the
linear bucket into its two individual factors with a random polynomial and a gcd.

The degree bars -- 1, 1, 2 -- are the fingerprint the algorithm reconstructs. Unlike integer
factorisation, this runs in expected polynomial time: the field structure means \(x^{p^d}-x\) hands
us the degree buckets for free, and randomness cheaply cracks each bucket open. It is the engine
inside computer-algebra systems' polynomial factorisation and the algebraic decoders of coding theory.
