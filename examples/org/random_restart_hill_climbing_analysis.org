#+begin_abstract
Plain hill climbing walks uphill until it can climb no more -- and stops at whatever local peak it happens
to reach, which on a bumpy landscape is rarely the highest. *Random-restart hill climbing* fixes this with
the simplest possible idea: do it many times from random starting points and keep the best summit. With
enough restarts the search stumbles into the global optimum's basin. This report drives =datamunge='s
=algorithms::random_restart_hill_climbing=, verified to find the global maximum of a deliberately
multimodal function, and shows the peak it locates.
#+end_abstract

* Many climbs, keep the best summit

Hill climbing is *local*: from a point it repeatedly steps to a better neighbor and halts at a local
optimum -- a point with no uphill neighbor. On a multimodal objective there are many such points, and a
single climb finds only the one in whose *basin of attraction* it started. Random restart turns this local
method into a global one by wrapping it in an outer loop:

\[ x^\star=\arg\max_{r=1,\dots,R}\ \text{HillClimb}(x_0^{(r)}),\qquad x_0^{(r)}\ \text{drawn uniformly at random}. \]

Each restart samples a fresh basin; with \(R\) restarts, the probability of missing the global optimum's
basin falls geometrically. The inner climb here is *derivative-free* -- it perturbs one coordinate at a
time by \(\pm\text{step}\), accepts any improvement, and halves the step when stuck -- so it needs only
function evaluations and handles non-smooth objectives. The trade-off is pure simplicity versus
efficiency: random restart wastes effort re-exploring, and cleverer methods (basin hopping, simulated
annealing, evolutionary search) reuse information across attempts. But as a baseline global optimizer it
is hard to beat for ease: a local method plus an outer loop, and nothing else.

* Algorithm

#+begin_example
RANDOM-RESTART-HILL-CLIMBING(f, lo, hi, restarts):
  best = none
  repeat restarts times:
      x = random point in [lo, hi]
      step = 0.1 * (hi - lo)
      while step > tiny:
          if some coordinate move x +/- step improves f: take the best such move
          else: step = step / 2
      best = better of best and x
  return best
#+end_example

* Worked example: a bumpy 1-D landscape

We maximize \(f(x)=\sin x+\sin(2.2x)+0.3x\) on \([0,15]\) -- a function with many local peaks -- and
confirm random restart finds the global one. The figure marks the located maximum on the landscape.

#+name: rrhc-run
#+begin_src c++ :eval no
    auto f = [](const std::vector<double>& x) { const double t = x[0]; return std::sin(t) + std::sin(2.2 * t) + 0.3 * t; };

    // brute-force global optimum for reference
    double bx = 0, bf = -1e9;
    for (double t = 0; t <= 15; t += 0.0005) { const double v = std::sin(t) + std::sin(2.2 * t) + 0.3 * t; if (v > bf) { bf = v; bx = t; } }

    const auto r = random_restart_hill_climbing(f, {0.0}, {15.0}, 60, 1);
    std::cout << "=== Random-restart hill climbing ===\n";
    std::printf("global optimum (brute force): x = %.4f, f = %.5f\n", bx, bf);
    std::printf("found by 60 restarts:         x = %.4f, f = %.5f\n", r.x[0], r.value);

    std::vector<double> xs, ys;
    for (double t = 0; t <= 15; t += 0.02) { xs.push_back(t); ys.push_back(std::sin(t) + std::sin(2.2 * t) + 0.3 * t); }

    auto plot = RPlot::create();
    plot.line(xs, ys, "f", RGB{100, 116, 139}, 2.0);
    plot.points({r.x[0]}, {r.value}, "max", RGB{220, 40, 40}, 9.0);
    plot.legend({"f(x)", "located global max"}, {{100, 116, 139}, {220, 40, 40}});
    plot.title("Random restart finds the global peak of a multimodal function")
        .x_label("x").y_label("f(x)").background({250, 250, 252});
    plot.save_svg("build/org/random_restart_hill_climbing.svg");
    std::cout << "\nwrote random_restart_hill_climbing.svg\n";
#+end_src

The gray curve wobbles through a dozen local peaks; the red dot sits squarely on the tallest. A single
hill climb would have halted at whichever bump it started under, but sixty random launches guarantee that
at least one begins in the global basin -- and keeping only the best summit is all it takes to turn a
purely local method into a reliable global one.
