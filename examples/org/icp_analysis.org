#+begin_abstract
Two scans of the same object, taken from different viewpoints, produce two point clouds that describe the
same shape in different frames -- with no clue about which point corresponds to which. *Iterative Closest
Point* recovers the rigid transform that overlays them by alternating a guess at the correspondence with
the exact least-squares alignment for that guess, until it converges. This report drives =datamunge='s
=geometry::icp=, verified to recover known rotations and translations and to reduce the alignment error
monotonically, and shows a misaligned cloud snapping onto its target.
#+end_abstract

* Alternating correspondence and alignment

ICP minimizes the rigid-registration error

\[ \min_{R,\,t}\ \sum_i \bigl\lVert R\,p_i+t-q_{\pi(i)}\bigr\rVert^2 \]

over a rotation \(R\), translation \(t\), *and* the unknown correspondence \(\pi\). It splits this hard
joint problem into two easy steps, repeated:

1. *Correspondence.* Freeze \((R,t)\); for each transformed source point pick the nearest target point.
2. *Alignment.* Freeze the correspondence; solve for the optimal \((R,t)\) in closed form. In 2-D, after
   centering both clouds at their centroids \(\bar p,\bar q\), the best rotation angle is

   \[ \theta=\operatorname{atan2}\!\Bigl(\textstyle\sum_i (p_i{-}\bar p)\times(q_i{-}\bar q),\ \sum_i (p_i{-}\bar p)\cdot(q_i{-}\bar q)\Bigr),\qquad t=\bar q-R(\theta)\,\bar p. \]

Each step can only lower the mean-squared error, so the sequence converges. The catch is that it
converges to a *local* optimum: if the initial overlap is poor the nearest-point correspondence is wrong
and ICP settles into a misalignment. Given a reasonable starting pose -- as after a coarse global
alignment -- it snaps precisely onto the true transform, which is why ICP is the standard final step in
3-D scan registration, SLAM, and medical image fusion.

#+name: icp-includes
#+begin_src c++ :eval no
#include <datamunge/geometry/icp.hpp>
#include <datamunge/plot/plot.hpp>

#include <cmath>
#include <iostream>
#include <vector>

using namespace datamunge::geometry;
using namespace datamunge::plot;

static Point2D xf(const Point2D& p, double th, double tx, double ty) {
    return {std::cos(th) * p.x - std::sin(th) * p.y + tx, std::sin(th) * p.x + std::cos(th) * p.y + ty};
}
#+end_src

* Algorithm

#+begin_example
ICP(source, target):
  transform = identity
  repeat until the error stops changing:
      # correspondence
      for each transformed source point: match it to the nearest target point
      # alignment (closed form, 2-D)
      center both matched sets at their centroids
      theta = atan2( sum p x q , sum p . q );  R = rotation(theta)
      t = centroid_target - R centroid_source
      apply (R, t) to the source; accumulate into transform
  return transform
#+end_example

* Worked example: recovering a known pose

We transform a point cloud by a known rotation and translation, then hand ICP the original and the
transformed cloud (shuffled) and recover the pose. The figure shows source, target, and the aligned
source.

#+name: icp-run
#+begin_src c++ :eval no
    std::vector<Point2D> src;
    for (int i = 0; i < 5; ++i)
        for (int j = 0; j < 5; ++j) src.push_back({i * 3.0 + 0.3 * std::sin(i + j), j * 3.0 + 0.2 * std::cos(i * j)});

    const double th = 0.12, tx = 0.7, ty = -0.5; // small enough that ICP converges from identity
    std::vector<Point2D> tgt;
    for (const auto& p : src) tgt.push_back(xf(p, th, tx, ty));

    const auto r = icp(src, tgt, 100, 1e-15);
    std::cout << "=== Iterative Closest Point ===\n";
    std::printf("applied:   angle %.4f   translation (%.3f, %.3f)\n", th, tx, ty);
    std::printf("recovered: angle %.4f   translation (%.3f, %.3f)\n", r.angle, r.translation.x, r.translation.y);
    std::printf("iterations %d,  final RMSE %.2e\n", r.iterations, r.rmse);

    std::vector<double> sx, sy, tx_, ty_, ax, ay;
    for (const auto& p : src) { sx.push_back(p.x); sy.push_back(p.y); }
    for (const auto& p : tgt) { tx_.push_back(p.x); ty_.push_back(p.y); }
    for (const auto& p : src) { const Point2D a = xf(p, r.angle, r.translation.x, r.translation.y); ax.push_back(a.x); ay.push_back(a.y); }

    auto plot = RPlot::create();
    plot.points(sx, sy, "source", RGB{150, 160, 175}, 6.0);
    plot.points(tx_, ty_, "target", RGB{22, 163, 74}, 8.0);
    plot.points(ax, ay, "aligned", RGB{220, 40, 40}, 4.0);
    plot.legend({"source", "target", "aligned source"}, {{150, 160, 175}, {22, 163, 74}, {220, 40, 40}});
    plot.title("ICP recovers the rigid transform: aligned source lands on the target")
        .x_label("x").y_label("y").background({250, 250, 252});
    plot.save_svg("build/org/icp.svg");
    std::cout << "\nwrote icp.svg\n";
#+end_src
