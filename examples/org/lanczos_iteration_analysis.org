#+begin_abstract
When a symmetric matrix is enormous but you only want a few of its eigenvalues -- the largest, the
smallest -- the *Lanczos iteration* delivers them from just matrix-vector products. It is the symmetric
special case of Arnoldi, where the projection collapses to a *tridiagonal* matrix built by a three-term
recurrence. Its eigenvalues, the *Ritz values*, race toward the extreme eigenvalues of the full matrix.
This report drives =datamunge='s =algorithms::lanczos_iteration=, verified to recover the full spectrum
when run to completion and to pin the extreme eigenvalues in a fraction of the steps, and shows that fast
convergence.
#+end_abstract

* A three-term recurrence and a tridiagonal projection

For symmetric \(A\), the Hessenberg matrix that Arnoldi produces is symmetric -- hence *tridiagonal* -- so
almost all of the Gram-Schmidt work vanishes. Orthogonalizing \(Av_j\) needs only the two previous basis
vectors, giving the celebrated three-term recurrence

\[ \beta_j v_{j+1}=Av_j-\alpha_j v_j-\beta_{j-1}v_{j-1},\qquad \alpha_j=v_j^\top Av_j,\quad \beta_j=\lVert Av_j-\alpha_jv_j-\beta_{j-1}v_{j-1}\rVert. \]

The scalars assemble into a symmetric tridiagonal matrix \(T_m\) with diagonal \(\alpha\) and off-diagonal
\(\beta\), satisfying \(T_m=V_m^\top A V_m\). Because \(T_m\) is tiny and tridiagonal, its eigenvalues are
cheap to compute (by the QR algorithm), and those *Ritz values* approximate \(A\)'s eigenvalues -- with
the *extreme* ones converging first and fastest, frequently to full accuracy in far fewer than \(n\) steps.
Run all the way to \(m=n\) it reproduces the entire spectrum exactly (in exact arithmetic). The catch is
that finite-precision Lanczos loses orthogonality among the basis vectors, spawning spurious duplicate
Ritz values; a re-orthogonalization step (used here) cures it. Lanczos is *the* method for a few
eigenvalues of the giant sparse symmetric matrices of quantum chemistry, structural mechanics, and network
science.

* Algorithm

#+begin_example
LANCZOS(A, b, m):                            # A symmetric
  v_1 = b/||b||;  v_0 = 0;  beta_0 = 0
  for j = 1..m:
      w = A v_j
      alpha_j = v_j . w
      w = w - alpha_j v_j - beta_{j-1} v_{j-1}   (+ re-orthogonalize)
      beta_j = ||w||;  v_{j+1} = w / beta_j
  return the tridiagonal T = tridiag(beta, alpha, beta)
  # eigenvalues of T (Ritz values) approximate those of A
#+end_example

* Worked example: Ritz values homing in on the extremes

We take a \(30\times30\) symmetric matrix, run Lanczos for a few steps, and watch the largest and smallest
Ritz values converge to the true extreme eigenvalues as the number of steps grows.

#+name: lan-run
#+begin_src c++ :eval no
    const int n = 30;
    std::vector<std::vector<double>> A(n, std::vector<double>(n, 0));
    unsigned s = 2024;
    auto rnd = [&] { s = s * 1103515245u + 12345u; return ((s >> 16) % 1000) / 500.0 - 1.0; };
    for (int i = 0; i < n; ++i) for (int j = i; j < n; ++j) { const double v = rnd(); A[i][j] = v; A[j][i] = v; }

    const auto eig = qr_eigenvalues(A); // true spectrum, ascending
    std::vector<double> b(n, 1.0);

    std::cout << "=== Lanczos iteration (30x30 symmetric) ===\n";
    std::printf("true extreme eigenvalues: min = %.6f, max = %.6f\n", eig.front(), eig.back());
    std::cout << " steps   min Ritz error   max Ritz error\n";
    std::vector<double> steps, top_err, bot_err;
    for (int m : {4, 6, 8, 10, 12, 15, 18, 22}) {
        const auto r = lanczos_iteration(A, b, m);
        const int  mm = static_cast<int>(r.alpha.size());
        std::vector<std::vector<double>> T(mm, std::vector<double>(mm, 0));
        for (int i = 0; i < mm; ++i) { T[i][i] = r.alpha[i]; if (i + 1 < mm) { T[i][i + 1] = r.beta[i]; T[i + 1][i] = r.beta[i]; } }
        const auto ritz = qr_eigenvalues(T);
        const double te = std::fabs(ritz.back() - eig.back()), be = std::fabs(ritz.front() - eig.front());
        std::printf("  %2d      %.3e        %.3e\n", m, be, te);
        steps.push_back(m); top_err.push_back(std::max(1e-16, te)); bot_err.push_back(std::max(1e-16, be));
    }

    auto plot = RPlot::create();
    plot.line(steps, top_err, "max", RGB{37, 99, 235}, 2.2);
    plot.points(steps, top_err, "max", RGB{37, 99, 235}, 5.0);
    plot.line(steps, bot_err, "min", RGB{220, 40, 40}, 2.2);
    plot.points(steps, bot_err, "min", RGB{220, 40, 40}, 5.0);
    plot.legend({"largest eigenvalue error", "smallest eigenvalue error"}, {{37, 99, 235}, {220, 40, 40}});
    plot.title("Lanczos Ritz values converge to the extreme eigenvalues (log scale)")
        .x_label("Lanczos steps").y_label("error").background({250, 250, 252});
    plot.save_svg("build/org/lanczos_iteration.svg");
    std::cout << "\nwrote lanczos_iteration.svg\n";
#+end_src

Both error curves plunge on the log axis: after a dozen or so steps the extreme Ritz values are exact to
the last bit, though the matrix has thirty eigenvalues. That the extremes emerge first -- long before the
interior of the spectrum -- is the defining feature of the Krylov approach, and why a Lanczos run of a few
dozen matrix-vector products can answer the largest-eigenvalue question for a matrix with millions of rows.
