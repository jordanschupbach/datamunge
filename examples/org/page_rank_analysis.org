#+title: PageRank
#+options: toc:t num:t
#+property: header-args:c++ :eval no

#+begin_abstract
PageRank is the stationary distribution of a random surfer who follows links
most of the time and teleports otherwise.  We derive the Markov equation,
handle dangling pages, give pseudocode, and rank a three-page network.
#+end_abstract

* Mathematics

Let \(P\) distribute each page's probability uniformly over its outgoing
links.  With damping \(0\le d<1\), PageRank satisfies
\[
r=\frac{1-d}{n}\mathbf1+dP^\top r.
\]
Dangling pages distribute their mass uniformly.  Teleportation makes the
chain irreducible and aperiodic, so the probability vector is unique and
power iteration converges.

* Pseudocode

#+begin_example
r <- uniform probability vector
repeat:
  dangling <- sum r[u] over pages with no outgoing links
  next[v] <- (1-d)/n + d*dangling/n
  for every link u->v: next[v] += d*r[u]/outdegree[u]
  swap(r,next)
until L1 change < tolerance
#+end_example

Each iteration is \(O(n+m)\) time with \(O(n+m)\) storage.

* C++ example

#+begin_src c++ :eval no
#include <datamunge/algorithms/network_analysis.hpp>
#include <iostream>
int main() {
  auto r=datamunge::algorithms::page_rank(3,{{0,2},{1,2},{2,2}});
  for(double x:r)std::cout<<x<<'\n';
}
#+end_src

Pages 0 and 1 tie by symmetry, while page 2 receives both endorsements and
therefore has the greatest score; the returned values sum to one.
