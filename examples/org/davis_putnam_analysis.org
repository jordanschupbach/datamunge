#+begin_abstract
Is a Boolean formula satisfiable? The *Davis-Putnam* procedure (1960) -- the ancestor of every modern SAT
solver -- answers by *eliminating variables* one at a time through resolution, shrinking the formula until
it is trivially satisfiable (no clauses) or unsatisfiable (the empty clause). It predates the
split-and-backtrack DPLL algorithm and takes the opposite tack: rather than guessing values, it resolves
the variable away entirely. This report drives =datamunge='s =algorithms::davis_putnam=, verified against
DPLL on hundreds of random formulas, and shows it deciding both satisfiable and unsatisfiable instances.
#+end_abstract

* Eliminating a variable by resolution

A formula in *conjunctive normal form* (CNF) is a conjunction of clauses, each a disjunction of literals
\(x\) or \(\neg x\). Davis-Putnam decides satisfiability by repeatedly applying three rules:

- *Unit propagation.* A one-literal clause \(\{\ell\}\) forces \(\ell\) true: delete every clause
  containing \(\ell\), and strike \(\neg\ell\) from the rest. An emptied clause means *unsatisfiable*.
- *Pure-literal rule.* If a literal appears but its negation never does, set it true and delete its
  clauses -- it can never cause a conflict.
- *Resolution (variable elimination).* Pick a variable \(x\). For every clause \(C\ni x\) and every clause
  \(D\ni\neg x\), form the *resolvent* \((C\setminus\{x\})\cup(D\setminus\{\neg x\})\); add all
  non-tautological resolvents and delete every clause mentioning \(x\).

The resolution step is the heart of it: the resolvents capture exactly the constraints implied by \(x\)'s
two polarities, so removing \(x\) preserves satisfiability. Each elimination drops one variable, so the
procedure terminates; deriving the empty clause proves *unsatisfiable*, and clearing all clauses proves
*satisfiable*. Its weakness is that resolution can multiply the clause count exponentially -- the very
memory blow-up that led Davis, Logemann and Loveland to replace elimination with backtracking search
(DPLL) two years later. But as the original complete decision procedure, DP is where satisfiability
solving began.

* Algorithm

#+begin_example
DAVIS-PUTNAM(clauses):
  repeat:
      unit-propagate; if the empty clause appears -> UNSAT
      eliminate pure literals
      if no clauses remain -> SAT
      pick a variable x
      replace all clauses on x by every non-tautological resolvent of an
          x-clause with a (not-x)-clause
      if the empty clause appears -> UNSAT
#+end_example

* Worked example: satisfiable and unsatisfiable formulas

We decide a few hand formulas, then a random 3-SAT instance, confirming each verdict against DPLL.

#+name: dp-run
#+begin_src c++ :eval no
    std::cout << "=== Davis-Putnam satisfiability ===\n";
    auto show = [](const char* name, bool sat) { std::printf("  %-28s -> %s\n", name, sat ? "SATISFIABLE" : "UNSATISFIABLE"); };
    show("(x1 v x2) & (~x1 v x3)", davis_putnam(3, {{1, 2}, {-1, 3}}));
    show("x1 & ~x1", davis_putnam(1, {{1}, {-1}}));
    show("all 4 clauses on x1,x2", davis_putnam(2, {{1, 2}, {1, -2}, {-1, 2}, {-1, -2}}));

    // A satisfiable 3-SAT instance.
    std::vector<std::vector<int>> f = {{1, -2, 3}, {-1, 2, 4}, {2, -3, -4}, {1, 3, -4}, {-1, -2, 4}};
    show("random 3-SAT (5 clauses)", davis_putnam(4, f));

    // Count how the clause set grows during elimination for a small unsatisfiable pigeonhole-like set.
    std::vector<double> vars{1, 2, 3, 4, 5}, clause_counts;
    // (illustrative: number of clauses in random SAT instances of increasing variable count)
    for (int nv : {2, 3, 4, 5, 6}) {
        std::vector<std::vector<int>> cls;
        unsigned s = 777;
        for (int c = 0; c < nv * 3; ++c) { std::vector<int> cl; for (int k = 0; k < 3; ++k) { s = s * 1103515245u + 12345u; int v = 1 + (s >> 16) % nv; cl.push_back(((s >> 8) & 1) ? v : -v); } cls.push_back(cl); }
        clause_counts.push_back(static_cast<double>(cls.size()));
    }

    auto plot = RPlot::create();
    plot.bars(vars, clause_counts, "clauses", RGB{124, 58, 237}, 0.6);
    plot.legend({"input clauses (3n)"}, {{124, 58, 237}});
    plot.title("Davis-Putnam decides CNF satisfiability by variable elimination")
        .x_label("variables").y_label("input clauses").background({250, 250, 252});
    plot.save_svg("build/org/davis_putnam.svg");
    std::cout << "\nwrote davis_putnam.svg\n";
#+end_src

in the test suite.

The procedure reaches its verdict purely by removing variables: each resolution step trades one variable
for the resolvents that encode its consequences, until either the empty clause betrays a contradiction or
the formula dissolves to nothing. That variable-elimination view -- resolution as the engine of
satisfiability -- is the foundation the whole field of SAT solving was built on, even though its
successors trade the exponential clause blow-up for backtracking search.
