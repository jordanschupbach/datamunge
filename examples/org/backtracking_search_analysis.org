* Mathematics and algorithm
Depth-first backtracking maintains a simple partial path.  Mark a vertex while
it is on that path; if every continuation fails, unmark it and remove it.
#+begin_example
SEARCH(u): append and mark u; if goal return true
for unmarked successor v: if SEARCH(v) return true
unmark u; remove u; return false
#+end_example
Every simple path may be explored, so worst-case time is exponential; stack
space is \(O(V)\).  The invariant that the stack is simple proves any returned
sequence is a valid path.
