#+begin_abstract
Quantum phase estimation (QPE) is the workhorse subroutine behind Shor's factoring and quantum
chemistry: given a unitary \(U\) and an eigenstate \(|\psi\rangle\) with
\(U|\psi\rangle=e^{2\pi i\varphi}|\psi\rangle\), it reads out the phase \(\varphi\in[0,1)\) to
\(t\) bits of precision. A register of \(t\) *counting* qubits is put in superposition;
controlled-\(U^{2^j}\) operations kick the phase \(e^{2\pi i\varphi 2^j}\) onto qubit \(j\); an
*inverse* QFT then concentrates the amplitude on the integer nearest \(2^t\varphi\). This
report runs the exact circuit with =datamunge='s =algorithms::phase_estimation= as a literate
program: every number and figure comes from one compiled binary. We estimate an exact dyadic
phase perfectly and a non-dyadic one with a characteristic spread.
#+end_abstract

* Phase kickback into a counting register

Each counting qubit starts as \(\frac{1}{\sqrt2}(|0\rangle+|1\rangle)\). A controlled-\(U^{2^j}\)
gate, acting on the eigenstate, multiplies the \(|1\rangle\) branch of qubit \(j\) by
\(e^{2\pi i\varphi 2^j}\) (phase kickback), so the counting register ends in
\[
  \frac{1}{\sqrt{2^t}}\sum_{x=0}^{2^t-1} e^{2\pi i\varphi x}\,|x\rangle .
\]
This is exactly a QFT of the state \(|2^t\varphi\rangle\); applying the *inverse* QFT therefore
yields \(|2^t\varphi\rangle\). When \(\varphi\) is a multiple of \(2^{-t}\) the readout is
exact; otherwise the amplitude peaks sharply on the nearest integer with a small spread onto
neighbours.

** Pseudocode

#+begin_example
PhaseEstimation(U with eigenphase phi, t counting qubits):
    counting register = |0..0>;  H on every counting qubit
    for j = 0..t-1:
        apply controlled-U^(2^j)     # kicks phase e^{2 pi i phi 2^j} onto qubit j
    inverse-QFT the counting register
    measure  ->  integer m;  estimate phi ~ m / 2^t
#+end_example

* A worked example

First an exact case, \(\varphi=3/8\) with \(t=3\) bits (\(2^3\varphi=3\), representable
exactly). Then a non-dyadic case, \(\varphi=0.3\) with \(t=5\) bits, where the estimate is the
nearest \(k/32\) and the distribution spreads slightly onto neighbours.

#+name: pe-run
#+begin_src c++ :eval no
    auto exact = phase_estimation(3, 0.375);
    std::cout << "=== QPE: exact dyadic phase phi = 3/8 = 0.375, t=3 ===\n";
    std::cout << "measured m = " << exact.measured << " -> estimate " << exact.estimate
              << ", probability " << exact.probability << "\n";

    const int t = 5;  double phi = 0.3;
    auto approx = phase_estimation(t, phi);
    std::cout << "\n=== QPE: non-dyadic phi = 0.3, t=5 (N=32) ===\n";
    std::cout << "true 2^t phi = " << phi * (1 << t) << " (not an integer)\n";
    std::cout << "measured m = " << approx.measured << " -> estimate " << approx.estimate
              << ", probability " << approx.probability << "\n";

    // Rebuild the t=5 counting-register distribution to show the peak + spread.
    QuantumState s = qstate_zero(t);
    for (int q = 0; q < t; ++q) h_gate(s, q);
    for (int q = 0; q < t; ++q) phase_gate(s, q, 2.0 * M_PI * phi * static_cast<double>(std::size_t{1} << q));
    inverse_qft(s, t);
    auto probs = probabilities(s);

    std::cout << "\ntop outcomes:\n";
    std::vector<double>      heights;
    std::vector<std::string> labels;
    for (std::size_t m = 0; m < probs.size(); ++m) {
        heights.push_back(probs[m]);
        labels.push_back((probs[m] > 0.03) ? std::to_string(m) : "");
        if (probs[m] > 0.05) std::cout << "  m = " << m << " (phi ~ " << double(m) / (1 << t)
                                       << "): P = " << probs[m] << "\n";
    }

    RPlot p = RPlot::barplot(heights, labels, "P(measure m)  [phi = m/32]", {37, 99, 235});
    p.save_svg("build/org/phase_estimation.svg");
    std::cout << "\nwrote build/org/phase_estimation.svg\n";
#+end_src

* Results

#+begin_example
=== QPE: exact dyadic phase phi = 3/8 = 0.375, t=3 ===
measured m = 3 -> estimate 0.375, probability 1

=== QPE: non-dyadic phi = 0.3, t=5 (N=32) ===
true 2^t phi = 9.6 (not an integer)
measured m = 10 -> estimate 0.3125, probability 0.573081

top outcomes:
  m = 9 (phi ~ 0.28125): P = 0.254867
  m = 10 (phi ~ 0.3125): P = 0.573081
#+end_example

The dyadic phase \(3/8\) is read out perfectly -- all the probability lands on \(m=3\), giving
\(\varphi=0.375\). For \(\varphi=0.3\) the ideal readout \(2^5\cdot0.3=9.6\) is not an integer,
so the distribution peaks on the nearest value \(m=10\) (\(\varphi\approx0.3125\)) with the rest
of the weight spread mostly onto \(m=9\); adding counting qubits narrows this spread and sharpens
the estimate. This ability to extract an eigenphase to arbitrary precision is exactly what
Shor's algorithm uses to turn period-finding into factoring.

* Character and relatives

QPE ties the quantum toolkit together: it is a QFT (companion report) wrapped around
controlled powers of a unitary, and it is the bridge from *period finding* (Simon/Shor) to
*eigenvalue estimation* (quantum chemistry, the HHL linear-systems algorithm). Its accuracy and
success probability trade off against the number of counting qubits and the cost of implementing
controlled-\(U^{2^j}\); *iterative* and *Bayesian* phase-estimation variants reduce the qubit
count at the price of more circuit repetitions, which matters on near-term hardware.

* Complexity

\(t\) Hadamards, \(t\) controlled-\(U^{2^j}\) applications, and an \(O(t^2)\) inverse QFT. The
state-vector simulation of the counting register is \(O(t\,2^t)\).
