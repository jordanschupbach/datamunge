#+begin_abstract
Plain Monte Carlo integration scatters samples uniformly and its error falls only as
\(1/\sqrt{N}\), no matter how the integrand is shaped -- wasteful when the mass is concentrated in a
small region. *MISER* (Press & Farrar, 1990) is *adaptive*: it recursively splits the domain where the
integrand varies most and pours samples into the high-variance sub-regions. This report drives
=datamunge='s =algorithms::miser_integrate=, verified against known integrals and shown to beat plain
Monte Carlo on a peaked integrand.
#+end_abstract

* Recursive stratified sampling

For a smooth integrand plain Monte Carlo is fine, but for a *peaked* one most uniform samples land where
the integrand is nearly zero and contribute almost nothing to reducing the variance. Stratified sampling
helps: split the region in two and the total variance is minimized by allocating samples to each half in
proportion to its standard deviation \(\sigma\),

\[ \operatorname{Var}\ \text{minimized when}\quad \frac{N_a}{N_b}=\frac{\sigma_a}{\sigma_b}. \]

MISER applies this recursively. At each level it:

1. draws a small *pilot* sample and, for each coordinate, estimates the integrand's variance in the two
   halves obtained by bisecting at the midpoint;
2. picks the coordinate whose bisection minimizes \(\sigma_a+\sigma_b\) (the split that best separates
   high- from low-variance regions);
3. allocates the remaining samples to the two halves in proportion to their \(\sigma\), and *recurses*.

The recursion bottoms out in plain Monte Carlo on small regions. By concentrating effort where the
integrand actually changes, MISER's error can fall much faster than the plain \(1/\sqrt N\) for peaked or
anisotropic integrands -- while remaining unbiased -- which is why it (and its cousin VEGAS) are the
default multidimensional integrators in scientific libraries.

* Algorithm

#+begin_example
MISER(f, a, b, calls):
  if calls small: return plain Monte Carlo estimate on [a,b]
  draw a pilot sample; for each dimension estimate sigma_left, sigma_right of the midpoint halves
  pick the dimension minimizing sigma_left + sigma_right; bisect there
  n_left = remaining * sigma_left / (sigma_left + sigma_right);  n_right = remaining - n_left
  return MISER(f, left half, n_left) + MISER(f, right half, n_right)
#+end_example

* Worked example: a sharply peaked integrand

We integrate a narrow Gaussian bump over the unit square (true value \(\pi/200\)) with MISER and with
plain Monte Carlo at the same budget, averaging the error over several seeds to compare their accuracy.

#+name: ms-run
#+begin_src c++ :eval no
    auto f = [](const std::vector<double>& x) {
        const double dx = x[0] - 0.5, dy = x[1] - 0.5;
        return std::exp(-200.0 * (dx * dx + dy * dy));
    };
    const double truth = M_PI / 200.0;

    std::cout << "=== MISER integration ===\n";
    const auto r = miser_integrate(f, {0, 0}, {1, 1}, 200000, 1);
    std::printf("narrow Gaussian bump:  MISER = %.6f   true = %.6f   |error| = %.2e\n",
                r.value, truth, std::fabs(r.value - truth));

    std::vector<double> budgets{2000, 5000, 10000, 20000, 50000, 100000}, mrms, prms;
    const int reps = 16;
    for (double N : budgets) {
        double me = 0, pe = 0;
        for (int seed = 1; seed <= reps; ++seed) {
            const double mv = miser_integrate(f, {0, 0}, {1, 1}, static_cast<long>(N), seed).value;
            me += (mv - truth) * (mv - truth);
            std::mt19937_64 rng(1000 + seed);
            std::uniform_real_distribution<double> u(0, 1);
            double s = 0;
            for (long k = 0; k < static_cast<long>(N); ++k) { const double a = u(rng), b = u(rng), dx = a - 0.5, dy = b - 0.5; s += std::exp(-200.0 * (dx * dx + dy * dy)); }
            const double pv = s / N;
            pe += (pv - truth) * (pv - truth);
        }
        mrms.push_back(std::sqrt(me / reps));
        prms.push_back(std::sqrt(pe / reps));
    }
    std::cout << "     N     MISER RMS    plain RMS\n";
    for (std::size_t i = 0; i < budgets.size(); ++i)
        std::printf("  %6.0f    %.3e    %.3e\n", budgets[i], mrms[i], prms[i]);

    auto plot = RPlot::create();
    plot.line(budgets, prms, "plain", RGB{220, 120, 120}, 2.0);
    plot.points(budgets, prms, "plain", RGB{220, 120, 120}, 5.0);
    plot.line(budgets, mrms, "miser", RGB{37, 99, 235}, 2.2);
    plot.points(budgets, mrms, "miser", RGB{37, 99, 235}, 5.0);
    plot.legend({"plain Monte Carlo", "MISER"}, {{220, 120, 120}, {37, 99, 235}});
    plot.title("MISER's error falls faster than plain Monte Carlo on a peaked integrand")
        .x_label("samples N").y_label("RMS error (log scale)").background({250, 250, 252});
    plot.save_svg("build/org/miser.svg");
    std::cout << "\nwrote miser.svg\n";
#+end_src

below plain Monte Carlo's -- the adaptive splitting pays off exactly where uniform sampling struggles.

Both methods descend on the log axis, but the blue MISER curve stays consistently under the red
plain-Monte-Carlo one: the same number of samples buys a smaller error because MISER spent them where the
integrand actually lived. That variance reduction, achieved automatically by recursively bisecting toward
the peak, is what makes stratified samplers the default for the multidimensional integrals of physics and
finance.
