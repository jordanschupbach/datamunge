#+begin_abstract
Heap's algorithm lists all permutations with one swap between neighbours, but that
swap can be of any two positions. The *Steinhaus-Johnson-Trotter* (SJT) algorithm
does something stronger: consecutive permutations differ by a single transposition
of two /adjacent/ positions. It is a *Gray code* for permutations -- the ordering
in which physical bell-ringers change a peal, and in which the largest element
sweeps back and forth like a shuttle. This report implements it in =datamunge='s
C++ =algorithms::sjt_permutations=, explains the "mobile element" rule, lists all
24 permutations of \(\{1,2,3,4\}\), and plots each value's position over time to
reveal the characteristic weaving of adjacent swaps.
#+end_abstract

* Mobile elements and directions

Give every element a *direction*, initially pointing left. An element is *mobile*
if the neighbour it points at exists and is smaller than it. One step of SJT is:

1. find the *largest mobile element* \(m\);
2. swap \(m\) with the (adjacent) neighbour it points at;
3. reverse the direction of every element /greater/ than \(m\).

Repeat until no element is mobile. Because step 2 only ever swaps adjacent
positions, consecutive permutations differ by a single adjacent transposition.
The direction-reversal in step 3 is what lets the largest elements repeatedly
traverse the whole array: the biggest element marches to one wall, a smaller one
ticks over, and the biggest marches back -- a permutation odometer. The process
emits all \(n!\) permutations.

* Algorithm

#+begin_example
SJT(n):
  perm <- [1, 2, ..., n];  dir[v] <- LEFT for every value v
  output(perm)
  loop:
      m <- largest value whose direction points at a smaller neighbour   # "mobile"
      if no such value: stop
      swap m with that neighbour
      for every value v > m: reverse dir[v]
      output(perm)
#+end_example

* Worked example: all permutations of {1, 2, 3, 4}

The program lists all \(4!=24\) permutations in SJT order and checks that each
consecutive pair differs by swapping two /adjacent/ positions.

#+name: sjt-run
#+begin_src c++ :eval no
    const std::size_t n = 4;
    const auto perms = sjt_permutations(n);

    std::cout << "=== Steinhaus-Johnson-Trotter: " << perms.size() << " permutations of {1,2,3,4} ===\n";
    for (std::size_t s = 0; s < perms.size(); ++s) {
        std::cout << "  " << (s + 1 < 10 ? " " : "") << s + 1 << ": ";
        for (int x : perms[s]) std::cout << x;
        if (s > 0) {
            std::size_t p = 0;
            while (p < n && perms[s][p] == perms[s - 1][p]) ++p;
            std::cout << "   (swapped adjacent positions " << p << "," << p + 1 << ")";
        }
        std::cout << "\n";
    }

    // Plot: the position of each value over the 24 steps -- adjacent swaps make ±1 zig-zags.
    auto plot = RPlot::create();
    const std::vector<RGB> palette = {{37, 99, 235}, {220, 38, 38}, {22, 163, 74}, {202, 138, 4}};
    for (int v = 1; v <= static_cast<int>(n); ++v) {
        std::vector<double> xs, ys;
        for (std::size_t s = 0; s < perms.size(); ++s)
            for (std::size_t p = 0; p < n; ++p)
                if (perms[s][p] == v) { xs.push_back(static_cast<double>(s)); ys.push_back(static_cast<double>(p)); }
        plot.line(xs, ys, "value " + std::to_string(v), palette[static_cast<std::size_t>(v - 1)], 2.0);
    }
    plot.legend({"1", "2", "3", "4"}, palette);
    plot.title("SJT: each value's position weaves by single adjacent swaps")
        .x_label("permutation index").y_label("position").background({250, 250, 252});
    plot.y_limits(-0.5, static_cast<double>(n) - 0.5);
    plot.save_svg("build/org/steinhaus_johnson_trotter.svg");
    std::cout << "\nwrote steinhaus_johnson_trotter.svg\n";
#+end_src

Every step swaps two /adjacent/ positions -- the defining property that makes SJT
a Gray code for permutations, stronger than Heap's "any single swap". The value 4,
being largest, is mobile most often and sweeps the full width of the array
repeatedly, the permutation odometer's fastest wheel.
