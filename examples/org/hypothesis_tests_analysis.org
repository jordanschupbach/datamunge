three species' petal lengths ($F=1180.16$, $H=130.41$, again both

($[0.056, 0.174]$) excludes 1 by a wide margin; a normality assessment of
setosa sepal length using the Shapiro-Francia and Kolmogorov-Smirnov

plot that shows why; and a chi-squared test of independence against

genuine structural zero -- no setosa flower's petal exceeds the pooled

* Introduction

Every report so far in this project has fit a /model/: a set of
parameters chosen to best explain data under some working assumption
about how the data were generated. This report is different in kind.
Hypothesis testing does not fit anything -- it asks a sharper, narrower
question: given a specific null hypothesis about the population (two
groups have the same mean, a variable is uncorrelated with another, a
sample came from a normal distribution), how surprising is the data we
actually observed? =datamunge='s =stats= module answers this question
for thirteen distinct tests spanning location, dispersion, association,
distributional shape, categorical independence, and proportions, each
returning a single shared result type (§2.1) mirroring R's =htest= S3
class.

The organizing idea behind every classical test in this family is a
trade: a parametric test (the \(t\)-test, ANOVA, Pearson correlation, the
\(F\)-test) assumes a specific population distribution -- almost always
normality -- in exchange for higher power when that assumption holds. Its
nonparametric or exact counterpart (the Wilcoxon test, Kruskal-Wallis,
Spearman correlation, Fisher's exact test) drops that assumption, trading
some power under ideal conditions for validity under a much wider range
of real-world data. This report pairs each classical test directly
against its distribution-free counterpart on the same data, so that every
comparison in §4 answers not just "is the null hypothesis rejected?" but
"does the answer depend on the normality assumption?"

As with its companions, this document is a /literate program/: prose and
source are interleaved in reading order, and a single "assembling the
program" step (§3.3.10) weaves every named chunk below into one =.cpp=
file, compiles it, and runs it. Every number and figure from §4 onward is
that program's literal output.

§2 derives each test's statistic and null distribution, grouped into the
six thematic pairs (plus one single-test dispersion comparison) that
structure the rest of the report, and ties each derivation to the
specific library call that implements it. §3 describes the program chunk
by chunk, including a real library bug (§3.3.9) found and fixed while
building this report's figures. §4 reports the results of all thirteen tests
alongside four supporting figures. §5 discusses what the
parametric/nonparametric agreement (or disagreement) in each pair tells us. §6
concludes.

* Background: Hypothesis Testing

** The shared result type

Every test function in =datamunge::stats= returns a single
=HypothesisTestResult=:

#+begin_src c++ :eval no
struct HypothesisTestResult {
    double statistic{0.0};
    double parameter1{0.0};   // e.g. degrees of freedom
    double parameter2{0.0};   // e.g. a second df, for two-sample tests
    double p_value{0.0};
    double estimate1{0.0};    // e.g. a correlation coefficient or proportion
    double estimate2{0.0};
    double conf_int_lower{0.0};
    double conf_int_upper{0.0};
    bool   has_conf_int{false};
    Alternative alternative{Alternative::TwoSided};
    std::string method;
};
#+end_src

This mirrors R's =htest= class deliberately: every test, however
different its internal machinery, answers the same four questions --
what is the test statistic, under what null distribution, giving what
\(p\)-value, and (where applicable) what confidence interval and point
estimate accompany it. We report every field a given test populates
below; fields a test leaves at their default (=parameter2= for a
one-sample test, =has_conf_int= for tests with no natural interval) are
simply omitted from that test's printed line.

** Two-sample location: Welch's \(t\)-test and the Wilcoxon rank-sum test

The classical two-sample \(t\)-test asks whether two independent samples
$x_1,\ldots,x_{n_1}$ and $y_1,\ldots,y_{n_2}$ share the same population
mean. =t_test_two_sample= implements Welch's unequal-variance form by
default (matching R's =t.test()= default), using the Satterthwaite
approximation for degrees of freedom rather than assuming
$\sigma_x^2=\sigma_y^2$:

$$t = \frac{\bar{x}-\bar{y}}{\sqrt{s_x^2/n_1 + s_y^2/n_2}}, \qquad
\nu \approx \frac{\left(s_x^2/n_1 + s_y^2/n_2\right)^2}
{\dfrac{(s_x^2/n_1)^2}{n_1-1} + \dfrac{(s_y^2/n_2)^2}{n_2-1}}$$

Under $H_0: \mu_x=\mu_y$, $t$ follows (approximately) a Student's $t$
distribution on $\nu$ degrees of freedom. This test is only exactly valid
when both populations are normal, though it is well known to be robust
to moderate departures given reasonably large, similarly-sized samples.

=wilcoxon_rank_sum_test= (equivalently, the Mann-Whitney $U$ test) drops
the normality assumption entirely, testing instead whether $x$ and $y$
are drawn from distributions with the same /location/, whatever their
shape. It pools both samples, ranks every observation, and sums the ranks
belonging to $x$:

$$U = W - \frac{n_1(n_1+1)}{2}, \qquad
z = \frac{U - n_1n_2/2}{\sqrt{n_1n_2(n_1+n_2+1)/12}}$$

with a continuity correction and a tie-correction to the variance applied
by =wilcoxon_rank_sum_test= to match R's =wilcox.test()= behavior once
ties are present. Because it only uses ranks, this test is invariant to
any monotonic transformation of the data and remains valid under
arbitrary (non-normal) continuous distributions -- at the cost of
discarding the magnitude information a \(t\)-test uses.

** \(k\)-sample location: one-way ANOVA and Kruskal-Wallis

One-way ANOVA generalizes the two-sample \(t\)-test to $k\geq2$ independent
groups, testing $H_0:\mu_1=\cdots=\mu_k$ by comparing between-group and
within-group variance:

$$F = \frac{\text{MS}_{\text{between}}}{\text{MS}_{\text{within}}}
= \frac{\sum_g n_g(\bar{x}_g - \bar{x})^2 / (k-1)}
{\sum_g \sum_i (x_{gi}-\bar{x}_g)^2 / (N-k)}$$

Under $H_0$ and normality within each group, $F$ follows an
$F_{k-1,\,N-k}$ distribution. =one_way_anova= takes every group's values
concatenated into one vector plus a vector of group sizes, and returns
=statistic= = $F$, =parameter1= = $k-1$, =parameter2= = $N-k$.

The Kruskal-Wallis test is ANOVA's rank-based, distribution-free
counterpart. It ranks all $N$ observations across all $k$ groups jointly
and computes

$$H = \frac{12}{N(N+1)} \sum_g \frac{R_g^2}{n_g} - 3(N+1)$$

where $R_g$ is the sum of ranks in group $g$, with a tie correction
applied. Under $H_0$, $H$ is approximately \(\chi^2_{k-1}\)-distributed.
=kruskal_wallis_test= shares the exact same =(values, group_sizes)= call
signature as =one_way_anova=, making the two directly interchangeable in
the program below.

** Association: Pearson and Spearman correlation

=pearson_correlation_test= tests $H_0:\rho=0$ for the population
correlation between two continuous variables, using the sample Pearson
correlation

$$r = \frac{\sum_i (x_i-\bar{x})(y_i-\bar{y})}
{\sqrt{\sum_i(x_i-\bar{x})^2}\sqrt{\sum_i(y_i-\bar{y})^2}}, \qquad
t = r\sqrt{\frac{n-2}{1-r^2}} \sim t_{n-2} \text{ under } H_0$$

Its confidence interval for $\rho$ uses Fisher's variance-stabilizing $z$
transform, $z=\operatorname{arctanh}(r)$, which is approximately normal
with variance $1/(n-3)$ regardless of $\rho$'s true value.

=spearman_correlation_test= computes the same Pearson correlation, but on
the /ranks/ of $x$ and $y$ rather than their raw values (=estimate1=
becomes $\rho_S$), with a \(p\)-value from the same \(t\)-approximation. This
tests only whether $x$ and $y$ have a /monotonic/ association, not
specifically a linear one, and is insensitive to outliers and
nonlinear-but-monotonic relationships that would inflate or deflate a raw Pearson
$r$.

** Dispersion: the \(F\)-test for equality of variance

=f_test_variance= tests $H_0:\sigma_x^2=\sigma_y^2$ via the ratio of
sample variances,

$$F = \frac{s_x^2}{s_y^2} \sim F_{n_1-1,\,n_2-1} \text{ under } H_0$$

=estimate1= reports this ratio directly, and =has_conf_int= is populated
with a confidence interval for the true variance ratio. Unlike the
\(t\)-test's Welch correction, there is no widely-used distribution-free
drop-in replacement for this specific test in the same way Wilcoxon
replaces the \(t\)-test -- variance comparisons are intrinsically more
sensitive to non-normality than location comparisons, which is one reason
Welch's \(t\)-test (not assuming equal variance) has become the default
two-sample location test in the first place.

** Normality: Shapiro-Francia and Kolmogorov-Smirnov

=shapiro_francia_test= tests $H_0:$ "the sample is drawn from /some/
normal distribution" by correlating the sorted sample against the
expected normal order statistics (Blom's approximation),

$$W' = \frac{\left(\sum_i m_i x_{(i)}\right)^2}
{\sum_i(x_{(i)}-\bar{x})^2 \sum_i m_i^2}$$

where $m_i$ are the expected standard-normal order statistics and
$x_{(i)}$ the sorted sample; =estimate1= reports $W'$ directly (near 1
for normal-looking data), with a \(p\)-value from Royston's (1993)
log-normal approximation to $W'$'s null distribution. A small \(p\)-value
is evidence /against/ normality -- exactly the opposite reading from
every other test in this report, where a small \(p\)-value indicates a
real effect.

=ks_test_one_sample_normal= instead compares the empirical CDF of the
sample against a /specific, fully-parameterized/ normal CDF
$\Phi(\cdot;\mu,\sigma)$ using the maximum absolute deviation,

$$D = \sup_x \left| F_n(x) - \Phi(x;\mu,\sigma)\right|$$

with a \(p\)-value from the asymptotic Kolmogorov distribution. Because
this requires $\mu$ and $\sigma$ to be supplied rather than estimated
from the same sample, we plug in the sample mean and standard deviation
below -- a common practical compromise, though one that technically makes
the reported \(p\)-value a slight overestimate. The two tests probe
normality from different angles: Shapiro-Francia is a correlation-based
test focused on the overall shape of the order statistics, while
Kolmogorov-Smirnov is a worst-case-deviation test anywhere along the
CDF. We accompany both with a quantile-quantile plot (via
=RPlot::qqnorm= / =qqline=), the direct visual counterpart of what
Shapiro-Francia's $W'$ is measuring numerically.

** Categorical association: chi-squared and Fisher's exact test

=chi_squared_test_independence= tests independence of two categorical
variables laid out in an $r\times c$ contingency table, comparing
observed counts $O_{ij}$ against the counts $E_{ij}$ expected under
independence (row total $\times$ column total $/$ grand total):

$$\chi^2 = \sum_{i,j} \frac{(O_{ij}-E_{ij})^2}{E_{ij}} \sim \chi^2_{(r-1)(c-1)}
\text{ under } H_0$$

For a $2\times2$ table, =chi_squared_test_independence= applies Yates'
continuity correction by default (matching R's =chisq.test()=), which
shrinks each $|O_{ij}-E_{ij}|$ by $0.5$ before squaring to compensate for
approximating a discrete count distribution with a continuous $\chi^2$
curve.

That approximation itself can fail when expected cell counts are small.
=fisher_exact_test_2x2= sidesteps the approximation entirely, computing
the /exact/ probability of the observed table (and every table at least
as extreme) under the hypergeometric distribution conditional on the
observed margins:

$$P(\text{table}) = \frac{\binom{a+b}{a}\binom{c+d}{c}}{\binom{n}{a+c}},
\qquad n=a+b+c+d$$

summed over all tables with the same margins that are at least as
extreme as the observed one. =estimate1= reports the sample odds ratio
$ad/(bc)$ directly (not R's default conditional MLE odds ratio), and no
confidence interval is computed.

** Proportions: the one-sample proportion test and the exact binomial test

=proportion_test_one_sample= tests $H_0: p=p_0$ for a single proportion
using the normal approximation to the binomial, with a continuity
correction (matching R's =prop.test()=):

$$z = \frac{|\hat p - p_0| - \frac{1}{2n}}{\sqrt{p_0(1-p_0)/n}}, \qquad
z^2 \sim \chi^2_1 \text{ under } H_0$$

Its confidence interval uses the Wilson score interval, which -- unlike
the naive $\hat p \pm z\sqrt{\hat p(1-\hat p)/n}$ interval -- stays inside
$[0,1]$ and has substantially better coverage near the boundary.

=binomial_test= computes the exact \(p\)-value by summing binomial
probabilities directly, with no normal approximation at all, and reports
the exact Clopper-Pearson confidence interval. It is the proportion
analog of Fisher's exact test: always valid, at the cost of being more
conservative (wider intervals, larger \(p\)-values) than the approximate
version when $n$ is small.

* Data and Methods

** The data

We use the iris dataset throughout (150 flowers, 3 species, 50 each),
already used extensively in the [[file:lda_iris_analysis.org][LDA]],
[[file:naive_bayes_penguins_analysis.org][Naive Bayes]], and
[[file:clustering_iris_analysis.org][clustering]] companion reports. Its
appeal here is the same as in those reports: real biological measurements
with a genuine grouping structure (species) that we can use to construct
meaningful two-sample and \(k\)-sample comparisons, plus two continuous
measurements (sepal length, petal length) whose real correlation gives a
non-trivial association test.

** Software

All computation uses =datamunge='s C++ =stats= module -- specifically
=stats::t_test=, =stats::wilcoxon_test=, =stats::anova_test=,
=stats::correlation_test=, =stats::variance_test=,
=stats::normality_test=, =stats::ks_test=, =stats::chi_squared_test=,
=stats::fisher_exact_test=, and =stats::proportion_test= -- together with
=plot::RPlot= for visualization. Unlike every DataFrame-and-formula-based
class used elsewhere in this project, every function here takes plain
=std::vector<double>= arguments (or, for =fisher_exact_test_2x2= and the
proportion tests, raw counts), reflecting hypothesis tests' generality:
they operate on any numeric sample, not specifically on rows of a
DataFrame.

const char* alternative_name(Alternative a) {
    switch (a) {
        case Alternative::Less: return "less";
        case Alternative::Greater: return "greater";
        default: return "two.sided";
    }
}

void print_result(const std::string& label, const HypothesisTestResult& r) {
    std::cout << label << ": statistic=" << r.statistic;
    if (r.parameter1 != 0.0) std::cout << ", df1=" << r.parameter1;
    if (r.parameter2 != 0.0) std::cout << ", df2=" << r.parameter2;
    std::cout << ", p=" << r.p_value << " ("
              << alternative_name(r.alternative) << ")";
    if (r.has_conf_int) {
        std::cout << ", CI=[" << r.conf_int_lower << ", "
                   << r.conf_int_upper << "]";
    }
    std::cout << " -- " << r.method << "\n";
}

std::vector<double> column_for_species(const datamunge::dstruct::DataFrame& iris,
                                        const std::string& column,
                                        const std::string& species) {
    std::vector<double> out;
    for (std::size_t i = 0; i < iris.nrows(); ++i) {
        if (iris.string_at("Species", i) == species) {
            out.push_back(iris.double_at(column, i));
        }
    }
    return out;
}

*** A real plotting-library bug, found and fixed

While first generating the two boxplot figures above, both rendered with
each box spanning more than half the plot's total width and bleeding off
both edges of the canvas. The cause was in =RPlot::boxplot='s automatic
axis-scaling routine (=compute_bounds= in =src/datamunge/plot.cpp=):
when computing the \(x\)-axis range to fit around the group positions
$0,1,\ldots,k-1$, it included only each box's /center/ position, not its
visual extent at =bar_width/2= to either side, then added a fixed 5%
padding on top of that already-too-tight range. With only two or three
groups spaced one unit apart, a box's half-width (0.3 units, for the
default =bar_width=0.6=) is far larger than the resulting padding
(0.05 units), so every box overflowed its own axes. The same bug affects
=RPlot::bars= / =RPlot::barplot= for the same reason, though it is far less
visible there since realistic bar charts typically have enough categories
that the auto-computed range grows faster than any single bar's width.
The fix, applied directly in the library, extends the bounds computation
to include each box's and bar's left and right visual edges (position
$\pm$ =bar_width/2=), not just its center:

#+begin_src c++ :eval no
// before: only the box/bar center position entered the x-range computation
if (series.kind == DataSeries::Kind::Box) {
    const double position = series.x.empty() ? 0.0 : series.x[0];
    for (double value : series.y) include(position, value);
    continue;
}
// after: both visual edges (position +/- bar_width/2) enter the computation
if (series.kind == DataSeries::Kind::Box) {
    const double position = series.x.empty() ? 0.0 : series.x[0];
    const double half     = series.bar_width / 2.0;
    for (double value : series.y) {
        include(position - half, value);
        include(position + half, value);
    }
    continue;
}
#+end_src

(The analogous change applies to the =Bar= case a few lines below.) All
four figures in §4 below were generated against the corrected library.

** Categorical association: "long" petals vs. species

#+begin_example
table: setosa=[0,50] versicolor=[21,29]
Chi-squared independence: statistic=24.1109, df1=1.0000, p=0.0000 (two.sided)
  -- Pearson's Chi-squared test with Yates' continuity correction
Fisher's exact test: statistic=0.0000, p=0.0000 (two.sided)
  -- Fisher's Exact Test for Count Data
#+end_example

Discretizing petal length at the pooled median (=2.45= cm) produces a
striking $2\times2$ table: /every single/ setosa flower falls at or below
the median, while versicolor splits 21 "long" to 29 "short." The
chi-squared test rejects independence decisively ($\chi^2=24.11$, 1 df,
$p$ underflowing to zero at four decimals), but this is exactly the kind
of table -- a zero cell -- where the chi-squared approximation is least
trustworthy, since the expected count in that cell is small relative to
what the continuous $\chi^2$ curve assumes. Fisher's exact test, which
makes no approximation at all, agrees on significance but with a
precisely computable \(p\)-value of $6.59\times10^{-8}$ (below the
four-decimal display precision used elsewhere, so it also prints as
=0.0000=). Because $a=0$ (no long-petaled setosa flowers), the sample
odds ratio $ad/(bc)$ is exactly 0 -- a real structural zero, not a
rounding artifact, reflecting genuine perfect separation between setosa
and "long petal" status in this sample.

** Proportions: fraction of "long" petals overall

#+begin_example
One-sample proportion test (vs 0.5): statistic=0.3267, df1=1.0000,
  p=0.5676 (two.sided), CI=[0.3951, 0.5529]
  -- 1-sample proportions test with continuity correction
Exact binomial test (vs 0.5): statistic=71.0000, df1=150.0000, p=0.5678 (two.sided),
  CI=[0.3913, 0.5564] -- Exact binomial test
#+end_example

Pooling all three species, 71 of 150 flowers (47.3%) have "long" petals
by the same pooled-median threshold, close enough to a 50/50 split that
neither test rejects $H_0:p=0.5$. The normal-approximation test
($p=0.5676$) and the exact binomial test ($p=0.5678$) agree to three
decimal places, and their confidence intervals ($[0.395, 0.553]$ Wilson
vs. $[0.391, 0.556]$ Clopper-Pearson) differ by only a few thousandths --
with $n=150$ and a proportion well away from 0 or 1, the normal
approximation that underlies the faster test is essentially exact here.

* Discussion

**Every parametric/nonparametric pair agreed on significance in this
report -- but for different reasons in different sections.** In §4.1,
§4.2, and §4.3, the underlying group differences and correlation are so
large relative to the sample sizes that no reasonable test, parametric or
not, could fail to detect them; the pairs' agreement mostly demonstrates
that the parametric assumption (normality within each species) was never
the deciding factor for these particular comparisons. §4.7's proportion
comparison shows the opposite situation: agreement not because the effect
is overwhelming, but because $n=150$ is large enough for the normal
approximation to be essentially exact even for a modest, non-significant
effect. The one place we would expect to actually see the parametric and
exact approaches diverge -- §4.6's zero-cell $2\times2$ table, precisely
the small-expected-count scenario where the chi-squared approximation is
least reliable -- both approaches still agreed on significance, though
Fisher's exact test alone gives a \(p\)-value ($6.59\times10^{-8}$) precise
enough to be meaningfully compared against a stringent significance
threshold, where the chi-squared approximation's \(p\)-value can only be
trusted qualitatively.

**Structural zeros are a real, not hypothetical, hazard of discretizing
continuous data.** §4.6's zero cell arose entirely from our own modeling
choice -- splitting petal length at the pooled median rather than at a
species-specific threshold -- not from any property of the biology
itself. It is a useful reminder that Fisher's exact test's odds-ratio
estimate (exactly 0 here) is not always usable as a standalone summary
number the way the chi-squared statistic is; when a table has a zero
cell, the odds ratio sits at a boundary of its own definition, and only
the \(p\)-value (and, in software that computes it, the profile-likelihood
confidence interval) remains fully informative.

**A small, quantitative correlation-test disagreement matched a real
qualitative feature of the data.** Spearman's statistic ($22.76$) was
noticeably larger than Pearson's ($21.65$) in §4.3, and the scatter plot
explains exactly why: species clustering introduces a visible small bend
in what is otherwise a strong linear trend, which a rank-based (purely
monotonic) test is insensitive to but a linear-correlation test is not.
This is the report's clearest example of the general principle from §1 --
that a nonparametric test's robustness is not merely a hedge against
distributional violations in the abstract, but can produce a
/measurably/ different, and in this specific sense more appropriate,
answer on real data.

**Finding a real bug in a plotting library while building a report about
statistical rigor is a fitting coincidence.** §3.3.9's boxplot
axis-scaling bug was caught the same way every other bug in this
project's line of reports has been caught: by looking closely at what the
program actually produced (an obviously-wrong figure) rather than
assuming the pipeline that generated a number or an image was correct
simply because it compiled and ran without error.

* Conclusion

Applying thirteen hypothesis tests across seven thematic groupings to the
iris dataset with =datamunge='s C++ =stats= module, every
parametric/nonparametric or approximate/exact pair reached the same
qualitative conclusion about significance, though for different
underlying reasons: overwhelming effect size in the location and
association comparisons (§4.1-§4.3), a large sample size making the
normal approximation essentially exact in the proportion comparison
(§4.7), and a case (§4.6) where only the exact test could report a
\(p\)-value precise enough to be fully trusted given a zero-cell table.
Building this report's first two figures also surfaced and fixed a real
=RPlot::boxplot= axis-scaling bug in the library itself (§3.3.9), fixed
before generating any of the final figures shown here. As with its
companions, this entire report is reproducible end to end via
=just org-example hypothesis_tests_analysis=, which re-executes §3.3.10's
assembly block -- and therefore every number and figure above -- from the
=datamunge= source tree.
