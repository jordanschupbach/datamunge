#+begin_abstract
The eigenvalues of a matrix are the roots of its characteristic polynomial -- but forming and rooting that
polynomial is hopelessly unstable. The *QR algorithm* instead finds all eigenvalues by a sequence of
*orthogonal similarity transformations*: factor \(A=QR\), reverse the product to \(RQ\), and repeat. The
matrix marches toward triangular form with the eigenvalues on its diagonal. This report drives
=datamunge='s =algorithms::qr_eigenvalues=, verified to recover known spectra of symmetric matrices to
machine precision, and shows the off-diagonal mass vanishing.
#+end_abstract

* Factor, reverse, repeat -- with a shift

Every matrix factors as \(A=QR\) with \(Q\) orthogonal and \(R\) upper triangular (Gram-Schmidt or
Householder). The QR *iteration* forms the reversed product

\[ A'=RQ=Q^\top A Q, \]

which is *orthogonally similar* to \(A\) -- same eigenvalues -- but with its weight nudged toward the
diagonal. Repeating, \(A^{(k)}\) converges to (block) upper-triangular form whose diagonal holds the
eigenvalues; for a symmetric matrix the limit is diagonal. Convergence of the plain iteration is only
linear, governed by ratios of eigenvalue magnitudes, so in practice each step first subtracts a *shift*
\(\mu I\), runs QR on \(A-\mu I\), and adds \(\mu I\) back:

\[ A-\mu I=QR,\qquad A'=RQ+\mu I. \]

Choosing \(\mu\) as the *Wilkinson shift* -- the eigenvalue of the trailing \(2\times2\) block closer to
the corner entry -- makes the bottom off-diagonal entry shrink *cubically*. Once it is negligible, the
corner eigenvalue is *deflated* off and the iteration continues on the smaller leading block. Tridiagonal
reduction beforehand makes each step cheap, and the whole method is the backbone of every dense
eigenvalue routine -- LAPACK's included.

* Algorithm

#+begin_example
QR-EIGENVALUES(A):                          # A symmetric
  for block size m = n down to 1:
      repeat:
          mu = Wilkinson shift from the trailing 2x2 of the active block
          A = A - mu I;  factor A = Q R;  A = R Q;  A = A + mu I
          if the last off-diagonal entry is negligible: break
      record A[m-1][m-1] as an eigenvalue; deflate to the (m-1) block
  return the sorted eigenvalues
#+end_example

* Worked example: a symmetric matrix with a known spectrum

We build a symmetric matrix with eigenvalues \(\{-4,1,3,8\}\) and confirm the QR algorithm recovers them.
The figure tracks the off-diagonal "mass" collapsing as the iteration proceeds on a small matrix.

#+name: qr-run
#+begin_src c++ :eval no
    // Symmetric A with known eigenvalues {-4, 1, 3, 8}: A = Q diag Q^T for a fixed orthogonal Q.
    auto qcol = [](int i, int j) { // a fixed orthonormal basis (rotations)
        static const double Q[4][4] = {
            {0.5, 0.5, 0.5, 0.5}, {0.5, -0.5, 0.5, -0.5}, {0.5, 0.5, -0.5, -0.5}, {0.5, -0.5, -0.5, 0.5}};
        return Q[i][j];
    };
    const double d[4] = {-4, 1, 3, 8};
    std::vector<std::vector<double>> A(4, std::vector<double>(4, 0));
    for (int i = 0; i < 4; ++i)
        for (int j = 0; j < 4; ++j) { double s = 0; for (int k = 0; k < 4; ++k) s += qcol(i, k) * d[k] * qcol(j, k); A[i][j] = s; }

    const auto e = qr_eigenvalues(A);
    std::cout << "=== QR algorithm eigenvalues ===\n";
    std::cout << "true spectrum:      -4  1  3  8\n";
    std::cout << "computed spectrum: ";
    for (double v : e) std::printf(" %.4f", v);
    std::cout << "\n";

    // Convergence: eigenvalue error against the fully-converged result as the
    // iteration cap grows, on a small symmetric matrix.
    std::vector<std::vector<double>> B = {{4, 1, 0.5}, {1, 3, 0.8}, {0.5, 0.8, 2}};
    const auto full = qr_eigenvalues(B, 1000, 1e-14);
    std::vector<double> it, mass;
    for (int cap : {1, 2, 3, 4, 6, 8, 12, 20}) {
        const auto ev = qr_eigenvalues(B, cap, 1e-16);
        double err = 0; for (std::size_t i = 0; i < ev.size(); ++i) err = std::max(err, std::fabs(ev[i] - full[i]));
        it.push_back(cap); mass.push_back(std::max(1e-16, err));
    }

    auto plot = RPlot::create();
    plot.line(it, mass, "err", RGB{37, 99, 235}, 2.2);
    plot.points(it, mass, "err", RGB{37, 99, 235}, 5.0);
    plot.legend({"eigenvalue error vs iterations"}, {{37, 99, 235}});
    plot.title("Shifted QR converges the eigenvalues in a few iterations (log scale)")
        .x_label("iteration cap").y_label("max eigenvalue error").background({250, 250, 252});
    plot.save_svg("build/org/qr_algorithm.svg");
    std::cout << "\nwrote qr_algorithm.svg\n";
#+end_src

The QR algorithm recovers the planted spectrum \(\{-4,1,3,8\}\) to full precision, and on the \(3\times3\)
example its eigenvalue error plummets within a handful of iterations -- the cubic convergence the
Wilkinson shift buys.

The error curve drops almost vertically on the log axis before flattening at the floor of double
precision: once each corner off-diagonal is shifted toward zero it collapses cubically, the eigenvalue
deflates, and the iteration moves on. Factor, reverse, shift, deflate -- that simple loop, stabilized by
orthogonal transformations, is why the QR algorithm has been the definitive way to compute eigenvalues for
over sixty years.
