#+begin_abstract
How precise is an estimate? For the sample mean the answer is the textbook
\(s/\sqrt n\), but for a median, a trimmed mean, or a ratio there is often no
tidy formula. Efron's (1979) *nonparametric bootstrap* answers the question
for /any/ statistic by brute force: it treats the sample as a stand-in for
the population and resamples from it -- drawing \(n\) observations with
replacement, many times over -- to reconstruct the statistic's sampling
distribution empirically. This report implements the bootstrap in
=datamunge='s C++ =stats::Bootstrap= and presents it as a literate program:
every number and figure is produced by a single compiled binary whose source
is the code chunks shown. We derive the plug-in principle behind the method,
the resampling estimates of standard error and bias, and four kinds of
confidence interval -- percentile, basic, normal, and the bias-corrected and
accelerated (BCa) interval -- then apply them to the median of iris
=Sepal.Length=, a statistic with no elementary standard error. As a check
that the machine is calibrated, the bootstrap standard error of the /mean/
comes out at 0.067, matching the closed-form \(s/\sqrt n = 0.068\) to three
digits.
#+end_abstract

* The plug-in principle

A statistic is a functional \(\theta = T(F)\) of the unknown distribution
\(F\) that generated the data -- the mean is \(T(F)=\int x\,dF\), the median
is \(T(F)=F^{-1}(1/2)\), and so on. The natural estimate replaces \(F\) with
the *empirical distribution* \(\hat F_n\) that puts mass \(1/n\) on each
observed point: \(\hat\theta = T(\hat F_n)\). This is the /plug-in/
estimator. Its sampling variability is governed by how \(\hat\theta\) would
change if we drew fresh samples from \(F\) -- which we cannot do, because we
have only the one sample.

The bootstrap's idea is to substitute \(\hat F_n\) for \(F\) in that thought
experiment too. A *bootstrap sample* \(X^\star = (X_1^\star,\dots,X_n^\star)\)
is drawn i.i.d. from \(\hat F_n\) -- equivalently, \(n\) draws /with
replacement/ from the observed data -- and the *bootstrap replicate* is
\(\hat\theta^\star = T(\hat F_n^\star)\). Repeating this \(B\) times yields
replicates \(\hat\theta^\star_1,\dots,\hat\theta^\star_B\) whose spread
approximates the true sampling distribution of \(\hat\theta\), with the
Monte Carlo error made negligible by taking \(B\) large.

#+name: boot-includes
#+begin_src c++ :eval no
#include <datamunge/datasets/datasets.hpp>
#include <datamunge/dstruct/dataframe.hpp>
#include <datamunge/plot/plot.hpp>
#include <datamunge/stats/bootstrap.hpp>

#include <algorithm>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <numeric>
#include <vector>

using namespace datamunge::stats;
using namespace datamunge::plot;

static double mean_of(const std::vector<double>& v) {
    return std::accumulate(v.begin(), v.end(), 0.0) / static_cast<double>(v.size());
}
static double median_of(std::vector<double> v) {
    std::sort(v.begin(), v.end());
    const std::size_t n = v.size();
    return n % 2 ? v[n / 2] : 0.5 * (v[n / 2 - 1] + v[n / 2]);
}
static double sd_of(const std::vector<double>& v) {
    const double m = mean_of(v);
    double s = 0.0;
    for (double x : v) s += (x - m) * (x - m);
    return std::sqrt(s / static_cast<double>(v.size() - 1));
}
#+end_src

* Standard error, bias, and confidence intervals

From the \(B\) replicates the bootstrap reads off two summaries directly:
\[
  \widehat{\mathrm{se}}_{\text{boot}}
    = \sqrt{\tfrac{1}{B-1}\sum_{b=1}^{B}\big(\hat\theta^\star_b - \bar\theta^\star\big)^2},
  \qquad
  \widehat{\mathrm{bias}}_{\text{boot}} = \bar\theta^\star - \hat\theta,
\]
where \(\bar\theta^\star\) is the mean of the replicates. Confidence intervals
require a little more care; =datamunge= returns four, in increasing order of
sophistication. Writing \(\hat\theta^\star_{(q)}\) for the \(q\)-quantile of
the replicates and \(z_q = \Phi^{-1}(q)\), and with \(\alpha = 1-\)level:

- *Percentile*: \(\big[\hat\theta^\star_{(\alpha/2)},\ \hat\theta^\star_{(1-\alpha/2)}\big]\) -- the empirical quantiles of the replicates.
- *Basic* (reverse-percentile): \(\big[\,2\hat\theta - \hat\theta^\star_{(1-\alpha/2)},\ 2\hat\theta - \hat\theta^\star_{(\alpha/2)}\big]\), which reflects the percentile interval through the point estimate to undo the direction of any bias.
- *Normal*: \((\hat\theta - \widehat{\mathrm{bias}}) \pm z_{1-\alpha/2}\,\widehat{\mathrm{se}}_{\text{boot}}\).
- *BCa* (Efron 1987): a percentile interval whose endpoints are shifted to correct for both median bias and a variance that changes with \(\theta\). It uses a bias-correction \(z_0 = \Phi^{-1}\!\big(\#\{\hat\theta^\star_b < \hat\theta\}/B\big)\) and an acceleration \(a\) estimated from the jackknife leave-one-out values \(\hat\theta_{(i)}\),
  \[
    a = \frac{\sum_i (\hat\theta_{(\cdot)} - \hat\theta_{(i)})^3}
             {6\,\big[\sum_i (\hat\theta_{(\cdot)} - \hat\theta_{(i)})^2\big]^{3/2}},
  \]
  and then takes the percentiles at the adjusted levels \(\Phi\!\big(z_0 + \tfrac{z_0 + z_{\alpha/2}}{1 - a(z_0 + z_{\alpha/2})}\big)\) and the analogous upper level. BCa is second-order accurate and transformation-respecting, and reduces to the percentile interval when \(z_0 = a = 0\).

* Example: the median of iris Sepal.Length

The median has no elementary standard-error formula, which is exactly where
the bootstrap earns its keep. We bootstrap it with \(B = 4000\) resamples,
report all four intervals, and -- as a calibration check -- also bootstrap
the /mean/, whose bootstrap standard error should reproduce the analytic
\(s/\sqrt n\).

#+name: boot-run
#+begin_src c++ :eval no
    const auto iris = datamunge::datasets::iris();
    std::vector<double> x;
    for (std::size_t i = 0; i < iris.nrows(); ++i) x.push_back(iris.double_at("Sepal.Length", i));

    std::cout << "=== Bootstrapping the median of iris Sepal.Length (n=" << x.size() << ") ===\n";
    Bootstrap boot(BootstrapOptions{4000, 0.95, 20240915});
    const auto med = boot.run(x, median_of);
    std::cout << "estimate (median) = " << med.estimate << "\n";
    std::cout << "bootstrap bias    = " << med.bias << "\n";
    std::cout << "bootstrap SE      = " << med.standard_error << "\n";
    std::cout << "95% CIs:\n";
    std::cout << "  percentile : [" << med.percentile_interval.first << ", " << med.percentile_interval.second << "]\n";
    std::cout << "  basic      : [" << med.basic_interval.first << ", " << med.basic_interval.second << "]\n";
    std::cout << "  normal     : [" << med.normal_interval.first << ", " << med.normal_interval.second << "]\n";
    std::cout << "  BCa        : [" << med.bca_interval.first << ", " << med.bca_interval.second << "]\n";

    std::cout << "\n=== Validation: bootstrap SE of the mean vs closed-form s/sqrt(n) ===\n";
    const auto mn = boot.run(x, mean_of);
    std::cout << "estimate (mean)  = " << mn.estimate << "\n";
    std::cout << "bootstrap SE     = " << mn.standard_error << "\n";
    std::cout << "closed-form s/vn = " << sd_of(x) / std::sqrt(static_cast<double>(x.size())) << "\n";

    auto plot = RPlot::hist(med.replicates, 30, "bootstrap medians");
    plot.title("Bootstrap distribution of the median (iris Sepal.Length)")
        .x_label("median (cm)").y_label("count").background({250, 250, 252});
    plot.save_svg("build/org/bootstrap_median_dist.svg");
    std::cout << "\nwrote bootstrap_median_dist.svg\n";
#+end_src

The calibration check is the headline: with no formula at all, the bootstrap
recovers the mean's standard error (0.067) to within a thousandth of the
closed-form \(s/\sqrt n\) (0.068). For the median -- where no such formula is
available -- it reports a standard error of 0.10 cm and four confidence
intervals that agree closely, all near \([5.6, 6.0]\). The bootstrap
distribution is visibly discrete and lumpy:

#+attr_html: :width 640
#+attr_latex: :width 0.8\linewidth
[[file:../../build/org/bootstrap_median_dist.svg]]

That granularity is a real feature of the median of a tied, finitely-valued
sample -- the resampled median can only land on one of a handful of order
statistics -- and it is precisely the kind of non-normal, formula-defying
behavior the bootstrap captures automatically. The percentile and BCa
intervals coincide here because the replicate distribution is nearly
symmetric about the estimate (so the bias-correction \(z_0\) and acceleration
\(a\) are small); on a skewed statistic they would part company, with BCa the
more accurate.
