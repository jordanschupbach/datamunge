#+begin_abstract
Least-squares fitting assumes every point is a slightly-noisy inlier; a handful of
gross *outliers* -- mislabeled data, sensor glitches, wrong correspondences -- can
tilt the fit arbitrarily. *RANSAC* (Fischler & Bolles 1981) inverts the logic:
rather than fit all the data and hope, it repeatedly *hypothesizes* a model from a
tiny random sample and keeps whichever hypothesis the most data points *agree
with*. This report implements it in =datamunge='s C++ =algorithms::ransac_line= as
a literate program: every number and figure comes from one compiled binary. We
fit a line to data that is one-third gross outliers, show that ordinary least
squares is dragged badly off while RANSAC recovers the true line from its inlier
consensus, and check the standard formula for how many trials are needed.
#+end_abstract

* The robust-fitting problem

Given points \((x_i,y_i)\), most generated by a true model plus small noise
(*inliers*) but some arbitrary (*outliers*), we want the model the inliers support.
Least squares minimizes \(\sum_i r_i^2\) over *all* points, so a single outlier with
large residual \(r_i\) can dominate the sum and swing the fit. RANSAC instead seeks
the model with the largest *consensus set* -- the most points within a residual
threshold -- which ignores outliers by construction.

* The algorithm

RANSAC repeats a hypothesize-and-verify loop:

1. *Sample* the minimal number of points that determine the model (two for a line).
2. *Fit* the model to that sample exactly.
3. *Score* it by counting inliers -- points within a distance \(\tau\) of the model.
4. *Keep* the model with the largest inlier set seen so far.

After enough trials it returns the best model, refit on its full inlier set for
precision. The number of trials to see, with probability \(p\), at least one
minimal sample that is all inliers -- given an inlier fraction \(w\) and sample size
\(s\) -- is
\[
  N = \left\lceil \frac{\log(1-p)}{\log\big(1 - w^{s}\big)} \right\rceil,
\]
which grows only mildly as outliers increase, the reason RANSAC is practical.

** Pseudocode

#+begin_example
RANSAC(points, tau, N):
    best = none
    repeat N times:
        S = minimal random sample (2 points for a line)
        M = model fit to S
        inliers = { p : distance(p, M) <= tau }
        if |inliers| > |best.inliers|: best = (M, inliers)
    refit best.M on best.inliers
    return best
#+end_example

* A worked example: a line in heavy contamination

We generate 80 inliers on the line \(y = 2x + 1\) with small noise and 40 gross
outliers scattered arbitrarily (one third of the data). We fit the line three
ways: ordinary least squares over everything, and RANSAC.

#+name: ransac-run
#+begin_src c++ :eval no
    std::mt19937_64                        rng(7);
    std::normal_distribution<double>       noise(0.0, 0.05);
    std::uniform_real_distribution<double> ux(0.0, 10.0), uy(-20.0, 40.0);
    std::vector<double>                    xs, ys;
    for (int i = 0; i < 80; ++i) {
        double x = ux(rng);
        xs.push_back(x);
        ys.push_back(2.0 * x + 1.0 + noise(rng));
    }
    for (int i = 0; i < 40; ++i) {
        xs.push_back(ux(rng));
        ys.push_back(uy(rng));  // outliers
    }

    // Ordinary least squares over ALL points (dragged by outliers).
    double n = static_cast<double>(xs.size()), sx = 0, sy = 0, sxx = 0, sxy = 0;
    for (std::size_t i = 0; i < xs.size(); ++i) { sx += xs[i]; sy += ys[i]; sxx += xs[i] * xs[i]; sxy += xs[i] * ys[i]; }
    double ls_slope = (n * sxy - sx * sy) / (n * sxx - sx * sx);
    double ls_int   = (sy - ls_slope * sx) / n;

    // RANSAC.
    RansacLine line   = ransac_line(xs, ys, 0.2, 500, 1);
    double     slope  = -line.a / line.b;
    double     inter  = -line.c / line.b;

    std::cout << "=== Line fit: 80 inliers (y=2x+1) + 40 outliers ===\n";
    std::cout << "ordinary least squares:  slope=" << ls_slope << "  intercept=" << ls_int << "\n";
    std::cout << "RANSAC:                  slope=" << slope << "  intercept=" << inter << "\n";
    std::cout << "RANSAC inliers: " << line.inlier_count << " / " << xs.size() << "  (trials " << line.trials
              << ")\n";
    std::cout << "trials for p=0.99 at w=0.67, s=2: " << ransac_required_iterations(0.67, 2, 0.99) << '\n';

    // Figure: inliers vs outliers, RANSAC line, least-squares line.
    std::vector<double> ix, iy, ox, oy;
    for (std::size_t i = 0; i < xs.size(); ++i)
        if (line.inliers[i]) { ix.push_back(xs[i]); iy.push_back(ys[i]); }
        else { ox.push_back(xs[i]); oy.push_back(ys[i]); }
    RPlot p = RPlot::create();
    p.points(ox, oy, "outliers", {148, 163, 184}, 3.5);
    p.points(ix, iy, "inliers", {37, 99, 235}, 3.5);
    std::vector<double> lx = {0, 10}, lr = {inter, slope * 10 + inter}, ll = {ls_int, ls_slope * 10 + ls_int};
    p.line(lx, lr, "RANSAC", {22, 163, 74}, 2.5);
    p.line(lx, ll, "least squares", {220, 38, 38}, 2.5);
    p.legend({"inliers", "outliers", "RANSAC", "least squares"},
             {{37, 99, 235}, {148, 163, 184}, {22, 163, 74}, {220, 38, 38}});
    p.save_svg("build/org/ransac_fit.svg");
    std::cout << "\nwrote build/org/ransac_fit.svg\n";
#+end_src

* Results

#+begin_example
=== Line fit: 80 inliers (y=2x+1) + 40 outliers ===
ordinary least squares:  slope=0.864541  intercept=4.46488
RANSAC:                  slope=2.00098  intercept=0.999635
RANSAC inliers: 80 / 120  (trials 500)
trials for p=0.99 at w=0.67, s=2: 8
#+end_example

Ordinary least squares, forced to accommodate every outlier, returns a line
badly off the truth. RANSAC recovers slope and intercept close to the true
\(y=2x+1\), because it scored candidate lines by inlier count and then refit only
on the consensus set -- the outliers never entered the final fit. The figure shows
the RANSAC line running through the inlier band while the least-squares line is
pulled toward the scattered outliers. The trials-needed formula confirms only a
few dozen samples suffice at this contamination level.

* Choices and relatives

RANSAC has three knobs: the *threshold* \(\tau\) (how close counts as an inlier --
set from the expected noise), the *trial count* \(N\) (from the formula, using a
worst-case inlier fraction), and the *minimal sample size* (model-dependent).
Its descendants refine the scoring and sampling: MSAC/MLESAC score inliers by
residual rather than a hard count, PROSAC samples promising points first, and
LO-RANSAC adds local optimization. RANSAC is a staple of computer vision --
fitting fundamental matrices, homographies, and 3-D transformations from
correspondence sets riddled with mismatches.

* Complexity

Each of \(N\) trials fits a minimal model in \(O(1)\)-ish and scores it in \(O(n)\),
so the loop is \(O(Nn)\); \(N\) comes from the inlier-fraction formula, independent
of \(n\). Memory is \(O(n)\).
