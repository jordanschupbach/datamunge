#+begin_abstract
We fit a naive Bayes classifier to the Palmer Archipelago penguins data
using =datamunge='s C++ =stats::NaiveBayesClassifier=, and report it as a
literate program: every fragment below is a real, compiled, executed chunk
of the single C++ binary that produced every number and figure in this
document. Unlike every prior classifier report in this project, the primary
model here mixes two numeric predictors (bill length and depth, each
Gaussian-per-class) with two categorical predictors (island and sex, each a
Laplace-smoothed frequency table per class) in a single formula, reaching
98.20% training accuracy (6 of 333 misclassified). A reduced model using
only the two numeric predictors, built purely to visualize a decision
boundary, drops to 93.09% -- direct, quantified evidence for how much
=island= alone contributes, since Chinstrap and Gentoo penguins are nearly
deterministically associated with a single island each in this data. A
Laplace-smoothing sensitivity sweep across five orders of magnitude shows
accuracy essentially flat until the smoothing parameter reaches 100, at
which point it degrades -- an honest report of exactly how much this
particular hyperparameter matters here. We derive Bayes' theorem, the
naive conditional-independence assumption, the per-class Gaussian and
categorical-frequency likelihoods, Laplace smoothing, log-space
computation, and the genuinely quadratic decision boundary this method
produces (in contrast to the LDA companion report's linear one), tying
each to the corresponding library call.
#+end_abstract

* Introduction

Every classifier this project has fit so far -- LDA, SVM, the decision
tree, random forest, GBM, XGBoost, the logistic regression in the
[[file:glm_iris_analysis.org][GLM companion report]], and KNN in the
[[file:knn_iris_analysis.org][KNN companion report]] -- predicts Fisher's
iris species from four numeric measurements, each built into a numeric
design matrix (dummy-encoded where necessary) before fitting. This report
changes two things at once: it moves to the Palmer Archipelago penguins
data, already used by this project's
[[file:lm_penguins_analysis.org][linear regression companion report]], and
it fits a method, naive Bayes, whose independence assumption lets it model
numeric and categorical predictors natively side by side -- a categorical
predictor's levels as one jointly-modeled frequency distribution per class,
not as separate 0/1 design-matrix columns. §2.7 makes precise why that
distinction matters and is not just a convenience.

As with its companions, this document is a /literate program/: prose and
source are interleaved in reading order, and a single "assembling the

program's literal output.

§2 derives Bayes' theorem, the naive independence assumption, the

§4 reports the fitted mixed-predictor model, a numeric-only model built for
visualization, a Laplace-smoothing sensitivity sweep, and predictions for

* Background: Naive Bayes

** Setup and notation

$n = 333$ penguins (of 344 total, after dropping rows with a null value in
any of the five columns this report uses -- matching R's =na.omit=
default, per =datamunge='s convention for every model class in this
project), $y_i \in \{1,2,3\}$ labeling one of three species
(/Adelie/, /Chinstrap/, /Gentoo/), and, for the primary model, $p = 4$
predictors of /two different kinds/: =bill_length_mm= and =bill_depth_mm=
(numeric), =island= and =sex= (categorical) -- the
[[file:lm_penguins_analysis.org][linear regression companion report]]'s
same dataset, but here every column keeps its native type instead of being
folded into one numeric design matrix.

** Bayes' theorem and the naive independence assumption

Bayes' theorem gives the posterior class probability as
$P(y \mid x) \propto P(y) \, P(x \mid y)$: prior times likelihood. The
difficulty in general is $P(x \mid y)$, the joint likelihood of all $p$
predictors together, which would require modeling their full joint
distribution within each class. Naive Bayes sidesteps this with the
/naive/ (conditional independence) assumption -- that, given the class,
every predictor is independent of every other:

\[
P(x \mid y) = \prod_{j=1}^p P(x_j \mid y) ,
\]

reducing an intractable joint-distribution estimation problem to $p$
separate, easy one-dimensional estimation problems, one per predictor,
each conditioned only on the class. This assumption is essentially always
literally false (here, for instance, bill length and bill depth are
correlated within every species, not independent) -- naive Bayes is a
textbook example of a method that is known to be misspecified yet performs
well in practice, a point §5 returns to.

** Class priors

$P(y)$ is estimated by the empirical class frequencies in the training
data, exposed directly by =class_priors()=; §4.2 reports all three for
this dataset.

** Gaussian likelihood for numeric predictors

For a numeric predictor $x_j$, $P(x_j \mid y)$ is modeled as a Gaussian
fit separately /within each class/,

\[
P(x_j \mid y=k) = \mathcal{N}(x_j; \mu_{jk}, \sigma_{jk}^2 + \epsilon) ,
\]

with $\mu_{jk}$ and $\sigma_{jk}^2$ the sample mean and variance of $x_j$
among training rows of class $k$ alone (=numeric_mean_= / =numeric_variance_=
internally), and $\epsilon$ a small variance floor
(=NaiveBayesClassifierOptions::var_smoothing=, default $10^{-9}$, scaled by
the largest per-feature variance in the training set) preventing a
division by zero for any class/predictor combination whose training
variance happens to be exactly zero -- matching scikit-learn's
=GaussianNB= =var_smoothing= convention exactly, per the library's own
documentation.

** Categorical likelihood and Laplace smoothing

For a categorical predictor $x_j$ with observed levels $\ell_1,\dots,\ell_m$,
$P(x_j \mid y)$ is a per-class frequency table rather than a parametric
distribution:

\[
P(x_j = \ell \mid y=k) = \frac{\mathrm{count}(x_j=\ell, y=k) + \alpha}
{\mathrm{count}(y=k) + \alpha m} ,
\]

the additive (Laplace, or more generally Lidstone) smoothing formula, with
$\alpha$ = =laplace_smoothing= (default 1.0). Without $\alpha > 0$, any
level never observed for a given class in the training data would receive
exactly zero probability, which -- combined with the product in §2.2 --
would zero out the /entire/ posterior for that class whenever such a level
appears, regardless of how strongly every other predictor favors it;
$\alpha$ guarantees every level/class combination keeps some nonzero
probability mass. §4.5 sweeps $\alpha$ directly.

** Log-space computation

Multiplying many probabilities together (§2.2's product over $p$
predictors) underflows in floating point for even moderately large $p$;
=log_posteriors_for_row= instead accumulates
$\log P(y) + \sum_j \log P(x_j \mid y)$ and compares sums of
log-probabilities across classes rather than raw products, mathematically
identical to §2.2's formula but numerically stable regardless of how many
predictors or how small any individual likelihood becomes.

** Mixed predictor types as first-class citizens

Every other classifier in this project's =Formula= / =DesignInfo= machinery
ultimately builds one numeric design matrix, dummy-encoding any categorical
predictor into a set of 0/1 indicator columns before fitting. Naive Bayes
does not: because §2.2's independence assumption already treats each
predictor as its own separate factor in the likelihood, a categorical
predictor's levels are modeled /jointly/, as one =categorical_log_prob_=
table per class (§2.5), never split into independent per-level indicator
features the way dummy encoding would. This is not an implementation
convenience -- splitting a categorical predictor into per-level indicators
and then treating those indicators as independent would double-count the
predictor's information and violate the very assumption the method is
built on, which is precisely why =NaiveBayesClassifier= rejects formula
terms other than plain column references (interactions, transforms) at
construction: those constructs only have a well-defined meaning inside a
numeric design matrix, not inside this per-feature-independent likelihood
factorization.

** Decision boundary shape

Because each numeric predictor gets its /own/ per-class variance
$\sigma_{jk}^2$ (§2.4) rather than a variance pooled across classes, Gaussian
naive Bayes' decision boundary between two classes is generally
/quadratic/, even with only two predictors -- in direct contrast to the
[[file:lda_iris_analysis.org][LDA companion report]], whose shared
pooled-covariance assumption produces a /linear/ boundary by construction.
§4.4's decision-region figure shows this curvature directly.

** What we will report

Given the fits, we report exploratory data, the mixed-predictor model's own
summary (class priors, per-class Gaussian and categorical statistics),
confusion matrix, a numeric-only model's classification and decision-region
plots, a Laplace-smoothing sensitivity sweep, and predictions for three new
penguins.

* Data and Methods

** The data

=datamunge::datasets::penguins()= returns the Palmer Archipelago penguins
dataset (344 rows: 3 species, 3 islands, bill and flipper measurements,
body mass, sex, year), matching the
[[file:lm_penguins_analysis.org][linear regression companion report]]'s
data exactly. This report drops rows with a null value in any of the five
columns it uses (=species=, =island=, =sex=, =bill_length_mm=,
=bill_depth_mm=), leaving 333 rows.

** Software

The entire analysis is one C++ program against =datamunge=:
=dstruct::DataFrame= for the data, the formula-driven
=stats::NaiveBayesClassifier= for every model in this report, and
=plot::RPlot= for every figure. No external plotting or statistics package
is used.

*** Fitting the mixed-predictor model

Two numeric predictors (Gaussian likelihood) and two categorical
predictors (frequency-table likelihood) in one formula.

#+name: nb-fit
#+begin_src c++ :eval no
    std::cout << "\n=== Naive Bayes"
               << " (mixed numeric + categorical predictors) ===\n";
    NaiveBayesClassifier model(penguins,
        "species ~ bill_length_mm + bill_depth_mm + island + sex");
    model.print_summary(std::cout);

    std::cout << "\nConfusion matrix (rows = actual, cols = predicted):\n";
    const auto cm = model.confusion_matrix();
    std::cout << std::setw(14) << "";
    for (const auto& c : model.classes()) std::cout << std::setw(12) << c;
    std::cout << "\n";
    for (std::size_t i = 0; i < cm.rows(); ++i) {
        std::cout << std::setw(14) << model.classes()[i];
        for (std::size_t j = 0; j < cm.cols(); ++j)
            std::cout << std::setw(12) << cm(i, j);
        std::cout << "\n";
    }

    std::size_t misclassified = 0;
    const auto predictions = model.predict(penguins);
    for (std::size_t i = 0; i < penguins.nrows(); ++i)
        if (predictions[i] != penguins.string_at("species", i))
            ++misclassified;
    std::cout << "\n" << misclassified << " of " << penguins.nrows()
               << " misclassified (" << std::fixed << std::setprecision(2)
               << (100.0 * static_cast<double>(misclassified)
                   / static_cast<double>(penguins.nrows()))
               << "%)\n";
#+end_src

Trained on =island= and =sex= alone (no numeric predictors, isolating

orders of magnitude of $\alpha$ and only degrades once $\alpha$ reaches

genuine near-deterministic island/species association §4.2 already
revealed. This is an honest report of a hyperparameter that, within any
reasonable range, does not matter much here -- the categorical evidence in
this particular data is strong enough that only extreme over-smoothing
degrades it.

* Discussion

**Mixing predictor types is a genuine capability, not a convenience.**
Every other classifier in this project would need =island= and =sex=
dummy-encoded into indicator columns before fitting, an encoding choice
that is invisible to those methods' own machinery. Naive Bayes' native
handling (§2.7) is not merely more convenient -- §4.3's controlled
comparison (98.20% mixed versus 93.09% numeric-only) is only possible
because adding or dropping a categorical predictor requires no encoding
decision at all, just a formula change, letting this report isolate
=island='s contribution cleanly.

**A misspecified assumption that still works.** §2.2 notes that the
independence assumption is essentially always literally false; here, bill
length and bill depth are visibly correlated within every species (§4.1).
That naive Bayes still reaches 98.20% accuracy despite this is the
well-documented empirical robustness the method is known for (Rish, 2001;
Zhang, 2004, both cited below) -- correlated predictors mean the assumption
is wrong, not that the resulting classifier is bad, since what actually
matters for classification accuracy is getting the /relative ranking/ of
posterior probabilities right, a weaker requirement than getting the joint
likelihood exactly right.

**Connection to the wider project.** This report's 98.20% training
accuracy is the highest resubstitution-style figure any classifier in this
project has reported, on a three-class problem with a different
classes-to-predictors structure than the iris reports' four measurements. That is
partly a property of this particular dataset -- =island= carries close to
deterministic information for two of three species -- and partly a
reminder that resubstitution accuracy, the same caveat every report using
it has raised, is still an optimistic upper bound rather than a validated
estimate of new-data performance; no report in this series has
cross-validated any classifier's resubstitution figure against a held-out set,
this one included.

* Conclusion

Fitting naive Bayes with =datamunge='s C++ =stats::NaiveBayesClassifier=
to the Palmer penguins data reaches 98.20% training accuracy using two
numeric and two categorical predictors together, natively, in one formula
-- the first report in this project to model categorical predictors as
first-class citizens rather than dummy-encoded columns. Dropping the two
categorical predictors costs 5.11 accuracy points, a direct measurement of
their real contribution; a Laplace-smoothing sweep shows this dataset's
categorical evidence is strong enough to tolerate four orders of magnitude
of smoothing-parameter variation before degrading; and the fitted decision
boundary is visibly quadratic, a direct, derived consequence of each
class's independently estimated variance rather than a modeling choice
