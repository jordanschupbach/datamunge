#+begin_abstract
*Gaussian elimination* is the workhorse direct method for solving \(Ax=b\): use row
operations to reduce the system to upper-triangular form, then read the unknowns off
by back substitution. Adding *partial pivoting* -- always eliminating with the
largest available pivot -- keeps it numerically stable. This report implements it in
=datamunge='s C++ =algorithms::gaussian_elimination=, solves a 3x3 system exactly,
and shows the coefficient matrix collapsing to a triangle.
#+end_abstract

* Reduce to a triangle, then back-substitute

For each column in turn, pick the row with the largest-magnitude entry in that
column as the *pivot* (swapping it up), then subtract multiples of the pivot row
from the rows below to zero out the column beneath the pivot. After \(n-1\) such
steps the matrix is upper-triangular. The last equation then involves one unknown,
the second-to-last two, and so on, so *back substitution* solves them from the
bottom up. The whole procedure is \(O(n^3)\). Partial pivoting matters: without it a
tiny pivot would divide the row and amplify rounding error catastrophically; picking
the largest pivot bounds the multipliers by 1 and keeps the arithmetic well behaved.
A pivot that is zero even after the search means the matrix is singular.

* Algorithm

#+begin_example
GAUSSIAN-ELIMINATION(A, b):
  for col in 0 .. n-1:
      pivot <- row (>= col) with largest |A[row][col]|
      if |A[pivot][col]| ~ 0: return "singular"
      swap rows col and pivot (in A and b)
      for row in col+1 .. n-1:
          f <- A[row][col] / A[col][col]
          A[row] <- A[row] - f * A[col];  b[row] <- b[row] - f * b[col]
  # back substitution
  for i in n-1 down to 0:
      x[i] <- (b[i] - sum_{j>i} A[i][j] x[j]) / A[i][i]
  return x
#+end_example

* Worked example: a 3x3 system

We solve
\(2x+y-z=8,\ -3x-y+2z=-11,\ -2x+y+2z=-3\), whose solution is \((2,3,-1)\). The
program prints the solution and the upper-triangular matrix the elimination
produces.

#+name: ge-run
#+begin_src c++ :eval no
    const std::vector<std::vector<double>> A = {{2, 1, -1}, {-3, -1, 2}, {-2, 1, 2}};
    const std::vector<double> b = {8, -11, -3};
    const auto sol = gaussian_elimination(A, b);

    std::cout << "=== Gaussian elimination ===\n";
    std::cout << "solution x = (";
    for (std::size_t i = 0; i < sol.x.size(); ++i) std::cout << sol.x[i] << (i + 1 < sol.x.size() ? ", " : "");
    std::cout << ")  (expected (2, 3, -1))\n\n";

    // Reproduce the elimination to display the upper-triangular form.
    auto U = A; auto c = b; const std::size_t n = A.size();
    for (std::size_t col = 0; col < n; ++col) {
        std::size_t piv = col;
        for (std::size_t r = col + 1; r < n; ++r) if (std::fabs(U[r][col]) > std::fabs(U[piv][col])) piv = r;
        std::swap(U[col], U[piv]); std::swap(c[col], c[piv]);
        for (std::size_t r = col + 1; r < n; ++r) {
            const double f = U[r][col] / U[col][col];
            for (std::size_t k = col; k < n; ++k) U[r][k] -= f * U[col][k];
            c[r] -= f * c[col];
        }
    }
    std::cout << std::fixed << std::setprecision(2) << "upper-triangular form [U | c]:\n";
    for (std::size_t i = 0; i < n; ++i) {
        std::cout << "  ";
        for (std::size_t j = 0; j < n; ++j) std::cout << std::setw(7) << U[i][j];
        std::cout << "  |" << std::setw(7) << c[i] << "\n";
    }

    auto plot = RPlot::create();
    auto grid = [&](const std::vector<std::vector<double>>& M, const std::vector<double>& rhs, double xoff, const char* label) {
        for (std::size_t i = 0; i < n; ++i) {
            for (std::size_t j = 0; j < n; ++j)
                plot.text(xoff + j, -static_cast<double>(i), std::to_string(static_cast<int>(std::lround(M[i][j]))),
                          std::fabs(M[i][j]) < 1e-9 ? RGB{203, 213, 225} : RGB{31, 41, 55}, 12.0);
            plot.text(xoff + n + 0.4, -static_cast<double>(i), std::to_string(static_cast<int>(std::lround(rhs[i]))), RGB{37, 99, 235}, 12.0);
        }
        plot.text(xoff + 1.0, 0.9, label, RGB{31, 41, 55}, 13.0);
    };
    grid(A, b, 0.0, "original [A | b]");
    grid(U, c, static_cast<double>(n) + 3.0, "reduced [U | c]");
    plot.title("Gaussian elimination reduces [A|b] to upper-triangular [U|c]")
        .x_label("").y_label("").background({250, 250, 252});
    plot.x_limits(-1.0, 2.0 * n + 5.0); plot.y_limits(-static_cast<double>(n), 1.5);
    plot.save_svg("build/org/gaussian_elimination.svg");
    std::cout << "\nwrote gaussian_elimination.svg\n";
#+end_src

The solver returns \((2,3,-1)\) exactly, and the printed matrix shows the
below-diagonal entries eliminated to zero -- the upper-triangular form from which
back substitution reads the answer. Partial pivoting reordered the rows so the
largest coefficient led each elimination step.
