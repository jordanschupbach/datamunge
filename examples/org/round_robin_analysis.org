#+begin_abstract
*Round-robin* scheduling gives each ready process a fixed *time quantum* on the CPU, then
preempts it to the back of a FIFO queue so the next process runs. No process waits longer
than \((n-1)q\) for its next turn, giving bounded response time and starvation-freedom -- the
scheduler of choice for interactive time-sharing. This report implements it in =datamunge='s
C++ =algorithms::round_robin= as a literate program: every number and figure comes from one
compiled binary. We schedule four processes, draw the execution timeline, and report waiting
and turnaround times.
#+end_abstract

* Quantum, queue, preemption

The ready processes sit in a FIFO queue. The scheduler dispatches the head for up to \(q\)
time units; if it finishes within the quantum it leaves, otherwise it is preempted and
re-enters at the *back* of the queue (behind any processes that arrived during its slice).
The quantum \(q\) tunes a trade-off: small \(q\) improves responsiveness but multiplies
context-switch overhead; as \(q\to\infty\) round-robin degenerates into first-come-first-served.
Turnaround time is completion minus arrival, and waiting time is turnaround minus the CPU
burst.

#include <cstddef>
#include <iostream>
#include <string>

using namespace datamunge::algorithms;
using namespace datamunge::plot;

// Draw a Gantt chart: one horizontal row per process id, a colored box per run slice.
inline void draw_gantt(const ScheduleResult& r, std::size_t nproc, const char* path) {
    static const RGB palette[] = {{37,99,235},{220,38,38},{22,163,74},{202,138,4},{147,51,234}};
    RPlot p = RPlot::create();
    for (const auto& g : r.gantt) {
        double y = static_cast<double>(g.id);
        p.polygon({(double)g.start,(double)g.end,(double)g.end,(double)g.start},
                  {y-0.4, y-0.4, y+0.4, y+0.4}, palette[g.id % 5], true);
    }
    // Anchor the axes so every row and the full time span are visible.
    std::vector<double> ax, ay;
    for (std::size_t i = 0; i < nproc; ++i) { ax.push_back(0.0); ay.push_back((double)i); }
    p.points(ax, ay, "", {0,0,0}, 0.1);
    p.save_svg(path);
}
#+end_src

** Pseudocode

#+begin_example
RoundRobin(processes, q):
    queue = processes sorted by arrival
    while some process unfinished:
        i = queue.pop_front()
        run i for min(q, remaining[i]); advance time
        enqueue any processes that arrived during the slice
        if remaining[i] > 0: queue.push_back(i)   # preempted
        else: record completion[i]
#+end_example

* A worked example

Four processes arrive at time 0 with bursts 5, 3, 1, 2 and a quantum of \(q=2\).

    std::vector<SchedProcess> procs = {{0,0,5},{1,0,3},{2,0,1},{3,0,2}};
    int quantum = 2;
    auto r = round_robin(procs, quantum);

    std::cout << "=== Round-robin (quantum " << quantum << ") ===\n";

    std::cout << "\nproc  completion  turnaround  waiting\n";

The timeline shows the characteristic round-robin interleaving: each process runs at most two
units before yielding, so short jobs (P2, P3) finish early while the long job P0 is spread
across several slices. The Gantt chart makes the rotation visible -- control cycles through the
ready queue rather than committing to one process at a time -- which is what bounds every
process's response time.

* Character and relatives

Round-robin is the canonical *fair, preemptive* scheduler; its behavior hinges entirely on
the quantum. It ignores burst length, so it gives worse average waiting time than
shortest-job-first on batch workloads but far better responsiveness for interactive ones. Real
schedulers generalize it: *multilevel feedback queues* run round-robin within each priority
level and demote CPU-bound processes, and Linux's older O(1) scheduler and the Completely Fair
Scheduler both descend from this time-slicing idea. Companion reports cover the burst-aware
alternatives shortest-job-next and shortest-remaining-time.

* Complexity

Each dispatch is \(O(1)\); the total work is \(O(\sum_i \lceil C_i/q\rceil)\) dispatches over
all processes -- linear in the number of time slices the workload is cut into.
