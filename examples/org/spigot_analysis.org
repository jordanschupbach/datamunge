#+subtitle: A literate C++ study of digit-by-digit constant computation with =datamunge='s =algorithms::spigot_e=

#+begin_abstract
A *spigot algorithm* produces the digits of a mathematical constant *one at a time*, like drips
from a tap, using only bounded small-integer arithmetic and *no knowledge of the digits already
produced*. For \(e\) the trick is to hold \(e\) in a *factorial-base* representation (position
\(i\) carries base \(i\)); multiplying that state by 10 and renormalising drips out the next
decimal digit as the overflow. This report drives =datamunge='s =algorithms::spigot_e=, verified
against the known digits of \(e\), and looks at the digit stream it produces.
#+end_abstract

* Factorial base, times ten, carry out

Write \(e-2=\sum_{i\ge2}\frac1{i!}\). In the *mixed-radix* system where position \(i\) has base
\(i\), that sum is simply \((1,1,1,\dots)\) -- a one in every column. To extract a decimal digit,
multiply the whole number by 10 and renormalise from the highest column down: at column \(i\),
form \(10\,a_i+\text{carry}\), keep \(a_i\gets(\cdot)\bmod i\), and pass \(\lfloor(\cdot)/i\rfloor\)
down as the carry. The carry that falls out of column 2 is the next decimal digit of \(e\).

#+begin_example
a[i] = 1 for i = 2..m           # e - 2 in factorial base
for each digit wanted:
    carry = 0
    for i = m down to 2:  x = 10*a[i] + carry;  a[i] = x mod i;  carry = x div i
    emit carry                   # the next decimal digit
#+end_example

Nothing but small multiplies, mods, and adds -- and crucially the loop never consults the digits
already emitted, the defining property of a *spigot*. It costs \(O(n^2)\) for \(n\) digits (each of
the \(n\) passes touches \(O(n)\) columns), so it is not how you set records, but it is beautifully
simple and needs only \(O(n)\) small integers of memory.

* Algorithm

#+begin_example
SPIGOT-E(n):
  a[2..m] = 1                     # m = n + guard columns
  output "2."
  repeat n times:
      carry = 0
      for i = m down to 2: x = 10*a[i] + carry; a[i] = x mod i; carry = x div i
      output the digit `carry`
#+end_example

* Worked example: the digits of e, and their frequencies

We print the first digits of \(e\), confirm them against the known value, then tally how often each
digit \(0\)-\(9\) appears over a longer run.

#+name: sp-run
#+begin_src c++ :eval no
    std::cout << "=== spigot digits of e ===\n";
    std::cout << spigot_e(40) << "\n";
    std::cout << "known: 2.7182818284590452353602874713526624977572\n\n";

    const std::string d = spigot_e(400);
    std::array<int, 10> freq{};
    for (char c : d) if (c >= '0' && c <= '9') ++freq[c - '0'];
    std::cout << "digit frequencies over the first 400 digits of e:\n";
    std::vector<double> heights; std::vector<std::string> labels;
    for (int k = 0; k < 10; ++k) { std::cout << k << ": " << freq[k] << "  "; heights.push_back(freq[k]); labels.push_back(std::to_string(k)); }
    std::cout << "\n";

    auto plot = RPlot::barplot(heights, labels, "count", RGB{124, 58, 237});
    plot.title("Digit frequencies in the first 400 digits of e (roughly uniform)")
        .x_label("digit").y_label("occurrences").background({250, 250, 252});
    plot.save_svg("build/org/spigot.svg");
    std::cout << "wrote spigot.svg\n";
#+end_src

* Results

#+begin_example
=== spigot digits of e ===
2.7182818284590452353602874713526624977572
known: 2.7182818284590452353602874713526624977572

digit frequencies over the first 400 digits of e:
0: 44  1: 35  2: 43  3: 45  4: 43  5: 33  6: 39  7: 50  8: 29  9: 40
wrote spigot.svg
#+end_example

The dripped digits match the known value of \(e\) exactly, and over four hundred digits each of
\(0\)-\(9\) appears with roughly equal frequency -- the statistical signature expected of a
"normal" constant, produced here by nothing more than repeated multiply-by-ten-and-carry.

The ten bars are all of similar height: no digit is favoured, consistent with the conjecture that
\(e\) is normal. Each of those digits fell out of the factorial-base state as a single carry, with
the algorithm never once looking back at what it had already emitted -- the essence of a spigot.
