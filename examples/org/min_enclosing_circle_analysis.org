#+begin_abstract
What is the smallest circle that contains a set of points? This *minimum enclosing circle*
(the smallest-circle or 1-center problem) is the tightest possible round bound -- used for
collision proxies, facility siting, and tolerance analysis. Remarkably, it is determined by
at most *three* of the points, and *Welzl's algorithm* (1991) finds it in *expected linear
time* with an elegant randomized recursion. This report drives =datamunge='s
=geometry::min_enclosing_circle=, verifies that every point lies inside, and draws the circle
hugging its determining points.
#+end_abstract

* Determined by at most three points

The minimum enclosing circle of a point set is *unique*, and its boundary passes through
either two points (which are then diametrically opposite) or three points. Welzl's insight is
a randomized incremental recursion around this fact:

- process points in random order, maintaining the smallest circle of those seen so far;
- when a new point falls *outside* the current circle, it must lie *on the boundary* of the
  new minimum circle -- so recurse with that point added to a set of "on the boundary"
  constraints (never more than three);
- with 1, 2, or 3 boundary points the circle is determined outright.

Because a point ends up on the boundary only with small probability at each step, the
expected work is \(O(n)\) -- linear, despite solving a global optimization. The result is
the circle's centre and radius.

* Algorithm

#+begin_example
WELZL(points, boundary):
  if points empty or |boundary| == 3:
      return circle defined by the boundary points (0,1,2, or 3 of them)
  p <- remove a random point from points
  c <- WELZL(points, boundary)
  if p is inside c: return c
  return WELZL(points, boundary + {p})       # p must lie on the new circle
#+end_example

* Worked example: the circle around a random cloud

We build the minimum enclosing circle of a random cloud, confirm every point lies within it,
and check that some points sit exactly on the boundary (the ones that determine it).

#+name: mc-run
#+begin_src c++ :eval no
    std::mt19937 rng(2718281);
    std::normal_distribution<double> nd(0.0, 2.0);
    std::vector<Point2D> pts;
    for (int i = 0; i < 80; ++i) pts.push_back({nd(rng), nd(rng)});

    const Circle c = min_enclosing_circle(pts);
    std::cout << "=== minimum enclosing circle of 80 points ===\n";
    std::cout << "center (" << c.center.x << ", " << c.center.y << "), radius " << c.radius << "\n";

    int outside = 0, on_boundary = 0;
    for (const Point2D& p : pts) {
        const double d = distance(p, c.center);
        if (d > c.radius + 1e-9) ++outside;
        if (std::fabs(d - c.radius) < 1e-6) ++on_boundary;
    }
    std::cout << "points strictly outside: " << outside << " (must be 0)\n";
    std::cout << "points on the boundary:  " << on_boundary << " (the determining points)\n";

    std::vector<double> px, py, cx, cy;
    for (const Point2D& p : pts) { px.push_back(p.x); py.push_back(p.y); }
    for (int i = 0; i <= 100; ++i) { const double a = 2.0 * M_PI * i / 100.0; cx.push_back(c.center.x + c.radius * std::cos(a)); cy.push_back(c.center.y + c.radius * std::sin(a)); }

    auto plot = RPlot::create();
    plot.line(cx, cy, "circle", RGB{220, 38, 38}, 2.0);
    plot.points(px, py, "points", RGB{100, 116, 139}, 5.0);
    plot.points({c.center.x}, {c.center.y}, "center", RGB{220, 38, 38}, 9.0);
    plot.legend({"minimum enclosing circle", "points", "center"},
                {{220, 38, 38}, {100, 116, 139}, {220, 38, 38}});
    plot.title("Smallest enclosing circle (Welzl): every point inside, 2-3 on the rim")
        .x_label("x").y_label("y").background({250, 250, 252});
    plot.save_svg("build/org/min_enclosing_circle.svg");
    std::cout << "wrote min_enclosing_circle.svg\n";
#+end_src

* Results

center (0.1988, 0.102117), radius 5.93857

points on the boundary:  2 (the determining points)

Every one of the eighty points lies inside (or exactly on) the circle -- zero strictly
outside -- and a small number sit precisely on the boundary: these are the two or three
points that *determine* the circle, the ones Welzl's recursion pins to the rim. Move any
interior point and the circle does not change; move a boundary point outward and it must
grow.
