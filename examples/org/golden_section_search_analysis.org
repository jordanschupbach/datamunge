#+begin_abstract
To find the peak of a *unimodal* function -- one that rises then falls -- without derivatives, golden-
section search brackets the maximum and repeatedly shrinks the bracket. The magic is the placement of
its two interior probes at the *golden ratio*: after discarding one side, the surviving probe is
exactly where the next iteration needs one of its probes, so each step costs a single new function
evaluation while shrinking the interval by \(1/\varphi\approx0.618\). This report drives =datamunge='s
=algorithms::golden_section_search=, verified to locate the maxima of several unimodal functions, and
shows the bracket collapsing geometrically.
#+end_abstract

* Two probes at the golden ratio

Keep a bracket \([a,b]\) known to contain the maximum, and place two interior points

\[ c=b-\tfrac1\varphi(b-a),\qquad d=a+\tfrac1\varphi(b-a),\qquad \tfrac1\varphi=\frac{\sqrt5-1}{2}\approx0.618. \]

Evaluate \(f(c)\) and \(f(d)\). By unimodality, if \(f(c)<f(d)\) the maximum lies in \([c,b]\), so set
\(a\gets c\); otherwise it lies in \([a,d]\), so set \(b\gets d\). Here is the payoff of the golden
ratio: the *retained* interior point becomes one of the two probes of the new, smaller bracket -- \(d\)
becomes the new \(c\) (or \(c\) becomes the new \(d\)) -- so only *one* fresh evaluation is needed per
step, not two. The interval shrinks by the constant factor \(1/\varphi\) each iteration, giving *linear
convergence* with rate \(0.618\): reaching a tolerance \(\varepsilon\) takes about
\(\log_{1/\varphi}((b-a)/\varepsilon)\) evaluations. No derivative is ever computed, which is why
golden-section search is the go-to for optimising noisy or black-box unimodal functions, and the line-
search primitive inside larger optimisers.

* Algorithm

#+begin_example
GOLDEN-SECTION(f, a, b):
  c = b - (b-a)/phi;  d = a + (b-a)/phi
  fc = f(c); fd = f(d)
  while b - a > tol:
      if fc < fd: a = c; c = d; fc = fd; d = a + (b-a)/phi; fd = f(d)   # max in [c,b]
      else:       b = d; d = c; fd = fc; c = b - (b-a)/phi; fc = f(c)   # max in [a,d]
  return (a+b)/2
#+end_example

* Worked example: a peak, and the shrinking bracket

We maximise a unimodal function, print the located peak, and plot the bracket width against the
iteration to expose the constant \(0.618\) shrink factor.

#+name: gs-run
#+begin_src c++ :eval no
    auto f = [](double x) { return std::sin(x) - 0.1 * (x - 1.5) * (x - 1.5); }; // unimodal on [0, 3]
    const auto r = golden_section_search(f, 0.0, 3.0, 1e-10);
    std::cout << "=== golden-section search ===\n";
    std::cout << "maximum at x = " << r.argmax << ", f(x) = " << r.value << " (" << r.iterations << " iterations)\n\n";

    // Reproduce the bracket shrinkage.
    const double invphi = (std::sqrt(5.0) - 1.0) / 2.0;
    double a = 0.0, b = 3.0, c = b - invphi * (b - a), d = a + invphi * (b - a), fc = f(c), fd = f(d);
    std::vector<double> it, width;
    int step = 0; it.push_back(0); width.push_back(b - a);
    std::cout << "iter   bracket width\n";
    while (b - a > 1e-6) {
        if (fc < fd) { a = c; c = d; fc = fd; d = a + invphi * (b - a); fd = f(d); }
        else { b = d; d = c; fd = fc; c = b - invphi * (b - a); fc = f(c); }
        ++step; it.push_back(step); width.push_back(b - a);
        if (step % 5 == 0) std::printf("%3d    %.6e\n", step, b - a);
    }

    auto plot = RPlot::create();
    plot.line(it, width, "w", RGB{37, 99, 235}, 2.0);
    plot.points(it, width, "w", RGB{37, 99, 235}, 4.0);
    plot.legend({"bracket width"}, {{37, 99, 235}});
    plot.title("Golden-section search shrinks the bracket by 0.618 each step")
        .x_label("iteration").y_label("bracket width").background({250, 250, 252});
    plot.save_svg("build/org/golden_section_search.svg");
    std::cout << "\nwrote golden_section_search.svg\n";
#+end_src

Golden-section search pins the peak to ten digits in a few dozen evaluations, and the bracket width
falls by a constant factor each step, exactly \(1/\varphi\approx0.618\). The test suite confirms it on
several unimodal functions, including a skewed one.

The width curve is a clean geometric decay -- a straight line on a log scale -- because every iteration
multiplies the interval by the same \(0.618\). That predictable, derivative-free contraction, reusing
one probe per step, is why golden-section search is the standard one-dimensional maximiser and the
line-search workhorse inside gradient and coordinate-descent optimisers.
