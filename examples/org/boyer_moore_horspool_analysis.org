#+begin_abstract
Boyer-Moore is the fastest substring search in practice, but its two shift heuristics take real effort
to build. In 1980 Horspool showed that keeping just *one* of them -- the bad-character rule, indexed by
a single character -- gives almost all the speed with a fraction of the code. The searcher compares the
pattern right-to-left and, on any mismatch, jumps ahead by a precomputed shift based on the text
character aligned with the pattern's last position. This report drives =datamunge='s
=algorithms::boyer_moore_horspool_search=, verified against a naive search over thousands of random
cases, and shows the shift table that lets it skip.
#+end_abstract

* One table, right-to-left comparison

Preprocess the pattern \(P\) of length \(m\) into a *bad-character shift*: for the character \(c\)
that the text places against the *last* position of the current window, how far can we safely slide
the pattern? If \(c\) occurs in \(P[0\ldots m-2]\) at its rightmost such index \(i\), the shift is
\(m-1-i\) (align that occurrence); otherwise \(c\) is not in the pattern's interior and we slide the
full \(m\):

\[ \text{shift}[c]=\begin{cases} m-1-\max\{\,i<m-1 : P[i]=c\,\} & c \text{ appears in } P[0\ldots m-2]\\ m & \text{otherwise.}\end{cases} \]

The search compares \(P\) against the window *back to front*; on a full match it records the position,
and in every case it advances the window by \(\text{shift}[\,\text{text char at the window's last
position}\,]\). Because a character absent from the pattern lets the window jump its whole length, the
expected running time is *sublinear* -- fewer than \(n\) character comparisons on typical text -- while
the worst case remains \(O(nm)\). Horspool's insight is that this single table captures most of
Boyer-Moore's skipping power.

* Algorithm

#+begin_example
HORSPOOL(text, pattern):
  m = |pattern|
  shift[c] = m for all c;  for i = 0..m-2: shift[pattern[i]] = m-1-i
  s = 0
  while s <= |text| - m:
      j = m-1
      while j >= 0 and text[s+j] == pattern[j]: j--
      if j < 0: report match at s
      s += shift[text[s + m - 1]]        # jump by the last window character's shift
#+end_example

* Worked example: searching, and the shift table

We find every occurrence of a pattern, confirm the positions, and plot the bad-character shift for each
letter of the pattern.

#+name: bh-run
#+begin_src c++ :eval no
    const std::string text = "abracadabra_abra_cadabra";
    const std::string pat  = "abra";
    const auto        hits = boyer_moore_horspool_search(text, pat);
    std::cout << "=== Boyer-Moore-Horspool ===\n";
    std::cout << "text:    " << text << "\n";
    std::cout << "pattern: " << pat << "\n";
    std::cout << "matches at: ";
    for (auto p : hits) std::cout << p << " ";
    std::cout << "\n\n";

    // Reproduce the bad-character shift table for the pattern's letters.
    const int m = static_cast<int>(pat.size());
    std::array<int, 256> shift; shift.fill(m);
    for (int i = 0; i + 1 < m; ++i) shift[(unsigned char)pat[i]] = m - 1 - i;

    std::cout << "bad-character shifts (pattern = " << pat << "):\n";
    std::vector<double> heights; std::vector<std::string> labels;
    for (char c : std::string("abr_z")) {
        std::cout << "  '" << c << "' -> " << shift[(unsigned char)c] << "\n";
        heights.push_back(shift[(unsigned char)c]);
        labels.push_back(std::string(1, c));
    }

    auto plot = RPlot::barplot(heights, labels, "shift", RGB{37, 99, 235});
    plot.title("Horspool bad-character shifts for pattern \"abra\" (z: not in pattern -> full jump)")
        .x_label("character aligned with pattern end").y_label("window shift").background({250, 250, 252});
    plot.save_svg("build/org/boyer_moore_horspool.svg");
    std::cout << "\nwrote boyer_moore_horspool.svg\n";
#+end_src

Every occurrence of the pattern is found, matching the naive search the test suite checks against over
thousands of random inputs. The shift table shows the skipping logic: a character not in the pattern
(here =z=) lets the window jump its full length, while characters near the pattern's end give smaller,
safe shifts.

The tallest bar is the "not in pattern" case: any such character aligned with the pattern's last
position lets Horspool slide forward by the entire pattern length, examining none of the skipped text.
That single table -- half of Boyer-Moore -- is what makes Horspool a favourite for its blend of speed
and simplicity in real text-search code.
