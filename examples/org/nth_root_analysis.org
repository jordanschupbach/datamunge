#+begin_abstract
How does a machine compute a cube root, or a tenth root, with only @math{+,-,\times,\div}?
The *nth root algorithm* applies Newton's method to @math{x^n - a = 0}, giving the update
@math{x\leftarrow\frac{(n-1)x + a/x^{n-1}}{n}} -- a weighted pull toward the root that, for
@math{n=2}, is exactly the ancient Babylonian square-root rule. Because @math{x^n} is
convex, the iteration converges *quadratically* from a decent start. This report
implements it in =datamunge='s C++ =algorithms::nth_root=, verified against @c std::pow
across many bases and degrees, and traces the digits doubling.
#+end_abstract

* Newton on x^n - a

To find @math{a^{1/n}} solve @math{f(x)=x^n-a=0}. With @math{f'(x)=n x^{n-1}}, Newton's
step @math{x-f(x)/f'(x)} is

\[ x_{k+1} = x_k - \frac{x_k^n - a}{n\,x_k^{\,n-1}} = \frac{(n-1)\,x_k + a/x_k^{\,n-1}}{n}. \]

Read the last form as a *weighted average*: keep @math{n-1} parts of the current guess and
one part of @math{a/x^{n-1}} (which overshoots to the other side of the root), and the two
errors cancel to second order. For @math{n=2} it is @math{x\leftarrow\tfrac12(x+a/x)}, the
Babylonian method. Since @math{x^n} is convex for @math{x>0}, once the iterate is near the
root the error is *squared* each step -- quadratic convergence. =datamunge= seeds the
iteration from the binary exponent of @math{a} (so @math{a=m2^e \Rightarrow x_0\approx
2^{e/n}}), which lands close enough that only a few steps are needed for any magnitude.

* Algorithm

#+begin_example
NTH-ROOT(a, n):
  if n == 1: return a
  if a == 0: return 0
  x <- 2^(exponent(a)/n)                       # seed from the binary exponent
  repeat:
      x <- ((n-1) x + a / x^(n-1)) / n         # Newton weighted average
  until x stops changing
  return x
#+end_example

* Worked example: roots of known values, and quadratic convergence

We check exact roots (@math{\sqrt2}, @math{\sqrt[3]{27}=3}, @math{\sqrt[10]{1024}=2}), then
trace the error of the cube-root iteration for @math{a=50} to expose the doubling of
correct digits.

#+name: nr-run
#+begin_src c++ :eval no
    std::cout << "=== known roots ===\n";
    std::printf("sqrt(2)      = %.15f (std %.15f)\n", nth_root(2.0, 2), std::sqrt(2.0));
    std::printf("cbrt(27)     = %.15f (exact 3)\n", nth_root(27.0, 3));
    std::printf("1024^(1/10)  = %.15f (exact 2)\n", nth_root(1024.0, 10));
    std::printf("1000^(1/3)   = %.15f (exact 10)\n\n", nth_root(1000.0, 3));

    // Trace cube-root convergence for a = 50 from the exponent seed.
    const double a = 50.0; const int n = 3;
    int e; (void)std::frexp(a, &e);
    double x = std::ldexp(1.0, e / n);
    const double root = std::cbrt(a);
    std::cout << "cube root of 50 (true " << root << "), |x - root| per step:\n";
    std::vector<double> it, logerr;
    for (int i = 0; i <= 7; ++i) {
        const double err = std::fabs(x - root);
        it.push_back(i); logerr.push_back(std::log10(std::max(err, 1e-18)));
        std::printf("  step %d: x=%.15f  error=%.3e\n", i, x, err);
        const double xnm1 = x * x; // x^(n-1) for n=3
        x = ((n - 1) * x + a / xnm1) / n;
    }

    auto plot = RPlot::create();
    plot.line(it, logerr, "error", RGB{124, 58, 237}, 2.0);
    plot.points(it, logerr, "error", RGB{124, 58, 237}, 7.0);
    plot.legend({"|x - cbrt(50)|"}, {{124, 58, 237}});
    plot.title("nth root by Newton: quadratic convergence of the cube root")
        .x_label("iteration").y_label("log10 error").background({250, 250, 252});
    plot.save_svg("build/org/nth_root.svg");
    std::cout << "\nwrote nth_root.svg\n";
#+end_src

The algorithm returns the known roots to the last displayed digit, and the cube-root trace
shows Newton's quadratic descent: from the exponent seed the error collapses in a handful
of weighted-average steps. The same routine handles any degree -- second, third, tenth --
with no special cases beyond the trivial @math{n=1}.

The error curve steepens as it falls -- each step roughly squares the previous error, the
fingerprint of quadratic convergence -- until it bottoms out at the machine floor. A single
weighted average, iterated four or five times, computes a root that looks transcendental
but is really just repeated multiplication and one divide per step.
