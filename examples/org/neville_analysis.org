#+begin_abstract
When you need only the /value/ of an interpolating polynomial at one point -- not
its coefficients -- *Neville's algorithm* is the tool: it builds a triangular
table of interpolants of increasing degree, each combining two neighbours, and
reads the answer off the apex. It computes the same polynomial as Lagrange but
more stably, and the way successive rows agree gives a built-in error estimate.
This report implements it in =datamunge='s C++ =algorithms::neville_interpolate=,
evaluates \(\cos(1.25)\) from tabulated cosine values, and plots the estimates
converging as more nodes enter the table.
#+end_abstract

* The recurrence

Let \(P_{i..j}\) denote the polynomial interpolating the nodes \(i\) through \(j\),
evaluated at the query point \(x\). A single node gives \(P_{i}=y_i\), and two
sub-interpolants merge by

\[
P_{i..j}=\frac{(x-x_j)\,P_{i..j-1}-(x-x_i)\,P_{i+1..j}}{x_i-x_j}.
\]

Filling the triangle from the single-node diagonal up to the full-range apex
\(P_{0..n-1}\) evaluates the degree-\((n-1)\) interpolant at \(x\) in \(O(n^2)\).
Each level raises the degree by one; because neighbouring entries interpolate
overlapping node sets, their difference estimates the truncation error -- the basis
of adaptive schemes like Richardson extrapolation and Romberg integration, which
are Neville's algorithm in disguise.

* Algorithm

#+begin_example
NEVILLE(xs, ys, x):
  p[j] <- ys[j]  for all j
  for i in 1 .. n-1:
      for j in n-1 down to i:
          p[j] <- ((x - xs[j-i]) * p[j] - (x - xs[j]) * p[j-1]) / (xs[j] - xs[j-i])
  return p[n-1]
#+end_example

* Worked example: cos(1.25) from a cosine table

We tabulate \(\cos\) at \(x=0,0.5,1,\dots,3\) and estimate \(\cos(1.25)\). Using
just the two nearest nodes gives a rough (linear) estimate; each extra node folded
into the table sharpens it, and by degree 4-5 the estimate has converged to
\(\cos(1.25)=0.315322\ldots\) to many digits. The program prints the
increasing-degree estimates and their error.

#+name: nv-run
#+begin_src c++ :eval no
    std::vector<double> xs, ys;
    for (int i = 0; i <= 6; ++i) { const double x = 0.5 * i; xs.push_back(x); ys.push_back(std::cos(x)); }
    const double x = 1.25, truth = std::cos(1.25);

    std::cout << std::fixed << std::setprecision(8);
    std::cout << "=== Neville: estimating cos(1.25) = " << truth << " ===\n";
    std::vector<double> deg, est;
    for (std::size_t m = 2; m <= xs.size(); ++m) {
        const std::vector<double> xm(xs.begin(), xs.begin() + static_cast<std::ptrdiff_t>(m));
        const std::vector<double> ym(ys.begin(), ys.begin() + static_cast<std::ptrdiff_t>(m));
        const double e = neville_interpolate(xm, ym, x);
        std::cout << "  degree " << m - 1 << " (" << m << " nodes): " << e
                  << "   error " << std::fabs(e - truth) << "\n";
        deg.push_back(static_cast<double>(m - 1)); est.push_back(e);
    }

    auto plot = RPlot::create();
    plot.line(deg, est, "estimate", RGB{37, 99, 235}, 2.0);
    plot.points(deg, est, "estimate", RGB{37, 99, 235}, 8.0);
    plot.abline_h(truth, RGB{22, 163, 74}, 1.5);
    plot.legend({"Neville estimate", "true cos(1.25)"}, {{37, 99, 235}, {22, 163, 74}});
    plot.title("Neville's algorithm: estimate of cos(1.25) converges with degree")
        .x_label("interpolant degree").y_label("estimate").background({250, 250, 252});
    plot.save_svg("build/org/neville.svg");
    std::cout << "\nwrote neville.svg\n";
#+end_src

The estimate improves by roughly an order of magnitude per added node over the
first several rows -- from a crude two-point linear guess (error 0.38) to about
five-digit accuracy by degree 5. The shrinking gap between successive rows is
exactly the error estimate Neville's table hands you for free.

Each blue point is the estimate of \(\cos(1.25)\) using one more node than the

visible convergence -- and the vertical distance between consecutive points, the
self-contained error bound that makes Neville's scheme so useful for adaptive
quadrature and extrapolation.
