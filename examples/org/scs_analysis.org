#+begin_abstract
The *shortest common supersequence* (SCS) of two sequences is the shortest
sequence that contains both as subsequences -- the tightest way to interleave them
while writing each shared item only once. It is the dual of the longest common
subsequence: \(|\text{SCS}| = |a| + |b| - |\text{LCS}|\). It models merging two
edit histories or two partial orderings with minimal duplication. This report
implements it in =datamunge='s C++ =algorithms::shortest_common_supersequence=,
works =AGGTAB= and =GXTXAYB= into a length-9 supersequence, and colours each output
element by whether it came from the shared backbone or from one side alone.
#+end_abstract

* From LCS to SCS

Any common supersequence must contain every element of \(a\) and every element of
\(b\), in their respective orders. The only elements that can be *shared* -- written
once and counted for both -- are those on a common subsequence. To make the
supersequence as short as possible we should share as many as possible, i.e. use a
*longest* common subsequence. Hence

\[
|\text{SCS}(a,b)| = |a| + |b| - |\text{LCS}(a,b)|,
\]

and an SCS is built by walking the same LCS dynamic-programming table: at a match,
emit the shared element once and step diagonally; at a mismatch, emit the private
element from whichever side the LCS traceback moves along, and step that way. When
one sequence is exhausted, append the rest of the other. Time and space are
\(O(|a||b|)\).

#include <datamunge/plot/plot.hpp>

#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

using namespace datamunge::algorithms;
using namespace datamunge::plot;

static std::vector<int> to_seq(const std::string& s) { return {s.begin(), s.end()}; }
static std::string      to_str(const std::vector<int>& v) { return {v.begin(), v.end()}; }
#+end_src

* Algorithm

#+begin_example
SCS(a, b):                            # via the LCS table C
  build C  (LCS lengths of all prefixes)
  i, j <- n, m ;  S <- ""
  while i > 0 and j > 0:
      if a[i] == b[j]:              prepend a[i] ; i, j <- i-1, j-1   # shared, once
      elif C[i-1][j] >= C[i][j-1]:  prepend a[i] ; i <- i-1           # a's private element
      else:                         prepend b[j] ; j <- j-1           # b's private element
  prepend remaining prefix of a, then of b
  return S
#+end_example

* Worked example: =AGGTAB= and =GXTXAYB=

Their longest common subsequence is =GTAB= (length 4), so the shortest common
supersequence has length \(6+7-4=9\). One such supersequence is =AGXGTXAYB=: the
=G T A B= backbone is shared, while =A G= come from the first string alone and
=X X Y= from the second. The program builds it and verifies that both inputs are
subsequences of the result.

#+name: scs-run
#+begin_src c++ :eval no
    const std::string as = "AGGTAB", bs = "GXTXAYB";
    const std::vector<int> a = to_seq(as), b = to_seq(bs);
    const std::vector<int> scs = shortest_common_supersequence(a, b);
    const std::vector<int> lcs = longest_common_subsequence(a, b);

    auto is_subseq = [](const std::vector<int>& sub, const std::vector<int>& seq) {
        std::size_t k = 0; for (int v : seq) if (k < sub.size() && sub[k] == v) ++k; return k == sub.size();
    };

    std::cout << "=== Shortest common supersequence ===\n";
    std::cout << "a   = " << as << "  (" << a.size() << ")\n";
    std::cout << "b   = " << bs << "  (" << b.size() << ")\n";
    std::cout << "LCS = " << to_str(lcs) << "  (" << lcs.size() << ")\n";
    std::cout << "SCS = " << to_str(scs) << "  (" << scs.size() << " = " << a.size() << "+" << b.size()
              << "-" << lcs.size() << ")\n";
    std::cout << "a is a subsequence of SCS: " << std::boolalpha << is_subseq(a, scs) << "\n";
    std::cout << "b is a subsequence of SCS: " << is_subseq(b, scs) << "\n";

    // Reconstruct the SCS with an origin tag per element: 0 shared, 1 from a only, 2 from b only.
    const std::size_t n = a.size(), m = b.size();
    std::vector<std::vector<int>> C(n + 1, std::vector<int>(m + 1, 0));
    for (std::size_t i = 1; i <= n; ++i)
        for (std::size_t j = 1; j <= m; ++j)
            C[i][j] = (a[i - 1] == b[j - 1]) ? C[i - 1][j - 1] + 1 : std::max(C[i - 1][j], C[i][j - 1]);
    std::vector<std::pair<int, int>> tagged; // (value, origin)
    {
        std::size_t i = n, j = m;
        while (i > 0 && j > 0) {
            if (a[i - 1] == b[j - 1]) { tagged.push_back({a[i - 1], 0}); --i; --j; }
            else if (C[i - 1][j] >= C[i][j - 1]) { tagged.push_back({a[i - 1], 1}); --i; }
            else { tagged.push_back({b[j - 1], 2}); --j; }
        }
        while (i > 0) { tagged.push_back({a[i - 1], 1}); --i; }
        while (j > 0) { tagged.push_back({b[j - 1], 2}); --j; }
        std::reverse(tagged.begin(), tagged.end());
    }

    auto plot = RPlot::create();
    const RGB shared{202, 138, 4}, from_a{22, 163, 74}, from_b{37, 99, 235};
    std::vector<double> x0, y0, x1, y1;
    for (std::size_t k = 0; k < tagged.size(); ++k) {
        const double x = static_cast<double>(k), y = 0.0, r = 0.46;
        x0.insert(x0.end(), {x - r, x + r, x + r, x - r});
        y0.insert(y0.end(), {y - r, y - r, y + r, y + r});
        x1.insert(x1.end(), {x + r, x + r, x - r, x - r});
        y1.insert(y1.end(), {y - r, y + r, y + r, y - r});
        const RGB col = tagged[k].second == 0 ? shared : (tagged[k].second == 1 ? from_a : from_b);
        plot.text(x, y, std::string(1, static_cast<char>(tagged[k].first)), col, 16.0);
    }
    plot.segments(x0, y0, x1, y1, RGB{148, 163, 184}, 1.2);
    plot.legend({"shared (LCS)", "from a", "from b"}, {shared, from_a, from_b});
    plot.title("Shortest common supersequence of AGGTAB and GXTXAYB (length 9)")
        .x_label("position in SCS").y_label("").background({250, 250, 252});
    plot.x_limits(-1.0, static_cast<double>(tagged.size()));
    plot.y_limits(-1.5, 1.5);
    plot.save_svg("build/org/scs.svg");
    std::cout << "\nwrote scs.svg\n";
#+end_src

* Results

#+begin_example
=== Shortest common supersequence ===
a   = AGGTAB  (6)
b   = GXTXAYB  (7)
LCS = GTAB  (4)
SCS = AGXGTXAYB  (9 = 6+7-4)
a is a subsequence of SCS: true
b is a subsequence of SCS: true

wrote scs.svg
#+end_example

The supersequence has length 9 -- exactly \(|a|+|b|-|\text{LCS}|\) -- and both
inputs are subsequences of it. Sharing the four-element =GTAB= backbone rather than
writing those letters twice is precisely what saves \(|\text{LCS}|=4\) positions.
