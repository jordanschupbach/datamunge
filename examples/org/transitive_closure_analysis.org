#+title: Transitive Closure with Warshall's Algorithm
#+options: toc:t num:t
#+property: header-args:c++ :eval no
* Mathematics
Let \(R^{(k)}_{ij}\) mean a path from \(i\) to \(j\) whose intermediate
vertices lie in \(0,\ldots,k-1\).  Then
\[
R^{(k+1)}_{ij}=R^{(k)}_{ij}\lor(R^{(k)}_{ik}\land R^{(k)}_{kj}).
\]
Induction on \(k\) proves the final matrix is exactly reachability.
* Pseudocode
#+begin_example
R <- adjacency; optionally set diagonal true
for k,i,j: R[i][j] <- R[i][j] or (R[i][k] and R[k][j])
#+end_example
Time is \(O(V^3)\), space \(O(V^2)\).
* C++ example
#+begin_src c++ :eval no
#include <datamunge/algorithms/routing_batch.hpp>
#include <iostream>
int main(){auto r=datamunge::algorithms::transitive_closure(
3,{{0,1},{1,2}});std::cout<<r[0][2]<<'\n';}
#+end_src
It prints 1 because the two edges compose into a path.
