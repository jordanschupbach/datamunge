* Mathematics and algorithm
Greedy best-first search expands the frontier vertex minimizing heuristic
\(h(v)\), ignoring accumulated path cost.  A priority queue implements the
rule in \(O((V+E)\log V)\); it is fast when \(h\) is informative but does not
guarantee a shortest path.
#+begin_example
queue start by h; repeatedly pop minimum
record unseen successors and predecessors; stop at goal
