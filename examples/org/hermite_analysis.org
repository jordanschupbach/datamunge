#+begin_abstract
Linear interpolation fixes the *values* at the samples; *cubic Hermite interpolation*
fixes the *slopes* there too. On each interval it fits the unique cubic that matches the
endpoint values *and* the endpoint derivatives, producing a @math{C^1} curve you can
sculpt by choosing tangents. The same four points with different slopes give visibly
different curves -- the mechanism behind Catmull-Rom splines, font outlines, and
animation easing. This report implements it in =datamunge='s C++
=algorithms::hermite_interpolate=, verified to reproduce a cubic exactly, and shows how
the tangents reshape the curve.
#+end_abstract

* The Hermite basis

On an interval @math{[x_k, x_{k+1}]} of width @math{h}, with @math{t=(x-x_k)/h}, the
cubic that matches values @math{y_k, y_{k+1}} and slopes @math{m_k, m_{k+1}} is

\[ p(x) = h_{00}(t)\,y_k + h_{10}(t)\,h\,m_k + h_{01}(t)\,y_{k+1} + h_{11}(t)\,h\,m_{k+1}, \]

with the four *Hermite basis functions*

\[
\begin{aligned}
h_{00} &= 2t^3-3t^2+1, & h_{10} &= t^3-2t^2+t,\\
h_{01} &= -2t^3+3t^2, & h_{11} &= t^3-t^2.
\end{aligned}
\]

By construction @math{h_{00}} and @math{h_{01}} interpolate the values (and are flat at
the ends) while @math{h_{10}} and @math{h_{11}} inject the tangents (and vanish at the
ends). The interpolant therefore passes through every node with exactly the prescribed
slope, so adjacent segments join @math{C^1}-smoothly whenever they share a nodal slope.
Choosing those slopes is the whole art: finite-difference tangents give a Catmull-Rom
spline, zero tangents give a flat-at-the-nodes "ease", and analytic derivatives reproduce
a known function to third order.

* Algorithm

#+begin_example
HERMITE-INTERPOLATE(xs, ys, slopes, x):
  k <- interval index with xs[k] <= x <= xs[k+1]
  h <- xs[k+1]-xs[k];  t <- (x-xs[k])/h
  return  h00(t) ys[k] + h10(t) h slopes[k]
        + h01(t) ys[k+1] + h11(t) h slopes[k+1]
#+end_example

* Worked example: same points, three different tangent fields

We interpolate four points three ways -- with *zero* slopes (flat at each node), with
*finite-difference* (Catmull-Rom) slopes, and, on a genuine cubic, with the *exact*
derivative -- and confirm the exact case reproduces the cubic.

#+name: he-run
#+begin_src c++ :eval no
    const std::vector<double> xs{0.0, 1.0, 2.0, 3.0};
    const std::vector<double> ys{0.0, 1.0, 0.0, 1.0}; // a zig-zag to make tangents matter

    // three slope choices
    std::vector<double> zero(4, 0.0), catmull(4);
    catmull[0] = ys[1] - ys[0];
    catmull[3] = ys[3] - ys[2];
    for (int i = 1; i < 3; ++i) catmull[i] = 0.5 * (ys[i + 1] - ys[i - 1]); // centred differences

    std::vector<double> xf, y_zero, y_cat;
    for (int i = 0; i <= 300; ++i) {
        const double x = 3.0 * i / 300.0;
        xf.push_back(x);
        y_zero.push_back(hermite_interpolate(xs, ys, zero, x));
        y_cat.push_back(hermite_interpolate(xs, ys, catmull, x));
    }

    // Exactness on a real cubic g(x)=x^3-2x+1 with analytic slopes.
    auto g = [](double x) { return x * x * x - 2 * x + 1; };
    auto dg = [](double x) { return 3 * x * x - 2; };
    std::vector<double> gy, gm;
    for (double x : xs) { gy.push_back(g(x)); gm.push_back(dg(x)); }
    std::cout << "=== Hermite reproduces the cubic x^3-2x+1 ===\n";
    for (double x : {0.5, 1.5, 2.5})
        std::cout << "x=" << x << ": hermite " << hermite_interpolate(xs, gy, gm, x) << " vs exact " << g(x) << "\n";
    std::cout << "\nzero-slope curve stays flat at each node; Catmull-Rom overshoots between them.\n";

    auto plot = RPlot::create();
    plot.line(xf, y_zero, "zero slopes", RGB{16, 185, 129}, 2.0);
    plot.line(xf, y_cat, "Catmull-Rom", RGB{220, 38, 38}, 2.0);
    plot.points(xs, ys, "nodes", RGB{37, 99, 235}, 8.0);
    plot.legend({"zero tangents (flat at nodes)", "Catmull-Rom tangents", "shared nodes"},
                {{16, 185, 129}, {220, 38, 38}, {37, 99, 235}});
    plot.title("Same four points, different tangents -> different cubic Hermite curves")
        .x_label("x").y_label("y").background({250, 250, 252});
    plot.save_svg("build/org/hermite.svg");
    std::cout << "wrote hermite.svg\n";
#+end_src

With analytic slopes Hermite reproduces the cubic to machine precision -- unsurprising,
since a cubic *is* its own Hermite interpolant. The two tangent choices on the zig-zag
show the control the slopes give: zero tangents flatten the curve as it touches each
node, while Catmull-Rom's centred-difference slopes make it swing through with momentum.

#+attr_html: :width 660
#+attr_latex: :width 0.85\linewidth
[[file:../../build/org/hermite.svg]]

Both curves pass through the same blue nodes, but the green zero-tangent curve arrives
and leaves each node horizontally, while the red Catmull-Rom curve keeps its slope and
overshoots between them. That is the defining feature of Hermite interpolation: the
points fix where the curve goes, the tangents fix how it gets there.
