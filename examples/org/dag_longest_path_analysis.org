#+options: toc:t num:t
#+property: header-args:c++ :eval no
* Mathematics
The unrestricted simple longest-path problem is NP-hard.  In a DAG, a
topological order makes it dynamic programming:
\[
d(v)=\max_{(u,v)\in E}\{d(u)+w(u,v)\},\quad d(s)=0.
\]
Every predecessor has already been finalized, proving the recurrence exact.
* Pseudocode
#+begin_example
topologically sort; reject a cycle
distance <- -infinity; distance[source] <- 0
for u in topological order:
  relax every u->v by maximum rather than minimum
#+end_example
Time is \(O(V+E)\).
