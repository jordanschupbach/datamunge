#+begin_abstract
The *secant method* fits a straight line through the two most recent iterates.
*Muller's method* goes one degree higher: it fits a *parabola* through the three most
recent points and jumps to that parabola's nearest root. A parabola bends, so it can
cross zero where a line cannot -- and it converges at order \(\approx1.84\), faster
than the secant's golden-ratio 1.618, while still using no derivative. This report
implements it in =datamunge='s C++ =algorithms::muller= and watches the parabola
close in on a root of a cubic.
#+end_abstract

* Fitting a quadratic instead of a line

Given three points \((x_0,x_1,x_2)\) with values \(f_i\), Muller builds the parabola
through them using divided differences and takes the root nearest \(x_2\):

\[
x_{3}=x_2-\frac{2c}{b\pm\sqrt{b^{2}-4ac}},\qquad
c=f_2,\quad b=a\,h_1+d_1,\quad a=\frac{d_1-d_0}{h_1+h_0},
\]

with \(h_i=x_{i+1}-x_i\) and \(d_i=(f_{i+1}-f_i)/h_i\). The \(\pm\) sign is chosen to
make the *denominator largest* in magnitude -- the numerically stable way to pick the
nearer root and avoid cancellation. Two features stand out:

- *No derivative.* Like the secant method, Muller needs only function values.
- *It can leave the real line.* The discriminant \(b^2-4ac\) may go negative, in which
  case the true parabola root is complex; the original method embraces this to find
  complex roots. This real-valued =datamunge= implementation *clamps* a negative
  discriminant to zero, so it stays real and targets real roots.

The order of convergence is the real root of \(t^3=t^2+t+1\), about *1.84* -- between
the secant method (1.618) and Newton (2.0), but with no derivative required.

* Algorithm

#+begin_example
MULLER(f, x0, x1, x2):
  repeat:
      h0 <- x1-x0;  h1 <- x2-x1
      d0 <- (f1-f0)/h0;  d1 <- (f2-f1)/h1
      a  <- (d1-d0)/(h1+h0);  b <- a*h1 + d1;  c <- f2
      disc <- max(b*b - 4*a*c, 0)                 # clamp: target real roots
      denom <- (|b+sqrt(disc)| > |b-sqrt(disc)|) ? b+sqrt(disc) : b-sqrt(disc)
      x3 <- x2 - 2c/denom
      shift (x0,x1,x2) <- (x1,x2,x3)
      if |f(x3)| < tol: return x3
#+end_example

* Worked example: the real root of x^3 - x - 2

The cubic \(x^{3}-x-2\) has a single real root near \(1.5214\). Starting from three
points \(1,\ 1.5,\ 2\), Muller's parabola locks on quickly. We also confirm it finds
\(\ln 2\) as a root of \(e^{x}-2\) using only function values.

#+name: mu-run
#+begin_src c++ :eval no
    auto cubic = [](double x) { return x * x * x - x - 2.0; };
    const RootResult r = muller(cubic, 1.0, 1.5, 2.0);
    std::cout << "=== Muller on x^3 - x - 2, from {1, 1.5, 2} ===\n";
    std::cout << "root = " << r.root << ", iterations = " << r.iterations << ", residual = " << r.residual << "\n\n";

    auto expo = [](double x) { return std::exp(x) - 2.0; };
    const RootResult r2 = muller(expo, 0.0, 0.5, 1.0);
    std::cout << "=== Muller on e^x - 2 (no derivative) ===\n";
    std::cout << "root = " << r2.root << "  (ln 2 = " << std::log(2.0) << "), iterations = " << r2.iterations << "\n\n";

    // Trace the residual per step on the cubic.
    std::vector<double> it, lg;
    { double x0 = 1.0, x1 = 1.5, x2 = 2.0, f0 = cubic(x0), f1 = cubic(x1), f2 = cubic(x2);
      for (int i = 1; i <= 12; ++i) {
          it.push_back(i); lg.push_back(std::log10(std::max(std::fabs(f2), 1e-16)));
          if (std::fabs(f2) < 1e-14) break;
          double h0 = x1 - x0, h1 = x2 - x1, d0 = (f1 - f0) / h0, d1 = (f2 - f1) / h1;
          double a = (d1 - d0) / (h1 + h0), b = a * h1 + d1, c = f2;
          double disc = std::max(b * b - 4 * a * c, 0.0), sq = std::sqrt(disc);
          double den = (std::fabs(b + sq) > std::fabs(b - sq)) ? b + sq : b - sq;
          double x3 = x2 - 2 * c / den;
          x0 = x1; f0 = f1; x1 = x2; f1 = f2; x2 = x3; f2 = cubic(x3);
      } }
    std::cout << "cubic residual per step: "; for (double v : lg) std::cout << v << " "; std::cout << "\n";

    auto plot = RPlot::create();
    plot.line(it, lg, "Muller", RGB{124, 58, 237}, 2.0);
    plot.points(it, lg, "Muller", RGB{124, 58, 237}, 7.0);
    plot.legend({"Muller (order 1.84)"}, {{124, 58, 237}});
    plot.title("Muller's parabola converges superlinearly on x^3 - x - 2")
        .x_label("iteration").y_label("log10 |f(x)|").background({250, 250, 252});
    plot.save_svg("build/org/muller.svg");
    std::cout << "\nwrote muller.svg\n";
#+end_src

* Results

#+begin_example

root = 1.52138, iterations = 5, residual = 0

=== Muller on e^x - 2 (no derivative) ===

cubic residual per step: 0.60206 -2.29067 -5.05522 -9.21377 -16
#+end_example

Muller reaches the cubic's real root in a handful of steps and pins \(\ln 2\) from
three ordinary points -- no derivative anywhere. The residual trace shows the
superlinear plunge: each step the parabola fits the local curvature and overshoots
far less than a straight secant would.

The residual falls steeply and then plummets to the machine floor -- the accelerating
descent of order-1.84 convergence. Because a parabola can bend across the axis, Muller
handles roots that a straight-line secant approaches only sluggishly, all while
touching nothing but function values.
