typeset PDF alongside it.

** [[./ica_analysis.html][Independent Component Analysis: Blind Source Separation via FastICA]] ([[./ica_analysis.pdf][PDF]])
/A literate C++ study of the cocktail-party problem and non-Gaussianity using datamunge/

We implement the deflationary FastICA algorithm (Hyvarinen & Oja, 1997) in =datamunge='s C++ =stats::ICA= and report it as a literate program: every fragment below is a real, compiled, executed chunk of the single C++ binary that produced every number and figure in this document. Three independent signals (sine, square, sawtooth) are linearly mixed and then recovered from the mixtures alone at a mean correlation of 0.9999 -- versus 0.7625 for a rank-matched PCA of the same data, since PCA removes only correlation while ICA removes all higher-order dependence by maximizing non-Gaussianity. A geometric example and a Gaussian-source control (where ICA's advantage over PCA vanishes, exactly as the theory requires) round out the study.
