Each report below is a literate C++ program: every number, table, and figure
it shows comes from a single real, compiled, executed program built directly
against =datamunge='s C++ library, not from hand-typed results. Click a title
for the HTML version (with a link back here in the page header), or grab the
typeset PDF alongside it.
