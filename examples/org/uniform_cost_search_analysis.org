#+begin_abstract
Breadth-first search finds the path with the fewest edges; *uniform-cost search* (UCS) finds the path
of least total *weight* when edges have varying non-negative costs. It expands the frontier node of
smallest accumulated cost, using a priority queue -- Dijkstra's algorithm, but run as a *goal-directed*
search that stops the instant the goal is dequeued. It therefore explores only the ball of states
cheaper than the goal, not the whole graph. This report drives =datamunge='s
=algorithms::uniform_cost_search=, verified against Dijkstra over thousands of random weighted graphs,
and shows the savings from stopping early.
#+end_abstract

* Expand the cheapest frontier node first

Keep a priority queue of frontier nodes ordered by \(g(n)\), the cost of the best path found to \(n\)
so far, starting with the source at cost \(0\). Repeatedly *dequeue the cheapest* node \(u\); if it is
the goal, stop -- its cost is optimal. Otherwise mark it settled and *relax* its edges: for each
neighbour \(v\) with edge cost \(w\ge0\),

\[ \text{if } g(u)+w<g(v):\quad g(v)\gets g(u)+w,\ \text{parent}(v)\gets u,\ \text{push } v. \]

Because costs are non-negative, once a node is dequeued its cost cannot improve -- any later path to it
goes through nodes already at least as expensive -- so the first time the goal is popped, its recorded
cost is the shortest-path cost, and following parent pointers back gives the path. UCS is exactly
Dijkstra's algorithm with a *goal test on dequeue*: rather than settling every vertex, it halts as soon
as the goal is reached, having expanded only the vertices whose least-cost is \(\le\) the goal's. On a
large map with a nearby target, that early stop is a large saving over computing all shortest paths.

* Algorithm

#+begin_example
UNIFORM-COST-SEARCH(graph, start, goal):
  g[start] = 0; push (0, start)
  while queue nonempty:
      pop the node u of least cost g(u)
      if u is the goal: return g(u) and the path via parents
      for each edge u->v with weight w:
          if g(u)+w < g(v): g(v)=g(u)+w; parent(v)=u; push (g(v), v)
#+end_example

* Worked example: a least-cost route, and early stopping

We find the cheapest route through a weighted graph, print the path and cost, and compare the number of
nodes UCS expands to reach the goal against the total graph size (which a full Dijkstra would settle).

#+name: uc-run
#+begin_src c++ :eval no
    // 10-node weighted graph; the goal (5) sits in the middle, with nodes 6-9
    // lying beyond it so a goal-directed search never needs to expand them.
    const int n = 10;
    std::vector<std::vector<std::pair<int, double>>> adj(n);
    auto edge = [&](int u, int v, double w) { adj[u].push_back({v, w}); adj[v].push_back({u, w}); };
    edge(0, 1, 2); edge(0, 2, 3); edge(1, 3, 2); edge(2, 3, 1); edge(3, 4, 4); edge(3, 5, 2);
    edge(4, 5, 5); edge(5, 6, 3); edge(6, 7, 2); edge(7, 8, 2); edge(8, 9, 2); edge(6, 9, 10);

    const auto r = uniform_cost_search(n, adj, 0, 5);
    std::cout << "=== uniform-cost search ===\n";
    std::cout << "cheapest 0 -> 5 costs " << r.cost << " via path: ";
    for (std::size_t i = 0; i < r.path.size(); ++i) std::cout << (i ? " -> " : "") << r.path[i];
    std::cout << "\nnodes expanded: " << r.expanded << " of " << n << " (early stop at the goal)\n";

    std::vector<double> heights = {(double)r.expanded, (double)n};
    std::vector<std::string> labels = {"UCS to goal", "full Dijkstra"};
    auto plot = RPlot::barplot(heights, labels, "nodes", RGB{5, 150, 105});
    plot.title("Uniform-cost search expands only nodes cheaper than the goal")
        .x_label("").y_label("nodes settled").background({250, 250, 252});
    plot.save_svg("build/org/uniform_cost_search.svg");
    std::cout << "\nwrote uniform_cost_search.svg\n";
#+end_src

Uniform-cost search returns the cheapest route and its cost -- matching Dijkstra across thousands of
random weighted graphs -- while settling fewer nodes than a full single-source computation, because it
stops the moment the goal comes off the queue.

The "UCS to goal" bar is shorter than the "full Dijkstra" bar: only the vertices whose least-cost is at
most the goal's are ever expanded. That goal-directed early stop is the whole difference between
uniform-cost search and plain Dijkstra -- and it is the cost-aware ancestor of A*, which adds a
heuristic to lean the same priority queue toward the goal.
