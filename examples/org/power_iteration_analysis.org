#+begin_abstract
Multiply almost any vector by a matrix over and over, renormalizing as you go, and
it swings around to point along the matrix's *dominant eigenvector* -- the direction
the matrix stretches most. This is *power iteration*, the simplest eigenvalue
method and the seed of PageRank, PCA's leading component, and much more. This report
implements it in =datamunge='s C++ =algorithms::power_iteration=, tracks the
*Rayleigh quotient* converging to the largest eigenvalue, and reads off the dominant
eigenpair of a small matrix.
#+end_abstract

* Why repeated multiplication aligns with the top eigenvector

Write the start vector in the eigenbasis, \(v_0=\sum_i c_i x_i\) with eigenvalues
\(|\lambda_1|>|\lambda_2|\ge\cdots\). Applying \(A\) scales each component by its
eigenvalue: \(A^k v_0=\sum_i c_i\lambda_i^k x_i=\lambda_1^k\!\left(c_1 x_1+\sum_{i>1}
c_i(\lambda_i/\lambda_1)^k x_i\right)\). Because every ratio \(\lambda_i/\lambda_1\)
has magnitude below 1, all but the first term decay, so the direction converges to
\(x_1\). Renormalizing each step keeps the vector bounded; the eigenvalue is
recovered as the *Rayleigh quotient* \(\lambda=v^{\top}Av/v^{\top}v\), which for a
unit \(v\) is just \(v^{\top}Av\). Convergence is linear at rate
\(|\lambda_2/\lambda_1|\) -- fast when the top eigenvalue is well separated, slow when
the top two are close.

* Algorithm

#+begin_example
POWER-ITERATION(A):
  v <- random unit vector
  repeat:
      w <- A v
      v <- w / ||w||
  lambda <- v^T A v          # Rayleigh quotient
  return (lambda, v)
#+end_example

* Worked example: the dominant eigenpair of [[2,1],[1,2]]

This symmetric matrix has eigenvalues 3 (eigenvector \((1,1)\)) and 1 (eigenvector
\((1,-1)\)). Starting from \((1,0)\), the Rayleigh quotient climbs 2, 2.8, 2.976,
... toward 3, and the iterate turns to point along \((1,1)\). The program traces
this and prints the eigenpair the library returns.

#+name: pi-run
#+begin_src c++ :eval no
    const std::vector<std::vector<double>> A = {{2.0, 1.0}, {1.0, 2.0}};
    const EigenPair e = power_iteration(A);
    std::cout << "=== Power iteration on [[2,1],[1,2]] ===\n";
    std::cout << "dominant eigenvalue = " << e.value << " (true 3)\n";
    std::cout << "eigenvector = (" << e.vector[0] << ", " << e.vector[1]
              << ")  (true direction (1,1))\n\n";

    // Trace the Rayleigh-quotient estimate per iteration.
    std::vector<double> its, est;
    {
        std::vector<double> v = {1.0, 0.0};
        for (int i = 0; i < 15; ++i) {
            const std::vector<double> w = {A[0][0] * v[0] + A[0][1] * v[1], A[1][0] * v[0] + A[1][1] * v[1]};
            const double ray = v[0] * w[0] + v[1] * w[1]; // v unit -> Rayleigh quotient
            its.push_back(i); est.push_back(ray);
            const double nw = std::sqrt(w[0] * w[0] + w[1] * w[1]);
            v = {w[0] / nw, w[1] / nw};
        }
    }
    std::cout << "Rayleigh estimates: ";
    for (double r : est) std::cout << r << " ";
    std::cout << "\n";

    auto plot = RPlot::create();
    plot.line(its, est, "estimate", RGB{37, 99, 235}, 2.0);
    plot.points(its, est, "estimate", RGB{37, 99, 235}, 7.0);
    plot.abline_h(3.0, RGB{22, 163, 74}, 1.5);
    plot.legend({"Rayleigh quotient", "true lambda = 3"}, {{37, 99, 235}, {22, 163, 74}});
    plot.title("Power iteration: the Rayleigh quotient climbs to the dominant eigenvalue")
        .x_label("iteration").y_label("eigenvalue estimate").background({250, 250, 252});
    plot.y_limits(1.8, 3.2);
    plot.save_svg("build/org/power_iteration.svg");
    std::cout << "\nwrote power_iteration.svg\n";
#+end_src

Power iteration recovers the eigenvalue 3 and an eigenvector along \((1,1)\). The
Rayleigh trace shows the estimate rising monotonically toward 3, each step closing
the gap by the factor \(|\lambda_2/\lambda_1|=1/3\), so a dozen iterations already
reach machine accuracy for this well-separated matrix.

The blue Rayleigh-quotient estimate climbs from 2 toward the green line at the true
dominant eigenvalue 3, flattening as the iterate aligns with the top eigenvector.
The speed of that approach is set entirely by how far the second eigenvalue (1)
sits below the first (3) -- the wider that gap, the faster power iteration locks on.
