* Mathematics and algorithm
Beam-stack search keeps beam search's best \(B\) paths but stores pruned
alternatives on a stack.  If the active beam dies, the most recent deferred
path is restored, combining bounded forward search with backtracking.
#+begin_example
expand and rank current beam
push candidates beyond width B onto deferred stack
if beam empties, pop one deferred path and continue
#+end_example
Finite simple-path search is complete, though exponential in the worst case.
