#+begin_abstract
Discretizing a partial differential equation on a grid produces a large, sparse linear system with a
handful of nonzeros per row. Point iterations like Gauss-Seidel solve it but crawl, because they couple
only adjacent nodes. Stone's *Strongly Implicit Procedure* (SIP, 1968) converges far faster by using an
*incomplete LU factorization* whose triangular factors mimic the operator, with the extra fill terms
partially cancelled. This report drives =datamunge='s =algorithms::stone_sip=, verified to solve a
Poisson system to machine precision and to drive the residual down monotonically, and shows the
geometric convergence.
#+end_abstract

* An incomplete factorization with controlled fill

A 5-point finite-difference stencil gives each grid node \(p\) an equation coupling it to its four
neighbors,

\[ A_p\,x_p + A_w\,x_{w} + A_e\,x_{e} + A_s\,x_{s} + A_n\,x_{n}=b_p. \]

An *exact* LU factorization of this sparse operator fills in with many new nonzeros; SIP instead builds an
*approximate* factorization \(M=LU\) whose factors keep only three diagonals each -- the same footprint as
\(A\) -- so \(M\) is cheap to form and to invert. The factorization deliberately produces a few extra
terms coupling to *diagonal* neighbors; SIP subtracts a fraction \(\alpha\) of those spurious terms (via a
Taylor-like cancellation) so that \(M\) stays close to \(A\). The iteration is then

\[ M\,\delta^{(k)}=r^{(k)}=b-Ax^{(k)},\qquad x^{(k+1)}=x^{(k)}+\delta^{(k)}, \]

each step a single forward and backward sweep through the grid. Because \(M\approx A\) far better than the
diagonal that Jacobi uses or the lower-triangle Gauss-Seidel uses, the residual falls geometrically with a
small contraction factor -- typically an order of magnitude every few iterations -- making SIP a classic
fast solver for the structured grids of computational fluid dynamics and heat transfer.

* Algorithm

#+begin_example
STONE-SIP(A coefficients, b, alpha):
  # incomplete LU with 3-diagonal L and U
  for each node p in row-major order:
      Lw, Ls from Aw, As with alpha-cancellation of the fill
      Lp = Ap + fill terms - Lw*Ue[w] - Ls*Un[s]
      Ue = (Ae - fill)/Lp;  Un = (An - fill)/Lp
  repeat:
      r = b - A x                          # residual
      solve L rho = r   (forward sweep)
      solve U dx  = rho (backward sweep)
      x += dx
  until ||r|| < tol
#+end_example

* Worked example: a Poisson system

We build a 5-point Laplacian on a \(30\times30\) grid, manufacture a right-hand side from a known
solution, solve it with SIP, and trace the residual per iteration.

#+name: st-run
#+begin_src c++ :eval no
    const int Nx = 30, Ny = 30, M = Nx * Ny;
    std::vector<double> Ap(M, 4), Aw(M, 0), Ae(M, 0), As(M, 0), An(M, 0);
    auto idx = [&](int i, int j) { return j * Nx + i; };
    for (int j = 0; j < Ny; ++j)
        for (int i = 0; i < Nx; ++i) {
            const int p = idx(i, j);
            if (i > 0) Aw[p] = -1; if (i < Nx - 1) Ae[p] = -1;
            if (j > 0) As[p] = -1; if (j < Ny - 1) An[p] = -1;
        }
    std::mt19937 rng(1);
    std::uniform_real_distribution<double> u(-1, 1);
    std::vector<double> xt(M);
    for (auto& v : xt) v = u(rng);
    std::vector<double> b(M, 0);
    for (int j = 0; j < Ny; ++j)
        for (int i = 0; i < Nx; ++i) {
            const int p = idx(i, j);
            double    ax = Ap[p] * xt[p];
            if (i > 0) ax += Aw[p] * xt[idx(i - 1, j)];
            if (i < Nx - 1) ax += Ae[p] * xt[idx(i + 1, j)];
            if (j > 0) ax += As[p] * xt[idx(i, j - 1)];
            if (j < Ny - 1) ax += An[p] * xt[idx(i, j + 1)];
            b[p] = ax;
        }

    const auto res = stone_sip(Nx, Ny, Ap, Aw, Ae, As, An, b, 0.92, 500, 1e-12);
    double maxerr = 0;
    for (int p = 0; p < M; ++p) maxerr = std::max(maxerr, std::fabs(res.x[p] - xt[p]));
    std::cout << "=== Stone's method (SIP) ===\n";
    std::printf("%dx%d Poisson system.  converged in %d iterations, residual %.2e, max|x-xtrue| %.2e\n",
                Nx, Ny, res.iterations, res.residual, maxerr);

    std::vector<double> it, rr;
    std::cout << "residual by iteration:\n";
    for (int k : {1, 2, 5, 10, 20, 40, 60, 80}) {
        const auto r = stone_sip(Nx, Ny, Ap, Aw, Ae, As, An, b, 0.92, k, 1e-15);
        it.push_back(k); rr.push_back(std::max(1e-14, r.residual));
        std::printf("  %3d iters: %.3e\n", k, r.residual);
    }

    auto plot = RPlot::create();
    plot.line(it, rr, "res", RGB{16, 122, 87}, 2.2);
    plot.points(it, rr, "res", RGB{16, 122, 87}, 5.0);
    plot.legend({"residual ||b - Ax||"}, {{16, 122, 87}});
    plot.title("Stone's SIP drives the residual down geometrically")
        .x_label("iteration").y_label("residual (log scale)").background({250, 250, 252});
    plot.save_svg("build/org/stone_sip.svg");
    std::cout << "\nwrote stone_sip.svg\n";
#+end_src

On the logarithmic axis the residual falls along a near-straight line -- geometric convergence with a
small contraction factor -- until it flattens at the floor of double precision. That steady, rapid decay
is the payoff of an incomplete factorization that hugs the operator: SIP spends a little more per
iteration than Gauss-Seidel but takes far fewer of them, which is why it long served as a default solver
for the structured grids of CFD and heat-transfer codes.
