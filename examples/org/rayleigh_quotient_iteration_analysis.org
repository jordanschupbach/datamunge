#+begin_abstract
Inverse iteration finds an eigenvector fast if you already know its eigenvalue. *Rayleigh quotient
iteration* removes that requirement by updating the eigenvalue estimate every step, using the current
vector's *Rayleigh quotient* -- the best possible scalar estimate. Vector and shift then refine each
other, and for a symmetric matrix the result is *cubic* convergence: the number of correct digits roughly
triples each iteration. This report drives =datamunge='s =algorithms::rayleigh_quotient_iteration=,
verified to converge to a true eigenpair to machine precision, and shows the residual collapsing cubically.
#+end_abstract

* Let the shift chase the vector

For a unit vector \(x\), the *Rayleigh quotient*

\[ \mu(x)=x^\top A x \]

is the scalar that best approximates an eigenvalue in the least-squares sense: if \(x\) is close to an
eigenvector \(v_j\), then \(\mu(x)\) is close to \(\lambda_j\), with error *quadratic* in the eigenvector
error. Rayleigh quotient iteration plugs this ever-improving estimate back in as the inverse-iteration
shift:

\[ \mu_k=x_k^\top A x_k,\qquad (A-\mu_k I)\,y=x_k,\qquad x_{k+1}=\frac{y}{\lVert y\rVert}. \]

Now both quantities improve together: a better vector gives a better shift, which through the near-singular
solve gives a far better vector. For symmetric \(A\) this feedback yields *cubic* local convergence -- the
error \(e_{k+1}=O(e_k^3)\) -- so a correct digit becomes three, then nine, then twenty-seven, reaching
machine precision in three or four steps. The price is that \(A-\mu_k I\) changes every iteration and must
be re-factored, but for the last few steps of an eigenvalue computation that cost is trivial next to the
blistering convergence. It is the refinement step behind high-accuracy symmetric eigensolvers.

* Algorithm

#+begin_example
RAYLEIGH-QUOTIENT-ITERATION(A, x0):
  x = normalized x0
  repeat:
      mu = x^T A x                 # Rayleigh quotient: best eigenvalue estimate
      solve (A - mu I) y = x
      x = y / ||y||
  return (mu, x)
#+end_example

* Worked example: cubic convergence

We build a symmetric matrix with eigenvalues \(\{1,3,7\}\), start from a generic vector, and record the
residual \(\lVert Ax-\mu x\rVert\) each step to expose the cubic rate.

#+name: rqi-run
#+begin_src c++ :eval no
    // Symmetric A with eigenvalues {1, 3, 7} via a fixed orthonormal Q.
    const double Q[3][3] = {{0.6667, -0.6667, 0.3333}, {0.6667, 0.3333, -0.6667}, {0.3333, 0.6667, 0.6667}};
    const double d[3] = {1, 3, 7};
    std::vector<std::vector<double>> A(3, std::vector<double>(3, 0));
    for (int i = 0; i < 3; ++i)
        for (int j = 0; j < 3; ++j) { double s = 0; for (int k = 0; k < 3; ++k) s += Q[i][k] * d[k] * Q[j][k]; A[i][j] = s; }

    std::vector<double> res;
    const auto p = rayleigh_quotient_iteration(A, {0.5, 0.4, 0.9}, 7, &res);
    std::cout << "=== Rayleigh quotient iteration ===\n";
    std::printf("converged eigenvalue = %.10f\n", p.value);
    std::printf("eigenvector = (%.4f, %.4f, %.4f)\n", p.vector[0], p.vector[1], p.vector[2]);
    std::cout << "residual per step:\n";
    for (std::size_t k = 0; k < res.size(); ++k) std::printf("  step %zu: %.3e\n", k, res[k]);

    std::vector<double> it, rr;
    for (std::size_t k = 0; k < res.size(); ++k) { it.push_back(static_cast<double>(k)); rr.push_back(std::max(1e-17, res[k])); }

    auto plot = RPlot::create();
    plot.line(it, rr, "r", RGB{190, 24, 93}, 2.2);
    plot.points(it, rr, "r", RGB{190, 24, 93}, 6.0);
    plot.legend({"residual ||A x - mu x||"}, {{190, 24, 93}});
    plot.title("Rayleigh quotient iteration converges cubically (log scale)")
        .x_label("iteration").y_label("residual").background({250, 250, 252});
    plot.save_svg("build/org/rayleigh_quotient_iteration.svg");
    std::cout << "\nwrote rayleigh_quotient_iteration.svg\n";
#+end_src

From a generic start the iteration locks onto one of the eigenvalues, its residual falling from order one
to machine precision in just a few steps -- each residual roughly the *cube* of the previous, the
signature of Rayleigh quotient iteration.

The residual plunges almost off the bottom of the log axis within three or four iterations: once the
vector is even roughly aligned, the Rayleigh-quotient shift becomes accurate enough that the next solve
nearly lands on the eigenvector exactly, and the one after that overshoots machine precision. Letting the
shift chase the vector -- each making the other better -- is what turns inverse iteration's steady
geometric decay into this explosive cubic convergence.
