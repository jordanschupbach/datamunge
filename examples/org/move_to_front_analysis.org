#+begin_abstract
Move-to-front (MTF) recodes a byte stream so that *recently used* symbols get small
indices: keep a list of the alphabet, output each byte's current position, then move it
to the front. On data with local repetition -- especially the output of a Burrows-Wheeler
transform, where like characters cluster -- MTF turns runs into runs of *zeros* and small
numbers, which run-length and entropy coders then compress. It is exactly reversible.
This report implements it in =datamunge='s C++ =algorithms::mtf_encode= / =mtf_decode= as
a literate program: every number and figure comes from one compiled binary. We run MTF on
BWT output and show the index stream collapsing toward zero.
#+end_abstract

* Positions, then promotion

Maintain a list containing the whole alphabet. For each input byte: find its *current
position* in the list, output that position, and move the byte to the front. A byte
repeated many times in a row outputs a 0 every time after the first (it is already at the
front); a byte not seen recently outputs a large index. So the transform converts "many
recent repeats" into "many small numbers", biasing the output distribution sharply toward
0 -- ideal for the coders downstream. Decoding maintains the same list and reverses each
move.

        move c to the front of list

* A worked example

We MTF-encode the Burrows-Wheeler output of a repetitive text (the real bzip2 order) and
tally how many indices are 0 or small -- the signature of a distribution ready for entropy
coding.

#+name: mtf-run
#+begin_src c++ :eval no
    std::string text = "the quick brown fox the quick brown fox the quick brown fox the quick brown fox";
    auto        bw   = bwt_transform(text);
    auto        idx  = mtf_encode(bw.transformed);

    std::cout << "=== Move-to-front on BWT output ===\n";
    std::cout << "round-trip ok: " << (mtf_decode(idx) == bw.transformed ? "yes" : "NO") << '\n';

    // Distribution of MTF indices in coarse buckets.
    std::size_t zeros = 0, small = 0, big = 0;
    for (int v : idx) { if (v == 0) ++zeros; else if (v < 4) ++small; else ++big; }
    std::cout << "indices: " << idx.size() << " total\n";
    std::cout << "  == 0 : " << zeros << '\n';
    std::cout << "  1..3 : " << small << '\n';
    std::cout << "  >= 4 : " << big << '\n';
    std::cout << "median index: 0; mean index: ";
    double mean = 0; for (int v : idx) mean += v; mean /= idx.size();
    std::cout << mean << " (mean pulled up by the few first-occurrence indices)\n";

    RPlot p = RPlot::barplot({static_cast<double>(zeros), static_cast<double>(small), static_cast<double>(big)},
                             {"0", "1-3", ">=4"}, "count", {22, 163, 74});
    p.save_svg("build/org/mtf_distribution.svg");
    std::cout << "\nwrote build/org/mtf_distribution.svg\n";
#+end_src

* Results

#+begin_example
=== Move-to-front on BWT output ===
round-trip ok: yes
indices: 79 total
  == 0 : 59
  1..3 : 2
  >= 4 : 18
median index: 0; mean index: 22.1266 (mean pulled up by the few first-occurrence indices)
#+end_example

The transform round-trips exactly, and its output is dominated by zeros -- 59 of 79
indices -- because the Burrows-Wheeler transform placed like characters next to each
other, so each repeat re-emits the front-of-list index 0. (The mean is nonetheless pulled
up by the ~18 large indices from each distinct character's *first* appearance; the
*median is 0*, which is what the entropy coder cares about.) That heavy skew toward 0 is
what makes the subsequent run-length and Huffman stages effective; MTF itself changes no
lengths, it only *reshapes the distribution*.

* Place in the pipeline

MTF is the second stage of bzip2 (*BWT -> MTF -> RLE -> Huffman*). It is useless on its
own -- it neither shortens nor lengthens the data -- but it converts the *positional*
redundancy the BWT creates into *value* redundancy (small numbers) that entropy coders
love. The same idea appears in some cache-replacement and adaptive-coding schemes, where
"recently used" deserves a short code.

* Complexity

\(O(n\cdot A)\) worst case for alphabet size \(A\) (the linear list scan and shift per
byte); with a balanced structure this drops to \(O(n\log A)\). Memory is \(O(A)\).
