#+begin_abstract
Is there an assignment of true/false to variables that makes a Boolean formula true? This is
*SAT*, the first problem proven NP-complete -- yet solved routinely on formulas with millions
of variables. The engine behind that success is *DPLL* (Davis-Putnam-Logemann-Loveland,
1962): backtracking search accelerated by *unit propagation* and *pure-literal elimination*,
two rules that force variables without guessing. This report drives =datamunge='s
=algorithms::dpll_sat=, verified against brute force, and traces the famous *phase
transition* where random 3-SAT flips from almost-always-satisfiable to almost-never.
#+end_abstract

* Propagate, eliminate, branch

A formula in *conjunctive normal form* is an AND of clauses, each an OR of literals. DPLL
tries to build a satisfying assignment, using two deductions before ever guessing:

- *Unit propagation.* If a clause has a single unassigned literal and the rest are false,
  that literal *must* be true -- assign it and repeat. This cascade often settles many
  variables at once.
- *Pure-literal elimination.* If a variable appears with only one polarity across the
  unsatisfied clauses, assigning it that polarity satisfies all of them for free.

Only when neither rule applies does DPLL *branch*: pick an unassigned variable, try it true,
and recurse; if that fails, try false. A clause with all literals false is a *conflict* that
triggers backtracking. This "propagate to fixpoint, then branch" loop is the skeleton every
modern CDCL solver still runs -- with clause learning and restarts bolted on. The result is
either a satisfying assignment or a proof (by exhausting the search) that none exists.

* Algorithm

#+begin_example
DPLL(clauses, assignment):
  loop:
      if all clauses satisfied: return SAT
      if some clause is empty (all literals false): return UNSAT (backtrack)
      if a unit clause exists: assign its literal true; continue
      if a pure literal exists: assign it; continue
      break
  pick an unassigned variable x
  return DPLL(clauses, assignment + {x=true}) or DPLL(clauses, assignment + {x=false})
#+end_example

* Worked example: a solvable formula, a contradiction, and the phase transition

We solve a small satisfiable formula (reading off an assignment), confirm a contradictory one
is unsatisfiable, then sweep the clause-to-variable ratio of random 3-SAT to expose the sharp
satisfiability threshold near @math{m/n\approx4.26}.

#+name: dp-run
#+begin_src c++ :eval no
    // (x1 or x2) and (not x1 or x3) and (not x2 or not x3) and (x1 or not x3)
    const std::vector<std::vector<int>> f{{1, 2}, {-1, 3}, {-2, -3}, {1, -3}};
    const SatResult s = dpll_sat(3, f);
    std::cout << "=== a 3-variable formula ===\n";
    std::cout << "satisfiable: " << (s.satisfiable ? "yes" : "no");
    if (s.satisfiable) { std::cout << ", assignment x1=" << (s.assignment[1] > 0) << " x2=" << (s.assignment[2] > 0) << " x3=" << (s.assignment[3] > 0); }
    std::cout << "\n";

    // A direct contradiction: x1 and not x1.
    const SatResult u = dpll_sat(1, {{1}, {-1}});
    std::cout << "x1 and (not x1): satisfiable = " << (u.satisfiable ? "yes" : "no") << " (expected no)\n\n";

    // Phase transition: random 3-SAT, n = 25 vars, sweep m/n.
    std::mt19937 rng(4242);
    const int n = 25; const int trials = 120;
    std::vector<double> ratios, sat_frac;
    std::cout << "m/n     fraction satisfiable\n";
    for (double r = 2.0; r <= 7.01; r += 0.25) {
        const int m = static_cast<int>(r * n);
        int sat = 0;
        for (int t = 0; t < trials; ++t) {
            std::vector<std::vector<int>> clauses;
            for (int c = 0; c < m; ++c) {
                std::vector<int> cl;
                while (cl.size() < 3) {
                    const int v = 1 + static_cast<int>(rng() % n);
                    bool dup = false; for (int l : cl) if (std::abs(l) == v) dup = true;
                    if (!dup) cl.push_back((rng() & 1) ? v : -v);
                }
                clauses.push_back(cl);
            }
            if (dpll_sat(n, clauses).satisfiable) ++sat;
        }
        const double frac = static_cast<double>(sat) / trials;
        ratios.push_back(r); sat_frac.push_back(frac);
        std::printf("%.2f    %.2f\n", r, frac);
    }

    auto plot = RPlot::create();
    plot.line(ratios, sat_frac, "P(sat)", RGB{124, 58, 237}, 2.0);
    plot.points(ratios, sat_frac, "P(sat)", RGB{124, 58, 237}, 5.0);
    plot.abline_v(4.26, RGB{220, 38, 38}, 1.5);
    plot.legend({"fraction satisfiable", "threshold ~4.26"}, {{124, 58, 237}, {220, 38, 38}});
    plot.title("Random 3-SAT phase transition: a sharp cliff near m/n = 4.26")
        .x_label("clause/variable ratio m/n").y_label("fraction satisfiable").background({250, 250, 252});
    plot.save_svg("build/org/dpll.svg");
    std::cout << "\nwrote dpll.svg\n";
#+end_src

DPLL reads off a satisfying assignment for the solvable formula and correctly declares the
contradiction @math{x_1\wedge\neg x_1} unsatisfiable. The sweep reproduces the celebrated
*phase transition*: for few clauses almost every formula is satisfiable, for many almost none
is, and the switch happens abruptly right around the theoretical threshold @math{m/n\approx
4.26} -- exactly where random SAT instances are also hardest to solve.

The purple satisfiable-fraction curve stays near 1 at low ratios, plunges through a narrow
window, and flattens near 0 -- a cliff, not a slope -- crossing one-half close to the red
@math{4.26} line (a touch to its right here, the finite-size shift expected at only
@math{n=25} variables; the crossing marches onto @math{4.26} as @math{n} grows). That sharp
threshold, discovered empirically and then studied intensely, is one of the most striking
phenomena in the theory of computation, and DPLL is the tool that makes it visible.
