#+begin_abstract
For a matrix so large that even storing a dense copy is out of the question, the *Arnoldi iteration*
extracts everything worth knowing from just repeated matrix-vector products. It builds an orthonormal
basis of the *Krylov subspace* \(\{b, Ab, A^2b, \dots\}\) and, as a by-product, the small upper-Hessenberg
projection of \(A\) onto it, whose eigenvalues approximate \(A\)'s. This report drives =datamunge='s
=algorithms::arnoldi_iteration=, verified to satisfy the Arnoldi relation and produce an orthonormal
basis to machine precision, and shows the projected matrix's structure.
#+end_abstract

* An orthonormal Krylov basis, and the Hessenberg projection

The Krylov subspace \(K_m(A,b)=\operatorname{span}\{b,Ab,\dots,A^{m-1}b\}\) is where iterative methods
live: it is the richest subspace you can reach with \(m-1\) matrix-vector products. Its natural basis
\(b,Ab,\dots\) is hopelessly ill-conditioned (every vector tilts toward the dominant eigenvector), so
Arnoldi *orthonormalizes as it goes*. Starting from \(v_1=b/\lVert b\rVert\), each step forms \(Av_j\),
removes its components along the existing basis (modified Gram-Schmidt), and normalizes:

\[ h_{ij}=v_i^\top Av_j,\quad w=Av_j-\sum_{i\le j}h_{ij}v_i,\quad h_{j+1,j}=\lVert w\rVert,\quad v_{j+1}=w/h_{j+1,j}. \]

The coefficients assemble into an upper-*Hessenberg* matrix \(H_m\) (zero below the first subdiagonal),
and the whole construction is summarized by the *Arnoldi relation*

\[ A V_m = V_m H_m + h_{m+1,m}\,v_{m+1}e_m^\top, \qquad H_m=V_m^\top A V_m, \]

so \(H_m\) is the orthogonal projection of \(A\) onto the Krylov subspace. Its eigenvalues -- the *Ritz
values* -- approximate the eigenvalues of \(A\), converging first to the extreme ones, often to high
accuracy with \(m\) far smaller than \(n\). This single construction underlies GMRES (for solving
\(Ax=b\)) and the implicitly restarted Arnoldi method (for eigenvalues of huge nonsymmetric matrices).

* Algorithm

#+begin_example
ARNOLDI(A, b, m):
  v_1 = b / ||b||
  for j = 1..m:
      w = A v_j
      for i = 1..j:  h_ij = v_i . w;  w = w - h_ij v_i    # orthogonalize
      h_{j+1,j} = ||w||
      if h_{j+1,j} ~ 0: stop (invariant subspace found)
      v_{j+1} = w / h_{j+1,j}
  return the basis V and the upper-Hessenberg H
#+end_example

* Worked example: the Arnoldi relation and orthonormality

We run Arnoldi on a matrix and verify the two guarantees numerically: the basis is orthonormal and the
Arnoldi relation holds. The figure shows the residual of the relation shrinking to machine precision.

#+name: arn-run
#+begin_src c++ :eval no
    const int n = 8;
    std::vector<std::vector<double>> A(n, std::vector<double>(n, 0));
    unsigned s = 42;
    auto rnd = [&] { s = s * 1103515245u + 12345u; return ((s >> 16) % 1000) / 500.0 - 1.0; };
    for (int i = 0; i < n; ++i) for (int j = 0; j < n; ++j) A[i][j] = rnd();
    std::vector<double> b(n); for (auto& x : b) x = rnd();

    const auto r = arnoldi_iteration(A, b, n);
    const int  m = static_cast<int>(r.V.size()) - 1;

    // max deviation from orthonormality
    double orth = 0;
    for (int a = 0; a <= m; ++a)
        for (int c = 0; c <= m; ++c) { double d = 0; for (int k = 0; k < n; ++k) d += r.V[a][k] * r.V[c][k]; orth = std::max(orth, std::fabs(d - (a == c ? 1.0 : 0.0))); }

    std::cout << "=== Arnoldi iteration ===\n";
    std::printf("built %d-dimensional Krylov basis of a %dx%d matrix\n", m, n, n);
    std::printf("max deviation from orthonormality: %.2e\n", orth);

    // Arnoldi relation residual per column j.
    std::vector<double> jj, resid;
    for (int j = 0; j < m; ++j) {
        std::vector<double> Av(n, 0);
        for (int i = 0; i < n; ++i) for (int k = 0; k < n; ++k) Av[i] += A[i][k] * r.V[j][k];
        for (int i = 0; i <= m; ++i) for (int k = 0; k < n; ++k) Av[k] -= r.H[i][j] * r.V[i][k];
        double e = 0; for (double v : Av) e += v * v;
        jj.push_back(j + 1); resid.push_back(std::max(1e-17, std::sqrt(e)));
    }
    std::printf("max Arnoldi-relation residual over all columns: %.2e\n", *std::max_element(resid.begin(), resid.end()));

    auto plot = RPlot::create();
    plot.bars(jj, resid, "res", RGB{37, 99, 235}, 0.6);
    plot.legend({"||A v_j - sum_i H_ij v_i||"}, {{37, 99, 235}});
    plot.title("The Arnoldi relation holds to machine precision at every step")
        .x_label("Krylov step j").y_label("residual").background({250, 250, 252});
    plot.save_svg("build/org/arnoldi_iteration.svg");
    std::cout << "\nwrote arnoldi_iteration.svg\n";
#+end_src

The basis comes out orthonormal to machine precision and the Arnoldi relation holds at every column --
the two facts that make \(H=V^\top A V\) a faithful, tiny projection of \(A\) whose eigenvalues are the
Ritz approximations.

Each bar is the residual of the Arnoldi relation at one Krylov step, all of them at the \(10^{-16}\) floor
of double precision -- the orthogonalization keeps the basis clean and the Hessenberg coefficients exact.
That a handful of matrix-vector products yields a small matrix carrying the large one's spectral
information is the whole idea of Krylov methods, and Arnoldi is the construction that makes it work for
matrices with no special structure.
