#+begin_abstract
A permutation group can be specified by a few generators yet contain astronomically many elements --
how do you compute its *order*, or test whether a given permutation belongs to it, without listing
everything? The Schreier-Sims algorithm builds a *base and strong generating set* (BSGS): a chain of
point stabilisers whose orbit sizes multiply to the group order and whose transversals give an
instant membership test. This report drives =datamunge='s =algorithms::schreier_sims=, verified to
recover the orders of symmetric, cyclic, dihedral, and alternating groups, and shows the stabilizer
chain factoring \(|S_n|=n!\) into orbit lengths.
#+end_abstract

* The stabilizer chain

Pick a sequence of *base* points \(\beta_1,\beta_2,\dots\) such that only the identity fixes all of
them. They define a descending chain of stabilisers

\[ G=G^{(1)}\ \ge\ G^{(2)}\ \ge\ \cdots,\qquad G^{(i+1)}=\{g\in G^{(i)}:g(\beta_i)=\beta_i\}. \]

By the orbit-stabiliser theorem, \([G^{(i)}:G^{(i+1)}]=|\beta_i^{G^{(i)}}|\), the size of the orbit
of \(\beta_i\). Multiplying down the chain telescopes to

\[ |G|=\prod_i \big|\beta_i^{G^{(i)}}\big|. \]

The work is to find *strong generators* -- enough generators that each level's orbit is computed
correctly. Schreier's lemma supplies candidate generators for each stabiliser (the *Schreier
generators* \(u_{s\beta}^{-1}\,s\,u_\beta\) built from a transversal \(u\)); the algorithm *sifts*
each one down the chain, and any that fails to reduce to the identity becomes a new strong generator,
possibly extending the base. Once every Schreier generator sifts away, the chain is complete: the
orbit sizes give the order, and sifting a permutation to the identity is exactly the membership test.

#+name: ss-includes
#+begin_src c++ :eval no
#include <datamunge/algorithms/schreier_sims.hpp>
#include <datamunge/plot/plot.hpp>

#include <cmath>
#include <iostream>
#include <numeric>
#include <vector>

using namespace datamunge::algorithms;
using namespace datamunge::plot;

static std::vector<int> cyc(int n) { std::vector<int> p(n); for (int i = 0; i < n; ++i) p[i] = (i + 1) % n; return p; }
static std::vector<int> tr01(int n) { std::vector<int> p(n); std::iota(p.begin(), p.end(), 0); std::swap(p[0], p[1]); return p; }
#+end_src

* Algorithm

#+begin_example
SCHREIER-SIMS(generators):
  sift each generator into a stabilizer chain (extend base as needed)
  repeat:
      for each level i, each orbit point beta, each strong generator s:
          schreier = u_{s(beta)}^{-1} . s . u_beta       # fixes base[i]
          (residue, level) = sift(schreier)
          if residue != identity:
              add residue as a new strong generator at `level`
              extend base if it fell through the bottom; restart from `level`
  until every Schreier generator sifts to the identity
  order = product of orbit sizes over the chain
#+end_example

* Worked example: orders of classic groups, and n! factored

We compute the orders of several groups from their generators, then confirm the symmetric-group
orders \(|S_n|=n!\) and plot the stabilizer chain's orbit sizes that multiply to \(720=6!\).

#+name: ss-run
#+begin_src c++ :eval no
    std::cout << "=== Schreier-Sims group orders ===\n";
    // S_5 from a transposition and a 5-cycle.
    std::cout << "S_5 = " << schreier_sims(5, {tr01(5), cyc(5)}).order << " (expect 120)\n";
    // Dihedral D_4 (order 8).
    std::cout << "D_4 = " << schreier_sims(4, {{1, 2, 3, 0}, {1, 0, 3, 2}}).order << " (expect 8)\n";
    // Alternating A_4 (order 12) from two 3-cycles.
    std::cout << "A_4 = " << schreier_sims(4, {{1, 2, 0, 3}, {0, 2, 3, 1}}).order << " (expect 12)\n\n";

    std::cout << "symmetric groups |S_n| = n!:\n";
    std::vector<double> nx, logord;
    for (int n = 2; n <= 9; ++n) {
        const auto g = schreier_sims(n, {tr01(n), cyc(n)});
        unsigned long long fact = 1; for (int k = 2; k <= n; ++k) fact *= k;
        std::cout << "  |S_" << n << "| = " << g.order << "  (n! = " << fact << ", match: " << (g.order == fact ? "yes" : "no") << ")\n";
        nx.push_back(n); logord.push_back(std::log10((double)g.order));
    }

    // Stabilizer-chain orbit sizes for S_6: 6, 5, 4, 3, 2  ->  product 720.
    const auto g6 = schreier_sims(6, {tr01(6), cyc(6)});
    std::vector<double> lvl, orb; std::vector<std::string> lab;
    for (std::size_t i = 0; i < g6.transversal.size(); ++i) {
        lvl.push_back((double)(i + 1)); orb.push_back((double)g6.transversal[i].size());
        lab.push_back("L" + std::to_string(i + 1));
    }

    auto plot = RPlot::barplot(orb, lab, "orbit", RGB{37, 99, 235});
    plot.title("Stabilizer chain of S_6: orbit sizes 6*5*4*3*2 = 720")
        .x_label("chain level").y_label("orbit size").background({250, 250, 252});
    plot.save_svg("build/org/schreier_sims.svg");
    std::cout << "\nwrote schreier_sims.svg\n";
#+end_src

The algorithm recovers every group order from just two generators apiece: the symmetric groups give
\(n!\) exactly, the dihedral group \(8\), and the alternating group \(12\). The order was never
computed by enumeration -- it fell out as the product of the stabilizer chain's orbit sizes.

The bars are the orbit sizes at each level of \(S_6\)'s stabilizer chain: \(6,5,4,3,2\), whose product
is \(720=6!\). Each level fixes one more base point, shrinking the orbit by exactly the factor
predicted by orbit-stabiliser. The same transversals that make this factorisation also strip an
arbitrary permutation to the identity in linear time -- the fast membership test that makes BSGS the
backbone of computational group theory.
