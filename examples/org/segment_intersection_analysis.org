#+begin_abstract
Deciding whether two line *segments* cross -- and where -- is the atom of computational
geometry, underlying map overlay, clipping, collision, and the sweep-line algorithms that
find all intersections among many segments. The robust test uses no division and no slopes:
it asks, via the *orientation* (cross-product sign) of point triples, whether each segment
*straddles* the other. This report drives =datamunge='s =geometry::segments_intersect= and
=segment_intersection_point=, verified on crossing and non-crossing pairs, and marks the
crossings it finds.
#+end_abstract

* Straddle, by the sign of a cross product

The *orientation* of an ordered triple \((a,b,c)\) is the sign of the cross product
\((b-a)\times(c-a)\): positive is a counterclockwise turn, negative clockwise, zero
collinear. Two segments \(p_1q_1\) and \(p_2q_2\) *properly cross* exactly when each
straddles the line of the other:

- \(p_2\) and \(q_2\) lie on *opposite* sides of \(p_1q_1\), *and*
- \(p_1\) and \(q_1\) lie on *opposite* sides of \(p_2q_2\).

In orientation terms, the two orientations \((p_1,q_1,p_2)\) and \((p_1,q_1,q_2)\)
differ, and likewise for the other segment. Collinear *touching* is handled by an explicit
on-segment check. The whole decision is four cross products -- integer-exact for integer
coordinates, with no slope divisions to blow up on vertical segments. When a unique crossing
exists, its location comes from solving the two segment parametrizations (a single \(2\times2\)
system); collinear overlap has no single point, so that case reports none.

* Algorithm

#+begin_example
SEGMENTS-INTERSECT(p1,q1, p2,q2):
  o1 <- orient(p1,q1,p2);  o2 <- orient(p1,q1,q2)
  o3 <- orient(p2,q2,p1);  o4 <- orient(p2,q2,q1)
  if o1 != o2 and o3 != o4: return true         # proper straddle both ways
  handle collinear on-segment touching cases     # o == 0 and point lies on the segment
  return false
#+end_example

* Worked example: crossing, touching, and disjoint pairs

We test three segment pairs against a common segment: one that crosses it, one that misses,
and one that meets at an endpoint, and compute the crossing point where there is one.

#+name: si-run
#+begin_src c++ :eval no
    const Point2D a1{0, 0}, a2{6, 6}; // the reference segment (diagonal)

    struct Pair { const char* name; Point2D p, q; };
    const Pair tests[] = {
        {"crosses",  {0, 6}, {6, 0}},   // anti-diagonal, crosses at (3,3)
        {"disjoint", {0, 5}, {2, 6}},   // off to the side
        {"touches",  {6, 6}, {8, 2}},   // shares the endpoint (6,6)
    };

    std::cout << "=== against reference segment (0,0)-(6,6) ===\n";
    std::vector<std::vector<double>> segs_x, segs_y;
    std::vector<double> ix, iy;
    for (const Pair& t : tests) {
        const bool hit = segments_intersect(a1, a2, t.p, t.q);
        std::cout << t.name << ": intersects = " << (hit ? "true" : "false");
        Point2D pt;
        if (segment_intersection_point(a1, a2, t.p, t.q, pt)) {
            std::cout << ", crossing at (" << pt.x << ", " << pt.y << ")";
            ix.push_back(pt.x); iy.push_back(pt.y);
        }
        std::cout << "\n";
        segs_x.push_back({t.p.x, t.q.x});
        segs_y.push_back({t.p.y, t.q.y});
    }

    auto plot = RPlot::create();
    plot.line({a1.x, a2.x}, {a1.y, a2.y}, "reference", RGB{17, 24, 39}, 3.0);
    const RGB cols[] = {{220, 38, 38}, {100, 116, 139}, {5, 150, 105}};
    for (std::size_t i = 0; i < segs_x.size(); ++i) plot.line(segs_x[i], segs_y[i], tests[i].name, cols[i], 2.0);
    plot.points(ix, iy, "crossing", RGB{220, 38, 38}, 10.0);
    plot.legend({"reference (0,0)-(6,6)", "crosses", "disjoint", "touches"},
                {{17, 24, 39}, {220, 38, 38}, {100, 116, 139}, {5, 150, 105}});
    plot.title("Segment intersection: straddle test finds the crossing point")
        .x_label("x").y_label("y").background({250, 250, 252});
    plot.save_svg("build/org/segment_intersection.svg");
    std::cout << "wrote segment_intersection.svg\n";
#+end_src

* Results

#+begin_example
=== against reference segment (0,0)-(6,6) ===
crosses: intersects = true, crossing at (3, 3)
disjoint: intersects = false
touches: intersects = true, crossing at (6, 6)
wrote segment_intersection.svg
#+end_example

The anti-diagonal crosses the reference squarely at its midpoint \((3,3)\); the disjoint
segment off to the side does not intersect; and the third segment, sharing the endpoint
\((6,6)\), is reported as touching. The straddle test settles each case with a handful of
cross-product signs.

The black reference segment is cut by the red one at the marked crossing, brushed at its top
end by the green one, and left untouched by the grey one off to the side. No slopes, no
divisions in the decision -- just the signs of four cross products, which is what makes the
test robust enough to be the inner loop of a sweep-line intersection finder.
