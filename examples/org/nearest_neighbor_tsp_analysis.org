#+options: toc:t num:t
#+property: header-args:c++ :eval no
* Algorithm
From the current city, repeatedly visit the closest unvisited city, then
return to the start.  The invariant is that the partial route contains each
selected city once; termination therefore yields a Hamiltonian cycle.
#+begin_example
tour <- start
while an unvisited city remains: append the nearest one
append start
#+end_example
The direct scan costs \(O(n^2)\).  It is fast but greedy and has no constant
approximation ratio on arbitrary instances.
