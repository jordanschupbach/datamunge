#+begin_abstract
*Odd-even sort* (brick sort) alternates two phases: compare-and-swap every
odd-indexed adjacent pair, then every even-indexed pair, repeating until nothing
moves. What makes it interesting is *parallelism*: within a phase the comparisons
touch disjoint pairs, so they can all happen *at once*. Odd-even sort is thus a
classic *sorting network*, running in \(O(n)\) parallel phases (and \(O(n^2)\) work
serially). This report implements it in =datamunge='s C++ =algorithms::odd_even_sort=
and draws the comparator network that makes its parallelism visible.
#+end_abstract

* Two phases of disjoint comparators

Number the positions \(0,1,\dots,n-1\). An *odd phase* compares the pairs
\((1,2),(3,4),(5,6),\dots\); an *even phase* compares \((0,1),(2,3),(4,5),\dots\).
Within either phase no two comparisons share an index, so they are independent --
on parallel hardware a whole phase executes in one step. Alternating the phases and
repeating until a full round produces no swap sorts the array; a theorem guarantees
that at most \(n\) phases are ever needed. Serially the total comparison count is
\(\Theta(n^2)\), the same order as bubble sort, but the value of odd-even sort is as
a *network*: a fixed, data-independent pattern of comparators ideal for hardware and
SIMD, where the wall-clock cost is the number of phases, not the number of
comparisons.

* Algorithm

#+begin_example
ODD-EVEN-SORT(a):
  repeat:
      sorted <- true
      for i in 1, 3, 5, ... while i+1 < n:  if a[i] > a[i+1]: swap; sorted <- false   # odd phase
      for i in 0, 2, 4, ... while i+1 < n:  if a[i] > a[i+1]: swap; sorted <- false   # even phase
  until sorted
#+end_example

* Worked example and the comparator network

We sort \([5,3,8,1,9,2,7]\), counting the phases, and draw the comparator network
for eight wires: blue comparators are the odd phase, red the even phase, and every
comparator within a colour runs simultaneously.

#+name: oe-run
#+begin_src c++ :eval no
    std::cout << "=== Odd-even sort of [5,3,8,1,9,2,7] ===\n";
    std::cout << "sorted: ";
    for (int v : odd_even_sort({5, 3, 8, 1, 9, 2, 7})) std::cout << v << " ";
    std::cout << "\n";
    std::vector<int> a = {5, 3, 8, 1, 9, 2, 7};
    bool sorted = false; int phases = 0;
    while (!sorted) {
        sorted = true;
        for (std::size_t i = 1; i + 1 < a.size(); i += 2) if (a[i] > a[i + 1]) { std::swap(a[i], a[i + 1]); sorted = false; }
        for (std::size_t i = 0; i + 1 < a.size(); i += 2) if (a[i] > a[i + 1]) { std::swap(a[i], a[i + 1]); sorted = false; }
        ++phases;
    }
    std::cout << "full rounds (odd+even phases) until sorted: " << phases << "\n";

    // Draw the comparator network for 8 wires over a few rounds.
    const int W = 8, rounds = 3;
    auto plot = RPlot::create();
    std::vector<double> wx0, wy0, wx1, wy1;
    for (int w = 0; w < W; ++w) { wx0.push_back(0); wy0.push_back(w); wx1.push_back(2.0 * rounds + 1); wy1.push_back(w); }
    plot.segments(wx0, wy0, wx1, wy1, RGB{203, 213, 225}, 1.0); // the wires
    std::vector<double> ox0, oy0, ox1, oy1, ex0, ey0, ex1, ey1;
    for (int r = 0; r < rounds; ++r) {
        const double xo = 2.0 * r + 1.0, xe = 2.0 * r + 2.0;
        for (int i = 1; i + 1 < W; i += 2) { ox0.push_back(xo); oy0.push_back(i); ox1.push_back(xo); oy1.push_back(i + 1); }
        for (int i = 0; i + 1 < W; i += 2) { ex0.push_back(xe); ey0.push_back(i); ex1.push_back(xe); ey1.push_back(i + 1); }
    }
    plot.segments(ox0, oy0, ox1, oy1, RGB{37, 99, 235}, 2.5);  // odd-phase comparators
    plot.segments(ex0, ey0, ex1, ey1, RGB{220, 38, 38}, 2.5);  // even-phase comparators
    plot.legend({"odd phase", "even phase"}, {{37, 99, 235}, {220, 38, 38}});
    plot.title("Odd-even sort as a comparator network (8 wires, 3 rounds)")
        .x_label("time (phase)").y_label("position / wire").background({250, 250, 252});
    plot.x_limits(-0.5, 2.0 * rounds + 1.5); plot.y_limits(-0.5, W - 0.5);
    plot.save_svg("build/org/odd_even_sort.svg");
    std::cout << "\nwrote odd_even_sort.svg\n";
#+end_src

sorted: 1 2 3 5 7 8 9

The seven-element array sorts in a handful of full rounds. Serially those phases are
just adjacent compare-swaps like bubble sort's, but their /structure/ is the point:
each phase's comparisons are independent, so the same algorithm on parallel hardware
finishes in a number of steps proportional to \(n\), not \(n^2\).

The grey horizontal lines are the eight wires (array positions); each vertical
connector is a compare-exchange. Blue connectors (odd phase) join positions
\((1,2),(3,4),(5,6)\); red connectors (even phase) join \((0,1),(2,3),(4,5),(6,7)\).
Because the connectors within one colour never share a wire, an entire phase happens
in a single parallel step -- the defining feature of a sorting network.
