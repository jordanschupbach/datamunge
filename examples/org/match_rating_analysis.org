#+begin_abstract
Soundex, NYSIIS, and Metaphone each turn *one* name into a code. The *Match Rating
Approach* (MRA), devised at Western Airlines in 1977, is built for a different job:
deciding whether *two* names are the same person. It compresses each name into a short
codex (vowels dropped, doubles removed, first-three-plus-last-three), then scores a
pair by cancelling their common letters and counting what is left -- accepting the
match only if the score clears a threshold that *relaxes as the names get longer*.
This report implements it in =datamunge='s C++ =algorithms::match_rating_comparison=,
verified against the =jellyfish= reference (codex over a 4000-word corpus, verdicts
over hundreds of name pairs).
#+end_abstract

* Codex, then a symmetric cancellation

MRA has two halves. First the *codex* squeezes a name:

1. Delete vowels except a leading one.
2. Remove the second letter of any doubled consonant.
3. If more than six letters remain, keep only the first three and the last three.

So =Catherine= -> =CTHRN=, =Byrne= -> =BYRN=, =Ashcraft= -> =ASHRFT=.

Then the *comparison* rates a pair of codexes:

1. If their lengths differ by 3 or more, refuse to judge (return "not comparable").
2. Set a *minimum rating* from the summed codex lengths: short pairs must match almost
   perfectly (min 5), long pairs are forgiven more (min 2).
3. Cancel letters common to both, scanning once left-to-right and once right-to-left;
   count the leftovers in the longer remainder.
4. The *similarity* is =6 - leftovers=. Declare a match when similarity >= the minimum.

The genius is step 2: a one-letter difference is damning in a 4-letter name but
trivial in a 12-letter one, and the sliding threshold encodes exactly that intuition.

* Algorithm

#+begin_example
MATCH-RATING(a, b):
  c1 <- codex(a);  c2 <- codex(b)
  if |len(c1) - len(c2)| >= 3: return NOT-COMPARABLE
  min_rating <- 5/4/3/2 by the sum len(c1)+len(c2)          # relaxes with length
  cancel letters common to c1 and c2 (left-to-right, then right-to-left)
  similarity <- 6 - (leftover letters in the longer remainder)
  return similarity >= min_rating
#+end_example

* Worked example: matches, near-misses, and the sliding bar

We run a batch of name pairs through the comparator and plot each pair's similarity
against the threshold it must clear.

#+name: mr-run
#+begin_src c++ :eval no
    const std::vector<std::pair<std::string, std::string>> pairs = {
        {"Byrne", "Boern"},   {"Smith", "Smyth"},      {"Catherine", "Kathryn"},
        {"Robert", "Rupert"}, {"Steven", "Stephen"},   {"Karen", "Caren"},
        {"Sean", "Shaun"},    {"Margaret", "Marguerite"}, {"Alice", "Zachary"},
        {"Jackson", "Johnson"}, {"Baker", "Barker"},   {"Nelson", "Wilson"}};

    std::vector<double> mx, ms, tx, tt, nx, ns;
    int                 idx = 0;
    std::cout << "=== Match Rating Approach ===\n";
    for (const auto& [a, b] : pairs) {
        const auto r = match_rating_comparison(a, b);
        std::cout << a << " vs " << b << ": codex " << match_rating_codex(a) << "/" << match_rating_codex(b);
        if (!r.comparable) {
            std::cout << "  -> NOT COMPARABLE (length gap >= 3)\n";
            ++idx;
            continue;
        }
        std::cout << "  similarity " << r.similarity << " vs min " << r.min_rating << "  -> "
                  << (r.match ? "MATCH" : "no match") << "\n";
        tx.push_back(idx);
        tt.push_back(r.min_rating);
        if (r.match) { mx.push_back(idx); ms.push_back(r.similarity); }
        else { nx.push_back(idx); ns.push_back(r.similarity); }
        ++idx;
    }

    auto plot = RPlot::create();
    plot.line(tx, tt, "threshold", RGB{100, 116, 139}, 2.0);
    plot.points(tx, tt, "threshold", RGB{100, 116, 139}, 4.0);
    plot.points(mx, ms, "match", RGB{22, 163, 74}, 8.0);
    plot.points(nx, ns, "no match", RGB{220, 38, 38}, 8.0);
    plot.legend({"minimum rating (threshold)", "similarity: match", "similarity: no match"},
                {{100, 116, 139}, {22, 163, 74}, {220, 38, 38}});
    plot.title("A pair matches when its similarity sits on or above the sliding threshold")
        .x_label("name-pair index (see table above)").y_label("rating (0-6)")
        .background({250, 250, 252});
    plot.save_svg("build/org/match_rating.svg");
    std::cout << "\nwrote match_rating.svg\n";
#+end_src

The spelling variants all clear their bar -- =Byrne=/=Boern=, =Smith=/=Smyth=,
=Catherine=/=Kathryn=, =Steven=/=Stephen=. MRA is deliberately *forgiving*: even loosely
similar surnames like =Baker=/=Barker= and =Nelson=/=Wilson= clear the (low) threshold,
so it favours recall over precision. The genuinely dissimilar =Alice=/=Zachary= is the
one pair that falls short -- similarity 1 against a required 3. Because the threshold
slides down for longer names, =Margaret=/=Marguerite= earns a perfect 6 and is accepted
outright.

Each green point (a match) sits on or above the grey threshold line; each red point (a

names than for short ones -- the sliding bar that makes MRA forgiving without being
indiscriminate.
