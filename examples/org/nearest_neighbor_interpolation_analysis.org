#+begin_abstract
To read a value between samples, most interpolants blend neighbors -- but the simplest one refuses to
blend at all: *nearest-neighbor interpolation* just returns the value of the closest sample. The result is
a piecewise-constant staircase that reproduces the samples exactly, never overshoots, and never invents an
intermediate value -- the right choice for categorical data and the fastest option for magnification. This
report drives =datamunge='s =algorithms::nearest_neighbor_interpolate=, verified against a brute-force
nearest-sample search, and shows the staircase it produces.
#+end_abstract

* The closest sample wins

Given samples \((x_i,y_i)\) with strictly increasing abscissae, nearest-neighbor interpolation returns

\[ f(x)=y_{i^\*},\qquad i^\*=\arg\min_i |x-x_i|. \]

Each query is assigned the value of whichever sample it is closest to, so the interpolant is *constant*
across the region nearer to one sample than any other, jumping to the next value exactly at the midpoint
between consecutive samples. Two properties follow immediately: it is *exact at the nodes*
(\(f(x_i)=y_i\)), and its range is exactly the set of sample values -- it can never overshoot or produce a
value that was not measured. That makes it the correct interpolant for data where averaging is meaningless
(class labels, categories, indexed lookups) and the artifact-free -- if blocky -- choice for enlarging
images or resampling signals when smoothness is not required. A binary search for the bracketing pair
makes each query \(O(\log n)\); the only design decision is the tie-breaking rule at the exact midpoint
(here, the lower index). It is the natural baseline against which smoother interpolants -- linear,
bicubic, Lanczos -- are measured.

* Algorithm

#+begin_example
NEAREST-NEIGHBOR(xs, ys, x):
  if x <= xs.front(): return ys.front()
  if x >= xs.back():  return ys.back()
  binary-search the pair xs[lo-1] < x <= xs[lo]
  return the y of whichever of xs[lo-1], xs[lo] is closer (tie -> lower)
#+end_example

* Worked example: a piecewise-constant staircase

We sample a smooth function coarsely, reconstruct it densely with nearest-neighbor interpolation, and plot
the staircase against the samples.

#+name: nn-run
#+begin_src c++ :eval no
    auto f = [](double x) { return std::sin(x) + 0.3 * x; };
    std::vector<double> xs, ys;
    for (int i = 0; i <= 8; ++i) { const double x = i * 0.8; xs.push_back(x); ys.push_back(f(x)); }

    std::cout << "=== Nearest-neighbor interpolation ===\n";
    std::cout << "value at each node is reproduced exactly:\n";
    for (std::size_t i = 0; i < xs.size(); ++i)
        std::printf("  x=%.1f  nn=%.4f  sample=%.4f\n", xs[i], nearest_neighbor_interpolate(xs, ys, xs[i]), ys[i]);
    std::printf("between nodes: x=1.4 -> %.4f (nearest x=1.6),  x=1.0 -> %.4f (nearest x=0.8)\n",
                nearest_neighbor_interpolate(xs, ys, 1.4), nearest_neighbor_interpolate(xs, ys, 1.0));

    std::vector<double> dx, dy, nx, ny;
    for (double x = 0; x <= 6.4; x += 0.02) { dx.push_back(x); dy.push_back(nearest_neighbor_interpolate(xs, ys, x)); }
    for (std::size_t i = 0; i < xs.size(); ++i) { nx.push_back(xs[i]); ny.push_back(ys[i]); }

    auto plot = RPlot::create();
    plot.line(dx, dy, "nn", RGB{37, 99, 235}, 2.0);
    plot.points(nx, ny, "samples", RGB{220, 40, 40}, 6.0);
    plot.legend({"nearest-neighbor interpolant", "samples"}, {{37, 99, 235}, {220, 40, 40}});
    plot.title("Nearest-neighbor interpolation is a piecewise-constant staircase")
        .x_label("x").y_label("value").background({250, 250, 252});
    plot.save_svg("build/org/nearest_neighbor_interpolation.svg");
    std::cout << "\nwrote nearest_neighbor_interpolation.svg\n";
#+end_src

The blue interpolant is a flat staircase, each tread centered on a red sample and each riser falling
exactly halfway to the next -- no slopes, no curves, no overshoot. That bluntness is precisely its virtue:
where a value must be one of the measured ones (a label, a category) or where speed beats smoothness,
nearest-neighbor interpolation is the honest, artifact-free answer, and the baseline every fancier
interpolant is judged against.
