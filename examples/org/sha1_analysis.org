#+begin_abstract
*SHA-1* extends the Merkle-Damgard design of MD5 to a 160-bit digest and 80 rounds, and
adds the feature that most distinguishes it: a *message schedule* that expands the sixteen
words of each block into eighty by XOR-and-rotate feedback. This report implements SHA-1 in
=datamunge='s =algorithms::sha1= as a literate program. We reproduce the FIPS 180 test
vectors, then visualise how the expanded schedule stirs each input word across many rounds.
We finish with the SHAttered collision and why SHA-1 is now retired from security use.
#+end_abstract

* Expanding sixteen words into eighty

SHA-1 pads exactly like MD5 but with a *big-endian* length, then processes 512-bit blocks
against a 160-bit state \((h_0,\dots,h_4)\). The novelty is the schedule. A block gives
sixteen 32-bit words \(W_0,\dots,W_{15}\); the remaining sixty-four are generated by

\[
  W_t = \text{ROTL}_1\!\left(W_{t-3}\oplus W_{t-8}\oplus W_{t-14}\oplus W_{t-16}\right),
  \qquad 16\le t<80.
\]

This linear-feedback expansion means every original word influences many later rounds,
deepening diffusion. The 80 rounds run in four 20-round phases, each with its own round
function and additive constant \(K\):

\[
  f = (b\wedge c)\vee(\neg b\wedge d)\ \ [0,20),\quad
  b\oplus c\oplus d\ \ [20,40),\quad
  \text{Maj}(b,c,d)\ \ [40,60),\quad
  b\oplus c\oplus d\ \ [60,80).
\]

Each round sets \(\text{temp} = \text{ROTL}_5(a) + f + e + K + W_t\) and rotates the five
state words; the block's contribution is added back at the end.

#+name: sha1-includes
#+begin_src c++ :eval no
#include <datamunge/algorithms/sha1.hpp>
#include <datamunge/plot/plot.hpp>

#include <array>
#include <cstdint>
#include <iostream>
#include <string>
#include <vector>

using namespace datamunge::algorithms;
using namespace datamunge::plot;

static int digest_hamming(const std::array<std::uint8_t, 20>& a,
                          const std::array<std::uint8_t, 20>& b) {
    int d = 0;
    for (int i = 0; i < 20; ++i) {
        std::uint8_t x = a[i] ^ b[i];
        while (x) { d += x & 1; x >>= 1; }
    }
    return d;
}
#+end_src

** Pseudocode

#+begin_example
SHA-1(message):
    h0..h4 = 0x67452301, 0xEFCDAB89, 0x98BADCFE, 0x10325476, 0xC3D2E1F0
    pad message with 0x80, zeros to 56 mod 64, then 64-bit big-endian bit length
    for each 512-bit block:
        W[0..15] = block words (big-endian)
        for t in 16..79:
            W[t] = rotl(W[t-3] ^ W[t-8] ^ W[t-14] ^ W[t-16], 1)
        a,b,c,d,e = h0..h4
        for t in 0..79:
            choose (f, K) by phase (t/20)
            temp = rotl(a,5) + f + e + K + W[t]
            e,d,c,b,a = d, c, rotl(b,30), a, temp
        h0..h4 += a,b,c,d,e
    return h0||h1||h2||h3||h4   # 20 big-endian bytes
#+end_example

* A worked example

We check the three canonical FIPS 180 vectors, then measure avalanche: flip each input
bit of a fixed message and count how many of the 160 output bits change (ideal 80).

#+name: sha1-run
#+begin_src c++ :eval no
    std::cout << "=== FIPS 180 reference digests ===\n";
    std::cout << "sha1(\"\")    = " << sha1_hex("") << "\n";
    std::cout << "sha1(\"abc\") = " << sha1_hex("abc") << "\n";
    std::cout << "sha1(56-char) = "
              << sha1_hex("abcdbcdecdefdefgefghfghighijhijkijkljklmklmnlmnomnopnopq") << "\n";

    const std::string base = "avalanche";
    auto base_digest = sha1(base);
    std::vector<double> changes;
    int total_bits = static_cast<int>(base.size()) * 8;
    for (int bit = 0; bit < total_bits; ++bit) {
        std::string m = base;
        m[bit / 8] ^= static_cast<char>(1u << (bit % 8));
        changes.push_back(digest_hamming(base_digest, sha1(m)));
    }
    double mean = 0;
    for (double c : changes) mean += c;
    mean /= changes.size();
    std::cout << "\n=== Avalanche over " << total_bits << " single-bit input flips ===\n";
    std::cout << "output bits changed: mean " << mean << " of 160 (ideal 80)\n";

    std::vector<double> bins(9, 0.0);  // centred 64,68,...,96
    std::vector<std::string> labels = {"64","68","72","76","80","84","88","92","96"};
    for (double c : changes) {
        int idx = static_cast<int>((c - 62) / 4);
        if (idx < 0) idx = 0; if (idx > 8) idx = 8;
        bins[idx] += 1.0;
    }
    RPlot p = RPlot::barplot(bins, labels, "SHA-1 avalanche: output bits changed per input-bit flip", {16, 122, 87});
    p.abline_v(4.0, {220, 38, 38}, 1.5);  // the ideal-80 column
    p.save_svg("build/org/sha1_avalanche.svg");
    std::cout << "wrote build/org/sha1_avalanche.svg\n";
#+end_src

change diffuses across roughly half the 160-bit digest.

* Uses and cautions

SHA-1 is *retired from security use*. The 2017 SHAttered attack produced two distinct PDFs
with the same SHA-1 digest, and chosen-prefix collisions followed. It remains embedded in
legacy protocols and as content-addressing in older version-control systems (git object
ids), where it acts as a fingerprint rather than an adversarial guarantee -- and even there
migration to stronger hashes is underway. For new work use SHA-256 or SHA-3.

* Complexity

\(O(n)\) time over \(n\) bytes: one 80-round compression per 512-bit block with an
80-word schedule, \(O(1)\) state.
