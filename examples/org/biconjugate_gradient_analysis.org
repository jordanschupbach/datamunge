#+begin_abstract
Conjugate gradient is unbeatable for symmetric positive-definite systems -- but real
problems (convection, circuits, Markov chains) give *non-symmetric* matrices, where
CG breaks down. The *biconjugate gradient* method (BiCG) generalizes CG to any
square matrix by running *two* coupled recurrences: the usual one with \(A\) and a
shadow one with \(A^{\top}\), kept bi-orthogonal. This report implements it in
=datamunge='s C++ =algorithms::biconjugate_gradient=, solves a non-symmetric system,
and plots its residual converging in at most \(n\) steps.
#+end_abstract

* Two coupled sequences

CG relies on \(A\)-conjugacy, which needs symmetry. BiCG instead builds two
sequences of residuals and directions -- \(r_k,p_k\) driven by \(A\) and
\(\tilde r_k,\tilde p_k\) driven by \(A^{\top}\) -- so that the two residual sets are
*bi-orthogonal* (\(\tilde r_i^{\top}r_j=0\) for \(i\ne j\)) and the direction sets
are *bi-conjugate* (\(\tilde p_i^{\top}Ap_j=0\)). The step lengths are
\(\alpha_k=\tilde r_k^{\top}r_k/\tilde p_k^{\top}Ap_k\), and each iteration costs
*two* matrix-vector products, one with \(A\) and one with \(A^{\top}\). In exact
arithmetic BiCG terminates in at most \(n\) steps. Its price relative to CG is the
extra transpose product and the possibility of *breakdown* (a zero inner product);
stabilized variants (BiCGSTAB, GMRES) address that, but BiCG is the clean archetype
of a non-symmetric Krylov solver.

* Algorithm

#+begin_example
BICG(A, b):
  x <- 0 ; r <- b ; r~ <- r ; p <- r ; p~ <- r~ ; rho <- r~.r
  repeat:
      Ap  <- A p ;  A^T p~ <- transpose(A) p~
      alpha <- rho / (p~ . Ap)
      x <- x + alpha p ;  r <- r - alpha Ap ;  r~ <- r~ - alpha A^T p~
      if ||r|| < tol: stop
      rho_new <- r~ . r ;  beta <- rho_new / rho
      p <- r + beta p ;  p~ <- r~ + beta p~ ;  rho <- rho_new
  return x
#+end_example

* Worked example: a non-symmetric system

We build a \(30\times30\) *non-symmetric* diagonally dominant matrix (random
off-diagonals, so \(A\ne A^{\top}\)) with \(b\) all ones, solve it with BiCG, and
record the residual per iteration.

#+name: bi-run
#+begin_src c++ :eval no
    const std::size_t n = 30;
    std::mt19937 rng(5);
    std::uniform_real_distribution<double> u(-2.0, 2.0);
    std::vector<std::vector<double>> A(n, std::vector<double>(n, 0.0));
    for (std::size_t i = 0; i < n; ++i) {
        double off = 0.0;
        for (std::size_t j = 0; j < n; ++j) if (i != j) { A[i][j] = u(rng); off += std::fabs(A[i][j]); }
        A[i][i] = off + 1.0; // diagonally dominant, but not symmetric
    }
    const std::vector<double> b(n, 1.0);

    const auto sol = biconjugate_gradient(A, b);
    std::cout << "=== Biconjugate gradient on a 30x30 non-symmetric system ===\n";
    std::cout << "is A symmetric? " << std::boolalpha << (A[0][1] == A[1][0]) << "\n";
    std::cout << "converged in " << sol.iterations << " iterations (<= n = " << n << "), residual "
              << sol.residual << "\n\n";

    auto matvec  = [&](const std::vector<double>& v) { std::vector<double> y(n, 0.0); for (std::size_t i = 0; i < n; ++i) for (std::size_t j = 0; j < n; ++j) y[i] += A[i][j] * v[j]; return y; };
    auto matvecT = [&](const std::vector<double>& v) { std::vector<double> y(n, 0.0); for (std::size_t i = 0; i < n; ++i) for (std::size_t j = 0; j < n; ++j) y[j] += A[i][j] * v[i]; return y; };
    auto dot     = [&](const std::vector<double>& p, const std::vector<double>& q) { double s = 0; for (std::size_t i = 0; i < n; ++i) s += p[i] * q[i]; return s; };

    std::vector<double> it, logres;
    {
        std::vector<double> x(n, 0.0), r = b, rt = b, p = b, pt = b; double rho = dot(rt, r);
        for (int k = 1; k <= 60; ++k) {
            auto Ap = matvec(p); auto Atp = matvecT(pt);
            double alpha = rho / dot(pt, Ap);
            for (std::size_t i = 0; i < n; ++i) { x[i] += alpha * p[i]; r[i] -= alpha * Ap[i]; rt[i] -= alpha * Atp[i]; }
            it.push_back(k); logres.push_back(std::log10(std::max(std::sqrt(dot(r, r)), 1e-16)));
            if (std::sqrt(dot(r, r)) < 1e-12) break;
            double rn = dot(rt, r), beta = rn / rho;
            for (std::size_t i = 0; i < n; ++i) { p[i] = r[i] + beta * p[i]; pt[i] = rt[i] + beta * pt[i]; }
            rho = rn;
        }
    }

    auto plot = RPlot::create();
    plot.line(it, logres, "residual", RGB{37, 99, 235}, 2.0);
    plot.points(it, logres, "residual", RGB{37, 99, 235}, 6.0);
    plot.title("BiCG residual on a non-symmetric system: converges within n steps")
        .x_label("iteration").y_label("log10 ||A x - b||").background({250, 250, 252});
    plot.save_svg("build/org/biconjugate_gradient.svg");
    std::cout << "wrote biconjugate_gradient.svg\n";
#+end_src

The matrix is genuinely non-symmetric, so conjugate gradient would not apply -- but
BiCG drives the residual to machine zero within \(n\) iterations by pairing each
step with a shadow \(A^{\top}\) recurrence. That ability to handle non-symmetric
systems is exactly what BiCG (and its robust descendants) buys over plain CG.

The residual falls steadily and then drops off a cliff to the machine floor -- the
finite-termination behaviour of a Krylov method, here achieved on a matrix CG
cannot touch. Each of those iterations spent two matrix-vector products (one by
\(A\), one by \(A^{\top}\)), the modest overhead that removes the symmetry
requirement.
