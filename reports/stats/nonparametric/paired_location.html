    Sign and Wilcoxon signed-rank tests for paired measurements

    Abstract

    Simulate measurements before and after an intervention on the same subjects. An improvement increases the recorded response. Both tests use the pairing and ask whether changes tend to be positive. The plot marks equality.

    Simulate, test and plot

    MethodStatisticp-value
    Paired exact sign test20.00.01785
    Wilcoxon signed rank test (exact conditional sign flips)289.00.02525

    Positive changes: 20 of 28 nonzero differences.

    Interpretation

    The sign test uses only the direction of each nonzero difference and has an exact binomial reference. The signed-rank test also uses the ranks of their absolute sizes. Its location interpretation assumes symmetric differences, and this sample uses the exact conditional sign-flip reference. The paired API switches to the tie- and continuity-corrected normal approximation above 100 nonzero differences.
