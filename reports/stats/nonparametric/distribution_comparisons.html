    Kolmogorov–Smirnov tests and empirical CDFs

    Abstract

    Simulate two sensor populations centered at zero, with different spreads. The two-sample KS test compares their full distributions. One-sample calls compare the first sample to a prespecified reference Normal distribution through both the convenience API and the general CDF API.

    Simulate, test and plot

    ComparisonDp-value
    Two independent samples0.2440.0001121
    First sample vs N(0, 1)0.0330.994
    Same null via CDF callback0.0330.994

    Interpretation

    KS measures the largest vertical separation between CDFs. The samples are generated with the same population location, so a distributional difference can reflect spread alone. One-sample KS calibration requires fixing the reference distribution independently of the data. The p-values here use asymptotic references.
