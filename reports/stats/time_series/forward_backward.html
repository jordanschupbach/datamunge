    Forward–backward: evidence, filtering and smoothed state marginals

    Abstract

    A hidden Markov model assigns a probability to an observation sequence by summing its hidden state paths. Forward–backward reuses partial sums to compute that evidence and every time-specific state marginal. A two-time example makes the sum and the influence of future evidence visible. The original fourteen-symbol illustrative stream retains its likelihood, smoothed probabilities and Viterbi decode. Actual scaled tables and work counts then distinguish filtering, smoothing and joint-path decoding, while impossible sequences and tiny probabilities delimit the numerical contract.

    Four hidden paths explain two observations

    Use two hidden states0 and1, each initially equally likely. Staying has probability 0.8 and switching0.2. State0 emits symbol0 with probability0.9 and symbol1 with probability0.1; state1 reverses those probabilities. Observe symbols0,1. For each possible state path q_0,q_1, multiply its initial, emission, transition and emission probabilities. The four joint masses are0.036,0.081,0.001 and0.036, which sum to evidence0.154.     Reuse prefix and suffix sums

    A discrete model has initial probabilities pi_i, transitions A_ij from state i to j, and emissions B_i,k. Conditional on the current state, the next state follows A; conditional on each state, its observation follows B. For fixed model parameters, write alpha_t(i)=P(o_0..o_t,q_t=i) and beta_t(i)=P(o_(t+1)..o_(T−1) given q_t=i). Grouping the joint path sum by its boundary state gives

    \[\alpha_0(i)=\pi_i B_{i,o_0},\qquad \alpha_{t+1}(j)=B_{j,o_{t+1}}\sum_i\alpha_t(i)A_{ij},\]
    \[\beta_{T-1}(i)=1,\qquad \beta_t(i)=\sum_j A_{ij}B_{j,o_{t+1}}\beta_{t+1}(j),\qquad \gamma_t(i)=\frac{\alpha_t(i)\beta_t(i)}{\sum_j\alpha_t(j)\beta_t(j)}.\]

    The likelihood is the sum of the last unscaled forward row. Filtering conditions on the observed prefix; smoothing conditions on the whole sequence. The tiny example therefore changes its first-time belief when the later symbol is revealed, while its last filtered and smoothed marginals agree up to rounding.

    Rabiner's [A tutorial on hidden Markov models and selected applications in speech recognition](https://www.cs.ubc.ca/~murphyk/Software/HMM/rabiner.pdf), Proceedings of the IEEE77(2),257–286(1989), [doi:10.1109/5.18626](https://doi.org/10.1109/5.18626), develops the path sum, forward/backward recursions and marginal-state criterion in SectionIII. SectionV.A explains scaling and log evidence. The notation here uses zero-based time and state IDs.

    The library's precise scaling convention

    Before normalizing forward row t, let z_t be its sum and c_t=1/z_t. The scaled forward row a_t has sum approximately one and is the filtering distribution. It satisfies a_t=(product of c_0 through c_t) times the unscaled alpha_t. The native backward table b uses terminal b_(T−1)=c_(T−1) and multiplies its recurrence by c_t. Thus b_t=(product of c_t through c_(T−1)) times the unscaled beta_t. Consequently, in exact arithmetic for positive evidence,

    \[\sum_i a_t(i)b_t(i)=c_t,\qquad \gamma_t(i)=\frac{a_t(i)b_t(i)}{\sum_j a_t(j)b_t(j)},\qquad \log P(O)=-\sum_{t=0}^{T-1}\log c_t.\]

    The backward rows are not probability distributions and can contain values larger than one. The first table checks the product sum against c_t rather than assuming unit normalization. Equivalent backward scaling conventions exist; mixing their terminal values and recurrence factors would change the computation.

    A marginal probability describes uncertainty conditional on the chosen model and parameters. It does not establish empirical calibration or account for parameter uncertainty. Thresholding these marginals happens to agree with Viterbi in the original example; that is not a general identity between the two objectives.

    Marginal modes can fail to form an admissible path

    Smoothing returns one distribution per time. Choosing the most probable state independently at each time maximizes the expected number of correctly labelled positions, because that expected count is the sum of the selected marginals. It need not maximize whole-path probability or respect a positive-probability transition at every step. Viterbi optimizes a joint path score instead.

    For a concrete positive-evidence control, take initial probabilities0.4,0.3,0.3. State0 goes to2; states1 and2 go to1; each allowed transition has probability one. Every state emits the single observed symbol with probability one, so the two-time evidence is one. The first marginal mode is0 and the second is1, but0→1 is forbidden. The most likely joint path is0→2 with mass0.4. The program queries both path masses through the same native joint-probability API.

    Scaling helps long products but has explicit numeric limits

    For one state with transition probability one and two equiprobable symbols, T repetitions of symbol0 have probability2^(−T). Every forward marginal is one, every reciprocal scale is two and every backward entry under this convention is two. The native log-likelihood remains finite when converting it back to an ordinary double probability underflows to zero. The table separates those two operations.

    Impossible evidence is a mathematical zero: no positive-weight state path explains the sequence, so its log-likelihood is negative infinity and conditioning on it has no posterior distribution. The returned zero gamma rows are placeholders for an undefined posterior. They must not be read as certain absence of every state. The old implementation incorrectly retained a finite prefix log score in this case; the canonical function now reports the impossible sequence correctly.

    A different case has positive support but an actual predictive sum rounds to zero. A Boolean support probe distinguishes that numeric failure from impossibility and throws an underflow error. Nonfinite reciprocal scales, accumulators or updates throw overflow errors. Smaller individual terms may still round away, so these checks do not establish arbitrary precision or accuracy for all rare states. Scaling does not promise to work unchanged for sequences of any length: table capacity, memory, summation error and representable intermediate values still matter. The widened enumerator also checks its positive prefix products for underflow; it is a small-model reference rather than an unlimited-precision oracle.

    Actual work, admission and ownership

    With N states, M symbols and T positive observations, the two recursions each visit (T−1)*N² transition terms. A forward term has one multiplication before its accumulation; a backward term has two. Initialization, scaling and gamma formation add O(TN). Full model validation adds O(N²+NM), including when T=0, and observation validation adds O(T). Total time is O(N²+NM+T+TN²); owned arrays use O(TN+T). The ordinary result already stores actual alpha, beta, gamma and scale tables, so no replay or redundant full-history interface is needed.

    All shapes are checked before probability values. Initial probabilities, every transition row and every emission row must have finite entries in[0,1] summing to one within absolute1e−12 in widened arithmetic. There must be N transition rows of length N and N equal, nonempty emission rows. Parameters are never silently normalized. Observations and supplied state-path IDs are zero based and validated in full before indexing. The entirely empty model with empty observations has likelihood one, log-likelihood zero and empty inference tables. Invalid models are still rejected for empty observations.

    For N,T>0 the work API admits the whole result using C=4T+3TN entry records: three row records and one scale value per time, plus three N-scalar rows. The bound is zero if either dimension is zero. These are entries, not bytes or peak RAM; container objects and exceptional support scratch are additional. The default cap is one million entries; zero disables only the optional cap and retains all representability checks. The historical two-argument function has no optional cap. Both paths share the executing kernel, and every returned table owns its storage. Full validation happens before admission, allocation or empty shortcuts. Failures return no partial result and leave caller parameters and observations untouched.

    Enumeration has a separate default cap of one million paths, with zero disabling only that cap. Checked integer NT and T*NT bounds remain; there is no floating pow-to-integer conversion. Its time is O(T*N^T) after model validation, with O(TN+T) output and O(T) path scratch. Empty observations enumerate one empty path of mass one. A strict best-weight comparison keeps the first enumerated tie; that tie policy need not match Viterbi's predecessor policy.

    The fixed illustrative models require no external dataset. All figures are native C++ outputs saved locally, and the complete programs above are their editable sources.
