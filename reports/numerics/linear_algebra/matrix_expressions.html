    Matrix expressions and least squares

    Choose a language tab for each example. Code and its results stay together. Run each tab independently. Python uses the local package in build/venv/pydatamunge-run; R uses build/r/library. Build these once with just build-python and just build-r, and rebuild after binding changes.

    Linear algebra

    Given a model \(\boldsymbol{y} = \boldsymbol{X} \boldsymbol{\beta} + \boldsymbol{\epsilon}\), we want to solve for \(\beta\) given our data \(y\) and our design matrix \(\boldsymbol{X}\). The best \(\beta\) is one that minimizes the squared errors: \(\hat{\boldsymbol{\beta}} = \text{argmin}_{\beta} ||(\boldsymbol{y} - \hat{\boldsymbol{y}})||_2\) where fitted values are \(\hat{\boldsymbol{y}} = \boldsymbol{X}\hat{\boldsymbol{\beta}}\).
