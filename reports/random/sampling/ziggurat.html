    Ziggurat Sampling: Equal-Area Proposals and Gaussian Measurement Replicates

    Abstract

    The Ziggurat method makes most normal draws with a table lookup, a multiply and a comparison. We derive its equal-area proposal rectangles, the wedge acceptance test and exponential-tail rejection step. Actual path counts separate fast proposals from successful returns, and Monte Carlo checks cover both supported table sizes. The application uses dm::datasets::eight_schools() directly: we perturb each reported estimate by its standard error, then compare simulated positive fractions with closed-form normal probabilities. These are conditional measurement replicates; the sampler does not supply a hierarchical inference model.

    The data: eight estimates with different uncertainties

    The eight-schools frame has eight rows and three columns: a school label, an estimated coaching effect in test-score points, and its standard error. It is small enough to inspect in full. Standard errors differ considerably, so a single common noise scale would discard information.

    The method: a proposal envelope with equal areas

    Symmetry lets us derive the algorithm on the positive half-line using the unnormalised normal kernel \(f(x)=e^{-x^2/2}\). Normalisation cancels in rejection ratios. Choose decreasing boundaries \(x_1=r>x_2>\cdots>x_N=0\). Layer zero combines the rectangle under height \(f(r)\) from zero to \(r\), with the remaining tail. Its area is

    \[V=rf(r)+\int_r^\infty f(t)\,dt =rf(r)+\sqrt{\frac{\pi}{2}}\operatorname{erfc}\!\left(\frac{r}{\sqrt2}\right).\]

    Represent this base proposal by an artificial width \(x_0=V/f(r)>r\). Every other proposal is a rectangle of width \(x_i\) between heights \(f(x_i)\) and \(f(x_{i+1})\). Equal area requires

    \[x_i\left[f(x_{i+1})-f(x_i)\right]=V,\qquad x_{i+1}=\sqrt{-2\log\!\left(f(x_i)+\frac{V}{x_i}\right)}.\]

    The last rectangle closes at the peak: \(x_{N-1}[1-f(x_{N-1})]=V\). Together with the tail-area equation, this determines \(r\) for a chosen \(N\). The implementation stores established constants for 128 and 256 layers; other layer counts are rejected, since reusing those constants would no longer construct an equal-area cover.

    Why almost every draw takes the fast path

    Choose \(I\) uniformly from \(0,\ldots,N-1\), independently draw \(U\) uniformly from \((-1,1)\), and set \(X=Ux_I\). If \(|U|<x_{I+1}/x_I\), the point is in a region known to lie under the curve, so it can be accepted without evaluating an exponential. The per-proposal probability of this shortcut is

    \[p_{\rm fast}=\frac1N\sum_{i=0}^{N-1}\frac{x_{i+1}}{x_i},\qquad p_{\rm accept}=\frac{\sqrt{\pi/2}}{NV}.\]

    These probabilities use proposals as the denominator. The fraction of returned samples that took the fast path is instead \(p_{\rm fast}/p_{\rm accept}\). Rejected proposals restart the outer loop, so confusing the two denominators overstates or understates the shortcut rate.

    If \(I>0\) and the shortcut fails, sample a height uniformly between the two strip boundaries and accept only if it lies below \(f(X)\). Dividing the height comparison by \(f(X)\) gives the implementation's test

    \[a_1+W(a_0-a_1)<1,\quad a_0=e^{-(x_I^2-X^2)/2},\quad a_1=e^{-(x_{I+1}^2-X^2)/2},\quad W\sim U(0,1).\]

    This samples uniformly under the curve within the strip. Equal proposal areas make uniform layer selection correct. Repeating after rejection leaves exactly the target normal density. Construction and storage cost \(O(N)\); each sample takes expected \(O(1)\) time, with no finite worst-case rejection count. This implementation uses separate engine draws for the coordinate and index, following Doornik's remedy for shared-bit selection dependencies; it does not claim a universal speed advantage.

    The base layer and exponential tail

    A base proposal inside \(r\) is accepted by the shortcut. The remaining base mass selects the normal tail. Set \(X=r+E\), propose \(E\sim\operatorname{Exp}(r)\), and note

    \[f(r+e)=f(r)e^{-re-e^2/2}.\]

    Relative to the exponential proposal, the remaining acceptance factor is \(e^{-e^2/2}\). If \(Y\sim\operatorname{Exp}(1)\), accepting when \(2Y\ge E^2\) has exactly that probability. Restore the original sign. The code forms exponential draws with -log1p(-u) for \(u\in[0,1)\), avoiding the undefined endpoint in -log(u) when a finite-precision uniform source returns zero.

    Applying it to the schools

    We condition on each reported effect \(y_j\) as a hypothetical mean and use its reported standard error \(s_j\) as the scale of a new measurement. Under this plug-in Gaussian model,

    \[Y_j^*=y_j+s_j Z,\qquad \mathbb E[Y_j^*]=y_j,\qquad \operatorname{sd}(Y_j^*)=s_j,\qquad \Pr(Y_j^*>0)=\Phi(y_j/s_j).\]

    This provides a direct oracle for a useful simulation. It does not mean that \(\Phi(y_j/s_j)\) is the probability a fixed unknown effect is positive; that interpretation requires a specified inferential model. The library preserves the original dataset columns and adds simulated means, standard deviations and positive fractions.

    mc_positive_se measures simulation error only. Increasing the number of draws by four halves this error, but it does not reduce any school's reported standard error. More simulation cannot create more observations.

    Conclusion

    The equal-area construction explains uniform layer selection, and the width ratios explain the cheap acceptance path. Explicit counters check both the common shortcut and the rare tail branch. Gaussian measurement replicates give exact distributional oracles on a real dataset, while the separate Monte Carlo standard errors show what simulation accuracy means. A sampler test can reveal implementation mistakes; passing a few moment, tail and KS checks does not certify all possible serial or high-dimensional properties of a random stream.
