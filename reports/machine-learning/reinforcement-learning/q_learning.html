    Q-learning: actual behavior draws, targets and finite policy evaluation

    Abstract

    An actual environment transition supplies the reward and next state; the native update bootstraps from the greedy next Q value even when behavior explores. The producer now records its real RNG branch, callback transition and scalar before/target/after values. The original 4x4 grid,500 episodes, seed 42 and 20-episode return smoothing remain. A deterministic corridor first exposes the mechanism; the grid then shows a finite training trajectory and a separate actual greedy-policy rollout.

    Mechanism and mathematical scope

    \[Q(s,a)\gets Q(s,a)+\alpha\{r+\gamma\max_b Q(s\prime,b)-Q(s,a)\};\qquad\text{terminal bootstrap}=0.\]

    API and interpretation

    A constant step size, constant exploration and a finite seed/run do not establish the asymptotic Q-learning convergence assumptions. Training returns belong to the exploring behavior policy; the separate fixed greedy rollout is labelled as evaluation. The-6 line is an undiscounted shortest-path reference for this deterministic grid, while Q values use discount. Smoothing is descriptive and supplies no uncertainty interval. Callback side effects cannot be rolled back; geometry, parameters and actual callback states/rewards are checked before their respective uses. Zero-step episodes reset and are truncated rather than falsely reported terminal.

    Reusable producers, fixtures and histories live in the canonical C++ library. Captured records own their values and do not come from a separate report replay. Selected counters and record/scalar policies are specified at their API boundaries; they are not peak-byte or wall-time budgets. Synthetic structural inputs are controlled fixtures for these mechanisms.
