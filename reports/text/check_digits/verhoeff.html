    Verhoeff: actual D5 transitions and error detection

    Abstract

    A decimal identifier can carry one check digit to detect common transcription errors. Verhoeff uses a noncommutative group accumulator and position-dependent permutations to catch single substitutions and unequal adjacent swaps.

    The method

    Read digits from right to left. Permute each digit by a position table p, then update group state c←d[c][p_i(digit)] in the dihedral group D5. Payload generation uses permutation offset1 and appends the inverse of the final state; validation uses offset0 and accepts residue0. The extra appended digit occupies position0, shifting every payload permutation by one. This proves generation and validation agree.     Interpretation and limits

    ASCII decimal bytes are the complete input grammar. Leading zeros are preserved, malformed payload generation throws, and malformed validation returns false. Empty payload generates digit0 but an empty full identifier is invalid. Error detection provides no authentication or adversarial integrity guarantee.
