    Fermat Primality: Witnesses, Base Populations and Actual Rounds

    Abstract

    Decide whether an unsigned integer can be ruled out as prime without first finding all of its factors. Fermat's little theorem supplies a cheap compositeness certificate: one failed modular congruence. Passing bases provide no converse certificate. We begin with four exact base tests for 15, retain the original prime/composite/Carmichael examples and their five coprime-liar fractions, then inspect actual seeded rounds. Native APIs replace the report-local powering and census loops. The report distinguishes conditional coprime fractions, the sampler's full support and hypothetical independent draws, and checks full-width arithmetic and capture limits.

    A failure proves compositeness; a pass does not prove primality

    For a prime p and 1≤a<p, multiplication by a permutes the nonzero residues. Multiplying all residues before and after the permutation and cancelling (p−1)! gives a(p−1)=1 modulo p. Thus a(n−1)≠1 modulo n proves n composite. A pass is only consistency with that necessary condition. For 15, base two gives 2^14 modulo 15 equal to four: a witness with gcd one. Base ten also fails, and its gcd five directly gives a factor. Bases four and eleven pass despite 15=3 times five being composite.

    The native single-base API computes the exact modular power through mod_pow and the actual gcd. The diagram and table use its returned records. The explicit-base range is [1,n); the seeded sampler later uses [2,n−2].

    Carmichael numbers fool coprime tests, not every sampled base

    A passing residue must be coprime: if a prime divisor of n divides a, it divides a^(n−1), so that residue cannot be one. Carmichael numbers pass for every coprime base, while their noncoprime bases still fail. For 561, the factors 3,11,17 are distinct primes and each p−1 divides 560. Applying the prime congruence in each factor and combining residues explains why every coprime base passes modulo 561. The report checks these factors and divisibilities, then computes the actual two populations.

    The native sampler draws from [2,n−2], represented as the half-open interval [2,n−1). For odd n this removes the always-passing endpoints one and n−1. For 561, there are 318 passes among 558 possible sampled bases, whereas all 318 coprime bases in that support pass. Those are different fractions. Native exact censuses below make the distinction visible.

    The seeded sequence uses SplitMix64 words reduced modulo n−3. A fixed seed is deterministic; modulo reduction generally introduces bias, and this generator does not establish independent uniform draws. Therefore neither the following population fractions nor powers of them are a rigorous error bound for the actual seeded API. They describe specified populations and, later, an explicitly hypothetical iid sampling model.

    Inspect actual seeded rounds and early termination

    The ordinary bool API, work API and trace API share one kernel. The positive-round base stream is unchanged: each actual round draws a base, computes gcd and the exact canonical modular power, and stops on failure. Adding the gcd makes the diagnostic factor visible without replacing the congruence with a different primality test. Small/even filters draw no bases. Zero and one are not prime, but are not composite either.

    A conditional error model, not a posterior probability

    For a fixed odd non-Carmichael composite, the coprime passing residues form a proper subgroup of the unit group. Its size is at most half the unit-group size. Removing always-passing endpoints does not increase that fraction. With independent uniform draws from a specified population with passing fraction f, all k rounds pass with probability fk. Carmichael numbers have f=1 under conditioning on coprimality, so that conditioned model has no decreasing bound. On the unconditioned sampler support, noncoprime witnesses make f smaller. These statements concern a fixed composite under an ideal draw model; fk is not the probability that an input is composite given a pass. The native deterministic stream has no such iid guarantee. See Shoup, Theorem10.1 and the following discussion.

    The plotted curves use actual census numerators/denominators but then apply this hypothetical iid model. They are neither observed frequencies from the native generator nor a security claim. Native same-base Miller–Rabin checks are included as a stronger comparison; they do not change the Fermat algorithm being studied.

    Optional trace history stores C=completed_rounds whole records. Default quota1000000 and the requested round count are independent; zero quota argument disables only capture quota. A record is admitted before its draw/gcd/power, and failures return no partial trace. Metadata, vector capacity, allocators and runtime storage are excluded from C: it is not peak memory. Work calls use constant auxiliary storage and no history quota. Copies own their rows independently.

    A round uses O(log(n)) modular products for this fixed-width representation, plus a gcd. R actual rounds take O(R log(n)) word work and a trace keeps O(R) records. An exhaustive B-base census takes O(B log(n)) word work, constant storage, and a default one-million-base work cap checked before any test. Arbitrary-precision bit costs differ. These routines expose branches and values and are educational numerical APIs, not constant-time cryptographic primitives.

    API contracts and verification

    The bool entry retains its compiled signature, defaults and original positive round stream. It now rejects nonpositive round counts before filtering; the old vacuous odd-input true for zero rounds was not evidence. The work and trace variants expose actual filters, round counts and residues. The single-base API requires n≥2 and 1≤base<n. The census requires a valid half-open interval 1≤first≤last≤n; [n,n) is a valid empty interval. It returns integer counts and leaves empty-denominator fractions undefined.

    Development checks preserve 19200 frozen positive-round decisions, including all original inputs, full-width values and seeded cases, and all 13 lines of original program stdout. Strict sanitizer tests compare small powers against repeated multiplication, split exact censuses into disjoint ranges, check golden seeded prefixes, actual early stops, capture/work caps and ownership. An optional independent Python pow/gcd oracle checks 42710 base results; it is not a report runtime dependency. The public Doxygen examples are compiled and their output checked separately.

    Keith Conrad, [Fermat's Test](https://kconrad.math.uconn.edu/blurbs/ugradnumthy/fermattest.pdf), sections1–3, explains congruence witnesses and why shared divisors can expose compositeness. The native single-base records show both tests explicitly.

    Victor Shoup, [A Computational Introduction to Number Theory and Algebra, version2](https://shoup.net/ntb/ntb-v2.pdf), 2008, section10.2, Theorem10.1 and the Carmichael discussion on pp.307–308, supplies the subgroup setting for the conditional counting argument. Native modulo-reduced seeded draws are distinguished from the book's ideal random-sampling model.
