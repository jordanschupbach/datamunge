    DPLL: Actual Propagation, Restored Backtracking and Finite Random-SAT Experiments

    Abstract

    Given a Boolean formula in conjunctive normal form, we want either a true/false assignment satisfying every clause or a decision that no such assignment exists. Enumerating all assignments can require exponentially many cases. DPLL combines forced unit assignments, satisfiability-preserving pure choices and true/false branching to reduce that search. We begin with a two-variable implication and a complete three-node refutation, then retain the original satisfiable formula, contradiction and random 25-variable experiment. Actual owned event traces expose propagation reasons and restored parent states. Measured search work and sampling intervals qualify the finite sweep; it is not a proof of an asymptotic 3-SAT threshold. The canonical core validates all CNF literals and uses an explicit heap stack rather than recursion by decision depth.

    Begin with two forced assignments

    Let C₀=(x₁) and C₁=(¬x₁∨x₂). A satisfying model must set x₁=true because C₀ is a unit clause. C₁ then has only x₂ unassigned, forcing x₂=true. No split is needed. The total returned model is [0,+1,+1]; index zero is deliberately unused. Event snapshots use zero for unassigned variables, while the final SAT model uses only +1 or −1 at variable positions.

    The program records actual states from the same kernel as the original solver. Clause indices in unit/conflict events refer to the original input. All other events use the clause-count sentinel, displayed as a dash in this table.

    The search rules and their proof obligations

    A CNF formula is an AND of clauses, each an OR of signed literals. Literal +v means xᵥ, and −v means ¬xᵥ. If a clause contains one unassigned literal and every other literal is false, satisfying the formula requires that literal to be true. Repeating this rule yields unit propagation.

    A pure literal appears in only one polarity among currently unsatisfied clauses. Choosing that polarity can satisfy those clauses without breaking a clause already satisfied by another assigned variable. It therefore preserves existence of a model. Unlike a unit assignment, a pure choice is not necessarily logically forced. The example below will exhibit another model with a different pure-variable value.

    When neither rule applies, split on an unassigned variable v:

    \[\operatorname{SAT}(F\mid A)= \operatorname{SAT}(F\mid A,v=\mathrm{true})\ \lor\ \operatorname{SAT}(F\mid A,v=\mathrm{false}).\]

    The two branches exhaust all possible values of v. A clause with every literal false proves the current branch inconsistent. Both branches failing proves their parent inconsistent. Each new assignment fixes a previously unassigned variable, so decision depth is at most n. A partial state already satisfying every clause can be completed by setting all remaining don't-cares true, as the original API does. Together these facts establish soundness, completeness and termination. Worst-case search remains exponential; this implementation does not include clause learning, watched literals, restarts or a timeout.

    A complete two-variable UNSAT tree

    Take all four binary clauses: C₀=(x₁∨x₂), C₁=(x₁∨¬x₂), C₂=(¬x₁∨x₂), C₃=(¬x₁∨¬x₂). There is no initial unit or pure literal. The solver splits x₁ true first. Clause C₂ forces x₂=true, falsifying C₃. It returns to the unchanged parent assignment [0,0,0], then tries x₁=false. Clause C₀ forces x₂=true, falsifying C₁. Both branches fail, so the root is exhausted. The root itself has no falsified clause under its empty partial assignment; its justification is the completed split.

    The actual event sequence makes these distinct failure reasons explicit. The tree has one decision, two attempted branches, three entered nodes, two conflicting leaves and two restored-parent backtracks.

    Retain the original model and distinguish a pure choice from a forced value

    The original formula is (x₁∨x₂)∧(¬x₁∨x₃)∧(¬x₂∨¬x₃)∧(x₁∨¬x₃). Its deterministic returned model remains x₁=true,x₂=false,x₃=true. The original direct contradiction (x₁)∧(¬x₁) remains UNSAT. The total-model checker below validates the original clauses rather than trusting the solver's verdict alone.

    For a separate tiny pure-literal example, use G=(x₁∨x₂)∧(¬x₁∨x₃). Variable x₂ initially appears only positively, so the solver chooses x₂=true. The remaining clause permits the pure choice x₁=false, after which x₃ is a don't-care filled true. But x₁=true,x₂=false,x₃=true also satisfies G. Thus the initial pure choice preserves satisfiability without being entailed by G.

    Repeat the original finite random 3-SAT sweep and measure search work

    Retain n=25 variables, seed 4242, 120 trials per ratio and all 21 requested ratios from 2 to 7 in quarter steps. The canonical generator preserves the original mt19937 stream: draw an id by rng()%n, reject repeated variables within a clause before drawing its sign, and allow repeated clauses. This has a tiny modulo bias, so it is a reproducible legacy sampling scheme rather than an exactly uniform mathematical sampler. The stream is continuous across trials and ratios; it is not reset.

    The original code uses m=floor(requested_ratio·25). Some requested quarter ratios therefore differ from the actual integer-clause ratio: for example,2.25 gives56 clauses and actual m/n=2.24. The table and plots below use those exact counts. Every sampled SAT model is checked. The workload panel records median entered nodes using the same solver and instances, which makes its difficulty claim directly testable.

    Wilson 95% intervals come from the existing proportion-test API and summarize binomial sampling uncertainty under an independent-trial interpretation. They are not confidence limits for an asymptotic threshold. The historical4.26 number is not drawn as a proven boundary: a single n=25 sample cannot establish a limiting threshold, convergence with n, or a universal solver-hardness location. Measured medians also depend on this first-variable, true-first, unit/pure implementation.

    Validate inputs, bound capture and expose a deliberately unreduced family

    The canonical solver validates every literal before any verdict or dense allocation, even after an empty clause or inside a tautology. The bound must be nonnegative; literals must be nonzero signed ids within 1…n, with INT_MIN rejected before absolute-value arithmetic. Empty CNF is true, including n=0; an empty clause is false. Returned SAT models have n+1 entries and fill don't-cares true; UNSAT returns an empty model.

    Original clause/literal order, duplicate occurrences and tautologies are retained to preserve deterministic behavior. A raw duplicate can delay unit detection because it has more than one unassigned occurrence. Presence bits avoid polarity-counter overflow. Search still finds an exact result. Its explicit frame stack avoids native recursion depth, but dense assignments cost n+1 entries per live frame and can require O(n²) live model storage along a deep branch.

    The trace's default cap is one million logical entries. Input costs 1+number_of_clauses+number_of_literals. Each event costs 1+(n+1) for its record and complete partial assignment. The cap is checked before the affected copy, and input/root capacity before allocating the initial dense state. Zero disables only this optional cap. It is not a byte, time or total working-memory quota. An exceeded cap throws without a partial SAT/UNSAT verdict. The two-unit example has 22 entries, so 22 passes and 21 fails.

    To make the effect of preserving raw clauses visible, construct n clauses (xᵢ∨¬xᵢ). They are all tautologies, but this implementation does not remove them. It enters a true-first chain until all variables are assigned: n+1 nodes, depth n, no unit/pure assignments or conflicts. At depth k, the status and unit scans each inspect2n−k literals; the pure scan inspects4n−3k. Including the final satisfied scan gives

    \[\text{literal visits}=\frac{11n^2+7n}{2},\qquad \text{clause visits}=3n^2+n.\]

    The following family verifies those exact counts. Linear node count alone would obscure quadratic repeated scan work; neither plot is an elapsed-time benchmark.

    Verification and limits

    Native tests compare all 512 canonical two-variable clause sets and all 19,683 ordered three-clause formulas over the 27 canonical three-variable clauses against exhaustive model enumeration. They also check 800 seeded raw formulas with duplicates, tautologies, empty clauses and unused variables. Actual event certificates validate entered child states, unit reasons, pure polarity, falsified clauses, unchanged restored parents, both-failed exhaustion and the final checked total model. Counter identities include nodes=branches+1 and, on a complete UNSAT tree, nodes=2·decisions+1 and conflicting_leaves=decisions+1.

    Additional tests cover invalid ids/counts, model shape and totality, exact/one-short/disabled capture limits, validation priority, owned copies, the unchanged generator's draw order/state and a 1024-decision iterative chain. Ordinary, work-only and traced results agree. Separate unchanged- source probes reproduce an invalid-literal bounds failure and signed num_vars+1 overflow in the old implementation; negative counts were also accepted rather than rejected.

    This is a transparent deterministic DPLL solver for propositional CNF. A SAT result supplies a directly checkable model. UNSAT follows from the completed search; the event sequence is not a standardized DRAT/LRAT certificate. The random sweep measures this solver on this small sampling scheme and cannot establish a general threshold or solver-independent hardness claim.
