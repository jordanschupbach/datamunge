    TD(0): actual sampled bootstrap updates and honest episode outcomes

    Abstract

    Temporal-difference prediction evaluates a fixed policy using actual one-step environment transitions. The original five-interior-state random walk retains its callback RNG, zero initialization and episode snapshots; real update and episode histories replace repeated report-side learning loops.

    Mechanism and mathematical scope

    At observed(s,r,next,terminal), let successor=0 if terminal, otherwise the current V(next). Compute target=r+gamma*successor, error=target-V(s), then V(s)<-V(s)+alpha*error. Read the successor before updating, including self transitions. This evaluates the supplied policy and does not improve it. In the fair five-state walk with right-exit reward1 and gamma1, the mathematical reference is V(k)=k/6 for k1..5 and zero terminal continuation. The original code initializes values to0, not0.5. Constant alpha=.1 gives a noisy tracking estimate; finite-sample errors need not decrease monotonically and exact asymptotic convergence is not promised. Classical prediction theorems require suitable task, visitation and step-size assumptions.

    API and interpretation

    Complete policy/actions/callback geometry and numeric learning controls are checked. Actual reset and successor IDs are validated even for terminal steps; nonfinite rewards/arithmetic fail. Zero episodes invokes no callback, while zero step cap still resets and records truncation. RLParameters.seed does not seed environment callbacks, and epsilon is ignored because the supplied policy is followed. Fresh random-walk factories own independent engines; copies of one returned environment share its captured engine. Histories retain actual transitions and initial/post-episode values without replaying callbacks.

    Reusable producers, fixtures and histories live in the canonical C++ library. Captured records own their values and do not come from a separate report replay. Selected counters and record/scalar policies are specified at their API boundaries; they are not peak-byte or wall-time budgets. Synthetic structural inputs are controlled fixtures for these mechanisms.
