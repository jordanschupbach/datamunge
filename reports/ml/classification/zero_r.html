    ZeroR: What a Majority-Class Baseline Measures

    Abstract

    ZeroR predicts the most frequent training label for every input. We derive its optimality among constant decisions under unweighted zero-one loss, including why randomising a feature-free decision cannot improve that objective. On dm::datasets::titanic(), the rule attains respectable ordinary accuracy while missing every survivor. Training/test separation, class-level recalls and balanced accuracy expose this difference. Repeated splits illustrate sampling variation without changing the decision rule. The result is a useful reference for a specified metric, rather than a universal test of whether a model has learned anything.

    The data: Titanic survival is imbalanced

    The built-in Titanic frame has 891 passengers and 12 columns. Survived is an integer-coded nominal label: 0 for a passenger who died and 1 for a survivor. ZeroR uses only this response, so missing ages, cabins or other predictors do not remove training or evaluation rows. Numeric storage does not make the response a regression target in this report.

    The method: empirical risk for a constant decision

    For labels \(y_1,\ldots,y_n\), let \(n_k\) count class \(k\). A constant prediction \(a\) makes \(n-n_a\) mistakes. Its empirical zero-one risk is therefore

    \[\widehat R(a)=\frac1n\sum_{i=1}^n\mathbf1\{y_i\ne a\} =1-\frac{n_a}{n},\qquad \widehat a\in\arg\max_k n_k.\]

    The library chooses the smallest integer class in a tie. Its model stores the selected class, its count and the training size. accuracy() is the training fraction \(n_{\widehat a}/n\), not an estimate automatically valid for another dataset.

    Could a feature-free random decision improve training accuracy? Let \(q_k\) be its probability of predicting class \(k\), independently of the outcome. Since the \(q_k\) sum to one,

    \[\mathbb E[\widehat{\operatorname{accuracy}}] =\sum_k q_k\frac{n_k}{n} \le\max_k\frac{n_k}{n}.\]

    A deterministic majority decision attains the bound. This proves optimality within the stated class of feature-free decisions and loss; it does not prove that features contain no information, or that majority prediction is optimal under another metric or cost.

    The current implementation uses a sorted map for counts, so training costs \(O(n\log K)\) time and \(O(K)\) counting storage for \(K\) classes. The DataFrame adapter also holds an \(O(n)\) temporary label vector. A prediction costs \(O(1)\) and does not inspect features. Empty training input produces an empty low-level model; evaluation helpers reject that model and empty evaluation data instead of reporting misleading scores.

    Fit on training data, then freeze the decision

    The split is a reproducible, unstratified random 70/30 partition. This keeps the numeric class column as supplied by the dataset. The model is fitted on train only; the separate evaluation helpers do not recompute the majority from test. A change in test prevalence can therefore change accuracy even though the prediction stays fixed.

    Why balanced accuracy reveals the blind spot

    For evaluation class \(k\), recall is the fraction of its true members predicted as \(k\). A constant rule has recall one for its chosen class and zero for every other observed class. If that chosen class is present among \(K\) evaluation classes, balanced accuracy is

    \[\operatorname{BA}=\frac1K\sum_{k=1}^{K}\operatorname{recall}_k =\frac1K.\]

    It is zero when the predicted class is absent. The helper averages only over classes actually observed in evaluation; absent classes are not invented as zero-recall members of the denominator. For this two-class test set, the theoretical value is exactly 0.5, regardless of imbalance.

    If detecting survivors were the priority, a classifier could improve survivor recall while losing some ordinary accuracy. That tradeoff would need evaluation under the chosen objective. The statement that any model below ZeroR accuracy has learned nothing would conceal it.

    Sampling variation across splits

    For a fixed constant class, test accuracy equals its test-set prevalence. If a test subset of size \(m\) is drawn without replacement from \(N\) records with class proportion \(p\), the number of correct predictions is hypergeometric and

    \[\mathbb E[\widehat A]=p,\qquad \operatorname{Var}(\widehat A)=\frac{p(1-p)}m\frac{N-m}{N-1}.\]

    This formula treats the decision as fixed. If a split changes the training majority, selecting a new class changes the calculation. The following runs record the chosen class explicitly. They reuse the same finite passenger dataset; their spread is a split-sensitivity diagnostic, not extra independent evidence about another population.

    Different losses give different feature-free baselines

    With binary prevalence \(\pi=\Pr(Y=1)\), a false-positive cost \(c_{01}\) and false-negative cost \(c_{10}\), the risks of constant predictions zero and one are respectively \(\pi c_{10}\) and \((1-\pi)c_{01}\). Predicting one is better when

    \[\pi>\frac{c_{01}}{c_{01}+c_{10}}.\]

    This need not be the majority threshold of one half. Likewise, a constant probability scored by squared probability error is optimised by the class frequency, rather than a hard zero/one decision. ZeroR's hard classification rule should not stand in for every probability or decision-cost baseline.

    Conclusion

    The class counts explain the accuracy a constant rule can obtain. A training-only fit gives an honest fixed decision for held-out evaluation; per-class recall shows the minority it never detects. Balanced accuracy checks the exact constant-rule value of one half, while repeated splits show the effect of changing prevalence. The baseline is useful when its loss, fitting data and evaluation metric are stated explicitly.
