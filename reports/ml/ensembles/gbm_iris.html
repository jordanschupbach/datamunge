    Gradient Boosting: Residual Trees, Scores and Validation

    The concept diagram below is drawn by dm::graphics::Diagram. Its editable C++ source is the complete block below; regeneration uses the same datamunge toolchain as the numerical examples. Exports consume the saved local SVG.

    The method

    Scores turn measurements into class probabilities

    For \(K\) observed training classes, let \(y_{ik}\) be one when row i has class \(k\), and zero otherwise. Fit one score \(F_k(x)\) per class. Softmax and the mean negative log likelihood are

    \[p_{ik}=\frac{\exp F_k(x_i)}{\sum_{j=1}^K\exp F_j(x_i)},\qquad L(F)=\frac1n\sum_{i=1}^n\left[\log\sum_{k=1}^K\exp F_k(x_i)-F_{y_i}(x_i)\right].\]

    The constant starting scores are \(F_{0,k}=\log(n_k/n)\), so the first probabilities equal the empirical class proportions. These minimize constant-model log loss: imposing \(\sum_k p_k=1\) on \(-\sum_k n_k\log p_k\) gives \(p_k=n_k/n\). Adding the same constant to every score leaves softmax unchanged; scores themselves are not probabilities. initial_scores() exposes the log priors and raw_scores(data,0) repeats them by row.

    For one observation, differentiation gives \(\partial\ell_i/\partial F_{ik}=p_{ik}-y_{ik}\). Thus the negative gradient is the pseudo-residual \(r_{ik}=y_{ik}-p_{ik}\). The global factor \(1/n\) changes the step-size convention but not the residual-fitting direction. At each round \(m\), compute all \(K\) targets using the same pre-round probabilities, fit a least-squares tree to each class target, and add its shrunken prediction to that class score:

    \[r_{imk}=y_{ik}-p_{i,m-1,k},\quad h_{mk}\approx\arg\min_h\sum_{i\in S_m}(r_{imk}-h(x_i))^2,\quad F_{mk}=F_{m-1,k}+\eta h_{mk}.\]

    GBMClassifier implements this direct first-order residual-tree variant. CART greedily chooses squared-error-reducing splits and each terminal node predicts its residual mean. It uses \(K\) trees even for two classes. There is no Newton leaf correction, class-count correction, score recentering or line search. Consequently a numeric comparison with scikit-learn's GradientBoostingClassifier would compare different algorithms: its classification terminal updates and binary score representation differ. Friedman's 2001 paper supplies the gradient-boosting framework; the equations above specify the particular variant used here.

    Each round samples one shared set \(S_m\) without replacement for all class trees. subsample=1 uses all retained training rows. Otherwise its size is max(1,round(subsample*n)); SplitMix64 and seed determine the sequence. Round count, depth, minimum leaf size, learning rate and sampling all affect flexibility. The constructor always fits its declared round budget; it performs no early stopping.

    When does a residual-tree step decrease loss?

    With full-sample leaf means, each residual is projected onto the constants on its chosen leaves. Within a leaf \(A\), \(\sum_{i\in A}r_i h_i=|A|\bar r_A^2=\sum_{i\in A}h_i^2\). Summing over leaves and classes yields the exact-arithmetic identity below. The Hessian of one-row log-sum-exp is \(\operatorname{diag}(p)-pp^T\), whose absolute row sums are \(2p_k(1-p_k)\le1/2\). Its spectral norm is at most 1/2. Taylor's quadratic upper bound then gives

    \[\langle r,h\rangle=\|h\|_2^2,\qquad L(F+\eta h)\le L(F)-\frac{\eta}{n}\langle r,h\rangle+ \frac{\eta^2}{4n}\|h\|_2^2 =L(F)-\frac{\eta(1-\eta/4)}n\|h\|_2^2.\]

    Thus \(0<\eta<4\) guarantees descent for a nonzero full-sample update in exact arithmetic; implementation tolerances and rounding affect tiny changes. This is a sufficient bound, not an optimal rate or a generalization claim. With subsampling, the leaf identity holds on \(S_m\) and need not hold on all training rows. A large eta can overshoot even with all rows. step_diagnostics() reports both inner product and squared norm over all training rows; interpret its projection-based quadratic_bound as a guarantee only for full samples.

    Training log loss and accuracy measure different things. Once every winning class is correct, probability concentration can continue improving log loss while accuracy stays flat. On new data, excessive concentration can be costly. Evaluation uses stable log-sum-exp without clipping the true-class probability at a floor, even if softmax underflows to zero. The historically named training_deviance() stores mean log loss, without a factor of two. The multiclass Brier score is \(n^{-1}\sum_i\sum_k(p_{ik}-y_{ik})^2\), without dividing by \(K\); smaller is better for both loss scores.

    Contracts, cost and importance

    The formula machinery fixes predictor encoding on fitting rows and omits rows with null formula values. kept_row_indices() maps compact training rows back to original indices. Predictions retain original query order, using an empty label/probability vector for a row with null predictors and a NaN raw-score row. An empty prediction frame returns empty predictions; a nonempty frame with no complete rows is rejected. Evaluation reports input, retained and skipped counts, and rejects response classes absent from training. Retained transformed predictors, learning rate and subsample must be finite. A query row uses the frozen model whether supplied alone or in a batch. Depth and tree counts are positive; minimum leaf size is positive and minimum split size is at least two.

    For \(M\) rounds, \(K\) classes, \(p\) encoded predictors, \(n\) rows and depth limit \(D\), this implementation's exhaustive CART splitter has a conservative \(O(MKpn^2(D+1))\) fitting bound: it scans all candidate thresholds and repartitions rows. It is not a histogram-based booster. Staged evaluation applies each tree once per row, \(O(MKn(D+1))\), rather than independently refitting every prefix. Stored trees require up to \(O(MK\min(n,2^D))\) nodes plus \(O(MKn)\) stored training targets/predictions, retained design data and sampling indices. Diagnostics traverse fitted trees without refitting.

    For each fitted class tree, normalize its featurewise squared-error gains by that tree's total gain, or use a zero vector when it has no split. feature_importance() averages these vectors equally across all \(MK\) trees. Its sum can be less than one when some trees are constant. importance_table() additionally gives relative_share, normalized across features to sum to one when any gain exists. Neither quantity pools raw gains across trees or measures causality, uncertainty, permutation importance or held-out usefulness.

    Simple examples

    Four rows: perfect classification is not probability one

    Take x=(0,1,2,3), with labels (a,a,b,b). Equal priors give scores log(.5), probabilities .5 and class-a residuals (.5,.5,−.5,−.5). A depth-one tree splits at x=1.5 and predicts those residual means exactly; class b is the negative. At eta=.5 the first row has scores (log(.5)+.25,log(.5)−.25). Therefore p(a)=1/(1+exp(−.5)) and mean loss is log(1+exp(−.5)). Classification is already perfect after this single round, while the predicted true-class probability is only about .622459.

    Six rows and three classes: compute targets simultaneously

    Take x=(0,1,2,3,4,5) with labels (a,a,b,b,c,c). Priors are one third. Every row's true-class residual is 2/3 and its other two residuals are −1/3. Class a can be isolated by the first stump and class c by the last. For class \(b\), two symmetric stump splits tie; the implementation keeps the first ascending threshold, 1.5. Its left prediction is −1/3 and its right prediction is (2/3+2/3−1/3−1/3)/4=1/6.

    At \(x=2\) after one \(\eta=.5\) step, score increments are \((-1/6,1/12,-1/6)\). Their softmax is approximately (.304504,.390991,.304504). The class-b residual used in that same round is still 2/3, computed before any score update. Separate class trees need not sum to zero at each x; softmax handles the common-score offset automatically.

    Checking the theory

    Full-sample projection, sampling and an oversized step

    Keep six x values but change labels to (a,a,b,b,a,b). The balanced prior still gives log loss log(2). The first full-sample class-a stump predicts .5 on the first two rows and −.25 on the remaining four; class b is its negative. Thus the squared update norm summed over both classes is 1.5, equal to its residual inner product. With eta=.5 the upper bound is log(2)−.5*(1−.5/4)*1.5/6, approximately .583772.

    Compare that small full-sample step with sampling half the rows and with eta=20 on all rows. The loss plot includes round zero. The diagnostic scatter places full-training inner product on x and squared norm on y, both divided by n. Full-sample leaf means lie on the identity; sampled leaf means need not. The oversized full-sample first step raises loss to about 1.666697, demonstrating why arbitrary positive rates do not inherit the descent guarantee. None of these training curves estimates held-out error.

    Iris: validation before a final test

    Declare the split and candidate settings

    dm::datasets::iris() contains 150 flowers, four numeric measurements in centimetres, and three species with 50 rows each. Use just Petal.Length and Petal.Width, so decision regions can be drawn without fixing omitted coordinates. Before fitting, zero-based rows with index modulo five equal to zero form the 30-row test set; those equal to one form the 30-row validation set; the remaining 90 rows fit the candidate models. This gives 30/10/10 fitting/validation/test flowers per species. There are no missing values here.

    Fix depth two, minimum leaf size two and full-sample fitting. Search eta in {.03,.1,.3} and every prefix from zero through 120. gbm_validation_search() fits one 120-round model per rate, scores its fixed prefixes on the validation rows and selects the lowest validation mean log loss. Exact ties prefer the first supplied rate and earliest prefix. The 363-row candidate table includes the prior-only option for every rate. Training loss and accuracy accompany the validation metrics for interpretation; they do not select settings. This is a single declared validation split, not cross-validation or an uncertainty estimate. A grid endpoint winner means the best setting within this grid.

    Conclusion

    The tiny examples expose the score-to-probability calculation, simultaneous multiclass residuals and the distinction between classification accuracy and probability loss. Full-sample leaf means satisfy a projection identity that yields a sufficient descent bound for \(0<\eta<4\); sampling and an oversized step require separate reasoning. Training loss reduction alone does not certify generalization.

    Iris uses a declared 90/30/30 split for fitting, validation and testing, selects only by validation log loss, and evaluates a single refitted setting on the reserved flowers. The selected eta=.3 and 106-round model gets 29 of 30 reserved flowers correct; its mean test log loss .21296239 still records the confidently mistaken flower. These selection, final-loss and confusion results describe this split and grid. A larger dataset, repeated outer evaluation and calibration assessment would answer questions that these thirty test rows and training-derived gain shares cannot.
