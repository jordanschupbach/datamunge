    Regularised Tree Boosting for Iris: Fit, Select, Then Test

    Abstract

    We derive the regularised leaf weights and split gains used by datamunge's XGBoost-style multiclass classifier. The implementation uses one class tree per round and a diagonal softmax curvature approximation; it is not a binding to the upstream XGBoost system. Fisher's iris measurements are split into training, validation and test partitions. Fixed-model staged evaluation separates decreasing training loss from validation behaviour, and a validation-only search selects the L2 penalty and round count. A model refitted on all development data is then evaluated once on the reserved test partition using accuracy, mean log loss, Brier score and class counts.

    The data and the evaluation design

    dm::datasets::iris() has 150 flowers, four measurements in centimetres, and three string-valued species labels with 50 observations each. Petal measurements show clear setosa separation and an overlap between the other two species. The classifier uses all four measurements, without scaling; a two-dimensional scatter is descriptive, not the full decision space.

Validation chooses among these settings; the final test data do not participate in that choice. No claim about relative performance against classifiers fitted with different defaults is made here.

    Deriving a regularised boosting round

    For class scores \(F_{ik}\), probabilities and the mean negative log likelihood are

    \[p_{ik}=\frac{e^{F_{ik}}}{\sum_j e^{F_{ij}}},\qquad \mathcal L=-\frac1n\sum_i\log p_{i,y_i}.\]

    The initial scores are log training-class proportions. Subtracting each row's largest score before exponentiating leaves probabilities unchanged and stabilises the computation. Differentiating the per-row loss gives

    \[g_{ik}=p_{ik}-\mathbf1\{y_i=k\},\qquad \frac{\partial^2\ell_i}{\partial F_{ik}\partial F_{ij}} =p_{ik}(\mathbf1\{k=j\}-p_{ij}).\]

    The local implementation retains only the diagonal \(h_{ik}=\max(p_{ik}(1-p_{ik}),10^{-6})\). It computes all class gradients from the scores at the start of a round, fits one tree per class, then adds the learning-rate-scaled contributions. Omitting off-diagonal terms makes this a diagonal Newton heuristic; it is not an exact joint Newton step. XGBoost 3.1.0's upstream multiclass objective instead uses the bound \(2p(1-p)\) with its own floor. Identical option names therefore do not establish numerical equivalence with that package.

    Leaf weights and split gains

    For a leaf, sum gradients and Hessians over its assigned training rows: \(G=\sum_i g_i\), \(H=\sum_i h_i\). With L2 penalty \(\lambda\) and L1 penalty \(\alpha\), its quadratic surrogate is

    \[Q(w)=Gw+\frac12(H+\lambda)w^2+\alpha|w|,\qquad w^*=-\frac{\operatorname{sign}(G)\max(|G|-\alpha,0)}{H+\lambda}.\]

    For positive or negative \(w\), set the corresponding derivative to zero. At \(w=0\), the subgradient condition is \(|G|\le\alpha\), which yields exactly zero. This derives the soft-threshold rule. Increasing lambda shrinks a leaf update for fixed \(G,H\), but later gradients and chosen splits also change, so an entire fitted model need not vary monotonically with lambda.

    Put \(S(G,H)=\operatorname{softthresh}(G,\alpha)^2/(H+\lambda)\). The best surrogate contribution is \(-S/2\). Subtracting the children's best objective from the parent's and charging a split penalty gives

    \[\operatorname{Gain}=\frac12\{S(G_L,H_L)+S(G_R,H_R)-S(G,H)\}-\gamma.\]

    The local tree enumerates exact midpoint thresholds and requires child row-count and summed-Hessian limits. A gain must improve the current best by more than \(10^{-12}\). Gain importance sums accepted regularised split gains, then normalises across features; it is training-derived attribution, not a causal effect or a probability that a predictor matters. A smaller learning rate and more rounds can compensate for shrinkage, so a fixed round budget is part of any regularisation comparison.

    The source's training_deviance() is mean negative log likelihood, not twice that quantity. Evaluation uses the same definition and a probability floor of \(10^{-15}\) for the logarithm. Brier score is \(n^{-1}\sum_i\sum_k(p_{ik}-\mathbf1\{y_i=k\})^2\), without dividing by the number of classes. Balanced three-class priors consequently give mean log loss \(\log3\), Brier score \(2/3\), and tie-broken accuracy \(1/3\). Probabilities are fitted softmax outputs, not verified calibrated posteriors.

    Selecting lambda and the stopping round on validation only

    For each predeclared lambda, the library picks the lowest validation mean log loss among stages 1 through 100. It then compares those five candidates. Exact ties retain the first supplied lambda and the earliest stage. The round-zero prior is a useful reference but excluded from this search. Validation accuracy can be identical while probability-sensitive log loss differs; accuracy alone would conceal that distinction.

The selected validation loss is optimistically biased by the search itself. It is not substituted for the final test score.

    Refit on development data, then evaluate the final test partition

    The selected settings are refitted from scratch on all 120 development flowers, combining the training and validation partitions. This can change every fitted tree; the selected validation loss does not describe the refitted model directly. The 30 reserved flowers are evaluated after that refit. The feature-importance plot uses only the development-fitted trees.

The refitted model classifies all 120 development flowers correctly, illustrating why training accuracy is not a replacement for the held-out result. Softmax probabilities have not been separately calibrated.

    Computational and modelling limits

    The local implementation enumerates midpoint candidates and rescans their rows. A conservative bound is \(O(MK(p+1)n^2(D+1))\) training work for \(M\) rounds, \(K\) classes, \(p\) resolved predictors and depth limit \(D\). Staged evaluation traverses each stored tree once per usable evaluation row, with \(O(nMK(D+1))\) traversal and \(O(nMK)\) score work. It avoids refitting \(M\) prefix models. This small exact-search implementation is appropriate for understanding the method; it does not implement upstream XGBoost's full scalable, sparse or distributed training system.

    Null response or predictor rows are omitted and counted consistently; unseen response classes and non-finite transformed predictors are errors. Categorical predictor levels must have appeared during training. Formula basis construction belongs to the training design, which is reused for validation and prediction. The procedure therefore separates fitting and scoring, but the user remains responsible for a sampling design relevant to the intended population and for keeping partitions disjoint.

    Conclusion

    The regularised leaf optimum and split gain follow from a quadratic loss surrogate; the diagonal multiclass approximation and curvature floor are explicit implementation choices. Staged evaluation shows training loss continuing to improve after validation loss has stopped improving. Validation selects a penalty and stopping round, then a fresh development fit is scored on reserved flowers. This sequence supports a measured predictive claim while keeping model selection, training fit and final evaluation distinct.
