    Snake: Pixel Observations, Reversal and Starvation

    Abstract

    Native C++ simulations expose explicit actions, seeded state transitions and owning observations. The complete editable source protocol retains its policy comparisons and checks. There is no hidden learning loop or external simulator process.

    Follow one actual transition

    A reversal request keeps the current direction

    The reset head points right with its tail to the left. Requesting left would reverse into the body, so the source ignores it and advances one cell right. Observation planes describe the resulting head, body and food.

    Complete source experiment

    The source seeds, episode counts, controls and checks are preserved. Every rollout and policy loop is visible here, using canonical C++ environment objects. The seeded greedy replay is available as both a video and a filmstrip.

    Inspect the captured source episode

    Head, body and food colours are rendered from the actual simulated state. Each cell is enlarged by the source factor, and the first frame is the reset state.

    A fixed-action diagnostic trajectory

    This additional trace starts from seed1 and repeatedly applies the displayed constant action until the first done flag or200 steps. It shows state evolution and rewards; it is not a learned-policy result. The complete original policy comparison above remains the experiment.

    4 transitions; cumulative reward -1.000000.

    Interpretation

    The source checks report reproducibility and the stated control comparisons. Distinguish the displayed fixed-action diagnostics from the original policies, MDP terminality from time-limit truncation, expected reward from sampled return, and a legal game move from an arbitrary action index. All policies and episode loops remain editable here.
