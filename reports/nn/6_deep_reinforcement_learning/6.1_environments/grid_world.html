    Grid Worlds: Transition Models, Walls and Cliff Rewards

    Abstract

    Native C++ simulations expose explicit actions, seeded state transitions and owning observations. The complete editable source protocol retains its policy comparisons and checks. There is no hidden learning loop or external simulator process.

    Follow one actual transition

    A cliff penalty returns to the start

    From the bottom-left start, moving right hits the cliff: reward-100, state36 again, and no terminal flag. Moving up then pays-1 and reaches state24. The cliff is a costly transition, not an absorbing loss state.

    Complete source experiment

    The source seeds, episode counts, controls and checks are preserved. Every rollout and policy loop is visible here, using canonical C++ environment objects. The native CAD renderer records the four deterministic policy replays at the end of the report.

    Inspect the actual board state

    The native diagram reads the current object directly. Board games display the five-move worked result; the grid displays its original start, walls and goal.

    Interpretation

    The source checks report reproducibility and the stated control comparisons. Distinguish the displayed fixed-action diagnostics from the original policies, MDP terminality from time-limit truncation, expected reward from sampled return, and a legal game move from an arbitrary action index. All policies and episode loops remain editable here.

    The four policy replays

    The first replay follows the manual policy down the left edge of the deterministic grid and along the bottom to the goal. On the cliff board, the risky policy follows the row immediately above the cliff. The safe policy uses the top row and takes four more moves. In the final replay the agent first steps onto the cliff, loses 100 reward, and returns to the start. The episode continues with the safe policy.
