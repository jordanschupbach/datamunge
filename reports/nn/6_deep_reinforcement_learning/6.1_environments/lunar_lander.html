    Simplified Lunar Landing: Source Physics and an Explicit Heuristic

    Abstract

    Native reusable physics/frame/data/model components support the full editable source protocol. Original seeds, control loops, objective/optimizer steps and actual default budgets are retained. Optional emulator execution and native physical task definitions are labelled explicitly.

    Follow the actual data path

    State8 -> discrete thrusters -> Euler / potential reward.

    A hand-checkable calculation

    Without thrust, gravity changes vertical speed by-1.6*.02=-.032 per source step. Semi-implicit position uses this updated speed. The source simplified point mass has no Box2D contacts.

    Complete preserved source protocol

    The code retains the source seeds, actual default caps and original optional full settings. Every controller, rollout, replay, objective, gradient/clipping/optimizer step and update schedule remains editable. Read-only capture hooks add no random draws or evaluations. In the local ALE-free build, the original synthetic preprocessing/Nature-update checks execute and emulator rollouts are explicitly skipped. Native InvertedPendulum/Hopper use datamunge physics; their smoke results establish execution and finite updates, without convergence or external-simulator parity. Timing rows are machine-dependent and excluded from source stdout equality checks.
