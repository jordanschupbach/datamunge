    Soft actor-critic on articulated vsim tasks

    Soft actor-critic on articulated vsim tasks

    Soft actor-critic fits a stochastic actor, two value critics, and an entropy temperature from a replay buffer. The target uses the lower of the two target critics and includes the next action’s entropy bonus. Only physical termination masks the bootstrap. The target critics follow exponential moving averages of the fitted critics.

    The actor samples Gaussian actions and applies tanh to keep them in the unit box. The simulator receives actions scaled to its actuator limits. Evaluation uses the deterministic tanh of the Gaussian mean. The rollout footage uses this mean policy, filmed on the highest-return of three seeded trials.

    The pendulum protocol uses 30,000 transitions. The longer Hopper protocol uses 300,000. Both use 256-unit layers, 256-sample replay batches, and 1,000 warmup actions. The C++ code accepts DM_SAC_TASK to select one task and DM_SAC_STEPS to set a smaller experimental budget. Datamunge initializes its own model parameters.

    Run with the vsim SDK

    Use the vsim SDK and original scenes setup. The same compiler flags enable the task adapter and link the offscreen renderer. The run publishes one chart and one video per task.

    Recorded 1,100-transition check

    Each run completed 100 optimizer updates after warmup. The mean return fell from 26.90 to 16.10 for InvertedPendulum and rose from 11.46 to 68.44 for Hopper. This run checks the training, evaluation, and video paths. At this budget the pendulum still falls quickly.

    Full pendulum schedule

    After 30,000 transitions and 29,000 updates, the ten-episode mean return increased from 26.90 to 1,000. The selected policy video covers 750 steps at 25 fps. The selected seed reaches the full 1,000-step horizon when evaluated without the recording cap.

    Full Hopper schedule

    After 300,000 transitions and 299,000 updates, the ten-episode mean return increased from 11.46 to 261.81. The best of the three recording seeds returned 261.47. The clip captures every second simulation step and the final terminal frame at 62 fps.
