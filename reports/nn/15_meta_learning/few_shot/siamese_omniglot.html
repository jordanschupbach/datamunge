    Siamese one-shot classification on Omniglot

    Siamese one-shot classification on Omniglot

    Train a shared convolutional encoder to verify whether two drawings depict the same character. Each pair in a balanced batch comes from one alphabet, so a negative example comes from a different character in the same writing system. The learned head scores the absolute difference between the two embeddings.

    In each held-out episode, compare one query to five support drawings from different characters in an unseen alphabet. The model picks the highest verification logit. The baseline picks the smallest squared pixel distance. The plot compares accuracy over the same 128 episodes.

    Prepare the archives with python3 scripts/prepare_omniglot.py in the TensorFlow examples checkout. Set DATAMUNGE_OMNIGLOT_DIR to its prepared dataset directory for another checkout location.
