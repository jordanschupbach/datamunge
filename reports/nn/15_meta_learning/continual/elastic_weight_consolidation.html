    Continual learning with EWC, synaptic intelligence and replay

    Continual learning with EWC, synaptic intelligence and replay

    Two logistic classification tasks use different coefficients on the same inputs. Training on task B alone can change the parameters needed for task A. Every method starts task B from the same fitted checkpoint.

    Elastic weight consolidation penalizes displacement from that checkpoint using the diagonal empirical Fisher on task A. Synaptic intelligence uses each parameter's accumulated gradient work divided by its squared net displacement plus a damping constant. Replay keeps a uniform reservoir of task-A rows and mixes draws from it into task-B minibatches. A matched task-B-only minibatch run isolates the effect of replay.

    MethodTask ATask B
    after_a198/256108/256
    sequential125/256200/256
    ewc187/256147/256
    si183/256156/256
    fresh_only150/256184/256
    replay179/256153/256

    Each retention method improves task-A accuracy over its corresponding task-B-only control. The same comparison shows lower task-B accuracy, so the experiment exposes the trade-off at these penalty and replay settings.
