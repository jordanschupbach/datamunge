    Proxy-NCA and Proxy Anchor metric learning

    Proxy-NCA and Proxy Anchor metric learning

    A trainable proxy represents each class. The model learns those proxies jointly with a shared embedding tower. Proxy-NCA compares a sample's squared distance to its own proxy with a soft aggregate over the negative proxies. The negative-only denominator allows negative values for this objective.

    Proxy Anchor treats each proxy as the anchor and aggregates positive and negative cosine similarities with separate log-sum-exp penalties. The positive penalty averages over classes present in the batch. The negative penalty includes all proxies. Both methods predict the held-out class by the highest cosine similarity.
