    Graph isomorphism network

    Graph isomorphism network

    Can a model distinguish a path from a star when every real node has the same input feature and the node IDs are shuffled? A graph isomorphism network sums each node's neighbors, adds its own feature with a learned coefficient, and applies an MLP. A sum preserves differences in how many neighbors contribute. This example concatenates the sum readouts from two layers to classify the full graph.

    Each graph has six to nine real nodes. Zero input features and zero incident edges identify padding, and a mask clears padded rows after each MLP. The model fits on 128 graphs, then predicts on 64 graphs sampled from a separate seed.
