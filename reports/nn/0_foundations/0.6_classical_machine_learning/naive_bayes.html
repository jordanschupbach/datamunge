    Naive Bayes: Counts, Absences and Gaussian Features

    Abstract

    A classifier can combine many weak feature observations through class-conditional likelihoods. We inspect smoothed multinomial word probabilities and show how Bernoulli likelihoods also count absent words. A separate Gaussian fixture verifies population variances and a constant-feature floor. All model state is fitted by explicit tensor Adam loops from the supplied training tensors.

    The method

    Naive Bayes uses log score log pi_c + sum_j log p(x_j|c), then softmax-normalises scores. For multinomial count features with additive smoothing alpha and vocabulary width D,

    \[\theta_{cj}=\frac{\sum_{i:y_i=c}x_{ij}+\alpha}{\sum_j\sum_{i:y_i=c}x_{ij}+\alpha D},\quad s_c^{\rm Bern}=\log\pi_c+\sum_j[x_j\log\theta_{cj}+(1-x_j)\log(1-\theta_{cj})].\]

    Multinomial scores omit the query's class-independent factorial coefficient, which does not change posteriors. An empty count document therefore reduces to the class prior. An all-zero Bernoulli document still contributes absence probabilities. Gaussian features use per-class population variance with an absolute positive floor. Every class must occur in training; callers supply valid nonnegative counts or binary indicators. The absolute variance constraint is specified in feature-squared units. The visible loops optimise the supervised generative joint likelihood, not discriminative cross-entropy of the class posterior. Initial and conditional logits remain learnable leaves. Multinomial pseudocounts add alpha times the sum of log conditional word probabilities; Bernoulli adds alpha times log p plus log(1-p) for every feature. Their stationary points are exactly the displayed smoothed count formulas. The empirical prior maximises the label likelihood. Gaussian Adam fits means and log variances; after each update, an explicit projection enforces variance at least .001. Fitting is iterative, not a constructor side effect. Each full-batch iteration and prediction costs O(ND) and O(QKD), respectively.

    A constant feature exercises the variance floor. Fit on 600 rows, then compare held-out scores with the sum of independent Gaussian log densities.

    Held-out Gaussian accuracy 100.00%; direct log-score error 3.55e-15.

    Conclusion

    The visible tensor Adam fits recover the smoothed count solutions and constrained Gaussian moments on the fixtures. Posterior normalisation does not prove conditional independence or calibration; those remain model assumptions and evaluation questions.
