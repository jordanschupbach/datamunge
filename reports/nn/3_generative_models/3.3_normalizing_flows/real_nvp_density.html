    RealNVP: Per-Point Volume Change and Exact-Form Inversion

    Abstract

    An invertible density model must assign normalized probabilities to observations and generate new observations from a simple base distribution. Affine couplings make both operations tractable while allowing local volume change. This native C++ study checks one hand-set coupling before fitting the original four-stage bounded RealNVP to procedural banana pools. The complete program retains all 48 Adam writes, both actual Jacobians, per-point forward and inverse-path log determinants, and all 1,024 latent-only samples. The fixed-final test NLL is 2.879116774 nats per two-coordinate row, better than the fitting-only full Gaussian's 2.994631823, while analytic truth scores 2.796480843. Exact source reproduction checks this compact experiment; it is not the full image model or a state-of-the-art density benchmark.

    Allow local volume change with triangular affine couplings

    [Dinh, Sohl-Dickstein and Bengio, Density estimation using Real NVP (2016)](https://arxiv.org/abs/1605.08803) uses invertible affine couplings with tractable likelihoods. Split coordinates into a,b and preserve a:

    \[y_A=a,\quad y_B=b\exp(s(a))+t(a),\qquad J=\begin{pmatrix}1&0\\b\exp(s)s'(a)+t'(a)&\exp(s)\end{pmatrix}.\]

    Thus log|det J|s(a). Invert with a=y_A and b=(y_B−t(a))exp(−s(a)); the inverse logdet is −s(a), evaluated on that inverse path's conditioning coordinate. Reversing several stages requires recomputing each conditioner on its current inverse input, not reusing values from an unrelated forward pass. The compact source uses four alternating 1->16 tanh->2 conditioners, with **s.8 tanh(raw_scale)** and t the second head. This bounded CPU adaptation omits the paper's image multiscale architecture and batch normalization.

    A final global positive diagonal scale gives z=exp(log_scale)×h. Accumulate four per-row coupling logdets in order, then add sum(log_scale):

    \[\log p_X(x)=-\log(2\pi)-\tfrac12\|z\|^2+ \sum_{i=0}^3s_i(h_i)+\sum_{c=0}^1\mathrm{log\_scale}_c.\]

    The loss is negative mean log density over rows, in nats per two-dimensional observation. Sampling supplies Gaussian z, unscales it, then reverses blocks 3,2,1,0. No rejection, ODE solve, approximate determinant or fitting loop is hidden inside the model API. Actual input Jacobians of both maps check the analytic determinants independently of the Gaussian density calculation.

    Hand-check an affine coupling and its determinant

    Use one active conditioner unit: h=tanh(.7a+.1), raw=.2h+.05, s=.8tanh(raw), t=.3h−.1, b=.5. The changed coordinate is .5exp(s)+t. Its derivative with respect to a is .5exp(s)s'(a)+t'(a); the derivative with respect to b is exp(s), so the determinant is exp(s), not one. The table checks five a values.     Hand-check the banana transform before generating its pools

    The source distribution is deliberately synthetic and analytic: u,v independent standard normals, x0=u, x1=v+.5(u²−1). It is a triangular map with determinant one and inverse v=x1−.5(x0²−1). Therefore its true log density is the standard Gaussian log density of that inverse. For v=0 and u=(2,-1,0,1,2), the changed coordinates are (1.5,0,.5,0,1.5). The density has one curved mode. This analytic invertible transform gives an exact reference likelihood, independently of the learned affine model. Its unit determinant describes the data generator; the fitted model has its own input-dependent determinant, which must be included in its likelihood.

    Five exact banana coordinates; native analytic log densities match their inverse standard-normal coordinates.

    Trace the executed compact affine architecture

    Each conditioner stores 16 hidden weights, 16 hidden biases, 32 head weights and two head biases: 66 values. Four give 264; log_scale adds two. The total is *266 values in 17 tensors*. Hidden weights use normal deviation .3 and bias .05; heads use deviation .01 and zero biases. Native seed 9403 initializes all forward blocks, then the global scale at zero. The original optional TensorFlow initial-array directory is absent, so its auto default selects this native initialization. The executed graph groups two affine stages per block for readability and counts the actual leaves, with 132 values in each pair.

    Keep the original data, fitting writes and latent-only sampling visible

    The original in-process protocol uses *512 fit / 128 validation / 128 test* observations. Independent Double Box-Muller banks use seeds 9203/9209/9221, with raw MT19937 midpoint uniforms, cosine partner before sine partner. Apply the banana map in Double and cast final observations once to Float32. Integer source IDs start at 0/10000/20000 for the three pools. These are procedural row identifiers, not real-world subjects or recordings. There is no downloaded or substituted dataset. All 1,024 prior rows come from seed 9257 and cast once to Float32; only these latent values enter inverse sampling.

    BatchOrder(512,32,9421) produces 16 full batches per epoch. Fit three fixed epochs, 48 Adam(.003) writes with betas(.9,.999), epsilon1e-8 and no weight decay. Epoch three is the predefined final selection, not a test-driven choice. Warm all leaves before optimizer construction. Evaluate NLL and both Jacobians with native operations; keep the update and epoch loops explicit. Restored weights, repeated samples and inference immutability are checked bit for bit.

    For exact source replay the model uses rounded_constant=true: log(2*pi) is first rounded to Float32, even if later promoted to Double. The analytic truth and full-precision Gaussian baselines use the full Double constant. This tiny rounding convention cannot explain the gap to truth. The fitting loss remains Float32 and matches the original exactly.

    The complete program also keeps every density grid position, each actual forward/inverse Jacobian and both roundtrip errors. Fitting-only Gaussian moments use the MLE divisor N, not N−1; held-out rows never enter them. Native Double cumulative sums preserve the source's divide-first, serial reduction order for moments and scalar baseline summaries. All numerical/model operations are in the datamunge API; the local functions below package named outputs, checks and file writes. There is no training or sampling loop in a helper header.

    What the checks establish

    All original procedural pools, learned states/gradients, 48 Adam writes, validation records, stage scale/shift fields, both actual Jacobians, every prior sample, density grid, fitting-only moments and non-timing scalar metrics match the source exactly. The independent NumPy audit composes analytic affine Jacobian matrices, checks all 17 parameter leaves by finite differences, verifies every update and inverse sample, and reconstructs all raw midpoint-MT Box-Muller banks. It checks spatially varying determinants on *both* paths without calling native model math or refitting a substitute.

    This four-stage two-dimensional model demonstrates tractable per-point volume change and exact-form inversion. Its original fixed-final likelihood improves on fitted Gaussian baselines, while analytic truth remains better. That result is specific to the retained 266-value architecture, seeds, tiny procedural pools and predefined final epoch. The study does not claim full-image RealNVP performance, a tuned best model or uncertainty quantified across training runs.
