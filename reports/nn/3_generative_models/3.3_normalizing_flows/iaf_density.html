    IAF: Parallel Sampling and Sequential Density

    Abstract

    An inverse autoregressive flow transforms known Gaussian coordinates using means and log scales that depend on earlier coordinates of that same known input. This permits a parallel sampling pass. Evaluating the density of an arbitrary observation instead requires recovering the unknown base coordinates sequentially. This native C++ study checks both directions on a hand-set strict conditioner, then fits the original four-stage, 466-value affine teaching model to procedural banana pools. The complete program keeps all 48 Adam writes, source masks, actual conditioner and whole-map Jacobians, both roundtrips and all 1,024 samples. Fixed-final test NLL is 2.879989624 nats per two-coordinate row, below the fitting-only full Gaussian's 2.994631823, above analytic truth's 2.796480843. This standalone exact-density experiment uses bounded affine scales; it does not fit a variational posterior or evaluate an ELBO.

    Put the parallel computation in the base-to-observation direction

    [Kingma et al., Improving Variational Inference with Inverse Autoregressive Flow (2016)](https://arxiv.org/abs/1606.04934) develops autoregressive invertible transformations for flexible variational posteriors. Our migrated source is a compact standalone affine density study. It uses the shared degree-masked Gaussian conditioner rather than the paper's sigmoid-gated posterior update. For one ordered source block, the known input u produces

    \[x_c=u_c\exp(s_c(u_{<c}))+\mu_c(u_{<c}),\qquad \log|\det Dg(u)|=\sum_c s_c(u_{<c}).\]

    Every u coordinate is supplied, so all heads and x coordinates evaluate in parallel. Strict own/future exclusion leaves exp(s_c)>0 on the Jacobian's diagonal. The source uses four 2->16 tanh->4 conditioners with alternating orders (0,1),(1,0). Heads are mu0,mu1,raw_s0,raw_s1; s=.8tanh(raw_s) bounds the log scale. The masks are the same as the paired MAF example; which input is known determines the computational direction.

    Given an arbitrary x, the heads require unknown u prefixes. Recover the first coordinate from its constant heads, recompute on that recovered prefix, then recover the second:

    \[u_c=(x_c-\mu_c(u_{<c}))\exp(-s_c(u_{<c})),\qquad \log|\det Dg^{-1}(x)|=-\sum_c s_c(u_{<c}).\]

    The source density path reverses blocks3,2,1,0. In each block it makes two prefix conditioner calls, then *re-evaluates the heads on the fully recovered input* for the recorded scale/mean fields and negative-sum determinant. That third call preserves the original graph and floating operation order. The native API retains it. Its inverse sampling path unscales the supplied Gaussian coordinates, then applies blocks0,1,2,3 with one parallel call each. These call counts describe dependency; this study makes no timing claim.

    A final positive diagonal density scale gives h=exp(log_scale)×u. Therefore

    \[\log p_X(x)=-\log(2\pi)-\tfrac12\|h\|^2 -\sum_{i=3}^0\sum_{c=0}^1s_{i,c}(u_i) +\sum_{c=0}^1\mathrm{log\_scale}_c.\]

    The loss is negative mean log density in nats per two-coordinate row. All fitting, sampling banks and epoch selection remain explicit in the report. Core operations supply reusable maps and owning live differentiable fields.

    Inspect the exact degree masks before fitting

    Even blocks assign input degrees (1,2); odd blocks use (2,1). Hidden unit j has degree floor(j/8): eight constant units of degree 0 and eight of degree 1. The four output degrees repeat the input pair. A hidden edge is allowed when input_degree<=hidden_degree; a head edge requires *hidden_degree<head_degree*. The strict final comparison excludes own and later input paths. A degree 0 hidden unit can still contribute a constant through its bias.

    Hand-check parallel sampling and sequential recovery

    Activate only source block 0 and hidden unit8: h=tanh(.7a+.1), mu0=.2, s0=.8tanh(.1), mu1=.3h−.1, s1=.8tanh(.2h+.05), with known input u=(a,.5). Zero every other head and the global scale so the remaining blocks are identity. The parallel observation map is x0=a exp(s0)+.2 and x1=.5exp(s1)+mu1. Its positive log determinant is s0+s1; the actual off-diagonal derivative is dx1/da=.5exp(s1)s1'+mu1'.

    For density, first recover a=(x0−.2)exp(−s0), recompute the conditioner using that recovered prefix, then recover .5=(x1−mu1)exp(−s1). The complete program checks the two actual whole-map Jacobians, the negative density determinant, manual sequential recovery, and all five points against these formulas.     Hand-check the banana transform before generating its pools

    The source distribution is deliberately synthetic and analytic: u,v independent standard normals, x0=u, x1=v+.5(u²−1). It is a triangular map with determinant one and inverse v=x1−.5(x0²−1). Therefore its true log density is the standard Gaussian log density of that inverse. For v=0 and u=(2,-1,0,1,2), the changed coordinates are (1.5,0,.5,0,1.5). The true density has a single mode. This analytic invertible transform gives an exact reference likelihood, independently of the learned autoregressive model. Its unit determinant describes the data generator; the fitted model has its own input-dependent determinant, which must be included in its likelihood.

    What the checks establish

    All original procedural pools, degree/mask inventories, learned states/partials, 48 Adam writes, validation records, actual conditioner Jacobians, both whole-map Jacobians, inverse samples, density cells, fitting-only moments and non-timing metrics match the source exactly. Independent NumPy checks all 22 source archives (226,631 values), all 144 update captures(44,784 values),17 leaf finite differences and160 additional masked-coordinate finite differences. It verifies40,704 forbidden conditioner Jacobian entries across recorded evaluations and7,680 zero-gradient/unchanged-weight entries across the 48 writes. It composes both maps' analytic Jacobian matrices and reconstructs all raw Gaussian/banana rows.

    The report preserves the asymmetry of computation: two recovered-prefix calls and one final head re-evaluation per density block, one parallel call per inverse sampling block. These counts explain dependency, not a measured speed comparison. The predefined final test likelihood improves over fitting-only Gaussian baselines while remaining worse than truth. That result belongs to this 466-value architecture, retained seeds and short procedural experiment; it is not a tuned best model, a full-image benchmark or uncertainty estimate across training runs.
