    CTC handwriting recognition on MNIST digit strings

    CTC handwriting recognition on MNIST digit strings

    Each strip shows one to three intact MNIST digits with small random gaps. Four-column frames feed a masked bidirectional LSTM. Connectionist temporal classification (CTC) sums the probabilities of frame paths that collapse to the target string. A blank separates repeated digits, and the loss and decoder ignore padded frames.

    The training and validation strips use separate glyphs from the official training split. Test strips use only the official test split. Set DM_MNIST_DIR to an existing IDX directory or let Datamunge fetch MNIST. The plot pairs the validation loss with the first held-out image and its greedy transcription.

    Validation loss decreases, but the three-epoch checkpoint produces no exact strings under greedy decoding. The character error count is as large as the number of reference digits.
