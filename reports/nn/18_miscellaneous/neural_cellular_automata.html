    Grow a pattern with a neural cellular automaton

    Abstract

    Fit a shared local update that grows a cross from one active cell. Train with random update masks and check how the learned pattern changes when the initial seed is translated.

    Share one update rule across cells

    Each cell has three continuous state channels. A 3-by-3 convolution reads the neighborhood. A tanh activation and a pointwise convolution produce a candidate change to the state. The result is added back to the previous state. This residual rule is applied four times with shared weights.

    During training, each cell accepts an update with probability 0.7, independently at every step. The squared error weights target cross pixels five times as heavily as the background. At test time all updates are enabled. Translating the seed checks whether the model uses the same rule at different positions. The pattern starts far enough from the boundaries for the four-step comparison.

    Reproduce the upstream translated-seed fixture

    Translated weighted MSE 0.40456471 to 0.17162434. Maximum translation error 0.00e+00.

    The image shows the translated seed, target and learned output from left to right. The grayscale display clips values to the range from zero to one. The error and translation check use the original continuous values.
