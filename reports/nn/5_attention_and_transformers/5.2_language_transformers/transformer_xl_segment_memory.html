    Transformer-XL segment memory

    Transformer-XL segment memory

    This character language model predicts the next character in each of two consecutive 16-position segments. At each Transformer layer, the second segment projects the first segment’s cached input states into keys and values. It sees the entire cache and the causal prefix of its own segment. Detaching the cache truncates differentiation at the boundary while preserving its effect on predictions.

    The attention score adds a content dot product and a query-dependent position dot product. The latter uses a projected sinusoid at the relative distance between query and key. Two learned biases per head adjust those scores before causal softmax. The experiment trains for 48 Adam updates on the pinned Tiny Shakespeare windows, using native parameter initialization. Validation loss is measured each epoch. Resetting the cache isolates its effect on the second-segment test loss.
