    ALBERT, DistilBERT and masking schedules

    ALBERT, DistilBERT and masking schedules

    These compact models use the same 64-character corpus and ten selected tokens per sequence. ALBERT projects eight-dimensional embeddings to the encoder width and reuses the same block twice. DistilBERT fits one block against a frozen two-block teacher. Its objective adds temperature-two KL over output distributions and a cosine penalty over hidden states to the ordinary masked-token loss.

    The RoBERTa-style run regenerates masks each epoch, uses batches of 16, and warms up then decays the learning rate. The static control uses batches of eight, reuses each record's corruption, and keeps the learning rate constant. This comparison changes both the masking and optimization schedules. All curves use the same validation masks.

    Set DM_CHARACTER_CORPUS to use a prebuilt character archive. The report trains the base teacher as part of the experiment.
