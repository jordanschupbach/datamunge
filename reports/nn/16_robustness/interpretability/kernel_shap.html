    Kernel SHAP with sampled and exhaustive coalitions

    Kernel SHAP with sampled and exhaustive coalitions

    For each coalition, retain the selected coordinates of the point and replace all other coordinates with values from a background row. Average the nonlinear model's predictions over the same 32 background rows for every coalition. This defines the value of including a set of features, including interactions.

    A weighted linear regression assigns an attribution to each feature. The intercept equals the empty-coalition value. Eliminating one coefficient enforces that all contributions sum to the difference between full and empty coalitions. Compare a sampled fit with the full enumeration on the same model and point. The sample includes all singleton masks to identify the regression coefficients.

    Full minus empty score 0.092212. Maximum sampled attribution error 0.006067.

    This comparison computes the full coalition table once as a reference. The sample reduces the regression design to 32 interior rows. The report evaluates attribution error at that sample size.
