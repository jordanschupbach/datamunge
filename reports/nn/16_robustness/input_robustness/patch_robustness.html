    Shared patch robustness on synthetic stripes

    Shared patch robustness on synthetic stripes

    A fixed classifier distinguishes horizontal and vertical stripes in noisy 8-by-8 images. One class score also responds to a checkerboard texture. This fixture measures whether a small localized replacement can overwhelm the stripe evidence.

    A single 3-by-3 patch minimizes the target-class cross-entropy averaged over the four corner placements. Each update clips the patch values to the valid pixel range. Evaluation uses separately generated images and an interior placement excluded from fitting. Among class-zero images the classifier originally gets right, the report counts how many move to class one and plots changes in the target-class logit margin.

    At the unseen placement, 43 of 43 originally correct class-zero images switch to class one.
