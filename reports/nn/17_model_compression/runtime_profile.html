    Profile a TensorFlow CPU graph across thread settings

    Abstract

    Measure untraced execution for two independent CPU matrix products, then capture a separate trace and export it for Chrome or Perfetto.

    The graph computes \(XY+YX\) for two fixed 256-by-256 matrices. The products can run concurrently. Intra-op threads are available to split work within an operation, while inter-op threads schedule independent operations. The benchmark creates a separate session for each thread configuration.

    After five warm-up calls, measure the median of 24 untraced calls. Each call includes the adapter's tensor copies. Request full runtime metadata only for a separate invocation so profiling overhead stays out of the timing samples. The trace uses complete events with a device group, thread ID, start time, and duration. Both products must appear.

    Compile Datamunge with -DDATAMUNGE_ENABLE_TENSORFLOW=ON and set CMAKE_PREFIX_PATH to a TensorFlow C++ SDK. Open the generated build/runtime_profile/runtime_*.json files in Chrome Trace Viewer or Perfetto to inspect operation overlap.
