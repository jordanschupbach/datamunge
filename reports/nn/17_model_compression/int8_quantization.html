    Compare post-training and quantization-aware int8 inference

    Abstract

    Fit a dense regressor, calibrate symmetric int8 scales on training data, and compare post-training quantization with quantization-aware training.

    Each scale is the largest training magnitude divided by 127. Divide by that scale, clip to the symmetric int8 range, and round to the nearest integer with ties to even. Inference widens packed int8 operands and returns exact int32 dot products. The CPU kernel uses a wider running sum. Multiply the result by the activation and weight scales to recover real-valued predictions.

    Post-training quantization uses the float fit directly. Quantization-aware training starts from zero and uses fake-quantized weights and features in the forward pass. Its clipped straight-through gradient updates the float weights inside the clipping interval. Both variants use the same scales. Held-out features extend to ±1.12, so test inputs can saturate at the activation bounds learned from features between ±1.

    Activation scale 0.00786916641. Weight scale 0.0070492708.

    FitFloat MSEInt8 MSE
    ptq0.0002181031860.000633749968
    qat0.0002245476220.00062598384

    The diagnostic NPZ file records int8 codes as Int32 arrays so the generic tensor archive can read them. Operands remain packed as signed bytes in the quantizer and are widened for the integer product.

    Reference

    • Jacob et al., Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference.
