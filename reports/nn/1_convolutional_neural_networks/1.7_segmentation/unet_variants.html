    UNet++ dense skips and additive attention U-Net

    Abstract

    Combining coarse context with fine spatial features can require more than a single skip connection. This report checks densely nested supervision and additive skip gating,then visibly fits both complete compact tensor models and examines their held-out masks and learned gates.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.7_segmentation/unet_variants.cpp.

    The method

    UNet++ refines dense nested skip pathways and supervises several full-resolution heads. Attention U-Net learns context-dependent sigmoid multipliers for encoder skips. Both mechanisms are checked with small examples and full graphs before explicit Adam fits.

    An additive gate with hand-checkable derivatives

    An attention gate projects the encoder skip and decoder context into a hidden space,adds them,applies ReLU,then a1x1 projection and sigmoid. The coefficient multiplies every skip channel at that location. Both input paths receive gradients; the coefficient is not a hard crop or a ground-truth mask.

    This fixture sets all projections explicitly. With skip x and context g=.4, z=2*x-g+.3, a=sigmoid(1.5*ReLU(z)-.2) and output x*a. Its skip derivative is a+x*a*(1-a)*3 when z>0,and a otherwise; its context derivative is -1.5*x*a*(1-a) when z>0,and zero otherwise. The following61 points avoid the ReLU kink; the native fixtures also check negative projections and sigmoid saturation.

    All61 gate values,outputs and both input derivatives match independent formulas,max error 0.000000000000. Native tests additionally cover negative ReLU branches and saturated sigmoid.

    Dense nested skips and complete model graphs

    UNet++ constructs x[i,j] by concatenating all earlier x[i,0..j-1] nodes with corner-aligned bilinear upsampling of x[i+1,j-1] to the actual encoder shape, then applying two3x3/ReLU convolutions. Four full-resolution learned heads provide deep supervision; evaluation uses the deepest head. At default base32, the deepest x[0,4] concatenates192 channels and the graph has15 nodes, 9,156,264 learned scalars and68 learned tensor gradients.

    Attention U-Net uses learned2x2 stride2 up-convolutions,one additive gate for each cropped encoder skip,and concatenated decoder convolution pairs. At default base64,it has31,381,414 scalars and70 tensor gradients. The adaptation omits BN and dropout in both models. Full graphs execute below at 32x32 with initialized weights,without a biomedical accuracy claim. Compact base8/four-class models retain every nested node/head or every attention gate. Native checks require every compact gradient to be nonzero and verify dense concatenation widths,odd nested alignment and rounded attention geometry.

    FullUNet++:9156264 learned scalars,all68 finite defined gradients at32px,4 supervised heads,15 nested nodes,no BN state. Fullattention U-Net:31381414 learned scalars,all70 finite defined gradients at32px,1 supervised heads,0 nested nodes,no BN state.

    Conclusion

    Analytic gate derivatives and complete graph checks precede compact training. Every nested head contributes explicitly to the objective. Fit-only class weights,validation-selected restoration,actual predictions and fixed-range gate maps expose the results without a biomedical benchmark claim.
