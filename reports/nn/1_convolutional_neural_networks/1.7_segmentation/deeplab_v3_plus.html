    DeepLab v3 global context and separable v3+ decoding

    Abstract

    Pixel classification needs both wide scene context and local boundary detail. DeepLab v3 adds image-level context to atrous features;v3+ combines separable context branches with low-level decoding. This report checks complete tensor graphs before fitting both compact models with explicit Adam.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.7_segmentation/deeplab_v3_plus.cpp.

    The method

    Five ASPP branches concatenate local,multiscale and global features. The optional separable decoder combines this context with a projected C2 map at stride4. Global means,dilated kernels,BN state and all fitting/evaluation arithmetic use tensors.

    A global image branch with exact input derivatives

    DeepLab v3's context module concatenates five branches:1x1 projection,three atrous3x3 convolutions and a global image-average projection. The image branch computes a spatial mean,normalizes/projects it,and broadcasts back by aligned- corner bilinear resizing. A constant projected mean is therefore constant across spatial locations;it still receives gradients from every output pixel.

    This fixture fixes an identity1x1 projection and compensates the stored BN variance offset,so each positive input channel's global mean broadcasts exactly. The derivative of the sum of every repeated output is1 for every source pixel. Native independent calculations check separate batches/channels and all pixels. Training at N=1 makes the1x1 global BN batch variance zero;the compact fit uses batch4 and the warmed moving-state path uses inference mode.

    Separate per-image/channel means broadcast;all252 source derivatives are1 within1e-5. First channel mean 0.745261. Fixed BN compensation isolates the operation without fitting.

    Full v3/v3+ graphs and the separable decoder

    Both models use a supported output-stride16 ResNet50 encoder. V3 concatenates ordinary ASPP features,projects1x1 and classifies. V3+ uses atrous depthwise/ pointwise blocks in ASPP,projects C2 to48 channels,fuses at stride4 and applies two separable decoder blocks before linear class scores. Each depthwise stage has BN/ReLU before its pointwise normalized projection. This is the source's ResNet-based variant;it does not claim the paper's Xception backbone.

    Full v3/v3+ learned counts are39,048,533/26,696,133,state56,192/70,720 and 179/203 learned tensor gradients. Both full backwards execute below at33px. Compact ResNet18/divisor8 uses head32,rates1/2/3,decoder32/low8,no dropout: 241,740/198,004 learned and1,584/2,256 state scalars. Native checks require all compact gradients nonzero and verify five branches concatenate160 channels. Stride8 doubles base atrous rates and preserves learned parameter shapes.

    Fullv3:39048533 learned/56192 state scalars,all179 finite defined gradients at33px,five ASPP branches. Fullv3+:26696133 learned/70720 state scalars,all203 finite defined gradients at33px,five ASPP branches.

    Fit-only inverse-square-root pixel weights use pseudocount1. Every learned leaf is warmed before Adam(.001),then all parameters fit32 epochs,batch4, 512 visible updates per model. Stable weighted CE normalizes by selected pixel-weight sum. Explicit .00005*sum(kernel²) penalizes kernels;biases and BN affine leaves are optimized but excluded from that penalty. Training-mode forwards update moving BN moments exactly once per batch. Strict validation mean IoU selects paired learned/BN checkpoints;restoration reproduces the selected score before test evaluation. Test data never fits weights or selects checkpoints. These bounded procedural fits make no VOC/Cityscapes benchmark claim.

    All encoder,ASPP,BN and optional decoder leaves enter the optimizer. The training forwards compute their logits once,so shared BN state updates once per batch. Decoder-enabled and decoder-free fits start independently from seed17 and select their own validation checkpoints.
