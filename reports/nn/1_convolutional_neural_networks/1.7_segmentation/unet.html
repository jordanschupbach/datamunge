    U-Net cropped skips and learned decoding

    Abstract

    Pixel classification needs fine boundaries as well as broad spatial context. U-Net combines a contracting CNN with learned decoding and aligned encoder skips; this report checks crops and gradients before a visible compact Adam fit and held-out mask evaluation.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.7_segmentation/unet.cpp.

    The method

    Encoder pooling increases context while learned transposed convolutions restore spatial resolution. Concatenated,cropped skip features preserve detail for each decoder pair. Original valid geometry and compact SAME geometry remain explicit and separately checked.

    Cropped skips and learned up-convolutions

    U-Net contracts through two3x3 ReLU convolutions and2x2 pooling per level, then expands with learned2x2 stride2 transposed convolutions. Each decoder concatenates its upsampled features with the floor-centred cropped encoder skip before another convolution pair. For odd excess sizes, extra pixels remain on the bottom/right. The crop differentiates source pixels only; reference tensor values merely supply the requested shape.

    Original valid-pair geometry maps572 pixels to388, with four pooling levels and base64 channels. The compact model uses base8,SAME pairs,RGB/four classes and no dropout; sides divisible by16 retain their size. The full architecture has dropout.5 at the deepest encoder and bottleneck during training. Up-convolution weights are learned, unlike FCN's frozen bilinear filters.

    Actual shape images and masks

    The tensor shape generator creates64 fitting/16 validation/16 test96-pixel RGB images with independent seeds11/22/33. Circle,rectangle and triangle brightness/noise/tint have the same distributions, so labels require spatial context. Later objects occlude earlier masks. This tensor RNG adaptation has different fixed-seed pixels from the original mt19937 generator; it preserves the procedural conventions rather than byte-for-byte samples. Four actual fitting image/mask pairs appear below. The mask palette is background dark, circle red,rectangle green,triangle blue.

    64 fitting RGB images96x96; classes0 background,1 circle,2 rectangle,3 triangle. Fit-only inverse-square-root pseudocount weights 1.149431/3.477891/3.045941/4.357872. Noise,tint and brightness are class-independent; later objects occlude earlier masks. Tensor RNG changes fixed-seed pixels relative to the old mt19937 generator.

    Whole-model explicit Adam and restored test masks

    The fit-only weight for class c is 1/sqrt((count_c+1)/fit_pixels). Pixel CE is normalized by the sum of selected pixel weights, using stable tensor log-softmax. Every leaf is warmed before Adam(.001); the visible loop performs 16 epochs of batch 4, 256 updates per model, which keeps the documentation build short. Explicit .00005*sum(kernel²) matches half the source L2 coefficient. Kernels,biases and score layers are optimized; there are no BN moving moments. Validation mean IoU strictly selects the learned checkpoint, then restoration reproduces the selected score before test evaluation. Mean IoU includes background and classes present in truth or prediction; classes absent from both are excluded. Test metrics never select epochs or fit weights.
