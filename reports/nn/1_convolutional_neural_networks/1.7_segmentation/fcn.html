    FCN32s,16s and8s dense prediction skips

    Abstract

    Assigning a class to every pixel needs spatially aligned outputs from coarse CNN features. This report checks frozen bilinear filters and released FCN crop geometry, then fits all three compact VGG skip variants with explicit Adam and compares their held-out masks.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.7_segmentation/fcn.cpp.

    The method

    FCN replaces classification layers with spatial convolutions. Bilinear deconvolution restores resolution; projected intermediate VGG features add progressively finer class scores. Full released geometry and compact teaching geometry are checked separately before fitting.

    Frozen bilinear filters and aligned skip fusion

    All thirteen VGG convolutions become a dense prediction backbone. Coarse class score maps are bilinearly upsampled; FCN16s adds projected pool4 scores, and FCN8s also adds pool3 scores. The frozen filter is a separable tent centred at stride-.5, multiplied by channel identity so classes never mix. Frozen filters are excluded from learned parameters and the optimizer.

    The released full geometry adds99 pixels per edge before SAME conv1, uses ceil/SAME pooling and valid7x7 fc6, crops skips at5/9, then crops final upsampling at19/27/31 for32s/16s/8s. The compact adaptation retains every VGG stage but uses SAME3x3 fc6 and zero-offset crops, with width divisor8, fc64/four classes and dropout disabled. It aligns odd95/96/97-pixel inputs.

    Every diagonal/cross-class filter element matches the independent tent oracle; max error 0.000000000000. Native fixtures also check exact fusion values and both input derivatives, full/compact crop conventions and odd spatial grids.

    Actual procedural image/mask pairs

    The tensor shape generator creates64 fitting/16 validation/16 test96-pixel RGB images with independent seeds11/22/33. Circle,rectangle and triangle brightness/noise/tint have the same distributions, so labels require spatial context. Later objects occlude earlier masks. This tensor RNG adaptation has different fixed-seed pixels from the original mt19937 generator; it preserves the procedural conventions rather than byte-for-byte samples. Four actual fitting image/mask pairs appear below. The mask palette is background dark, circle red,rectangle green,triangle blue.

    64 fitting RGB images96x96; classes0 background,1 circle,2 rectangle,3 triangle. Fit-only inverse-square-root pseudocount weights 1.149431/3.477891/3.045941/4.357872. Noise,tint and brightness are class-independent; later objects occlude earlier masks. Tensor RNG changes fixed-seed pixels relative to the old mt19937 generator.

    Explicit Adam for all three skip variants

    The fit-only weight for class c is 1/sqrt((count_c+1)/fit_pixels). Pixel CE is normalized by the sum of selected pixel weights, using stable tensor log-softmax. Every leaf is warmed before Adam(.001); the visible loop performs 8 epochs,batch4,128 updates per model. Explicit .00005*sum(kernel²) matches half the source L2 coefficient. Kernels,biases and score layers are optimized; there are no BN moving moments. Validation mean IoU strictly selects the learned checkpoint, then restoration reproduces the selected score before test evaluation. Mean IoU includes background and classes present in truth or prediction; classes absent from both are excluded. Test metrics never select epochs or fit weights.

    Conclusion

    Full released graphs and every learned gradient are checked separately from compact training. Fit-only class weights,visible optimization and validation-selected restoration support held-out comparisons while retaining segmentation errors in the actual prediction galleries.
