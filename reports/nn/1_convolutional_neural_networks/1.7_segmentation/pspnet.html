    PSPNet pyramid context and auxiliary supervision

    Abstract

    Local pixel features can confuse shapes without scene-level context. PSPNet pools several spatial scales and fuses them with dense encoder features. This report checks exact overlapping bins and full graphs,then visibly fits the compact model with explicit main/auxiliary Adam supervision.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.7_segmentation/pspnet.cpp.

    The method

    Adaptive1/2/3/6 bins collect global and regional context. Projected,aligned-corner resized means concatenate with dense ResNet features before class prediction. A separate auxiliary head contributes explicitly to the training objective;test predictions use the main head.

    Overlapping adaptive bins on a known rectangular grid

    PSPNet summarizes dense features at1/2/3/6 spatial bin scales,projects each, resizes them to the encoder grid and concatenates them with the original features. Adaptive-bin starts are floor(i*H/bins) and ends are ceil((i+1)*H/bins). Odd-grid bins overlap: repeated source pixels receive the sum of every contributing mean derivative. Bins may exceed an input axis; a1x1 image copied into6x6 bins has derivative36 per channel for a summed output.

    On the known5x7 grid containing0..34,three-bin row ranges are[0,2),[1,4),[3,5) and column ranges[0,3),[2,5),[4,7). The centre mean is17. The following code checks every mean and derivative with independent loop arithmetic.

    All nine means and35 source derivatives match independent bin loops,max error 0.000000000000;centre mean 17.000000. Native rectangular/multibatch/channel/bin-larger-than-grid tests also pass.

    Full PSPNet101 and complete auxiliary-head gradients

    The encoder is dense output-stride8 ResNet101. Four adaptive pools at1/2/3/6 bins project to512 channels;corner-aligned resizing and the original2048 features concatenate to4096 channels before the3x3/512 fusion head. A linear classifier restores input-sized logits. A C4 auxiliary classifier supports supervised training. BN uses momentum.9/epsilon1e-5;full training dropout keep probability is.9. No pretrained weights are used.

    The full model executes67,949,930 learned/110,976 state scalars and all334 tensor gradients below at33px. The compact model retains every pool/head, ResNet18/divisor8,pool16/head32/aux16,four classes and no dropout. Native checks require every compact gradient nonzero and exact96/97-pixel main/aux alignment;all five concatenated context sources contribute.

    Full PSPNet101:67949930 learned/110976 state scalars,all334 finite defined gradients at33px,four pools and auxiliary head. Compact96px:222704 learned/1424 state scalars;main/aux align,adaptive bins1/2/3/6. Compact97px:222704 learned/1424 state scalars;main/aux align,adaptive bins1/2/3/6.

    Actual data and explicit main/auxiliary Adam fitting

    The tensor generator creates64 fitting/16 validation/16 test96-pixel RGB shape scenes,seeds11/22/33. Class-independent noise,brightness and image-wide tint require spatial context;later objects occlude earlier masks. Tensor RNG changes the old mt19937 fixed-seed pixels. Palette: background dark,circle red, rectangle green,triangle blue. Four actual fitting pairs appear below.

    64 fitting RGB images96x96; classes0 background,1 circle,2 rectangle,3 triangle. Fit-only inverse-square-root pseudocount weights 1.149431/3.477891/3.045941/4.357872. Noise,tint and brightness are class-independent; later objects occlude earlier masks. Tensor RNG changes fixed-seed pixels relative to the old mt19937 generator.

    Fit-only inverse-square-root pixel weights use pseudocount1. Every learned leaf is warmed before Adam(.001),then all parameters fit32 epochs,batch4, 512 visible updates per model. Stable weighted CE normalizes by selected pixel-weight sum. Explicit .00005*sum(kernel²) penalizes kernels;biases and BN affine leaves are optimized but excluded from that penalty. Training-mode forwards update moving BN moments exactly once per batch. Strict validation mean IoU selects paired learned/BN checkpoints;restoration reproduces the selected score before test evaluation. Test data never fits weights or selects checkpoints. These bounded procedural fits make no VOC/Cityscapes benchmark claim.

    The explicit objective is (main_weighted_CE+.4*auxiliary_weighted_CE)/1.4, then kernel L2. Both classifier paths and the entire encoder/pyramid/fusion model enter Adam. The main and auxiliary outputs come from one training forward,so BN moments update once per batch. Evaluation uses main logits; auxiliary scores do not replace them or select a separate checkpoint.
