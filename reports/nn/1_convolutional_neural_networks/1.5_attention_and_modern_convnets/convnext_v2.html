    ConvNeXt V2: Global Response Normalization and Visible Atto Fitting

    Abstract

    Modern convolutional blocks combine large depthwise spatial filters with expanded channel processing. We check the normalization or layer-scale rule, distinguish analytic model budgets from executed forwards, then expose every tensor Adam update of a complete Atto classifier.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.5_attention_and_modern_convnets/convnext_v2.cpp.

    The method

    V2's response normalization uses G_c=sqrt(sum_H,W X_c²), N_c=G_c/(mean_channels G+1e-6), then Y=X+gamma*X*N+beta. Gamma and beta start at zero, making the layer exactly identity. Its safe square-root argument defines the norm derivative at zero as zero, avoiding 0*infinity NaNs for dead channels. At active affine values, gradients include normalized-response effects. Multiplying X by a positive scalar only APPROXIMATELY preserves N because epsilon stays fixed. The pictured fixture checks all-zero/single-dead-channel initialization and active affine values. V2's fully convolutional masked-autoencoder pretraining is not implemented by this classifier.

    Both versions use biased depthwise 7×7 filtering, channels-last LayerNorm (epsilon 1e-6), a pointwise expansion to 4C, exact erf GELU, pointwise projection and raw shortcut addition. V1 scales the projected branch by a learned channel vector initialized to 1e-6; V2 instead inserts GRN between expanded GELU and projection. Filters and classifier use untruncated N(0,.02), biases zero, an initialization adaptation from the released truncated normal. There is no BN or moving-statistics store. Per-example inverted branch dropout increases linearly from zero to drop_path at the LAST block, using i/(n−1), and is absent in inference.

    A biased 4×4/4 patchify convolution with LayerNorm starts the reference network. Three LayerNorm plus biased 2×2/2 joins connect four stages. Global mean, LayerNorm and a classifier finish it. The report prints analytical learned counts for every released table entry, checking those formulas against actual full-weight Atto/Tiny 64-pixel forwards and a Tiny 224-pixel forward. The other large designs are not allocated; Huge's count does not require allocating its roughly 2.6 GB Float32 weights. Exact reference MACs use 56/28/14/7 stage sides and exclude normalization/nonlinearity/GRN/addition/memory work. They are not latency measurements.

    The full-width Tiny backward probe retains all eighteen blocks at 64 pixels. It activates V1 layer scales or V2 GRN affine entries to inspect learned-branch derivatives, separately from the near-identity initialization fixture. All parameter-tensor derivatives must be finite and above a relative diagnostic threshold; this fixture does not guarantee nonzero gradients for arbitrary inputs. All model computations, preprocessing, losses and updates use the tensor library.

    The visible fit retains the complete Atto layout, depths 2/2/6/2 and widths 40/80/160/320, with a 2×2/2 CIFAR patchify stem, ten classes and drop_path=.1. It uses 128 fit/64 validation/ 64 official-test images, 8 batch-eight epochs, explicit Adam(.001) and kernel L2=.0001/2, with padded crops/flips. Validation selects learned parameters; no moving state exists to save. The two versions have 3376290/3389170 learned scalars in this setting. These bounded runs do not reproduce the paper's AdamW, longer schedules, stronger augmentation or pretraining.

    Conclusion

    Controlled tensor fixtures explain the residual rule, while exact count formulas and actual Atto/Tiny forwards distinguish architecture budgets from large allocations. Visible optimization connects the complete Atto topology to data without claiming published pretraining or benchmarks.
