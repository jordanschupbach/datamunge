    CondenseNet: Tensor Pruning, Packed Groups and Explicit Optimization

    Abstract

    Learned group convolutions select reusable dense features before conversion into grouped filters. We inspect tensor mask updates, verify packed values and every derivative, then fit the complete 42-layer dense body with a visible Adam, group-lasso and pruning loop.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.4_efficient_and_mobile_architectures/condensenet.cpp.

    The method

    The CIFAR-86 configuration has three dense stages with 14 layers each and growth 8/16/32. A 16-channel stem precedes BN/ReLU, a learned 1×1 bottleneck with 4k outputs, then BN/ReLU and a 3×3 four-group convolution adding k new channels by concatenation. Transitions average-pool without compression. Final BN/ReLU, global mean and a biased 10-class classifier use all 800 final channels. The full training form has 1451594 learned scalars and 1273850 BN/mask/stage scalars before its scalar step counter is created.

    For C=4 condensation and G=4 output groups, outputs kG+g share a mask for group g. Importance is the sum of absolute masked weights over that group's outputs. At each of three stages, the least important Cin/C still-live inputs are removed per group. Stable ranking resolves equal scores by input index; jumping forward in progress catches up every missing stage, and moving backwards never resurrects a connection. All production ranking, mask updates and packed kernel gathering use tensors, preserving Float32/Float64 types. The host sort below exists only as an independent oracle.

    \[L=L_{\mathrm{NLL}}+\lambda\sum_{\ell,i,g}\sqrt{\max(\sum_k(W_{\ell,i,kG+g}M_{\ell,i,g})^2,10^{-6})} +\frac{10^{-4}}2\sum_{W\text{ kernels}}\lVert W\rVert_2^2.\]

    Each forward clones its current mask and computes its loss with that snapshot. It then updates stored masks using PRE-optimizer weights for the NEXT forward. Progress is the pre-forward step divided by total steps, with target stage min(C−1,floor(2(C−1)progress)). In 18 updates, the forward at step 9 (the 10th update) stores stage three; the next forward first uses it. Lasso is included while the snapshot's old stage is below three. BN uses epsilon 1e-5; learned affine state and moving moments are separate. Frozen diagnostic state disables both BN and mask/step updates. Training snapshots include parameters, BN, masks, stages and step. Pruned entries remain dense parameters; L2 and Adam may still change them behind zero masks.

    Packing gathers each group's surviving inputs and corresponding BN vectors, packs its kernel, uses a core grouped convolution, and restores the original interleaved output channel order with PaperChannelShuffle. The Float64 fixture checks outputs and ALL input/filter/BN derivatives. This is a converted single-layer demonstration. The separate converted-network cost helper is ANALYTICAL: its default additionally assumes a half-width final classifier. No fitted classifier feature-selection algorithm or fully converted network is claimed. Keeping all 800 features costs 4000 extra parameters and MACs in the CIFAR budget. MACs exclude BN, pooling, activations, gathers and memory traffic; dense masked training does not realize packed speedups.

    The visible subset fit retains all stage depths and widths. It uses 48 fit, 32 validation and 32 official-test images; 3 batch-eight epochs (18 updates) of Adam(.001), explicit lasso and kernel L2, with padded crops/flips. Inference restores the lowest validation-NLL checkpoint with ALL state, which can precede full condensation. Its saved stages are printed separately from final training stages. This deliberately tiny single-seed CPU run (kept short so the report builds in seconds) shows the mechanics only; it does not reproduce paper accuracy or a mobile latency study.

    Pruning schedule and independent oracle

    All three tensor pruning stages agree with an independent importance oracle: 16/12/8/4 inputs per group. A jump to progress .5 catches up all stages; equal scores prune lower input indices first.

    Packing with preserved derivatives

    Packed Float64 kernel [1,1,4,16]; nontrivial BN state/affine values gathered with inputs. Outputs and all input/filter/BN derivatives agree; maximum absolute error 0.000000000000.

    Complete model and explicit budget assumptions

    Full CIFAR C86: 1451594 learned / 1273850 BN-mask-stage scalars before training; 42 dense layers, 800 final channels, 383 finite parameter-tensor gradients. Analytical fully converted CIFAR budget with assumed 400-feature classifier: 516202 parameters / 62377888 MACs. Keeping all 800 classifier features: 520202 parameters / 62381888 MACs. Analytical ImageNet G=C=4: 4773944 parameters / 516640576 MACs, assuming half-width classifier; no full converted network is executed here. Analytical ImageNet G=C=8: 2935416 parameters / 261545792 MACs, assuming half-width classifier; no full converted network is executed here.

    Conclusion

    Learned masks prune feature reuse while a packed grouped layer preserves the masked function and derivatives. Explicit optimization exposes group lasso, the next-forward pruning schedule and stateful checkpoint selection. Analytical conversion budgets remain separate from the executed single-layer packing and dense subset fit.
