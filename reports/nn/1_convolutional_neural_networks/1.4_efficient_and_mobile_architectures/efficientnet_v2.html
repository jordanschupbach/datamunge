    EfficientNetV2: Fused Early Blocks and Explicit Base-B0 Fitting

    Abstract

    EfficientNetV2 combines fused early blocks with later SE mobile bottlenecks. We compare executed block arithmetic, check all seven full-weight designs and exact target budgets, then expose every update of a complete base-B0 tensor Adam fit.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.4_efficient_and_mobile_architectures/efficientnet_v2.cpp.

    The method

    Fused-MBConv replaces the pointwise expansion and depthwise spatial filtering with one dense spatial expansion. It keeps a separate linear pointwise projection when expansion exceeds one. At expansion one it uses a single spatial projection followed by BN/swish, with no SE in the released tables. Later ordinary MBConv blocks use SE .25, logistic gates and linear projection. Every compatible stride-one block can add its raw input; training residual masks use the same zero-based .2*i/n drop schedule as EfficientNet. Classifier dropout follows each variant's table.

    Fusing is a computational choice, not an algebraic folding of identical weights. The controlled 24-to-48, stride-two, expansion-four comparison at 96 pixels executes two separately initialized functions: MBConv uses 8256 parameters/33841152 MACs in three convolutions; Fused-MBConv uses 25632/58392576 in two. More arithmetic can still suit accelerator hardware; no runtime is measured. Their displayed maps are illustrative, not a numerical-equivalence claim.

    S/M/L have their own searched tables with 40/57/79 blocks. Base B0-B3 scale a separate table with 21/27/28/32 blocks. Stem width is the first block's input, while the 1280-channel head scales with width. All seven full-weight networks execute at 64 pixels for parameter/state counts. Exact reference-resolution budgets use ceil side geometry at every SAME downsampling, keeping pooled SE/classifier costs fixed. Base B0 also executes an actual 224-pixel cross-check. Large S/M/L target-resolution forwards are not claimed. A full base-B0 backward probe at 64 pixels freezes moving updates and branch dropout, shifts BN/SE biases, and checks every derivative is finite. Some projection BN shifts cancel through pointwise/BN paths; early padded fused filters can preserve a spatially varying boundary contribution, so not all projection shifts are redundant.

    The visible CIFAR fit retains all 21 base-B0 blocks and 5871514 learned scalars. It uses fixed 32-pixel inputs and fixed regularization throughout. The paper's progressive resizing and adaptive regularization schedule is not reproduced or hidden in the model helper.

    All model computation, image scaling, augmentation, losses and optimizer updates use tensors. Architecture strings, integer dimensions and plotted vectors are metadata. Convolutions use He-uniform initialization and TensorFlow SAME padding, BN epsilon 1e-3 with learned scale/shift, and a biased classifier. Training uses batch moments; inference uses saved moving moments. Dropout draws from the learned store's generator. The arithmetic log counts convolution, pooled SE and classifier products, excluding BN, pooling, activations, additions and memory traffic. One MAC is a multiply-accumulate pair, not measured latency or individual FLOPs.

    The bounded fit uses original 32×32 CIFAR-10 images, changes only the stem stride and class count, and retains every block and channel width. It shows four epochs (64 updates, kept short for build time), batch eight, Adam(.001), explicit kernel L2=.0001/2 and independent padded crops/flips. Fixed subsets contain 128 fit, 64 validation and 64 official-test rows. The lowest validation NLL selects paired learned/BN checkpoints before test scoring. No accuracy threshold is imposed on this small single-seed experiment; it is not the published ImageNet training schedule or a latency search.

    Conclusion

    Fused early filtering changes learned computation and hardware arithmetic. Full table counts, precise target geometry and visible base-B0 fitting explain that design without treating fused blocks as equivalent functions or claiming the published progressive-training results.
