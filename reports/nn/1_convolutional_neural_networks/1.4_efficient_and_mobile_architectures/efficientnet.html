    EfficientNet: Compound Scaling and Visible B0 Optimization

    Abstract

    EfficientNet scales width, repeated depth and input resolution together. We inspect released coefficients, verify all eight full parameter budgets, demonstrate per-row branch dropout and explicitly fit the complete B0 network with tensor Adam.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.4_efficient_and_mobile_architectures/efficientnet.cpp.

    The method

    Compound scaling balances depth, width and resolution rather than increasing only one axis. For a conceptual scale phi, d=alphaphi, w=betaphi and r=gamma^phi with approximate compute constraint alpha*beta²*gamma²≈2. The released B0-B7 table uses concrete coefficients; it is that table, rather than a newly searched optimum, that the code executes.

    Every B0 stage uses SE .25 with a reduction based on unexpanded input width, swish x*sigmoid(x), and an expansion-one or expansion-six mobile bottleneck. Widths round to multiples of eight, with at most ten percent rounding reduction; repeats ceil(depth*base_repeats). Stem and head widths also scale. A linear projection precedes any raw identity shortcut. The first-repeat stride downsamples each specified stage; repeated blocks use stride one.

    At zero-based block index i of n, matching training residuals drop with probability .2*i/n. The inverted surviving branch is multiplied by 1/p; inference uses the full branch. Head dropout comes from the released variant table. The mask fixture checks row sharing and input derivatives, including p=0 and p=1 endpoints. Branch filters/BN still execute, so dropout alone does not imply conditional-computation speedup. The B0 CIFAR model has 4020358 learned scalars and sixteen blocks.

    All eight FULL-WEIGHT models execute at 64 pixels for counts. Their exact target-resolution MAC budgets use ceil(resolution/downsampling_divisor) on each SAME map, not a global area ratio; SE/classifier work stays fixed. B0 additionally executes an actual 224-pixel forward. The larger models are not claimed to run at their large reference resolutions. A separate full B0 backward probe retains every channel/block at 64 pixels, freezes moving updates and disables branch dropout while retaining classifier dropout. Projection BN shifts may cancel through subsequent pointwise/BN paths, so every gradient must be finite but need not be nonzero.

    All model computation, image scaling, augmentation, losses and optimizer updates use tensors. Architecture strings, integer dimensions and plotted vectors are metadata. Convolutions use He-uniform initialization and TensorFlow SAME padding, BN epsilon 1e-3 with learned scale/shift, and a biased classifier. Training uses batch moments; inference uses saved moving moments. Dropout draws from the learned store's generator. The arithmetic log counts convolution, pooled SE and classifier products, excluding BN, pooling, activations, additions and memory traffic. One MAC is a multiply-accumulate pair, not measured latency or individual FLOPs.

    The bounded fit uses original 32×32 CIFAR-10 images, changes only the stem stride and class count, and retains every block and channel width. It shows 8 epochs (64 updates, kept short so the report builds quickly), batch eight, Adam(.001), explicit kernel L2=.0001/2 and independent padded crops/flips. Fixed subsets contain 64 fit, 32 validation and 32 official-test rows. The lowest validation NLL selects paired learned/BN checkpoints before test scoring. No accuracy threshold is imposed on this small single-seed experiment; it is not the published ImageNet training schedule or a latency search.

    Conclusion

    Released coefficients make compound scaling concrete, while tensor masks expose the stochastic residual rule. Complete counts, explicit target geometry and visible B0 fitting preserve the architecture and distinguish a bounded experiment from published benchmarks and runtime claims.
