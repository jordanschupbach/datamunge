    MobileNet v2: Expanded Features and Linear Bottlenecks

    Abstract

    Expanding before nonlinear filtering can preserve more information than clipping a narrow representation. We illustrate ReLU recovery on a spiral, check signed inverted residuals, verify full model budgets/gradients and explicitly fit all seventeen blocks with tensor Adam.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.4_efficient_and_mobile_architectures/mobilenet_v2.cpp.

    The method

    V2 expands a narrow Cin-channel map by t with a 1×1 BN/ReLU6, applies depthwise 3×3 BN/ReLU6, then projects linearly with 1×1 BN. Expansion is skipped at t=1. The shortcut adds the narrow input only for equal width and stride one; no activation gates the projection or sum.

    \[y=x+P\bigl(\operatorname{ReLU6}(D(\operatorname{ReLU6}(Ex)))\bigr).\]

    The spiral example projects two-dimensional points into wider random spaces, applies ReLU, then uses tensor least squares over active coordinates as an independent information-recovery oracle. It illustrates why clipping a narrow manifold can lose recoverable coordinates; it does not prove all learned expansions are injective, and least squares does not fit the classifier. A separate zero-projection fixture verifies exact signed identity and weighted input derivatives.

    The complete Table-2 architecture has seventeen inverted residuals in seven groups with counts 1/2/3/4/3/3/1. Channel widths align to eight, increased if rounding down loses more than 10%. The final 1280-channel width does not shrink for alpha<1. Global mean, training dropout .2 and a dense classifier finish the model. Full alpha-one has 3504872 learned and 34112 moving scalars; subtracting BN affine counts gives 3470760, explaining comparisons with tables that omit BN. Nine width/resolution MAC budgets are checked. The full-width backward probe shifts BN betas and separately checks seventeen projection BN shifts removed by downstream training normalization. It retains every block at 64-pixel synthetic inputs; classifier dropout is disabled for that probe.

    The CIFAR fit retains full width with 2236682 learned scalars and dropout retention .8. All model computations and fitting use the tensor library. BN learns scale/shift with epsilon .001; training uses batch moments and eager moving updates use unbiased variance. He-uniform fan-in initialization is an adaptation of the original release. Images stay at original 32×32 resolution; only the first stride changes to one, retaining every later block/downsampling. Fits use 128 fitting, 64 validation and 64 official-test images, six batch-eight epochs (96 updates, kept short for build time) of Adam(.001), explicit kernel L2=.0001/2 and independent padded crops/flips. Validation selects paired weights/moving moments before test evaluation. These tiny CPU fits differ from both the larger source runs and published ImageNet schedules. MAC counts are arithmetic budgets from measured output shapes, not latency.

    Conclusion

    Expanded nonlinear processing and an ungated narrow projection define the inverted residual. The recovery oracle, exact identity derivatives and full budgets explain those choices; explicit Adam fitting shows the complete classifier while keeping tiny-data limitations visible.
