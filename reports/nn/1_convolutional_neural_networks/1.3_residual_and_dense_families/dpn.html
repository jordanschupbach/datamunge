    Dual Path Networks: Shared Filters, Residual Sums and Dense Growth

    Abstract

    A network can both reuse a fixed representation and retain newly discovered features. Dual Path Networks split one shared bottleneck output between residual addition and dense concatenation. We verify their direct derivatives and ordered stage algebra, check all released preset counts, and train the complete compact DPN-92 with explicit tensor Adam updates.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.3_residual_and_dense_families/dpn.cpp.

    The method

    A unit joins residual R and dense D channels before a preactivated 1×1 / grouped 3×3 / 1×1 bottleneck. Its final filter emits r+i channels, split into updates uR and uD. An ordinary unit is

    \[R_{t+1}=R_t+u^R_t,\qquad D_{t+1}=\operatorname{concat}(D_t,u^D_t).\]

    Both updates depend on the joined input, so the learned paths are coupled through shared filters. Setting the final filter to zero isolates exact signed direct paths: R and old D remain unchanged, i zeros append, and the derivative of the summed output is one for every incoming scalar. The toy tests both input paths rather than assuming a residual-only shortcut.

    Each stage begins with a separate preactivated projection P(join(R,D)) to r+2i channels, which initializes R0 (r channels) and D0 (2i channels). The first unit then applies its learned updates too. After L units, residual width is r and dense width is (L+2)i. Residual values are R0 plus the ordered fold of all uR; dense values are concat(D0,uD1,...,uDL). The float32 reference uses the same addition order, because reassociation can change rounding. A controlled stride-two projection independently checks BN/ReLU, channel redistribution and input derivatives. Stage projections are not raw identities and can clip negative inputs.

    For joined width C, inner bottleneck b, groups G, residual width r and increment i, branch kernel weights are Cb+9b²/G+b(r+i); a stage projection adds C(r+2i). These also count MACs per spatial position at unchanged resolution. Different input/output grids matter at reductions. The grouped filter uses one HWIO tensor [3,3,b/G,b], with contiguous channel groups. Convolutions are bias-free with He-uniform initialization; learned-scale BN uses epsilon .001, eager moving-mean updates and unbiased moving variance. Final BN/ReLU, global mean and linear scores follow. There is no dropout or pretrained state.

    Released unit counts give depths 68/92/98/107/131 (three convolutions per unit plus stem and classifier, excluding stage projections). All five learned/moving scalar counts are checked on 64-pixel inputs because counts do not depend on image size. A separate full-width DPN-92 check at 224 pixels verifies joined widths 336/704/1552/2688 at 56/28/14/7 pixels. Backward and stage-algebra checks use a complete compact DPN-92, keeping all 3/4/20/3 units.

    The compact model uses quarter widths/increments, groups eight, a 3×3 stride-one stem and ten classes: 2474330 learned and 31304 moving scalars. Cardinality is explicit: the first inner width is 24, so retaining the full model's 32 groups would be invalid; eight preserves three channels per group. End-stage residual widths are 64/128/256/512 and dense widths 20/48/132/160.

    The CIFAR-10 fit shows all 8 epochs, batch-eight ordering, independent tensor crops/flips, Adam(.001), mean cross entropy and kernel L2=.0001/2. It uses 64 fitting, 32 validation and 32 official-test images, kept small so the fit runs in seconds. Validation selects paired parameter/moving-state checkpoints before the test pass. Pixels map to [-1,1]. Cached CIFAR-10 is required; this is a bounded CPU experiment.

    Conclusion

    A shared bottleneck supplies two different updates: a fixed-width residual sum and a growing, ordered dense representation. Stage projections initialize both paths and must be checked separately from ordinary direct-path identities. Exact fixtures, full counts, complete compact gradients and the visible Adam fit make the model's mathematics and state transitions reviewable.
