    ResNet Basic Blocks: Shortcuts, Post-Add Gates and Complete Depth

    Abstract

    Adding layers can make fitting harder even when a larger model could represent the desired mapping. Residual blocks add learned corrections to a shortcut path. We check the exact post-activation rule and dimension-changing projection, then train complete compact ResNet-18 and ResNet-34 models with visible tensor Adam loops and separate batch-normalisation state, scoring the full CIFAR-10 test set with GPU inference.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.3_residual_and_dense_families/resnet_basic.cpp.

    The method

    A basic block has two bias-free 3×3 convolutions. The first is followed by BN/ReLU; the second has BN without ReLU before addition. The shortcut is an identity only when channels and stride match; otherwise it is a bias-free 1×1 projection with BN. The block is

    \[y=\operatorname{ReLU}(F(x)+S(x)),\qquad J_y=\operatorname{diag}(F(x)+S(x)>0)(J_F+J_S).\]

    Even if F=0 and S is identity, the result is ReLU(x), which clips negative inputs and their derivatives. The toy sets the final branch BN gamma to zero so the residual is exactly zero. Its projection variant downsamples a 5×5×2 input to 3×3 and copies two channels into four. Projection BN gamma sqrt(1+epsilon) cancels inference variance one plus epsilon. A tensor slice-and-duplicate reference checks values and input derivatives, including stride alignment.

    ResNet-18 uses block counts 2/2/2/2; ResNet-34 uses 3/4/6/3. Learned depth is one stem convolution plus two per block plus one classifier; shortcut projections are not counted in that name. Reference stage widths are 64/128/256/512. The standard stem uses a 7×7 stride-two convolution with symmetric pad three, then 3×3 stride-two max-pooling with negative-infinity pad one. At 224 pixels, stem and stage sides are 56, then 56/28/14/7. These explicit edge conventions are not a bitwise Caffe compatibility claim. GAP feeds a linear 1000-class head. Learned/moving scalar counts are 11689512/9600 and 21797672/17024, respectively.

    At constant width C, two 3×3 branch kernels cost 18 C² weights and O(NHW 18 C²) MACs, plus BN and any projection. BN learns gamma/beta with epsilon 1e-5; its moving mean and unbiased EMA variance live in a separate store. No dropout or pretrained weights are used. Both canonical models check their shape and parameter inventories and finite nonzero gradients through every learned tensor.

    The CIFAR-10 fits retain all four stages with quarter-width channels and a 3×3 stride-one stem. A seeded holdout selects 12,000 fitting and 5,000 validation images from all five development files. Each model runs twelve epochs with batch size 128, Adam(.001), a .0001/2 kernel penalty, and independent crops and flips. The selected checkpoint includes parameters and BN moving moments. Both models score all 10,000 official test images after selection.

    Validation and test inference use the first CUDA device when the linked Datamunge supports it. The report records the device used and includes the same inference path on the CPU.

    Conclusion

    The shortcut adds a direct path, while post-add ReLU still gates signed signals. Projection shortcuts change both sampling and channel count. The canonical checks and the compact fits make those details visible. The saved moving moments are part of each selected checkpoint.
