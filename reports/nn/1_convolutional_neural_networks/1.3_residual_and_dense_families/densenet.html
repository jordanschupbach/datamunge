    DenseNet: Preserved Features, Growing Channels and Compressed Transitions

    Abstract

    A later convolution can reuse earlier evidence directly if those feature maps remain available. DenseNet concatenates old and newly computed channels instead of adding them. We verify feature order and direct derivatives, hand-check a compressed pooling transition, and fit a complete DenseNet-BC-40 using visible tensor Adam updates on cached CIFAR-10 images.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.3_residual_and_dense_families/densenet.cpp.

    The method

    A dense layer appends k channels: x_next=concat(x,F(BN/ReLU(x))). After L layers, width is C0+Lk, and every old feature remains verbatim in its original slice. A loss on that original slice has an exact identity derivative; losses on newly added channels also contribute indirect derivatives. When added features are zero, the derivative of the sum of all output channels is exactly one for each signed original scalar. The fixture verifies old/new ordering for four basic and four bottleneck layers, with widths 3,5,7,9,11.

    Without a bottleneck, each layer uses one preactivated 3×3 filter. DenseNet-B uses a preactivated 1×1 reduction to 4k channels, followed by preactivation and 3×3 filtering to k. The final filter has no output activation, so newly appended features can be signed. Summed kernel weights without bottlenecks are

    \[9k\sum_{l=0}^{L-1}(C_0+lk)=9k\left(LC_0+\frac{kL(L-1)}{2}\right).\]

    A bottleneck layer instead uses 4k Cin+36k² kernel weights, plus BN. A transition applies BN/ReLU, a bias-free 1×1 projection to floor(theta Cin), then VALID 2×2 average pooling. It compresses channels and halves spatial size. Positive inputs (a,2a) with weights (.25,.75) give 1.75a before pooling; a=1..16 on a 4×4 grid gives (6.125,9.625,20.125,23.625). Input derivatives of the summed pooled output are .0625 and .1875 for the two channels. Controlled BN gamma cancels its inference variance offset in this arithmetic fixture.

    The four-stage ImageNet BC-121 layout has 6/12/24/16 dense layers, growth 32, compression .5 and 7978856 learned scalars. CIFAR BC-100 has three 16-layer blocks, growth 12 and 769162 scalars. Their moving-state counts are 83648 and 23988. Stem width is 2k; ImageNet adds BN/ReLU/max-pooling after its 7×7 stride-two stem, while CIFAR uses a raw 3×3 stride-one stem. Final BN/ReLU, global mean and a linear classifier follow. Full forward shapes/counts and complete-depth growth-four parameter gradients are checked separately.

    BN learns gamma/beta with epsilon 1e-5. He-uniform initialization and eager unbiased-variance moving updates are adaptations. This model materializes every concatenation: retaining L successive maps costs O(NHW(LC0+kL²)) accumulated feature storage, before other backward buffers. It does not implement the release's shared-memory buffers or activation recomputation.

    The dataset fit uses CIFAR DenseNet-BC-40 k=12: three six-layer blocks, 4k bottlenecks, .5 compression, 176122 learned scalars and no dropout. It runs 8 epochs, batch eight, Adam(.001), explicit kernel L2=.0001/2 and independent tensor crops/flips on 128 fitting images, kept short so the fit runs in seconds. Validation uses 64 separate rows, selects paired parameter/moving-state checkpoints, and precedes one 64-row official-test evaluation. Cached CIFAR-10 is required. This short demonstration does not reproduce the paper's SGD schedule or establish a benchmark.

    Conclusion

    Concatenation retains existing features exactly and adds new signed channels. Bottlenecks control spatial-filter cost, and transitions control both channel width and spatial resolution. Ordering, derivatives, hand arithmetic, complete-depth checks and the explicit BC-40 subset fit provide separate evidence for those claims, with the eager memory cost stated directly.
