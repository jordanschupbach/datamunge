    Res2Net: Multi-Scale Features Inside One Bottleneck

    Abstract

    Res2Net chains channel splits inside a residual bottleneck to create multiple receptive fields. We check spatial values, derivatives and the special stage-entry path, verify the full ImageNet architecture, then explicitly fit all fifty layers at compact widths using tensor Adam.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.3_residual_and_dense_families/res2net.cpp.

    The method

    The original 26w/4s bottleneck reduces to s*d channels, where d=floor(planes*26/64), then splits them into s equal groups. Ordinary blocks apply a 3×3 BN/ReLU transform to the first group, then add each processed result into the next input group before its 3×3. The last split bypasses these filters. Concatenation and linear 1×1/BN expansion precede shortcut addition and ReLU.

    \[y_0=K_0(x_0),\qquad y_i=K_i(x_i+y_{i-1})\ (1\le i<s-1),\qquad y_{s-1}=x_{s-1}.\]

    With positive activations and uniform 3×3 kernels, centre-output derivatives from split zero have 3/5/7 side support in the first three processed groups; the last split has its own direct 1×1 derivative. Exact support, derivative mass and a separate scalar spatial recurrence are checked below. The recurrence is an independent numerical oracle; model computations remain tensor operations. These controlled linear receptive fields do not claim all trained units stay linear or activate every possible path.

    The first block of EVERY stage is special, including the stride-one first stage: processed splits are independent, without hierarchical additions; the last is padded 3×3 average pooling. Padding zeros remain in its divisor, giving 16/9 at a corner for a constant-four last split. Scale one retains one 3×3 filter without bypass. Ordinary blocks require stride one; stage entries permit stride two. This is the original release, without the later v1b modifications.

    Full Res2Net-50 uses 3/4/6/3 blocks, a 7×7/2 stem and padded max-pool, outer widths 256/512/1024/2048 and stage sides 56/28/14/7 at 224 pixels. It has 25699120 learned and 59492 moving scalars. BN learns scale/shift with epsilon 1e-5; He-uniform fan-in initialization replaces normal fan-out. The compact fit retains all sixteen blocks/fifty layers, quarter outer widths, a 3×3/1 stem and no initial pool. Split widths floor to 6/13/26/52; learned/moving counts are 1493062/14852. Complete compact backward checks reach every parameter tensor.

    Six batch-eight epochs (96 updates, kept short so the report runs quickly) use 128 fit/64 validation/64 official-test images, Adam(.001), explicit kernel L2=.0001/2 and independent padded crop/flip augmentation. Paired learned/moving-state checkpoints are selected solely by validation NLL before test evaluation. The visible loop uses the tensor library throughout. These bounded CIFAR fits differ from both the larger source-example run and published ImageNet experiments; they do not reproduce benchmark results.

    Conclusion

    Hierarchical split paths provide several spatial supports within one bottleneck. Stage-entry pooling and independence are essential exceptions. Visible derivatives, full counts and an explicit optimizer connect those details to a complete trainable tensor model.
