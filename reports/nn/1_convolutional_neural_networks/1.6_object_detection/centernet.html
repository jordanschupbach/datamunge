    CenterNet Gaussian centres and learned upsampling

    Abstract

    Verify Gaussian radii, maximum-combined heatmaps, centre collisions and analytic loss derivatives, then check the full learned-upsample graph and explicitly fit the complete compact source detector with paired BN checkpoints.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.6_object_detection/centernet.cpp.

    The method

    CenterNet detects objects as class heatmap centres with learned size and subpixel offsets. Size-adaptive Gaussians supervise peak location, while masked L1 supervises geometric attributes at retained centres.

    Adaptive Gaussian heatmaps and centre collisions

    CenterNet represents each object at floor(pixel centre/4) on a stride-four class heatmap, with height/width and subpixel dy/dx heads. The authors' radius formula takes the minimum of three quadratic expressions at overlap .7. This port preserves their code, including division by two in the second and third expressions. It floors the radius and uses sigma=(2*radius+1)/6 inside a finite square support. White pixels represent target1 and green pixels target0 in the heatmap figure. Same-class kernels combine by *maximum* and clip at image edges. Gaussian shoulders are negative targets with reduced penalty, not soft positive class labels.

    When several objects share a centre cell, this source keeps the largest area across classes, first truth on exact area ties. Only that winner draws a Gaussian; each discarded object counts as a collision. The fixture below checks a clipped radius-two kernel and three colliding objects.

    Every Gaussian pixel matches independent oracle, max error0.0000000000000000; radius(10,10)=2.733200530682. Two collisions retain class3 at row4,column5, size5/5, offset.25/.25.

    Penalty-reduced focal and masked L1 objective

    The heatmap loss uses sigmoid(-x)²*softplus(-x) at targets exactly one; other pixels use (1-target)^4*sigmoid(x)²*softplus(x). There is no RetinaNet alpha factor. Summed heatmap focal plus .1*size L1 + offset L1 divides by retained centres floored at one. L1 applies only at retained cells; background images still train heatmap negatives. The independent fixture checks every derivative, including the Gaussian .5 shoulder's factor of1/16.

    Heatmap/size/offset fixture loss1.037404014976; every analytic derivative error0.000000000000. Background heatmap loss0.519860385420 retains learning with exact zero size/offset derivatives.

    Full learned-upsample graph and compact fit

    The full ResNet18 CenterNet has 14,046,164 learned and 10,496 BN-state scalars. Three 4x4 stride-two transposed convolutions (256/128/64 channels) each have BN/ReLU. Independent 3x3/ReLU then1x1 heads predict 80 heatmaps, height/width and dy/dx. Head kernels use normal standard deviation .001, heatmap bias -2.19; encoder/deconvolutions use their source initialization. No pretrained weights are loaded. This full128-pixel backward verifies all81 learned tensor derivatives.

    Full CenterNet128: 14046164 learned/10496 state scalars,32x32x80 heatmap and all81 finite defined learned tensor derivatives. Initialized validation, not trained benchmark output.

    The complete compact source network uses ResNet18 with widths divided by eight, upsampling widths64/32/32 and hidden heads32: 319,862 learned and1,456 BN-state scalars. This report fits64-pixel scenes, an explicit smaller-scene adaptation. The split uses64 fit/16 validation scenes from the first2048 MNIST training digits(seed11), and eight test scenes from the first512 official test digits(seed22). Actual training pixels and boxes appear below.

    80 generated training/validation scenes; 195 accepted digits. Preview: first eight training scenes with tight green boxes.

    Every learned backbone, transposed-convolution and head parameter is warmed before Adam(.001), batch four,32 epochs and512 updates. The objective adds .00005*sum(kernel²); biases and normalization affines are fitted but excluded from kernel L2. Validation AP50 selects paired learned/BN state checkpoints, which are restored before test evaluation and checked against selected AP.

    Decoding keeps classwise3x3 local maxima; equal plateaus retain all tied maxima. The top100 scores strictly above .01 per image are chosen *before* rejecting nonpositive sizes or clipped zero-area boxes. Higher flattened heatmap index wins exact score ties. Centres/sizes convert to pixels with stride four. There is no box NMS. Native tests check these ordering choices and plateaus.

    Conclusion

    The executed results above describe the current selected checkpoint and its held-out detection quality. Small scene sets and bounded schedules do not establish architecture rankings. Inspect localization, missed targets and false positives together with validation selection and the actual prediction gallery.

    Independent Gaussian and objective oracles precede full-graph validation and explicit compact fitting. The selected learned and normalization state are restored together; actual held-out predictions illustrate this instructional run without claiming full-dataset accuracy.
