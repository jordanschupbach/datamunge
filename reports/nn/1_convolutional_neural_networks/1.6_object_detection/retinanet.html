    RetinaNet sigmoid focal loss and shared dense heads

    Abstract

    Verify tensor focal values and gradients, ignored-anchor matching and full RetinaNet graph structure, then fit and evaluate the complete compact source detector with a visible Adam loop and paired BN-state checkpoints.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.6_object_detection/retinanet.cpp.

    The method

    RetinaNet combines feature pyramids with shared class/box towers and focal modulation of dense foreground/background imbalance. Every class is an independent sigmoid channel, and moving backbone normalization state is part of the selected fitted model.

    Sigmoid focal modulation and gradients

    RetinaNet uses independent foreground sigmoid channels and no background column. With target y and p=sigmoid(x), the loss is alpha_t*(1-p_t)^gamma*BCE(x,y). Alpha is .25 for positives and .75 for negatives; gamma is two. Gamma zero recovers weighted BCE. The stable tensor expression uses Softplus for the modulator and BCE. Confident correctly classified examples may round to zero; incorrect logits at magnitude 80 remain finite. The following checks 42 values and central-difference gradients against an independent scalar oracle.

    42 focal values and central differences pass; maximum derivative error 0.000000000360. Curves are tensor evaluations, not a fitted model.

    Nine anchors per cell and ignored matches

    Each P3–P7 cell has three scales (1, cube-root 2, cube-root 4) and three height/width ratios (.5, 1, 2), ordered level, row, column, scale, ratio. Pixel strides are 8/16/32/64/128 and base sides double by level. Tensor powers can differ by one Float32 rounding unit from the source host cube root; the Float64 independent coordinate oracle checks every coordinate within 1e-12. Anchors are unclipped until decoding. Distinct forced matching gives every truth a different anchor even at low IoU, then adds IoU >.5 matches. Unmatched anchors with IoU >.4 are ignored; remaining anchors are background. Positive box coding uses unit variances. The loss is masked focal plus positive Smooth-L1 with beta 1/9, divided by batch positives floored at one. An empty positive set still trains background focal loss, unlike SSD hard-negative mining.

    Compact64: 774 anchors. Fixture IoUs1,10/22,0 give positive, ignored and background masks[1,0,0]/[1,0,1]. Equal x/y pixel scaling preserves anchor shapes.

    Full-weight architecture and compact fitting

    The full model uses feature-only ResNet50, a linear 256-channel FPN and shared four-layer classification/regression towers. P6 comes from original C5; P7 comes from ReLU(P6). Predictor/tower kernels use normal standard deviation .01 and classifier bias logit(.01). Full counts are 37,968,692 learned scalars and 53,120 BN-state scalars, with 76,725 anchors at 640 pixels. The source's 128-pixel full-weight backward check below computes all 195 learned tensor derivatives. It is an initialized graph check, without pretraining or fitting.

    Full-weight128-pixel graph: 37968692 learned scalars, 53120 state scalars, 3069 anchors and 195 defined finite learned tensor derivatives. At640 pixels, tensor anchors number76725. No fitted benchmark is claimed.

    The bounded fit uses 64 fit/16 validation scenes made from the first 2048 MNIST training digits, seed 11; eight test scenes use the first 512 official test digits, seed 22. The compact source network has ResNet18 with widths divided by eight, a 32-channel FPN and shared towers: 346,246 learned scalars plus 1,200 backbone BN-state scalars. This report uses 64-pixel scenes and base anchor side eight (the source's larger scene run uses 128 pixels/base16). It fits the entire network with explicit Adam(.001), batch four, 32 epochs, 512 updates and .00005*sum(kernel²). All leaves are warmed before constructing Adam. Biases/normalization affines are optimized but excluded from kernel L2. Validation AP50 selects paired learned-parameter and moving-state files.

    80 generated training/validation scenes; 195 accepted digits. Preview: first eight training scenes with tight green boxes.

    Inference considers every foreground sigmoid class, takes up to 200 scores strictly above .01 per image/class (higher anchor index wins score ties), uses unit box coding, clips to the image, removes zero-area boxes and applies class-wise IoU .5 NMS with at most 100 detections/image. Validation and test use moving BN state; the training forward updates it. Checkpoint restoration is verified by recomputing the selected validation metric.

    Conclusion

    The executed results above describe the current selected checkpoint and its held-out detection quality. Small scene sets and bounded schedules do not establish architecture rankings. Inspect localization, missed targets and false positives together with validation selection and the actual prediction gallery.

    The independent focal oracle, ignored-band fixture and full-weight backward check precede a bounded whole-network fit. Actual training scenes and restored held-out detections are saved locally. This is an instructional compact digit detector, not pretrained COCO accuracy.
