    YOLO v3 residual features and global three-scale assignment

    Abstract

    Verify exact independent-logistic loss derivatives, global prior/scale matching and full80/20-class graphs, then visibly fit the complete compact75-convolution model with multiscale Adam, paired BN checkpoints and actual digit scenes.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.6_object_detection/yolo_v3.cpp.

    The method

    YOLO v3 combines residual Darknet53 features with three top-down prediction scales. A target selects one prior globally; independent class/objectness logistic losses and area-weighted coordinates train all scales in one visible tensor optimization loop.

    The concept diagram below is drawn by dm::graphics::Diagram. Its editable C++ source is the complete block below; regeneration uses the same datamunge toolchain as the numerical examples. Exports consume the saved local SVG.

    Independent logistic classes and the exact three-head loss

    YOLO v3 uses independent class sigmoid logits instead of a per-anchor softmax. The stable elementwise loss is softplus(logit)-logit*target; its derivative at zero is .5-target. The fixture deliberately gives one anchor two positive class targets to verify independent labels. The actual digit-scene targets below remain single-label one-hot assignments.

    Coordinates are sigmoid cell offsets plus raw log prior-size ratios, with .5*squared_error*(2-relative_target_area) at positive anchors. Objectness BCE uses target1 on positives and a detached ignore mask. Class BCE sums all class channels on positives. All three heads sum before division by total batch positives, floored at one. Empty scenes still train background objectness.

    All four complete multi-label/coordinate/background/ignored fixtures pass across every head derivative; max error 0.000000000000. Fixtures isolate losses with equal1x1 grids; actual models double grids coarse to fine.

    Nine fit-only pixel priors and one global assignment

    Nine priors are clustered from all boxes in the64 fitting scenes only, using tensor IoU clustering. They are in *input-pixel* units at the base64-pixel scene size, unlike YOLO v2's grid-unit priors. Sorted by area, the smallest three belong to the fine stride8 head, middle three to stride16 and largest three to coarse stride32. Each truth chooses exactly one best prior globally, first on IoU ties, then its centre cell at that scale. Same-slot collisions keep the largest target area, first on ties.

    Unassigned predictions overlapping *any* truth at current decoded IoU>.5 are ignored for objectness, across every scale. Positives restore weight1. The source-compatible fixture assigns8/16/32-pixel objects once each to fine/middle/coarse heads and checks the resulting area weights. Fitting uses actual cached MNIST scenes, with no validation/test contribution to priors.

    Full residual/top-down graphs and compact widths

    Darknet53 stages contain1/2/8/8/4 residual units after padded stride-two convolutions. Three top-down routes use five alternating1x1/3x3 convolutions, then3x3/linear prediction heads. Reduced routes nearest-upsample and join finer backbone features. There are75 convolutions total, with BN/leaky-ReLU.1 on feature convolutions and biased linear prediction layers.

    The initialized full80/20-class models have61,949,149/61,626,049 learned scalars, 52,608 state scalars and222 learned tensor gradients each. Both full128-pixel backward probes execute below. No pretrained weights, COCO/VOC training or benchmark accuracy is implied. The complete compact10-class, width-divisor8, grayscale model has976,795 learned/6,576 state scalars and supports64/96/128px multiscale inputs without changing learned shapes.

    Full80-class YOLO v3: 61949149 learned/52608 state scalars, all222 finite defined tensor gradients at128px. Heads4/8/16, three priors each. Full20-class YOLO v3: 61626049 learned/52608 state scalars, all222 finite defined tensor gradients at128px. Heads4/8/16, three priors each.

    Actual scenes and visible multiscale Adam fitting

    The split uses64 fit/16 validation scenes from the first2048 official MNIST training digits(seed11), and eight test scenes from the first512 test digits (seed22). The actual first eight fitting scenes and boxes appear below. There is no frozen backbone, classifier pretraining or hidden training call.

    80 generated training/validation scenes; 195 accepted digits. Preview: first eight training scenes with tight green boxes.

    Every leaf is warmed before Adam(.001), then the visible loop performs32 epochs,batch4,512 updates. Input size cycles64/96/128 every10 updates by tensor bilinear resizing; current input size changes prior-relative geometry and target assignment. Loss adds explicit .00005*sum(kernel²); biases and BN affine parameters are optimized but excluded from that L2 term. Target construction uses detached outputs from the same raw forward, so BN updates only once per training batch. Validation/test remain64 pixels. Strict validation AP50 improvement saves/restores paired learned and moving-state checkpoints.

    All class channels and scales decode before class-wise IoU.45 NMS and a100/image cap. Scores are sigmoid(objectness)*sigmoid(class), strictly above.01. Sizes use exp(clipped raw log ratios,±10), and boxes clip to the image. The tensor native tests verify combined-level suppression, class/image separation and raw-candidate counts as well as empty-scene gradients and exact loss fixtures.

    Conclusion

    The computed results above describe the current executed experiment. Assess held-out errors, validation selection and the stated fitting budget together; these bounded instructional examples do not establish benchmark rankings.

    Independent objective/assignment fixtures precede full-graph checks and compact whole-model fitting. Fit-only priors, multiscale geometry and paired BN restoration are explicit, while actual held-out results and boxes retain errors without a benchmark claim.
