    LeNet-5: Sparse Connections, Learned Pooling and RBF Outputs

    Abstract

    A digit recogniser needs useful image features with few shared weights. LeNet-5 combines local convolutions, learned subsampling and a fixed-prototype readout. We preserve the original sparse C3 connections and parameter count, inspect absent-channel derivatives, and show the complete tensor Adam loop on original MNIST images.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.1_fundamentals/lenet5.cpp.

    The method

    The padded 32×32 input passes C1(6,5×5), learned S2, sparse C3(16,5×5), learned S4, C5(120,5×5) and F6(84). Every stage uses 1.7159 tanh(2x/3). S2 and S4 sum each 2×2 window, multiply by a learned channel scale and add a bias. C3 stores only the 60 connected input/output channel pairs from the paper, rather than masking a dense parameter tensor.

    \[\text{parameters}=156+12+1516+32+48120+10164=60000,\qquad z_k=-\|h-c_k\|^2.\]

    Disconnected C3 inputs have exactly zero derivative for that output map. The fixed 7×12 seven-segment prototypes used here are our own, not the original paper's digit art. Input pixels pad to 32×32 and map to [-.1,1.175]. Training uses sparse softmax cross entropy on negative distances with Adam and kernel L2, a modern adaptation rather than reproduction of the paper's loss and optimiser. The benchmark fits 55,000 rows for eight epochs, selects on 5,000 validation rows and evaluates all 10,000 official test rows. Sparse convolution work sums only connected pairs; parameter sparsity is preserved, while 16 small C3 calls need not minimise runtime.

    Executed architecture diagram

    The diagram below is generated by this model's forward function through nn::Module::plot. Each style runs a zero-valued shape probe in inference mode; it does not fit parameters or load a trained checkpoint. Shapes include the example batch, and learned-value counts deduplicate shared tensors. The flow and LeNet views use named composite blocks; the graph view shows functional layers and their actual branches. ModelPlotDetail::Operations expands both into tensor primitives. All views run left to right with node labels rotated 90 degrees counterclockwise. Colors identify layer categories and are explained by the legend. The settings below control fill/edge opacity, category colors, column/lane spacing, label content, font size and wrapping. Flow labels show full layer metadata; graph and LeNet labels show names and exact shapes. All three views use shared linear shape scales: face axes follow spatial dimensions, depth follows channel count, and vector height follows feature count. Batch size is excluded from geometry. A one-pixel visibility floor keeps very small dimensions visible; it is disclosed in each figure. The scales can instead use SquareRoot or Logarithmic compression explicitly. LeNet sheet counts and graph neuron markers are bounded samples; their envelopes follow the shape scales. Graph neuron bundles are drawn only for actual dense connections. Dots mark omitted units. Wide diagrams can be scrolled at native size on the website. Arrows follow the executed differentiable path; constants and deliberately detached paths are not expanded. The visual conventions are inspired by [VisualTorch's examples](https://visualtorch.readthedocs.io/en/latest/usage_examples/index.html).

    Conclusion

    The original sparse architecture has exactly 60000 learned scalars, and absent C3 inputs have zero derivative. The report distinguishes its fixed prototype art and Adam training adaptations from the original model and evaluates the selected checkpoint on the full official MNIST test split.
