    Depthwise Separable Convolution: Cost and Rank

    Abstract

    A dense spatial convolution mixes every input channel with every output channel at every tap. Factoring spatial filtering from channel mixing reduces cost while restricting the filters it can represent. We compose both factors into a dense tensor kernel and check forward values, gradients and the multiplier-dependent rank bound.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.1_fundamentals/depthwise_separable.cpp.

    The method

    For depthwise D[a,b,i,m] and pointwise P[iM+m,o], the equivalent dense filter is

    \[W[a,b,i,o]=\sum_{m=0}^{M-1}D[a,b,i,m]P[iM+m,o],\qquad \operatorname{rank}(W_i)\le M.\]

    A k×k dense layer has k² Cin Cout weights; depthwise plus pointwise has k² Cin M+Cin M Cout. The ratio is M/Cout+M/k², with the same multiply-count ratio per output site. This is a count, not a measured latency guarantee. The composition holds only without intervening nonlinearities or an intermediate bias. With M=1 each input channel shares a single spatial pattern across output channels; increasing M can recover higher ranks. Tensor matmul composes factors differentiably.

    Checking the theory

    A rank-two spatial/output target cannot be represented with multiplier one. Its second singular value gives the best possible rank-one residual in Frobenius norm.

    Rank reconstruction and CPU cost

    Truncating each input channel's spatial-by-output matrix to the retained singular directions gives the best approximation at that multiplier. The squared error comes from the discarded directions. The second experiment times equivalent dense and separable filters after warming up both code paths. The ratio of multiply-accumulates describes their arithmetic cost, while elapsed time depends on the implementation and machine.

    Conclusion

    The composed kernel and both factor gradients match the two-stage operator. The multiplier controls both cost and a precise expressivity limit; inserting a ReLU changes the function class and removes this single-linear-kernel equivalence.
