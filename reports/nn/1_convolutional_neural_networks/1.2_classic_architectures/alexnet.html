    AlexNet: Grouped Filters, Channel Normalisation and Dropout

    Abstract

    A convolutional classifier needs enough learned filters to describe images without making every layer prohibitively expensive. AlexNet combines grouped filters, rectified activations, overlapping pooling and dropout. We isolate its channel connectivity and normalisation, verify full reference geometry, then expose every tensor Adam update in a compact CIFAR-10 fit.

    Source example: examples/cpp/source/nn/1_convolutional_neural_networks/1.2_classic_architectures/alexnet.cpp.

    The method

    The five convolution widths are 96, 256, 384, 384 and 256. Layers 2, 4 and 5 use two groups: an output group reads only its contiguous half of the preceding channels. For a k×k kernel, G groups reduce kernel weights and MACs per output location from k² Cin Cout to k² Cin Cout/G; biases add Cout. This is a connectivity restriction, not simply a faster evaluation of an unrestricted dense kernel. The report compares separate-group convolution with the core grouped kernel, including every input and parameter derivative.

    Local response normalisation across channels is

    \[y_c=x_c\left(b+\alpha\sum_{j=\max(0,c-r)}^{\min(C-1,c+r)}x_j^2\right)^{-\beta}.\]

    The architecture uses r=2, b=2, alpha=.0001 and beta=.75: alpha multiplies a sum, with no window-width divisor. This follows the paper's constants; the BVLC deployment supplies 227-pixel geometry, not identical LRN defaults. A radius-one toy x=(1,2,3), b=2, alpha=.1 gives denominators (2.5,3.4,3.3), including clipped edge windows. Tensor matmul against a constant channel band implements the sum; its O(C²) band storage and O(numel(x)C) work are an explicit CPU adaptation, rather than a fused linear-time sliding-window kernel.

    The VALID 11×11 stride-four stem maps 227 to 55. Three overlapping VALID 3×3 stride-two pools give 27,13,6. SAME convolutions between pools preserve size. Two 4096-unit ReLU dense layers precede 1000 logits; the full model has 60965224 learned scalars. In training, inverted dropout retains half the hidden units and divides survivors by .5; inference uses every unit. He/Glorot initializers and the compact demonstration's Adam differ from the original recipe.

    The dataset experiment retains all five convolutions, three pools, groups, LRN and dropout, but uses 67-pixel bilinear resizing, quarter convolution widths and 256-unit dense layers. It fits 12,000 CIFAR-10 images for ten epochs with independent padded crops and flips, Adam(.001) and a .0001/2 kernel penalty. The minimum NLL on 5,000 separate validation images selects the checkpoint for evaluation on all 10,000 official test images.

    Conclusion

    Grouped convolution restricts channel dependencies; LRN couples neighbouring channel energies; dropout changes training evaluations while preserving deterministic inference. The canonical checks exercise every stage and learned tensor. The compact CIFAR-10 run measures how its validation-selected checkpoint classifies unseen images.
