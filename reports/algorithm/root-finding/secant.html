    Secant roots: actual proposals, queries and explicit failure stops

    Abstract

    Find a scalar root from two starting points using the secant line. Actual native callbacks distinguish evaluated candidates from failed proposals; the original x squared minus two experiment starts at one and two.

    Mechanism and mathematical scope

    Linear interpolation of the two retained function values gives

    \[x_{k+1}=x_k-f(x_k)\frac{x_k-x_{k-1}}{f(x_k)-f(x_{k-1})}.\]

    For a simple sufficiently regular root and suitable starting points the local convergence order is the golden ratio. This unbracketed iteration has no global guarantee. The implementation normalizes the residual pair before forming a widened proposal and reports horizontal denominators, arithmetic range, stagnation and budget exhaustion separately. Only an actual residual success sets converged.

    API and interpretation

    Both initial points are queried. Iterations now counts completed correction queries rather than a historical loop-index offset. A failed proposal retains the last queried point and matching residual. Nonfinite callback values reject; callback exceptions propagate.

    Reusable producers, fixtures and histories live in the canonical C++ library. Captured records own their values and do not come from a separate report replay. Selected counters and record/scalar policies are specified at their API boundaries; they are not peak-byte or wall-time budgets. Synthetic structural inputs are controlled fixtures for these mechanisms.
