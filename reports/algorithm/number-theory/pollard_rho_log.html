    Rho logarithms: actual invariant walks and collision congruences

    Abstract

    Study the actual native producer from a tiny, inspectable example through the retained original experiment and explicit boundary/work controls. Complete editable C++ programs own every rendered native figure.

    Mechanism and scope

    Each native cursor carries a group value and exponents satisfying value=ga hb. A Floyd iteration performs one tortoise update and two hare updates. With the exact base order, a collision gives a linear congruence. The native solver also accepts an annihilating multiple and then solves a stronger congruence, which can discard useful collisions. A nontrivial gcd may produce several candidates, each actually verified. The original base6 modulo104729 has order5512, while the supplied104728 is an annihilating multiple, so a verified exponent need not uniquely identify the original secret. The original six-prime first-collision study now uses the same native update kernel and reports completed iterations separately from its old zero-based index.

    \[g^a h^b=g^A h^B\quad\Longrightarrow\quad (a-A)\equiv x(B-b)\pmod{\mathrm{ord}(g)}.\]
