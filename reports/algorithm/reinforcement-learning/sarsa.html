    SARSA: actual behavior actions, on-policy targets and cliff returns

    Abstract

    Learn action values from sampled state-action-reward-state-action transitions. Native action and update histories expose the on-policy bootstrap; the original 4-by-12 cliff experiment compares SARSA and Q-learning using the same controls.

    Mechanism and mathematical scope

    For a nonterminal transition, sample the next epsilon-greedy behavior action before updating:

    \[Q(s,a)\leftarrow Q(s,a)+\alpha\{r+\gamma Q(s',a')-Q(s,a)\}.\]

    Terminal transitions use zero bootstrap. Q-learning instead uses the maximum next-state action value. Constant exploration makes cliff risk part of the behavior return. The original finite constant-rate, single-seed experiment illustrates this distinction without proving optimality or comparing statistically independent populations. Initial action selection occurs even with a zero-step episode; every nonterminal transition selects a next action, including the final capped transition.
