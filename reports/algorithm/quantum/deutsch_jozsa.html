    Deutsch–Jozsa: One Oracle Query, Visible Interference and the Promise

    Abstract

    A Boolean function on n input bits is promised to be constant or to return one on exactly half its inputs. We want to identify which case holds. Deutsch–Jozsa uses one logical quantum oracle application: equal phases reinforce the all-zero outcome, while a balanced set of signs cancels it. A two-bit worked example exposes actual gate-boundary amplitudes before retaining the original five four-bit examples. Native traces distinguish the mathematical promise from the legacy numerical threshold and demonstrate what happens outside the promise. Measured callback, gate and amplitude-pair counts show the exponential cost of this classical state-vector simulation. A sequential classical API supplies actual comparison counts; a query advantage on ideal quantum hardware does not make this C++ program a one-call classical algorithm.

    A hand-checkable four-input example

    Let the basis order be 00, 01, 10, 11: bit zero is the least significant qubit. Take f(x)=x mod 2, with truth table [0,1,0,1]. Starting at |00⟩, two Hadamard gates produce amplitudes [1/2,1/2,1/2,1/2]. The phase oracle changes them to [1/2,−1/2,1/2,−1/2]. The final two Hadamards leave amplitude one at |01⟩ and zero at |00⟩. Thus the all-zero measurement never occurs in the ideal circuit. The native diagram uses the actual trace, rather than a second oracle pass. Its one logical oracle stage entails four classical callback evaluations.

    Why the promise turns interference into a decision

    Write N=2^n and w for the number of inputs with f(x)=1. Applying the final Hadamards to each phase-marked basis state gives

    \[a_y=\frac1N\sum_{x=0}^{N-1}(-1)^{f(x)\oplus(x\cdot y)},\qquad a_0=\frac{N-2w}{N},\qquad P_0=\left(1-\frac{2w}{N}\right)^2.\]

    For a constant function w is zero or N, so a_0 is +1 or −1 and P_0=1. For a balanced function w=N/2, so a_0=P_0=0. The sign distinguishes the two constant state vectors but is a global phase; measuring the register cannot identify which constant was supplied. Nonzero measurement means balanced only under the promise. The implementation computes the distribution, rather than drawing a random shot. Its compatibility flag is the numerical test P_0>0.5, not a physical measurement or a certificate for an arbitrary function.

    A conventional reversible bit oracle acts as |x,b⟩→|x,b XOR f(x)⟩. Preparing its auxiliary qubit in |−⟩=(|0⟩−|1⟩)/√2 makes an output flip contribute the phase (−1)^f(x), leaving the auxiliary qubit separable. The C++ phase-oracle simulation omits that unchanged qubit. The one-query form follows the phase-kickback presentation of [Cleve, Ekert, Macchiavello and Mosca](https://arxiv.org/abs/quant-ph/9708016). Deutsch and Jozsa introduced the promised separation in 1992; the improved form was published by Cleve and colleagues in 1998.

    Preserve all five original four-bit oracles

    Constants zero and one, full parity, the top bit and the least significant bit are the original examples. The last three are balanced. Their final peaks are respectively basis indices 15, 8 and 1, but Deutsch–Jozsa only asks whether the index is zero. The independent fast Walsh transform already in datamunge provides an amplitude cross-check. Every numerical result below comes from the shared circuit kernel.     Outside the promise, the threshold has no promised meaning

    For an arbitrary truth table P_0 depends only on its number of ones; the remaining spectrum depends on their positions. With four bits and one one, P_0=49/64=0.765625, and the compatibility flag says constant despite the nonconstant table. With two bits and table [0,0,0,1], P_0=1/4, and the flag says false despite the table being unbalanced. Native trace promise categories identify both as neither. The classical API also relies on the promise: querying inputs 0 through 8 misses a four-bit function's lone one at input 15.

    Balanced functions need not be parities or concentrate at a single nonzero basis state. The piecewise function below uses the low bit on x<4 and the next bit on x≥4. Its truth table [0,1,0,1,0,0,1,1] is balanced, but its final distribution has four nonzero probabilities of one quarter each. The sweep then checks every possible number of ones on the four-bit domain.

    Query complexity and the cost of running this simulator

    For n≥1, a deterministic classical algorithm can be forced to receive the same answer at N/2 distinct inputs. Those observations are compatible with a constant function and with a balanced completion, so it needs another query in the worst case. N/2+1 queries suffice: two different outputs mean balanced, while N/2+1 equal outputs exclude balanced. The sequential API implements this rule. The top-bit control attains its bound exactly; low-bit parity instead stops after two queries. For n=0 the domain contains one input and only a constant case; both APIs call that input once.

    The ideal circuit uses one logical phase query and 2n single-qubit Hadamards, excluding oracle construction and measurement hardware. This classical simulator instead stores N complex amplitudes, makes N callback calls and executes 2n×N/2=nN amplitude-pair updates. Each callback's own cost is extra. The rich trace retains three actual states and one integer table: O(N) storage; the original API retains only its working state, also O(N). A full classical truth-table count could check the promise with N evaluations and O(1) extra storage, without simulating any circuit. The new trace's inspection of every callback value is likewise classical evidence, not an extra physical promise test obtained for free from a quantum measurement.

    A randomised classical comparison changes the conclusion. With k independent uniform queries with replacement, a balanced function produces all equal answers with probability 2×(1/2)k=2(1−k). Declaring balanced once two answers differ has no error on constant functions; ten queries give balanced-case error 1/512, independent of n. Therefore the exponential separation concerns exact deterministic classical query complexity, not bounded-error classical query complexity. It also assumes a coherent oracle is already available.

    Contracts and reproducibility

    The original two-field DeutschJozsaResult and its formatter remain unchanged. The ordinary function still returns p0>0.5 and the raw computed probability; it deliberately preserves the original effective bit f(x)&1 even for other integer outputs. Promise claims refer to those effective bits. Negative or unrepresentable qubit counts and empty callbacks now throw before evaluation; capacity checks protect allocations. The trace defaults to at most 1,048,576 basis states, with a checked complete cap before allocation or callbacks. Zero disables that optional cap but retains arithmetic and capacity guards. Memory allocation and oracle exceptions propagate, without undoing prior callback side effects. A physical oracle must be a fixed Boolean function: inspecting a stateful callback once only documents the table it actually produced.

    All four programs are complete and editable; figures are saved under local build/ and copied into figures/. No external dataset suits this promise problem, so the examples use explicit Boolean oracles. Independent tests check every one of the 65,814 Boolean tables with n=0 through 4 by direct character sums, including all 12,958 promised tables. Further checks cover every affine parity through eight bits, complements, a nonlinear balanced function, the shared Fourier circuit, original outputs, classical early and worst-case exits, caps, empty and throwing callbacks, ownership, low-bit compatibility and safe dimension validation. Numerical probabilities use double precision: “exact” describes the ideal decision under the promise, not exact floating arithmetic or a sampled hardware experiment.
