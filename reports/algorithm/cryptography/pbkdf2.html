    PBKDF2: actual HMAC chains and block XORs

    Abstract

    For each output block, U1 hashes salt followed by the one-based big-endian block index. Later U values hash the preceding32-byte U; their XOR forms that output block. The requested prefix is returned. The exact producing HMAC calls are counted, including every partial output block. Distinct salts alter these fixtures but cannot make a finite hash collision-free or add password entropy. Public tiny iteration counts are educational fixtures, not deployment settings. RFC8018 section5.2 defines the construction. No external dataset is needed.
