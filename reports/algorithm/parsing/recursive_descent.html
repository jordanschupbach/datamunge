    Recursive descent: actual grammar calls, evaluated nodes and source spans

    Abstract

    Arithmetic text must be grouped by precedence before its operators can be evaluated correctly. Recursive descent encodes that grouping directly in expr, term and factor functions. The native producer now records its actual completed syntax nodes and byte spans, replacing a hand-drawn tree unrelated to parser state. The original six expressions remain, together with complete-token, malformed-input and finite-arithmetic controls.

    Mechanism and mathematical scope

    The grammar separates additive and multiplicative precedence:

    \[E\to T((+\mid-)T)^*,\quad T\to F((*\mid/)F)^*,\quad F\to\mathrm{number}\mid(+\mid-)F\mid(E).\]

    Each nonterminal consumes exactly its grammatical prefix and returns its evaluated value. Binary loops fold left, so10-2-3 means(10-2)-3 and 8/4/2 means(8/4)/2. Prefix recursion binds signs at factor level; parentheses recursively invoke the full expression rule. Induction over the produced syntax tree proves that every stored node value matches its child operation.

    Actual nodes append in completion postorder, with real child ids and original source byte spans. Complete-input checking rejects a second decimal point or trailing token rather than silently accepting a numeric prefix. The grammar excludes exponents and power syntax. Runtime is linear in bytes plus actual grammar entries, with bounded recursion and optional linear retained tree storage. This parser is an evaluator for this explicit grammar, not a general left-recursive grammar parser.

    API and interpretation

    Number conversion uses locale-independent from_chars over exactly the scanned decimal token. Nonfinite conversion/arithmetic and division by zero reject; no NaN/Infinity is reported as an evaluated scalar. Embedded NUL never masquerades as end of the borrowed source. The produced tree owns its source and node values. Native measured tree layout validates source spans and tree shape, rather than reconstructing a guessed parse from text. A node child equal to SIZE_MAX means absent; that explicit sentinel is printed as an integer in the tiny table. The default 512 live-call bound protects ordinary nesting; callers may configure it explicitly.

    Reusable producers, fixtures and histories live in the canonical C++ library. Captured records own their values and do not come from a separate report replay. Selected counters and record/scalar policies are specified at their API boundaries; they are not peak-byte or wall-time budgets. Synthetic structural inputs are controlled fixtures for these mechanisms.
