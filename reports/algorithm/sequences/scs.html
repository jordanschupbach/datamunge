    Shortest common supersequences: actual LCS cells and reverse emissions

    Abstract

    Given two integer sequences, construct a shortest sequence containing both as subsequences. A two-by-two example makes the LCS table and native backtracking visible before the original fixtures.

    Mechanism and mathematical scope

    Let L(i,j) be the LCS length of the first i and j values. Its zero borders are zero. Matching values give L(i,j)=1+L(i-1,j-1); otherwise take max(L(i-1,j),L(i,j-1)). Matching tails emit once; an unequal tie emits from the first input. Each shared emission saves one position, so

    \[|SCS(A,B)|=|A|+|B|-L(n,m).\]

    Any supersequence aligns at most L common occurrences, giving the lower bound; the actual backtrack attains it. This full-table method takes O(n*m) time and storage, plus linear output. The displayed emission history is reverse order.

    API and interpretation

    An SCS need not be unique. The explicit first-input tie rule preserves historical ordering. Empty inputs work; table and optional retained-history bounds are separate. Full DP is deliberately retained rather than claiming Hirschberg linear storage.

    Reusable producers, fixtures and histories live in the canonical C++ library. Captured records own their values and do not come from a separate report replay. Selected counters and record/scalar policies are specified at their API boundaries; they are not peak-byte or wall-time budgets. Synthetic structural inputs are controlled fixtures for these mechanisms.
