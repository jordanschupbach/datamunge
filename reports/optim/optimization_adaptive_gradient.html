    Adaptive Gradient Methods: What the Accumulators Change

    Abstract

    A smooth objective can have very different curvature along different coordinates, so one global learning rate may either oscillate or make little progress. Adaptive gradient methods rescale coordinates using past gradients and updates. We derive this library's AdaGrad, RMSProp, AdaDelta, AMSGrad and Nadam variants, check their first steps on a scalar quadratic, and compare declared settings on isotropic and stiff bowls. A stability-boundary example shows why a returned value or a small objective change is not a stationarity certificate.

    The method

    Let \(g_t=\nabla f(x_t)\) be the full gradient at the current point. These are deterministic full-batch implementations, even though their histories arose in stochastic/online learning. A diagonal rescaling is not a rotation-invariant curvature solve. On a positive definite quadratic, gradient descent contracts an eigencomponent by 1-eta*h; convergence with a constant positive rate requires eta*h below two on every axis.

    For coordinate j, this implementation uses

    \[\begin{aligned} G_{tj}=G_{t-1,j}+g_{tj}^2,\quad x_{t+1,j}=x_{tj}-\eta g_{tj}/\sqrt{G_{tj}+\epsilon}\quad\text{(AdaGrad)}, \\V_{tj}=\rho V_{t-1,j}+(1-\rho)g_{tj}^2,\quad x_{t+1,j}=x_{tj}-\eta g_{tj}/(\sqrt{V_{tj}}+\epsilon)\quad\text{(RMSProp)}. \end{aligned}\]

    G never decreases, so its coordinate multiplier decreases. This does not prove that every actual update decreases: the current gradient also changes. RMSProp forgets old gradients and can keep moving or oscillating near the solution under a fixed rate. Epsilon's position and value matter in exact small-gradient checks.

    AdaDelta also averages squared updates, starting both histories at zero:

    \[\Delta x_{tj}=-\frac{\sqrt{D_{t-1,j}+\epsilon}}{\sqrt{V_{tj}+\epsilon}}g_{tj}, \qquad D_{tj}=\rho D_{t-1,j}+(1-\rho)(\Delta x_{tj})^2.\]

    There is no separate global step-size field, but rho, epsilon, starting scale and the objective still matter. With constant curvature, epsilon supplies the initial update scale; removing a learning-rate field does not make tuning irrelevant.

    AMSGrad keeps m_t=beta1*m_previous+(1-beta1)*g_t and the analogous squared average v_t. This code takes the maximum of uncorrected second moments, then bias-corrects:

    \[M_t=\max(M_{t-1},v_t),\quad \widehat m_t=m_t/(1-\beta_1^t),\quad x_{t+1}=x_t-\eta\widehat m_t/(\sqrt{M_t/(1-\beta_2^t)}+\epsilon).\]

    M is nondecreasing, but M/(1-beta2t) need not be. This bias-corrected variant must not inherit the original paper's convergence theorem without checking its assumptions. A successful quadratic run is not a test of the published Adam counterexample. Nadam here uses fixed beta values rather than Dozat's scheduled momentum products: replace the corrected first-moment direction by beta1*m_t/(1-beta1t)+(1-beta1)*g_t/(1-beta1^t), with Adam's corrected second moment. All five methods test the gradient they just used after applying their update. Their supplied callbacks must have finite, matching coordinate dimensions. Work per step is O(p) beyond the gradient cost, with O(p) persistent local state; every optimize call starts that state from zero.

    Small worked example

    Two AdaGrad steps are enough to check the accumulator

    Use \(f(x)=x^2\), initial \(x=2\), \(\eta=.5\) and \(\epsilon=.01\). The first gradient is four, G_1=16, and x_1=2-2/sqrt(16.01). The next gradient is 2*x_1 and its square is added to the same accumulator; a second optimize call would reset that history.     An objective-change stopping rule can stop at an oscillation

    For f=100*x squared, one plain gradient step multiplies x by 1-200*eta. At eta=.01, x=one becomes minus one, with exactly the same loss and a gradient of magnitude 200. GradientDescent's small-objective-change test therefore returns after this first update. At eta=.011 the factor is -1.2, so repeated steps grow rather than converge. Smaller declared rates contract.     Conclusions and references

    The scalar example checks the accumulator and epsilon convention directly. The two bowls test specific settings, not general superiority, and the stability boundary supplies an exact counterexample to equating objective-change stopping with stationarity. The AMSGrad and Nadam formulas above name the implemented variants explicitly; no stochastic convergence theorem is inferred from these runs.

    • J. Duchi, E. Hazan and Y. Singer (2011), [Adaptive Subgradient Methods for Online Learning and Stochastic Optimization](https://jmlr.org/papers/v12/duchi11a.html), JMLR 12, 2121–2159.
    • G. Hinton (2012), [Neural Networks for Machine Learning, lecture 6e](https://www.cs.utoronto.ca/~hinton/coursera_lectures.html), RMSProp.
    • M. Zeiler (2012), [ADADELTA: An Adaptive Learning Rate Method](https://arxiv.org/abs/1212.5701).
    • S. Reddi, S. Kale and S. Kumar (2018), [On the Convergence of Adam and Beyond](https://openreview.net/forum?id=ryQu7f-RZ).
    • T. Dozat (2016), [Incorporating Nesterov Momentum into Adam](https://openreview.net/pdf?id=OM0jvwB8jIp57ZJjtNEZ).

    Reading the numerical evidence

    trace_optimize calls the configured native optimizer through its stated abstract interface. It records callback requests without inserting fitting evaluations. Value calls can be rejected trials; gradient calls can be look-ahead points. optimization_comparison explicitly re-evaluates selected points afterwards on these pure objectives. Those diagnostic calls are excluded from fitting counts. Callback indices are neither accepted iterations nor wall time. The plotted gap uses the declared reference (minimum or stated lower bound) and a display floor of 1e-14; that floor does not modify any optimizer update. Returned coordinates, checked objective and appropriate stationarity/feasibility checks carry more information than a return from a finite iteration budget. Native APIs do not expose a uniform stop-status flag. The recorder retains exceptions and rejects nonfinite requested values/gradients; this makes failures visible rather than letting an instrumented run continue on NaN.
