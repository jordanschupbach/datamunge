    Levenberg–Marquardt: Residuals, Damping and Stopping

    Abstract

    A nonlinear model is fit by reducing residuals between observations and model predictions. Linearising those residuals gives a useful local step, but weak curvature or a poor starting point can make an undamped update unreliable. We derive the library's Levenberg–Marquardt rule, check an exact rank-deficient linear control, and fit the original noisy offset-exponential and logistic curves. A deliberately overdamped run shows that a tiny proposed step need not imply stationarity.

    The method

    Let r(theta)=model(theta)-y and F=.5*sum(r squared). Its gradient is J transpose r. Linearise r(theta+s) approximately by r+J*s and add a quadratic step penalty:

    \[\min_s\ \tfrac12\|r+Js\|^2+\tfrac\mu2\|s\|^2, \qquad (J^TJ+\mu I)s=-J^Tr.\]

    For positive mu the mathematical matrix is positive definite even when J is rank deficient. This implementation solves its dense normal equations by unpivoted elimination, rather than a QR/SVD least-squares solve. Conditioning of J transpose J is therefore a practical limitation. Work per step is O(n*p squared+p cubed), with O(n*p+p squared) dense storage. Parameter positivity and box constraints are not imposed by this solver.

    The native rule accepts only strict loss reductions, multiplies damping by .3 on acceptance and by ten on rejection, then tests the proposed step norm against tolerance. A tiny rejected step can terminate with a nonzero J transpose r. This is not a full model-agreement trust-region rule. The recorder retains every residual request, including rejected candidates; these are not accepted iterations. Final half SSE and a separate J-transpose-r norm are checked after fitting.

    Small worked example

    A constant curve supplies an exact damped step

    Use two observations at t=zero, y=(1,3), and the two-parameter exponential model A*exp(-k*t). The data identify A but not k: J has rows (1,0). Starting at (0,0), r=(-1,-3), J transpose r=(-4,0), and J transpose J=diag(2,0). With damping one, the step is (4/3,0), accepted because F falls from five to 13/9. The optimum has A=two, F=one, with arbitrary k. This explicitly separates a well-defined damped solve from identification of every parameter.

    Noisy curve fits

    Offset-exponential decay: preserve the declared generating model

    Use 40 points t=.25*i, y=5*exp(-.7*t)+one plus normal noise SD .1, seed 42. The native data recipe owns a local mt19937_64; standard normal distribution implementations can differ across platforms. The parameter order is (A,k,c), with residual A*exp(-k*t)+c-y and Jacobian row (exp(-k*t),-A*t*exp(-k*t),one). Start at (1,.1,0), use default damping and a 200-step budget, and check the analytic Jacobian separately using scale-aware central differences. That check has truncation and rounding error; it is not the derivative used by the optimizer. Known generating parameters describe the simulation, not the exact optimum of a noisy sample. Training RMSE or small gradient does not certify model adequacy or out-of-sample prediction uncertainty.

    Logistic growth: a different residual geometry

    Use 50 points t=.2*i, true (L,k,mid)=(10,1.5,5), normal noise SD .15 and seed 43. For p=logistic(k*(t-mid)), the Jacobian row is (p,L*(t-mid)*p*(1-p),-L*k*p*(1-p)). Stable logistic evaluation prevents avoidable exponential overflow in the inverse link, but does not solve parameter-identifiability or local-optimum problems. The deliberately poor start remains (1,.1,0). The same half-SSE convention, proposed-step caveat and independent derivative checks apply. No real dataset is forced: the original generated curves provide known means and exact derivative formulas for checking this optimizer.

    A tiny rejected proposal is not a stationarity certificate

    Return to the constant-curve control and compare initial damping .001, one and 1e20. At 1e20, the first amplitude proposal is only about 4e-20. Its loss rounds to the unchanged value five, so the strict-decrease test rejects it; the tiny-step test then ends the solve. The returned amplitude stays zero and J transpose r has norm four. This is an exact mechanism for premature stopping under excessive damping, rather than evidence that the residuals were minimised.

    Conclusions and references

    The linear control checks the sign, half-SSE convention and damping matrix exactly. Analytic Jacobian checks accompany the two original noisy curve families. The large-damping counterexample separates proposed-step stopping from stationarity. Normal equations, unconstrained parameters, local starts and the absence of a model-ratio acceptance rule qualify this compact implementation; fitting a curve does not supply predictive confidence intervals.

    • K. Levenberg (1944), [A Method for the Solution of Certain Non-Linear Problems in Least Squares](https://doi.org/10.1090/qam/10666).
    • D. W. Marquardt (1963), [An Algorithm for Least-Squares Estimation of Nonlinear Parameters](https://doi.org/10.1137/0111030).

    Reading the numerical evidence

    trace_optimize calls the configured native optimizer through its stated abstract interface. It records callback requests without inserting fitting evaluations. Value calls can be rejected trials; gradient calls can be look-ahead points. optimization_comparison explicitly re-evaluates selected points afterwards on these pure objectives. Those diagnostic calls are excluded from fitting counts. Callback indices are neither accepted iterations nor wall time. The plotted gap uses the declared reference (minimum or stated lower bound) and a display floor of 1e-14; that floor does not modify any optimizer update. Returned coordinates, checked objective and appropriate stationarity/feasibility checks carry more information than a return from a finite iteration budget. Native APIs do not expose a uniform stop-status flag. The recorder retains exceptions and rejects nonfinite requested values/gradients; this makes failures visible rather than letting an instrumented run continue on NaN.
