    Polynomial

    class Polynomial
    #include <datamunge/algebra/polynomial.hpp> source

    Dense univariate polynomial over the reals, stored as coefficients in ascending degree order (coefficients()[i] is the coefficient of x^i). Always kept trimmed – no trailing (highest-degree) zero coefficients, except for the zero polynomial itself, which is stored as the single coefficient {0.0}.

    to_tex

    #source
    Tex to_tex(const std::string & variable = "x", int precision = 7) const

    Render this polynomial in descending powers as a composable C++ Tex value.

    Omits zero terms and unit coefficients of nonconstant terms, groups powers, and prints conventional signs. Coefficients use locale-independent decimal/scientific notation; infinity and NaN have explicit math commands. Returns owned source without math-mode delimiters, leaving coefficients unchanged. Serialization may run concurrently.

    Parameters
    variable

    Raw TeX symbol for the formal variable, default "x"; e.g. "h" or "\\theta". Must not be empty; supply one math atom rather than a sum.

    precision

    Significant decimal digits, default 7; from 1 to double's max_digits10.

    Returns

    Owned Tex fragment supporting annotations, display() and inline_math().

    Throws
    std::invalid_argument

    For an empty variable or unsupported precision.

    Example
    const dm::algebra::Polynomial p({-1, 0, 1});
std::print("{}\n", p.to_tex().display());
std::print("{}\n", p.to_tex("h").underbrace("p(h)"));
