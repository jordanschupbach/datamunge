    class datamunge::algebra

    Expr

    class Expr
    #include <datamunge/algebra/expression.hpp> source

    A symbolic expression tree over +, -, *, /, ^ (power) and sin/cos/exp/log, supporting symbolic differentiation, basic algebraic simplification, and numeric evaluation. Value type wrapping a shared, immutable node tree – copies are cheap and structural sharing across copies is always safe since nodes are never mutated after construction.

Supports: the sum/difference and constant-multiple rules; the power rule x^c (any real c != -1) and its log special case (c == -1); sin/cos/exp/log of any expression that is affine (a*var + b) in var, via the standard substitution result for each; a constant divided by an affine expression (reduces to the log rule); and, for a product of two var-dependent factors, generic tabular integration by parts – reusing differentiate() to peel one factor down to the constant 0 across at most 15 repeated derivatives (terminates for any genuine polynomial factor), paired with repeated antiderivatives of the other factor.     #source
    Expr(double value)

    Construct a symbolic constant from a C++ numeric value, including implicit conversion.

    Numeric arguments convert to double, matching constant(); integers larger than double's exact integer range may round. Infinity and NaN are accepted. The new immutable node owns its value. Enables literals on either side of expression operators and assignment such as Expr f = 1. Does not add a conversion from Expr back to a number; use evaluate().

    Parameters
    value

    Numeric constant, stored as a double without evaluation or simplification.

    Throws
    std::bad_alloc

    If the constant node cannot be allocated.

    Example
    dm::algebra::Expr value = 2.5;
std::print("{}\n", value.evaluate({}, {})); // 2.5

    integrate

    #source
    Expr integrate(const std::string & var) const

    The symbolic antiderivative with respect to var (any other variable name is treated as a constant, matching differentiate()). Supports: the sum/difference and constant-multiple rules; the power rule x^c (any real c != -1) and its log special case (c == -1); sin/cos/exp/log of any expression that is affine (a*var + b) in var, via the standard substitution result for each; a constant divided by an affine expression (reduces to the log rule); and, for a product of two var-dependent factors, generic tabular integration by parts – reusing differentiate() to peel one factor down to the constant 0 across at most 15 repeated derivatives (terminates for any genuine polynomial factor), paired with repeated antiderivatives of the other factor. Not a full computer-algebra integrator: general rational functions (a non-constant denominator that isn't affine), a variable exponent, and products/quotients outside the forms above (e.g. sin(x)*cos(x), which never reduces to zero under repeated differentiation) are not attempted.

    Throws
    std::invalid_argument

    when no rule above applies.

    to_tex

    #source
    Tex to_tex(int precision = 7) const

    Render this symbolic expression as a composable C++ Tex value.

    Preserves the tree's operations without evaluating or simplifying it. Products use cdot, quotients use frac, powers group their full exponents and ambiguous bases, and sin/cos/exp/log use named math operators with sized parentheses. Single ASCII letter names are math symbols; all other logical variable names are escaped literally with Tex::text(). Constants use a locale-independent decimal point, integer scientific exponents, and explicit infinity/NaN commands; signed zero prints as 0. The result owns its source, has no math-mode delimiters and supports Tex chaining. Read-only serialization may run concurrently and does not mutate shared tree nodes.

    Parameters
    precision

    Significant decimal digits, default 7; from 1 to double's max_digits10.

    Returns

    Owned Tex fragment; call display() or inline_math() to insert it in a report.

    Throws
    std::invalid_argument

    If precision is outside the supported range.

    Example
    const auto x = dm::algebra::Expr::variable("x");
const auto f = x ^ 3;
std::print("{}\n", f.differentiate("x").simplify().to_tex().underbrace("f'(x)").display());
