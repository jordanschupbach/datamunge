    function datamunge::datasets

    data_home

    #include <datamunge/datasets/download.hpp>
    #source
    std::string data_home()

    The cache root where downloaded datasets are stored.

    The first of: $DATAMUNGE_DATA_DIR; $XDG_CACHE_HOME/datamunge/datasets; $HOME/.cache/datamunge/datasets; on Windows LOCALAPPDATA%/datamunge/datasets; otherwise build/datasets relative to the working directory. Nothing is created.

    Returns

    The directory path (it may not exist yet).

    Example
    std::print("{}\n", dm::datasets::data_home());   // e.g. /home/me/.cache/datamunge/datasets
