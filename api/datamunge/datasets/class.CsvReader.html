    class datamunge::datasets

    CsvReader

    class CsvReader
    #include <datamunge/datasets/csv.hpp> source

    Streams a CSV file as DataFrames of at most batch_size() rows each.

    Only the current chunk is ever in memory, so files larger than RAM can be processed. Column types are decided once, at construction, from the first CsvOptions::infer_rows data rows, so every chunk has the same columns and types. A later cell that does not fit its numeric column throws; list such columns in CsvOptions::string_columns.

    Not thread-safe: one reader holds one open file position.

    Example
    dm::datasets::CsvReader reader(dm::datasets::fetch("diamonds"), 5000);
double total = 0;
while (reader.has_next()) {
  const auto chunk = reader.next();               // <= 5000 rows
  for (double price : chunk.get_column("price").values()) total += price;
}
reader.reset();                                    // start again from the first row
