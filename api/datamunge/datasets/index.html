    datamunge/datasets/gaussian_blobs.hpp

    Classes

    GaussianBlobsOwned numeric features and zero-based centre labels for Gaussian clouds. Rows are grouped by centre, then draw order; coordinates are unscaled. Copies are independent. The generator stores no references to centres or shared RNG state.

    Functions

    gaussian_blobs()Generate equally sized isotropic Gaussian clouds with a local seeded RNG. Each coordinate is centre plus an independent normal draw of standard deviation sd, in centre/row/coordinate order. Uses mt19937_64 and normal_distribution<double>; same-toolchain repeats are identical, but normal draws may differ across standard libraries. At sd zero, centres repeat exactly without draws. Empty centres or zero rows return empty arrays after validation. Nonempty centres must have equal positive dimension and finite values. Inputs are unchanged; owned result has O(k*n*d) work and storage for k centres, n rows per centre and d coordinates. No shared state.

    datamunge/datasets/generators.hpp

    Functions

    circle()Points uniform on \([-1,1]^d\), class "1" inside the centred ball that fills half the cube and "2" outside (R's mlbench.circle), each label flipped with probability flip.
    ringnorm()Breiman's ringnorm benchmark: class "1" is \(N(0,4I)\), class "2" is \(N(a\mathbf 1,I)\) with \(a=1/\sqrt d\) (R's mlbench.ringnorm).
    swiss_roll() ×2Points on a Swiss roll: a rectangle rolled into a spiral in 3-D, as scikit-learn's make_swiss_roll().
    threenorm()Breiman's threenorm benchmark: class "1" is an equal mixture of \(N(a\mathbf 1,I)\) and \(N(-a\mathbf 1,I)\), class "2" is \(N((a,-a,a,\dots),I)\), with \(a=2/\sqrt d\) (R's mlbench.threenorm).
    twonorm()Breiman's twonorm benchmark: two Gaussian classes with identity covariance and means \(\pm a\mathbf 1\), \(a=2/\sqrt d\) (R's mlbench.twonorm).

    datamunge/datasets/network_data.hpp

    Classes

    GMLGraphAn owned graph topology with explicit original-to-native vertex mapping. node_ids are ascending unique original signed decimal ids; native index i corresponds to node_ids[i]. edges preserve input order, direction, loops and multiplicity. directed records graph metadata, default false. Weights, labels, layout and other attributes are skipped: this is a topology reader, not a weighted/labeled GML round trip. Copies own all vectors independently.

    Functions

    karate_club()Fetch and read the original unweighted Zachary karate-club topology.
    read_gml_graph()Read bounded GML node/edge topology with an owned zero-based mapping.

    datamunge/datasets/translated_grid_2d.hpp

    Functions

    translated_grid_2d()Replicate a two-dimensional rectangular grid about each supplied centre. Rows are ordered by centre, grid row, then grid column. Coordinate formulas are centre[0]+x_step*column+x_offset and centre[1]+y_step*row+y_offset, evaluated in double. Negative/zero steps are allowed. This is a deterministic lattice, not a Gaussian sample. Empty centres or a zero axis count return empty after validation. Inputs are borrowed/unchanged; owned output uses O(k*rows*columns) work/storage, with no RNG or shared state. Generated nonfinite coordinates throw.
