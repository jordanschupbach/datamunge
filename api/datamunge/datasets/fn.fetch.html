    function datamunge::datasets

    fetch

    #include <datamunge/datasets/download.hpp>
    #source
    std::string fetch(const std::string & name, const std::string & directory = "")

    Makes sure a downloadable dataset is on disk and returns where it is.

    For the tabular datasets ("diamonds", "california_housing") this is the CSV file. For the image datasets it is a directory: "mnist" and "fashion_mnist" hold the four uncompressed IDX files (train-images-idx3-ubyte, ...); "cifar10" holds data_batch_1..5.bin and test_batch.bin; "cifar100" holds train.bin and test.bin (the binary versions); "sudoku" holds Norvig's easy50.txt, top95.txt and hardest.txt. "karate_club" holds the970-byte original ZIP, GML topology and source README; every cached archive/member is checksum-verified. karate_club() reads34nodes/78edges. "rebot_devarm" holds 38 pinned Seeed DevArm CAD/URDF/STL files and the CERN-OHL-W-2.0 source license in their upstream relative directory layout. DevArm verifies the size and SHA-256 of every cached file on every call; changed files throw without replacement. Missing files are staged and verified before publication. It uses the same offline/mirror/cache controls, and works without the optional native data-preparation dependencies. Hashing uses memory proportional to the largest source file (about 35 MB). Approximate download sizes: diamonds 2.7 MB, california_housing 1.4 MB, MNIST 11 MB, Fashion-MNIST 30 MB, CIFAR-10 163 MB, CIFAR-100 161 MB, sudoku 14 KB, DevArm 56 MB.

    Parameters
    name

    One of downloadable().

    directory

    Where the files live; empty means data_home() + "/" + name. Files already present there are used as they are, except DevArm and karate_club's verified files.

    Returns

    The local path of the CSV file or the dataset directory.

    Throws
    std::invalid_argument

    for an unknown name.

    std::runtime_error

    if files are missing and downloading is disabled or fails, or a download does not match its checksum.

    Example
    const auto housing = dm::datasets::read_csv(dm::datasets::fetch("california_housing"));

    For a complete CAD asset tree, use dm::datasets::fetch("rebot_devarm").
