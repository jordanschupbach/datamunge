    function datamunge::datasets

    prepare_example_data

    #include <datamunge/datasets/assets.hpp>
    #source
    std::string prepare_example_data(
    const std::string & name,
    const std::string & directory = "")

    Prepare original-source datasets or explicit local teaching fixtures through the native library.

    Accepted names: autorec, audio, depth, flowers, medical, mesh, multilabel, ocr, optical_flow, pose, signals, style, text, two_stream, video, voxel, memory, mnist-assets, beta-vae-assets, sequence-vae-assets, inception-metric, character_rnn, ptb_word, bilstm_tagging, imdb_lstm and image_gpt. Uses the original pinned sources and deterministic record selections of the executable reports. Produces NPZ arrays plus provenance JSON/TSV files. AutoRec uses checksummed MovieLens100K, users/items1..256 and199 warm users; native seed4601 partitions observed ratings8079/898/898. Its manifest explicitly distinguishes this canonical partition from unavailable external preparation archives. Existing completed native preparations are reused; missing outputs are rebuilt. Archive downloads honor the same offline/mirror controls as fetch_file(). Video uses ffmpeg on PATH for codec decoding only; curl is needed for downloads. Calls for the same cache are serialized. Errors propagate, never generating substitute data. beta-vae-assets explicitly generates the original 294 binary circle/square teaching images with known factors, compositional splits and ascending source IDs; it is procedural data, not a downloaded benchmark. sequence-vae-assets enumerates the repository's 432 unique six-factor sentences: 288 fit, 72 validation, 72 test, ordered by source ID. Its sequence_vae/ directory contains sentences.npz (sixteen Int32 arrays), vocabulary.txt (PAD0/BOS1/EOS2 and sixteen words) and manifest.json. Targets have seven steps with EOS-inclusive lengths six or seven; decoder inputs are BOS followed by the previous target. Held-out combinations use residue=2*((colour+shape+adverb)%3)+(article+verb+direction)%2: test0, validation1, fit2..5. This is local procedural teaching data. Existing supplied sentence archives are preserved, without schema validation; a missing vocabulary is supplied and a missing manifest records unverified caller provenance. Reports must validate supplied arrays before using them. Independent framework reference fixtures are test artifacts, not downloaded or regenerated by this data API. nn-completion-assets creates versioned, explicitly reconstructed teaching recipes in family subdirectories. It preserves documented model shapes/budgets but does not claim missing original partitions or TF recordings. Sources include authenticated CIFAR/MNIST, original character/CoNLL/MR pools, pinned sunspots, UCI PenDigits and PyTorch tutorial English/French sentences. It also converts real authenticated Google Small BERT Float32 SafeTensors to native44-array NPZ, without Python. Training/checkpoint generation remains caller-owned editable report code.

    Recovered text/pixel adapters preserve the original tflow_examples preparation recipes: tinyShakespeare90/5/5 partitions and65-character fit alphabet; canonical PTB files with full training vocabulary; complete short CoNLL sentences with training-only POS ontology and fit-only words; balanced original Keras IMDB prefixes; and fit-only CIFAR K16 palette fitting. Inputs are hash-verified; legacy IMDB object arrays use a bounded integer-list decoder without executing Python/pickle callables. Native NPZ byte-valued arrays use Int32 tensors without changing their numeric values.

    Parameters
    name

    Dataset adapter name from the list above.

    directory

    Explicit dataset cache directory. Empty selects the conventional cache below data_home(): e.g. flowers102, modelnet, style_transfer or action_video. For signals, text, memory, mnist-assets, beta-vae-assets and sequence-vae-assets, the directory is their shared parent; an empty value selects data_home() itself. inception-metric instead selects data_home()/inception_metric and downloads the original inception-2015-12-05.tgz from TensorFlow's official archive. Retains the source archive, unmodified95,673,916-byte classify_image_graph_def.pb, original LICENSE and provenance manifest. Both archive and graph have pinned SHA-256/size checks; completed graph caches are rehashed on every call. No weights/features are synthesized or converted; no TensorFlow runtime is used. Native FrozenGraph executes the supplied ExpandDims:0 Float32 RGB input in0..255 to the original2048 features and1008 classes. Callers choose whether to include the graph's classifier bias when computing probabilities.

    Returns

    Absolute prepared cache directory.

    Throws
    std::invalid_argument

    For an unknown adapter.

    std::runtime_error

    For unavailable adapters, download, format or preparation errors.

    Example
    #include <dm/dm.hpp>
const auto root = dm::datasets::prepare_example_data("beta-vae-assets", "build/local-datasets");
const auto arrays = dm::nn::load_npz(root + "/beta_vae/factors.npz");
    #include <dm/dm.hpp>
const auto root = dm::datasets::prepare_example_data("sequence-vae-assets", "build/local-datasets");
const auto arrays = dm::nn::load_npz(root + "/sequence_vae/sentences.npz");
