    function datamunge::datasets

    digits

    #include <datamunge/datasets/datasets.hpp>
    #source
    dstruct::DataFrame digits()

    1797 8x8 images of handwritten digits, as in scikit-learn's load_digits().

    1797 rows and 65 numeric columns: pixel_0..pixel_63, the 8x8 image in row-major order with intensities 0..16, then digit (0-9). No missing values. Small enough to keep in memory; see ImageLoader for the full 28x28 MNIST.

    Returns

    A new 1797 x 65 DataFrame owned by the caller.

    Example
    const auto digits = dm::datasets::digits();
std::print("{}\n", digits.nrows());   // 1797
