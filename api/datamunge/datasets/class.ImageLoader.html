    class datamunge::datasets

    ImageLoader

    class ImageLoader
    #include <datamunge/datasets/image_loader.hpp> source

    A configurable, disk-backed batch iterator over a standard image dataset.

    Datasets: "mnist" and "fashion_mnist" (28x28 grayscale, 10 classes; 60000 train / 10000 test), "cifar10" (32x32 RGB, 10 classes; 50000 / 10000) and "cifar100" (32x32 RGB, 100 fine or 20 coarse classes; 50000 / 10000).

    Iteration works in epochs. has_next()/next() walk the current epoch's order; reset() starts the next epoch (with a fresh shuffle when shuffling is on). Every setter returns the loader for chaining and rewinds the current epoch, so configure before iterating.

    Reading is const and opens files per call, so batch()/take() may be called from several threads at once; next()/reset() and the setters mutate and must not race.

    Example
    dm::datasets::ImageLoader test("cifar10", "test");
test.set_batch_size(500).set_layout("nchw").set_normalize(false);
const auto first = test.next();          // shape {500, 3, 32, 32}, values 0..255
std::print("{}\n", test.class_names()[first.labels[0]]);   // "cat"
