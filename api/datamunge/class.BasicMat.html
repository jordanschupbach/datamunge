    BasicMat

    template<bool Sparse, class T>
class BasicMat : public datamunge::linalg::matrix_detail::Expression< BasicMat< Sparse, T > >
    #include <datamunge/linalg/matrix.hpp> source

    Owned floating-point matrix backed by canonical DenseMatrix or SparseCSR storage. Initialisers are rows and must be rectangular. Empty rows and zero dimensions are valid. Dense reads are constant time; sparse reads use a row binary search. set() is constant time for dense storage and linear in rows plus stored entries for sparse storage. Expressions borrow lvalue matrices, so those matrices must outlive evaluation. They own temporary matrices and copy expression nodes (including any matrices those nodes own). Mutations before eval()/printing are visible; construction/assignment to Mat or SpMat takes a snapshot, safely handling aliased operands. Nonfinite entries are stored; dense products follow IEEE arithmetic, while sparse products skip structural zeros. Solving rejects nonfinite coefficient/right-hand-side entries. Concurrent reads/evaluations are safe only while all borrowed operands remain unmodified.

    Template parameters
    Sparse

    False for row-major dense storage (Mat), true for CSR storage (SpMat).

    T

    Floating-point scalar: float, double (default) or long double.

    Example
    dm::Mat<> A = {{1, 2}, {3, 4}};
auto expression = A.t() * A;
dm::Mat<> snapshot = expression;
A.set(0, 0, 5);
std::print("{:.0f} {:.0f}\n", snapshot(0, 0), expression(0, 0));  // 10 34

    #source
    decltype(auto) operator()(std::size_t row, std::size_t col)

    Access a writable coefficient using checked, zero-based indices. Dense matrices return a scalar reference, invalidated by storage replacement. Sparse matrices return a coordinate proxy: reading never inserts an entry and assigning zero removes it. The matrix must outlive its reference/proxy; sparse proxies remain valid across insertions at other coordinates. Assignment has the same storage and complexity semantics as set().

    Parameters
    row

    Zero-based row, strictly less than rows().

    col

    Zero-based column, strictly less than cols().

    Returns

    Dense scalar reference or writable CSR coefficient proxy.

    Throws
    std::out_of_range

    If either index is outside the matrix.

    Example
    dm::Mat<> A(3, 5);
A(2, 4) = 1.1;
dm::SpMat<> S(30, 40);
S(2, 8) = 2.3;
std::print("{:.1f} {:.1f} {}\n", A(2, 4), S(2, 8), S.nnz()); // 1.1 2.3 1
