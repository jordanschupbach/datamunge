    KNNClassifier

    class KNNClassifier
    #include <datamunge/datamunge.hpp> source

    SWIG-friendly facade for datamunge::stats::KNNClassifier — k-nearest-neighbors classification. Since a training point's nearest neighbor is always itself, training_accuracy()/confusion_matrix() report leave-one-out performance rather than a trivial resubstitution fit.
