    Dual

    class Dual
    #include <datamunge/datamunge.hpp> source

    SWIG-friendly facade for datamunge::autodiff::Dual – a first-order forward-mode dual number. Build an expression out of named operations (starting from a seed with derivative=1) to read off an exact derivative alongside the value.

    Constructors

    Dual

    #source
    explicit Dual(double value, double derivative = 0.0)

    A dual number value + derivative·ε (ε² = 0).

    Seed the variable you differentiate with derivative 1 and constants with 0; every operation then carries the exact derivative with respect to that seed.

    Parameters
    value

    Real part, the function value.

    derivative

    Dual part, the derivative with respect to the seed (default 0).

    Example
    const dm::Dual x(2.0, 1.0);  // seed d/dx
std::print("{}\n", x.multiply(x).derivative());  // 4
