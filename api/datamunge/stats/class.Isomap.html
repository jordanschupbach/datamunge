    class datamunge::stats

    Isomap

    class Isomap
    #include <datamunge/stats/isomap.hpp> source

    Isomap: classical scaling of shortest-path distances on a union-kNN graph.

    Requires a connected graph; it never inserts artificial cross-component bridges. isomap_graph() inspects disconnected inputs before fitting. No feature standardization or out-of-sample transform is performed. Finite graph distances need not be Euclidean: negative centred-Gram eigenvalues are reported and zeroed only for coordinates. Eigenvector signs and rotations in repeated eigenspaces are arbitrary; compare Gram matrices or distances rather than individual coordinates across implementations.

    Dense Floyd-Warshall and symmetric Householder/QL eigendecomposition cost O(n^3), in addition to graph construction. Storage is O(n^2+n*p+n*k). Diagnostics are in-sample; a high positive-inertia fraction does not establish true-geodesic recovery. Returned references live as long as the model; const methods have no mutable shared caches.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{0,1,1,0});
d.add_column("y",std::vector<double>{0,0,1,1});
const dm::stats::Isomap model(d,{"x","y"},{2,2});
std::print("{:.1f}\n",model.goodness_of_fit()); // 1.0

    dimension_diagnostics

    #source
    dstruct::DataFrame dimension_diagnostics() const

    Spectral and geodesic-distance diagnostics for every fitted prefix, without refitting.

    Returns

    Owned dimensions/gof_positive/negative_mass/relative_strain/geodesic_rmse/ relative_geodesic_error/residual_variance table. negative_mass is sum(abs(negative eigenvalues))/sum(abs(all eigenvalues)); strain is normalized Gram Frobenius error. Distance sums use unordered pairs. residual_variance=1-Pearson(Dgeo,Dembedded)^2; it is NaN when either pair-distance vector is constant. Zero norm denominators give zero. O(n^2*n_components) work and O(n^2) workspace.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{0,1,1,0});
d.add_column("y",std::vector<double>{0,0,1,1});
const dm::stats::Isomap model(d,{"x","y"},{2,2});
std::print("{:.1f}\n",model.dimension_diagnostics().double_at("negative_mass",1)); // 0.2

    reference_diagnostics

    #source
    dstruct::DataFrame reference_diagnostics(
    const dstruct::DataFrame & reference,
    const std::vector< std::string > & columns) const

    Compares graph/embedded distances with independent Euclidean reference coordinates.

    Parameters
    reference

    Original-row-aligned frame, with exactly the training input row count.

    columns

    Nonempty finite numeric reference coordinates at every retained row.

    Returns

    Owned n/pairs/geodesic_relative_error/embedding_relative_error/geodesic_correlation/ embedding_correlation/max_edge_stretch row. max_edge_stretch is the largest reference Euclidean edge length divided by its input edge weight; it is meaningful when both use comparable units. Zero/zero edge ratios are zero; positive/zero is infinity. All fitted embedding axes are used, no alignment or rescaling. Relative errors divide by the norm of reference pair distances (zero/zero is zero, positive/zero is infinity); correlations are NaN when either distance vector is constant.

    Throws
    std::invalid_argument

    Row mismatch, missing/non-numeric columns, retained nulls, nonfinite values or reference distance overflow.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{0,1,1,0});
d.add_column("y",std::vector<double>{0,0,1,1});
const dm::stats::Isomap model(d,{"x","y"},{2,2});
std::print("{:.0f}\n",model.reference_diagnostics(d,{"x","y"}).double_at("n",0)); // 4
