    KNNClassifier

    class KNNClassifier
    #include <datamunge/stats/knn_classifier.hpp> source

    k-nearest-neighbour classifier from a formula class ~ x1 + x2 + ....

    The model stores the (standardised) training points. A query is assigned the class with the largest share of votes among its k nearest training points. Ties in distance are broken by training-row order and ties in the vote by the order of classes() (sorted labels), as in scikit-learn. Each standardised difference is computed as the raw difference times \(1/s_j\), so points tied in the raw data stay exactly tied. Factor predictors enter as their dummy columns.

    There is no meaningful resubstitution accuracy (with \(k=1\) every training point is its own nearest neighbour), so fitted_classes(), training_accuracy() and confusion_matrix() are leave-one-out: each row is classified by the other \(n-1\) rows, with the standardisation recomputed without it, exactly as refitting \(n\) times would.

    Example
    const auto iris = dm::datasets::iris();
const dm::stats::KNNClassifier knn(iris, "Species ~ Petal.Length + Petal.Width", {.k = 5});
std::print("{:.4f}\n", knn.training_accuracy());  // 0.9667 (leave-one-out)
    References

    • T. M. Cover and P. E. Hart (1967). "Nearest neighbor pattern classification". IEEE Transactions on Information Theory 13(1), 21–27.

    • scikit-learn KNeighborsClassifier: https://scikit-learn.org/stable/modules/generated/sklearn.neighbors.KNeighborsClassifier.html

    loo_accuracy_path

    #source
    std::vector< double > loo_accuracy_path(std::size_t max_k) const

    Leave-one-out accuracy for every \(k=1,\dots,K\) at once, with this model's metric, voting and standardisation.

    Each row's neighbours are sorted once, so the whole path costs about as much as one leave-one-out evaluation.

    Parameters
    max_k

    \(K\); reduced to \(n-1\) if larger.

    Returns

    Accuracies; element \(k-1\) is the accuracy with \(k\) neighbours.

    Throws
    std::invalid_argument

    If max_k is 0.

    Example
    const dm::stats::KNNClassifier knn(dm::datasets::iris(), "Species ~ Petal.Length + Petal.Width");
std::print("{:.4f}\n", knn.loo_accuracy_path(15)[4]);  // 0.9667, the same as k = 5

    plot_decision_regions

    #source
    graphics::RPlot plot_decision_regions(
    const std::string & x_feature,
    const std::string & y_feature,
    std::size_t grid_resolution = 150,
    std::optional< std::array< double, 4 > > limits = std::nullopt) const

    The predicted class over the plane of the two predictors, shaded in pale class colours, with the training points on top.

    The plane is limits, or else the training range padded by 5% in x and 10% in y, cut into grid_resolution × grid_resolution cells; each cell takes the class predicted at its centre, and runs of equal cells along a row are drawn as one rectangle.

    Parameters
    x_feature

    Predictor on the x axis.

    y_feature

    Predictor on the y axis.

    grid_resolution

    Cells per axis (at least 2).

    limits

    Optional box {x_min, x_max, y_min, y_max}, e.g. to leave room for the legend at the top right.

    Returns

    The plot, with its axis limits set to the shaded box.

    Throws
    std::invalid_argument

    If the model does not have exactly these two predictors, or limits is not increasing.

    Example
    const dm::stats::KNNClassifier knn(dm::datasets::iris(), "Species ~ Petal.Length + Petal.Width");
knn.plot_decision_regions("Petal.Length", "Petal.Width").save_svg("regions.svg");
