    class datamunge::stats

    UStatistic

    class UStatistic
    #include <datamunge/stats/u_statistic.hpp> source

    Average a symmetric degree-m kernel over all distinct-index subsets or random subset draws.

    Complete enumeration averages C(n,m) terms. Random draws contain distinct indices within each tuple, but can repeat subsets across draws. Each next subset is uniform conditional on the preceding shuffle state. The kernel must be symmetric and deterministic; neither property is tested. Complete tuples are in index order, random tuples in shuffle order. For i.i.d. data and integrable h, both estimators are unbiased for E[h]. Asymptotic normality additionally requires fixed degree, finite second moment and nonzero first projection variance; growing-degree and degenerate cases need separate theory.

    Fitting uses O(n+m) working storage and O(T*m) bookkeeping plus T callback costs. Complete T=C(n,m) may be prohibitive; no automatic switch to incomplete sampling occurs. Inputs are borrowed and unchanged; each call owns its RNG. Same seeds reproduce draws within an STL implementation; uniform_int_distribution is not a cross-STL bitstream contract. Concurrent calls are safe only if the caller's callback is safe to call concurrently.

    Example
    const dm::stats::UStatistic u(2);
const auto fit=u.run({1,2,4},[](const auto& x){return 0.5*(x[0]-x[1])*(x[0]-x[1]);});
std::print("{:.6f}\n",fit.estimate); // 2.333333
    References

    • W. Hoeffding (1948). A class of statistics with asymptotically normal distribution. Annals of Mathematical Statistics 19(3), 293-325. https://doi.org/10.1214/aoms/1177730196

    • G. Blom (1976). Some properties of incomplete U-statistics. Biometrika 63(3), 573-580. https://doi.org/10.1093/biomet/63.3.573

    analyze

    #source
    UStatisticAnalysis analyze(const std::vector< double > & sample, const SymmetricKernel & kernel) const

    Adds conditional subset variance, coverage and a complete-fit delete-one jackknife.

    With complete enumeration and n>m, U_(-i)=(n*U-m*g_i)/(n-m); pseudo-values are n*U-(n-1)*U_(-i), and jackknife variance is (n-1)/n sum((U_(-i)-U)^2). This equals ((n-1)/(n-m))^2 times the legacy projection variance. It is an estimate, not the exact population variance, and need not be valid for a degenerate kernel. Uncovered conditional means and unavailable delete-one diagnostics are NaN. Incomplete Monte Carlo variance estimates only variability from random subset draws with the data fixed.

    Parameters
    sample

    Finite sample of size n>=degree(), unchanged.

    kernel

    Deterministic symmetric callback, finite on every evaluated tuple.

    Returns

    Owned analysis; no kernel is evaluated more often than in run().

    Throws
    std::invalid_argument

    As run().

    std::bad_function_call

    For an empty callback; other callback exceptions propagate.

    std::overflow_error

    For an unrepresentable complete term count.

    Example

    See UStatisticAnalysis.

    incomplete_path

    #source
    dstruct::DataFrame incomplete_path(
    const std::vector< double > & sample,
    const SymmetricKernel & kernel,
    const std::vector< std::size_t > & budgets,
    std::size_t repetitions = 256) const

    Calibrates conditional Monte Carlo error against a complete reference on a fixed sample.

    Deliberately computes the complete reference, so this diagnostic is for tractable samples. Every budget uses the same repeated seeds options().seed+r (unsigned wrap), pairing repetitions across budgets. options().max_terms is ignored. The expected RMSE is sqrt(complete kernel_variance/B), since draws are independent with replacement across subsets.

    Parameters
    sample

    Finite observations, size at least degree().

    kernel

    Deterministic symmetric finite-valued callback.

    budgets

    Nonempty positive term counts; order is retained.

    repetitions

    Positive independent seeded runs per budget, default 256.

    Returns

    Owned rows: terms, repetitions, complete_estimate, mean_estimate, bias_to_complete, rmse_to_complete, expected_rmse, mean_estimated_mc_variance. Work proportional to C(n,m)+repetitions*sum(budgets) kernel calls.

    Throws
    std::invalid_argument

    For invalid samples, empty/zero budgets, zero repetitions or non-finite values.

    std::bad_function_call

    For an empty callback; other callback exceptions propagate.

    std::overflow_error

    For an unrepresentable complete term count.

    Example
    const auto path=dm::stats::UStatistic(2).incomplete_path({1,2,4},
    [](const auto& x){return std::abs(x[0]-x[1]);},{10,100},64);
std::print("{}\n",path.to_md(4));

    two_point_law

    #source
    UStatisticLaw two_point_law(
    std::size_t n,
    double low,
    double high,
    double p,
    const SymmetricKernel & kernel) const

    Exact law of the complete U-statistic for independent draws from {low,high}.

    If K~Binomial(n,p), a tuple's number of high observations given K is hypergeometric. The method evaluates h on the m+1 possible tuple compositions and uses their weights to compute U conditional on each K, its mean/variance and known first projection. This is a finite sum, not simulation; settings max_terms/seed are ignored. O(n*m) arithmetic and O(n+m) storage plus m+1 kernel calls. Numerical log-combination arithmetic can lose precision for extremely large n. No growing-degree CLT is asserted.

    Parameters
    n

    Sample size, at least degree(), less than SIZE_MAX.

    low

    Finite first population value.

    high

    Finite second population value, distinct from low (ordering need not increase).

    p

    Probability of the second value, finite in [0,1].

    kernel

    Deterministic symmetric finite-valued callback.

    Returns

    Owned count distribution, population target, sampling moments and first-order variance.

    Throws
    std::invalid_argument

    For invalid n, population values/probability or non-finite callback values.

    std::bad_function_call

    For an empty callback; other callback exceptions propagate.

    Example

    See UStatisticLaw.
