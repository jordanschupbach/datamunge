    HypothesisTestResult

    struct HypothesisTestResult
    #include <datamunge/stats/hypothesis_test_result.hpp> source

    Owned hypothesis-test result, analogous to R's htest list. Each test documents which fields it populates and what its interval estimates. Unused numeric fields retain zero; this default is storage, not a claim of zero effect. Read bounds only when has_conf_int is true; one-sided intervals may be unbounded. p_value is a null-model tail probability, not a posterior probability of the null. Objects own their method string and contain no borrowed references or shared state.

    Example
    const auto t=dm::stats::t_test_one_sample({1,2,3,4});
std::print("{}\n",t.has_conf_int); // true

    • https://stat.ethz.ch/R-manual/R-devel/library/stats/html/t.test.html
