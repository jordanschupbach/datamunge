    class datamunge::stats

    LDA

    class LDA
    #include <datamunge/stats/lda.hpp> source

    Fit pooled within-class covariance linear discriminant analysis from a categorical formula. Owns fitted design, means, precision terms and training observations; no borrowed dataframe lifetime. Class order is alphabetical. Null predictors/response rows are dropped while fitting; finite usable numerical designs and positive-definite within-class scatter are required, with at least2 classes, at least2 rows per class and n>classes+predictors. Formula transforms/interactions are supported; intercept is ignored. No regularization or posterior calibration is performed. Fitting uses scatter W and Sigma=W/(n-classes), not the maximum-likelihood W/n. Bayes scores use the full design; discriminant plots use at most two axes. Const inference borrows no mutable global state; mutable fitting is constructor-only.

    Example
    const dm::stats::LDA model(dm::datasets::iris(), "Species ~ Petal.Length + Petal.Width");
std::print("{} {}\n",model.observations(),model.num_discriminants()); // 150 2
    References

    • Fisher(1936), The Use of Multiple Measurements in Taxonomic Problems, https://doi.org/10.1111/j.1469-1809.1936.tb02137.x.

    predict

    #source
    std::vector< std::string > predict(const dstruct::DataFrame & newdata) const

    Classify new rows from the fitted predictor design without response labels. Null predictor rows are omitted from compact computation and restored as empty output entries; finite design values are required. Largest Bayes score wins, alphabetical-first on exact ties; softmax gives model posteriors, not a calibration guarantee. No refit or mutation.

    Throws
    std::invalid_argument

    On missing columns or unseen categorical levels.

    std::bad_alloc

    On design/output allocations.

    Parameters
    newdata

    Borrowed rows with training predictor columns/levels; response not required.

    Returns

    Owned labels, one per original row; empty for missing predictors.

    Example

std::print("{}\n",model.predict(dm::datasets::iris().head(1))[0]); // setosa

    plot_discriminants

    #source
    graphics::RPlot plot_discriminants(bool decision_regions = true) const

    Scatter of the training data's first two discriminant scores (LD1 vs LD2; LD1 against 0 if there is only one), colored by true class.

    With decision_regions, the background is shaded by the class the model predicts there and the boundaries between classes are drawn. LDA picks the class whose mean is nearest in discriminant space (after a log-prior adjustment), so each region is a convex polygon, computed exactly by clipping the plot rectangle with one half-plane per competing class. With up to three classes the two discriminants carry the whole model, so the regions are the model's own predictions; with more classes they are the predictions of the model restricted to LD1 and LD2 (MASS's predict(dimen = 2)).

    Parameters
    decision_regions

    Shade class regions and draw boundaries (default true).

    Returns

    The plot, ready to save or adjust.

    Example
    const dm::stats::LDA model(dm::datasets::iris(),
    "Species ~ Sepal.Length + Sepal.Width + Petal.Length + Petal.Width");
model.plot_discriminants().save("iris_lda.svg");
model.plot_discriminants(false).save("iris_lda_points.svg");   // points only
    References

    • T. Hastie, R. Tibshirani, J. Friedman (2009). The Elements of Statistical Learning, 2nd ed., Section 4.3.3 (reduced-rank LDA as nearest centroid). Springer. doi:10.1007/978-0-387-84858-7

    • W. N. Venables, B. D. Ripley (2002). Modern Applied Statistics with S, 4th ed., Section 12.1. Springer. doi:10.1007/978-0-387-21706-2

    plot_decision_regions

    #source
    graphics::RPlot plot_decision_regions() const

    Training data and decision regions in the space of the two predictors, for a model with exactly two (e.g. "Species ~ Petal.Length + Petal.Width").

    Each class region is the convex polygon where that class's discriminant function is largest, so boundaries are exact straight lines.

    Returns

    The plot, with the predictors as axis labels.

    Throws
    std::logic_error

    if the model does not have exactly two predictor columns.

    Example
    const dm::stats::LDA petals(dm::datasets::iris(), "Species ~ Petal.Length + Petal.Width");
petals.plot_decision_regions().save("petal_regions.svg");
