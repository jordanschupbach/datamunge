    GaussianProcessRegression

    class GaussianProcessRegression
    #include <datamunge/stats/gaussian_process_regression.hpp> source

    Formula-driven exact RBF Gaussian-process regression with profiled covariance scale.

    Uses z=(y-mean(y))/population_sd(y), R_ij=exp(-||x_i-x_j||^2/(2 ell^2)), C=R+(noise_ratio+jitter_ratio) I and K=s C. The signal variance s is max(1e-12,z'C^-1 z/n). Both selection and prediction use this same K. Negative length/noise settings select a finite geometric grid by marginal likelihood; this is empirical Bayes, without integration over hyperparameters, centring or scaling uncertainty. Default predictor standardization acts on the formula's expanded design columns; no intercept column is fitted. Null training rows are dropped jointly; non-finite retained values are rejected. The object owns its design, data and factorizations; const reads may run concurrently. A grid of G candidates costs O(G*(n^3+n^2*p)) work and O(n^2+np+G) storage.

    fitted_values(), r_squared() and rmse() retain their historical fixed-fit conditional leave-one-out meaning: preprocessing, mean, scales and hyperparameters from all data are held fixed. They do not refit the full pipeline in each deletion fold.

    Example
    dm::dstruct::DataFrame data; data.add_column("x",std::vector<double>{0,1});
data.add_column("y",std::vector<double>{-1,1});
dm::stats::GaussianProcessRegressionOptions options;
options.length_scale=1/std::sqrt(2*std::log(2.0)); options.noise_ratio=.5;
options.standardize=false; options.jitter_ratio=0;
const dm::stats::GaussianProcessRegression gp(data,"y ~ x",options);
std::print("{:.3f}\n",gp.predict(data)[0]); // -0.500
    References

    • C. E. Rasmussen and C. K. I. Williams (2006). Gaussian Processes for Machine Learning, equations 2.23-2.30 and 5.12. https://gaussianprocess.org/gpml/

    Fits an exact RBF GP, with a fixed or grid-selected length scale and noise ratio.

    Parameters
    data

    Training frame; nulls in selected response/predictors are dropped jointly.

    formula

    Numeric-response formula, e.g. "Petal.Length ~ Petal.Width"; expanded features define RBF distance.

    options

    Preprocessing, finite kernel settings and positive grid sizes; defaults select both grids.

    Throws
    std::invalid_argument

    For invalid formula/options, non-finite retained values or overflowing standardization.

    std::runtime_error

    If no complete rows remain, no candidate is finite/SPD, or final factorization fails.

    Example

    See the class example for a hand-checkable two-point fit.

    predict_covariance

    #source
    linalg::DenseMatrix< double > predict_covariance(
    const dstruct::DataFrame & newdata,
    bool observation_noise = false) const

    Joint covariance between query targets, including off-diagonal posterior dependence.

    Parameters
    newdata

    Query predictors; null rows yield NaN rows/columns, empty yields a 0 by 0 matrix.

    observation_noise

    If true, add independent observation noise only on the diagonal; default false.

    Returns

    Owned M by M covariance in squared original response units. Repeated queries have identical latent values; their independent new-observation noises remain distinct. Cost O(M*(n^2+np)+M^2*(n+p)).

    Throws
    std::invalid_argument

    For schema/category errors or non-finite retained predictors.

    std::runtime_error

    For no complete rows or numerically invalid covariance.

    Example
    dm::stats::GaussianProcessRegressionOptions options; options.length_scale=.5; options.noise_ratio=.05;
const auto data=dm::datasets::iris();
const dm::stats::GaussianProcessRegression gp(data,"Petal.Length ~ Petal.Width",options);
std::print("{}\n",gp.predict_covariance(data.head(2)).rows()); // 2
    References

    training_details

    #source
    dstruct::DataFrame training_details() const

    Training posterior and conditional deletion diagnostics, aligned to retained source rows.

    Returns

    Owned columns row (one-based source index), observed, posterior_mean, loo_mean, loo_residual, loo_observation_sd, loo_z. The deletion mean holds all fitted preprocessing and hyperparameters fixed; its observation variance excludes numerical jitter on the held-out target. A zero SD gives NaN z. Costs O(n) after the fit's inverse-diagonal calculation.

    Example

    See model_summary(); training_details() returns one row per retained observation.

    References

    • Rasmussen and Williams (2006), equation 5.12. https://gaussianprocess.org/gpml/chapters/RW5.pdf

    score

    #source
    dstruct::DataFrame score(const dstruct::DataFrame & data, double level = .95) const

    Scores supplied responses using the existing fit, without refitting or tuning.

    The caller must exclude these rows from training to interpret this as held-out performance.

    Parameters
    data

    Frame with query predictors and the original response column. Null response/query rows are omitted.

    level

    Central interval probability in (0,1), default .95.

    Returns

    Owned one-row columns n, rmse, mae, r_squared, latent_coverage, observation_coverage, mean_observation_width and mean_nlpd (Gaussian negative log predictive density). Coverage is empirical, not a guarantee; NLPD is NaN if any predictive variance is zero. Constant-response R squared is one for zero SSE, otherwise zero.

    Throws
    std::invalid_argument

    For invalid level/schema/non-finite responses or no scoreable rows.

    std::runtime_error

    As in prediction_table().

    Example

    See model_summary(); gp.score(heldout) assesses external predictions, whereas training_details() diagnoses deletions.
