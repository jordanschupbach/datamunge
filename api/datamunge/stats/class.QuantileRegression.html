    QuantileRegression

    class QuantileRegression
    #include <datamunge/stats/quantile_regression.hpp> source

    Linear quantile regression: \(\hat\beta_\tau=\arg\min_\beta\sum_iw_i\rho_\tau(y_i-x_i^\top\beta)\).

    The conditional \(\tau\)-quantile of the response is modelled as linear in the design built from an R-style formula. Formula parsing, null-row omission, categorical encoding and prediction follow the same conventions as stats::LM. The fit is a linear program: the simplex (default) solves it exactly, ADMM to a tolerance, and both expose the dual solution (Koenker's regression rank scores less \(1-\tau\)). coefficient_table() adds standard errors.

    Example
    dm::dstruct::DataFrame d;
d.add_column("x", std::vector<double>{1, 2, 3, 4, 5});
d.add_column("y", std::vector<double>{1, 3, 2, 5, 4});
const dm::stats::QuantileRegression median(d, "y ~ x");
// median.coefficients() == {0.25, 0.75}: the line through the first and last rows,
// median.objective() == 1.75, median.basis() == {0, 4}
    References

    • Koenker, R. and Bassett, G. (1978). Regression quantiles. Econometrica 46, 33-50.

    • Koenker, R. (2005). Quantile Regression. Cambridge University Press.

    bool converged() const

    Whether the solver met its stopping rule.

    ADMM: both residual norms are below their tolerances. Simplex: no edge from the final vertex lowers the loss and every dual value lies in \([\tau-1,\tau]\) (to 1e-9), which proves optimality.

    True on convergence.

    basis

    #source
    const std::vector< std::size_t > & basis() const

    The rows the fit interpolates (zero residual).

    Simplex: exactly the p rows of the final vertex, whose submatrix \(X_h\) gives \(\hat\beta=X_h^{-1}y_h\). ADMM: the rows whose split residual the soft threshold set to exactly zero, usually p of them once converged.

    Returns

    Indices into the fitted rows (0 .. observations() - 1), ascending.

    dual_solution

    #source
    const std::vector< double > & dual_solution() const

    The solution \(\hat a\) of the dual linear program \(\max_a\sum_iw_ia_iy_i\) subject to \(X^\top Wa=0\), \(a_i\in[\tau-1,\tau]\).

    \(a_i=\tau\) above the fit and \(\tau-1\) below it; interpolated rows take values inside the interval. At the optimum \(\sum_iw_ia_iy_i\) equals objective(), and \(a+1-\tau\) are Koenker's regression rank scores. Simplex: solved exactly from the basis; ADMM: the scaled multiplier \(\varrho u_i/w_i\).

    Returns

    One value per fitted row.

    coefficient_table

    #source
    QuantileCoefficientTable coefficient_table(
    QuantileStandardErrors method = QuantileStandardErrors::NID,
    double level = 0.95,
    std::size_t replications = 200,
    std::uint64_t seed = 1) const

    Standard errors, t statistics, p-values and confidence intervals.

    IID needs no refit; NID refits at \(\tau\pm h\) with Hall and Sheather's bandwidth and clamps each row's density estimate \(2h/x_i^\top(\hat\beta_{\tau+h}-\hat\beta_{\tau-h})\) at zero, as quantreg does. The bootstrap refits on \(n\) rows resampled with replacement (weights travel with their rows) and skips resamples whose design is rank-deficient. Refits use options().

    Parameters
    method

    IID, NID (default) or Bootstrap.

    level

    Confidence level in (0, 1).

    replications

    Bootstrap resamples (ignored otherwise), at least 2.

    seed

    Bootstrap seed.

    Returns

    The table.

    Throws
    std::invalid_argument

    On a level out of range, fewer than 2 replications, or \(n\le p\).
