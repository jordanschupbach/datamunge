    AdditiveModel

    class AdditiveModel
    #include <datamunge/stats/gam.hpp> source

    Fitted additive terms, predictions and optional group effects.

    Models own the training bases, their centers and the coefficient estimates. Fixed terms sum to zero over the training rows. Spline evaluation clamps to the training boundary, and linear terms extrapolate linearly. Group effects can be included for known groups. Predictions without effects are conditional means at group effect zero.

    Example
    const auto model = dm::stats::fit_gam({1, 2, 3, 4}, {{0, 1, 2, 3}},
                                    {.smooths = {{.basis_size = 0}}});
std::print("{:.0f}", model.predict({{2}}).front()); // 3

    predict

    #source
    std::vector< double > predict(const std::vector< std::vector< double > > & predictors, const std::vector< std::string > & groups = {}) const

    Predicts response-scale means from columns in training predictor order.

    Parameters
    predictors

    One finite vector per fitted additive term, with equal lengths.

    groups

    Optional group label per row. Empty uses zero group effects. Unknown nonempty labels also use zero. Only mixed models accept labels.

    Returns

    Owned means in query order.

    Throws
    std::invalid_argument

    Invalid columns, nonfinite values or invalid group labels.

    std::runtime_error

    A prediction leaves the family domain or overflows.

    Example

    See the AdditiveModel class example.
