    BARTOptions

    struct BARTOptions
    #include <datamunge/stats/bart.hpp> source

    Regularization, structure prior and sampler settings for Gaussian BART.

    Example
    dm::stats::BARTOptions settings{.num_trees = 30, .warmup = 100, .draws = 200};
