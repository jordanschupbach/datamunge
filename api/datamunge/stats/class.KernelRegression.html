    KernelRegression

    class KernelRegression
    #include <datamunge/stats/kernel_regression.hpp> source

    Nadaraya-Watson regression: nonnegative local averages on a frozen formula design.

    Resolves numeric responses and a no-intercept predictor design with Formula, omitting training rows with null required values jointly. At least two finite complete rows and one design column are required. Standardization uses training population SD, not n-1. Scalar h is in standardized design units when enabled, otherwise raw design units. Categoricals/transforms follow Formula; dummy encoding is a metric choice, not a separate categorical kernel. Gaussian weights are normalized after subtracting a common log weight, avoiding underflow of every original weight at distant queries/tiny h. Compact kernels return NaN when no strictly positive weight remains.

    fitted_values(), rmse() and r_squared() use direct leave-one-out deletions at fixed h and fixed full-training design/scaling. They do not refit preprocessing for each fold. Auto search requires every deleted prediction to be finite: incomplete candidates get objective infinity and a wholly ineligible grid throws. Selected CV loss is a tuning criterion, not an unbiased evaluation of the selected procedure; use held-out data.

    Fixed fitting costs O(n^2*p), default B-candidate search O(B*n^2*p), storage O(n*p+n+B). Explicit smoothing matrices add O(n^2) storage. Models own their data/diagnostics; borrowed accessors live with the model. Const methods use no mutable shared caches.

    Example
    const dm::stats::KernelRegression m(dm::datasets::iris(),"Petal.Length ~ Petal.Width");
std::print("{}\n",m.observations()); // 150

    • G. S. Watson (1964), Smooth Regression Analysis, Sankhya A 26(4), 359-372. https://www.jstor.org/stable/25049340

    score

    #source
    dstruct::DataFrame score(const dstruct::DataFrame & data) const

    Scores external responses, including a training-mean prediction baseline. Null responses are excluded before query evaluation; retained nonfinite responses throw. Errors/R-squared/baseline use only finite predictions, so always compare coverage. R-squared uses the covered evaluation subset's mean; the baseline uses the training response mean without evaluation-label fitting. No refitting or bandwidth choice occurs.

    Parameters
    data

    Query predictors and numeric response column named by the training formula.

    Returns

    n/n_response/n_predicted/coverage/rmse/mae/r_squared/mean_baseline_rmse row; no coverage gives NaN metrics, zero evaluation TSS gives NaN R-squared.

    Throws
    std::invalid_argument

    Invalid response schema/nonfinite response or predict() errors.

    std::runtime_error

    As predict().

    Example
    const auto [train,test]=dm::stats::train_test_split(dm::datasets::iris(),.2,42,"Species");
const dm::stats::KernelRegression m(train,"Petal.Length ~ Petal.Width");
std::print("{:.0f}\n",m.score(test).double_at("n",0)); // 30
