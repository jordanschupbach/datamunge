    RandomForestRegressorOptions options = {})

    Fits the same model from a formula object, in R's (formula, data) argument order.

    Same as the (data, formula, ...) constructor; a string literal or std::string converts to Formula implicitly, so RandomForestRegressor("y ~ x", data) also works.

    Parameters
    formula

    Model formula, e.g. dm::formula("y ~ x1 + x2").

    data

    Data frame holding every column the formula names.

    options

    Same as in the (data, formula, ...) constructor.

    Throws
    std::invalid_argument

    As the (data, formula, ...) constructor.
