    FactorAnalysis

    class FactorAnalysis
    #include <datamunge/stats/factor_analysis.hpp> source

    Exploratory common-factor covariance model fitted by iterative principal axes. For centred rows Z, models C approximately as Lambda*Lambda^T+diag(Psi), with unit-variance uncorrelated latent factors and diagonal variable-specific variance. This is PAF, not R factanal's maximum-likelihood estimator or a minres optimizer. Each reduced matrix replaces C's diagonal with clipped communalities; negative retained eigenvalues become zero. SMC initialization and regression scores use an eigenvalue-floored inverse, floor 1e-8*max(diag(C)); this is not a pseudoinverse. Orthogonal varimax preserves the common covariance, not the identities of factors. Factors are ordered by squared loading sum, signs by largest-magnitude loading. Rows with any null selected feature are dropped; other retained values must be finite, with positive sample variance in every selected column. Repeated names, invalid options and unrepresentable arithmetic are rejected. Negative parameter- count df is allowed for exploration, not certified identification. Boundary fits can converge: check diagnostics(), raw_uniqueness and covariance residuals. Existing uniquenesses() remain clipped nonnegative; reported communalities remain actual squared loading norms and may exceed observed variance (Heywood violation). Owns fitted state; inputs unchanged; const operations share no mutable caches. For t extraction steps, bounded Jacobi sweeps and small k, main work O(np^2+t*p^3), plus bounded rotation work; storage O(np+p^2+t*p) including the iteration history.

    Example
    const auto d=dm::datasets::iris();
const dm::stats::FactorAnalysis m(d,
    {"Sepal.Length","Sepal.Width","Petal.Length","Petal.Width"}, {1,true,"none"});
std::print("{} {}\n",m.observations(),m.num_factors()); // 150 1

    diagnostics

    #source
    dstruct::DataFrame diagnostics() const

    Separates numerical stopping, covariance fit and parameter-count evidence.

    Returns

    One owned row: observations, features, factors, iterations, converged (0/1), degrees_freedom=((p-k)^2-p-k)/2, heywood_variables, offdiagonal_rms, max_diagonal_excess, total_variance, common_variance, kaiser_varimax. Nonnegative df is necessary by parameter counting, not sufficient for identification; no likelihood statistic or p-value is computed. Kaiser varimax is the normalized sum over factors of sum_j(q_jc^4)-(sum_j(q_jc^2))^2/p, q normalized by row norm.

    Throws
    std::invalid_argument

    Unrepresentable diagnostic arithmetic.

    Example
    const auto d=dm::datasets::iris();
const dm::stats::FactorAnalysis m(d,
    {"Sepal.Length","Sepal.Width","Petal.Length","Petal.Width"}, {1,true,"none"});
std::print("{:.0f}\n",m.diagnostics().double_at("degrees_freedom",0)); // 2
