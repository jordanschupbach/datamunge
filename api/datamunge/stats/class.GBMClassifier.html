    GBMClassifier

    class GBMClassifier
    #include <datamunge/stats/gbm_classifier.hpp> source

    Multiclass additive trees fitted to one-hot-minus-softmax residuals. Starts from log empirical class priors. At each round, all K residual targets use the same pre-round probabilities, then one least-squares CART tree per class is fitted. A scalar learning_rate multiplies its leaf means. There is no Newton leaf correction, (K-1)/K multiplier, centring constraint, line search or built-in early stopping; this is not numerically identical to sklearn GradientBoostingClassifier/LogitBoost. Formula supplies finite encoded predictors (including categorical/interaction terms) and a string response. Complete cases define sorted classes and priors; null formula rows are dropped. Needs at least one expanded predictor and two retained classes. All prior trees remain fixed. Subsampling selects rows without replacement once per round, shared across its K trees. The seed does not affect full-sample deterministic CART fits; greedy split ties follow predictor/threshold order and absolute tolerances. training_deviance is mean multinomial negative log likelihood, without factor two, computed with log-sum-exp rather than flooring probabilities. Prefix zero is the prior model. Evaluation is explicit, never used to fit or alter trees. Training accuracy or loss cannot diagnose generalization or select a stopping round without held-out data. Model owns the Formula schema, trees, encoded training data and row maps. Inputs are unchanged; const operations share no mutable caches. This CART implementation scans all candidate thresholds: conservative fit work O(M*K*p*n^2*(D+1)), with storage O(np+M*K*(n+nodes_per_tree)) including each tree's stored training predictions. Numeric inference traverses fitted trees; no query preprocessing is learned.

    Example
    dm::dstruct::DataFrame d;
d.add_column("x",std::vector<double>{0,1,2,3});
d.add_column("label",std::vector<std::string>{"a","a","b","b"});
const dm::stats::GBMClassifier m(d,"label ~ x",{2,.5,1});
std::print("{} {:.0f}\n",m.n_trees(),m.training_accuracy()); // 2 1
    References

    • J. H. Friedman (2001), Greedy function approximation: A gradient boosting machine. https://doi.org/10.1214/aos/1013203451

    training_step

    #source
    dstruct::DataFrame training_step(std::size_t round) const

    Exposes one training round's simultaneous residual targets and fitted updates. All class residuals use the same pre-round probabilities, including rows omitted by stochastic sampling. in_bag identifies which original rows actually fitted those trees. Work O(round*n*K*(D+1)); output O(n*K), with no refitting or shared mutable caches.

    Parameters
    round

    One-based completed round in 1..n_trees().

    Returns

    Owned n*K row-major/class-minor rows: round, original_row, class, one_hot, before_score, before_probability, pseudo_residual, tree_value, after_score, after_probability, in_bag (0/1). Scores include the learning-rate multiplier; tree_value itself is unshrunk. Original row indices refer to the constructor frame.

    Throws

    Invalid training round.

    std::invalid_argument

    Unrepresentable accumulated score.

    #source
    dstruct::DataFrame step_diagnostics(std::size_t round) const

    Aggregates one step's full-training projection and loss-change evidence.

    Parameters
    round

    One-based completed round in 1..n_trees().

    Returns

    Owned row: round, sample_size, full_sample (0/1), loss_before, loss_after, gradient_tree_inner, tree_squared_norm, quadratic_bound. Inner/norm are sums over every retained row and class. The bound is loss_before-eta*(1-eta/4)*norm/n; its descent interpretation requires a full-sample leaf-mean projection and 0<eta<4. Stochastic fits need not satisfy that projection identity or bound.     staged_evaluation

    #source
    dstruct::DataFrame staged_evaluation(const dstruct::DataFrame & data) const

    Evaluates every fixed-model prefix on identical complete labelled rows. Includes the prior at round zero; each fitted tree is traversed once per evaluation row. No refitting, early stopping, calibration or model mutation occurs. Mean log loss uses stable log-sum-exp, without probability clipping. Brier is mean(sum_k(p_k-y_k)^2), without dividing by K. Accuracy is a fraction; training and evaluation rows are distinct only if the caller supplies distinct data. Work O(n*M*K*(D+1)), storage O(n*K+M).

    Parameters
    data

    Borrowed labelled data with the frozen response/predictor schema.

    Returns

    Owned M+1 rows: round, input_rows, evaluated_rows, skipped_rows, accuracy, mean_log_loss, brier. Null formula rows are omitted jointly, at every stage.

    Throws
    std::invalid_argument

    Invalid schema/response class, retained nonfinite predictors, or unrepresentable score/metric arithmetic.

    std::runtime_error

    No complete nonempty rows or an unseen categorical predictor level.

    std::out_of_range

    Missing predictor columns or an invalid round prefix.

    std::domain_error

    A Formula transform is outside its domain.

    Example
