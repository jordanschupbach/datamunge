    LassoOptions

    struct LassoOptions
    #include <datamunge/stats/elastic_net.hpp> source

    Lasso controls forwarded to ElasticNet, fixing alpha=1. Same defaults/constraints as ElasticNetOptions; no alpha field.

    Example

std::print("{}\n",o.standardize); // true
