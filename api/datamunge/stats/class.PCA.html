    class datamunge::stats

    PCA

    class PCA
    #include <datamunge/stats/pca.hpp> source

    PCA from a named numeric DataFrame schema, retaining a full p-axis basis. Like R prcomp in centred/scaled score semantics, but uses a covariance eigensolver, defaults scale=true, permits constant columns and always returns p components, including null directions when p>=n. Rank is separate from num_components(). Fitting drops rows with any null selected feature and rejects retained nonfinite values. Training means/scales and axes are frozen for new rows. With centring, eigenvalues are sample variances; without it they are second-moment energies. Signs are arbitrary, and repeated eigenvalues permit rotations of their eigenspace. Gram formation squares the data condition number; this is not a high-relative-accuracy SVD for near-null directions. Work O(np^2+p^3) for bounded Jacobi sweeps, storage O(np+p^2). Model owns all state; const operations have no shared mutable caches.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{-1,0,1});
const dm::stats::PCA fit(d,{"x"},dm::stats::PCAOptions{true,false});
std::print("{:.0f}\n",fit.explained_variance()[0]); // 1

    Fits all p principal axes to complete rows of selected numeric features.

    Parameters

    Borrowed frame; selected-feature nulls drop rows, including their other values.

    Center/scale switches, both true by default; see PCAOptions.

    Throws

    Bad schema, fewer than two complete rows, retained nonfinite values, or unrepresentable preprocessing, covariance, eigenvalues or scores.

    transform

    #source
    linalg::DenseMatrix< double > transform(const dstruct::DataFrame & newdata) const

    Projects query rows using the frozen training offsets, divisors and axes. No row dropping, refit, whitening or centring on the query batch. Work O(mp^2).

    Parameters
    newdata

    Frame containing all selected numeric features; extra columns ignored. Every query coordinate must be nonnull/finite. Zero rows are allowed.

    Returns

    Owned m-by-p scores in query row order, even for m=1.

    Throws
    std::invalid_argument

    Bad schema, missing/nonfinite values or unrepresentable arithmetic.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{-1,0,1});
const dm::stats::PCA m(d,{"x"},dm::stats::PCAOptions{true,false});
dm::dstruct::DataFrame q;q.add_column("x",std::vector<double>{2});
std::print("{:.0f}\n",std::abs(m.transform(q)(0,0))); // 2

    reconstruct

    #source
    linalg::DenseMatrix< double > reconstruct(
    const dstruct::DataFrame & newdata,
    std::size_t components) const

    Projects onto a leading-axis prefix and returns coordinates in original feature units. Computes mean + scale * ((preprocess(newdata)*V_k)*V_k^T). The rank-k approximation minimizes preprocessed squared error, not generally original-unit error when scaled. k=0 returns the fitted origin; all p axes reconstruct to floating-point precision.

    Parameters
    newdata

    Query frame with the same requirements as transform().

    components

    Number of leading axes in [0,p].

    Returns

    Owned m-by-p matrix in feature_names() order and original feature units.

    Throws
    std::invalid_argument

    Bad k/schema, missing/nonfinite values or unrepresentable arithmetic.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{1,2,3});
const dm::stats::PCA m(d,{"x"});std::print("{:.0f}\n",m.reconstruct(d,0)(0,0)); // 2

    reconstruction_curve

    #source
    dstruct::DataFrame reconstruction_curve(const dstruct::DataFrame & newdata) const

    Measures query reconstruction error for every leading prefix, including zero axes. Uses the actual preprocessed query entries, not a full-score reconstruction as the reference. Fitting state is unchanged. Error decreases in preprocessed norm; original- unit error need not decrease at every prefix when scaling is active. Work O(mp^2), storage O(mp+p). Input labels are not inspected and this is not a calibrated anomaly score.

    Parameters
    newdata

    Nonempty query frame accepted by transform(); use complete fitted rows for the training eigenvalue-tail identity. Independent query rows need not satisfy that identity.

    Returns

    Owned p+1-row components/preprocessed_sse/preprocessed_rmse/original_rmse table, RMS over m*p entries; units of the last column mix supplied feature units if they differ.

    Throws
    std::invalid_argument

    Empty query, invalid transform input or unrepresentable errors.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{-1,0,1});
const dm::stats::PCA m(d,{"x"});std::print("{}\n",m.reconstruction_curve(d).nrows()); // 2
    References

    • Eckart and Young (1936). https://doi.org/10.1007/BF02288367
