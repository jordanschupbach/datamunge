    class datamunge::stats

    MDS

    class MDS
    #include <datamunge/stats/mds.hpp> source

    Classical MDS (principal coordinates), similar to R's cmdscale without an additive correction.

    Double-centres squared dissimilarities to B=-J D^2 J/2, then retains the leading positive eigenpairs. This minimises squared Gram error (strain), not squared distance error (stress). Negative eigenvalues are exposed and clamped to zero for coordinates. Euclidean feature distances recover unscaled, centred PCA scores up to an orthogonal transformation. No predictor standardisation is performed. Dense fitting takes O(n^2) storage and O(n^3) work per Jacobi sweep; feature distances additionally cost O(n^2*p). Returned matrices are borrowed for the model lifetime unless documented as owned. Const methods do not mutate the fit; signs and axes within repeated eigenspaces are arbitrary.

    Example
    const dm::stats::MDS model(dm::datasets::iris(),
    {"Sepal.Length", "Sepal.Width", "Petal.Length", "Petal.Width"});
std::print("{:.4f}\n", model.goodness_of_fit()); // 0.9777

    • W. S. Torgerson (1952). Multidimensional scaling: I. Theory and method. Psychometrika 17, 401-419. https://doi.org/10.1007/BF02288916

    • J. C. Gower (1966). Some distance properties of latent root and vector methods used in multivariate analysis. Biometrika 53, 325-338. https://doi.org/10.1093/biomet/53.3-4.325

    from_distances

    #source
    static MDS from_distances(
    const linalg::DenseMatrix< double > & dissimilarities,
    std::size_t n_components = 2)

    Classical scaling of an explicit dissimilarity matrix, as in R's cmdscale(d).

    No triangle inequality or Euclidean assumption is required. All entries must be finite and non-negative. Symmetry and zero diagonal are checked with tolerance 1e-12 times the largest dissimilarity; accepted asymmetric entries are averaged and diagonal set to zero. Input is copied; no null-dropping, standardisation or additive correction. feature_names() is empty and kept_row_indices() is 0,...,n-1. Axes beyond positive rank are zero or rounding-sized; exactly n_components columns are always returned.

    Parameters
    dissimilarities

    Square n by n matrix of distances, not squared distances, n >= 2.

    n_components

    Requested axes, default two, in [1,n-1].

    Returns

    Owned fitted model; the input is unchanged.

    Throws
    std::invalid_argument

    For invalid shape, entries, diagonal, symmetry, component count, or squared distances/centred Gram entries outside finite range.

    Example
    const dm::linalg::DenseMatrix<double> distances(3,3,{0,1,2, 1,0,1, 2,1,0});
const auto model = dm::stats::MDS::from_distances(distances,1);
std::print("{:.3f}\n", model.goodness_of_fit()); // 1.000

    spectrum

    #source
    dstruct::DataFrame spectrum() const

    Spectral summary exposing both positive and negative inertia.

    Columns: dimension (one-based), eigenvalue, positive_share, absolute_share, cumulative_positive_share, retained (1 if within requested axes), significant_negative. The last flag uses lambda < -1e-10*max(abs(lambda)) to distinguish round-off from meaningful negative eigenvalues. Shares use the raw spectrum and zero denominators give zero.

    Returns

    Owned n-row table, O(n) time and storage.

    Example
    const dm::stats::MDS model(dm::datasets::iris(), {"Petal.Length", "Petal.Width"});
std::print("{}\n", model.spectrum().head(5).to_md(4));

    dimension_diagnostics

    #source
    dstruct::DataFrame dimension_diagnostics() const

    Distance distortion and optimal Gram residual for every fitted prefix of axes.

    Row k describes the first k axes, k=1,...,n_components(). Columns: dimensions, gof_positive (goodness_of_fit definition), gof_absolute (retained positive sum divided by sum(abs(lambda))), strain_squared (sum of discarded positive and all negative eigenvalues squared), relative_strain (sqrt(strain_squared/sum(lambda^2))), distance_rmse (sqrt(mean((D-dhat)^2))) and relative_distance_error (sqrt(sum((D-dhat)^2)/sum(D^2))). Distance sums are over unordered pairs. Zero denominators give zero. Strain is the spectral optimum for a positive-semidefinite Gram matrix of rank at most k; it does not establish that stress is minimised. No refits; O(n^2*k) work, O(n^2+k) temporary storage.

    Returns

    Owned k-row table in increasing dimension order.

    Example
    const dm::stats::MDS model(dm::datasets::iris(),
    {"Sepal.Length", "Sepal.Width", "Petal.Length", "Petal.Width"}, {4});
std::print("{}\n", model.dimension_diagnostics().to_md(6));

    Scatter coloured by external labels, which do not participate in fitting.

    Parameters
    group_labels

    One label per retained row, in kept_row_indices() order.

    dimension_x

    Horizontal axis, default zero.

    dimension_y

    Vertical axis, default one.

    Returns

    Owned plot, colours in sorted group order; allow legend headroom through y_limits().

    Throws
    std::out_of_range

    For axes outside n_components().

    std::invalid_argument

    If group_labels does not match observations().

    Example
    const auto iris = dm::datasets::iris();

std::vector<std::string> labels;
for (auto i : model.kept_row_indices()) labels.push_back(iris.string_at("Species",i));
model.plot_embedding(labels).save_svg("mds.svg");
