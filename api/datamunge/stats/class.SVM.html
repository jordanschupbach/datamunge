    class datamunge::stats

    SVM

    class SVM
    #include <datamunge/stats/svm.hpp> source

    Soft-margin multi-class SVM, similar to R's e1071::svm, with deterministic simplified SMO.

    Trains one binary classifier per class pair. The sorted first class has sign +1; non-negative pair decisions vote for it, and final vote ties use sorted class order. Missing response/predictor rows are dropped for fitting. Formula intercept terms are ignored. Numeric design columns are scaled by training means and sample SDs by default. Prediction uses those fixed statistics. Votes are not calibrated probabilities. The dense pair Gram matrix costs O(m^2) space; each coordinate sweep costs O(m^2). Fits stop on unchanged-sweep or total-sweep budgets; inspect diagnostics() for accuracy. Const methods do not mutate fitted state; returned tables/matrices are owned copies.

    Example
    const auto iris = dm::datasets::iris();
const dm::stats::SVM model(iris, "Species ~ .");
std::print("{:.4f}\n", model.training_accuracy()); // 0.9733

    decision_function

    #source
    linalg::DenseMatrix< double > decision_function(const dstruct::DataFrame & newdata) const

    Raw one-vs-one decision values, as in an SVM's pairwise decision_function.

    Columns enumerate (classes()[i], classes()[j]) with i < j, i outermost. A non-negative value votes for class i; a negative value votes for class j. Values are functional margins, not probabilities or geometric distances. Scaling uses training means and sample standard deviations. No model state is changed.

    Parameters
    newdata

    Predictor rows; response optional. Missing-predictor rows produce NaNs.

    Returns

    Owned matrix with newdata.nrows() rows and k*(k-1)/2 columns.

    Throws
    std::invalid_argument

    If required columns are absent or types are incompatible.

    std::runtime_error

    For unseen categorical levels or no complete predictor rows.

    std::domain_error

    If a formula transformation is outside its domain.

    Example
    const auto iris = dm::datasets::iris();
const dm::stats::SVM model(iris, "Species ~ Petal.Length + Petal.Width");
const auto values = model.decision_function(iris.head(3)); // 3 rows, 3 columns

    diagnostics

    #source
    dstruct::DataFrame diagnostics() const

    Per-pair primal/dual objectives and numerical optimality checks.

    One row per pair in decision_function() order: positive_class, negative_class, observations, support_vectors, bias, norm_squared, hinge_loss, primal, dual, gap, equality_residual, max_kkt_violation, sweeps. Norm is in kernel feature space; primal = norm_squared/2 + C*hinge_loss; gap = primal-dual is not clipped. Equality residual is abs(sum(alpha*y)). KKT residual is max of max(0,1-y*f) where alpha<C-epsilon and max(0,y*f-1) where alpha>epsilon, with epsilon=min(1e-8,C*1e-6) to ignore rounding-sized distances from a box face. Checks describe the returned iterate; the sweep limit does not certify convergence. Convexity, weak duality and gap interpretation require a positive-semidefinite kernel; arbitrary sigmoid parameters do not guarantee this. Tables are owned copies; O(k^2).

    Returns

    Owned diagnostic table, one row per binary model.

    Example
    const dm::stats::SVM model(dm::datasets::iris(), "Species ~ .");
std::print("{}\n", model.diagnostics().to_md(4));

    training_details

    #source
    dstruct::DataFrame training_details() const

    Training coefficients and margins, including non-support points, for every pair.

    Rows are grouped by pair then retained training order. Columns: positive_class, negative_class, row (zero-based ORIGINAL input row), label, y (+1 for first class), alpha, decision, margin (y*decision), slack (max(0,1-margin)). Alpha is the returned SMO iterate; prediction drops coefficients <=1e-8, so differences at that scale may occur. Returns owned copies; O(sum of pair training sizes) time/storage.

    Returns

    Table of coefficients and functional margins in training feature space.

    Example
    const dm::stats::SVM model(dm::datasets::iris(), "Species ~ .");
std::print("{}\n", model.training_details().head(5).to_md(4));

    error

    #source
    double error(const dstruct::DataFrame & data) const

    Misclassification rate on new labelled rows, like a classifier's score complement.

    Skips rows with a null response or missing predictors; unknown non-null response labels count as errors. Uses training preprocessing; does not refit. O(prediction cost).

    Parameters
    data

    Frame containing the original response column and all predictors.

    Returns

    Fraction of evaluable rows predicted incorrectly, in [0,1].

    Throws
    std::invalid_argument

    If the response is absent or no evaluable rows remain, or predictor columns/types are incompatible.

    std::runtime_error

    For unseen categorical levels or no complete predictor rows.

    std::domain_error

    If a formula transformation is outside its domain.

    Example
    const auto [train, test] = dm::stats::train_test_split(dm::datasets::iris(), 0.3, 42, "Species");
const dm::stats::SVM model(train, "Species ~ .");
const double test_error = model.error(test);

    plot_decision_regions

    #source
    graphics::RPlot plot_decision_regions(
    const std::string & x_feature,
    const std::string & y_feature,
    std::size_t grid_resolution = 100,
    std::optional< std::array< double, 4 > > limits = std::nullopt) const

    Shaded decision regions and original training points for a two-numeric-predictor SVM.

    Evaluates at cell centres and merges runs of equal predicted class into rectangles. Limits default to training ranges padded by 5% horizontally and 10% vertically. The result is a sampled approximation, not an exact contour; O(grid_resolution^2) predictions. Training points are coloured by observed class. Model is unchanged.

    Parameters
    x_feature

    Numeric predictor for the horizontal axis.

    y_feature

    Other numeric predictor for the vertical axis.

    grid_resolution

    Cells per axis, default 100, clamped to at least 2.

    limits

    Optional finite increasing {xmin,xmax,ymin,ymax} box.

    Returns

    Owned plot with axes in unscaled design-column units.

    Throws
    std::invalid_argument

    If the model is not on exactly these two numeric predictors, or limits are non-finite or not increasing.

    Example
    const dm::stats::SVM model(dm::datasets::iris(), "Species ~ Petal.Length + Petal.Width");
model.plot_decision_regions("Petal.Length", "Petal.Width").save_svg("svm.svg");
