    class datamunge::stats

    LLE

    class LLE
    #include <datamunge/stats/lle.hpp> source

    Locally Linear Embedding (Roweis and Saul 2000) of selected numeric columns of a DataFrame.

    Fitting finds each row's LLEOptions::n_neighbors nearest rows (brute force, \(O(n^2p)\)), solves for the reconstruction weights with lle_reconstruction_weights() ( \(O(nk^3)\)), forms \(M=(I-W)^\top(I-W)\) and computes its full eigendecomposition with linalg::symmetric_eigen() ( \(O(n^3)\), about one second at \(n=1000\)). Rows with a null in any feature column are dropped first.

    The embedding is \(Y=[v_1,\dots,v_d]\), the eigenvectors of the \(d\) smallest non-trivial eigenvalues, smallest first; each column has unit length and sums to zero, as in scikit-learn (Roweis and Saul scale by \(\sqrt n\) instead). Each column's sign is fixed so that its largest-magnitude entry is positive. A connected neighbour graph gives one trivial eigenvalue 0 (the constant vector). A neighbour graph with \(c\) connected components makes \(M\) block diagonal, with one zero eigenvalue per component, so the \(c\) smallest are discarded; the components are then embedded independently and each remaining eigenvector lives on one component only. The trivial eigenvectors are known exactly (component indicators), so they are shifted above the spectrum before solving: an embedding eigenvalue close to zero then cannot mix with them, and every column sums to zero on each component to rounding error (scikit-learn instead drops the first eigenvector as returned, which can be a rotation of the two). connected_components() reports \(c\): when it exceeds 1, increase n_neighbors or embed the components separately.

    Example
    const auto roll = dm::datasets::swiss_roll(400, 0.0, 1);
const dm::stats::LLE lle(roll, {"x", "y", "z"}, {.n_components = 2, .n_neighbors = 12});
std::print("{} {}\n", lle.observations(), lle.connected_components());  // 400 1
    References

    • S. T. Roweis and L. K. Saul (2000). "Nonlinear dimensionality reduction by locally linear embedding". Science 290(5500), 2323-2326. doi:10.1126/science.290.5500.2323

    • scikit-learn LocallyLinearEmbedding: https://scikit-learn.org/stable/modules/generated/sklearn.manifold.LocallyLinearEmbedding.html

    cost

    #source
    double cost(const std::vector< double > & values) const

    Embedding cost \(\Phi(v)=\sum_i\big(v_i-\sum_jw_{ij}v_j\big)^2=v^\top Mv\) of a candidate coordinate, after centring it and scaling it to unit length.

    On the same scale as eigenvalues(): every embedding column \(c\) has cost equal to its eigenvalue, and no unit, zero-sum vector costs less than the smallest non-trivial one. Comparing the cost of a known coordinate (the arc length of a Swiss roll, say) with that of the raw input columns shows which of them the embedding will prefer.

    Parameters
    values

    One value per fitted row (align with kept_row_indices()).

    Returns

    \(\Phi\) of the centred, unit-length values.

    Throws
    std::invalid_argument

    If the length is not observations() or values is constant.

    Example
    const auto roll = dm::datasets::swiss_roll(1000, 0.0, 1);
const dm::stats::LLE lle(roll, {"x", "y", "z"}, {.n_neighbors = 12});
std::print("{:.2e}\n", lle.cost(roll.numeric_column("arc_length").values()));  // 1.18e-05
