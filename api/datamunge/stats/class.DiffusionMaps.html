    DiffusionMaps

    class DiffusionMaps
    #include <datamunge/stats/diffusion_maps.hpp> source

    Dense Gaussian diffusion maps with alpha degree correction and right Markov eigenvectors. Coordinates are lambda^time D^-1/2 v, where v has Euclidean norm one. Degree weighting, feature units, null handling, time and eigenvalue conventions follow diffusion_maps_trace(). Density independence at alpha one is an asymptotic manifold result under regularity and sampling conditions, not an exact finite-data guarantee. Fit work O(n*n*p+n^3), temporary storage O(n*n+n*p), retained storage O(n*k+n+p). The object owns its results; concurrent const reads are safe. No prediction on new rows.

    Example
    dm::dstruct::DataFrame d;d.add_column("x",std::vector<double>{0,1,2});
dm::stats::DiffusionMaps m(d,{"x"},{1,1,0,1});
std::print("{} {}\n",m.observations(),m.n_components()); // 3 1
    References

    • Coifman and Lafon (2006), Diffusion maps. doi:10.1016/j.acha.2006.04.006
