    class datamunge::stats

    GLMM

    class GLMM
    #include <datamunge/stats/glmm.hpp> source

    Fits binary or count mixed models by a maximum-working-likelihood PQL approximation.

    A single lme4-style random term supports an intercept and plain numeric slopes, e.g. y ~ x + (1 + x | group). Fixed terms use Formula. Formula-null, group-null and random-slope-null rows are omitted jointly; retained numeric values must be finite. Requires n>p>0, full fixed rank and at least two retained groups. Binomial proportions without trial counts and fractional Poisson counts are rejected. No weights/offsets, nested/crossed groups or observation-level dispersion parameter are implemented. Working and stored training means are bounded at 1e-8 (and 1-1e-8 for binomial) for finite relinearization; predictions use the direct stable inverse link.

    Each outer iteration freezes a working response/weights and estimates covariance by profiled Gaussian ML (not REML). DE plus bounded local polishing is approximate. This is not exact GLMM marginal maximum likelihood: working_criterion(), historical deviance(), aic() and bic() are working-Gaussian quantities, unsuitable for original response likelihood comparisons. Wald standard errors condition on estimated covariance.

    The Woodbury solve factors q-by-q matrices within each group and a p-by-p fixed information matrix. One objective evaluation costs O(n*(p*p+p*q+q*q)+G*q*q*q+p*p*p), using O(n*(p+q)+G*q*q+p*p) workspace. Recording K states additionally stores O(K*(p+G*q+q*q)). Const methods have no mutable caches and support concurrent reads of immutable input frames. Borrowed references live as long as the model.

    Example
    dm::dstruct::DataFrame d;
d.add_column("y",std::vector<double>{1,3,5,7});
d.add_column("g",std::vector<std::string>{"A","A","B","B"});
dm::stats::GLMMOptions opt; opt.family=dm::stats::GLMMFamily::Poisson;
opt.fixed_random_intercept_sd=1.0;
const dm::stats::GLMM m(d,"y ~ 1 + (1 | g)",opt);
std::print("{} {}\n",m.observations(),m.num_groups()); // 4 2

    #source
    GLMM(const Formula & formula, const dstruct::DataFrame & data, GLMMOptions options = {})

    Fits the same model from a formula object, in R's (formula, data) argument order.

    Same as the (data, formula, ...) constructor; a string literal or std::string converts to Formula implicitly, so GLMM("y ~ x + (1|g)", data) also works.

    Parameters
    formula

    Model formula, e.g. dm::formula("y ~ x + (1|g)").

    data

    Data frame holding every column the formula names.

    options

    Same as in the (data, formula, ...) constructor.

    Throws
    std::invalid_argument

    As the data-first constructor.

    std::runtime_error

    As the data-first constructor.

    Example

    See GLMM; GLMM(dm::formula("y ~ 1 + (1|g)"),d,opt) is equivalent.

    std::vector< double > predict(const dstruct::DataFrame & newdata) const

    Conditional means for known groups, or zero-random-effect means otherwise.

    Parameters
