    class datamunge::stats

    GLM

    class GLM
    #include <datamunge/stats/glm.hpp> source

    Maximum-likelihood canonical-link regression by iteratively reweighted least squares.

    Formula-null rows are omitted jointly; all retained design/response values and prior weights must be finite. Requires n > p > 0 and full column rank. Categorical responses are not auto-encoded. Binomial responses must be exactly zero or one; fractional nonnegative Poisson responses permit fitting but have no count-likelihood AIC. Fractional binomial prior weights use a power likelihood, not R's rounded-trial AIC. Read converged() and boundary() before using inference: deviance convergence alone does not establish existence of a finite MLE, especially under logistic separation. A finite last iterate is retained at max_iter; invalid/rank-deficient steps throw.

    This implementation explicitly accumulates the QR factor Q: fitting K updates costs O(K*n*n*p + K*p*p*p) work and O(n*n + n*p + K*p) storage. Const operations share no mutable caches; concurrent const use is supported when input frames are not mutated. Returned references live as long as the model.

    Example
    dm::dstruct::DataFrame d;
d.add_column("y",std::vector<double>{0,0,1,1});
const dm::stats::GLM m(d,"y ~ 1",{.family=dm::stats::GLMFamily::Binomial});
std::print("{:.1f} {}\n",m.fitted_values()[0],m.converged()); // 0.5 true

    #source
    double aic() const

    R-family AIC including the dispersion parameter when estimated; NaN for fractional Poisson responses.

    Returns

    R-family AIC including the dispersion parameter when estimated; NaN for fractional Poisson responses. Fractional binomial weights use a Bernoulli power likelihood rather than rounded R trials. Gamma follows R's family convention using deviance/sum(weights) inside its density, an approximation to a fully maximized shape likelihood; the Pearson dispersion used for coefficient inference is a separate estimate.

    #source
    GLMPrediction predict(
    const dstruct::DataFrame & newdata,
    GLMPredictionInterval interval,
    double level = 0.95) const

    Predicts conditional means and optional pointwise mean-response confidence limits.

    Parameters
    newdata

    Query frame; null predictors yield NaN, response is ignored.

    interval

    None or Confidence; no observation/predictive intervals are implemented.

    level

    Finite confidence probability strictly between zero and one, even for None.

    Returns

    Owned vectors. SE is delta-method; limits transform link-scale z/t endpoints. For Gamma inverse links, a confidence interval reaching eta<=0 has upper limit infinity; a query with eta<=0 is rejected. Limits are pointwise and condition on the fitted model.

    Throws
    std::invalid_argument

    Invalid level/enum, nonfinite query design, unknown levels or Gamma eta<=0.

    std::runtime_error

    No complete query rows.

    Example
    dm::dstruct::DataFrame d; d.add_column("y",std::vector<double>{0,0,1,1});
const dm::stats::GLM m(d,"y ~ 1",{.family=dm::stats::GLMFamily::Binomial});
const auto p=m.predict(d,dm::stats::GLMPredictionInterval::Confidence);
std::print("{:.1f}\n",p.fit[0]); // 0.5
