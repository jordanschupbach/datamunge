    AdaBoostClassifier

    class AdaBoostClassifier
    #include <datamunge/stats/adaboost_classifier.hpp> source

    Binary AdaBoost.M1 classifier with decision stumps, fit from a DataFrame and an R-style formula whose response is a two-level string column.

    The alphabetically second class is coded \(y=+1\) (positive_class()) and the first \(y=-1\). Each round fits the stump with the smallest weighted error \(\varepsilon_t\), gives it the vote \(\alpha_t=\tfrac12\ln\frac{1-\varepsilon_t}{\varepsilon_t}\) and reweights the rows by \(e^{-\alpha_t y_i h_t(x_i)}\); the classifier is the sign of \(F(x)=\sum_t\alpha_t h_t(x)\). Rows with a missing response or predictor are dropped.

    Example
    const auto [train, test] = dm::stats::train_test_split(dm::datasets::breast_cancer(), 0.3, 1, "diagnosis");
const dm::stats::AdaBoostClassifier model(train, "diagnosis ~ .", {.n_rounds = 200});
std::print("test error {:.3f}\n", model.error(test));
std::print("{}\n", model.history().head(5).to_md());
    References

    • Y. Freund, R. E. Schapire (1997). A decision-theoretic generalization of on-line learning and an application to boosting. Journal of Computer and System Sciences 55(1), 119-139.

    • R. E. Schapire, Y. Freund, P. Bartlett, W. S. Lee (1998). Boosting the margin. Annals of Statistics 26(5), 1651-1686.

    #source
    graphics::RPlot plot_decision_regions(const dstruct::DataFrame & data) const

    The exact decision regions of a two-predictor model with data drawn on top.

    Stumps only cut along the axes, so the prediction is constant on each cell of the grid formed by the stumps' thresholds; each cell is drawn as one shaded rectangle.

    Parameters

    Rows to draw as points, coloured by their true class.

    if the model does not have exactly two predictors.
