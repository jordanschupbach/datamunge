    DecisionTreeClassifier

    class DecisionTreeClassifier
    #include <datamunge/stats/decision_tree_classifier.hpp> source

    CART binary classification tree, fit from a data frame and an R-style formula whose response is a string column.

    Each node is split on one predictor at a threshold \(x_j\le c\), choosing the predictor and the midpoint \(c\) between consecutive distinct values that most reduce the weighted impurity of the children. Each predictor's rows are sorted once per node and swept from left to right, so a node of \(n\) rows costs \(O(pn\log n)\). Ties between equally good splits go to the predictor that comes first and the smaller threshold. Growing stops at max_depth, at pure nodes, at nodes smaller than min_samples_split, or when no split decreases the impurity by more than min_impurity_decrease. Any intercept in the formula is ignored, and rows with a missing predictor or response are dropped.

    Example
    const dm::stats::DecisionTreeClassifier tree(dm::datasets::iris(), "Species ~ .", {.max_depth = 30});
std::print("{} nodes, depth {}, training accuracy {:.2f}\n", tree.node_count(), tree.depth(),
           tree.training_accuracy()); // 17 nodes, depth 5, training accuracy 1.00

    node_frame

    #source
    dstruct::DataFrame node_frame() const

    The tree as a table, one row per node in depth-first order (node 0 is the root).

    Columns: node, depth, feature ("" for a leaf), threshold (null for a leaf; rows with a value at most the threshold go left), left and right (child node ids, -1 for a leaf), n (training rows reaching the node), impurity, and class (majority class).

    Returns

    The node table.

    Example
    const dm::stats::DecisionTreeClassifier tree(dm::datasets::iris(), "Species ~ Petal.Length + Petal.Width",
                                             {.max_depth = 2});
std::print("{}\n", tree.node_frame().to_md());

    plot_tree

    #source
    graphics::Diagram plot_tree(std::size_t max_nodes = 255) const

    Draw the actual fitted CART nodes and branches as an owned native diagram. Labels show node id, the stored threshold or predicted leaf class, sample count and the fitted Gini/entropy impurity. Thresholds use shortest round-trip decimal text; no model is refit or inferred from predictions. Left edges mean <=; right edges mean >. Leaves retain depth-first left-to-right order, with parents centred over their descendant leaves. Long labels wrap using Diagram's native font metrics; exceptionally long words can expand boxes. Layout uses O(node_count()) temporary storage without recursive traversal. The node cap is checked before layout allocation. The model is unchanged; the returned diagram owns its labels and may outlive the model. No file I/O. Concurrent const calls are safe when the model is not assigned or destroyed.

    Parameters
    max_nodes

    Optional complete-node cap, default 255; zero disables only this cap.

    Returns

    Editable diagram, with root at the top and class-coloured leaves.

    Throws
    std::length_error

    If the complete fitted tree exceeds a nonzero cap.

    std::logic_error

    If no fitted nodes remain, for example after moving the model.

    std::bad_alloc

    If owned labels or layout storage cannot be allocated.

    Example
    const dm::stats::DecisionTreeClassifier tree(dm::datasets::iris(), "Species ~ .", {.max_depth=1});
const auto picture=tree.plot_tree();
std::print("{}\n",picture.to_svg().find("n=150")!=std::string::npos); // true
