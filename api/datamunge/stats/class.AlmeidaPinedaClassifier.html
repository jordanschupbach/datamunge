    AlmeidaPinedaClassifier

    class AlmeidaPinedaClassifier
    #include <datamunge/stats/almeida_pineda_classifier.hpp> source

    Multiclass classifier whose prediction is the equilibrium of a fully recurrent tanh network, trained with Almeida-Pineda gradients.

    Unit 0 is a bias clamped to 1; the next units are clamped to the standardised predictors; then come the hidden units and one output unit per class. Every free unit connects to every unit except itself, so hidden and output units feed back into each other. A row's outputs are the output units' values at the fixed point, and the prediction is the class with the largest output. Training minimises the mean of \(\tfrac12\sum_k(x_k-t_k)^2\) with targets \(\pm\)target, by gradient descent with momentum. Rows with a missing value are dropped.

    Example
    const auto [train, test] = dm::stats::train_test_split(dm::datasets::iris(), 0.3, 1, "Species");
const dm::stats::AlmeidaPinedaClassifier model(train, "Species ~ .");
std::print("test error {:.3f}\n", model.error(test));
