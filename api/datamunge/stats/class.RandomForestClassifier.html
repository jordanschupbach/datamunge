    RandomForestClassifier

    class RandomForestClassifier
    #include <datamunge/stats/random_forest_classifier.hpp> source

    Random forest classifier: \(B\) CART trees, each fit to a bootstrap sample of the rows and restricted to \(m\) random predictors at every split, combined by majority vote.

    Built from a data frame and an R-style formula whose response is a string column, like the other stats classifiers. Rows with a missing predictor or response are dropped before fitting, and every per-row accessor (fitted classes, out-of-bag votes, margins) refers to the remaining rows in order. Each row is out of bag for the trees whose bootstrap sample missed it, about \(e^{-1}\approx37\%\) of them, and the votes of those trees give an accuracy estimate that needs no held-out data (oob_accuracy()). Ties in a vote go to the class that sorts first.

    Example
    const dm::stats::RandomForestClassifier forest(dm::datasets::iris(), "Species ~ .", {.n_trees = 200});
std::print("{} trees, m = {}, OOB accuracy {:.4f}\n", forest.n_trees(), forest.max_features_used(),
           forest.oob_accuracy()); // 200 trees, m = 2, OOB accuracy 0.9600

    permutation_importance

    #source
    RandomForestPermutationImportance permutation_importance(std::uint64_t seed = 1) const

    Out-of-bag permutation importance.

    For each tree and predictor, the predictor's values are shuffled among the tree's out-of-bag rows and the drop in that tree's out-of-bag accuracy is recorded. Unlike feature_importance(), a predictor the response does not depend on scores about 0.

    Parameters
    seed

    Seed for the shuffles.

    Returns

    Mean decrease and standard error per predictor.

    Example
    const dm::stats::RandomForestClassifier forest(dm::datasets::iris(), "Species ~ .");
const auto pi = forest.permutation_importance();
for (std::size_t j = 0; j < pi.importance.size(); ++j)
    std::print("{} {:.3f}\n", pi.predictor_names[j], pi.importance[j]);

    plot_decision_regions

    #source
    graphics::RPlot plot_decision_regions(
    const std::string & x_feature,
    const std::string & y_feature,
    std::size_t grid_resolution = 150,
    std::optional< std::array< double, 4 > > limits = std::nullopt) const

    The majority-vote class over the plane of the forest's two predictors, shaded by how unanimous the vote is, with the training points on top.

    Each class has three tints: darkest where at least 90% of trees agree, medium for 60% to 90%, palest below 60%.

    Parameters
    x_feature

    Predictor on the x axis.

    y_feature

    Predictor on the y axis.

    grid_resolution

    Cells per axis.

    limits

    Optional box {x_min, x_max, y_min, y_max}; default the training range padded by 5% in x and 10% in y.

    Returns

    The plot, with its axis limits set to the box.

    Throws
    std::invalid_argument

    If the model does not have exactly these two predictors.

    Example
    const dm::stats::RandomForestClassifier forest(dm::datasets::iris(), "Species ~ Petal.Length + Petal.Width");
forest.plot_decision_regions("Petal.Length", "Petal.Width").save_svg("forest_regions.svg");
