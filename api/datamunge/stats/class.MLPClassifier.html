    MLPClassifier

    class MLPClassifier
    #include <datamunge/stats/mlp_classifier.hpp> source

    A feed-forward neural network (multi-layer perceptron) classifier, trained by backpropagation with mini-batch stochastic gradient descent. Each layer computes an affine map followed by a nonlinearity, z = W a + b, a' = act(z); the final layer's outputs pass through a softmax to give class probabilities, and training minimizes the cross-entropy loss. With one or more hidden layers the network learns nonlinear decision boundaries no linear model can express (the classic XOR/two-moons problems); with an empty hidden-layer list it reduces exactly to multinomial logistic regression. Uses the same formula + DataFrame constructor style as the other classifiers. Rows with a null value in any model column are dropped before fitting.

    Fits the same model from a formula object, in R's (formula, data) argument order.

    Same as the (data, formula, ...) constructor; a string literal or std::string converts to Formula implicitly, so MLPClassifier("y ~ x", data) also works.
