    class datamunge::stats

    ICA

    class ICA
    #include <datamunge/stats/ica.hpp> source

    Deflationary FastICA with population whitening and frozen new-row transforms. Fits centered x=A*s under the modelling assumption of mutually independent sources and a full-column-rank instantaneous linear mixture. At most one source may be Gaussian for identifiability up to sign/scale/permutation; Gaussian subspaces remain rotationally unidentifiable. Finite-sample contrast optimization does not certify statistical independence, non-Gaussianity or true-source recovery. PCA truncation discards information before ICA. No standardization of original feature units occurs. Null feature rows are dropped jointly during fitting; retained nonfinite values are rejected. Uses 1/n covariance and matching 1/n fixed-point averages. Eigenvalue rank threshold is max(n,p)*epsilon*largest eigenvalue after a common feature-scale factor. Returned sources have population covariance identity to numerical precision, even when a finite iteration budget is exhausted. Final signs make the first largest- absolute training value positive; component order is extraction order, not variance. Owns means, retained rows, PCA whitening, rotation, training arrays and diagnostics. Inputs remain unchanged; const inference has no shared mutable caches. Same seed/STL reproduces initialization, but normal_distribution is not bit-identical across STLs. Fit work O(n*p^2+p^3+sum(iterations)*n*k+sum(iterations)*k^2); retained storage O(n*(p+k)+p^2+k^2+k*sum(iterations)). Jacobi eigensolver uses at most 100 sweeps.

    Example
    const auto d=dm::stats::ica_benchmark(100,42,"independent");
const dm::stats::ICA m(d,{"x1","x2","x3"},{3});
std::print("{} {}\n",m.observations(),m.n_components()); // 100 3

    #source
    ICA(
    const dstruct::DataFrame & data,
    const std::vector< std::string > & feature_columns,
    ICAOptions options = {})

    Fits population-whitened components immediately from numeric feature columns.

    Parameters
    data

    Borrowed input; rows with a null selected feature are omitted jointly.

    feature_columns

    Unique nonempty numeric names, defining original feature order/units.

    options

    Validated retained dimension, contrast, iteration/tolerance/seed controls.

    Throws
    std::invalid_argument

    Invalid options/schema, fewer than two complete rows, duplicate names, retained nonfinite values or insufficient numerical covariance rank.

    std::runtime_error

    A deflated initialization or contrast update collapses to zero.

    Example

    See the class example.

    #source
    dstruct::DataFrame convergence_history() const

    Returns every completed unsigned fixed-point update, before final sign fixing. History is grouped by component, with iterations starting at one. No refit.

    Returns

    Owned component, iteration, alignment_error, update_norm and w0..w(k-1) columns. Initial directions are returned separately by initial_directions().
