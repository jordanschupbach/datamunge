    TukeyHSD

    class TukeyHSD
    #include <datamunge/stats/tukey_hsd.hpp> source

    Tukey's honest significant differences for a one-way layout, like R's TukeyHSD(aov(value ~ group)).

    Compares every pair of group means with family-wise confidence intervals and adjusted p-values from the studentized range distribution, using the pooled within-group mean square error (MSE) on N-k degrees of freedom; unequal group sizes use the Tukey-Kramer standard error sqrt(MSE/2 * (1/n_i + 1/n_j)). Assumes independent normal observations with a common variance. Groups are the distinct labels sorted lexicographically (R's default factor order); comparisons follow R's order and sign: for levels a < b < c the rows are b-a, c-a, c-b, each estimating mean(group1) - mean(group2). O(N log k + k^2) work.

    Example
    const dm::stats::TukeyHSD hsd(dm::datasets::iris(), "Sepal.Length ~ Species");
std::print("{} {:.3f}\n", hsd.comparisons()[0].label(), hsd.comparisons()[0].diff);
// versicolor-setosa 0.930
    References

    • J. W. Tukey (1949). "Comparing Individual Means in the Analysis of Variance". Biometrics 5(2), 99-114. doi:10.2307/3001913

    • C. Y. Kramer (1956). "Extension of Multiple Range Tests to Group Means with Unequal Numbers of Replications". Biometrics 12(3), 307-310. doi:10.2307/3001469

    • https://stat.ethz.ch/R-manual/R-devel/library/stats/html/TukeyHSD.html

    #source
    TukeyHSD(
    const dstruct::DataFrame & data,
    const Formula & formula,
    double conf_level = 0.95)

    Runs Tukey's HSD from a one-way formula, like R's TukeyHSD(aov(value ~ group, data)).

    The formula must be response ~ group with a numeric response column and a single string grouping column; anything else on the right-hand side is rejected. Strings convert implicitly to Formula, so TukeyHSD(iris, "Sepal.Length ~ Species") works. Otherwise identical to the column-name constructor.

    Parameters
    data

    Frame holding both columns; unchanged.

    formula

    value ~ group.

    conf_level

    Family-wise confidence level, default 0.95.

    Throws
    std::out_of_range

    A missing column.

    std::invalid_argument

    A right-hand side that is not a single column name, a mistyped column (the message suggests the swapped formula when the sides look reversed), or any error of the vector constructor.

    Example
    const dm::stats::TukeyHSD hsd(dm::datasets::iris(), "Sepal.Length ~ Species");
std::print("{}\n", hsd.comparisons()[0].label());   // versicolor-setosa

    plot

    #source
    graphics::RPlot plot(
    graphics::RGBA significant = {220, 38, 38},
    graphics::RGBA not_significant = {100, 116, 139}) const

    Plots each difference with its family-wise interval, like R's plot(TukeyHSD(...)).

    One horizontal interval per comparison (first comparison on top) with the estimate as a point and a reference line at zero; the left margin is widened to fit the labels. Intervals that exclude zero, i.e. pairs whose adjusted p-value is below 1 - conf_level, are drawn in significant; the rest in not_significant. A legend names both.

    Parameters
    significant

    Color of significantly different pairs.

    not_significant

    Color of the remaining pairs.

    Returns

    A new plot; title, labels and size can be changed by chaining.

    Example
    const dm::stats::TukeyHSD hsd(dm::datasets::iris(), "Sepal.Length", "Species");
hsd.plot().save("tukey.png");
