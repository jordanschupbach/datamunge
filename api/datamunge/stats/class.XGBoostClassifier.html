    XGBoostClassifier

    class XGBoostClassifier
    #include <datamunge/stats/xgboost_classifier.hpp> source

    Local regularised second-order tree boosting with softmax class probabilities.

    Fits one tree per class per round to gradients p-y and diagonal Hessians max(p*(1-p),1e-6), starting from log training-class proportions. Scores are updated simultaneously by class within each round; this is a diagonal Newton heuristic, not an exact full-Hessian Newton step or the complete upstream XGBoost system. Formula resolution drops rows with null predictors or response; categorical responses are string labels. Finite transformed predictors are required. Training summaries are in-sample quantities. Models own their fitted design and trees; concurrent const predictions are safe when the input frame is not mutated. The exact split search rescans candidate thresholds: at most O(M*K*(p+1)*n^2*(D+1)) training work for depth D, with O(M*K*2^D) tree storage (also bounded by the available training rows).

    Example
    const dm::stats::XGBoostClassifier model(dm::datasets::iris(),"Species ~ Petal.Length + Petal.Width");
const auto classes=model.classes().size(); // 3

    predict_detail

    #source
    XGBoostClassifierPrediction predict_detail(const dstruct::DataFrame & newdata) const

    Return full-model softmax probabilities and class labels in original row order.

    A null predictor leaves that row's label and probability vector empty. The response is not required. Ties choose the first sorted class. Class probabilities use max-subtracted softmax; they are not calibrated posteriors. O(n*M*K*D) tree traversal, with O(n*K) temporary/result storage.

    Parameters
    newdata

    Borrowed frame containing the fitted predictor schema.

    Returns

    Owned labels and probabilities; see XGBoostClassifierPrediction.

    Throws
    std::invalid_argument

    If a used transformed predictor or accumulated score is non-finite.

    std::runtime_error

    If a categorical predictor level was unseen at training.

    std::out_of_range

    If a required predictor column is missing.

    std::domain_error

    If a formula transform is outside its mathematical domain.

    Example
    const dm::stats::XGBoostClassifier model(dm::datasets::iris(),"Species ~ Petal.Length");
const auto result=model.predict_detail(dm::datasets::iris().head(1));
const auto columns=result.probability[0].size(); // 3

    staged_evaluation

    #source
    dstruct::DataFrame staged_evaluation(const dstruct::DataFrame & data) const

    Evaluate a fixed fitted ensemble after every round, including its round-zero priors.

    Resolves the supplied frame with the training design, omits null response or predictor rows, and traverses each fitted tree once per usable row. No refitting or state mutation occurs. mean_log_loss is -mean(log(p_true)) with p_true floored at 1e-15, matching training_deviance(); brier is mean(sum_k (p_k-y_k)^2), without division by class count. Accuracy is a fraction. The same complete-case rows are used at every round. O(n*M*K*D) traversal plus O(n*M*K) scoring; O(n*K+M) working/result storage.

    Parameters
    data

    Borrowed labelled evaluation data with the training predictor schema.

    Returns

    Owned round, input_rows, evaluated_rows, skipped_rows, accuracy, mean_log_loss and brier columns for rounds 0 through n_trees().

    Throws
    std::invalid_argument

    If a complete-case response class is absent from training, the response schema is invalid, or a used transformed predictor or accumulated score is non-finite.

    std::runtime_error

    If no complete evaluation rows remain or predictor levels are unseen.

    std::out_of_range

    If a required predictor column is missing.

    std::domain_error

    If a formula transform is outside its mathematical domain.

    Example
    dm::stats::XGBoostClassifierOptions options; options.n_trees=5;
const dm::stats::XGBoostClassifier model(dm::datasets::iris(),"Species ~ Petal.Length",options);
const auto curve=model.staged_evaluation(dm::datasets::iris());
const auto rows=curve.nrows(); // 6, including round zero

    evaluation

    #source
    dstruct::DataFrame evaluation(const dstruct::DataFrame & data) const

    Return full-model held-out metrics using the same complete-case rules as staged_evaluation().

    Computes the staged path and returns its last row; never refits the model. Time/storage and score definitions are those of staged_evaluation().

    Parameters
    data

    Borrowed labelled evaluation frame, unchanged.

    Returns

    One owned row with the final round's counts, accuracy, mean_log_loss and brier.

    Throws
    std::invalid_argument

    If schema, classes or finite-value constraints are violated.

    std::runtime_error

    If no complete rows remain or categorical predictor levels are unseen.

    std::out_of_range

    If a required predictor column is missing.

    std::domain_error

    If a formula transform is outside its mathematical domain.

    Example
    const dm::stats::XGBoostClassifier model(dm::datasets::iris(),"Species ~ Petal.Length");
const auto scores=model.evaluation(dm::datasets::iris());
const auto rows=scores.double_at("evaluated_rows",0); // 150
