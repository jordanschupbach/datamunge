    KernelRidgeRegression

    class KernelRidgeRegression
    #include <datamunge/stats/kernel_ridge_regression.hpp> source

    Dense RKHS least squares with a genuine optional unpenalized intercept. Minimizes sum_i(y_i-b-f(x_i))^2+lambda*||f||_H^2. With a free intercept, center both K and y: alpha=(C*K*C+lambda*I)^-1*C*y and predict with the consistently centered query kernel plus mean(y). This enforces sum(alpha)=0; the equivalent raw-kernel intercept is b=mean(y)-mean_kernel'alpha. Without an intercept, neither K nor y is centered and b=0. Formula intercept markers do not add kernel features; fit_intercept controls b explicitly.

    Numeric Formula design supports expanded transforms/categoricals. Required null fitting rows are omitted jointly; nonfinite retained cells are rejected. Training-only predictor scaling is frozen at query time. The fast LOO identity refits the intercept/kernel centering at each deletion but holds this metric and design schema fixed. It does not refit scaling or hyperparameter selection. Use kernel_ridge_cross_validate() for fold-local preprocessing, and a separate holdout to assess the selected procedure. fitted_values()/rmse()/r_squared() retain their historical LOO meaning; training_predictions() is resubstitution.

    Lambda zero uses a relative-rank spectral pseudoinverse and explicit fixed-metric deletions; it is a numerical minimum-RKHS-norm least-squares limit, not guaranteed interpolation for duplicate/incompatible rows. Positive lambda never uses an arbitrary denominator or leverage floor. Tiny lambdas can still be ill-conditioned.

    G gamma candidates and L penalties cost O(G*(n^2*p+n^3+L*n^2)); zero-penalty deletion diagnostics can add O(G*n^4). Dense fitted storage is O(n^2+n*p). Models own their arrays; const calls use no mutable caches and do not mutate inputs.

    Example
    dm::dstruct::DataFrame d;
d.add_column("x", std::vector<double>{0, 1});
d.add_column("y", std::vector<double>{0, 2});
dm::stats::KernelRidgeRegressionOptions o;
o.lambda = .5;
o.gamma = std::log(2.);
o.standardize = false;
const dm::stats::KernelRidgeRegression m(d, "y ~ x", o);
std::print("{:.1f} {:.1f}\n", m.training_predictions()[0],
           m.training_predictions()[1]); //
                                         // Expected: 0.5 1.5
