    ElasticNet

    class ElasticNet
    #include <datamunge/stats/elastic_net.hpp> source

    Elastic-net penalized least squares via cyclic exact-coordinate descent. Accepts Formula numeric/categorical main effects and interactions. Rows with a null formula value are dropped; retained design entries and responses must be finite. With an intercept, centre X/y; without one, use a zero origin. Optional predictor scaling uses sqrt(sum((x-mean)^2)/n), including for indicator/interaction columns; exact zero scales become one. Response is never standardized. Published slopes and intercept are restored to raw formula-design units; penalties apply to scaled slopes. Automatic paths share a grid derived from the full training set. Each validation fold fits its own predictor/response offsets and predictor scales on training rows, using the fixed full-data Formula schema, and pools held-out squared errors by row. Selection minimizes this MSE, retaining the first (largest lambda) on exact ties. The selected full-data path fit supplies coefficients; exhausted fits are retained and flagged, not silently removed from selection. Inspect fold and path status. Cyclic descent uses actual column norms, including zero/constant columns. Stopping requires max_change<=tol and KKT<=tol*max(1,max_j(abs(X_j^T*y/n))) in preprocessed coordinates. A finite iteration limit returns a partial fit, with converged=false. Positive lambda*(1-alpha) gives a strictly convex slope objective; lasso/OLS can have nonunique coefficients on dependent designs. No covariance, p-values or confidence intervals are inferred from selected coefficients. Unlike the rescaled 2005 elastic net estimator, this implements the direct glmnet-style penalized objective. Owns fitted state, leaves input unchanged; const methods have no mutable caches. One t-sweep fit costs O(t*n*p); a length-L, F-fold path costs O((F+1)*L*t*n*p), plus Formula expansion, with numerical storage O(n*p+L*p+F*L).

    Example
    dm::dstruct::DataFrame d;
d.add_column("x",std::vector<double>{-1,-1,1,1});
d.add_column("y",std::vector<double>{1,1,5,5});
const dm::stats::ElasticNet m(d,"y ~ x",{.5,.5});
std::print("{:.1f} {:.0f}\n",m.coefficients()[0],m.intercept()); // 1.4 3
    References

    predict

    #source
    std::vector< double > predict(const dstruct::DataFrame & newdata) const

    Predicts using the frozen Formula schema and original-unit coefficients. No query centring/scaling is fitted. A row has the same prediction alone or batched.

    Parameters
    newdata

    Borrowed predictors; response is not required, extra columns ignored.

    Returns

    Owned vector in original row order, NaN for null-predictor rows. Empty input returns empty before schema validation. If every nonempty row is incomplete, throws.

    Throws
    std::invalid_argument

    Missing/mistyped columns, unseen categorical levels, retained nonfinite design entries, or unrepresentable predictions.

    std::runtime_error

    No complete query rows remain.

    Example
    dm::dstruct::DataFrame d;
d.add_column("x",std::vector<double>{-1,-1,1,1});
d.add_column("y",std::vector<double>{1,1,5,5});
const dm::stats::ElasticNet m(d,"y ~ x",{.5,.5});
std::print("{:.1f}\n",m.predict(d)[0]); // 1.6

    score

    #source
    dstruct::DataFrame score(const dstruct::DataFrame & newdata) const

    Scores complete labelled query rows using the frozen model.

    Parameters
    newdata

    Borrowed response/predictor columns; null formula rows are omitted.

    Returns

    Owned row: n_input, n_scored, rmse, mae, r_squared, mean_baseline_rmse. Metrics use retained query rows; the baseline is the complete training response mean, including for no-intercept models.     Throws

    Example
