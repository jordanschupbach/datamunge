    KNNRegressor

    class KNNRegressor
    #include <datamunge/stats/knn_regressor.hpp> source

    k-nearest-neighbour regressor from a formula y ~ x1 + x2 + ....

    The prediction at \(x\) is \(\hat f(x)=\frac1k\sum_{j\in N_k(x)}y_j\) (or the \(1/d\)-weighted mean), a step function of \(x\). Ties in distance are broken by training-row order; differences are taken on the raw values before scaling, so raw ties stay exact. fitted_values(), r_squared() and rmse() are leave-one-out: each row is predicted from the other \(n-1\) rows, with the standardisation recomputed without it.

    Example
    const dm::stats::KNNRegressor knn(dm::datasets::iris(),
                                  "Petal.Length ~ Sepal.Length + Sepal.Width + Petal.Width");
std::print("{:.4f}\n", knn.r_squared());  // leave-one-out R^2, about 0.96
    References

    • scikit-learn KNeighborsRegressor: https://scikit-learn.org/stable/modules/generated/sklearn.neighbors.KNeighborsRegressor.html
