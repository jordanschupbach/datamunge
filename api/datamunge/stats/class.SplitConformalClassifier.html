    SplitConformalClassifier

    class SplitConformalClassifier
    #include <datamunge/stats/conformal.hpp> source

    Split (inductive) conformal prediction for classification.

    Wraps any classifier that outputs class probabilities. Each calibration example's true class is scored, and a test point's set holds every class whose score is at most the conformal_quantile() of the calibration scores. If calibration and test data are exchangeable, the set contains the true class with probability at least \(1-\alpha\), whatever the model and the data distribution. With class_conditional, the guarantee holds for each class separately.

    Example
    const dm::stats::SplitConformalClassifier cp({{0.9, 0.1}, {0.2, 0.8}, {0.6, 0.4}, {0.3, 0.7}},
                                            {"no", "yes", "no", "yes"}, {"no", "yes"}, {.alpha = 0.2});
std::print("{}\n", cp.predict_set({0.65, 0.35})[0]);  // no (threshold 0.4, the largest of 4 scores)

    p_values

    #source
    std::vector< double > p_values(const std::vector< double > & probabilities) const

    Conformal p-value of each class for one probability row.

    \(p_k=(1+\#\{i:s_i\ge s_k\})/(n+1)\) over the calibration scores (of class \(k\) only, when class-conditional). Under exchangeability the true class's p-value is super-uniform, \(P(p_y\le t)\le t\), and the set is \(\{k:p_k>\alpha\}\) up to ties (before the nonempty fallback).

    Parameters
    probabilities

    Class probabilities.

    Returns

    One p-value per class.
