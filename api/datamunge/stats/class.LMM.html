    class datamunge::stats

    LMM

    class LMM
    #include <datamunge/stats/lmm.hpp> source

    A linear mixed model \(y=X\beta+Zb+\varepsilon\) with one grouping factor, fit by REML or ML from a DataFrame and an lme4-style formula.

    The formula is a fixed-effects formula plus one random-effects term, e.g. "score ~ hours + (1 + hours | school)". The fixed part supports everything Formula does (factors, interactions, I(...), poly(...)). The random part is an intercept and/or plain numeric columns against one grouping column: (1 | g), (x | g) (intercept and slope), (0 + x | g) (slope only). Each group \(g\) gets a random vector \(b_g\sim N(0,\Sigma)\), independent across groups and of the errors \(\varepsilon\sim N(0,\sigma^2I)\). Rows with a null in any column used are dropped.

    With \(\Sigma=\sigma^2\Lambda\Lambda^\top\) ( \(\Lambda\) lower triangular, its entries are \(\theta\)), the marginal covariance of group \(g\)'s responses is \(\sigma^2M_g\) with \(M_g=I+Z_g\Lambda\Lambda^\top Z_g^\top\). For fixed \(\theta\), \(\beta\) is the generalised least squares estimate and \(\sigma^2\) has a closed form, so the (RE)ML criterion is profiled down to a function of \(\theta\) alone (deviance_at()). It is minimised by differential evolution followed by a Nelder-Mead polish. Fixed effects, standard errors, variance components, log-likelihood and BLUPs agree with R's nlme::lme and lme4::lmer (standard errors use \(\sigma^2(X^\top V^{-1}X)^{-1}\); tests on them use the normal distribution, so they are z tests, like lme4's t values read against \(N(0,1)\)).

    Example
    const auto growth = dm::datasets::orthodont();
const dm::stats::LMM fit(growth, "distance ~ age + (1 | subject)");
std::print("{:.4f} {:.4f}\n", fit.random_effect_std_devs()[0], fit.residual_std_dev());  // 2.1147 1.4316

    deviance_at

    #source
    double deviance_at(const std::vector< double > & theta) const

    The profiled criterion at any \(\theta\), with \(\beta\) and \(\sigma^2\) at their optimal values for that \(\theta\).

    ML: \(n\log(2\pi\hat\sigma^2_\theta)+n+\sum_g\log|M_g|\) with \(\hat\sigma^2_\theta=r^\top M^{-1}r/n\). REML: \((n-p)\log(2\pi\hat\sigma^2_\theta)+(n-p)+\sum_g\log|M_g|+\log|X^\top M^{-1}X|\) with \(\hat\sigma^2_\theta=r^\top M^{-1}r/(n-p)\). Evaluating it on a grid draws the likelihood profile of the variance components.

    Parameters
    theta

    \(q(q+1)/2\) entries of \(\Lambda\), as theta().

    Returns

    The criterion (smaller is better).

    Throws
    std::invalid_argument

    If theta has the wrong length.

    Example
    const dm::stats::LMM fit(dm::datasets::orthodont(), "distance ~ age + (1 | subject)");
std::print("{:.3f} {:.3f}\n", fit.deviance_at(fit.theta()), fit.deviance_at({0.0}));  // 447.003 509.169
