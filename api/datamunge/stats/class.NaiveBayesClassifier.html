    NaiveBayesClassifier

    class NaiveBayesClassifier
    #include <datamunge/stats/naive_bayes_classifier.hpp> source

    Naive Bayes classifier from a formula class ~ x1 + x2 + ... mixing numeric and categorical predictors.

    The predictors are modelled as independent given the class, \(P(c\mid x)\propto\pi_c\prod_jp_j(x_j\mid c)\). A numeric predictor has a Gaussian density per class (maximum-likelihood mean and variance, divisor \(n_c\), plus a small floor). A categorical predictor has one smoothed frequency table per class over its levels, modelled as one variable rather than as separate dummy columns. Formula terms must be plain column references. Rows with a missing predictor or class are dropped. Posterior probabilities are computed in log space and normalised with the log-sum-exp shift.

    training_accuracy() and confusion_matrix() are resubstitution figures (the model is fitted and evaluated on the same rows). loo_fitted_classes() and loo_accuracy() are exact leave-one-out figures: the fitted counts, means and variances are downdated without each row in turn, which equals refitting \(n\) times (with the categorical levels kept as those of the full data).

    Example
    const auto penguins = dm::datasets::penguins();
const dm::stats::NaiveBayesClassifier nb(penguins, "species ~ bill_length_mm + bill_depth_mm + island");
std::print("{:.4f} {:.4f}\n", nb.training_accuracy(), nb.loo_accuracy());
    References

    • D. D. Lewis (1998). "Naive (Bayes) at forty: the independence assumption in information retrieval". ECML-98, LNCS 1398, 4–15.

    • P. Domingos and M. Pazzani (1997). "On the optimality of the simple Bayesian classifier under zero-one loss". Machine Learning 29, 103–130.

    • scikit-learn GaussianNB and CategoricalNB: https://scikit-learn.org/stable/modules/naive_bayes.html
