    DiffusionMapsTrace

    struct DiffusionMapsTrace
    #include <datamunge/stats/diffusion_maps.hpp> source

    Value-owned matrices from the actual dense diffusion fit, without replay. All square matrices are n by n in kept-row order. Right eigenvectors have D-weighted norm one, not stationary-probability norm one. Multiply coordinates by sqrt(sum(degrees)) to obtain the latter convention. No input references survive.

    Example

    See diffusion_maps_trace().

    References

    • Coifman and Lafon (2006), Diffusion maps. doi:10.1016/j.acha.2006.04.006
