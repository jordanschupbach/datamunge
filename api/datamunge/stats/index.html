    Classes

    DiffusionMapsDense Gaussian diffusion maps with alpha degree correction and right Markov eigenvectors. Coordinates are lambda^time D^-1/2 v, where v has Euclidean norm one. Degree weighting, feature units, null handling, time and eigenvalue conventions follow diffusion_maps_trace(). Density independence at alpha one is an asymptotic manifold result under regularity and sampling conditions, not an exact finite-data guarantee. Fit work O(n*n*p+n^3), temporary storage O(n*n+n*p), retained storage O(n*k+n+p). The object owns its results; concurrent const reads are safe. No prediction on new rows.
    DiffusionMapsOptionsDense Gaussian diffusion-map controls, with raw feature units and no automatic scaling. Defaults retain two coordinates, epsilon one, alpha one half and time one. Validated by DiffusionMaps and diffusion_maps_trace().
    DiffusionMapsTraceValue-owned matrices from the actual dense diffusion fit, without replay. All square matrices are n by n in kept-row order.     Functions

    diffusion_maps_trace()Fits dense diffusion coordinates and retains every normalization matrix from that execution. Shares the model kernel. Drops rows with a null feature; rejects nonfinite retained values. Uses raw Euclidean features, no centring or standardization. Time zero uses scale one even for zero eigenvalues. Roundoff-negative eigenvalues within 128*n*eps are clipped to zero; a more negative spectrum is rejected. Numerically disconnected kernels are rejected because discarding a single trivial mode would be ambiguous. Work O(n*n*p+n^3), storage O(n*n+n*p), including six owned square trace matrices.     datamunge/stats/elastic_net.hpp

    Classes

    ElasticNetElastic-net penalized least squares via cyclic exact-coordinate descent. Accepts Formula numeric/categorical main effects and interactions. Rows with a null formula value are dropped; retained design entries and responses must be finite. With an intercept, centre X/y; without one, use a zero origin. Optional predictor scaling uses sqrt(sum((x-mean)^2)/n), including for indicator/interaction columns; exact zero scales become one. Response is never standardized. Published slopes and intercept are restored to raw formula-design units; penalties apply to scaled slopes. Automatic paths share a grid derived from the full training set. Each validation fold fits its own predictor/response offsets and predictor scales on training rows, using the fixed full-data Formula schema, and pools held-out squared errors by row. Selection minimizes this MSE, retaining the first (largest lambda) on exact ties. The selected full-data path fit supplies coefficients; exhausted fits are retained and flagged, not silently removed from selection. Inspect fold and path status. Cyclic descent uses actual column norms, including zero/constant columns. Stopping requires max_change<=tol and KKT<=tol*max(1,max_j(abs(X_j^T*y/n))) in preprocessed coordinates. A finite iteration limit returns a partial fit, with converged=false. Positive lambda*(1-alpha) gives a strictly convex slope objective; lasso/OLS can have nonunique coefficients on dependent designs. No covariance, p-values or confidence intervals are inferred from selected coefficients. Unlike the rescaled 2005 elastic net estimator, this implements the direct glmnet-style penalized objective. Owns fitted state, leaves input unchanged; const methods have no mutable caches. One t-sweep fit costs O(t*n*p); a length-L, F-fold path costs O((F+1)*L*t*n*p), plus Formula expansion, with numerical storage O(n*p+L*p+F*L).
    ElasticNetOptionsGaussian elastic-net controls in glmnet's lambda/alpha parameterization. The objective is RSS/(2*n)+lambda*(alpha*L1+(1-alpha)*L2_squared/2), applied to preprocessed slope coefficients. The intercept is unpenalized; response is not scaled. CV-only path/fold controls are ignored for a fixed nonnegative lambda.
    LassoLasso convenience model using the shared coordinate-descent/CV engine. Fixes alpha=1; all ElasticNet contracts apply. L1 thresholding permits exact zero slopes. Dependent designs can have nonunique coefficients; predictions may still be unique.
    LassoOptionsLasso controls forwarded to ElasticNet, fixing alpha=1. Same defaults/constraints as ElasticNetOptions; no alpha field.
    RidgeRidge convenience model using the shared coordinate-descent/CV engine. Fixes alpha=0; all ElasticNet contracts apply. L2 shrinkage does not impose a sparsity threshold, but exact zero coefficients are possible for zero/orthogonal predictors.
    RidgeOptionsRidge controls forwarded to ElasticNet, fixing alpha=0. Same defaults/constraints as ElasticNetOptions; no alpha field.

    datamunge/stats/factor_analysis.hpp

    Classes

    FactorAnalysisExploratory common-factor covariance model fitted by iterative principal axes. For centred rows Z, models C approximately as Lambda*Lambda^T+diag(Psi), with unit-variance uncorrelated latent factors and diagonal variable-specific variance. This is PAF, not R factanal's maximum-likelihood estimator or a minres optimizer. Each reduced matrix replaces C's diagonal with clipped communalities; negative retained eigenvalues become zero. SMC initialization and regression scores use an eigenvalue-floored inverse, floor 1e-8*max(diag(C)); this is not a pseudoinverse. Orthogonal varimax preserves the common covariance, not the identities of factors. Factors are ordered by squared loading sum, signs by largest-magnitude loading. Rows with any null selected feature are dropped; other retained values must be finite, with positive sample variance in every selected column. Repeated names, invalid options and unrepresentable arithmetic are rejected. Negative parameter- count df is allowed for exploration, not certified identification. Boundary fits can converge: check diagnostics(), raw_uniqueness and covariance residuals. Existing uniquenesses() remain clipped nonnegative; reported communalities remain actual squared loading norms and may exceed observed variance (Heywood violation). Owns fitted state; inputs unchanged; const operations share no mutable caches. For t extraction steps, bounded Jacobi sweeps and small k, main work O(np^2+t*p^3), plus bounded rotation work; storage O(np+p^2+t*p) including the iteration history.
    FactorAnalysisOptionsControls iterative principal-axis factoring (PAF), not maximum likelihood. Both extraction and optional pairwise varimax use max_iter/tol. Extraction's absolute tolerance is in fitted variance units; rotation uses its normalized objective.

    Functions

    covariance_residual_rms()Root mean squared covariance residual over ordered off-diagonal entries.
    factor_model_sample()Samples a zero-mean Gaussian common-factor model with independent standard factors. Rows are x=Lambda*f+sqrt(Psi)*epsilon; all factor/noise draws are independent. Input loadings/unique variances are in original feature units; no sample standardization. mt19937_64 and std::normal_distribution give reproducibility within a toolchain, not bit-identical normal draws across standard libraries. Work O(npk), storage O(np+k). Inputs borrowed unchanged; no shared generator state.

    datamunge/stats/gbm_classifier.hpp

    Classes

    GBMClassifierMulticlass additive trees fitted to one-hot-minus-softmax residuals. Starts from log empirical class priors. At each round, all K residual targets use the same pre-round probabilities, then one least-squares CART tree per class is fitted. A scalar learning_rate multiplies its leaf means. There is no Newton leaf correction, (K-1)/K multiplier, centring constraint, line search or built-in early stopping; this is not numerically identical to sklearn GradientBoostingClassifier/LogitBoost. Formula supplies finite encoded predictors (including categorical/interaction terms) and a string response. Complete cases define sorted classes and priors; null formula rows are dropped. Needs at least one expanded predictor and two retained classes. All prior trees remain fixed. Subsampling selects rows without replacement once per round, shared across its K trees. The seed does not affect full-sample deterministic CART fits; greedy split ties follow predictor/threshold order and absolute tolerances. training_deviance is mean multinomial negative log likelihood, without factor two, computed with log-sum-exp rather than flooring probabilities. Prefix zero is the prior model. Evaluation is explicit, never used to fit or alter trees. Training accuracy or loss cannot diagnose generalization or select a stopping round without held-out data. Model owns the Formula schema, trees, encoded training data and row maps. Inputs are unchanged; const operations share no mutable caches. This CART implementation scans all candidate thresholds: conservative fit work O(M*K*p*n^2*(D+1)), with storage O(np+M*K*(n+nodes_per_tree)) including each tree's stored training predictions. Numeric inference traverses fitted trees; no query preprocessing is learned.
    GBMClassifierOptionsControls the number, shrinkage, shape and row sampling of residual trees. max_depth must be positive; unsplittable nodes remain constant. Rates above one are allowed, but no monotone training-loss guarantee is asserted for arbitrary rates or stochastic samples.
    GBMClassifierPredictionOwned labels and softmax probabilities in original query-row order. Missing predictors produce an empty string and empty probability row. A complete row has K probabilities in GBMClassifier::classes() order; ties use the first sorted class. Probabilities can underflow to zero and are not post-hoc calibrated.
    GBMValidationResultOwned learning-rate/round search result, including a possible prior-only choice. selected_options can refit on the caller's chosen data. If selected_rounds is zero, selected_options.n_trees is one solely to satisfy the fit constructor; use explicit prefix zero when evaluating/predicting that selected model.

    Functions

    gbm_validation_search()Selects learning rate and prefix by validation mean log loss, without touching test data. Fits one full-budget model per supplied rate on train, then evaluates its fixed stages on validation. Exact ties prefer the first supplied rate and earliest round, including zero. All other options remain fixed. No cross-validation, calibration or refitting on validation occurs here. The caller is responsible for disjoint train/validation rows; no record-identity check or test frame is part of this API. Cost is one training plus one staged evaluation per rate, rather than refitting every round count.

    datamunge/stats/ica.hpp

    Classes

    ICADeflationary FastICA with population whitening and frozen new-row transforms. Fits centered x=A*s under the modelling assumption of mutually independent sources and a full-column-rank instantaneous linear mixture.     TSNEt-distributed Stochastic Neighbor Embedding (van der Maaten & Hinton, 2008): converts pairwise distances into conditional probabilities (calibrated per-point via a perplexity-targeted binary search over a Gaussian bandwidth), symmetrizes them into a joint distribution P, and iteratively moves points in a low-dimensional space via momentum-based gradient descent so that a Student-t-distributed joint distribution Q over the embedded points matches P as closely as possible (minimizing their KL divergence). Unlike PCA/MDS, t-SNE preserves local neighborhood structure rather than global distances or variance, and is primarily useful for visualization (typically n_components 2 or 3). Rows with a null value in any feature column are dropped before fitting.

    UMAPUMAP (Uniform Manifold Approximation and Projection): builds a fuzzy simplicial set (a weighted k-nearest-neighbor graph with per-point smooth calibration and probabilistic t-conorm symmetrization) from the high-dimensional data, then optimizes a low-dimensional embedding via cross-entropy minimization using attractive forces on graph edges and repulsive forces from negative sampling.     enum class QuantileRegressionMethod

    The algorithm QuantileRegression uses to minimise the check loss.

    EnumeratorValueDescription
    Simplex

    Exact vertex-to-vertex descent on the linear program (in the spirit of Barrodale and Roberts), started from the rows nearest the least-squares fit: the fit interpolates exactly p rows and is certified optimal. The default: exact, and usually a handful of pivots.

    Alternating direction method of multipliers: one least-squares solve and one asymmetric soft threshold per iteration. Accurate only to its tolerances and far slower here; kept for comparison and as a template for penalised variants.
