    function datamunge::stats

    isomap_graph

    #include <datamunge/stats/isomap.hpp>
    #source
    IsomapGraph isomap_graph(
    const dstruct::DataFrame & data,
    const std::vector< std::string > & feature_columns,
    std::size_t n_neighbors,
    DistanceMetric metric = DistanceMetric::Euclidean)

    Constructs an inspectable union-kNN graph without requiring connectivity. Nulls are dropped jointly; retained numeric values and distances must be finite. Uses brute-force distances and partial row sorting: O(n^2*p+n^2*log(k)) work and O(n^2+n*p+n*k) storage. The caller owns all returned fields; input is unchanged.

    Parameters
    data

    Input frame.

    feature_columns

    Nonempty numeric columns; no automatic rescaling.

    n_neighbors

    Number of other neighbours per row, 2<=k<n after null omission.

    metric

    Euclidean (default) or Manhattan; unknown enum values are rejected.

    Returns

    Owned graph result, including component labels before any shortest-path fitting.

    Throws
    std::invalid_argument

    Missing/non-numeric columns, nonfinite retained values, invalid metric/k, too few complete rows or distance overflow.

    Example

    See IsomapGraph's runnable example.

    References

    • J. B. Tenenbaum, V. de Silva and J. C. Langford (2000), A Global Geometric Framework for Nonlinear Dimensionality Reduction. https://doi.org/10.1126/science.290.5500.2319
