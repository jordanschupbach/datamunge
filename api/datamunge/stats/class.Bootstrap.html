    class datamunge::stats

    Bootstrap

    class Bootstrap
    #include <datamunge/stats/bootstrap.hpp> source

    Nonparametric resampling with replacement, as in R's boot with ordinary resampling.

    Resamples n observations B times and evaluates a deterministic statistic. No missing-value filtering occurs; the statistic controls input non-finite handling but must return finite values for the original sample, resamples and jackknife samples. BCa acceleration may also evaluate the statistic on n leave-one-out samples. Copies cost O(B*n+n*n), plus statistic evaluations and O(B log B) sorting; temporary/result storage is O(n+B). Inputs are borrowed and unchanged. Instances own only options and can be shared when callbacks/engines are safe.

    Example
    const dm::stats::Bootstrap bootstrap({100,0.95,42});
const auto result = bootstrap.run({1,1,1}, [](const auto& values){return dm::mean(values);});
const double se = result.standard_error; // 0
    References

    • B. Efron (1979), Bootstrap Methods: Another Look at the Jackknife, https://doi.org/10.1214/aos/1176344552

    • B. Efron (1987), Better Bootstrap Confidence Intervals, https://doi.org/10.1080/01621459.1987.10478410

    #source
    BootstrapResult run(
    const std::vector< double > & sample,
    const SampleStatistic & statistic,
    random::RandomGenerator & generator) const

    Run with a caller-owned random stream using unbiased inclusive integer resampling.

    Uses generator.uniform_u64(0,n-1), which may consume a variable number of raw outputs due to rejection. options().seed is ignored; the supplied generator is advanced and remains advanced if a callback later throws. All other estimates and intervals use the same code as the default run.

    Parameters
    sample

    Nonempty observations; borrowed and unchanged.

    statistic

    Deterministic scalar callback, including required jackknife samples.

    generator

    Mutable caller-owned stream; not safe to share concurrently.

    Returns

    Owned replicates, summary estimates and confidence intervals.

    Throws
    std::invalid_argument

    If sample is empty.

    std::bad_function_call

    If statistic is empty; callback exceptions propagate.

    std::domain_error

    If a statistic result is nonfinite, possibly after advancing the stream.

    std::overflow_error

    If a summary or interval exceeds finite double range.

    Example
    dm::random::Xoshiro256StarStar rng(42);
const auto result = dm::stats::Bootstrap().run({1,1}, [](const auto& values){return dm::mean(values);}, rng);
const double se = result.standard_error; // 0

    run_studentized

    #source
    StudentizedBootstrapResult run_studentized(
    const std::vector< double > & sample,
    const SampleStatistic & statistic,
    const SampleStatistic & standard_error) const

    Computes a bootstrap-t confidence interval using a sample-level SE callback.

    Each resample supplies a statistic and its own error estimate. The method inverts the type-7 quantiles of (replicate minus estimate) divided by its standard error using the original standard error. Discards zero-SE resamples, requires at least two retained pivots, and uses the default local engine and seed from options().

    Parameters
    sample

    Nonempty sample passed unchanged to the callbacks.

    statistic

    Deterministic scalar statistic on the sample and resamples.

    standard_error

    Deterministic SE estimator on the same samples.

    Returns

    Original statistic and SE, pivots, discarded count and ordered interval.

    Throws
    std::invalid_argument

    Empty sample or fewer than two requested resamples.

    std::domain_error

    Nonfinite statistics, invalid SEs, or fewer than two retained pivots.

    std::bad_function_call

    If a callback is empty. Other callback exceptions propagate.

    std::overflow_error

    If a pivot or interval endpoint is outside finite double range.

    Example
    const auto fit = dm::stats::Bootstrap({100, 0.95, 42}).run_studentized(
    {1, 2, 3, 4, 5}, [](const auto& x) { return dm::mean(x); },
    [](const auto& x) { return dm::sd(x) / std::sqrt(x.size()); });
std::print("{}", fit.estimate); // 3
