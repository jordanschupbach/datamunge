    DBSCAN

    class DBSCAN
    #include <datamunge/stats/dbscan.hpp> source

    Density-based spatial clustering (Ester et al. 1996) fit from a DataFrame and a list of numeric feature columns. Rows with a null value in any feature column are dropped before fitting. Unlike KMeans/AgglomerativeClustering, the number of clusters is discovered automatically from the density structure, and points in low-density regions are labeled as noise rather than forced into a cluster.
