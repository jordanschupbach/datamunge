    INLAMixedModel

    class INLAMixedModel
    #include <datamunge/stats/inla_mixed_model.hpp> source

    Approximate Bayesian mixed model using dense Gaussian-strategy INLA. Supports one lme4-style random term, e.g. y~x+(1+x|group). Latent coordinates are fixed effects followed by one random-effect block per group. At each theta the conditional Gaussian is centered at the mode; hyperparameter integration combines those Gaussians. No marginal skew correction, sparse solver or exact posterior sampler is supplied. See INLAMixedModelOptions for the proper priors. Complete cases across response/fixed predictors/group/random slopes are fitted; nonfinite retained numeric inputs are rejected. All fitted storage is owned. Units/centering change the meaning of the independent fixed-effect priors.

    Example
    auto o=dm::stats::INLAMixedModelOptions{};
o.strategy=dm::bayes::INLAIntegrationStrategy::EmpiricalBayes;
o.mode_population_size=8;o.mode_max_generations=4;
const dm::stats::INLAMixedModel m(dm::datasets::tooth_growth(),"len ~ dose + (1 | supp)",o);
std::print("{}\n",m.observations()); // 60

    predict

    #source
    std::vector< double > predict(const dstruct::DataFrame & newdata) const

    Inverse link of the approximate posterior mean latent predictor. This is a plug-in response prediction, not an integrated posterior predictive mean for logit/log links. Seen groups use their fitted random effects; missing/null/unseen groups use fixed effects with random effects set to zero. In particular that fallback does not integrate over a new group's uncertainty. Rows with missing/nonfinite numeric predictors/slopes return NaN in input order. An empty query frame returns an empty vector.

    Parameters
    newdata

    Matching fitted fixed-predictor schema and any random slope columns.

    Returns

    Owned response-scale vector with newdata.nrows() entries.

    Throws
    std::invalid_argument

    Wrong predictor/group types, missing slope columns, or nonfinite numeric group keys.

    std::runtime_error

    Unseen fixed categorical predictor level.

    std::out_of_range

    Missing required fixed-predictor column.

    Example
    auto o=dm::stats::INLAMixedModelOptions{};
o.strategy=dm::bayes::INLAIntegrationStrategy::EmpiricalBayes;
o.mode_population_size=8;o.mode_max_generations=4;
const dm::stats::INLAMixedModel m(dm::datasets::tooth_growth(),"len ~ dose + (1 | supp)",o);
std::print("{}\n",m.predict(dm::datasets::tooth_growth()).size()); // 60
