    KernelPCA

    class KernelPCA
    #include <datamunge/stats/kernel_pca.hpp> source

    Kernel PCA in the training-centred feature space, as sklearn.decomposition.KernelPCA.

    Numeric predictors are used in their supplied units, without input scaling. Required training nulls are omitted jointly; retained nonfinite values are rejected. At least two complete rows are required. Kc=H*K*H, H=I-11'/n, is diagonalized with a scaled symmetric eigensolver. Scores are V*sqrt(lambda); the historical eigenvalues() returns retained Gram eigenvalues, not covariance variances (those are lambda/(n-1)). Signs are fixed by a largest-magnitude entry, but repeated eigenspaces admit arbitrary orthogonal rotations. Rank uses 64*n*epsilon*largest_eigenvalue. Requested dimensions exceeding that rank throw; small signed eigenvalues remain visible in all_eigenvalues(). Materially negative eigenvalues throw instead of silently clipping an indefinite kernel.

    Linear centering uses centred raw predictors; RBF centering uses expm1 of negative squared distance, cancelling its common constant before subtraction. This preserves small-gamma structure that can disappear from a rounded all-ones raw kernel matrix. Fit costs O(n^2*p+n^3) time and O(n^2+n*p) space. Models own all matrices and the training centre. Const operations use no shared mutable caches. No inverse transform, pre-image estimator, automatic gamma choice or classifier is fitted.

    Example
    const auto d=dm::datasets::iris();
const dm::stats::KernelPCA m(d,{"Petal.Length","Petal.Width"},{.gamma=.13});
std::print("{}\n",m.observations()); // 150

    transform

    #source
    linalg::DenseMatrix< double > transform(const dstruct::DataFrame & newdata) const

    Projects new rows onto frozen training axes using the training feature-space centre. Each query's cross-kernel mean and the stored training column/grand means centre its row. Query batches never learn a new centre; adding other queries cannot change a row's coordinates. Work O(m*n*(p+d)), output O(m*d); no fitting or label use.

    Parameters
    newdata

    Numeric training-named columns; extra columns ignored. Empty input allowed.

    Returns

    Owned m-by-d scores in original query order; null/nonfinite rows are all NaN.

    Throws
    std::invalid_argument

    Missing/nonnumeric schema or unrepresentable kernel geometry.

    Example
    const auto d=dm::datasets::iris();
const dm::stats::KernelPCA m(d,{"Petal.Length","Petal.Width"});
std::print("{}\n",m.transform(d.head(3)).rows()); // 3

    projection_details

    #source
    dstruct::DataFrame projection_details(const dstruct::DataFrame & newdata) const

    Feature-space query norm, retained squared norm and orthogonal projection loss. Residual is ||phi(x)-mu_train||^2 - sum(score^2), rounded below by zero. This is feature-space reconstruction loss, not original-unit error, density or a calibrated anomaly score; changing kernel/units changes its meaning. No pre-image is computed.

    Parameters
    newdata

    Same schema and row handling as transform().

    Returns

    Owned query_row/centered_norm_squared/projected_norm_squared/residual_energy/status; status is ok, missing_predictor or nonfinite_predictor; invalid rows have NaN norms.

    Throws

    Example
