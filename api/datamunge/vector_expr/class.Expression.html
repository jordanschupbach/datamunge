    class datamunge::vector_expr

    Expression

    template<class D>
class Expression : public datamunge::VectorExpressionTag
    #include <datamunge/vector.hpp> source

    Shared read-only range and materialisation API for lazy numeric nodes. Lvalue Vector leaves are borrowed; temporary Vectors and all child nodes are owned. Borrowed leaves must outlive evaluation. Reads see their current values and lengths. Copies of a node copy any temporary vectors that it owns.

    D

    Concrete node type.

    eval

    #source
    Vector< double > eval() const

    Compute one owned snapshot in a single pointwise pass.

    Returns

    Owned numeric Vector; later operand mutations do not affect it.

    Example
    auto x = dm::c(1, 2);
const auto lazy = x + 1;
const auto snapshot = lazy.eval();
x[0] = 10;
std::print("{} {}\n", lazy[0], snapshot[0]); // 11 2

    values

    #source
    std::vector< double > values() const

    Materialise standard storage for APIs requiring std::vector<double>.

    Returns

    Owned values, recomputed on each call; no cache or operand mutation.

    Example
    const auto expression = dm::c(1, 2) + 1;
const std::vector<double> values = expression.values();
std::print("{}\n", values); // [2, 3]
