    struct datamunge::sim

    UrdfPhysicsOptions

    struct UrdfPhysicsOptions
    #include <datamunge/sim/articulation.hpp> source

    Explicit physical import approximations for URDF collision meshes and missing inertias. Source units are metres/radians/kg. No external physics engine is used.

    Example
    dm::sim::UrdfPhysicsOptions options; options.missing_mass=.04;

    Members

    Fields

    missing_massZero rejects missing dynamic inertias; positive explicitly opts into nominal data.
    missing_inertiaNominal diagonal COM inertia when missing_mass is positive.
    joint_dampingDefault only when URDF has no dynamics damping.
    hinge_armatureNominal reflected arm inertia, kg m²; not inferred from URDF transmissions.
    slider_armatureNominal reflected slide inertia, kg.
    slider_dampingDefault slide damping if absent from URDF.
    mesh_x_slicesOptional per-link convex slab decomposition in mesh-local X metres.
    hull_directionsDeterministic support sampling; zero retains every source vertex.
