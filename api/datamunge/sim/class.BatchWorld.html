    BatchWorld

    class BatchWorld
    #include <datamunge/sim/batch.hpp> source

    Fixed-size collection of independent native worlds for CPU rollouts. Construction deep-copies a prototype, including pending forces and solver state. Stepping/reset reuse reserved storage; capture_reset allocates during setup. Each world has an independent deterministic random stream. Streams advance across episode resets; reseeding is explicit. Single-writer: do not mutate worlds concurrently with a batch operation. GPU physics is not yet supported.

    Example
    dm::sim::WorldOptions
limits;limits.body_capacity=8;limits.pair_capacity=16;limits.contact_capacity=16; dm::sim::World
prototype(limits); dm::sim::BatchWorld batch(prototype,4,dm::compute::Context({},2),42);
batch.step(1./60);batch.reset({1,0,0,1});

    void step(double delta, const std::vector< std::uint8_t > & mask = {})

    Advance selected worlds on persistent workers, rolling back the batch on failure. All selected worlds run once. Errors are collected after every worker finishes; every successfully advanced world then rewinds, counters remain unchanged, and the lowest-index failing world's exception is rethrown.

    Parameters
    delta

    Finite positive seconds at most 1/30.

    mask

    Empty selects all; otherwise exactly size() binary bytes.

    Throws
    std::invalid_argument

    Invalid delta or mask, before advancement.

    std::exception

    Native solver error after whole-batch rollback.

    Example
