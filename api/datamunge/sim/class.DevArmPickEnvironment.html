    DevArmPickEnvironment

    class DevArmPickEnvironment
    #include <datamunge/sim/devarm_pick.hpp> source

    Headless DevArm pick-and-place environment with a caller-selected bin objective. Nine actions operate a bounded Cartesian lattice; numerical IK drives the six real URDF joint coordinates, clamped to limits and limited to 1.5 rad/s. IK accepts up to 12 mm position residual and uses a soft wrist-down preference. The grasp point is end_link local (-.02,0,0) m, between the finger tips. Tool and carried-payload collision guards reject moves through workcell solids. The grasp is an ideal proximity latch with size-dependent jaw aperture and payload orientation stabilization; opening restores dynamic gravity/contact physics. Robot servos are kinematic: this is not torque control, a full mesh-collision robot simulator, or hardware deployment. Observations are privileged state, not image observations. Instances are single-writer and own independent worlds.

    Example
    dm::sim::DevArmPickEnvironment env("ReBot_Arm_DM.urdf");
env.reset(42);
auto state=env.step(dm::sim::PickAction::ZMinus);
    References

    • S. R. Buss, Introduction to Inverse Kinematics with Jacobian Transpose, Pseudoinverse and Damped Least Squares methods (author's notes). https://mathweb.ucsd.edu/~sbuss/ResearchWeb/ikmethods/

    step

    #source
    PickObservation step(PickAction action)

    Execute a Cartesian/gripper action and return its measured transition. Reward is -0.05 per decision, -0.15 for a blocked move, +10 for a settled requested-bin release, or -3 for a failed release/lost fruit, plus 0.98*Phi(next)-Phi(current). Phi is -1-3*distance(tool,fruit) before grasp and 1-3*distance(fruit,requested-bin release point) while grasped; terminal Phi=0.

    Parameters
    action

    One of the nine PickAction values; no automatic action selection.

    Returns

    State with separate termination and time-limit flags.

    Throws
    std::invalid_argument

    Unknown action, before mutation.

    std::logic_error

    Episode already ended.

    std::runtime_error

    Native solver failure.

    joint_target

    #source
    std::array< double, 6 > joint_target(int x, int y, int z)

    Solve one existing Cartesian lattice target without moving the live arm. This exposes the same cached real-URDF IK used by step(), for continuing controllers which own their own world clock and interpolate servo commands.

    Parameters
    x

    Longitudinal index -2..2, world X=.10+.03*x metres.

    y

    Lateral index -16..16, world Y=.03*y metres.

    z

    Height index 0..8, world Z=.76+.03*z metres.

    Returns

    Six joint angles in radians, within the URDF limits.

    Throws
    std::invalid_argument

    Index outside the lattice.

    std::runtime_error

    Target has no IK solution within the 12 mm tolerance.

    Example
    dm::sim::DevArmPickEnvironment env("ReBot_Arm_DM.urdf");
auto hover=env.joint_target(0,0,4);
