    class datamunge::sim

    World

    class World
    #include <datamunge/sim/world.hpp> source

    A library-owned, noncopyable native physics world; no window or external physics runtime. World methods are single-writer; use independent worlds for parallel rollouts. Bodies are world-scoped positive IDs, never reused. External input is validated before mutation. A failed solve restores the pre-step state. Snapshots retain solver state and must not be confused with authored scene serialization.

    Example
    dm::sim::World world;
dm::sim::Body body; body.motion=dm::sim::Motion::Dynamic; body.position={0,3,0};
const auto id=world.add_body(body); world.step(1./60);
std::print("{}\n",world.body(id).position[1]<3); // true
    References

    • Erin Catto (2006), Fast and Simple Physics using Sequential Impulses, https://box2d.org/files/ErinCatto_SequentialImpulses_GDC2006.pdf. This implementation uses native 3D primitive constraints and conservative sweeps.

    step

    #source
    void step(double delta)

    Advance native physics by a finite positive delta of at most 1/30 second. Dynamic speeds are bounded by 500 m/s and each body's angular_speed_limit. clamp_velocities=true clips magnitudes; false rejects excess speed. block_joints factors up to 256 independent bilateral rows; singular systems reject the step. The default sequential solver also supports redundant rows.

    Parameters
    delta

    Simulation seconds; forces persist across configured substeps then clear.

    Throws
    std::invalid_argument

    Invalid delta.

    std::runtime_error

    Solver or capacity failure; pre-step physics state is restored.

    Example
    dm::sim::World world; world.step(1./60);
