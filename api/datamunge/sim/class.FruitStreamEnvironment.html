    FruitStreamEnvironment

    class FruitStreamEnvironment
    #include <datamunge/sim/fruit_stream.hpp> source

    Native continuing multi-fruit conveyor, real-URDF servos and asynchronous outcomes. The belt always runs at .22 m/s. Independent exponential inter-arrival times are scheduled even during arm motion, and insertion is quantized by at most one 1/240-second physics tick. Fruit passing X=.30 m is missed. There is no between-pick reset, teleport, stopped belt or hidden queue at the source. An opt-in training_proxy accelerates empty/servo intervals using analytic belt transport and a .4 s bin-settling approximation, omitting fruit-fruit contacts. Arrivals and task rewards are shared, but the proxy is incompatible with articulated dynamics and is not physics evidence. Use articulated_physics for contact-based learning/evaluation; it imports link inertias/collision hulls and simulates finite actuator effort, free payload rotation, slip and physical release momentum. Interception options target the oldest/second-oldest observed fruit, inspect it through a supplied classifier, time a descending grasp, lift, traverse and release. Fixed IK servos are not learned torques; the scheduler is trainable. The default perception channel is explicitly SYNTHETIC and intended for fast RL training, with configured class-error probabilities. Supply set_perception() for actual RGB evaluation; unknown predictions never use true-label fallback. With watch_infeed enabled, reset starts at a camera-aimed entry observation pose. Empty-queue waits return there via guarded, rate-limited waypoints; the next decision can interrupt after 0.125 seconds. This orients the real rigid camera, not a virtual pan. Queue state still uses privileged tracking, not RGB detection. Instances are single-writer; callbacks must not mutate the environment.

    Example
    dm::sim::FruitStreamOptions options; options.watch_infeed=true;
dm::sim::FruitStreamEnvironment env("ReBot_Arm_DM.urdf",options);
env.reset(42);
while(env.observation().time<10)env.step(dm::sim::StreamAction::LateFront);

    StreamTransition step(StreamAction action)

    Execute one interception/wait option while the entire world advances. Legacy latches stabilize orientation and use tool/payload fixture guards. Articulated mode keeps fruit dynamic, requires sustained opposing finger forces, checks actual bin-floor support and permits slip. Non-adjacent arm collisions are solved, using convex hulls and decomposed finger proxies. A solver warning rejects the run; reset before reusing a failed simulation. Optional empty-queue surveillance shares the wait's 0.125-second budget, including missing-target actions, and never delays arrivals or active picks.
