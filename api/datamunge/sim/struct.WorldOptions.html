    WorldOptions

    struct WorldOptions
    #include <datamunge/sim/world.hpp> source

    Explicit fixed-capacity physics controls; capacities reserve reusable working memory.

    Example
    dm::sim::WorldOptions options; options.gravity={0,0,0};
