    struct datamunge::sim

    FruitStreamOptions

    struct FruitStreamOptions
    #include <datamunge/sim/fruit_stream.hpp> source

    Configuration of an unbounded-time, bounded-memory sorting workcell. Arrivals are never postponed for a busy arm. At capacity, arrivals are counted as overflow misses. Outcomes are removed after two seconds (self-emptying bins). Legacy mode stabilizes orientation and uses ideal latches. Articulated mode integrates free rotation, force-limited servos and physical grasps. Motor geometry remains privileged state; nominal physics is not a hardware calibration.

    Example
    dm::sim::FruitStreamOptions options; options.arrival_rate=.14;
options.watch_infeed=true; // point the wrist camera upstream while idle
options.synchronized_grasp=true; // align the inspection and descent wrist roll
options.articulated_physics=true; // native, no external physics runtime
options.physics_timestep=1./960;
options.queued_wait_cost=.5; options.miss_cost=6; options.wrong_cost=8;
