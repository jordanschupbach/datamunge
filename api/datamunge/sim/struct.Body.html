    struct datamunge::sim

    Body

    struct Body
    #include <datamunge/sim/types.hpp> source

    Owned rigid-body creation and edit parameters; no dependency on a renderer. Coordinates use SI units. Validation matches the implemented VSim component ranges. Quaternion input must already be unit length within 1e-6.

    Example
    dm::sim::Body body; body.motion=dm::sim::Motion::Dynamic; body.validate();
