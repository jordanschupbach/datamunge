    PickObservation

    struct PickObservation
    #include <datamunge/sim/devarm_pick.hpp> source

    Owned state and render frame in CAD Z-up metres and URDF radians.

    Example
    dm::sim::DevArmPickEnvironment env("ReBot_Arm_DM.urdf");
auto frame=env.observation();

    Used in reports

    Robot-arm fruit-sorting playground
