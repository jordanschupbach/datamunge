    struct datamunge::geometry

    GrahamWork

    struct GrahamWork
    #include <datamunge/geometry/graham_scan.hpp> source

    Selected native preparation and scan work, excluding validation and allocation. Sort counts depend on the standard library and input order. Angular and sweep tests call the exact binary64 orientation predicate; other comparisons do not. The scan pushes each distinct point once when there are at least three.

    Example
    const auto a=dm::geometry::graham_scan_analyze({{0,0},{1,0},{0,1}});
std::print("{} {}\n",a.work.pushes,a.work.pops); // 3 0
