    IcpWork

    struct IcpWork
    #include <datamunge/geometry/icp.hpp> source

    Selected producing work, separate from extra error-observation passes. Counts exclude validation, centroids, covariance, trigonometry, copies, allocations and comparisons. Ordinary final RMSE adds one nearest pass; traced steps add fixed-match and nearest error observations after each update.

    Example
    const auto r=dm::geometry::icp_run({{0,0}},{{1,0}},1);
std::print("{} {}\n",r.work.distance_evaluations,r.work.point_updates); // 1 1
    See also
