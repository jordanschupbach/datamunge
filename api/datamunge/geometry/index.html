    DelaunayInsertionOwned actual cavity removal, directed boundary and replacement for one site. removed/added may contain ghosts, identified by c=the original input count. boundary is ordered by canonical undirected endpoint key but retains the first directed occurrence; shared interior edges are cancelled.     DelaunayTraceComplete owned sites, earliest-identity mapping, finite mesh and actual events. Numeric coordinate equality coalesces duplicates and signed zeros. Strict positive incircle conflicts retain an existing diagonal on an exact cocircular tie; permutations may therefore select another valid mesh. Final finite triangles rotate their smallest id first and are lexicographically sorted, independent of map/hash traversal.
