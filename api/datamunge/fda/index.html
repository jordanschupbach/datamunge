    datamunge/fda/adaptive_pspline.hpp

    Classes

    AdaptiveSplineCandidateCounterfactual refinement audit entry; includes unsuccessful numerical fits.
    AdaptiveSplineCellOne cell of a complete binary refinement tree, in creation order.
    AdaptiveSplineFitOwned continuous fitted spline, selected tree, and complete refinement audit. Predictions use an equivalent finest-grid B-spline representation, avoiding evaluation-order dependence at cell boundaries. Const evaluation is thread-safe. Path and candidates describe the entire searched path, including prefixes beyond the validation-selected tree. The cells/splits fields describe only the selected model. Fields are snapshots; editing them can invalidate the fit.
    AdaptiveSplineOptionsSearch controls for continuous HB/THB regression and hierarchical P-splines. The domain is fixed before fitting. A common finest dyadic coefficient grid defines the penalty, independent of the chosen hierarchical basis. Lambda zero gives least squares. This API fits genuine hierarchical spaces, unlike the independent residual patches of HierarchicalBSpline. No global risk optimum is asserted. The fixed-lambda API uses a training-driven greedy path; the joint API alternates validation tuning and recursive growth.
    AdaptiveSplineStepA fitted path prefix and its honest held-out validation score.
    AdaptiveSplineTuningOne smoothing-parameter evaluation on an accepted tree. Entries include rejected numerical solves and all interpolation probes.
    JointAdaptiveSplineOptionsControls for alternating mesh growth and smoothing-parameter selection. Every accepted tree is retuned using the supplied validation observations. Validation therefore influences subsequent growth; independent test data are required to assess this complete procedure. The original fixed-lambda API remains available when growth must depend on training responses alone.

    Functions

    fit_adaptive_pspline()Greedily grow by the largest positive parent-local training-MSE drop; validate prefixes. Each proposal bisects one eligible leaf into both children and globally refits all active coefficients. Only training rows determine proposals, scores and the growth order. Strictly positive gains are required; ties within 1e-12*max(1,|gain|) select the lower cell id. Both children need the requested minimum training count. Intervals are half-open except the domain maximum. Validation chooses the lowest-MSE prefix, with the earlier/smaller prefix winning ties at the same tolerance. No validation refit is performed. The search is finite and greedy: it is not a global tree/risk optimum.
    fit_hierarchical_pspline()Globally fit a fixed continuous hierarchical space with a common-grid P-spline penalty. Uses active HB or THB functions on the supplied tree, maps them exactly to the fixed finest dyadic grid, and minimizes MSE + lambda*h^-3*||G2*c_fine||². G2 uses second divided differences at Greville sites, scaled by h². It is ordinary D2 where both spacings equal h, and annihilates constants and physical affine functions at clamped boundaries. For consecutive spacings a,b its row is 2*h²/(a+b) times (1/a,-1/a-1/b,1/b). HB/THB coordinates therefore define the same estimator on the same tree. Finest-grid data assembly is O(n*p²), with dense space restriction/solution thereafter. Normal-equation accumulation and Cholesky use long double; no artificial identifying ridge is added. Paired child creation aligns refinement-domain boundaries with parent grids.
    fit_joint_adaptive_pspline()Recursively refine a mesh while retuning lambda on every accepted tree. On each tree, fit all seed lambdas plus the previous tree's chosen lambda. Then test the two neighboring midpoints around the best evaluated lambda for each refinement round: geometric means for positive brackets and arithmetic halves beside zero. Select lowest validation MSE; ties favor the smaller lambda, then the earlier/smaller prefix (tolerance 1e-12*max(1,abs(scores))). Each leaf proposal is globally fitted at the CURRENT tree's tuned lambda, so its local-MSE gain compares the same penalty on both sides. Require positive gain and increased basis dimension. Rank by gain, or optionally by width^4*mean(f''^2); curvature is integrated analytically with four-point Gauss quadrature on each finest knot span. Priority ties favor lower cell ids. After acceptance, retune lambda and repeat, even through worsening validation prefixes, until the usual depth/sample/split bounds or no eligible gain. Validation influences growth through lambda; it is a tuning set, not a test estimate. Returned coefficients use training rows only. This is an alternating finite search, with no global tree/lambda or test-risk optimality guarantee.

    enum class SplineSolver

    Linear-system method used by the spline least-squares fits.

    Every fit forms symmetric normal equations (B^T B + P) c = B^T y. Cholesky is exact but costs O(K^3) for K unknowns; conjugate gradient on the sparse system costs roughly O(nnz) per iteration and suits large, well-conditioned (usually penalized) systems.

    Example
    dm::fda::SplineSolveOptions options{dm::fda::SplineSolver::ConjugateGradient};
    See also
