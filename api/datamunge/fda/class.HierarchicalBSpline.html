    HierarchicalBSpline

    class HierarchicalBSpline
    #include <datamunge/fda/hierarchical_bspline.hpp> source

    Classical (overlay) hierarchical B-spline in the style of Forsey and Bartels: every cell of a dyadic tree may carry its own local "detail" TensorBSpline.

    evaluate(x) sums the patch of every cell on the root-to-leaf path containing x. Each patch is evaluated in its cell's local coordinates, (x - cell_min) / (cell_max - cell_min) in [0, 1]^d, so patch bases should span [0, 1]. Patches are independent (no shared nested basis and no truncation); see TruncatedHierarchicalBSpline for the THB-spline construction. Cells are identified by integer ids (root 0).

    Example
    dm::fda::HierarchicalBSpline h({0.0}, {1.0});
auto b = dm::fda::BSplineBasis::open_uniform(0, 1);              // constant patch
h.set_spline(h.root(), dm::fda::TensorBSpline(b, {1.0}));
h.refine(h.root(), 1, dm::fda::TensorBSpline(b, {2.0}));          // upper half
std::print("{} {}\n", h.evaluate({0.25}), h.evaluate({0.75}));    // 1 3
    References

    • D. R. Forsey and R. H. Bartels (1988). Hierarchical B-spline refinement. ACM SIGGRAPH Computer Graphics 22(4), 205-212. https://doi.org/10.1145/378456.378512

    fit_cell

    #source
    void fit_cell(
    int cell,
    std::vector< BSplineBasis > bases,
    const std::vector< std::vector< double > > & points,
    const std::vector< double > & values,
    const SplineSolveOptions & options = SplineSolveOptions())

    Least-squares fits a new patch on cell so the whole hierarchy matches values at points.

    The patch explains only what is left after every other patch on the path (the residual values - evaluate(points)), in the spirit of Forsey-Bartels editing, so pass raw data values rather than residuals. Points are global coordinates inside the cell.

    Parameters
    cell

    Cell id; must not already have a patch (clear_spline() first to refit).

    bases

    Patch bases on [0, 1], one per dimension.

    points

    Sample locations inside the cell.

    values

    One raw data value per point.

    options

    Solver settings.

    Throws
    std::out_of_range

    For an invalid id.

    std::invalid_argument

    If the cell has a patch, inputs are empty/mismatched, or a point lies outside the cell.

    std::runtime_error

    If the local normal equations are singular.

    Example
    dm::fda::HierarchicalBSpline h({0.0}, {1.0});
auto b = dm::fda::BSplineBasis::open_uniform(1, 2);
h.fit_cell(h.root(), {b}, {{0.0}, {1.0}}, {1.0, 3.0});
std::print("{}\n", h.evaluate({0.5})); // 2
