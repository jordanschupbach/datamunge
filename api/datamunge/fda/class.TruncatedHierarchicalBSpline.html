    TruncatedHierarchicalBSpline

    class TruncatedHierarchicalBSpline
    #include <datamunge/fda/hierarchical_bspline.hpp> source

    Truncated hierarchical B-spline (THB-spline) of Giannelli, Juttler and Speleers.

    Level 0 is the caller's TensorBSpline; level l + 1 is the dyadic refinement of level l. A dyadic cell tree defines the nested domains Omega^0 (whole domain) contains Omega^1 contains ..., where Omega^l is the union of cells of depth >= l. A level-l basis function is active when its support lies in Omega^l but not in Omega^(l+1). The THB basis consists of the active functions, each truncated: its representation on finer levels drops the finer functions whose support lies in the finer refined domain. The resulting basis is a partition of unity, preserves the continuity of the underlying splines, and spans the hierarchical spline space.

    Internally each level stores a full coefficient net whose entries outside the next level's refined domain always equal the refinement of the coarser level; coefficient edits are pushed down through all finer levels with truncation, so evaluation needs only the finest level covering a point. Refinement never changes the represented function. Bases must be clamped. Cells are integer ids (root 0).

    Example
    auto b = dm::fda::BSplineBasis::open_uniform(2, 4);
dm::fda::TruncatedHierarchicalBSpline thb(dm::fda::TensorBSpline({b, b}, std::vector<double>(16, 1.0)));
thb.refine_region({0.0, 0.0}, {0.5, 0.5}, 1);
std::print("{} {:.3f}\n", thb.level_count(), thb.evaluate({0.2, 0.2})); // 2 1.000
    References

    • C. Giannelli, B. Juttler and H. Speleers (2012). THB-splines: The truncated basis for hierarchical splines. Computer Aided Geometric Design 29(7), 485-498. https://doi.org/10.1016/j.cagd.2012.03.025

    • D. R. Forsey and R. H. Bartels (1988). Hierarchical B-spline refinement. https://doi.org/10.1145/378456.378512

    fit_level

    #source
    void fit_level(
    int level,
    const std::vector< std::vector< double > > & points,
    const std::vector< double > & values,
    const SplineSolveOptions & options = SplineSolveOptions())

    Least-squares update of the active coefficients at level only.

    Solves for the change of the level's active coefficients that best explains the residual values - evaluate(points), using the exact truncated basis, so pass raw data values. Points shallower than level are unaffected by these functions and are ignored. Typical use is coarse-to-fine: fit level 0, refine where residuals are large, then fit the new level.

    Parameters
    level

    Level with at least one active function.

    points

    Sample locations inside the domain.

    values

    One raw value per point.

    options

    Solver settings.

    Throws
    std::out_of_range

    For an invalid level.

    std::invalid_argument

    On empty/mismatched inputs, points outside the domain, or a level with no active functions.

    std::runtime_error

    If the normal equations are singular.

    Example
    auto b = dm::fda::BSplineBasis::open_uniform(1, 2);
dm::fda::TruncatedHierarchicalBSpline thb(dm::fda::TensorBSpline(b, {0.0, 0.0}));
thb.fit_level(0, {{0.0}, {1.0}}, {1.0, 3.0});
std::print("{}\n", thb.evaluate({0.5})); // 2

    fit_penalized

    #source
    void fit_penalized(
    const std::vector< std::vector< double > > & points,
    const std::vector< double > & values,
    const std::vector< double > & lambdas,
    int order = 2,
    const SplineSolveOptions & options = SplineSolveOptions())

    Penalized all-level fit: adds lambda_k times the squared order-q differences along axis k of every run of q + 1 neighbouring active coefficients of a level.

    Differences that would involve an inactive coefficient are omitted, so for q >= 1 constant coefficients (and, generally, polynomials of degree < q in the coefficient index on each level) are unpenalized; q = 0 is ridge regression on all coefficients.

    Parameters
    points

    Sample locations.

    values

    One value per point.

    lambdas

    Nonnegative per-axis weights.

    order

    Difference order (default 2).

    options

    Solver settings.

    Throws
    std::invalid_argument

    As for fit() and tensor_difference_penalty().

    std::runtime_error

    If the normal equations are singular.

    Example
    auto b = dm::fda::BSplineBasis::open_uniform(2, 6);
dm::fda::TruncatedHierarchicalBSpline thb(dm::fda::TensorBSpline(b, std::vector<double>(6, 0.0)));
thb.refine_region({0.0}, {0.5}, 1);
thb.fit_penalized({{0.0}, {1.0}}, {2.0, 2.0}, {1.0}, 1);
std::print("{:.3f}\n", thb.evaluate({0.3})); // 2.000
