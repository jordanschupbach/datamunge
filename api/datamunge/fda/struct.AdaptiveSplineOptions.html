    AdaptiveSplineOptions

    struct AdaptiveSplineOptions
    #include <datamunge/fda/adaptive_pspline.hpp> source

    Search controls for continuous HB/THB regression and hierarchical P-splines. The domain is fixed before fitting. A common finest dyadic coefficient grid defines the penalty, independent of the chosen hierarchical basis. Lambda zero gives least squares. This API fits genuine hierarchical spaces, unlike the independent residual patches of HierarchicalBSpline. No global risk optimum is asserted. The fixed-lambda API uses a training-driven greedy path; the joint API alternates validation tuning and recursive growth.

    Example
    dm::fda::AdaptiveSplineOptions options;
options.lambda = 1e-4; options.max_splits = 3;
    References

    • Giannelli, Jüttler and Speleers (2012), https://doi.org/10.1016/j.cagd.2012.03.025

    • Eilers and Marx (1996), https://doi.org/10.1214/ss/1038425655

    See also
