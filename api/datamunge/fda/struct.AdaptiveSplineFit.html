    AdaptiveSplineFit

    struct AdaptiveSplineFit
    #include <datamunge/fda/adaptive_pspline.hpp> source

    Owned continuous fitted spline, selected tree, and complete refinement audit. Predictions use an equivalent finest-grid B-spline representation, avoiding evaluation-order dependence at cell boundaries. Const evaluation is thread-safe. Path and candidates describe the entire searched path, including prefixes beyond the validation-selected tree. The cells/splits fields describe only the selected model. Fields are snapshots; editing them can invalidate the fit.

    Example
    dm::fda::AdaptiveSplineOptions o; o.root_basis=4; o.max_depth=0;
auto fit=dm::fda::fit_hierarchical_pspline({0,.25,.5,.75,1}, {0,.25,.5,.75,1}, o);
const auto predictions=fit.predict({.1,.9});
    See also

    AdaptiveSplineOptions, fit_adaptive_pspline()

    derivative

    #source
    std::vector< double > derivative(const std::vector< double > & x, int order = 1) const

    Evaluate an analytic derivative of the fitted spline. Input coordinates are clamped before evaluation, as for predict(). These are derivatives of the interior spline evaluated at the clamped point.

    Parameters
    x

    Finite query coordinates; empty is accepted.

    order

    Derivative order, 0..degree, default 1; zero equals predict().

    Returns

    Owned derivative values, in query order.

    Throws
    std::invalid_argument

    For an invalid order, query or coefficient count.

    Example
    dm::fda::AdaptiveSplineOptions o; o.root_basis=4; o.max_depth=0;
auto fit=dm::fda::fit_hierarchical_pspline({0,.25,.5,.75,1}, {0,.25,.5,.75,1}, o);
const auto slopes=fit.derivative({.2,.8}); // approximately {1,1}
