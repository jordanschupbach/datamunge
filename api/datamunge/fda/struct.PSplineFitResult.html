    PSplineFitResult

    struct PSplineFitResult
    #include <datamunge/fda/pspline.hpp> source

    Owned P-spline fit on a supplied BSplineBasis, with fixed-lambda diagnostics.

    Fields preserve observation/basis order. The default size-based fit uses repeated boundary knots; PSplineRegression instead extends equally spaced knots past the domain. Changing fields manually can invalidate diagnostics. Const methods are safe to call concurrently if the object is not mutated. No uncertainty intervals are estimated.

    Example
    const auto fit = dm::fda::fit_pspline({0,1,2}, {0,1,0}, 1, 3, {1.0,2});
std::print("{:.6f}\n", fit.coefficients[1]); // 0.428571
    References

    • P. H. C. Eilers and B. D. Marx (1996). Flexible smoothing with B-splines and penalties. https://doi.org/10.1214/ss/1038425655

    gcv

    #source
    double gcv() const noexcept

    Generalized cross-validation n RSS / (n - edf) squared, with response-squared units.

    Returns

    Fixed-lambda score; infinity when n-edf is numerically zero or negative.

    Example
    const auto fit = dm::fda::fit_pspline({0,1,2}, {0,1,0}, 1, 3, {1.0,2});
std::print("{:.3f}\n", fit.gcv()); // 2.000
    References

    • G. H. Golub, M. Heath and G. Wahba (1979). Generalized cross-validation as a method for choosing a good ridge parameter. https://doi.org/10.1080/00401706.1979.10489751

    loo_residuals

    #source
    std::vector< double > loo_residuals() const

    Delete-one residuals e_i/(1-h_ii), keeping knots and lambda fixed.

    Returns

    Owned n-vector; NaN where 1-h_ii <= 64 machine epsilons (deletion not identified).

    Throws
    std::invalid_argument

    If leverage and residual vector lengths differ.

    Example
    const auto fit = dm::fda::fit_pspline({0,1,2}, {0,1,0}, 1, 3, {1.0,2});
std::print("{:.1f}\n", fit.loo_residuals()[1]); // 1.0
    References
