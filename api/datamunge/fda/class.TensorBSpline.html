    TensorBSpline

    class TensorBSpline
    #include <datamunge/fda/hierarchical_bspline.hpp> source

    A scalar tensor-product B-spline f(x) = sum_j c_j B_j(x) with owned coefficients.

    With one basis this is an ordinary spline curve; with d bases a surface or volume. The coefficient net is row-major over the per-axis basis sizes (last axis fastest), the same column order as fda::BSpline::evaluate(). Evaluation clamps each coordinate into the basis domain, so points outside the domain take the boundary value. Const methods are safe to call concurrently while the object is not mutated.

    Example
    auto b = dm::fda::BSplineBasis::open_uniform(1, 2);     // linear on [0, 1]
dm::fda::TensorBSpline f({b, b}, {0, 1, 1, 2});         // f(x, y) = x + y
std::print("{:.2f}\n", f.evaluate({0.25, 0.5}));        // 0.75
    References

    • C. de Boor (1972). On calculating with B-splines. Journal of Approximation Theory 6(1), 50-62. https://doi.org/10.1016/0021-9045(72)90080-9

    dyadic_refine

    #source
    TensorBSpline dyadic_refine() const

    Dyadically refines every axis and maps the coefficients, giving an identical function on the finer, nested tensor basis.

    Returns

    The refined spline.

    Throws
    std::invalid_argument

    If some axis basis is not clamped.

    Example
    dm::fda::TensorBSpline f(dm::fda::BSplineBasis::open_uniform(2, 4), {0, 1, 3, 2});
auto g = f.dyadic_refine();
