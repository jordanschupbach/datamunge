    class datamunge::compute

    Context

    class Context
    #include <datamunge/compute/context.hpp> source

    Execution context with persistent workers and shared, bounded allocations. Context copies share workers and allocations. CPU and current GPU commands are synchronous; parallel_for serializes submissions on one context and propagates callback exceptions after all workers finish. Separate contexts can run concurrently. No global thread count or current-device setting is changed.

    Example
    const dm::compute::Context context({}, 2);
std::vector<int> values(4);
context.parallel_for(4, [&](std::size_t i) { values[i] = int(i*i); });
std::print("{}\n", values[3]); // 9

    Copy bytes between buffers created by this context; overlap is supported on CPU. GPU overlap requires a temporary buffer; identical views are a no-op. Vulkan copy offsets and byte counts must be multiples of four.

    Parameters
    destination

    Destination view with at least bytes accessible bytes.

    source

    Source view with at least bytes accessible bytes.

    bytes

    Number of bytes to copy; zero is valid.

    Throws
    std::invalid_argument

    Undefined/foreign buffers, overlapping GPU ranges or unaligned Vulkan copy.

    matmul

    #source
    void matmul(
    Buffer & destination,
    const Buffer & a,
    const Buffer & b,
    const MatrixProduct & product) const

    Synchronously overwrite a packed matrix using native GPU arithmetic. Inputs and output must be scalar-aligned views from this context, with at least the requested packed bytes. Extra trailing bytes are untouched. Output must not overlap either input's used range; inputs may alias each other. Calls on one context are serialized. GPU data never passes through host math.

    Parameters
    destination

    Output C allocation/view, overwritten; beta is zero.

    a

    Packed stored A, unmodified.

    b

    Packed stored B, unmodified.

    product

    Logical shape, precision and optional transposes.

    Throws
    std::logic_error

    Native matrix adapter not enabled for this context.

    std::invalid_argument

    Foreign/undefined/unaligned buffers, invalid precision, dimension above INT_MAX, or overlapping output/input ranges.

    std::overflow_error

    Requested byte counts overflow size_t.

    std::out_of_range

    A buffer is too small.

    std::runtime_error

    CUDA driver failure.

    Example
    const dm::compute::Device device{dm::compute::Backend::CUDA,0};
if (dm::compute::probe(device).available) {
  const dm::compute::Context gpu(device);
  if (gpu.supports_matmul()) {
    const float left[]{1,2}, right[]{3,4};
    auto a=gpu.allocate(sizeof(left)), b=gpu.allocate(sizeof(right));
    auto c=gpu.allocate(sizeof(float));
    gpu.upload(a,left,sizeof(left)); gpu.upload(b,right,sizeof(right));
    gpu.matmul(c,a,b,{1,1,2});
    float result=0; gpu.download(&result,c,sizeof(result));
    if (result!=11) throw std::runtime_error("Unexpected matrix product");
  }
}

    Runs the in-house tiled GEMM (shaders/compute/blas.cu, fused multiply-add, one fixed summation order per element). Builds with DATAMUNGE_ENABLE_CUBLAS use cuBLAS instead when DATAMUNGE_CUDA_GEMM=cublas is set as the device is created, for comparison.

    See also

    MatrixProduct, supports_matmul()

    void dispatch(

    Parameters

try { cpu.dispatch(empty,{},nullptr,0); } catch(const std::invalid_argument&) { /* Undefined
handles are rejected. */ }

    parallel_for

    #source
    void parallel_for(std::size_t count, const std::function< void(std::size_t)> & function) const

    Synchronously evaluate one independent callback per index on CPU. The callback must not submit work to the same context (reentry is rejected). A worker error cancels unclaimed indices, waits for running callbacks and rethrows the first exception. The context remains usable afterwards.

    Parameters
    count

    Number of indices [0,count); zero invokes nothing.

    function

    Borrowed callable, alive until all work completes.

    Throws
    std::invalid_argument

    Empty callable.

    std::logic_error

    GPU context or reentry from a callback on this context.

    std::exception

    Callback exception, after outstanding work is joined.

    Example
    const dm::compute::Context context({},2);
std::vector<int> out(3);
context.parallel_for(3,[&](std::size_t i){out[i]=int(i);});
std::print("{}\n",out[2]); // 2
