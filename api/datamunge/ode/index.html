    datamunge::ode

    Canonical checked forward initial-value ODE integration and native studies.

    datamunge/ode/ode_solver.hpp

    Classes

    ODEAttemptActual step proposal, acceptance and callback range, not a replay.
    ODEEvaluationActual finite RHS input state/time and returned derivative, copied from the executing callback.
    ODEExecutionLimitsOptional actual work, retained solution and trace policies, all0values disable their quota.
    ODEOptionsOriginal-order numerical controls for all native forward methods.
    ODESolutionOwned actual forward trajectory including initial and exact requested final time. Public vectors are mutable by C++ callers; accessors retain the original cross-language-friendly shape without promising every binding installation.
    ODESolverOwned-options forward solver with canonical one-step/adaptive/PECE paths. Different solver objects own their options; concurrency also depends on the caller's RHS thread safety. Methods use local work buffers and no global state.
    ODETraceOwned original controls/state and actual callback/attempt/accepted-solution histories.

    datamunge/ode/rhs.hpp

    Classes

    RHSCaller-defined derivative callback dy/dt=f(t,y), without retained solver-owned references. The solver requires finite matching-dimensional returns and guards stages/call budgets before invoking it. User callback exceptions/effects propagate and are not rolled back. Thread safety belongs to the callback implementation. Configured SWIG director support is backend-specific; named builtin systems remain available independently of subclassing support. No all-binding claim.

    Functions

    ode_decay_comparison()Run all six original decay comparison configurations through canonical builtins. Euler/midpoint/RK4/AB4/PECE4 use h.01; RK45 uses initialh.1,abs/rel1e-8. Every solve uses y0=1,k=1,t0..2 and original default actual-work policies. Work/storage follow actual native solver trajectories; no caller data/references, callbacks, random draws or shared mutable state. Default policies apply.
    ode_decay_step_study()Run the original six-step-size Euler/RK4 final-error comparison. Steps.1,.05,.02,.01,.005,.002 retain original order; decay y0=1,k=1,t0..2. Counts and errors derive from each actual native solve, not report-side recurrences. Work/storage follow actual native solver trajectories; no caller data/references, callbacks, random draws or shared mutable state. Default policies apply.
    ode_harmonic_study()Run the original omega1 harmonic oscillator over0..20 with RK4h.01. Returns actual states/projections, sampled cos/sin references and scaled energy drift. This is a numerical diagnostic, not a symplectic/energy-preservation guarantee. Work/storage follow actual native solver trajectories; no caller data/references, callbacks, random draws or shared mutable state. Default policies apply.
    ode_lorenz_study()Run the original Lorenz parameters/initial state over0..25 with RK4h.005. Retains the complete initial transient and all actual x/z projections. A finite phase portrait is not certified long-time pointwise accuracy or attractor proof. Work/storage follow actual native solver trajectories; no caller data/references, callbacks, random draws or shared mutable state. Default policies apply.

    ODESolver

    EnumeratorValueDescription

    One-stage forward Euler.

    Midpoint

    Two-stage explicit midpoint.

    RK4

    Four-stage classical Runge-Kutta.

    RK45

    Seven-evaluation Dormand-Prince embedded4/5, no FSAL reuse.

    AdamsBashforth

    Explicit constant-step Adams order2through4, RK4 startup/tail.

    One PECE correction after Adams prediction, not an iterated implicit solve.
