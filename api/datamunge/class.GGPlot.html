    GGPlot

    class GGPlot
    #include <datamunge/datamunge.hpp> source

    SWIG-friendly facade for datamunge::graphics::GGPlot — a ggplot2-style grammar-of-graphics builder. Geom/theme/scale/facet calls are chainable, mirroring ggplot2's own layered ggplot(df, aes(...)) + geom_point() + ... style as closely as C++ method chaining allows.
