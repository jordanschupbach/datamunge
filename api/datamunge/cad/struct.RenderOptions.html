    struct datamunge::cad

    RenderOptions

    struct RenderOptions
    #include <datamunge/cad/render.hpp> source

    Controls for deterministic, device-independent CPU rendering. The optional material workflow uses GGX reflection and Schlick Fresnel with approximate ambient illumination and a filmic display curve; it is not a path tracer or a subsurface-scattering model. Defaults retain legacy shading.

    Example
    dm::cad::RenderOptions settings;
settings.physically_based=true; settings.shadow_samples=6;
settings.studio_environment=.5; // optional broad studio reflections
    References

    • Walter et al. (2007), Microfacet Models for Refraction through Rough Surfaces. https://doi.org/10.2312/EGWR/EGSR07/195-206

    • Schlick (1994), An Inexpensive BRDF Model for Physically-based Rendering. https://doi.org/10.1111/1467-8659.1330233
