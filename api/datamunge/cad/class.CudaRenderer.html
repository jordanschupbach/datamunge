    class datamunge::cad

    CudaRenderer

    class CudaRenderer
    #include <datamunge/cad/render.hpp> source

    Explicit NVIDIA CUDA offscreen CAD renderer with persistent device resources. Uses the existing compute CUDA kernel backend. Primary, shadow and AO rays, materials/maps, transparency, sampling and wire overlays execute on the GPU. Geometry/BVH preparation stays on the CPU. Float32 device arithmetic and scale-aware ray bias can differ from the CPU reference; this is not a bit-exact replacement. Inputs must be representable in float32. The last base snapshot and its uploaded geometry are retained until replaced or this renderer is destroyed. Calls on one instance serialize; separate instances own separate contexts. No silent fallback is performed. CPU render() remains available in builds without CUDA; select fallback explicitly in the application.

    Example
    if (dm::compute::probe({dm::compute::Backend::CUDA,0}).available) {
  dm::cad::Scene scene;
  dm::cad::AddPrimitiveToScene(&scene,dm::cad::PrimitiveKind::Cube);
  auto camera=dm::cad::fit_camera(scene);
  dm::cad::PreparedScene prepared(std::move(scene));
  dm::cad::CudaRenderer gpu;
  auto image=gpu.render(prepared,{},camera);
}

    render

    #source
    RenderResult render(
    const PreparedScene & base,
    const Scene & actors,
    const Camera & camera,
    const RenderOptions & options = {})

    Render a prepared base and transient actors with the base's lights on CUDA. Reuses base uploads for the same snapshot. Moving actors and the combined hierarchy are uploaded each call. Output is synchronous, owned host RGBA8, centre-ray depth and source IDs. No window, hardware ray-tracing API, or external renderer is needed. options.threads affects only CPU rendering.

    Parameters
    base

    Owned validated base snapshot; unchanged and retained by the cache.

    actors

    Transient owned scene; may be empty; validated without mutating it.

    camera

    Camera in the same world units as the scene.

    options

    Output/material settings; defaults match CPU render options.

    Returns

    Owned float32-derived color/depth/ID buffers.

    Throws
    std::invalid_argument

    Invalid scene, camera/options or float32 overflow/underflow.

    std::length_error

    Device buffer indexing exceeds signed 32-bit limits.

    std::runtime_error

    Native allocation, upload, execution or readback failure.
