    class datamunge::cad

    Solid

    class Solid
    #include <datamunge/cad/solid.hpp> source

    An owned B-rep solid with value-returning modelling and export operations. Geometry uses doubles in caller-selected consistent units. Copies own topology; immutable surfaces may be shared. Operations return new solids, preserving inputs. Unsupported kernel operations throw std::runtime_error with the kernel diagnostic. Concurrent const access is safe; do not mutate a shared object concurrently.

    Example
    auto block = dm::cad::Solid::box(4, 3, 2);
auto hole = dm::cad::Solid::cylinder(.4, 4).translated(2, 1.5, -1);
auto part = block.subtracted(hole);
part.save("part.step");
