    class datamunge::cad

    VideoWriter

    class VideoWriter
    #include <datamunge/cad/video.hpp> source

    Stream rendered frames directly into a silent H.264 MP4 without intermediate PNGs. Requires ffmpeg with libx264 on PATH. Uses a bounded OS stream with synchronous backpressure; there is no unbounded queue or shell command interpolation. Encoding uses baseline/yuv420p, CRF19, fast, no B frames and a two-second GOP. Input alpha is discarded by the encoder. One writer is single-threaded; independent writers may coexist. Call finish() to publish the completed file; destruction closes the child and discards unfinalized temporary output. Existing destinations are retained until successful finalization.

    Example
    dm::cad::RenderResult frame;frame.width=64;frame.height=48;
frame.rgba.assign(64*48*4,255);
dm::cad::VideoWriter video("example.mp4",64,48,15);
video.append(frame);video.append(frame);video.finish();
    References

    • FFmpeg's rawvideo input options and explicit pixel format/dimensions/frame rate: https://github.com/FFmpeg/FFmpeg/blob/master/doc/demuxers.texi
