    class datamunge::cad

    Robot

    class Robot
    #include <datamunge/cad/robot.hpp> source

    Load real robot visual meshes and compute poses from URDF joint values. Supports a single rooted link tree, fixed/revolute/continuous/prismatic joints, mimic relations, visual origins, mesh scale, materials and relative or package:// asset paths. Coordinates are URDF metres/radians; CAD STEP files keep their own file units. Inertial/collision/dynamics/transmissions are not evaluated by this visual loader. Xacro must be expanded first. Geometry is owned; copies share immutable source meshes and have independent joint positions. Concurrent const scene generation is safe.

    Example
    auto robot = dm::cad::Robot::load_urdf("ReBot_Arm_DM.urdf");
robot.set_joint("joint2", -.6);
auto scene = robot.scene();
dm::cad::render(scene, dm::cad::fit_camera(scene)).save("arm.png");
    References

    #source
    static Robot load_urdf(const std::string & path, const std::string & package_root = "")

    Load a URDF tree and every referenced visual asset synchronously.

    Parameters
    path

    Existing plain URDF file.

    package_root

    Optional directory containing ROS package directories; empty searches ancestors of the URDF for a matching package name.

    Returns

    Owned model with zero independent coordinates clamped into their limits.

    Throws
    std::invalid_argument

    Invalid/duplicate/cyclic graph, unsupported geometry/joint, malformed numeric values, limits or unresolved package URI.

    std::runtime_error

    XML or asset I/O/import failure.

    set_measured_joint

    #source
    void set_measured_joint(const std::string & name, double value)

    Set a finite measured joint coordinate without enforcing authored motion limits. For rendering physical encoder states, including small compliant-limit excursions. Does not simulate or clamp motion. Mimic relations still apply; this copy's FK subsequently accepts measured coordinates. set_joint() remains strictly limited.

    Parameters
    name

    Existing independent movable joint.

    value

    Finite radians/metres, absolute magnitude at most 1000.

    Throws
    std::invalid_argument

    Invalid name, fixed/mimic joint or invalid value.

    Example
    auto robot=dm::cad::Robot::load_urdf("ReBot_Arm_DM.urdf");
robot.set_measured_joint("joint2", .0001); // measured compliant-stop excursion
auto scene=robot.scene();
    See also

    set_joint(), link_transform()

    set_measured_joints

    #source
    void set_measured_joints(const std::vector< std::pair< std::string, double > > & values)

    Set a group of measured encoder coordinates in one transaction. Uses the same finite measured-state semantics as set_measured_joint(), with one map copy and validation pass. Empty input leaves this model unchanged.

    Parameters
    values

    Unique independent joint names and finite coordinates, absolute value <=1000.

    Throws
    std::invalid_argument

    Duplicate/unknown names, fixed/mimic joints or invalid values.

    Example
    auto robot=dm::cad::Robot::load_urdf("ReBot_Arm_DM.urdf");
robot.set_measured_joints({{"joint1",.1},{"joint2",-.5}});
auto pose=robot.link_transform("end_link");
