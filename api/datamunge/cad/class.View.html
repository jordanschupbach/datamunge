    class datamunge::cad

    View

    class View
    #include <datamunge/cad/view.hpp> source

    A small code-driven scene facade, exposed as CadScene in Python/R. Owns scene/camera/render controls. All operations delegate to the canonical CAD, polygon and renderer APIs; copying retains independent scene state.

    Example
    dm::cad::View view;
view.add(dm::cad::Solid::box(2, 3, 4), "#3b82f6", "block");
view.size(640, 480); view.render("block.png");

    Used in reports

    from_urdf

    #source
    static View from_urdf(const std::string & path)

    Load an articulated URDF visual model and its asset files.

    Parameters
    path

    URDF file; relative meshes resolve beside it.

    Returns

    Owned view at the loader's initial joint coordinates.

    Throws
    std::invalid_argument

    Invalid URDF/joint data.

    std::runtime_error

    Import failure.

    Example
    auto view = dm::cad::View::from_urdf("robot.urdf");
view.set_joint("joint2", -.6); view.render("robot.png");
