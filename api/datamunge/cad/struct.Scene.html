    FindObject

    #source
    Object3D * FindObject(int id)

    Borrow an editable scene object by its stable integer ID.

    Parameters
    id

    Object ID returned by AddObject or a scene construction helper.

    Returns

    Borrowed pointer, or nullptr for an unknown ID. Reacquire after any objects-vector mutation, including AddObject and RemoveObject.

    Example
    dm::cad::Scene scene;
int id = dm::cad::AddPrimitiveToScene(&scene, dm::cad::PrimitiveKind::Cube);
if (auto* object = scene.FindObject(id)) object->color = {1, 0, 0, 1};
