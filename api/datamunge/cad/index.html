    datamunge/cad/render.hpp

    Classes

    CameraA camera value independent of a window or graphics device. Camera units match the scene; up need not be normalized. A valid camera has distinct position/target and an up direction not parallel to its view.
    CudaRendererExplicit NVIDIA CUDA offscreen CAD renderer with persistent device resources. Uses the existing compute CUDA kernel backend. Primary, shadow and AO rays, materials/maps, transparency, sampling and wire overlays execute on the GPU. Geometry/BVH preparation stays on the CPU. Float32 device arithmetic and scale-aware ray bias can differ from the CPU reference; this is not a bit-exact replacement. Inputs must be representable in float32. The last base snapshot and its uploaded geometry are retained until replaced or this renderer is destroyed. Calls on one instance serialize; separate instances own separate contexts. No silent fallback is performed. CPU render() remains available in builds without CUDA; select fallback explicitly in the application.
    PickResultA nearest visible triangle hit in scene coordinates.
    PreparedSceneOwned immutable transformed geometry reusable across cameras and frames. Construction validates and prepares a snapshot. Copies share that immutable snapshot; later changes to the source Scene cannot affect it. Concurrent const renders are safe. An optional actor scene is prepared for just that call and participates in all primary, shadow and AO rays. Base lighting is retained. Actor rendering shares validated, transformed base triangles and rebuilds a combined hierarchy in flattened scene order, preserving equal-depth ties. The base-only hierarchy is initialized lazily under a thread-safe once guard.
    RayA world-space ray; rendering/picking normalize its direction.
    RenderOptionsControls for deterministic, device-independent CPU rendering. The optional material workflow uses GGX reflection and Schlick Fresnel with approximate ambient illumination and a filmic display curve; it is not a path tracer or a subsurface-scattering model. Defaults retain legacy shading.
    RenderResultOwned RGBA8 render and centre-ray depth/object buffers. Pixels are top-left row-major. Depth is normalized-ray distance in scene units, infinity for background; object IDs are -1 for background. Samples affect color only. Buffers outlive the scene and may be inspected in code.

    Functions

    draw_text()Draw compact bitmap text onto owned RGBA pixels, for native video/chart overlays. Uses the original built-in 5x7 font: ASCII lowercase is uppercased, unsupported bytes use '?', newline starts an eight-row line. Pixels outside the image are clipped. Alpha blends only RGBA; depth/object buffers remain unchanged.
    fit_camera()Choose a perspective camera framing all visible transformed vertices.
    pick()Intersect a ray with visible transformed scene meshes using a BVH.
    render()Render a scene without a window, GPU context or external executable. Uses the source modeller's ambient/diffuse/specular metallic-roughness formula, directional/point lights, RGBA textures and tangent-space normal maps. Shadows use triangle rays rather than the editor's shadow map. Materials use the source's red-channel roughness/metallic textures. Const scene access is safe across independent concurrent renders.

    Types and constants

    Projectionenum Camera projection for offline rendering.
    RenderStyleenum Surface shading and optional visible triangle-edge display.

    datamunge/cad/robot.hpp

    Classes

    RobotLoad real robot visual meshes and compute poses from URDF joint values. Supports a single rooted link tree, fixed/revolute/continuous/prismatic joints, mimic relations, visual origins, mesh scale, materials and relative or package:// asset paths. Coordinates are URDF metres/radians; CAD STEP files keep their own file units. Inertial/collision/dynamics/transmissions are not evaluated by this visual loader. Xacro must be expanded first. Geometry is owned; copies share immutable source meshes and have independent joint positions. Concurrent const scene generation is safe.
    RobotJointAn owned summary of a URDF joint and its limits.

    datamunge/cad/solid.hpp

    Classes

    SolidAn owned B-rep solid with value-returning modelling and export operations. Geometry uses doubles in caller-selected consistent units. Copies own topology; immutable surfaces may be shared. Operations return new solids, preserving inputs. Unsupported kernel operations throw std::runtime_error with the kernel diagnostic. Concurrent const access is safe; do not mutate a shared object concurrently.

    Functions

    add_solid()Add a tessellated solid as an owned polygon scene object.
    load_scene()Load a polygon or CAD document into an owned renderable scene. Supports STEP/STP, IGES/IGS, STL, mepcad, OBJ/MTL, glTF/GLB, IQM, VOX, M3D and native Blender mesh import. Parametric documents are rebuilt first. CAD data are tessellated for rendering; use ReadStepText/ReadIgesText to retain exact topology and their detailed unsupported-entity reports.

    datamunge/cad/video.hpp

    Classes

    VideoWriterStream rendered frames directly into a silent H.264 MP4 without intermediate PNGs. Requires ffmpeg with libx264 on PATH. Uses a bounded OS stream with synchronous backpressure; there is no unbounded queue or shell command interpolation. Encoding uses baseline/yuv420p, CRF19, fast, no B frames and a two-second GOP. Input alpha is discarded by the encoder. One writer is single-threaded; independent writers may coexist. Call finish() to publish the completed file; destruction closes the child and discards unfinalized temporary output. Existing destinations are retained until successful finalization.
