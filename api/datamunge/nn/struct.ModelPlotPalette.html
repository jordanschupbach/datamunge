    ModelPlotPalette

    struct ModelPlotPalette
    #include <datamunge/nn/model_plot.hpp> source

    Shared category colors for all model diagram styles.

    Values must be six-digit hexadecimal SVG colors, including '#'. Category labels in the legend keep the figure interpretable without relying on color alone.

    Example
    dm::nn::ModelPlotPalette colors;
colors.convolution = "#3388CC";
dm::nn::ModelPlotOptions options;
options.colors = colors;
