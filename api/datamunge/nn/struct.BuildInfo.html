    BuildInfo

    struct BuildInfo
    #include <datamunge/nn/build_info.hpp> source

    A snapshot of build and run-time facts, as returned by build_info().

    Members

    Functions

    to_markdown()A two-column Markdown table of the fields, one row each.

    Fields

    versionLibrary version string, or "unknown" when the build did not generate a version header.
    dtypesSupported tensor dtypes, in DType order.
    gemm_backendThe GEMM used for float matmul and convolution: "inhouse-<isa>" (the library's own kernels, e.g. "inhouse-avx512"), or "accelerate", "openblas", "cblas" in DATAMUNGE_USE_BLAS builds.
    lapackWhether dense linear algebra (cholesky, eigh, svd, ...) uses LAPACK.
    threadsThreads nn kernels may use (get_num_threads()).
    hardware_threadsHardware threads reported by the C++ runtime (0 if unknown).
    architectureCPU architecture the library was compiled for ("x86_64", "aarch64", ...).
    compilerCompiler name and version.
    cpu_featuresSIMD and arithmetic features the running CPU reports (e.g. "AVX2", "FMA", "NEON").
