    datamunge/nn/tabular_classification.hpp

    Classes

    TabularClassificationDataOwned two-predictor classification fixture, with no fitted model.
    TabularClassificationSplitOwned actual seeded row partition; no labels or features are consulted.
    TabularStandardizationFrozen training-column population mean and scale computed using tensor reductions. Constant columns use scale1. Values own detached storage; inference never updates them.

    Functions

    fit_tabular_standardization()Fit standardization on supplied training rows only, with no model/optimizer changes. O(ND) tensor reductions. Population variance uses divisor N, not N-1.
    iris_petal_classification_data()Load bundled Iris with only Petal.Length and Petal.Width, without fitting/scaling.
    moon_classification_data()Generate the original noisy interleaved moons using its exact draw schedule. Uses theta=pi*i/(per_moon-1), normal(0,.12), MT19937_64 seed3. Each row pair draws upper x/y then lower x/y; lower=(1-cos(theta),.5-sin(theta)). O(N) work/storage; no fitting or caller RNG mutation.
    tabular_classification_split()Shuffle original row IDs with MT19937_64 and partition without replacement. O(N) work/storage, deliberately not stratified; preserves original report splits.
    tabular_decision_regions()Plot actual tensor classifier argmax on a raw two-variable grid with labeled observations. Uses training-feature extrema plus10% padding; does not inspect held-out features to choose ranges or refit statistics. Query logits callback must apply the same frozen training standardization as its model. Evaluation runs with NoGradGuard. Cells display argmax class IDs; no posterior calibration or extrapolation claim. O(G squared) callback rows/output, plus observation copy; caller model is borrowed.
    transform_tabular_features()Apply frozen training statistics through differentiable tensor arithmetic. No refit or input mutation. O(ND) work/output; gradients flow to input when enabled.
    xor_classification_data()Generate the original four noisy XOR corners with a local MT19937_64 stream. Corner order(0,0),(0,1),(1,0),(1,1), drawing x jitter then y jitter for each row. Noise is normal(0,.12), seed1; labels0 for equal corners and1 otherwise. O(N) work/storage, no global RNG state mutation or fitting.
