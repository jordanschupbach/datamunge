    model_stage

    2 overloads.

    #include <datamunge/nn/model_plot.hpp>
    #source
    Tensor model_stage(
    const std::string & name,
    const Tensor & input,
    const Tensor & output)

    Mark a composite stage for grouped model diagrams, returning its output unchanged.

    Call inside a forward function after computing output from input. Outside plotting, this is an identity with no allocation or tensor mutation. A grouped stage stands for the subgraph between input and output; all external data inputs must pass through input. For independent inputs, use the vector-input overload or concatenate them before computing the stage output. A detached output may declare a data-only producer for Blocks detail. A consumer must list that same output handle as a boundary to show the dependency; no gradient edge is created. Producers may be marked before or after their consumers. Named layer detail remains available with detail=Layers, and primitives with detail=Operations (or expand_layers=true). A later mark of the same output wins. Does not fit, detach, copy values or alter gradient flow.

    Parameters
    name

    Display name for this stage.

    input

    Tensor at the stage's boundary, preceding output in the forward graph.

    output

    Computed stage output; must differ from input to create a group.

    Returns

    The same output tensor handle.

    Example
    namespace n = dm::nn;
n::ParameterStore p(17);
const auto graph = n::plot_model([&](const auto &x) {
  const auto y = n::mlp(p, "hidden", x, {4, 4});
  return n::model_stage("Two hidden layers", x, y);
}, n::zeros({1, 2}));
    See also

    plot_model(), ModelPlotOptions::expand_layers

    #source
    Tensor model_stage(
    const std::string & name,
    const std::vector< Tensor > & inputs,
    const Tensor & output)

    Mark a composite stage with multiple external tensor inputs.

    Records one block with an incoming edge from each distinct differentiable input or explicitly declared detached producer. Supply every external data boundary used by output; unnamed constants without gradient history are ignored. Detached producers are marked with model_stage() on the same tensor handle and may be declared before or after this consumer. Inputs precede output in the logical graph; cycles are rejected by plot_model() in Blocks detail. No gradient edges are added. Grouping does not recompute values or change gradients. Outside a plot it returns output without allocating. Layers/Operations detail expands the block as for the single-input form.

    Parameters
    name

    Display name for this stage.

    inputs

    External data boundaries; duplicates are merged. Empty/undefined boundaries leave the output ungrouped, as does a boundary equal to output.

    output

    Already-computed output depending on the supplied inputs.

    Returns

    The same output tensor handle.

    Example
    namespace n=dm::nn;
const auto graph=n::plot_model([](const n::Tensor& x){
  const auto a=x*2., b=x*3.;
  return n::model_stage("Two-branch merge",std::vector<n::Tensor>{a,b},n::relu(a+b));
},n::ones({1,4}));
    namespace n=dm::nn;
const auto masked=n::plot_model([](const n::Tensor& x){
  const auto mask=n::cast(n::greater(x,0.),x.dtype());
  n::model_stage("Detached sign selector",x,mask);
  return n::model_stage("Apply selector",std::vector<n::Tensor>{x,mask},x*mask);
},n::ones({1,4}));
// Blocks detail retains both the activity and detached-selector dependencies.
