    MobileNetClassifier

    class MobileNetClassifier
    #include <datamunge/nn/mobile_classifier.hpp> source

    Full MobileNet-v1 with a configurable narrow width and native Adam/autograd training. Uses all thirteen depthwise/pointwise blocks, ReLU6, moving-statistic BN and global average pooling. CPU float32 inputs are NHWC RGB in [0,1]; the forward normalizes them to [-1,1]. Default width .125 and side 64 make a compact model. This is trained from scratch, without pretrained weights. The checkpoint includes architecture, every learned tensor and every BN moving moment. Single-writer, including inference; fitting is not resumable from optimizer state.

    Example
    dm::nn::MobileNetClassifier model(2,64,.125,17);
auto probabilities=model.predict(dm::nn::zeros({1,64,64,3}));
model.save("mobile.npz");
auto restored=dm::nn::MobileNetClassifier::load("mobile.npz");
    References

    • Howard et al. (2017), MobileNets: Efficient Convolutional Neural Networks for Mobile Vision Applications. https://arxiv.org/abs/1704.04861

    fit

    #source
    MobileClassifierTraining fit(
    const Tensor & images,
    const Tensor & labels,
    const Tensor & validation,
    const Tensor & validation_labels,
    MobileClassifierOptions options = {})

    Fit every layer using Adam and select an epoch solely on validation loss. Brightness augmentation multiplies each training image by a seeded random gain and clamps to [0,1]; optional seeded grayscale augmentation uses luminance .299R+.587G+.114B on each training image. Validation is never augmented or used for gradients. Inputs are checked before any training mutation; solver errors may leave partial training updates. The optional progress observer runs after each measured epoch; its exceptions propagate before best-checkpoint restoration. At completion both weights and BN moments are restored together to the selected epoch.

    Parameters
    images

    Nonempty CPU float32 [N,side,side,3], finite values in [0,1].

    labels

    CPU int64 [N], each in [0,classes).

    validation

    Independent nonempty images with the same pixel contract.

    validation_labels

    Corresponding CPU int64 labels.

    options

    Valid positive training settings.

    Returns

    Full per-epoch evidence and the selected epoch index.

    Throws
    std::invalid_argument

    Invalid pixels, shapes, labels or settings, before mutation.

    std::runtime_error

    Nonfinite training/validation loss.

    Example
    dm::nn::MobileNetClassifier model(2,16,.0625,17);
auto x=dm::nn::zeros({2,16,16,3});
auto y=dm::nn::from_vector(std::vector<std::int64_t>{0,1});
dm::nn::MobileClassifierOptions options; options.epochs=1;
auto fitted=model.fit(x,y,x,y,options); // Use independent validation data in real work.
