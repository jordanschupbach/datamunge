    SavedModelHttpServer

    class SavedModelHttpServer
    #include <datamunge/nn/saved_model_http.hpp> source

    Serve the affine Float32 SavedModel signature on IPv4 loopback.

    GET /healthz returns ok. POST /predict accepts whitespace-separated finite feature pairs and returns one prediction per line. Requests are handled sequentially with bounded headers, bodies, and row counts.

    Example
    const dm::nn::SavedModel model("saved_model");
dm::nn::SavedModelHttpServer server(model);
std::println("{}", server.port());
    See also

    SavedModel, saved_model_http_available()

    serve

    #source
    void serve(std::size_t requests = 0)

    Run the event loop on the calling thread.

    Parameters
    requests

    Completed routed replies before stopping, or zero to serve continuously. A finite run times out after ten seconds. Call from only one thread at a time.

    Throws
    std::runtime_error

    Event loop error or finite run timeout.

    Example
    dm::nn::SavedModelHttpServer server(dm::nn::SavedModel("saved_model"));
// A separate client connects to server.port() and sends one request.
server.serve(1);
