    HiddenMarkovModel

    class HiddenMarkovModel
    #include <datamunge/nn/classical_components.hpp> source

    Run scaled categorical HMM inference and one expectation/maximization update.

    Fixed positive K,V,T; accepts nonempty Int32 CPU[B,T] symbols and validated Float64 probability tables. Runs without autograd, preserving source equations and first-index ties. Callers own EM iterations, convergence and checkpoints. Shared input writes require synchronization.

    Throws
    std::invalid_argument

    Invalid geometry, dtype, backend, nonfinite inputs or scalar domain.

    Example
    dm::nn::ml::HiddenMarkovModel model(2,2,3);
    References

    • Rabiner (1989), A tutorial on hidden Markov models and selected applications in speech recognition, https://doi.org/10.1109/5.18626 .

    Run

    #source
    HmmResult Run(const nn::Tensor & observations, const HmmState & state) const

    observations: int32 [B,T] symbols in [0,V).

    Compute scaled smoothing, Viterbi paths and exactly one Baum-Welch update.

    Detached Float64 CPU outputs. Zero-count transition/emission rows retain prior probabilities; T=1 retains all transition rows. No pseudocounts or fitting loop. O(B T K squared + B T K V) work; owns output storage. Numerically impossible sequences throw rather than returning invalid posteriors.

    Parameters
    observations

    Int32 CPU[B,T], B>0, symbols in[0,V).

    state

    Borrowed normalized Float64 CPU[K],[K,K],[K,V] tables.

    Returns

    Detached likelihoods, smoothed state probabilities, best paths and next tables.

    Throws
    std::invalid_argument

    Invalid dimensions, symbol range, backend, dtype or normalized probability tables.

    std::runtime_error

    A sequence has zero or numerically invalid probability.

    Example
    namespace n=dm::nn;n::ml::HiddenMarkovModel m(2,2,3);n::ml::HmmState
s{n::full({2},.5,n::DType::Float64),n::full({2,2},.5,n::DType::Float64),n::full({2,2},.5,n::DType::Float64)};auto
r=m.Run(n::zeros({1,3},n::DType::Int32),s);
