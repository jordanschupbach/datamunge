    struct OptimizerConfig
    #include <datamunge/nn/optim.hpp> source

    Validated update-rule settings; unused fields retain their defaults for other rules.

    Used in reports

    Early Stopping and Checkpoints: Selection Is Not ResumeLearning-Rate Schedules: Clock, Endpoints and StateSGD, Momentum and Nesterov: State, Rates and Stability

    Members

    Functions

    validate()Throws std::invalid_argument for out-of-range settings.

    Fields

    kindRule used for every parameter in this optimizer.
    momentumVelocity decay for Momentum, Nesterov, and LARS; in [0, 1).
    beta1First-moment decay for Adam-family methods and Lion; in [0, 1).
    beta2Second-moment decay, or Lion's history decay; in [0, 1).
    rhoRMSProp/Adadelta squared-history decay; in [0, 1).
    epsilonPositive numerical stabilizer; placement depends on the update rule.
    initial_accumulatorNonnegative starting squared-gradient sum for Adagrad.
    weight_decayNonnegative decay used only by AdamW, LAMB, LARS, and Lion.
    trust_coefficientPositive multiplier for the LARS local trust ratio.
    factor_epsilonPositive Adafactor squared-gradient regularizer/variance floor.
    parameter_epsilonPositive RMS weight floor for Adafactor parameter scaling.
    update_clipPositive maximum RMS of the normalized Adafactor direction.
    decay_exponentAdafactor second-moment decay exponent, in (0, 1].
    relative_stepCap Adafactor's rate at 1/sqrt(step) when enabled.
    scale_parameterMultiply Adafactor's rate by max(RMS(weight), parameter_epsilon).
