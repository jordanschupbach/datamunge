    ExactImageShapley

    struct ExactImageShapley
    #include <datamunge/nn/image_explainers.hpp> source

    Owned exact-enumeration fixed-baseline Shapley values and actual coalition scores. patch_values is Float64 [R,C]; coalition_scores is Float64 [2^P], indexed by ascending integer masks with patch zero the least significant bit. All retained tensors are detached independent storage. Base/full are actual endpoints, and efficiency_residual=sum(patch_values)-(full-base), including rounding error. Exact means no coalition sampling, not exact real arithmetic or causal evidence. Attributions may be signed; changing baseline, partition or score changes the game.

    Example
    dm::nn::ImagePatchOptions o;o.patch_rows=1;o.patch_cols=1;
const auto e=dm::nn::exact_image_shapley(dm::nn::ones({1,1,1,1}),[](const dm::nn::Tensor& x){return dm::nn::sum(x,{1,2,3});},o);
std::print("{:.0f} {}\n",e.patch_values.item(),e.work.evaluations); // 1 2
    References

    • Lundberg and Lee (2017), A Unified Approach to Interpreting Model Predictions. https://proceedings.neurips.cc/paper/2017/file/8a20a8621978632d76c43dfd28b67767-Paper.pdf. Exact fixed-baseline coalition game, not conditional-expectation or KernelSHAP estimation.
