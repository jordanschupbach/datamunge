    AdversarialSR

    #include <datamunge/nn/adversarial_super_resolution.hpp>
    #source
    AdversarialSROutput AdversarialSR(
    ParameterStore & generator,
    ParameterStore & critic,
    ParameterStore & stats,
    const Tensor & lr,
    const Tensor & target,
    const Tensor & bicubic,
    const Tensor & feature_weight,
    const Tensor & feature_bias,
    bool enhanced = false,
    bool adversarial = false)

    Evaluate explicit compact SRGAN/ESRGAN pixel/content/adversarial phases without fitting.

    Three distinct matching Float32/64 G,D,stats stores. Finite signed matching CPU lr[N,16,16,3],target/bicubic[N,32,32,3], N>0 aligned; frozen matching1792 feature values as AdversarialSRFeatures. All supplied inputs/aliases/products validate before leaves. Source seeds7001/7013/0. Both saved-statistic and batch- statistic G paths always evaluate; stats unchanged beyond initialization. G1591/25,D1673/8,BN40/10(default SRGAN), or G3511/40,D1672/7,no BN(ESRGAN). Objectives read training G: SRGAN pixelMSE, post-ReLU featureMSE; ESRGAN pixelL1, pre-activation featureL1. Both feature tensors divide by255 BEFORE loss. Frozen weights/bias always stop; target extracted features stop, target pixel/real-score paths remain live. SRGAN D is full real/fake logistic mean sum, G adversarial is full nonsaturating mean. ESRGAN uses live relativistic means and half-scaled D/G terms. gan_loss=content+double(float(.001 or .005))*adversarial; ESRGAN adds double(float(.01))*pixel. g_loss=(1-phase)*pixel+phase*gan_loss, phase=adversarial?1:0, computing all components even during warm-up. No fitting, hidden no-grad, partial capture, weight/statistic write or later RNG. Only missing leaves initialize. Caller owns16 pixel-only G steps, resets BOTH Adam states without changing weights/stats, then D capture/write followed by a fresh G capture/write on the same batch. After each G weight write, explicitly commit BN moving candidates from the detached moments captured WITH that G partial, momentum double(.9f). Never recompute moments after writing weights. BN state and1792 frozen feature values are excluded from optimizers; no generator weight EMA exists. Applicable first/higher paths remain live. Owning fields keep storage/graphs; stored-leaf/state/math errors may follow initialization. O(N) fixed-map work/storage, largest features[N,32,32,64]; synchronize stores.

    Parameters
    generator

    Caller-owned floating G store, source seed7001.

    critic

    Distinct same-dtype D store, source seed7013.

    stats

    Distinct same-dtype saved BN store, source seed0; excluded from optimizers.

    lr

    Finite matching CPU[N,16,16,3] low-resolution inputs.

    target

    Finite aligned matching CPU[N,32,32,3] HR targets, never G inputs.

    bicubic

    Finite aligned matching CPU[N,32,32,3] external LR-derived image shortcut.

    feature_weight

    Finite matching CPU[3,3,3,64] actual frozen feature values.

    feature_bias

    Finite matching CPU[64] actual frozen bias.

    enhanced

    Select ESRGAN(true), otherwise SRGAN(false default).

    adversarial

    Select content/adversarial G objective(true), otherwise pixel warm-up(false default).

    Returns

    Owning AdversarialSROutput with all source fields and detached optional BN captures.

    Throws
    std::invalid_argument

    For invalid geometry, dtype, values, alignment, products, aliased stores or incompatible leaves.

    std::logic_error

    For non-CPU storage.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;n::ParameterStore g(7001),d(7013),s(0);
auto lr=n::zeros({2,16,16,3}),hr=n::zeros({2,32,32,3});
auto out=n::models::AdversarialSR(g,d,s,lr,hr,hr,n::zeros({3,3,3,64}),n::zeros({64}),true,true);
auto partial=n::grad(out.d_loss,d.parameters());
// Caller applies D, reruns G, applies G, then commits same-capture BN moments if present.
    References

    • Ledig et al.(2017), Photo-Realistic Single Image Super-Resolution Using a Generative Adversarial Network, https://arxiv.org/abs/1609.04802 ; Wang et al.(2018), ESRGAN: Enhanced Super-Resolution Generative Adversarial Networks, https://arxiv.org/abs/1809.00219 . Fixed-width x2 teaching adaptations with a bicubic image shortcut, not pretrained benchmark models.
