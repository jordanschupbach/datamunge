    CondenseNetConfig

    struct CondenseNetConfig
    #include <datamunge/nn/condensenet_models.hpp> source

    Dense-stage dimensions, group condensation and regularization settings.

    Defaults describe CIFAR CondenseNet-86: 42 dense layers, growth 8/16/32. Metadata validation allocates no learned tensors; no fitting is hidden.

    Example
    dm::nn::models::CondenseNetConfig cfg;
cfg.Validate();
    References

    • Huang et al. (2018), https://arxiv.org/abs/1711.09224; https://github.com/ShichenLiu/CondenseNet

    Functions

    Validate

    #source
    void Validate() const

    Validate stage lengths, divisibility, probabilities and representable channel widths.

    Every layer input must divide by groups and condense; every growth and LGC output must divide by groups. O(number of dense layers), no learned allocation.

    Throws
    std::invalid_argument

    For invalid stages, widths, overflow, classes, lasso or momentum.

    Example
    dm::nn::models::CondenseNetConfig{}.Validate();
