    Vq2ConditionalPrior

    class Vq2ConditionalPrior
    #include <datamunge/nn/vector_quantized_autoencoder_2.hpp> source

    Fit a fine raster prior conditioned on parent-aligned coarse symbols and the previous fine symbol.

    Coarse grids[B,Ht*Wt] pair with fine grids[B,4*Ht*Wt], interpreted as raster Ht×Wt and 2Ht×2Wt. For fine position(r,c), parent=(r/2)*Wt+c/2 using integer division. Each image starts previous=BOS=K; transitions are counted by [parent_code,previous_fine,current_fine]. Positive Dirichlet smoothing gives p=(count+s)/(context_total+K*s). Defaults K16,Ht=Wt=7,s=0.5 preserve the source. The caller supplies fitting codes only and enforces provenance; no image, neural prior, model update or RNG is involved. This first-order baseline conditions on one aligned top symbol, not the full coarse grid or fine prefix. Construction copies state; exports are independent. Read-only methods are thread-safe. Work O(B*4*Ht*Wt+K^3), storage O(B*4*Ht*Wt+K^3).

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::models::Vq2ConditionalPrior
prior(n::zeros({1,1},n::DType::Int32),n::zeros({1,4},n::DType::Int32),1,1,2); const auto
ids=prior.Sample(n::zeros({1,1},n::DType::Int32),n::full({1,4},.2,n::DType::Float64));
// A four-symbol fine grid drawn from caller-supplied uniforms and one coarse code.
    References

    • Razavi et al. (2019), https://arxiv.org/abs/1906.00446 , motivates fitting a fine-code prior conditional on coarse codes. This repository's smoothed parent/previous-symbol baseline is not the paper's neural PixelCNN prior.

    Sample

    #source
    Tensor Sample(const Tensor & top, const Tensor & uniforms) const

    Sample a fine grid from a supplied coarse grid and explicit uniform values.

    Uses the aligned top parent and previous sampled fine symbol; BOS resets per image. Selects the first cumulative probability strictly greater than u, with final-code fallback for row-sum roundoff. Uniforms must be Float64 in [0,1), retaining source precision at CDF boundaries. No RNG is consumed. Inputs/state unchanged; owning detached IDs. Read-only thread-safe calls. Work O(B*bottom_tokens*K), storage O(B*(top_tokens+bottom_tokens)).

    Parameters
    top

    Valid nonempty Int32[B,top_tokens] coarse codes, accepting strides.

    uniforms

    Explicit finite Float64[B,bottom_tokens] values in[0,1).

    Returns

    Owning detached Int32[B,bottom_tokens] fine IDs.

    Throws
    std::invalid_argument

    For malformed grids, dtype, invalid symbols or uniform values.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
auto top=n::zeros({1,1},n::DType::Int32);
n::models::Vq2ConditionalPrior prior(top,n::zeros({1,4},n::DType::Int32),1,1,2);
const auto ids=prior.Sample(top,n::full({1,4},.9,n::DType::Float64));
// ids=[1,1,1,1]: first u exceeds.75, then unseen previous1 is uniform.

    Nll(), VqMarkovPrior::Sample()

    Nll

    #source
    double Nll(const Tensor & top, const Tensor & bottom) const

    Score paired coarse/fine grids in mean conditional nats per complete fine grid.

    Resets BOS per image, sums fine-token NLLs with aligned parents and divides by B only. This is conditional code-grid NLL, not image likelihood or per- token loss. Inputs/state unchanged; no gradients. Work/storage O(B*bottom_tokens).

    Parameters
    top

    Valid nonempty Int32[B,top_tokens] coarse codes.

    bottom

    Matching valid Int32[B,bottom_tokens] fine codes.

    Returns

    Mean natural-log conditional code NLL per image/grid.

    Throws
    std::invalid_argument

    For invalid paired geometry, dtypes or symbols.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
auto top=n::zeros({1,1},n::DType::Int32),bottom=n::zeros({1,4},n::DType::Int32);
n::models::Vq2ConditionalPrior prior(top,bottom,1,1,2);
const double nll=prior.Nll(top,bottom);
// -log(.75)-3*log(.875), approximately0.688276 nats/grid.
    See also

    Sample(), probabilities()
