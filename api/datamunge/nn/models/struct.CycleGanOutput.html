    CycleGanOutput

    struct CycleGanOutput
    #include <datamunge/nn/cycle_gan.hpp> source

    Own both translations/cycles/identities, four patch maps and all explicit CycleGAN terms.

    Nineteen flat Tensor fields retain storage/applicable graphs after parent or store collection. Unpaired domain row counts may differ. No optimizer, derivative capture, hidden stop/no-grad, mutable batch state or schedule.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore ab(6203),ba(6211),da(6217),db(6221);
auto out=n::models::CycleGan(ab,ba,da,db,n::zeros({2,28,28,1}),n::ones({3,28,28,1}));
// fake_b/cycle_a have2 rows; fake_a/cycle_b have3 rows. The batches are unpaired.
    References

    • Zhu et al. (2017), https://arxiv.org/abs/1703.10593 .
