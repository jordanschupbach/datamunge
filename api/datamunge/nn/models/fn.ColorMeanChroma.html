    function datamunge::nn::models

    ColorMeanChroma

    #include <datamunge/nn/colorization_data.hpp>
    #source
    std::array< double, 2 > ColorMeanChroma(const ColorData & fit)

    Compute the fitting-only normalized mean chroma as an independent oracle.

    Float64 tensor reduction;host array only presents two values. Reports should fit this trainable baseline with an explicit optimizer and use this as an oracle.

    Parameters
    fit

    Fitting chroma Float32[N,H,W,2],nonempty.

    Returns

    Double[2] means in normalized a/128,b/128 units.

    Throws
    std::invalid_argument

    For invalid shape,dtype,rows,range or nonfinite color values.

    Example
    namespace n = dm::nn;
const n::models::ColorData data{n::zeros({1, 1, 1, 1}), n::ones({1, 1, 1, 2}),
                                n::zeros({1, 1, 1, 3})};
const auto mean = n::models::ColorMeanChroma(data);
    References

    • Scikit-image v0.25.2 colorconv.py, https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/color/colorconv.py. sRGB matrices,transfer thresholds and D65/2degree white follow the source. This example performs Lab chroma regression,not Zhang classification.
