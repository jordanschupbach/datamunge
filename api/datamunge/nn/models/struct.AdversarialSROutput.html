    AdversarialSROutput

    struct AdversarialSROutput
    #include <datamunge/nn/adversarial_super_resolution.hpp> source

    Own both SR generator paths, raw scores, feature/loss boundaries and detached BN captures.

    Twenty flat fields retain storage/applicable graphs beyond parent/store collection. prediction/residual use saved-statistic inference; prediction_training and all objectives use batch-statistic G. Target feature extraction stops before ReLU/scaling. moments_mean/unbiased_variance[5,4] are detached on SRGAN path, undefined for ESRGAN; row order matches AdversarialSRGenerated. No captured partials, optimizer state, fitting, EMA write or mutable callback is retained.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;n::ParameterStore g(7001),d(7013),s(0);
auto
o=n::models::AdversarialSR(g,d,s,n::zeros({2,16,16,3}),n::zeros({2,32,32,3}),n::zeros({2,32,32,3}),n::zeros({3,3,3,64}),n::zeros({64}));
// Source-sized zero-feature fixture; actual report loads1792 official frozen values.
    References

    • Ledig et al.(2017), Photo-Realistic Single Image Super-Resolution Using a Generative Adversarial Network, https://arxiv.org/abs/1609.04802 ; Wang et al.(2018), ESRGAN: Enhanced Super-Resolution Generative Adversarial Networks, https://arxiv.org/abs/1809.00219 . Fixed-width x2 teaching adaptations with a bicubic image shortcut, not pretrained benchmark models.
