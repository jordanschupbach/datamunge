    PafMetrics

    struct PafMetrics
    #include <datamunge/nn/paf_decode.hpp> source

    Own custom grouped annotated-joint counts and tensor-derived precision/recall.

    Counts are discrete matching metadata. Derived neck1 is excluded. These diagnostics are custom greedy.2-box matching,not COCO OKS/AP.

    Throws
    std::invalid_argument

    For invalid field geometry,nonfinite candidates,indices or decoder configuration.

    Example
    namespace n = dm::nn;
namespace m = n::models;
const m::PafMetrics score{};
    References

    • Cao,Simon,Wei and Sheikh(2017),Realtime Multi-Person2D Pose Estimation using Part Affinity Fields, https://arxiv.org/abs/1611.08050. Source teaching decoder uses local3x3 NMS,ten clamped bilinear samples,distance prior,stable greedy limb matching and conflict-safe person assembly. Custom grouped.2-box diagnostics exclude derived neck and are not COCO AP.

    See also

    PafPeaks(), MatchPafPeaks(), AssemblePafPeople(), DecodePafs()
