    function datamunge::nn::models

    SplitStarDomains

    #include <datamunge/nn/star_domains.hpp>
    #source
    StarDomains SplitStarDomains(
    const Tensor & images,
    const Tensor & labels,
    const Tensor & source_ids,
    std::int64_t per_class = 30)

    Select disjoint original/inverted/rotated domains by each class occurrence order.

    Finite unit Float32/64 CPU images[N,28,28,1], N>0 divisible by10; Int32/64 CPU labels[N] in0..9 exactly balanced N/10 each; aligned Int32/64 nonnegative unique source_ids[N]. per_class positive and at most floor(N/30). Take first per_class observations of each class for domain0, next per_class for1, next for2; retain remaining IDs explicitly as unused. All selected and unused IDs preserve original global order/dtype. Domain/digit outputs are Int32. Default per_class30 selects900 fitting rows from1000; use6 for180/200 held-out. All original selected pixels are retained exactly before native transformation. No random pairing or per-label sort; labels only partition data/diagnostics. Does not certify official source provenance, pixel uniqueness or cross-pool independence: checked LoadSaliency supplies those checks. Validates metadata, balance and unit pixels before gathers. No RNG, fitting, parameters or optimizer. Inputs unchanged; owning fields keep applicable image paths. O(N) host metadata and O(Nselected*784) native image work/storage; synchronize external mutation.

    Parameters
    images

    Finite unit floating CPU[N,28,28,1], N positive/divisible by10.

    labels

    Aligned integer CPU[N] class IDs0..9, exactly balanced.

    source_ids

    Aligned integer CPU[N] nonnegative unique original identities.

    per_class

    Positive selected rows per class per domain, default30; explicit6 for held-out.

    Returns

    Owning StarDomains with selected images/originals, domain/digit/source and unused IDs.

    Throws
    std::invalid_argument

    For invalid geometry, dtype, values, domain IDs or alignment.

    std::logic_error

    For non-CPU storage.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
auto labels=n::cast(n::arange(0,40,1,n::DType::Float64)/4.,n::DType::Int64);
auto
p=n::models::SplitStarDomains(n::zeros({40,28,28,1}),labels,n::arange(100,140,1,n::DType::Int64),1);
// 30 selected rows and10 explicitly unused IDs; first domains are0,1,2.
    References

    • Choi,Choi,Kim,Ha,Kim and Choo (2018), StarGAN: Unified Generative Adversarial Networks for Multi-Domain Image-to-Image Translation, https://arxiv.org/abs/1711.09020 . Compact teaching domains/maps differ from the paper architecture.
