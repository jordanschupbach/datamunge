    BigGan

    #include <datamunge/nn/big_gan.hpp>
    #source
    BigGanOutput BigGan(
    ParameterStore & generator,
    ParameterStore & discriminator,
    ParameterStore & generator_spectral,
    ParameterStore & discriminator_spectral,
    ParameterStore & moving,
    const Tensor & image,
    const Tensor & noise,
    const Tensor & labels,
    bool display_batch_statistics = false)

    Evaluate both compact hierarchical GAN paths and explicit hinge-plus-orthogonal objectives.

    Calls G inference then G batch capture, D real then training-fake then inference-fake, HingeGanObjectives on real/training-fake, and ModifiedOrthogonalPenalty on raw G. display_batch_statistics selects only fake/fake_score convenience endpoints; all losses and moments ALWAYS come from the batch-statistics generator path, even when the displayed image uses saved BN statistics. This preserves the source evaluation convention; use the explicit path names when reporting. Defaults create G789/17 leaves,D241/9,G-SN241/18,D-SN77/10,BN24/6: 1030 optimized values,342 state values,60 tensors in five distinct stores.

    Matching Float32/64 CPU stores, finite signed image[N,8,8,1]/noise[N,12], positive matching N and Int32/64 labels[N] in[0,10) required. Strides and applicable first/higher continuous paths remain live; class labels are discrete, spectral columns/saved BN stop. No noise draw beyond missing leaves, spectral advance, moment commit, optimizer, fitting, freeze or checkpoint is hidden. Caller initializes, explicitly warms each spectral store16 times, then each batch advances D spectral state, writes D, advances G spectral state, recomputes through updated D, captures G moments, writes G and commits those captured moments. D phases freeze every G state; G phases freeze every D state. Input checks precede leaves; incompatible/nonfinite leaves may fail later. Inputs unchanged, outputs own lifetime. O(N) fixed-architecture work/storage, plus validation and raw-kernel Gram matrices. Synchronize shared stores; exclude all three state stores from Adam. Approximate SN is not a norm certificate.

    Parameters
    generator

    Mutable floating G weight owner.

    discriminator

    Distinct matching D weight owner.

    generator_spectral

    Third distinct matching G spectral-column owner.

    discriminator_spectral

    Fourth distinct matching D spectral-column owner.

    moving

    Fifth distinct matching G BN saved-moment owner.

    image

    Finite signed matching floating CPU[N,8,8,1], N>0.

    noise

    Finite signed matching floating CPU[N,12], same N as image.

    labels

    Int32/64 CPU[N] classes in[0,10), supplied to both networks.

    display_batch_statistics

    Select batch fake convenience fields when true; inference display when false(default).

    Returns

    Owning BigGanOutput with both paths, explicit losses and live captured moments.

    Throws
    std::invalid_argument

    For invalid inputs/stores/products/labels, incompatible leaves or nonfinite computation.

    std::logic_error

    For non-CPU storage.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore g(6803),d(6823),gs(0),ds(0),moving(0);
auto x=n::zeros({2,8,8,1}),z=n::zeros({2,12}),c=n::zeros({2},n::DType::Int32);
n::models::BigGan(g,d,gs,ds,moving,x,z,c);n::advance_cached_spectral_state(g,gs,16);n::advance_cached_spectral_state(d,ds,16);
auto out=n::models::BigGan(g,d,gs,ds,moving,x,z,c,true);
auto derivative=n::grad(out.g_loss,g.parameters());
// After the selected G optimizer write, commit out.moments; no write was hidden here.
