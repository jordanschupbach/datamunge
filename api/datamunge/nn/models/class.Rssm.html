    Rssm

    class Rssm
    #include <datamunge/nn/rssm.hpp> source

    Borrow a ParameterStore to build the source LSTM recurrent state-space model.

    The store must outlive this object and every graph that uses its leaves. Copies share the borrowed store; Tensor copies share native storage. Missing named parameters initialize lazily in exact source call order; existing leaves are reused. Graph methods may create parameters despite const qualification. All matrices are nonempty Float32 CPU tensors; value finiteness follows primitive operations. No optimizer, objective, random engine, environment collection or fitting/planning loop is owned.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
n::ParameterStore p(0);n::models::Rssm model(p,{});auto state=model.Zero(2);
    References

    • Hafner et al. (2019), PlaNet, https://arxiv.org/abs/1811.04551; Hafner et al. (2020), Dreamer, https://arxiv.org/abs/1912.01603 .

    Kl

    #source
    Tensor Kl(const RssmGauss & q, const RssmGauss & p) const

    Compute source rowwise diagonal-Gaussian KL(q||p).

    Uses exp(2*(q.log_std-p.log_std)) and squared standardized mean displacement in source order. Primitive first/higher derivatives are retained; callers apply free-nats/reduction/objective weights.

    Parameters
    q

    Float32 CPU mean/log-std[B,stoch].

    p

    Same-shape Float32 CPU prior mean/log-std.

    Returns

    Live KL[B], not clamped by free_nats.

    Throws
    std::invalid_argument

    Nonfinite values, incompatible geometry or explicit bounds are invalid.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
n::ParameterStore p(0);n::models::Rssm model(p,{});auto g=model.Prior(n::zeros({2,64}));auto
kl=model.Kl(g,g);

    Observe

    #source
    Unrolled Observe(
    const RssmState & start,
    const std::vector< Tensor > & obs_t,
    const std::vector< Tensor > & act_t,
    const std::vector< Tensor > & eps_t) const

    Build a live source posterior/filtering sequence graph from an explicit start state.

    Lists and batches validate before parameter creation. Empty aligned lists yield empty outputs. At t0 the supplied deterministic h/c is used; for t>0 transition uses action[t-1]. The final action is therefore unused, as in source. Prior precedes posterior; source lazy-initialization order is retained. This is model graph unrolling, without environment steps, target loss or optimizer updates.

    Parameters
    start

    Valid Float32 CPU h/c/z start state.

    obs_t

    T Float32 CPU[B,obs_dim] tensors, T at most1million.

    act_t

    T Float32 CPU[B,act_dim] tensors; action t is taken after observation t.

    eps_t

    T Float32 CPU[B,stoch] caller noise tensors.

    Returns

    Live per-step posterior states, KL, reconstructed observations and rewards.

    Throws
    std::invalid_argument

    Nonfinite values, incompatible geometry or explicit bounds are invalid.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
n::ParameterStore p(0);n::models::Rssm model(p,{});auto
path=model.Observe(model.Zero(2),{n::zeros({2,3})},{n::zeros({2,1})},{n::zeros({2,16})});
    References

    • Hafner et al. (2019), PlaNet, https://arxiv.org/abs/1811.04551; Hafner et al. (2020), Dreamer, https://arxiv.org/abs/1912.01603 .
