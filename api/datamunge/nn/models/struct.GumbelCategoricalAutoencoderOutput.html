    GumbelCategoricalAutoencoderOutput

    struct GumbelCategoricalAutoencoderOutput
    #include <datamunge/nn/gumbel_categorical_autoencoder.hpp> source

    Own categorical posterior, soft/hard sample, decoder and objective endpoints.

    All fields own lifetime. Floating paths retain mathematical gradients; discrete indices/hard codes carry no logits/noise derivative. No straight-through path.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore p(2903);
const auto out=n::models::GumbelCategoricalAutoencoder(
    p,n::zeros({2,784}),n::zeros({2,4,8}));
// Eight parameter leaves/53104 scalars; code is [2,32].
