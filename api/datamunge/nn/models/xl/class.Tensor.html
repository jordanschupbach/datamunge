    Tensor

    class Tensor
    #include <datamunge/nn/tensor.hpp> source

    A typed N-d array with explicit device storage and reverse-mode autograd history. Native storage, views, packing, fill and explicit transfers support CPU/CUDA/Vulkan. Host element access and numerical operations without GPU kernels throw for GPU tensors. Transfer to an explicit CPU context before reading host values.

    Example
    const auto x=dm::nn::zeros({2,3});
std::print("{}\n",x.numel()); // 6
    See also

    to(), device(), compute::Context Copies alias the same implementation. Metadata and data access on an undefined tensor throw std::logic_error unless a method explicitly accepts that state.

    item

    #source
    template<typename T = double>
T item() const

    Copies one tensor value to a host value using the destination numeric type.

    Any rank is allowed when there is exactly one element. Int64 storage is converted directly, preserving every bit when T is Int64; it does not pass through double. Other conversions use ordinary static_cast semantics, so callers must choose a destination that can represent the stored value. This reads storage without changing the tensor or recording a gradient.

    Template parameters
    T

    Destination numeric type, default double.

    Returns

    An owning host value converted to T.

    Throws
    std::invalid_argument

    If the tensor does not contain exactly one value.

    std::logic_error

    If this tensor is undefined or has GPU storage; transfer to CPU first.

    Example
    const auto value = dm::nn::from_vector(std::vector<std::int64_t>{9007199254740993LL});
const auto id = value.item<std::int64_t>(); // 9007199254740993, exactly.

    to_vector

    #source
    template<typename T>
std::vector< T > to_vector() const

    Copies all logical tensor elements to an owning row-major host vector.

    Strided views are packed in logical order before conversion; empty tensors return an empty vector. Int64 elements convert directly without an intermediate double, preserving exact Int64 source IDs across the full signed range. Other numeric conversions use static_cast; the destination must represent the requested values. This does not mutate source storage.

    Template parameters
    T

    Arithmetic destination element type.

    Returns

    An independent vector of converted values in logical row-major order.

    Throws
    std::logic_error

    If this tensor is undefined or has GPU storage; transfer to CPU first.

    Example
    const auto values = dm::nn::from_vector(
    std::vector<std::int64_t>{9007199254740993LL, 2, 3, -9007199254740993LL}, {2, 2});
const auto copy = values.transpose().to_vector<std::int64_t>();
// {9007199254740993, 3, 2, -9007199254740993}, all exact.

    to

    #source
    Tensor to(const compute::Context & context) const

    Copy logical values to packed storage in an explicit context, preserving dtype. Always allocates an independent copy. This is a synchronous transfer boundary; cross-context GPU transfers stage bytes through host memory. GPU views are packed on their device. Floating transfers record an identity backward that returns gradients to the source context. Unsupported numerical GPU operations still throw; transfer support does not imply model/backend parity.

    Parameters
    context

    Destination owner, retained by the result.

    Returns

    Independent contiguous tensor with the same shape and dtype.

    Throws
    std::logic_error

    Undefined tensor.

    std::length_error

    GPU byte range exceeded.

    std::runtime_error

    Native allocation, packing or transfer failed.

    Example
    const dm::compute::Context cpu;
const auto original=dm::nn::from_vector(std::vector<float>{1,2});
const auto copy=original.to(cpu);
std::print("{}\n",copy.numel()); // 2
