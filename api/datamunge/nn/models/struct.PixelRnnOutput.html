    PixelRnnOutput

    struct PixelRnnOutput
    #include <datamunge/nn/recurrent_pixels.hpp> source

    Own the zero-state paths, gate projections and full Row-LSTM image sequence.

    Seven flat Tensor handles retain applicable graphs/storage after parent or store collection. initial_hidden and initial_cell share the same first-row input feature times zero, preserving the source's connected zero path and signed-zero arithmetic. They are not learned states. The remaining fields concatenate real row outputs along the image-height axis. No optimizer, model object, moving statistics or sampling stream is retained.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;n::ParameterStore p(8303);
auto out=n::models::PixelRnn(p,n::zeros({2,8,8,1}));
// logits[2,8,8,1], hidden/cell[2,8,8,4], input/row gates[2,8,8,16].
    References

    • van den Oord, Kalchbrenner and Kavukcuoglu(2016), Pixel Recurrent Neural Networks, https://arxiv.org/abs/1601.06759 . One-layer width4 teaching variant.
