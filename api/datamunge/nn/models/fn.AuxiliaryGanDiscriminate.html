    AuxiliaryGanDiscriminate

    #include <datamunge/nn/auxiliary_classifier_gan.hpp>
    #source
    AuxiliaryDiscriminator AuxiliaryGanDiscriminate(
    ParameterStore & discriminator,
    const Tensor & image,
    std::int64_t features = 784,
    std::int64_t classes = 10,
    std::int64_t hidden = 32)

    Predict real/fake source and auxiliary classes from images alone.

    Dense hidden tanh H feeds class logits C and a raw source logit. Creates hidden/W,b, class/W,b, source/W,b in that order: the class head precedes the source head in the initialization stream. Defaults create six leaves/25483 values. Images are finite signed Float32/64 CPU [N,F], matching store dtype; strides and all continuous first/higher paths are retained. No class condition, target, noise, sigmoid source probability, loss, RNG draw beyond missing-leaf creation, fitting or update is hidden. Inputs remain unchanged; outputs own lifetime. Invalid inputs fail before leaves; incompatible existing leaves or nonfinite computation may fail later. Work O(N*H*(F+C+1)), activation storage O(N*(H+C+1)); synchronize callers sharing a mutable store.

    Parameters
    discriminator

    Caller-owned floating store, mutated only for missing leaves.

    image

    Finite signed CPU matrix [N,features], N>0, matching store dtype.

    features

    Positive image width F, default 784.

    classes

    Positive auxiliary class count C, default 10.

    hidden

    Positive tanh hidden width H, default 32.

    Returns

    Owning source logits, class logits and softmax class probabilities.

    Throws
    std::invalid_argument

    For invalid widths/products, inputs, stored leaves or computed nonfinite values.

    std::logic_error

    For non-CPU storage.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore d(5219,n::DType::Float64);
const auto
out=n::models::AuxiliaryGanDiscriminate(d,n::full({2,3},-.2,n::DType::Float64),3,2,4);
// No labels enter D; out.class_probability has two columns.
    References

    • Odena, Olah and Shlens (2017), Conditional Image Synthesis with Auxiliary Classifier GANs, https://arxiv.org/abs/1610.09585 . This compact dense teaching discriminator differs from the paper's convolutional architecture.
