    CachedTransformerLM

    class CachedTransformerLM
    #include <datamunge/nn/decoder_cache.hpp> source

    Own initialized source decoder parameters and validate explicit caller K/V appends.

    The store uses source seed9001 and creates all named leaves at construction. Copies are disabled by ParameterStore ownership. Calls require synchronization against store/config mutation. Config and store are exposed for original checkpoint workflows; keep geometry fixed after construction. Cache state and token-history loops remain caller-owned. Returned inference endpoints have no training graph.

    Example
    dm::nn::models::CachedTransformerLM model;auto state=model.Empty(1);
auto output=model.Append(dm::nn::from_vector(std::vector<int>{0},{1,1}),state);

    Projects only the new tokens, attends to the cached prefix plus the chunk (causally), and replaces state with the grown keys/values.

    Project new tokens, causally attend to retained keys and replace cache endpoints.

    Checks before inference; no parameter creation occurs after construction with unchanged geometry. Old tensor aliases retain old storage. No gradient recording is enabled.

    Advance

    #source
    std::map< std::string, Tensor > Advance(
    const std::vector< int > & history,
    KvState & state,
    bool * rebuilt = nullptr)

    Absolute positions reset when the last-context window slides: old K/V at shifted positions are invalid, so rebuild rather than evict one entry.

    Append the final history token or rebuild the last absolute-position context.

    Absolute positions reset when the window slides; existing keys at shifted positions are discarded. This is one history transition, not a generation loop. No random draws occur.

    Parameters
    history

    Nonempty caller-owned chronological token history, length fitting int.

    state

    Caller cache endpoints, replaced after successful inference.

    rebuilt

    Optional borrowed flag, default nullptr; written before inference.

    Returns

    Inference fields from appending one token or rebuilding the retained context window.

    Throws
    std::invalid_argument

    Empty history, incompatible state or append geometry.

    Example
    dm::nn::models::CachedTransformerLM model;auto state=model.Empty(1);auto
output=model.Advance({0,1},state);
