    StyleGanSynthesize

    #include <datamunge/nn/style_gan.hpp>
    #source
    StyleGanSynthesis StyleGanSynthesize(
    ParameterStore & generator,
    const Tensor & w0,
    const Tensor & w1,
    const Tensor & noise4,
    const Tensor & noise8,
    bool version2 = false,
    const Tensor & first_style_override = Tensor())

    Synthesize8x8 pixels from per-layer W styles and caller-supplied spatial noise only.

    Finite signed matching Float32/64 CPU w0/w1[N,8], noise4[N,4,4,1],noise8 [N,8,8,1], positive aligned N, strides allowed. Learn constant[1,4,4,4] normal .02, tile N, styled3x3 layer4, nearest up2, styled3x3 layer8,1x1 RGB sigmoid. AdaIN(default): plain normal conv, raw dense(w,8), zero noise strengths/bias, leaky((conv+noise*strength)+bias,.2), population spatial normalization, then affine(1+scale_delta,shift). RGB is biased normal plain1x1. Version2: learned dense(w,4)+1 gains, per-example modulated/demodulated feature kernels, same explicit noisy/leaky grouping, no AdaIN; RGB is modulated without demodulation using w1, then bias/sigmoid. Source guards are double(1e-8f); taps accumulate row-major batched matmuls. All normal kernels.02, affine styles native Glorot.

    Call StyleGanMap first for original full-G initialization order. Synthesis alone creates517/13(AdaIN) or481/15(version2) values/leaves; mapping adds144/4 for source totals661/17 or625/19. Existing leaves unchanged. Never retain a variant flag; using incompatible variant leaves raises an error. Optional first_style_override[N,4] is version2 only: replaces first actual gains while still creating/computing its unused affine parameters, as the original control. All nine fields own applicable first/higher W/noise/weight graphs. No hidden no-grad, random noise, truncation, moving W average, fitting or optimizer write. Inputs unchanged. Validate all supplied geometry before leaves; stored-leaf/ math failures may follow initialization. O(N) fixed-map work/storage; synchronize.

    Parameters
    generator

    Caller-owned matching floating G store, source seed6607.

    w0

    First layer mapped styles[N,8], independent from w1 for mixing.

    w1

    Second layer and version2 RGB mapped styles[N,8].

    noise4

    Explicit finite signed matching spatial noise[N,4,4,1].

    noise8

    Explicit finite signed matching spatial noise[N,8,8,1].

    version2

    True selects weight modulation/demodulation; false(default) selects AdaIN.

    first_style_override

    Optional matching first-layer channel gains[N,4] for version2; undefined(default) uses affine(w0)+1.

    Returns

    Owning StyleGanSynthesis with live image/boundary/style/demodulator fields.

    Throws
    std::invalid_argument

    For invalid inputs/products/variant/override/leaves or nonfinite computation.

    std::logic_error

    For non-CPU storage.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;n::ParameterStore g(6607);
auto w=n::models::StyleGanMap(g,n::ones({1,8}));
auto o=n::models::StyleGanSynthesize(g,w,w,n::zeros({1,4,4,1}),n::zeros({1,8,8,1}));
// First/second AdaIN styles are[1,8],demodulators scalar1; source G has661 values.
    References

    • Karras et al. (2018/2019), https://arxiv.org/abs/1812.04948 ; Karras et al. (2019/2020), https://arxiv.org/abs/1912.04958 . Compact two-layer teaching variants, without progressive growth, path-length regularization or EMA.
