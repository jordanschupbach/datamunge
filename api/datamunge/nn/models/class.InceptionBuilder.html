    InceptionBuilder

    class InceptionBuilder
    #include <datamunge/nn/inception_models.hpp> source

    Compose reference Inception branches while tracking widths and stage names.

    Borrows p, state, out and cfg; all must outlive the builder, so do not pass a temporary cfg. Width scaling applies only to learned convolution outputs. The two stores must be distinct and have the input floating dtype. Calls create/reuse leaves and optionally update BN state; they never fit parameters. A shared builder/stores are not safe for concurrent mutation.

    Example
    namespace n = dm::nn;
n::models::Inception23Config cfg;
cfg.image_size = 107;
cfg.classes = 3;
cfg.width_divisor = 8;
n::ParameterStore p(17), state(17);
n::models::Inception23Outputs out;
n::models::InceptionBuilder b(p, state, out, cfg, false);
const n::models::ConvFeature x{n::ones({1, 7, 7, 8}), 8};
const auto y = b.Conv("c", x, 32, 1, 3);
    References

    • Ioffe and Szegedy (2015), https://arxiv.org/abs/1502.03167; Szegedy et al. (2016), https://arxiv.org/abs/1512.00567; TF-Slim reference definitions, https://github.com/tensorflow/models/tree/master/research/slim/nets

    Borrow stores, output recorder and validated layer configuration.

    Initializes beta-only BN with epsilon .001 and cfg.momentum; no fitting.

    Parameters

    Mutable learnable parameter store.

    state

    Separate mutable BN moving-statistic store.

    out

    Mutable ordered stage recorder.

    cfg

    Configuration borrowed by reference; must outlive this builder.

    training

    Use batch moments and eager moving-state updates when true.

    Throws
    std::invalid_argument

    If cfg.Validate rejects a setting.

    int channels,
    int h = 1,
    int w = 1,

    Apply a width-scaled rectangular convolution, beta-only BN and ReLU.

    Uses the builder BN training mode and eager state updates; no fitting.

    Parameters
    name

    Prefix for named layer leaves; repeated names reuse matching store entries.

    x

    Initialized NHWC feature with matching positive channel metadata.

    channels

    Positive reference output width, exactly divisible by cfg.width_divisor.

    h

    Positive kernel height, default one.

    w

    Positive kernel width, default one.

    stride

    Positive common stride, default one.

    padding

    SAME (default) or VALID, case-sensitive.

    Returns

    Feature preserving its graph, with channels/cfg.width_divisor outputs.

    Throws
    std::invalid_argument

    For inexact/invalid widths or invalid convolution, BN, tensor or store settings.

    Example

    V2Module

    #source
    ConvFeature V2Module(
    const std::string & name,
    const ConvFeature & x,
    const std::array< int, 7 > & w,
    bool max_pool = false)

    Apply BN-Inception branches with one, three and two stacked 3x3 filters.

    Four SAME branches concatenate; the double-3x3 path adds a second BN/ReLU. All learned output widths are divided exactly; spatial size is retained.

    Parameters
    name

    Prefix for named layer leaves; repeated names reuse matching store entries.

    x

    Initialized NHWC feature with matching positive channel metadata.

    w

    Seven reference widths: one, three_reduce, three, double_reduce, double1, double2, pool.

    max_pool

    Choose max-pool on the projected pooling branch when true; average by default.

    Returns

    Width-scaled NHWC feature, also appended to the stage recorder.

    Throws
    std::invalid_argument

    For invalid widths, geometry, tensor/store settings or incompatible branches.

    Example
    namespace n = dm::nn;
n::models::Inception23Config cfg;
cfg.image_size = 107;
cfg.classes = 3;
cfg.width_divisor = 8;
n::ParameterStore p(17), state(17);
n::models::Inception23Outputs out;
n::models::InceptionBuilder b(p, state, out, cfg, false);
const n::models::ConvFeature x{n::ones({1, 7, 7, 8}), 8};
const auto y = b.V2Module("m", x, {64, 64, 64, 64, 96, 96, 32});
