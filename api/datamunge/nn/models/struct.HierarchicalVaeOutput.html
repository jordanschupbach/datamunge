    HierarchicalVaeOutput

    struct HierarchicalVaeOutput
    #include <datamunge/nn/hierarchical_variational_autoencoder.hpp> source

    Own all nineteen spatial/posterior/prior/reconstruction/objective hierarchy endpoints.

    Fields own lifetime and retain continuous paths. Neither greedy posterior means nor decoded greedy means generally equal posterior predictive means.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore p(2609),state(0);
const auto out=n::models::HierarchicalVariationalAutoencoder(
    p,state,n::zeros({2,784}),n::zeros({2,51}),true);
// Default NVAE:37 trainable tensors/2027 scalars plus six BN moving buffers.
