    LadderPriorOutput

    struct LadderPriorOutput
    #include <datamunge/nn/ladder_variational_autoencoder.hpp> source

    Own all six explicit ancestral Ladder endpoints without an image or inference state.

    Every field owns lifetime and retains applicable continuous gradients. No random draws, optimizer or encoder are hidden. Only lower_z enters decoding; top_z affects decoding through the conditional prior and lower sample.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore p(2503);
const auto prior=n::models::LadderPrior(p,n::zeros({2,2}),n::zeros({2,4}));
// Zero lower noise makes lower_z exactly prior_mu; probabilities are[2,784].
    See also

    LadderPrior(), GaussianVaeDecode(), LadderVariationalAutoencoder()
