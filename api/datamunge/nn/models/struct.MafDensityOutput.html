    MafDensityOutput

    struct MafDensityOutput
    #include <datamunge/nn/maf_density.hpp> source

    Own all compact MAF conditioner inputs, autoregressive stages and density intermediates.

    Twenty-three flat Tensor handles retain applicable first/higher graphs and storage after parent/store collection. No vector/nested record ownership, fitting workflow, optimizer or sampler. Scale fields mean bounded log scales; each stage's conditioner sees that stage's recorded input in parallel.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;n::ParameterStore p(9603);
auto out=n::models::MafDensity(p,n::zeros({2,2}));
// latent/unscaled/conditioner_input0..3/coupling0..3/scale/shift[2,2]; logdets[2].
    References

    • Papamakarios et al.(2017), MAF, https://arxiv.org/abs/1705.07057 .

    See also
