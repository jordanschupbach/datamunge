    VqMarkovPrior

    class VqMarkovPrior
    #include <datamunge/nn/vector_quantized_autoencoder.hpp> source

    Fit a smoothed first-order raster Markov prior to caller-supplied discrete grids.

    Each input row begins with BOS=K; counts[previous,current] include K ordinary contexts plus BOS. p=(count+smoothing)/(context_total+K*smoothing), with default K16/half-count0.5. There is no EOS or cross-row transition. This cheap separate code prior is not the paper's learned PixelCNN or an image likelihood. The caller supplies ONLY fitting codes and chooses model/checkpoint separately; this class cannot check split provenance. Construction copies all counts and probabilities; the input may be destroyed. Exports return independent tensors. Read-only scoring/sampling is thread-safe, no shared RNG or network updates. Work O(B*T+K*K), storage O(B*T+K*K); sampling takes explicit Float64 uniforms.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::models::VqMarkovPrior prior(n::from_vector(std::vector<int>{0,1,1,0},{2,2}),2);
const auto ids=prior.Sample(n::full({1,3},.25,n::DType::Float64));
// An explicit-uniform three-symbol sample; prior never reads images or updates a model.
    References

    • van den Oord et al. (2017), https://arxiv.org/abs/1711.00937 , motivates a separately fitted prior. This first-order half-count baseline is a compact repository variant, not the paper's neural autoregressive prior.

    Sample

    #source
    Tensor Sample(const Tensor & uniforms) const

    Sample raster codes from explicit uniforms without any RNG or image input.

    Uniforms must be finite Float64[B,T] in[0,1), B,T>0. Each row resets BOS; choose the first cumulative probability strictly greater than u, matching source inverse-CDF ties. Final-code fallback absorbs floating row-sum error. Codes own lifetime and have no gradient; input unchanged, state unchanged. Work O(B*T*K), storage O(B*T), safe for concurrent read-only calls.

    Parameters
    uniforms

    Explicit nonempty Float64[B,T] values in[0,1), accepting strides.

    Returns

    Owning Int32[B,T] sampled IDs; no random state is consumed.

    Throws
    std::invalid_argument

    For malformed shape/dtype or invalid uniform values.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::models::VqMarkovPrior prior(n::zeros({1,2},n::DType::Int32),2);
const auto ids=prior.Sample(n::full({1,2},.75,n::DType::Float64));
// ids=[1,1]: u at a cumulative boundary selects the NEXT interval.

    Nll

    #source
    double Nll(const Tensor & grid) const

    Score valid code grids in mean natural-log nats per complete row.

    Resets BOS per image and sums all token NLLs, then divides by B only. Grid token count may differ from fitting. State/input unchanged; no autograd. Work/storage O(B*T) for validated symbols; concurrent read-only calls are safe.

    Parameters
    grid

    Nonempty valid Int32[B,T] code grid, accepting strides.

    Returns

    Mean nats per grid, not per token, image log likelihood or a codec bitrate.

    Throws
    std::invalid_argument

    For invalid grid/dtype/symbols.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::models::VqMarkovPrior prior(n::zeros({1,2},n::DType::Int32),2);
const double nll=prior.Nll(n::zeros({1,2},n::DType::Int32));
// nll=-2*log(.75), approximately0.575364 nats/grid.
    See also

    Sample(), probabilities()
