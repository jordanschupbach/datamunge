    RevNetConfig

    struct RevNetConfig
    #include <datamunge/nn/reversible_residual_models.hpp> source

    Stage layout and preactivation options for released reversible residual networks.

    Default CIFAR-110 has 9 units per stage and basic coupling functions. Configuration is value metadata without model allocation or fitting.

    Example
    const auto cfg = dm::nn::models::RevNetConfig::Cifar(38);
const auto widths = cfg.Widths();
    References

    • Gomez et al. (2017), https://arxiv.org/abs/1707.04585; https://github.com/renmengye/revnet-public/blob/master/resnet/models/revnet_model.py

    Cifar

    #source
    static RevNetConfig Cifar(int depth, int classes = 10)

    Construct a released CIFAR RevNet-38, 110 or 164 preset.

    Depth 38 uses 3/3/3 units and stage widths 32/64/112. Depths 110/164 use 9/9/9 units and filter widths 32/64/128, expanded for 164.

    Parameters
    depth

    Exactly 38, 110 or 164; 164 selects bottleneck functions.

    classes

    Output class count, default ten; Widths() validates at least two.

    Returns

    Independent preset metadata; no parameters allocated.

    Throws
    std::invalid_argument

    For unsupported depth.

    Example
    const auto cfg = dm::nn::models::RevNetConfig::Cifar(38);
    References

    • Gomez et al. (2017), https://arxiv.org/abs/1707.04585; https://github.com/renmengye/revnet-public/blob/master/resnet/models/revnet_model.py

    ImageNet

    #source
    static RevNetConfig ImageNet(int depth)

    Construct a released ImageNet RevNet-56 or 104 bottleneck preset.

    Unit counts are 2/2/3/2 or 2/2/11/2. Inner stage widths 128/256/512/832 expand fourfold; entry strides are 1/2/2/2.

    Parameters
    depth

    Exactly 56 or 104.

    Returns

    Metadata with 1000 classes, four stages and a 128-channel stem.

    Throws
    std::invalid_argument

    For unsupported depth.

    Example
    const auto cfg = dm::nn::models::RevNetConfig::ImageNet(56);
    References

    • Gomez et al. (2017), https://arxiv.org/abs/1707.04585; https://github.com/renmengye/revnet-public/blob/master/resnet/models/revnet_model.py

    Widths

    #source
    std::vector< int > Widths() const

    Validate the full configuration and return stem/expanded stage widths.

    Requires at least one stage, matching vectors, positive unit counts, stride one/two, even nondecreasing widths and valid classes/momentum. Basic stage increases must be multiples of four for symmetric padding of both halves. Work/storage O(stages); does not mutate configuration or learned state.

    Returns

    Copy of filters with every post-stem entry multiplied by four for bottlenecks.

    Throws
    std::invalid_argument

    For invalid layout, widths, classes or momentum.

    Example
    const auto w = dm::nn::models::RevNetConfig::Cifar(38).Widths(); // {32,32,64,112}
