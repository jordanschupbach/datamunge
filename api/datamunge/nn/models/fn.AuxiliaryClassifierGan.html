    AuxiliaryClassifierGan

    #include <datamunge/nn/auxiliary_classifier_gan.hpp>
    #source
    AuxiliaryClassifierGanOutput AuxiliaryClassifierGan(
    ParameterStore & generator,
    ParameterStore & discriminator,
    const Tensor & image,
    const Tensor & noise,
    const Tensor & labels,
    std::int64_t features = 784,
    std::int64_t classes = 10,
    std::int64_t hidden = 32)

    Evaluate a conditional generator and image-only auxiliary discriminator with explicit losses.

    ConditionalGanGenerate() concatenates noise [N,Z] with one-hot labels [N,C], then uses hidden tanh H and output sigmoid F. AuxiliaryGanDiscriminate() sees only real or generated coordinates and predicts source plus class. Source objectives come from LogisticGanObjectives(); D minimizes source_D+(CE_real+ CE_fake), G minimizes source_G+CE_fake, with unit class weights. The supplied labels condition G and serve as CE targets; they never enter D's forward. Defaults with Z=16 create G four leaves/26736 and D six leaves/25483 values, in hidden/output and hidden/class/source order (each W then b), respectively.

    All mathematical paths remain live. Select only D parameters for D loss, then recompute through the updated D and select only G parameters for G loss. There is no hidden optimizer, alternating write, fit, noise draw except initial leaf creation, checkpoint, evaluation guard or O(N^2) MMD. Use GanCoarsePixels() and ImqMmd() explicitly for the separate source game diagnostic. Finite signed Float32/64 CPU image/noise matrices and two distinct matching-dtype stores are required; integer labels are discrete. Strides and higher continuous gradients are retained. All input/width checks precede any leaf creation; incompatible existing leaves or nonfinite computed states may fail later. Inputs unchanged, output fields own lifetime; synchronize shared stores. Work O(N*H*(Z+C+F)) plus the two O(N*H*(F+C)) discriminator branches; activation storage O(N*(Z+C+H+F)). No claim of convergence or image quality is implied.

    Parameters
    generator

    Mutable independent floating generator store.

    discriminator

    Mutable independent floating discriminator store, matching dtype.

    image

    Finite signed CPU real matrix [N,features], matching dtype.

    noise

    Finite signed CPU explicit noise [N,Z], N,Z>0, matching dtype.

    labels

    Int32/64 CPU [N] requested classes and real/fake CE targets, in [0,classes).

    features

    Positive image/output width F, default 784.

    classes

    Positive class count C, default 10.

    hidden

    Positive tanh hidden width H, default 32.

    Returns

    Owning fifteen-field record with live endpoints and separate scalar objectives.

    Throws
    std::invalid_argument

    For invalid inputs/geometry/products, aliased or mismatched stores, incompatible leaves or nonfinite computation.

    std::logic_error

    For non-CPU storage.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore g(5209),d(5219);
const auto
out=n::models::AuxiliaryClassifierGan(g,d,n::zeros({2,784}),n::zeros({2,16}),n::zeros({2},n::DType::Int32));
const auto dg=n::grad(out.discriminator_loss,d.parameters());
// Caller applies dg only to D, then recomputes before differentiating G loss.
    References

    • Odena, Olah and Shlens (2017), Conditional Image Synthesis with Auxiliary Classifier GANs, https://arxiv.org/abs/1610.09585 . This compact MLP teaching variant uses the non-saturating source G loss, not the paper's architecture.

    • Goodfellow et al. (2014), Generative Adversarial Networks, https://arxiv.org/abs/1406.2661 .
