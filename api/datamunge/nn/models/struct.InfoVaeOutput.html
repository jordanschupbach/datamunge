    InfoVaeOutput

    struct InfoVaeOutput
    #include <datamunge/nn/info_variational_autoencoder.hpp> source

    Own all sixteen Gaussian, decoder, MMD and objective endpoints of a compact InfoVAE.

    Every tensor owns lifetime and keeps autograd history. No optimizer, RNG or fitting state is stored. MMD matrices include within diagonals for inspection; only scalar within estimates exclude them. Negative unbiased MMD is retained.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::ParameterStore p(3901);
const auto out=n::models::InfoVariationalAutoencoder(p,n::full({2,784},.2),
    n::ones({2,4}),n::zeros({3,4}),1);
// MMD-VAE has zero local KL weight, but out.kl remains a diagnostic; xy is[2,3].
    See also

    InfoVariationalAutoencoder(), MmdOutput, InfoVaeObjective()
