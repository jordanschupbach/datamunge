    WaveStackCache

    class WaveStackCache
    #include <datamunge/nn/wavenet_generation.hpp> source

    Own fixed WaveStack weights and circular histories for one categorical code stream.

    Snapshot required finite Float32 CPU leaves from a warmed ParameterStore; later store writes/collection cannot affect this cache. Each block retains its OWN input at its dilation, not a raw-code history or another block's residual. Input uses previous/current code taps; the last residual projection is absent. Skip summation, ReLU/post/ReLU/head match WaveStack. One next(code) consumes one code and returns the logits for the following code. The source scalar Float32 multiply/add order and tanh(filter)/(1.f+exp(-gate)) arithmetic are retained; cached/full-convolution results may differ by roundoff.

    Fixed weights and mutable state own all storage. C++ copies and clone() fork independent streams at the current position. Output Tensors own detached storage and outlive the cache. No fitting, optimizer, RNG, categorical draw, codec, parameter writes or autograd path. Distinct caches are independent; callers synchronize access to one cache. Reset restores the true beginning with zero feature histories and no previous code, not code-zero padding. Memory is copied weights plus R*cycles*(2^levels-1) floats for rings. Per-code work is O(R*classes+blocks*(R^2+R*skip)+skip^2+skip*classes), independent of generated length; scratch is O(blocks*R+skip+classes). Failed invalid-code, count-limit or nonfinite-candidate steps preserve the previous state.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;namespace m=n::models;
m::WaveStackConfig c{4,8,5,1,256};n::ParameterStore p(541);
m::WaveStack(p,n::one_hot(n::zeros({1,2},n::DType::Int32),256),c);
m::WaveStackCache cache(p,c);auto logits=cache.next(128);
// Owning detached Float32[256]; cache.consumed()==1. Choose/feed the next code explicitly.
    References

    • van den Oord et al.(2016), WaveNet: A Generative Model for Raw Audio, https://arxiv.org/abs/1609.03499 . Circular block-input histories implement the repository's two-tap unconditional teaching stack, not conditioned TTS.

    WaveStackCache

    #source
    WaveStackCache(const ParameterStore & parameters, const WaveStackConfig & config)

    Snapshot the required Float32 leaves and initialize empty per-layer histories.

    Store/config must describe the already-warmed WaveStack architecture. Required keys are input, block1..L/gate, block1..L/skip, block1..L-1/residual, post and output, each /W and /b. W shape[1,kernel,in,out], b[out]; input/gate kernel2, others1. Unrelated store leaves are ignored. Strided CPU leaves are copied contiguously, preserving Float32 values; no leaf or RNG is created. Validate widths, levels1..12,cycles1..4,classes>=2 and representable2*R. Invalid construction publishes no partial object. Initial consumed()==0.

    Parameters
    parameters

    Read-only warmed Float32 store with all required finite CPU leaves.

    config

    Explicit matching WaveStackConfig, copied by value; no implicit architecture inference.

    Throws
    std::invalid_argument

    For invalid config, missing/misshaped/nonfinite/non-CPU or non-Float32 leaves.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;namespace m=n::models;
m::WaveStackConfig c{1,2,2,1,3};n::ParameterStore p(17);
m::WaveStack(p,n::one_hot(n::zeros({1,1},n::DType::Int32),3),c);
m::WaveStackCache cache(p,c); // Copies learned values; store and cache are independent.
    References

    • van den Oord et al.(2016), https://arxiv.org/abs/1609.03499 . Matches the canonical teaching WaveStack checkpoint names and two-tap architecture.

    next

    #source
    Tensor next(int code)

    Consume one observed/generated code and return detached scores for the next code.

    Valid code0..classes-1 and consumed()<INT64_MAX. Reads each layer's old input at timedilation, computes the current block and accumulates skips in source Float32 scalar order. No sampling or softmax: feed every prefix code, then choose a code from the returned head and feed it back explicitly. Candidate ring writes are committed only after a finite head/state and an owning output Tensor have been constructed. Input errors, overflow yielding nonfinite state/head and count-limit errors preserve all previous history. Outputs have no weight/input autograd connection, even when source leaves require gradients. Existing returned heads remain valid across next/reset.

    Parameters
    code

    Integer code in[0,classes); code128 is the source cold-start seed for256 classes.

    Returns

    Owning detached Float32 CPU[classes] logits predicting the following code.

    Throws
    std::invalid_argument

    For an out-of-range code or nonfinite candidate state/head.

    std::overflow_error

    When consumed() already equals INT64_MAX.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;namespace m=n::models;
m::WaveStackConfig c{1,2,2,1,3};n::ParameterStore p(17);
m::WaveStack(p,n::one_hot(n::zeros({1,1},n::DType::Int32),3),c);
m::WaveStackCache cache(p,c);auto first=cache.next(1);auto second=cache.next(2);
// first/second each own three logits; consumed()==2; no categorical sampling is hidden.
    References

    • van den Oord et al.(2016), https://arxiv.org/abs/1609.03499 . Per-layer own-input rings implement the source teaching stack's causal dilations.

    reset

    #source
    void reset() noexcept

    Clear every feature ring and previous-code tap without changing the weight snapshot.

    Restores consumed()==0 and the true beginning-of-stream state. Replaying the same codes reproduces the same heads; earlier output Tensors and clones remain unchanged. O(total ring floats), no allocation, fitting or RNG.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;namespace m=n::models;
m::WaveStackConfig c{1,2,1,1,3};n::ParameterStore p(17);
m::WaveStack(p,n::one_hot(n::zeros({1,1},n::DType::Int32),3),c);
m::WaveStackCache cache(p,c);auto a=cache.next(1);cache.reset();auto b=cache.next(1);
// dm::nn::equal_bits(a,b) is true; consumed()==1 after the replayed code.

    clone

    #source
    WaveStackCache clone() const

    Fork an independent weight snapshot and all current circular state by value.

    Equivalent to the native C++ value copy, including consumed count and previous code. The two caches can continue/reset independently without shared mutable storage. O(weight floats+ring floats) copy, no fitting/RNG.

    Returns

    Owning independent WaveStackCache at the same stream position.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;namespace m=n::models;
m::WaveStackConfig c{1,2,1,1,3};n::ParameterStore p(17);
m::WaveStack(p,n::one_hot(n::zeros({1,1},n::DType::Int32),3),c);
m::WaveStackCache a(p,c);a.next(1);auto b=a.clone();
auto x=a.next(2),y=b.next(2); // equal_bits(x,y); both consumed()==2.
