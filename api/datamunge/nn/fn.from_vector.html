    from_vector

    #include <datamunge/nn/tensor.hpp>
    #source
    template<typename T>
Tensor from_vector(const std::vector< T > & values, Shape shape = {})

    Copies values into a tensor of the matching dtype. An empty shape means a 1-D tensor of values.size() elements, so a one-element vector gives shape [1], not a 0-d scalar: use from_scalar / scalar, or .reshape({}), for a 0-d tensor.
