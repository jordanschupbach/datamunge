    class datamunge::nn

    Module

    class Module
    #include <datamunge/nn/model_plot.hpp> source

    Callable functional neural-network module with an architecture plot method.

    Wrap existing linear, deep, convolutional or other tensor forward functions. Owns the callback, not the stores referenced by it. Copies share the callback's captured state. Forward execution and any mutable stores require the caller's usual locking.

    Example
    namespace n = dm::nn;
n::ParameterStore p(17);
n::Module model([&](const auto &x) {
  return n::dense(p, "output", n::mlp(p, "hidden", x, {8, 4}), 2);
}, "Deep classifier");
model.plot(n::zeros({1, 3})).save_svg("deep.svg");

    plot

    #source
    ModelDiagram plot(const Tensor & example, ModelPlotOptions options = {}) const

    Plot this module using one forward pass on a cloned example input.

    Parameters
    example

    Floating example tensor, including batch size.

    options

    Rendering settings; the default title uses this module's name.

    Returns

    A diagram with save_svg() and to_svg(); no model graph retained.

    Throws
    std::invalid_argument

    As documented for plot_model(); callback errors propagate.

    Example
    dm::nn::Module model([](const auto &x) { return dm::nn::tanh(x); }, "Tanh");
model.plot(dm::nn::zeros({1, 2})).save_svg("tanh.svg");

    Execute the wrapped forward function with ordinary eager semantics.

    Parameters

    Tensor supplied unchanged to the callback.

    Returns

    The callback's tensor, retaining its ordinary autograd history.

    Throws

    Any exception thrown by the callback propagates.

    Example
