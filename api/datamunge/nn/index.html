    datamunge/nn/bar_images.hpp

    Classes

    BarImageBatchOwned balanced alternating bar images, true masks, metadata and reproducible row order. Shapes use NHWC. Row 2i is horizontal/class zero and row 2i+1 is vertical/class one. Masks identify the noiseless object, not a threshold on the noisy image. shuffled_rows is a permutation drawn after generation from the same local engine; splitting this order does not alter the original image identities. All values own storage; changing an image does not change its independent mask.
    BarImageOptionsFinite square-image bar geometry and independent clipped pixel noise. Horizontal bars span every column; vertical bars span every row. Position is the first occupied row/column. Both classes share the inclusive position range; max_position=-1 selects side-thickness. Noise is added before clipping to [0,1]. Float32/Float64 output is supported. This is a controlled synthetic task, not a natural-image dataset or a claim about translation-invariant predictions.

    Functions

    make_bar_images()Generate balanced noisy bar tensors with a local seeded MT19937-64 stream. Draws one position then row-major pixel noise for each alternating class row; the normal distribution is reconstructed per image, preserving the original report's draw/cache convention. Zero noise skips those draws. Samples are clipped to [0,1]; masks retain true object membership. After all images, shuffle ascending original row ids with the same engine. Distribution/shuffle mapping may differ across standard libraries, so bitwise portability is not promised. Positive per_class and valid geometry/range/finite noise/dtype are required. Checks complete tensor dimensions before allocation. O(per_class*side^2) work and owned storage; no global RNG state or fitting is involved.
