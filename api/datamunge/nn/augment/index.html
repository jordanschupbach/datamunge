    namespace datamunge::nn

    datamunge::nn::augment

    datamunge/nn/augment.hpp

    Classes

    MixedBatchResult of mixup / CutMix. weight is the share of each original image (and its label) kept; the partner image contributes 1 - weight.
    RectA pixel rectangle. It may extend past the image; only the overlap counts.

    Functions

    adjust_brightness()images + delta (TF adjust_brightness; no clamping).
    adjust_contrast()(x - mean) * factor + mean with the mean per image and channel over H and W (TF adjust_contrast / AdjustContrastv2).
    adjust_hue()Rotates hue by delta turns, delta in [-1, 1] (TF adjust_hue; C must be 3).
    adjust_saturation()Scales HSV saturation by factor, clamped to [0, 1] (TF adjust_saturation; C must be 3).
    beta_mix_weight()Beta(alpha, alpha) draw used as a mixing weight (tflow BetaMixWeight).
    color_jitter()Brightness, contrast, saturation and hue in that order, then clamps to [0, 1] (tflow ColorJitter). Identity at (0, 1, 1, 0) apart from the clamp.
    crop()images[:, top:top+height, left:left+width, :]; throws if the window leaves the image.
    cutmix()Pastes rect from images[permutation] into every image. The label weight is the fraction of pixels kept, measured after clipping (tflow Cutmix).
    cutout()Sets the pixels inside rect (clipped to the image) to fill, for every image.
    flip_left_right()Mirrors the W axis (TF flip_left_right).
    flip_up_down()Mirrors the H axis (TF flip_up_down).
    mixup()images * weight + images[permutation] * (1 - weight), and the same for the float [N, K] labels (one-hot or soft; convert class indices with one_hot).
    per_image_standardization()(x - mean) / max(stddev, 1 / sqrt(H*W*C)) per image (TF per_image_standardization).
    random_brightness()Adds a uniform delta in [-max_delta, max_delta] to each image.
    random_contrast()adjust_contrast with a factor uniform in [lower, upper) per image.
    random_crop()A uniformly placed height x width window of each image.
    random_cutmix()CutMix (Yun et al. 2019): weight lambda ~ Beta(alpha, alpha), a box of H*sqrt(1-lambda) x W*sqrt(1-lambda) centred at a uniform pixel, a random partner permutation; labels use the clipped area. Shared by the batch.
    random_cutout()Cutout (DeVries and Taylor 2017): a size x size square centred at a uniform pixel, clipped at the borders, set to fill in each image.
    random_flip_left_right()Flips each image left-right with probability p.
    random_flip_up_down()Flips each image up-down with probability p.
    random_hue()adjust_hue with a delta uniform in [-max_delta, max_delta] per image.
    random_mixup()mixup (Zhang et al. 2018) with a random batch permutation and a Beta(alpha, alpha) weight shared by the batch.
    random_pad_crop()tflow ImageBatch training augmentation: pads by pad pixels of fill on every side and crops back to H x W at a uniform offset, then (with flip) mirrors left-right with probability 1/2. Per image it draws the row shift, the column shift and then the coin, in that order. CIFAR training uses pad = 4, flip = true. tflow pads with 0 in uint8 units, i.e. black; apply this to [0, 1] images (fill 0) before rescaling.
    random_saturation()adjust_saturation with a factor uniform in [lower, upper) per image.
