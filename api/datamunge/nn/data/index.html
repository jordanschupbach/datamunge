    datamunge/nn/tfrecord.hpp

    Classes

    DenseSpecA fixed-length (dense) feature for ParseSingleExample: size values of kind, or default_value when the key is absent (none = required).
    FeatureOne tf.train.Feature: exactly one of the three lists is used.

    Functions

    Crc32c()Compute reflected CRC-32C (Castagnoli), including initial/final complements.
    MaskedCrc()Apply TFRecord rotate-and-offset masking to CRC-32C.
    ParseExample()Parses a serialized tf.Example; throws std::invalid_argument when malformed.
    ParseFeature()Decode one Feature protobuf, accepting packed or unpacked numeric fields.
    ParseSingleExample()TF ParseSingleExample for dense features: one Feature per spec, in spec order. A missing required key, a type mismatch or a wrong value count throws std::invalid_argument.
    ReadTFRecords()Read a complete file and validate every frame checksum before returning payloads.
    SerializeExample()Encode name-sorted typed lists as a tf.Example protobuf.
    ValidateCompression()Reject unsupported TFRecord compression names.
    WriteTFRecords()Replace a file with framed records and optional whole-stream compression.

    Types and constants

    Exampletype Name-sorted map of feature lists; keys are serialized deterministically.
