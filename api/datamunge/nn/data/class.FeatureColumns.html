    FeatureColumns

    class FeatureColumns
    #include <datamunge/nn/csv.hpp> source

    Fit immutable numeric/categorical feature state on selected training rows.

    Numeric features emit value then missing indicator. Categories emit missing, unknown, then known categories in sorted order. No target column is inferred. Header lookup makes column order irrelevant. Transform never refits the state; concurrent const calls are safe when the table and fitted object are not being modified.

    Example
    namespace d = dm::nn::data;
const auto t = d::ParseCsv("x,city\n1,A\n3,B\n9,C\n");
const auto f = d::FeatureColumns::Fit(t, {0,1},
{{"x",d::FeatureKind::kNumeric},{"city",d::FeatureKind::kCategorical}}); const auto validation =
f.Transform(t, {2});

    static FeatureColumns Fit(
    const CsvTable & table,
    const std::vector< size_t > & training_rows,
    const std::vector< FeatureSpec > & specs)

    Estimate feature state using only explicitly selected rows.

    Parameters
    table

    Rectangular string table.

    training_rows

    Nonempty zero-based training indices; duplicates act as repeated observations.

    specs

    Nonempty unique input-column specifications in output order.

    Returns

    Fitted object with fixed output names.

    Throws
    std::invalid_argument

    On invalid specifications, missing columns, invalid numbers or overflow; std::out_of_range on invalid rows.

    Example
    namespace d = dm::nn::data;
const auto t = d::ParseCsv("x\n1\n3\n");
const auto f = d::FeatureColumns::Fit(t,{0,1},{{"x",d::FeatureKind::kNumeric}});

    Transform

    #source
    datamunge::nn::Tensor Transform(const CsvTable & table, const std::vector< size_t > & rows) const

    Apply fitted preprocessing without changing moments or vocabulary.

    Parameters
    table

    Compatible named columns; may be reordered.

    rows

    Zero-based rows, in desired output order; may be empty.

    Returns

    Owned Float32 [rows, names().size()] tensor without gradient history.

    Throws
    std::logic_error

    If unfitted; std::invalid_argument on absent columns, invalid numbers or overflow; std::out_of_range on invalid rows.

    Example
    namespace d = dm::nn::data;
const auto t = d::ParseCsv("x\n1\n3\n");
const auto x =
d::FeatureColumns::Fit(t,{0,1},{{"x",d::FeatureKind::kNumeric}}).Transform(t,{1});
