    class datamunge::nn

    NnModel

    class NnModel
    #include <datamunge/nn/api.hpp> source

    A sequential network. Layers are added by spec and own parameters named "<kind><index>/..." (e.g. "dense0/W", "conv1/b"); batch-norm moving statistics live in a second store. Parameters are created on the first forward pass, when the input width is known.
