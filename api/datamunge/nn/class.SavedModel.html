    SavedModel

    class SavedModel
    #include <datamunge/nn/saved_model.hpp> source

    Own a serving session for a trusted local TensorFlow SavedModel.

    Select exactly one named Float32 input and output from a SignatureDef. Shapes use -1 for dynamic axes. Copies share the loaded inference session.

    Example
    const dm::nn::SavedModel model("saved_model");
const auto y = model.predict(dm::nn::zeros({1, 2}));
    References

    • TensorFlow SavedModel, https://www.tensorflow.org/guide/saved_model

    const std::string & directory,

    Load the serve-tagged MetaGraph and resolve named Float32 tensors.

    Parameters
    directory

    Trusted local directory containing saved_model.pb and its data.

    signature

    SignatureDef key, default serving_default.

    input

    Logical input key, default features.

    output

    Logical output key, default predictions.

    Throws
    std::invalid_argument

    Missing signature, incompatible tensor metadata or additional required inputs.

    std::runtime_error

    Backend unavailable or TensorFlow failed to load the model.

    Example
    const dm::nn::SavedModel model("saved_model", "serving_default", "features", "predictions");
