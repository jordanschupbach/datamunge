    to

    #source
    ParameterStore to(const compute::Context & context) const

    Copy every value to an explicit device, keeping names, order, dtype and seed state. The copies are detached, so a GPU copy is ready for inference under NoGradGuard; training continues on the original store. Copy back with copy_from() if needed.

    Parameters
    context

    Destination execution context, e.g. dm::compute::Context({Backend::CUDA, 0}).

    Returns

    Independent store whose tensors live on context.

    Throws
    std::runtime_error

    Native transfer failure.

    Example
    namespace n = dm::nn;
n::ParameterStore p(17);
p.get("w", {2, 2}, n::init::ones());
const auto copy = p.to(dm::compute::Context{});
std::print("{}\n", copy.count()); // 4
