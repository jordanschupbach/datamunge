    class Node : public std::enable_shared_from_this< Node >
    #include <datamunge/nn/autograd.hpp> source

    One recorded op.

    Derived classes: datamunge::nn::AccumulateGrad

    Members

    Constructors

    Node()Owns a backward callback, graph edges, and metadata for one recorded operation.
    ~Node()Frees upstream nodes iteratively, so dropping a very deep graph (an RNN unrolled over thousands of steps) cannot overflow the stack.

    Functions

    name()Borrows the operation name used in graph displays and errors.
    next_edges()Borrows upstream gradient destinations, one per forward input.
    input_meta()Borrows forward-input metadata used to validate returned gradients.
    output_meta()Borrows forward-output metadata used to create missing zero gradients.
    sequence_nr()Creation order (process-wide counter): a node made later has a larger number.
    released()True once release() has freed the backward function and saved values.
    apply()Runs the backward function. Throws if the node was already released.
    release()Frees the backward function and anything it saved.
    save_outputs()Keeps detached views of the outputs and their storage versions so apply() can return them to the backward callback with this node as their history. The storage is shared rather than copied; later in-place mutation is detected.

    Fields

    name_Diagnostic name of the recorded forward operation.
    next_edges_Ordered upstream destinations for gradients returned by the callback.
    input_meta_Forward-input dimensions and dtypes checked during backward propagation.
    output_meta_Forward-output dimensions and dtypes of the callback's incoming gradients.
    fn_Owned backward closure and its captures; cleared when the node is released.
    released_Whether saved state has been freed and another backward call must fail.
    saved_outputs_Detached output views, avoiding an ownership cycle back to this node.
    saved_versions_Storage version at capture time for each entry in saved_outputs_.
    sequence_nr_Monotonic creation ID used to delimit checkpoint recomputation graphs.

    Owns a backward callback, graph edges, and metadata for one recorded operation.

    Parameters
    name

    Operation name used in diagnostics.

    next_edges

    Destinations for gradients of each forward input, in input order.

    input_meta

    Shape and dtype of each forward input, aligned with next_edges.

    output_meta

    Shape and dtype of each forward output, defining incoming gradient slots.

    fn

    Backward callback; marker and derived nodes may supply null when they override apply().
