    class datamunge::nn

    Neat

    class Neat
    #include <datamunge/nn/neat.hpp> source

    Evolve feed-forward, single-output tanh networks with NEAT.

    Networks share innovation IDs for connections and split nodes. The population starts with only input and bias connections. Speciation uses the first compatible representative and unnormalized counts of nonmatching genes. Each step preserves one global elite and draws the other offspring from species weighted by mean fitness.

    Example
    std::mt19937 rng(1);
dm::nn::Neat population(2,8,rng);
const auto predictions=population.predict(dm::nn::zeros({4,2}));
std::print("{}\n",predictions.size(0)); // 8
    References

    • Stanley and Miikkulainen (2002), Evolving Neural Networks through Augmenting Topologies. doi:10.1162/106365602320169811

    evolve

    #source
    Tensor evolve(std::span< const float > fitness, std::mt19937 & rng, double threshold = 3.4)

    Replace the population using selection, crossover and structural mutation.

    Parameters
    fitness

    Nonnegative finite scores, with at least one positive score. Larger is better.

    rng

    Generator advanced by selection and mutation.

    threshold

    Compatibility cutoff passed to species(), default 3.4.

    Returns

    Parent IDs [population,2] in offspring order. -1 denotes no second parent.

    Throws
    std::invalid_argument

    Invalid scores or species threshold.

    Example
    std::mt19937 rng(1);
dm::nn::Neat population(2,2,rng);
const std::array fitness{0.5f,1.f};
const auto parents=population.evolve(fitness,rng);
std::print("{}\n",parents.to_vector<int>()[0]); // 1
