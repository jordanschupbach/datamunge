    FrozenGraph

    class FrozenGraph
    #include <datamunge/nn/frozen_graph.hpp> source

    Own an immutable frozen GraphDef and execute its supported numeric subgraphs natively.

    No TensorFlow runtime, protobuf library, variables, training, network access or random sampling. Numeric constants retain exact Float32/64, Int32/64 or Bool bits; scalar rank is preserved. Unsupported constant types/operations may be present outside fetched ancestry, allowing feeds to bypass JPEG decoding. evaluate() documents the supported operations. Models are caller-supplied; this class does not certify their identity or preprocessing. Copies share an immutable parsed model; evaluations use independent local working storage and are safe concurrently when caller feeds are not concurrently mutated. Outputs are detached owning copies. Mutable internal constant storage never escapes.

    Example
    #include <dm/dm.hpp>
const std::vector<unsigned char>
bytes{10,30,10,1,99,18,5,67,111,110,115,116,42,18,10,5,118,97,108,117,101,18,9,66,7,8,1,45,0,0,0,64};
dm::nn::FrozenGraph g(bytes); // Standard GraphDef containing scalar Const c=2.
const auto out=g.evaluate({}, {"c:0"}); // out[0].second.item() == 2.

    #source
    explicit FrozenGraph(
    const std::vector< unsigned char > & bytes,
    std::uint64_t max_bytes = 512ULL *1024 *1024)

    Parse owned model bytes and decode supported immutable numeric constants.

    The byte buffer may be destroyed after construction. The positive bound limits both serialized bytes and total decoded numeric constant storage, default512MiB. Rejects malformed lengths/varints/shapes, duplicate names, missing referenced nodes, nonzero serialized input ports and excessive node count(100000). Numeric constants accept little-endian tensor_content or typed repeated fields; missing typed values fill zero and a short nonempty list repeats its last value. Unknown metadata fields are skipped. Unsupported dtype constants are deferred until requested. Cycles and operation support are checked for the fetched graph.

    Parameters
    bytes

    Complete GraphDef wire bytes, nonempty and within max_bytes.

    max_bytes

    Positive byte/decoded-constant bound, default512MiB.

    Throws
    std::invalid_argument

    For malformed/inconsistent input or exceeded bounds.

    Example
    #include <dm/dm.hpp>
dm::nn::FrozenGraph g(std::vector<unsigned
char>{10,30,10,1,99,18,5,67,111,110,115,116,42,18,10,5,118,97,108,117,101,18,9,66,7,8,1,45,0,0,0,64});
// One node, scalar Float32 c=2, without TensorFlow installed.

    evaluate

    #source
    NamedTensors evaluate(const NamedTensors & feeds, const std::vector< std::string > & fetches) const

    Execute only fetched numeric ancestry with explicit feed overrides and no autograd.

    Supports Const, Placeholder, Identity, StopGradient, CheckNumerics, Relu, Add/AddV2, Sub, Mul, Div/RealDiv, BiasAdd, MatMul, Reshape, Squeeze, ExpandDims, Concat/ConcatV2, Softmax, ResizeBilinear, Conv2D, AvgPool, MaxPool and legacy BatchNormWithGlobalNormalization. Spatial ops use NHWC, SAME/VALID; no batch/channel stride or pooling. Conv spatial dilation is supported. BiasAdd is last-axis; MatMul honors transpose flags; resize accepts Float32 and honors align_corners/half_pixel_centers. Division and Softmax require floating inputs; spatial ops require Float32/64. Legacy BN preserves epsilon's serialized Float32 value and scale_after_normalization. Control dependencies execute too, including CheckNumerics, and cycles/depth>1024 are rejected. Feed overrides cut all input/control ancestry of that node. JPEG/string, variable, function, random and multi-output execution is unsupported.

    Feeds are defined CPU tensors with native numeric dtype; static dtype attrs are checked where available. No shape inference or pretrained identity is assumed; primitive geometry checks propagate. NaNs are permitted unless a reachable CheckNumerics rejects them. Inputs/internal weights are unchanged. First/higher paths always stop. Independent local work storage releases intermediates after their last consumer; fetch order and spelling are retained, including duplicate fetches. Empty fetches return empty, after feed checks.

    Parameters
    feeds

    Named feed tensors; unique node names optionally suffixed:0.

    fetches

    Requested existing output-zero names, in result order.

    Returns

    Detached owning result copies named exactly as requested.

    Throws
    std::invalid_argument

    For invalid feeds/names, unsupported reachable ops/attrs, cycles, nonfinite CheckNumerics values or primitive argument errors.

    std::logic_error

    For non-CPU storage or primitive runtime restrictions.

    Example
    #include <dm/dm.hpp>
namespace n=dm::nn;
n::FrozenGraph g(std::vector<unsigned
char>{10,30,10,1,99,18,5,67,111,110,115,116,42,18,10,5,118,97,108,117,101,18,9,66,7,8,1,45,0,0,0,64});
auto out=g.evaluate({{"c",n::full({},7)}},{"c:0","c"}); // Two detached scalar7 copies.
