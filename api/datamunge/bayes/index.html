    datamunge/bayes/gibbs.hpp

    Classes

    GibbsOptionsSettings for GibbsSampler.
    GibbsResultOutput of GibbsSampler::sample().
    GibbsSamplerMetropolis-within-Gibbs: updates one coordinate at a time, each via a scalar random-walk Metropolis step evaluated against the SAME joint log-density with every other coordinate held fixed – mathematically equivalent to a Metropolis step targeting the exact full conditional p(x_i | x_-i), since the joint-density ratio with everything else held fixed IS the full-conditional-density ratio. This is the standard fallback used whenever a full conditional isn't conjugate/directly sampleable (what BUGS/JAGS call "Metropolis-within-Gibbs"), not exact Gibbs sampling via closed-form conditional samplers – those are necessarily model-specific (they need to know each conditional's actual distributional family) and aren't something a generic engine driven only by a joint log-density can provide. Updating one coordinate at a time (rather than proposing the whole vector jointly, as RandomWalkMetropolis does) can mix substantially better when parameters live on very different scales or are only weakly correlated.

    datamunge/bayes/importance_sampling.hpp

    Classes

    ImportanceSamplingImportance sampling against a multivariate Gaussian proposal N(mean, covariance) – a natural choice when a Laplace approximation is available and reasonably close to the target's shape (e.g. bayes::MAP's mode paired with a numerically estimated Hessian there). Produces a weighted i.i.d. sample in one shot rather than a Markov chain – no warmup, nothing to check for mixing – but accuracy depends entirely on how well the Gaussian proposal covers the target's mass; effective_sample_size is the diagnostic to check before trusting the result.

    Functions

    datamunge/bayes/inla.hpp

    Classes

    INLAGaussian-strategy integrated Laplace inference for a latent Gaussian field. Model: eta=D*x, x|theta~N(0,Q(theta)^-1), with conditionally independent observations. At each theta, Newton finds x's mode and inverse Hessian. The Laplace log integrand is log prior(theta)+.5 log|Q|+log likelihood-.5*x'Q*x-.5 log|H|. Grid integration forms a mixture of these Gaussians; there is no simplified/full marginal Laplace skew correction and no sparse GMRF solver. Non-Gaussian conditional modes are used as approximate means. Use only modest dense latent dimensions. Borrowed callbacks run synchronously; result owns everything. Const calls have no shared mutation, but user callbacks must themselves be thread-safe when shared.
    INLAConditionalOne converged Gaussian approximation at fixed hyperparameters. Mode equals conditional mean only when the conditional posterior is Gaussian. Covariance is inverse negative Hessian at the mode; all arrays own their storage.
    INLALikelihoodPointLog likelihood and its first derivative and negative second derivative in eta. Curvature must be finite/nonnegative for the concave conditional model. Owns values.
    INLAOptionsNumerical controls for dense Gaussian-strategy INLA; no sparse or skew correction. Grid work grows as points^theta_dim. DE is a seeded mode search, not a global certificate.
    INLAResultGaussian-mixture posterior summaries and the full retained hyperparameter grid. These are approximate moments, not exact posterior draws. Within variance is the weighted conditional variance; between variance is variance of conditional modes. Their sum is total variance; neither term alone orders total variance against EB. All members own their data. Conditional covariance storage costs O(K*p^2).

    Functions

    inla_binomial_logit_likelihood()Stable Bernoulli logit log density, score y-p and curvature p*(1-p). This accepts individual zero/one outcomes, not fractional proportions or trial totals.
    inla_gaussian_likelihood()Normal observation likelihood with identity link and callback-selected noise SD. Includes the normal density constant. Returned function borrows no external model state beyond what its owned sigma callback captures; inputs are unchanged.
    inla_poisson_log_likelihood()Poisson log-link log density including log-factorial, score y-exp(eta).

    Types and constants

    INLALikelihoodFntype Callback (y,eta,theta) -> likelihood value/derivatives; parameters are borrowed.
    INLALogPriorFntype Log hyperprior on the caller's theta scale, including any change-of-variable Jacobian. Return negative infinity for excluded points. Normalize the prior for evidence calculations.
    INLAPrecisionFntype Callback theta -> owned symmetric positive-definite latent precision Q(theta).

    datamunge/bayes/inla_diagnostics.hpp

    Functions

    inla_conditional_table()Conditional mode/SD and repeated convergence diagnostics for each latent coordinate. Inputs are borrowed unchanged, results owned, O(p) work/storage.
    inla_grid_table()Retained theta grid, normalized weights, log integrand and conditional-mode diagnostics. O(K*(d+p)) work/result storage; owns tables, leaves input unchanged. EB gives one row.
    inla_latent_density()Evaluate a latent marginal's retained Gaussian-mixture density at specified values. Uses conditional modes and diagonal inverse Hessians, not a single Gaussian fitted to the final mean/SD. O(K*m) work, O(m) result; no input mutation/shared state.
    inla_latent_quantile()Quantile of a retained latent Gaussian-mixture marginal by CDF bisection. Brackets over all components and expands as needed; at most 120 bisection steps. This is an interval of the approximate mixture, not an exact-posterior guarantee. Work O(K*120), no input mutation/shared state.
    inla_latent_summary()Mixture moments and the exact law-of-total-variance accounting used by INLA. Within/between terms are nonnegative; their sum equals sd squared to roundoff. No input mutation, O(p) work/result storage; does not certify approximation accuracy.
    inla_scalar_reference()Direct finite-window quadrature of a scalar latent posterior at fixed theta. Integrates the actual likelihood times a normalized N(0,1/precision) prior using the midpoint grid_posterior() rule, without Laplace approximation. Truncation and quadrature errors remain: widen/refine the window and inspect edge_mass. O(n*points) work and O(points) result; no input mutation. This supports one scalar intercept loading one on each observation, not a general multivariate reference.

    datamunge/bayes/nuts.hpp

    Classes

    NUTSThe No-U-Turn Sampler (Hoffman & Gelman 2014, the efficient slice-sampling variant, Algorithm 3): Hamiltonian Monte Carlo with an automatically chosen trajectory length – the leapfrog trajectory is grown by repeated doubling until it would start turning back on itself (a "U-turn"), removing the need to hand-tune a fixed number of leapfrog steps. Step size is still adapted via the same dual-averaging scheme as HMC. Uses an identity mass matrix.
    NUTSOptionsSettings for NUTS.
    NUTSResultOutput of NUTS::sample().

    datamunge/bayes/rwm.hpp

    Classes

    RandomWalkMetropolisRandom-walk Metropolis-Hastings: the classic gradient-free MCMC baseline, proposing x' = x + step_size * N(0, I) and accepting with probability min(1, exp(log_posterior(x') - log_posterior(x))). Complements HMC/NUTS (which need a gradient via optim::DifferentiableFunction) for targets where only a log-density evaluation is available – a black-box model, a discontinuous/non-differentiable posterior, or a director-subclassed optim::ArbitraryFunction in a language without access to this library's autodiff.
    RWMOptionsSettings for RandomWalkMetropolis.
    RWMResultOutput of RandomWalkMetropolis::sample().
