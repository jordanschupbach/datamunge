    class datamunge::bayes

    INLA

    class INLA
    #include <datamunge/bayes/inla.hpp> source

    Gaussian-strategy integrated Laplace inference for a latent Gaussian field. Model: eta=D*x, x|theta~N(0,Q(theta)^-1), with conditionally independent observations. At each theta, Newton finds x's mode and inverse Hessian. The Laplace log integrand is log prior(theta)+.5 log|Q|+log likelihood-.5*x'Q*x-.5 log|H|. Grid integration forms a mixture of these Gaussians; there is no simplified/full marginal Laplace skew correction and no sparse GMRF solver. Non-Gaussian conditional modes are used as approximate means. Use only modest dense latent dimensions. Borrowed callbacks run synchronously; result owns everything. Const calls have no shared mutation, but user callbacks must themselves be thread-safe when shared.

    Example
    dm::bayes::INLAOptions o;o.strategy=dm::bayes::INLAIntegrationStrategy::EmpiricalBayes;
const dm::bayes::INLA solver(o);
const auto r=solver.fit(dm::linalg::DenseMatrix<double>(3,1,1),{1,2,3},
    dm::bayes::inla_gaussian_likelihood([](const auto&){return 1.;}),
    [](const auto& t){return dm::linalg::DenseMatrix<double>(1,1,std::exp(t[0]));},
    [](const auto& t){return dm::bayes::normal_lpdf(t[0],0,1);},{-5},{5},{0});
std::print("{}\n",r.theta_grid_weights.size()); // 1

    fit()Fit bounded hyperparameters and combine conditional Gaussian moments. Search and grid evaluations stay within the supplied box. Finite differences use inward probes near its boundary.     INLAResult fit(
    const linalg::DenseMatrix< double > & design,

    Fit bounded hyperparameters and combine conditional Gaussian moments. Search and grid evaluations stay within the supplied box. Finite differences use inward probes near its boundary. A non-SPD hyper-Hessian triggers the recorded box-width fallback. For one theta dimension, boundary cells are clipped and recentered. Higher dimensions use constant rotated cell volumes and skip outside-box centers; failed conditional fits are also skipped and counted. There is no adaptive grid refinement or error guarantee. Check density/span/resolution sensitivity. Evidence requires normalized likelihood/prior and intentional integration support; a constant improper hyperprior has an arbitrary evidence scale. EB returns one conditional fit and NaN evidence, not an integrated likelihood. Work per conditional Newton iteration O(n*p^2+p^3); retained storage O(K*p^2).

    Parameters
    design

    Finite nonempty n-by-p observation matrix.

    y

    Exactly n finite responses valid for the supplied likelihood.

    likelihood

    Concave observation log density/derivatives; callback exceptions propagate.

    precision

    Returns p-by-p finite symmetric SPD Q(theta); failed builders are skipped.

    log_prior

    Log hyperprior on theta scale; negative infinity excludes a point.

    theta_lower

    Finite lower bounds, strictly below upper bounds.

    theta_upper

    Finite upper bounds; part of the integration support.

    theta_init

    Finite in-box seed; nonempty and determines theta dimension.

    Returns

    Owned approximate mixture and all retained conditional fits.

    Throws
    std::invalid_argument

    Bad shapes/finite values/box, empty callbacks or excessive grid.

    std::runtime_error

    No usable converged approximation at the selected mode/grid.

    conditional

    #source
    INLAConditional conditional(
    const linalg::DenseMatrix< double > & design,
    const std::vector< double > & y,
    const INLALikelihoodFn & likelihood,
    const linalg::DenseMatrix< double > & precision,
    const std::vector< double > & theta = {}) const

    Approximate only the latent posterior at fixed precision and hyperparameters. Uses the same safeguarded Newton loop as fit(). Exhaustion is an error, never silently reported as convergence. Gaussian likelihood gives exact normal moments up to floating-point error; other families generally have skew approximation error.

    Parameters
    design

    Finite nonempty n-by-p design.

    y

    n finite responses valid for likelihood.

    likelihood

    Concave log density and its eta derivatives.

    precision

    Finite symmetric SPD p-by-p prior precision, borrowed.

    theta

    Finite callback hyperparameters; default empty for fully fixed models.

    Returns

    Owned mode, full covariance, conditional Laplace evidence and convergence evidence.

    Throws
    std::invalid_argument

    Invalid design/response/callback or nonfinite theta.

    std::runtime_error

    Invalid precision, failed line search or exhausted Newton budget.

    Example
    const auto r=dm::bayes::INLA().conditional(dm::linalg::DenseMatrix<double>(2,1,1),{0,1},
    dm::bayes::inla_binomial_logit_likelihood(),dm::linalg::DenseMatrix<double>(1,1,1));
std::print("{:.1f}\n",r.mode[0]); // 0.0
