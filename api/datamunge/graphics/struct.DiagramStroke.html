    DiagramStroke

    struct DiagramStroke
    #include <datamunge/plot/diagram.hpp> source

    Appearance of a native diagram path, polygon or ellipse. Values are owned; widths are pixels and RGB opacity is respected. All numeric values must be finite. Width must be positive; RGB channels and opacity are clamped on export.

    Example
    dm::graphics::DiagramStroke arrow;
arrow.arrow = true;
arrow.color = {37, 99, 235};
dm::graphics::Diagram().path({{0, 0}, {2, 1}}, arrow).save_svg("arrow.svg");
    See also

    Diagram::path(), Diagram::edge()
