    class datamunge::graphics

    Plot

    class Plot
    #include <datamunge/plot/plot.hpp> source

    Renderer-facing state shared by every 2-D plot: canvas, labels, axes, and series.

    User code works with the derived RPlot (spelled dm::Plot), whose setters return RPlot&; this base holds the data, the read-only accessors, and the output functions to_svg(), save(), and show(). The base-class setters below return Plot& and are what RPlot's same-named setters forward to; call the RPlot forms in user code so chains keep the RPlot type. A const Plot& is also what RLayout::add() accepts and RLayout::panel() returns.

    Every output function renders from the stored state, so it throws std::runtime_error for a plot with no data series (reference lines and legend rows alone are not enough) or a canvas too small for its margins. Plots are copyable values with no shared state; distinct plots may be used from different threads, but one plot must not be mutated while it is rendered.

    Example
    const dm::graphics::Plot& base = dm::Plot(dm::c(1.0, 2.0), dm::c(1.0, 4.0)).set_title("Base");
std::print("{} {}x{}\n", base.title_text(), base.width(), base.height());  // Base 960x640

    to_svg

    #source
    std::string to_svg() const

    Renders the plot as a standalone SVG document and returns it as a string.

    The document starts with an XML declaration and draws text as embedded Computer Modern glyph outlines, so it displays identically in any SVG viewer, with or without web fonts. The plot is not modified, and no file or display is used.

    Returns

    The complete SVG text.

    Throws
    std::runtime_error

    If the plot has no data series, or the canvas is smaller than its margins.

    Example
    const auto svg = dm::Plot(dm::c(1.0, 2.0), dm::c(2.0, 1.0)).set_title("Tiny").to_svg();
std::print("{}\n", svg.starts_with("<?xml"));  // true
std::print("{}\n", svg.contains("Tiny"));      // true
    See also

    save(), show()

    save

    #source
    void save(const std::string & path) const

    Writes the plot to path, choosing the format from the file extension (R's svg()/png()/pdf() devices followed by dev.off(), in one call).

    .svg or no extension writes the same text as to_svg(); .png writes the raster image the X11 viewer displays; .pdf wraps that raster in a single-page PDF. The extension is case-sensitive. An existing file is overwritten. Needs no display.

    Parameters
    path

    Destination file; relative paths resolve against the working directory.

    Throws
    std::invalid_argument

    For any other extension (e.g. .jpg).

    std::runtime_error

    If the file cannot be opened for writing, the plot has no data series, or the canvas is smaller than its margins.

    Example
    auto plt = dm::Plot(dm::c(1.0, 2.0, 3.0), dm::c(1.0, 4.0, 9.0)).set_title("Squares");
plt.save("squares.svg");  // vector
plt.save("squares.png");  // raster
plt.save("squares.pdf");  // raster in a one-page PDF
    See also

    save_svg(), to_svg(), show()

    show

    #source
    void show(const std::string & title_hint = "") const

    Opens the plot in an interactive X11 window and blocks until it is closed (like printing a plot in an interactive R session).

    The window has toolbar and keyboard zoom/pan (it re-renders from data bounds) and closes on q or Escape; the function returns only then. The window title is title_hint, or the plot's title (title_text()) when the hint is empty. Requires a build with X11 support and a reachable DISPLAY; use save() in headless code such as tests and CI.

    Parameters
    title_hint

    Window title; empty (the default) uses the plot's title.

    Throws
    std::runtime_error

    If X11 support was not compiled in, the display cannot be opened, its visual is unsupported, or the plot has no data series.

    Example
    const auto x = dm::runif(0, 1, 1000);
const auto y = dm::sin(20 / (x + 0.25)) + dm::rnorm(0, 0.2, 1000);
dm::Plot(x, y).set_title("Doppler").set_col("blue").show("Doppler signal");
