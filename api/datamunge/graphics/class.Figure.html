    class datamunge::graphics

    Figure

    class Figure
    #include <datamunge/plot/figure.hpp> source

    A finished figure of any kind (a single plot or a grid of panels) with one output interface: title(), size(), to_svg()/to_png()/to_pdf(), save*(), and show().

    Every plot type in the library converts to a Figure implicitly: RPlot (dm::Plot), its subclasses such as Histogram, RLayout, Splom, and GGPlot. A Figure is an owned copy, so it does not refer back to the object it came from. For a single plot, title() and size() act on that plot; for a grid they act on the whole figure (title() draws a heading band above the panels), and every panel is resized to its cell so text keeps its pixel size.

    Example
    const auto x = dm::seql(0.0, 6.0, 30);
dm::graphics::Figure fig = dm::graphics::RLayout::create(1, 2)
                               .add(dm::Plot(x, dm::sin(x)).set_title("sin"))
                               .add(dm::Plot(x, dm::cos(x)).set_title("cos"));
fig.title("Two views").size(1000, 420).save_png("trig.png");
std::print("{} panels, {}x{}\n", fig.panel_count(), fig.width(), fig.height());
// 2 panels, 1000x420
    See also

    dm::plot(), RPlot, RLayout

    size

    #source
    Figure & size(std::size_t width, std::size_t height)

    Sets the size of the whole figure in pixels.

    For a grid, each panel is resized to its cell (see RLayout::fit_panels()), so labels stay readable rather than being scaled down with the panel. Any size works: a panel or plot smaller than RLayout::min_panel_px on a side is drawn on a larger canvas and scaled down.

    Parameters
    width

    Width in pixels.

    height

    Height in pixels, including any title band.

    Returns

    This figure, for chaining.
