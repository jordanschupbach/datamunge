    datamunge::graphics

    Plotting: RPlot (dm::Plot) and RLayout (R base graphics), GGPlot (ggplot2-style), Splom (pairs plots), and Figure, the common output type the free dm::plot() functions return. Named graphics (after R's package) so that dm::plot can be a function.

    datamunge/plot/diagram.hpp

    Classes

    DiagramEditable native method diagrams, exported as standalone SVG without external renderers. Coordinates have equal scales on both axes and y points upwards. Nodes own their labels, wrap words and size themselves from the plotting library's embedded Computer Modern font metrics. Text supports UTF-8 and explicit newlines (not TeX markup). Visible labels use native glyph outlines so viewers cannot substitute a differently sized font; selectable source text and accessible labels are retained. Unicode digit scripts, superscript plus/minus/T and script ell use native base glyphs. Other characters absent from the embedded font render as question marks; accessible labels retain the original text. Arrows join node boundaries. Paths, polygons, ellipses and free labels share one coordinate system. Export fits all primitives, labels, stroke widths and arrowheads, leaving a pixel margin. A diagram wider than max_width is scaled uniformly, retaining its aspect ratio. Mutation is not thread-safe; const export may be called concurrently on an unmodified object. Rendering and storage are linear in the number of primitives and their text/path lengths.
    DiagramNodeStyleNode appearance and minimum size; text expands the box when necessary. Explicit newlines are retained; long lines wrap at word boundaries within width. An unbreakable word may expand the box. Padding is applied on all sides. Nodes are rounded rectangles, or circles when circle is true. Numeric values must be finite; dimensions and font size are positive, padding and corner radius nonnegative.
    DiagramPointA diagram coordinate; x grows rightwards and y upwards, in diagram units.
    DiagramStrokeAppearance of a native diagram path, polygon or ellipse. Values are owned; widths are pixels and RGB opacity is respected. All numeric values must be finite. Width must be positive; RGB channels and opacity are clamped on export.

    datamunge/plot/ggplot.hpp

    Classes

    AesAesthetic mapping, mimicking ggplot2's aes(). Column names refer to columns of the dstruct::DataFrame passed to GGPlot::create(). color and fill are treated identically (both select a discrete grouping column); leave a field empty to omit it.
    GGPlotA ggplot2-style grammar-of-graphics builder: layers of geoms are accumulated against one Aes mapping and replayed at save() time (once per facet panel, if facet_wrap() was used), each replay producing an RPlot so rendering reuses the exact same SVG/PNG/PDF engine as the R-base graphics library.

    datamunge/plot/grayscale_images.hpp

    Classes

    GrayscaleImagePanelOwned rectangular grayscale values and a panel title. Rendering requires finite values in0..255; the source values are never changed.

    Functions

    diagram_grayscale_images()Draw one or two grayscale grids as equal-scale native pixel cells. Zero is black and255 white. Display colors round to the nearest8-bit gray; numeric source values and algorithms are untouched. Rows increase downwards. Default color-only cells have invisible borders and ten-pixel native units; optional four-significant-digit labels widen cells to fit. The figure scales uniformly to at most1100px width. Color-only views suit halftone patterns. Full shape/finite/range validation precedes the complete total-cell cap and rendering. Empty grids are valid. One or two panels only; diagrams own their primitives and retain no input views. O(total rows+cells) work/storage. No input mutation or shared mutable state.

    datamunge/plot/label_images.hpp

    Classes

    LabelImagePanelOwned rectangular nonnegative label grid and its panel heading. Zero is background; positive IDs may have gaps, allowing provisional maps. Storage is independent of the labeller. Colours repeat after eight positive IDs.
    ValueImagePanelOwned rectangular signed-value grid and its panel heading. Values are categories, not magnitudes; every int, including INT_MIN, is valid.

    Functions

    diagram_label_images()Draw one or two label grids as native equal-scale cell diagrams. Rows increase downwards. Zero cells are white; positive IDs use eight cycling pastel colours, so colour alone is not a unique component identifier. Optional numeric labels include background zeros. Cells widen for the longest integer label; the complete figure fits within 1100 pixels. Full shape/value validation precedes the complete total-cell cap and rendering. Empty grids are valid; zero or more than two panels is invalid. No mutation/global state. O(total rows + total cells) construction work and returned diagram storage.
    diagram_value_images()Draw one or two signed categorical grids with consistent shared colors. Zero is white. The sorted union of nonzero values across the supplied panels selects an eight-color cycle; a value has the same color within this figure, but its color can differ across separate calls. More than eight categories reuse colors, so retain labels when identity matters. Rows increase downwards; equal-scale cells widen to fit signed labels, with maximum figure width1100px. Complete shape validation precedes the total-cell cap and palette allocation. Empty grids are valid; the returned editable diagram owns its primitives. O(total rows + N log(V+1)) construction work for N cells and V nonzero values; O(N+V) returned/temporary storage. No mutation or shared mutable state.

    datamunge/plot/plot.hpp

    Classes

    ABLineA straight reference line across the whole plotting area, as drawn by R's abline(a, b), abline(h =) and abline(v =).
    DataSeriesOne drawn layer of a plot (points, a line, bars, a box, a polygon, a label, or segments), as stored by RPlot's layer verbs and read back through Plot::series().
    LegendEntryOne manually specified legend row, as drawn by R's legend().
    PlotRenderer-facing state shared by every 2-D plot: canvas, labels, axes, and series.
    RGBA plotting color: 8-bit red, green, and blue channels plus an alpha opacity, the C++ counterpart of R's rgb(r, g, b, alpha, maxColorValue = 255).
    RLayoutTiles independently built plots into one multi-panel figure, like R's par(mfrow = c(rows, cols)) followed by one plot per panel.
    RPlotA single R-base-graphics-style plot, spelled dm::Plot in user code.

    Functions

    diverging_colors()n colours from dark blue through white to dark red, a diverging palette for signed values such as correlations (ColorBrewer's RdBu, reversed so that low is blue).
    terrain_colors()n colours from green through yellow and brown to near-white, as R's terrain.colors(n).
    value_colors()One colour per value on a continuous scale, for colouring scatter points by a numeric variable (ggplot2's scale_colour_viridis_c()).
    viridis_colors()n colours of the viridis scale, from dark purple through blue and green to yellow, matching R's viridisLite::viridis(n) at n = 10.

    #source
    using RGBA = RGB

    Alias of RGB for colors with a meaningful alpha channel.

    Accepts numeric channels, RGB values, color names and hex strings. RGBA{r, g, b, alpha} reads better than RGB{r, g, b, alpha} for translucent colors; the two names denote the same type and mix freely in palettes.

    Example
    auto plt = dm::Plot(dm::rnorm(0, 1, 500), dm::rnorm(0, 1, 500))
               .set_col(dm::RGBA{37, 99, 235, 0.3});  // overplotting shows as density
plt.save("cloud.svg");
