    struct datamunge::graphics

    DataSeries

    struct DataSeries
    #include <datamunge/plot/plot.hpp> source

    One drawn layer of a plot (points, a line, bars, a box, a polygon, a label, or segments), as stored by RPlot's layer verbs and read back through Plot::series().

    A plain aggregate holding data coordinates and styling. Which fields matter depends on kind; each Kind value documents how it reads x, y, and the other fields. Layers are drawn in insertion order, after the reference lines, and every layer's coordinates widen the automatic axis ranges (bars also pull the y range down or up to 0). A nonempty label puts the layer in the automatic legend unless it is a Text layer. User code normally creates layers through RPlot verbs (points(), lines(), bars(), ...) and only reads this struct.

    Example
    auto plt = dm::Plot().points(dm::c(1.0, 2.0), dm::c(3.0, 4.0), "pts");
const dm::graphics::DataSeries& s = plt.series()[0];
std::print("{} {} {} {}\n", s.kind == dm::graphics::DataSeries::Kind::Scatter, s.x.size(),
           s.label, s.marker_size);  // true 2 pts 4

    Types

    Kind

    #source
    enum class Kind

    How a DataSeries is drawn and how its coordinate vectors are read.

    EnumeratorValueDescription
    Scatter

    One marker (radius marker_size px) per (x[i], y[i]); colors from point_colors when set.

    Line

    A polyline joining (x[i], y[i]) in order, stroke_width px wide (R's lines()).

    Bar

    Vertical bars from y = 0 to y[i], centered on x[i], bar_width data units wide.

    Box

    One box-and-whisker at x[0]: y = {whisker_lo, q1, median, q3, whisker_hi, outliers...}; bar_width is the box width in data units.

    Polygon

    A closed polygon through (x[i], y[i]); filled selects fill vs. outline only.

    Text

    A centered text label at (x[0], y[0]); label holds the text and marker_size the font size in pixels. Never listed in the automatic legend.

    Segment

    Disconnected segments joining (x[2i], y[2i]) to (x[2i+1], y[2i+1]), stroke_width px wide (R's segments()).
