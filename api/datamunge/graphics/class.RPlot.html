    RPlot

    class RPlot : public datamunge::graphics::Plot
    #include <datamunge/plot/plot.hpp> source

    A single R-base-graphics-style plot, spelled dm::Plot in user code.

    Covers R's high-level plotting calls (plot(), hist(), barplot(), boxplot(), pie(), curve(), qqnorm(), ...) as constructors and static factories, plus the "add to the current plot" verbs R exposes as separate functions (points(), lines(), abline(), legend(), text(), ...) as chainable member functions. A plot is an ordinary value: it owns copies of its data, copies cheaply enough to pass around, and draws nothing until it is rendered with to_svg(), save(), or show().

    Two composition styles mix freely. Setters such as set_title() and verbs such as points() mutate the plot and return RPlot& for chaining; the pipe plot | dm::points(...) (see compose.hpp) appends a reusable layer to a copy. A fresh plot has the title "datamunge plot", axis labels "x" and "y", a 960x640 canvas, and a light grid.

    Example
    const auto x = dm::seql(-2.0, 2.0, 9);
auto plt = dm::Plot(x, x * x)
               .set_title("Parabola")
               .set_xlab("x")
               .set_ylab("x squared");
plt.lines(x, x * x, dm::RGB{220, 38, 38}).abline_h(0.0);
plt.save("parabola.svg");

    boxplot

    #source
    static RPlot boxplot(
    std::vector< std::vector< double > > groups,
    std::vector< std::string > names = {},

    Builds side-by-side box-and-whisker plots, one per group, like R's boxplot(list(...), names = names).

    Group g is drawn at x = g (0, 1, 2, ...) as a 0.6-unit-wide box from the first to the third quartile with a line at the median. Quartiles are R's default "type 7" sample quantiles. R's boxplot() instead uses Tukey's hinges (fivenum()), so for some sample sizes the box edges and the fences differ slightly from R: for 1, ..., 9, 40 this gives quartiles 3.25 and 7.75 where R draws hinges at 3 and 8. All boxes share color; the title and axis labels keep their defaults.

    names

    color

    Returns

    pretty_ticks

    #source
    RPlot & pretty_ticks(bool enabled = true)

    Places numeric ticks at round values (default on) instead of six evenly spaced ticks across the range, in the spirit of R's pretty().

    The step is 1, 2, or 5 times a power of ten, chosen as the "nice number" nearest a fifth of the visible range (Heckbert's rule), and ticks are its multiples inside the range.
