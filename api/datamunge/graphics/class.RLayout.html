    class datamunge::graphics

    RLayout

    class RLayout
    #include <datamunge/plot/plot.hpp> source

    Tiles independently built plots into one multi-panel figure, like R's par(mfrow = c(rows, cols)) followed by one plot per panel.

    Create it with create(rows, cols), then add() up to rows * cols panels; they fill the grid row by row. Each panel is copied (and its SVG rendered) at add() time, so later changes to the original plot do not show and panels need not outlive the layout. Each cell is width / cols by (height - band) / rows pixels, where band is title_band_px when a figure title is set and 0 otherwise; every panel is scaled from its own canvas size into its cell. The figure background is white. Unused cells stay empty.

    Example
    const auto x = dm::seql(0.0, 6.0, 30);
auto fig = dm::graphics::RLayout::create(1, 2)
               .size(1200, 500)
               .title("Two views")
               .add(dm::Plot(x, dm::sin(x)).set_title("sin"))
               .add(dm::Plot(x, dm::cos(x)).set_title("cos"));
std::print("{} panels in {}x{}\n", fig.panel_count(), fig.rows(), fig.cols());
// 2 panels in 1x2
fig.save("two_views.svg");

    Functions

    add()Copies panel into the next free cell, filling rows left to right, top to bottom.
    size()Sets the size of the whole figure in pixels (default 960 by 640).
    title()Sets an optional figure-level heading drawn in a band above the panels, like R's mtext(main, outer = TRUE); an empty string (the default) reserves no band.
    rows()Returns the number of panel rows given to create().
    cols()Returns the number of panel columns given to create().
    width()Returns the figure width in pixels.
    height()Returns the figure height in pixels.
    panel_count()Returns how many panels have been added.
    title_text()Borrows the figure-level heading for the lifetime of this layout.
    panel()Borrows the copy of the index-th added panel.
    to_svg()Renders the multi-panel figure as a standalone SVG document and returns it as a string.
    save()Saves the figure, choosing the format from the extension: .svg (or none) writes SVG, .png / .pdf write the same tiled raster the X11 viewer shows.
    save_svg()Writes to_svg() to path regardless of its extension.
    to_png()Renders the tiled figure as PNG image bytes (the raster save() writes for .png).
    to_pdf()Renders the tiled figure as a one-page PDF holding the raster image.
    save_png()Writes to_png() to path regardless of its extension.
    save_pdf()Writes to_pdf() to path regardless of its extension.
    fit_panels()Resizes every stored panel's canvas to its cell, so text keeps its pixel size instead of being scaled with the panel.
    show()Opens the tiled figure in the interactive X11 viewer; the toolbar zoom/pan buttons act on every panel's data bounds at once, keyboard zoom/pan scales the whole image.
    view()Same as show(); kept as an alias for older code.

    Static data

    title_band_pxHeight in pixels of the heading band reserved above the panels when a title is set.
    min_panel_pxSmallest canvas side fit_panels() gives a panel; smaller cells get a larger canvas with the cell's aspect ratio, scaled down when drawn, so the margins still fit.

    #source
    static RLayout create(std::size_t rows, std::size_t cols)

    Creates an empty layout with rows by cols cells, like R's par(mfrow = c(rows, cols)).

    The figure starts at 960 by 640 pixels with no title.

    Parameters
    rows

    Number of panel rows; must be positive.

    cols

    Number of panel columns; must be positive.

    Returns

    The empty layout.

    Throws
    std::invalid_argument

    If rows or cols is 0.

    See RLayout.

    add

    #source
    RLayout & add(const Plot & panel)

    Copies panel into the next free cell, filling rows left to right, top to bottom.

    The panel's SVG is rendered immediately and stored with the copy, so rendering errors surface here and later edits to the original plot have no effect on the layout.

    Parameters
    panel

    The plot to add; any RPlot (or other Plot) converts.

    Returns

    This layout, for chaining.

    Throws
    std::invalid_argument

    If all rows * cols cells are already filled.

    std::runtime_error

    If panel has no data series or its canvas is smaller than its margins.

    Example
    auto fig = dm::graphics::RLayout::create(1, 1).add(dm::Plot(dm::c(1.0, 2.0), dm::c(2.0, 1.0)));
try {
  fig.add(dm::Plot(dm::c(1.0), dm::c(1.0)));
} catch (const std::invalid_argument& e) {
  std::print("{}\n", e.what());  // RLayout::add: layout is already full
}

    fit_panels

    #source
    RLayout & fit_panels()

    Resizes every stored panel's canvas to its cell, so text keeps its pixel size instead of being scaled with the panel.

    Call it after size() and title() (the title band changes the cell height). Panels added later keep their own size until fit_panels() is called again. A cell whose shorter side is under min_panel_px gets a canvas scaled up to that side (same aspect ratio), so its text is drawn proportionally smaller instead of the margins overflowing the panel.

    Returns

    This layout, for chaining.

    Example
    auto fig = dm::graphics::RLayout::create(1, 2)
               .add(dm::Plot(dm::c(1.0, 2.0), dm::c(2.0, 1.0)))
               .add(dm::Plot(dm::c(1.0, 2.0), dm::c(1.0, 2.0)))
               .size(1000, 400)
               .fit_panels();
std::print("{}x{}\n", fig.panel(0).width(), fig.panel(0).height());  // 500x400
