    GGPlot

    class GGPlot
    #include <datamunge/plot/ggplot.hpp> source

    A ggplot2-style grammar-of-graphics builder: layers of geoms are accumulated against one Aes mapping and replayed at save() time (once per facet panel, if facet_wrap() was used), each replay producing an RPlot so rendering reuses the exact same SVG/PNG/PDF engine as the R-base graphics library.

    Used in reports

    Regularised Tree Boosting for Iris: Fit, Select, Then Test
