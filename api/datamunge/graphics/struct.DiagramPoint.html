    struct DiagramPoint
    #include <datamunge/plot/diagram.hpp> source

    A diagram coordinate; x grows rightwards and y upwards, in diagram units.

    Example
    const dm::graphics::DiagramPoint origin{0, 0};
std::print("{} {}\n", origin.x, origin.y);  // 0 0
