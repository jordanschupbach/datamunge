    DiagramNodeStyle

    struct DiagramNodeStyle
    #include <datamunge/plot/diagram.hpp> source

    Node appearance and minimum size; text expands the box when necessary. Explicit newlines are retained; long lines wrap at word boundaries within width. An unbreakable word may expand the box. Padding is applied on all sides. Nodes are rounded rectangles, or circles when circle is true. Numeric values must be finite; dimensions and font size are positive, padding and corner radius nonnegative.

    Example
    dm::graphics::DiagramNodeStyle style;
style.fill = {255, 237, 213};
dm::graphics::Diagram().node("step", {0, 0}, "Evaluate\nresidual", style).save_svg("step.svg");
