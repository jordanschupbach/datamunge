    struct datamunge::graphics

    RGB

    struct RGB
    #include <datamunge/plot/plot.hpp> source

    A plotting color: 8-bit red, green, and blue channels plus an alpha opacity, the C++ counterpart of R's rgb(r, g, b, alpha, maxColorValue = 255).

    Brace-initialize numeric channels: dm::RGB{255, 0, 0} is opaque red and dm::RGB{255, 0, 0, 0.5} is half-transparent red. A default-constructed RGB is the library's dark-slate ink {31, 41, 55}, fully opaque. Channels are not validated: keep them in [0, 255] (both the raster and SVG renderers clamp out-of-range channels), and keep alpha in [0, 1] (both renderers clamp it). Every plotting API takes RGBA (the same type as RGB) by value, and dm::c(...) of several RGBs builds a palette usable with select() and set_col(). Color strings convert implicitly: names are case-insensitive black, white, red, green, blue, yellow, cyan, magenta, gray/grey and transparent; hex accepts #RRGGBB and #RRGGBBAA, with alpha last and scaled to [0, 1]. Malformed text throws before a plot is changed. RGB and RGBA remain the same type, preserving existing palettes and the binary layout of numeric colors. Parsing owns no reference to the string.

    Example
    const auto gold = dm::RGB{255, 215, 0};
const auto glass = dm::RGBA{37, 99, 235, 0.3};  // translucent blue
const dm::RGB ink;                              // {31, 41, 55}, opaque
std::print("{} {} {}\n", gold.r, glass.alpha, ink.r);  // 255 0.3 31
const auto palette = dm::c(gold, glass);       // a dm::Vector<dm::RGB>

    #source
    RGB(const std::string & color)

    Implicitly parse a color name, #RRGGBB or #RRGGBBAA string. Names and hexadecimal digits are case-insensitive. Hex alpha is the final byte divided by 255; omitted alpha is 1. Whitespace is not stripped. Named green is (0, 128, 0); transparent is black with alpha zero. The input is copied while parsing and is never borrowed by a plot or palette.

    Parameters
    color

    Color text; supported names are listed in the class description.

    Throws
    std::invalid_argument

    For empty text, unknown names or malformed hex.

    Example
    const dm::RGBA glass = std::string("#ff44ff55");
const auto plt = dm::plot(dm::c(0, 1), dm::c(1, 2), "data", "#ff44ff55");
std::print("{} {}\n", glass.r, dm::round(glass.alpha, 3)); // 255 0.333
