    class datamunge::graphics

    Diagram

    class Diagram
    #include <datamunge/plot/diagram.hpp> source

    Editable native method diagrams, exported as standalone SVG without external renderers. Coordinates have equal scales on both axes and y points upwards. Nodes own their labels, wrap words and size themselves from the plotting library's embedded Computer Modern font metrics. Text supports UTF-8 and explicit newlines (not TeX markup). Visible labels use native glyph outlines so viewers cannot substitute a differently sized font; selectable source text and accessible labels are retained. Unicode digit scripts, superscript plus/minus/T and script ell use native base glyphs. Other characters absent from the embedded font render as question marks; accessible labels retain the original text. Arrows join node boundaries. Paths, polygons, ellipses and free labels share one coordinate system. Export fits all primitives, labels, stroke widths and arrowheads, leaving a pixel margin. A diagram wider than max_width is scaled uniformly, retaining its aspect ratio. Mutation is not thread-safe; const export may be called concurrently on an unmodified object. Rendering and storage are linear in the number of primitives and their text/path lengths.

    Example
    dm::graphics::Diagram diagram;
diagram.node("input", {0, 0}, "Observations\ny")
       .node("fit", {5, 0}, "Least squares\nminimise residual")
       .edge("input", "fit")
       .text({2.5, -1.5}, "The residual is perpendicular to the design columns.");
diagram.save_svg("method.svg");
