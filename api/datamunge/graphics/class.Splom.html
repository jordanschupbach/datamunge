    Splom

    class Splom
    #include <datamunge/plot/splom.hpp> source

    A generalized pairs plot: every pair of variables drawn as one small panel in an n-by-n grid, choosing the panel type from the two variables' kinds.

    Numeric columns are quantitative variables and string columns are categorical variables. Panel (row i, column j) puts variable j on the horizontal axis and variable i on the vertical axis:

    • diagonal: kernel density curves, one per group_by() group (quantitative), or a single stacked bar of level counts (categorical), with the variable name above it;

    • quantitative vs quantitative, above the diagonal: the points with a nonparametric smooth of the mean (local linear regression, as R's loess(degree = 1)) and a 95% prediction band, one per group;

    • quantitative vs quantitative, below the diagonal: contours of a bivariate Gaussian kernel density estimate (MASS's kde2d()), one set per group in the group's color, drawn at the levels enclosing 25%, 50%, 75% and 95% of the estimated probability;

    • categorical vs quantitative: one violin (kernel density) per level, with the interquartile range and median marked; vertical when the categorical variable is on x, horizontal otherwise;

    • categorical vs categorical: a mosaic plot whose tiles are shaded by the Pearson residuals of a chi-squared test of independence (blue: more rows than expected, red: fewer; darker past |residual| 2 and 4, as in R's mosaicplot(shade = TRUE)), with the test's p-value on top.

    Rows with a missing value in either variable of a panel are dropped from that panel only. Rendering reuses the RPlot SVG and raster engines through an RLayout, so to_svg()/save()/ show() behave like any other plot.

    group_by

    #source
    Splom & group_by(const std::string & column, std::vector< RGB > palette = {})

    Splits the data into groups by the levels of string column column (GGally's ggpairs(mapping = aes(colour = g))), recycling palette over the sorted levels; an empty palette uses the default level palette.

    Each group gets its own color for points, its own density on the diagonal, its own smooth and prediction band above the diagonal, and its own density contours below it. When column is also a panel variable, its violins, bars and mosaic axis share these colors. The column must have been present in the frame passed to create(); rows with a missing group value are left out of the quantitative panels. Pass "" to clear the grouping. Clears point_colors().

    Throws
    std::invalid_argument

    If the column was not a string column of the source frame.
