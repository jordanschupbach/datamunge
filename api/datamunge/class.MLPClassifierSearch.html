    MLPClassifierSearch

    class MLPClassifierSearch
    #include <datamunge/datamunge.hpp> source

    A two-predictor MLP classifier with Bayesian hidden-width selection and a held-out test.

    Splits complete labelled data by class into 60% fitting, 20% validation and 20% test rows (per-class rounding applies). Four random widths followed by eight Gaussian-process expected-improvement proposals are the default search budget. Proposals in [min_hidden,max_hidden] are rounded to integer widths; repeated widths reuse their cached validation log loss. Smaller loss wins; ties retain the first proposal. Each candidate has one tanh hidden layer, softmax output, training-only standardization, SGD learning rate 0.05, batch size 32 and L2 penalty 0.0001. Initialization/shuffling use seed for every candidate.

    After selection the network is refitted on fitting plus validation rows, with new standardization statistics, then scored once on the untouched test. Validation loss belongs to the candidate fit, not the final refit, and is an optimistic selection score. Neither split nor test performance is a guarantee for other seeds or datasets. Owns all state, borrows inputs only during calls, does not change data or global RNG state. Const methods may run concurrently. Search cost is at most (initial_samples+iterations) fits plus one refit; cached repeats are cheaper. Prediction/plot costs follow MLPClassifier.

    Example
    const std::unique_ptr<dm::DataFrame> iris(dm::data::iris());
dm::MLPClassifierSearch fit(*iris, "Species", "Petal.Length", "Petal.Width");
const bool valid = fit.best_hidden_nodes() >= 2 && fit.best_hidden_nodes() <= 24; // true
    References

    • D. R. Jones, M. Schonlau and W. J. Welch (1998), Efficient Global Optimization of Expensive Black-Box Functions, https://doi.org/10.1023/A:1008306431147

    #source
    MLPClassifierSearch(
    const DataFrame & data,
    const std::string & response,
    const std::string & x_feature,
    const std::string & y_feature,
    std::size_t min_hidden = 2,
    std::size_t max_hidden = 24,
    std::size_t initial_samples = 4,
    std::size_t iterations = 8,
    std::size_t epochs = 400,
    std::uint64_t seed = 42)

    Tune a single hidden layer, refit on development rows and evaluate the test rows.

    Parameters
    data

    Borrowed labelled frame; unchanged. Every selected value must be present and finite.

    response

    String response column, with nonempty labels and at least five rows per class.

    x_feature

    First numeric predictor, distinct from response and y_feature.

    y_feature

    Second numeric predictor; these two are the only model inputs.

    min_hidden

    Smallest hidden width, default 2; at least 1 and below max_hidden.

    max_hidden

    Largest hidden width, default 24; at most 1000000.

    initial_samples

    Random initial proposals, default 4; at least 1.

    iterations

    Surrogate-guided proposals, default 8; zero permits initial design only.

    epochs

    SGD passes for each candidate and the final refit, default 400; at least 1.

    seed

    Local split/search/initialization seed, default 42; validation split uses seed+1 modulo 2^64.

    Throws
    std::invalid_argument

    For invalid columns, labels, nonfinite/missing data or search controls.

    std::runtime_error

    If fitting or scoring fails to produce finite probabilities.

    Example
    const std::unique_ptr<dm::DataFrame> iris(dm::data::iris());
dm::MLPClassifierSearch fit(*iris, "Species", "Petal.Length", "Petal.Width", 2, 24, 4, 8, 400, 42);
const auto n = fit.test_rows(); // 30

    plot_decision_regions

    #source
    datamunge::graphics::RPlot plot_decision_regions(std::size_t grid_resolution = 120) const

    Plot final predicted class regions and development observations in the predictor plane.

    Pale merged rectangles show the predicted class; saturated points show observed development labels in the same palette. Test rows are excluded. Axis ranges cover development points plus 10% padding, in original units. Rendering samples cell centers, so boundaries are a grid approximation.

    Parameters
    grid_resolution

    Cells per axis, default 120; at least 2.

    Returns

    Owned editable native plot; save it to an SVG/PNG file rather than printing XML.

    Throws
    std::invalid_argument

    If grid_resolution is less than 2.

    Example
    const std::unique_ptr<dm::DataFrame> iris(dm::data::iris());
dm::MLPClassifierSearch fit(*iris, "Species", "Petal.Length", "Petal.Width");
auto plot = fit.plot_decision_regions();
plot.save_svg("build/iris-mlp.svg");
