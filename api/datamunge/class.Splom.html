    Splom

    class Splom
    #include <datamunge/datamunge.hpp> source

    A scatterplot matrix (R's pairs(), GGally's ggpairs()) over the columns of a data frame, with chainable setters; the SWIG-friendly facade for graphics::Splom.

    Panel (row i, column j) puts variable j on x and variable i on y. The panel type follows the two variables' kinds (numeric columns are quantitative, string columns categorical):

    • diagonal: kernel density curves, one per group_by() group (numeric), or a stacked bar of level counts (string), titled with the variable name;

    • numeric vs numeric above the diagonal: the points with a local linear smooth of the mean and a 95% prediction band, one per group; point colors follow set_col() or group_by();

    • numeric vs numeric below the diagonal: bivariate kernel density contours, one set per group;

    • string vs numeric: one violin per level with the median and interquartile range marked;

    • string vs string: a mosaic shaded by chi-squared Pearson residuals, with its p-value.

    Values are copied at construction, so the frame need not outlive the matrix. Rows with a missing value in either variable are dropped from that panel only. Setters return Splom& for chaining; nothing is drawn until to_svg(), save(), or show(). The default figure is 960 by 960 pixels with blue {37, 99, 235} points of radius 2.5.

    Example
    const auto iris = dm::datasets::iris();
const auto species = dm::factor(dm::c(iris.get_column<std::string>("Species").values()));
const auto palette = dm::c(dm::RGB{255, 255, 80}, dm::RGB{100, 255, 255},
                           dm::RGB{220, 100, 255});
auto pairs = dm::Splom(iris).set_title("Iris Pairs").set_col(species, palette);
pairs.show();  // or pairs.save("iris_pairs.svg") without a display

    #source
    explicit Splom(
    const dstruct::DataFrame & data,
    const std::vector< std::string > & columns = std::vector< std::string >())

    Builds the matrix straight from a core frame, e.g. dm::Splom(dm::datasets::iris()).

    With columns empty, every numeric column is used, plus each string column that has between 1 and graphics::Splom::max_default_levels (12) distinct values; so iris gives a 5 by 5 grid including Species. Naming columns fixes both the selection and the panel order.

    Parameters
    data

    Source frame; its values are copied.

    columns

    Columns to include, in panel order; empty selects them automatically.

    Throws
    std::invalid_argument

    For a missing column, or fewer than two variables.

    Example
    const auto iris = dm::datasets::iris();
std::print("{}\n", dm::Splom(iris).variables());
// ["Sepal.Length", "Sepal.Width", "Petal.Length", "Petal.Width", "Species"]
auto petals = dm::Splom(iris, {"Petal.Length", "Petal.Width", "Species"});

    set_col

    #source
    Splom & set_col(const Vector< int > & factor, const Vector< datamunge::graphics::RGB > & palette)

    R's col = palette[f]: colors scatter points by factor (one-based codes from dm::factor(), one per row) using palette, e.g. dm::Splom(iris).set_col(dm::factor(species), palette). The categorical column the factor came from fills its violins and stacked bar with the same palette.

    Row i takes palette[(factor[i] - 1) % palette.size()]; a code below 1 (missing) uses the single color(). Replaces any earlier group_by()/point_colors()/set_col() choice.

    Parameters
    factor

    One level code per data row, as returned by dm::factor().

    palette

    Nonempty colors indexed by level code - 1, recycled when shorter.

    Returns

    This matrix, for chaining.

    Throws
    std::invalid_argument

    If factor's length is not the row count or palette is empty.

    Example
    const auto tooth = dm::datasets::tooth_growth();
const auto supp = dm::factor(dm::c(tooth.get_column<std::string>("supp").values()));
auto pairs = dm::Splom(tooth)
                 .set_title("ToothGrowth Pairs")
                 .set_col(supp, dm::c(dm::RGB{100, 255, 255}, dm::RGB{220, 100, 255}));
pairs.save("tooth_pairs.svg");

    group_by

    #source
    Splom & group_by(
    const std::string & column,
    const std::vector< datamunge::graphics::RGB > & palette = std::vector< datamunge::graphics::RGB >())

    Splits every numeric panel by the groups of string column column (GGally's ggpairs(aes(colour = group))); an empty palette uses the default level palette.

    The column need not be a panel variable but must be a string column of the source frame. Groups are its sorted distinct non-missing values, and group k takes palette[k % palette.size()]. Each group gets its own points, diagonal density, smooth and prediction band, and density contours; rows with a missing group are left out of those panels. When the column is also a panel variable its violins, bars, and mosaic axis share the colors. Pass "" to clear the grouping. Clears point_colors().

    Parameters
    column

    String column to group by, or "" to clear.

    palette

    Group colors in sorted-group order; empty uses the default.

    Returns

    This matrix, for chaining.

    Throws
    std::invalid_argument

    If column is not a string column of the source frame.

    Example
    auto pairs = dm::Splom(dm::datasets::iris()).group_by("Species");
std::print("{}\n", pairs.groups());  // ["setosa", "versicolor", "virginica"]
    See also

    groups(), set_col()

    panel

    #source
    datamunge::graphics::RPlot panel(std::size_t row, std::size_t col) const

    Builds the panel with variable col on x and variable row on y.

    The panel is a standalone dm::Plot sized to one grid cell, useful for inspecting or saving a single pair. Indices are zero-based positions in variables().

    Parameters
    row

    Zero-based index of the y variable.

    col

    Zero-based index of the x variable; equal to row gives the diagonal panel.

    Returns

    The rendered-on-demand panel plot.

    Throws
    std::out_of_range

    If either index is not below variables().size().

    std::invalid_argument

    If the panel has no complete rows to draw.

    Example
    const auto pairs = dm::Splom(dm::datasets::iris(), {"Sepal.Length", "Sepal.Width"});
pairs.panel(1, 0).save("sepal_scatter.svg");  // Sepal.Length on x, Sepal.Width on y

    show

    #source
    void show(const std::string & title_hint = "") const

    Opens the matrix in the interactive X11 viewer and blocks until the window closes.

    Zoom and pan act on every panel at once; q or Escape closes the window. Requires an X11-enabled build and a reachable display; use save() in headless code.

    Parameters
    title_hint

    Window title; empty uses the figure title, or "datamunge splom".

    Throws
    std::runtime_error

    If X11 is unavailable or the display cannot be opened.

    Example
    dm::Splom(dm::datasets::iris()).set_title("Iris Pairs").group_by("Species").show();
