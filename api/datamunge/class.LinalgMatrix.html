    LinalgMatrix

    class LinalgMatrix
    #include <datamunge/linalg/bindings.hpp> source

    Binding counterpart of Mat/SpMat with shared, immutable expression operands. Transpose, multiplication and inverse actions defer native computation until eval(), values() or text(). Handles keep temporary operands alive across garbage collection. Sparse products use CSR; solves use the canonical dense LU/QR implementation. Concurrent const evaluation is safe; no evaluation cache is mutated.

    Example
    dm::LinalgMatrix A({2, 0, 0, 4}, 2, 2), b({6, 8}, 2, 1);
auto x = A.inverse_action().multiply(b);
std::print("{:.0f}\n", x.values()[0]); // 3
