    class datamunge::rl::planning

    TransitionSet

    class TransitionSet
    #include <datamunge/rl/transition_data.hpp> source

    Append owning continuous transitions and sample source-compatible minibatches.

    Copies own their host rows. Add and Sample require external synchronization on a shared instance; Sample mutates the caller random engine. No optimizer or experiment is owned.

    Example
    dm::rl::planning::TransitionSet data;data.Add({1},{.5},{2},3);
std::mt19937_64 rng(0);auto batch=data.Sample(2,rng);

    Copy one finite transition after validating consistent bounded geometry.

    At most one million rows and64 million row*(observation+action) coordinates. Inconsistent/nonfinite input throws std::invalid_argument before rows are appended. Allocation failures propagate.

    Parameters
    st

    Nonempty observation, width at most one million; copied.

    at

    Nonempty action, width at most one million; copied.

    st2

    Successor with the same width as st; copied.

    rt

    Finite scalar reward.

    Example
    dm::rl::planning::TransitionSet data;data.Add({0},{.5},{1},2);

    Sample

    #source
    TransitionBatch Sample(int n, std::mt19937_64 & rng) const

    Draw an owning native minibatch with replacement using raw engine modulo.

    Throws std::invalid_argument for an empty dataset or invalid batch geometry. Modulo sampling deliberately preserves the original example stream rather than changing to a distribution adapter.

    Parameters
    n

    Batch size1..1000000; n*(observation+action) at most64 million.

    rng

    Borrowed engine; exactly n draws consumed.

    Returns

    New independent Float32 CPU tensors in state/action/next_state/reward order.

    Example
    dm::rl::planning::TransitionSet data;data.Add({0},{1},{2},3);
std::mt19937_64 rng(0);auto batch=data.Sample(1,rng);
