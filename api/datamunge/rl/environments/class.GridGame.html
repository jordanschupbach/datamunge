    class datamunge::rl::environments

    GridGame

    class GridGame : public datamunge::rl::environments::Game
    #include <datamunge/rl/environments/board_games.hpp> source

    Own the GridGame simulation state or interface.

    Instances own mutable board state and no RNG; concurrent access requires external synchronization. Returned observations own their values. Reset before stepping and after done. VecEnv owns its children; client calls remain serialized, while workers access distinct children.

    Example
    namespace e=dm::rl::environments;e::TicTacToe concrete;e::GridGame& obj=concrete;obj.Reset();
    References

    • Repository original local simulation protocol, preserved in docs/mepml/nn/6_deep_reinforcement_learning/6.1_environments/.
