    class datamunge::rl::environments

    EnvBase

    class EnvBase : public datamunge::rl::environments::Env
    #include <datamunge/rl/environments/interface.hpp> source

    Own the EnvBase simulation state or interface.

    Instances own mutable state and a local RNG; concurrent access to one instance requires external synchronization. Returned observations own their values. Reset before stepping and after done. VecEnv owns its children; client calls remain serialized, while workers access distinct children.

    Example
    namespace e=dm::rl::environments;e::CartPole concrete;e::EnvBase& obj=concrete;obj.reset(1);

    Construct EnvBase with independent owned simulation state.

    Parameters
    max_steps

    Nonnegative source time limit; zero means unlimited.

    Mutable operations advance only this instance or caller-supplied RNG. Borrowed references expire at owner destruction; storage-changing operations invalidate borrowed buffers. Invalid explicit bounds/actions throw std::invalid_argument or std::out_of_range before their checked access. VecEnv propagates worker exceptions after all in-flight tasks finish; some children may advance.
