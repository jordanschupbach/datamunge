    ActionSpace

    struct ActionSpace
    #include <datamunge/rl/environments/interface.hpp> source

    Own the ActionSpace simulation state or interface.

    This value owns its described fields; it has no global state or hidden random generator. Returned owning values remain valid after the source object is destroyed. Borrowed buffers require the owner to remain alive and expire when their storage changes.

    Example
    namespace e=dm::rl::environments;auto obj=e::ActionSpace::Discrete(2);

    static ActionSpace Discrete(int n)

    Create a discrete action space with positive action count.

    Parameters
    n

    Positive discrete action or environment count; vector pools accept1..4096.

    Returns

    Owning value or borrowed reference exactly as indicated by the return type; observation/state units follow the owning class.

    Mutable operations advance only this instance or caller-supplied RNG. Borrowed references expire at owner destruction; storage-changing operations invalidate borrowed buffers. Invalid explicit bounds/actions throw std::invalid_argument or std::out_of_range before their checked access. VecEnv propagates worker exceptions after all in-flight tasks finish; some children may advance.
