    class datamunge::rl::environments

    VecEnv

    class VecEnv
    #include <datamunge/rl/environments/vector.hpp> source

    Owned homogeneous environment batch with deterministic per-instance streams and persistent worker threads.

    Instances own mutable state and a local RNG; concurrent access to one instance requires external synchronization. Returned observations own their values. Reset before stepping and after done. VecEnv owns its children; client calls remain serialized, while workers access distinct children.

    Example
    namespace e=dm::rl::environments;e::VecEnv obj([]{return
std::make_unique<e::CartPole>();},2,1);obj.reset();

    VecEnv

    #source
    VecEnv(const Factory & factory, int n, uint64_t seed, int threads = 1)

    Construct VecEnv with independent owned simulation state.

    Parameters
    factory

    Nonempty callable producing a new non-null owned Env of matching observation/action geometry.

    n

    Positive discrete action or environment count; vector pools accept1..4096.

    seed

    UInt64 local generator seed; reset(seed) restarts this instance stream.

    threads

    Worker count in1..64, default1; capped at environment count.

    Mutable operations advance only this instance or caller-supplied RNG. Borrowed references expire at owner destruction; storage-changing operations invalidate borrowed buffers. Invalid explicit bounds/actions throw std::invalid_argument or std::out_of_range before their checked access. VecEnv propagates worker exceptions after all in-flight tasks finish; some children may advance.

    Throws
    std::invalid_argument

    Invalid checked bounds, geometry or action.

    Example
