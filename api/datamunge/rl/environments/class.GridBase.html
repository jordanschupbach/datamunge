    class datamunge::rl::environments

    GridBase

    class GridBase : public datamunge::rl::environments::TabularEnv
    #include <datamunge/rl/environments/grid_world.hpp> source

    Own the GridBase simulation state or interface.

    Instances own mutable state and a local RNG; concurrent access to one instance requires external synchronization. Returned observations own their values. Reset before stepping and after done. VecEnv owns its children; client calls remain serialized, while workers access distinct children.

    Example
    namespace e=dm::rl::environments;e::GridWorld concrete;e::GridBase& obj=concrete;obj.reset(1);
    References

    • Gymnasium environment API and classic-control source: https://gymnasium.farama.org/api/env/ ; https://github.com/Farama-Foundation/Gymnasium/tree/main/gymnasium/envs/classic_control .
