    AtariFrameStack

    class AtariFrameStack
    #include <datamunge/rl/environments/atari_frames.hpp> source

    Own four source-preprocessed grayscale frames without an emulator dependency.

    Frame-major Float32 observations scale bytes by255. Integer box averages use source floor division, including upsampling by nearest source cell. Copies own independent frame deques. Mutations require external synchronization. RGB conversion and emulator frame skipping belong to the caller.

    Example
    dm::rl::environments::AtariFrameStack frames(2,2);
for(int i=0;i<4;++i)frames.PushFrame({0,64,128,255});auto obs=frames.StackedObs();
    References

    • Mnih et al. (2015), Human-level control through deep reinforcement learning, https://doi.org/10.1038/nature14236 ; source integer box-filter resize variant retained.

    void PushFrame(const std::vector< unsigned char > & gray)

    Box-average a source screen and append its owning84-square bytes.

    Keeps only the last four frames. Coordinates and truncating integer averages preserve the source protocol. Borrowed previous last_frame references may be invalidated.

    Parameters
    gray

    Borrowed row-major bytes with exactly raw_w*raw_h entries.

    Throws
    std::invalid_argument

    Example
