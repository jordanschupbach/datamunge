    LunarLander

    class LunarLander : public datamunge::rl::environments::EnvBase
    #include <datamunge/rl/environments/lunar_lander.hpp> source

    Source simplified lunar-landing environment with point-mass rotational physics.

    Eight Float32 observation coordinates are x,y,vx,vy,angle,angular velocity and two identical ground contacts. Semi-implicit Euler uses dt.02, gravity1.6 and source thrust/fuel constants. This is not Box2D/Gym physics. Copies own state/RNG; callers synchronize mutation. No episode/controller loop is owned.

    Example
    dm::rl::environments::LunarLander env;auto start=env.reset(0);auto next=env.step(0);
    References

    • Gymnasium LunarLander reward/interface reference, https://gymnasium.farama.org/environments/box2d/lunar_lander/ ; source hand-written point-mass protocol retained.

    step

    #source
    virtual StepResult step(const Action & action) override

    Advance source physics, shaping and independent episode-end flags.

    A gentle touchdown has |vy|<.5, |vx|<.5 and |angle|<.3, and requires |x|<=.25 for landing. Landing adds100; crash subtracts100. Terminal steps short-circuit CountStep as in source. No automatic reset is performed.

    Parameters
    action

    Discrete thruster index0..3; validated before mutation.

    Returns

    Owning next observation, shaped reward minus fuel, terminal/truncated flags.

    Throws
    std::invalid_argument

    Action descriptor is incompatible or out of range.

    Example
    dm::rl::environments::LunarLander env;auto start=env.reset(0);auto next=env.step(0);
