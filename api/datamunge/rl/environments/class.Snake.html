    class datamunge::rl::environments

    Snake

    class Snake : public datamunge::rl::environments::EnvBase
    #include <datamunge/rl/environments/snake.hpp> source

    Local snake teaching game with three binary observation planes and starvation truncation.

    Instances own mutable state and a local RNG; concurrent access to one instance requires external synchronization. Returned observations own their values. Reset before stepping and after done. VecEnv owns its children; client calls remain serialized, while workers access distinct children.

    Example
    namespace e=dm::rl::environments;e::Snake obj;obj.reset(1);
    References

    • Repository original local simulation protocol, preserved in docs/mepml/nn/6_deep_reinforcement_learning/6.1_environments/.

    • Sutton and Barto (2018), Reinforcement Learning, second edition, http://incompleteideas.net/book/the-book-2nd.html .
