    class datamunge::rl::environments

    WorldPixelCartPole

    class WorldPixelCartPole : public datamunge::rl::environments::Env
    #include <datamunge/rl/environments/planning_tasks.hpp> source

    Native CartPole observed through the source binary12-by24 renderer.

    Physics, rewards, termination and random stream are delegated to owned CartPole. Rendering creates owning row-major observations; copies own physics. Mutating calls require synchronization.

    Example
    dm::rl::environments::WorldPixelCartPole env;auto frame=env.reset(0);
    See also

    CartPole, Render()

    Used in reports

    Render

    #source
    static Obs Render(const Obs & state)

    Rasterize a finite four-coordinate source CartPole observation.

    Three cart pixels occupy the bottom row; ten pole samples project sin(angle). Rounded cart coordinate is clamped before integer conversion. Invalid width/nonfinite coordinates throw std::invalid_argument.

    Parameters
    state

    Finite[x,velocity,angle,angular_velocity]; only x and angle affect pixels.

    Returns

    Owning288-element vector with values0 or1, row-major.

    Example
    auto frame=dm::rl::environments::WorldPixelCartPole::Render({0,0,0,0});
