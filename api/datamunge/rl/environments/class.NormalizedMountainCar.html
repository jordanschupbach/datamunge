    NormalizedMountainCar

    class NormalizedMountainCar : public datamunge::rl::environments::Env
    #include <datamunge/rl/environments/normalized_mountain_car.hpp> source

    Affine observation adapter for the source native mountain-car task.

    Maps[position,velocity] to[(position+.3)/.9,velocity/.07] in Float32. The owning inner MountainCar retains source force/gravity, goal, rewards and200-step limit. Copies own independent physical state/RNG; this adapter changes observations, not dynamics or reward.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
e::NormalizedMountainCar env;auto row=env.reset(1);auto step=env.step(1);
    References

    • Sutton and Barto (2018), Chapter13, http://incompleteideas.net/book/the-book-2nd.html; Schulman et al. (2016), Generalized Advantage Estimation, https://arxiv.org/abs/1506.02438 .

    #source
    static Obs Scale(const Obs & o)

    Transform one finite source observation with the exact Float32 affine map.

    Does not clip values outside the physical state box.

    Parameters
    o

    Two finite Float32 coordinates[position,velocity].

    Returns

    Owning scaled two-coordinate vector; input unchanged.

    Throws
    std::invalid_argument

    Nonfinite values, incompatible geometry or explicit bounds are invalid.
