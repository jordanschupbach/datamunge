    datamunge/rl/discrete.hpp

    Classes

    DiscreteEnvironmentBorrowed single-writer callbacks; their owners must outlive train_discrete(). Neither callback may mutate a policy concurrently. Exceptions propagate after any already completed progress. Reset seeds are derived independently of action draws.
    DiscreteModelArchitecture and initialization for a native CPU policy.
    DiscreteObservationOwned observation with finite features, a binary feasibility mask and optional table row. Masks have exactly model.actions entries and at least one allowed action, except a true terminal successor may have none. No true class/future state is required.
    DiscretePolicyOwned inference policy; copies require clone(), which never shares learnable storage. Neural scores are native nn tensors internally. Inference is single-writer; optimizer/replay/RNG training state is not part of an inference checkpoint.
    DiscreteTrainingOptionsMatched-window controls for tabular, replay-based and on-policy learning. Checkpoints occur at powers of two from window 128 and at completion. The trainer bootstraps time-limit/window boundaries, never true terminal states. Forced-action chains can be coalesced with exact composed reward/discount; every underlying environment step still runs and sees new arrivals.
    DiscreteTrainingResultTraining evidence and independent inference checkpoints, without optimizer resumption.
    DiscreteTransitionOne actual environment option, preserving terminal versus time-limit semantics.
    DiscreteWindowComplete measured work for one independent training window.

    Functions

    train_discrete()Train masked Q(lambda), Double DQN, dueling Double DQN or clipped PPO in native C++. Uses CPU nn autograd/Adam for neural methods, uniform replay with a hard target network and Huber loss for DQN, and stored behavior log-probabilities, elapsed- time GAE, clipped ratios, value loss and entropy for PPO. Truncations bootstrap from the actual final observation and cut GAE/reset traces. No environment labels or future observations are inferred by the trainer. Single-writer only.

    enum class DiscreteMethod

    Discrete controllers sharing observation, masking, discount and checkpoint contracts.

    Example
    auto method=dm::rl::DiscreteMethod::DoubleDqn;
    EnumeratorValueDescription
    QLambda

    Tabular off-policy Q-learning with replacing Watkins eligibility traces.

    DoubleDqn

    Replay/target-network Double DQN with a two-layer ReLU MLP.

    DuelingDoubleDqn

    Double DQN with shared features and separate value/advantage heads.

    Ppo

    Clipped categorical PPO with a shared tanh trunk, value head and GAE.
