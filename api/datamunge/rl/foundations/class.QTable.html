    QTable

    class QTable
    #include <datamunge/rl/tabular.hpp> source

    Own a caller-updated action-value table in native Float32 CPU tensor storage.

    Copies clone storage; moves transfer it and invalidate checked access on the source. No optimizer, learning rule or rollout is owned. Scalar/row references borrow storage until assignment, move or destruction. tensor() returns an independent owning copy. Concurrent mutation requires a caller lock.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
f::QTable q(3,2);q(0,1)=.5f;auto snapshot=q.tensor();
    References

    • Sutton and Barto (2018), Reinforcement Learning, second edition, http://incompleteideas.net/book/the-book-2nd.html .
