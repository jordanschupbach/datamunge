    EpisodicNovelty

    class EpisodicNovelty
    #include <datamunge/rl/episodic_novelty.hpp> source

    Score novelty relative to a memory of states visited this episode.

    An episode uses a frozen embedding table. Each observation contributes its nearest squared distances to a running mean that persists through resets. A kernel sum over the normalized distances estimates local density. The bonus is the inverse square root of that density with a small offset in the denominator.

    Example
    dm::rl::EpisodicNovelty novelty;
novelty.reset(dm::nn::eye(2),0);
const auto fresh=novelty.observe(1);
std::print("{}\n",fresh>novelty.observe(1)); // true
    References

    • Badia et al. (2020), Never Give Up: Learning Directed Exploration Strategies. https://arxiv.org/abs/2002.06038
