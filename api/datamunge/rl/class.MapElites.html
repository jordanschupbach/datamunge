    class datamunge::rl

    MapElites

    class MapElites
    #include <datamunge/rl/map_elites.hpp> source

    Retain the highest-scoring candidate in each behavior bin.

    Both behavior axes are regularly spaced and start at zero. Values at or above an axis's upper boundary enter its final bin. Earlier arrivals win exact score ties. The archive owns each candidate's parameter vector.

    Example
    dm::rl::MapElites archive({8,8},{0.25,0.15});
const auto [cell,replaced]=archive.insert({0.5,0.15},-2.,{0.,1.});
std::print("{}\n",cell); // 17
    References

    • Mouret and Clune (2015), Illuminating search spaces by mapping elites. https://arxiv.org/abs/1504.04909

    Functions

    insert

    #source
    std::pair< std::size_t, bool > insert(std::array< double, 2 > behavior, double score, std::vector< double > parameters)

    Compare a candidate with the incumbent in its behavior cell.

    Parameters
    behavior

    Finite nonnegative descriptor values.

    score

    Finite objective to maximize.

    parameters

    Candidate parameter vector, moved into the cell on improvement.

    Returns

    Flattened cell index and whether the candidate became its elite.

    Throws
    std::invalid_argument

    Nonfinite score or invalid descriptor.

    std::overflow_error

    The insertion stream exhausted its index range.

    Example
    dm::rl::MapElites archive({2,2},{1.,1.});
archive.insert({0.,0.},2.,{0.5});
const auto [cell,replaced]=archive.insert({0.,0.},1.,{1.});
std::print("{}\n",replaced); // false
