    DiscreteTrainingOptions

    struct DiscreteTrainingOptions
    #include <datamunge/rl/discrete.hpp> source

    Matched-window controls for tabular, replay-based and on-policy learning. Checkpoints occur at powers of two from window 128 and at completion. The trainer bootstraps time-limit/window boundaries, never true terminal states. Forced-action chains can be coalesced with exact composed reward/discount; every underlying environment step still runs and sees new arrivals.

    Example
    dm::rl::DiscreteTrainingOptions options; options.windows=2048;
options.model.method=dm::rl::DiscreteMethod::DuelingDoubleDqn;
