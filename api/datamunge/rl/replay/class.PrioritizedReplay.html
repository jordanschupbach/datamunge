    PrioritizedReplay

    class PrioritizedReplay
    #include <datamunge/rl/replay.hpp> source

    Source sum-tree proportional replay with stratified sampling and importance weights.

    Copies own independent tree and experiences. New rows receive the maximum historical transformed priority. Sampling uses one Float32 uniform per stratum. Weight normalization uses the sampled batch maximum, not a full-buffer maximum. Concurrent writes or sample/write races require caller synchronization.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
dm::rl::replay::PrioritizedReplay buffer(8,2);

    Sample

    #source
    Batch Sample(int n, float beta, std::mt19937_64 & rng) const

    Sample stratified proportional replay with source Float32 importance weights.

    Each stratum spans total_mass/n. Exact-zero draws cannot select a zero-mass empty leaf. Caller refreshes priorities after computing its own learning errors.

    Parameters
    n

    Positive batch count at most1million; replay must be nonempty.

    beta

    Finite correction exponent in[0,1].

    rng

    Caller engine advanced by one Float32 uniform draw per sampled row.

    Returns

    Owning native Batch with weights(N*p)^(-beta), normalized by sampled maximum.

    Throws
    std::invalid_argument

    Nonfinite values, incompatible geometry or explicit bounds are invalid.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
dm::rl::replay::PrioritizedReplay
buffer(8,2);buffer.Add({{0,1},0,1,{1,2},0,{}});std::mt19937_64 rng(1);auto
sample=buffer.Sample(2,.4f,rng);

    UpdatePriorities

    #source
    void UpdatePriorities(const std::vector< int > & indices, const std::vector< float > & td_abs)

    Refresh caller-selected priorities in the supplied update order.

    All indices/errors are validated before mutation. Priorities are(abs_td+1e-6)^alpha. Maximum historical transformed priority never decreases, including after overwritten slots.

    Parameters
    indices

    Aligned valid stored positions; repeated indices are allowed, last update wins.

    td_abs

    Aligned finite nonnegative errors; transformed masses must leave total Float32 mass representable.

    Throws
    std::invalid_argument

    Nonfinite values, incompatible geometry or explicit bounds are invalid.

    Example
    namespace n=dm::nn;namespace f=dm::rl::foundations;namespace e=dm::rl::environments;
dm::rl::replay::PrioritizedReplay
buffer(8,2);buffer.Add({{0,1},0,1,{1,2},0,{}});buffer.UpdatePriorities({0},{2});
