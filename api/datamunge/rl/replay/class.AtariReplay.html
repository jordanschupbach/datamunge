    class datamunge::rl::replay

    AtariReplay

    class AtariReplay
    #include <datamunge/rl/atari_replay.hpp> source

    Bounded ring of Atari transitions with shared immutable byte frames. AtariFrameStack observations survive packing and unpacking exactly. The source and successor stacks retain their frame order, including across resets. Sampling draws ring slots with replacement, using the ordinary replay order.

    Example
    dm::rl::replay::AtariReplay buffer(32);
dm::rl::environments::Obs pixels(4*84*84,0.f);
buffer.Add({pixels,0,0.f,pixels,0.f,{}});
std::mt19937_64 rng(0);
const auto batch=buffer.Sample(1,rng);
    See also

    ReplayBuffer, environments::AtariFrameStack
