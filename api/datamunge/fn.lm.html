    function datamunge

    lm

    #include <datamunge/datamunge.hpp>
    #source
    template<class... Args, std::enable_if_t< std::is_constructible_v< LM, Args &&... >, int > = 0>
LM lm(Args &&... args)

    Fit and return an LM using the lowercase, R-style lm() spelling. Forwards constructor arguments without changing fitting or ownership. Accepts (data, formula[, weights_column]), (y, dense_predictors[, intercept]) or (y, sparse_predictors[, intercept[, options]]). Matrix fits add an intercept by default. Sparse inputs retain CSR storage and the constructor's solver defaults. Lazy responses are materialised at the LM constructor boundary; the returned model owns the data needed for prediction after inputs expire.

    Template parameters
    Args

    Arguments accepted by an LM constructor, including optional settings.

    Parameters
    args

    Constructor arguments, forwarded with their original value categories.

    Returns

    Owned LM value, equivalent to constructing LM with the same arguments.

    Throws
    std::invalid_argument

    For invalid shapes, formulas, data or solver settings.

    std::runtime_error

    For rank deficiency or solver failure, as in LM.

    Example
    const auto y = dm::c(1, 3, 5, 7) + 0;
const auto fit = dm::lm(y, dm::SpMat<>{{0}, {1}, {2}, {3}});
std::print("{:.0f}\n", fit.predict(dm::SpMat<>{{4}})[0]); // 9
const auto data = dm::DataFrame(dm::Mat<>{{0, 1}, {1, 3}, {2, 5}, {3, 7}}, {"x", "y"});
const auto formula_fit = dm::lm(data, "y ~ x");
std::print("{:.0f}\n", formula_fit.predict(dm::DataFrame(dm::Mat<>{{4}}, {"x"}))[0]); // 9
