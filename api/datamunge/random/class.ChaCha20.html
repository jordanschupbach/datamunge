    class datamunge::random

    ChaCha20

    class ChaCha20 : public datamunge::random::RandomGenerator
    #include <datamunge/random/random.hpp> source

    Buffered RFC 8439 ChaCha20 engine emitting little-endian 64-bit words. Uses a fixed 256-bit key, 96-bit nonce and checked 32-bit block counter. Eight next_u64() calls consume one 64-byte block; unused words remain buffered. The counter never carries into the nonce. Copies preserve raw position and the inherited normal() cache: copying duplicates a stream, not an independent key. Separate instances share no state; concurrent mutation needs external locking. Raw calls take constant amortised time/storage with no allocation. This wrapper supplies no entropy acquisition, nonce management, authentication, reseeding, backtracking resistance, key erasure or machine-code constant-time assurance. Public fixed keys are for conformance checks; a 64-bit seed is for simulation.

    Example
    dm::random::ChaCha20 rng(std::array<std::uint32_t,8>{});
std::print("{:016x}\n",rng.next_u64()); // 903df1a0ade0b876
    References

    • Y. Nir and A. Langley (2018), RFC 8439, Sections 2.3-2.4, https://www.rfc-editor.org/rfc/rfc8439.html; word buffering is this wrapper.

    #source
    ChaCha20(
    const std::array< std::uint32_t, 8 > & key,
    const std::array< std::uint32_t, 3 > & nonce = {},
    std::uint32_t initial_counter = 0)

    Start a fixed-key, fixed-nonce stream at the requested RFC block counter. Words are values, not host-endian byte buffers: each serializes least- significant byte first. Owns copies of all inputs; all bit patterns are accepted. No entropy, uniqueness or key quality is checked. The default zero nonce/counter enables reproducible tests; callers manage stream reuse. No allocation; input arrays are unchanged.

    Parameters
    key

    Eight uint32 words comprising the 256-bit key in RFC order.

    nonce

    Three uint32 words comprising the 96-bit nonce, default all zero.

    initial_counter

    First block number, default zero; UINT32_MAX allows eight words.

    Example
    dm::random::ChaCha20 rng(std::array<std::uint32_t,8>{},{},0xffffffffU);
std::print("{}\n",rng.remaining_u64()); // 8

    virtual std::uint64_t next_u64() override

    Consume two buffered 32-bit words as low | (high << 32), refilling as needed. Refills use the canonical twenty-round permutation and feed-forward, preserving valid-range legacy outputs. The final counter's full eight-word block is usable; a later call throws before mutation. Leaves normal()'s cached draw intact. Amortised O(1) time, constant storage, no allocation in successful calls.

    Returns

    Next little-endian uint64, advancing raw position by exactly one word.

    Throws
    std::length_error

    If no raw words remain at the fixed key/nonce.

    remaining_u64

    #source
    std::uint64_t remaining_u64() const noexcept

    Read the number of still available raw uint64 draws, including the buffered tail. Does not generate a block, mutate state or inspect/reset the normal cache. Initially 8*(2^32-initial_counter), at most 2^35. A distribution sampler can consume multiple raw words or a cached normal value, so this is not a count of remaining distribution calls. O(1), no allocation; concurrent reads need no concurrent mutation of this instance.

    Returns

    Remaining raw draws, zero only after the final block is consumed.

    Example

std::print("{}\n",rng.remaining_u64()); // 16
