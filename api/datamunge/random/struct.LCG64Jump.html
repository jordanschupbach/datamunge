    struct datamunge::random

    LCG64Jump

    struct LCG64Jump
    #include <datamunge/random/linear_congruential_analysis.hpp> source

    Owned actual logarithmic affine-power evaluation, separate from any engine mutation. This evaluates affine composition, not count raw steps. Stages are actual composition evidence, not a fabricated raw-word trajectory. All products/adds use defined unsigned wrap; no modular inverse/division by a-1 is required.

    Example
    const auto j=dm::random::lcg64_jump(1,5,3,3);
std::print("{}\n",j.after); // 218
    References

    • Hull and Dobell(1962), Random Number Generators, SIAM Review4(3),230–254, https://doi.org/10.1137/1004061.

    See also

    lcg64_trace(), lcg64_jump(), lcg64_low_bits_orbit()
