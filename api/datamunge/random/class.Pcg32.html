    class datamunge::random

    Pcg32

    class Pcg32 : public datamunge::random::RandomGenerator
    #include <datamunge/random/random.hpp> source

    PCG XSH-RR with 64-bit state and odd selectable increment. Two consecutive 32-bit outputs form each next_u64(), first in the high half. Stream selectors differing only in bit63 alias after doubling; different streams are not claimed statistically independent. Each odd-increment state transition has period 2^64. Deterministic simulation use, not cryptography. Instances own state; copies continue identically, including inherited caches. Concurrent mutation of one instance requires external synchronisation.

    Example
    dm::random::Pcg32 a(42,54),b(42,54);std::print("{}\n",a.next_u64()==b.next_u64()); // true
    References

    • M. E. O'Neill, PCG reference implementation, https://www.pcg-random.org/download.html
