    discard

    #source
    void discard(std::uint64_t steps)

    Advances the generator by steps outputs in \(O(k^2)\) time, without producing them.

    Uses the closed form \(Y_j^{(n)} = \sum_{m=0}^{j} \binom{n+j-m-1}{j-m} Y_m^{(0)} \bmod 2^{64}\), with the binomial coefficients computed exactly modulo \(2^{64}\) (powers of two are tracked separately and odd denominators inverted). The result equals calling next_u64() steps times.

    Example
    dm::random::Acorn64 a(7), b(7);
a.discard(1'000'000'000'000);   // instant
