    class datamunge::random

    LinearCongruential64

    class LinearCongruential64 : public datamunge::random::RandomGenerator
    #include <datamunge/random/random.hpp> source

    Full-period mixed unsigned64 affine generator with explicit raw transition evidence. Recurrence x_next=a*x+c modulo2^64, returning the updated state. Constructor requires a=1 modulo4 and odd c, exactly the mixed full-period conditions for this modulus. Any seed is valid, including0. The period theorem is not an empirical traversal of2^64 states, independence or cryptographic security. Low bits have short autonomous periods; all raw outputs are predictable from known state/parameters. Copies own raw state and inherited normal() spare cache. Raw next calls leave that cache unchanged, matching other engines. O(1) raw step/time/storage; separate instances share no mutable state, concurrent mutation requires synchronization. Default constants are not a quality proof.

    Example
    dm::random::LinearCongruential64 g(1,5,3);
const auto a=g.next_u64(),b=g.next_u64(),c=g.next_u64();
std::print("{} {} {}\n",a,b,c); // 8 43 218
    References

    • Hull and Dobell(1962), Random Number Generators, https://doi.org/10.1137/1004061.
