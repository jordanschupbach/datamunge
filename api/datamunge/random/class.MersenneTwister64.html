    class datamunge::random

    MersenneTwister64

    class MersenneTwister64 : public datamunge::random::RandomGenerator
    #include <datamunge/random/random.hpp> source

    MT19937-64: a 312-word simulation engine with period 2^19937-1. Scalar seeding and every raw output match std::mt19937_64. The recurrence updates in place in increasing index order, with an invertible output temper. Period refers to the nonzero effective recurrent state, not to a short test, all arbitrary restored arrays, or 19968 independent stored bits. A scalar seed chooses at most 2^64 streams. This is not a cryptographic generator. Instances own state; copying preserves both raw position and the inherited normal() cache. Separate instances share no state; concurrent mutation of one instance needs external synchronisation. Construction/refill cost O(312); next_u64() is O(1) amortised, with 312 stored 64-bit words plus metadata/cache.

    Example
    dm::random::MersenneTwister64 rng(5489);
std::print("{}\n",rng.next_u64()); // 14514284786278117030
    References

    • M. Matsumoto and T. Nishimura (1998), Mersenne Twister: A 623-dimensionally equidistributed uniform pseudo-random number generator (32-bit original), https://doi.org/10.1145/272991.272995

    • Authors' distinct 64-bit version, https://math.sci.hiroshima-u.ac.jp/m-mat/MT/emt64.html

    • C++ specification, https://eel.is/c++draft/rand.predef

    from_output_block

    #source
    static MersenneTwister64 from_output_block(const std::array< std::uint64_t, 312 > & outputs)

    Recover a raw continuation from one complete aligned block of outputs. Untempers exactly 312 full 64-bit outputs and sets index to 312, ready for the next refill. The caller supplies an uninterrupted block starting just after a refill. Alignment is not inferred or checked; this is not seed recovery and does not recover a normal-distribution cache. No input is mutated. O(312) work/storage, no allocation, fresh empty normal cache. Arbitrary arrays define a deterministic continuation but need not be valid seeded states; all-zero outputs deliberately produce a degenerate zero stream.

    Parameters
    outputs

    Exactly one aligned block in generation order, not floating samples.

    Returns

    Owned engine positioned immediately after that block.

    Example
    dm::random::MersenneTwister64 source(42);
std::array<std::uint64_t,312> block{};
for(auto& word:block)word=source.next_u64();
auto clone=dm::random::MersenneTwister64::from_output_block(block);
std::print("{}\n",source.next_u64()==clone.next_u64()); // true
