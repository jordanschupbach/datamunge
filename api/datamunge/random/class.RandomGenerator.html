    class datamunge::random

    RandomGenerator

    class RandomGenerator
    #include <datamunge/random/random.hpp> source

    Common distribution samplers driven by a deterministic raw-word interface. Instances own a cached Box-Muller normal spare; copying an engine also copies that cache and duplicates the stream. Distribution calls may consume zero (cached normal), one, or multiple (rejection/retry) raw words. Mutating one instance concurrently requires external synchronization. Floating results use the host libm; raw deterministic sequences do not guarantee cross-libm bitwise transcendental results. No entropy, independence or security claim follows from sampling.

    Example
    dm::random::SplitMix64 rng(42);
std::print("{}\n",rng.uniform_u64(7,7)); // 7
    References

    • D. Lemire (2019), https://doi.org/10.1145/3230636; Box and Muller (1958), https://doi.org/10.1214/aoms/1177706645

Full unsigned interval returns one raw word directly; a singleton still consumes one raw word.
