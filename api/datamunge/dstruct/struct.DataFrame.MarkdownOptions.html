    DataFrame::MarkdownOptions

    struct MarkdownOptions
    #include <datamunge/dstruct/dataframe.hpp> source

    Formatting choices for to_md(), in the spirit of knitr::kable().

    Numbers are printed with at most digits decimals. Within a column every number gets the same number of decimals: the fewest (up to digits) that show each value exactly, so a column of counts prints as 50, a column of 5.1, 4.9, ... prints with one decimal, and a column of means prints with digits decimals.

    Example
    DataFrame::MarkdownOptions opts;
opts.digits = 2;
opts.column_digits = {{"p.value", 4}};
opts.scientific = {"eigenvalue"};
std::print("{}\n", frame.to_md(opts));
