    DataFrame::Row

    struct Row
    #include <datamunge/dstruct/dataframe.hpp> source

    A snapshot of one row: each column name mapped to its cell (null, double or string).

    Rows are what filter()/dm::filter_rows() predicates and dm::mutate()/mutate_with() row callables receive; DataFrame::row(i) also returns one. A Row is an independent copy, so it stays valid after the frame changes. The typed getters must match the column's type: get_double() for numeric columns and get_string() for string columns.

    Example
    const auto tooth = dm::datasets::tooth_growth();
const auto row = tooth.row(0);
std::print("{} {} {}\n", row.get_double("len"), row.get_string("supp"),
           row.get_double("dose"));   // 4.2 VC 0.5
    See also

    DataFrame::filter(), dm::filter_rows(), dm::mutate()

    get_double

    #source
    double get_double(const std::string & column_name) const

    The value of a numeric cell.

    Use this inside filter/mutate callbacks on columns without nulls; for nullable columns (e.g. penguins' measurements) use get_optional_double() or check is_null() first.

    Parameters
    column_name

    Name of a numeric column.

    Returns

    The cell's value.

    Throws
    std::out_of_range

    if the row has no such column.

    std::bad_variant_access

    if the cell is null or the column is a string column.

    Example
    const auto tooth = dm::datasets::tooth_growth();
const auto high_dose = tooth
  | dm::filter_rows([](const auto& row) { return row.get_double("dose") >= 1; });
std::print("{}\n", high_dose.nrows());   // 40
