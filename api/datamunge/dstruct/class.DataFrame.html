    DataFrame

    class DataFrame
    #include <datamunge/dstruct/dataframe.hpp> source

    Column-oriented table of named numeric (double) and string columns with nulls, in the spirit of R's data.frame/tibble and pandas' DataFrame.

    Every column is a NullableColumn of the same length (nrows()); column order is preserved. Most operations are non-mutating and return a new frame (head(), filter(), mutate(), arrange(), select(), join(), group_by() + summarise_each(), ...), so they chain either as methods or through the dplyr-style | verbs in pipe.hpp. Copies are deep (value semantics). std::print("{}", frame) prints a Markdown-style table (see format.hpp) with nulls as NA, and dm::info(frame) gives a per-column summary.

    Example
    const auto tooth = dm::datasets::tooth_growth();
std::print("{}\n", tooth.head(3));   // DataFrame[3 x 3]: len, supp, dose
const auto summary = tooth
  | dm::filter_rows([](const auto& row) { return row.get_double("dose") >= 1; })
  | dm::group_by("supp", "dose")
  | dm::summarise_each(dm::mean);   // 4 x 3

    summarise

    #source
    DataFrame summarise(const std::vector< std::string > & key_columns, const std::vector< AggSpec > & specs) const

    General dplyr::summarise()-style aggregation: one output row per distinct combination of key_columns, with one output column per AggSpec. See also group_by(), which returns a GroupedDataFrame wrapping this same method.

    Groups appear in order of first appearance (dplyr sorts them); null keys form their own group. Per AggSpec:

    • Sum, Mean, Min, Max, Median, StdDev skip nulls (R na.rm = TRUE); a group with no non-null values gets a null. Median averages the two middle values for an even count. StdDev is the sample standard deviation (n - 1 denominator, like R sd()), but a group with one non-null value gets 0 where R gives NA.

    • Min and Max also work on string columns (lexicographic) and give a string column.

    • Count is the group's row count (nulls included); column is ignored.

    • NDistinct counts distinct values, with a null counted once (dplyr::n_distinct()).

    Output columns are named by AggSpec::result_name, else column, else "n" for Count. This frame is not modified.

    Parameters
    key_columns

    Grouping columns, at least one.

    specs

    Aggregations, at least one; one output column each, in this order.

    Returns

    One row per group: the key columns, then one column per spec.

    Throws
    std::invalid_argument

    if key_columns or specs is empty, a numeric-only aggregation is applied to a string column (only raised for a group that has a non-null value), or two output names collide (including with a key column).

    std::out_of_range

    if a key or spec column does not exist.

    Example
    using DataFrame = dm::dstruct::DataFrame;
const auto penguins = dm::datasets::penguins();
const auto stats = penguins.summarise({"species"}, {
    {"body_mass_g", DataFrame::AggFunc::Median, "median_mass"},
    {"body_mass_g", DataFrame::AggFunc::StdDev, "sd_mass"},
    {"island", DataFrame::AggFunc::NDistinct, "islands"},
    {"", DataFrame::AggFunc::Count, ""}});
std::print("{}\n", stats);   // 3 x 5: species, median_mass, sd_mass, islands, n
                             // Adelie: 3700, 458.566, 3, 152

    join

    #source
    DataFrame join(
    const DataFrame & right,
    const std::string & left_key,
    const std::string & right_key,
    const JoinType join_type = JoinType::Inner,
    const std::string & left_suffix = "_x",
    const std::string & right_suffix = "_y") const

    Single-key relational join with right, like dplyr's inner_join(), left_join(), right_join(), full_join(), semi_join() and anti_join() (or pandas merge()).

    Keys match on cell equality: a numeric key never matches a string key, and a null key matches a null key (dplyr's default na_matches = "na"). Each left row is paired with every matching right row, in right's row order, so duplicates multiply. Output rows follow left's order; Right/Full joins then append unmatched right rows in right's order, with nulls on the left side. Columns are left's (key included) followed by right's. When left_key equals right_key the key appears once and is filled from right for unmatched right rows; otherwise both key columns are kept, and the left key stays null on unmatched right rows (dplyr would coalesce them). Uses a hash table on right's key: expected O(rows of both + output rows). Neither frame is modified.

    Parameters
    right

    Frame to join with.

    left_key

    Key column in this frame.

    right_key

    Key column in right.

    join_type

    One of Inner/Left/Right/Full/Semi/Anti (default Inner). Semi/Anti keep only left's rows (matched / unmatched respectively) and never merge in right's columns. For the others, any column name present in both frames (other than the key column when left_key == right_key) is suffixed on both sides (left_suffix/right_suffix) so the output has no duplicate names.

    left_suffix

    Suffix for clashing left columns (default "_x", as in dplyr).

    right_suffix

    Suffix for clashing right columns (default "_y").

    Returns

    The joined frame (for Semi/Anti, a subset of this frame's rows).

    Throws
    std::out_of_range

    if left_key is not in this frame or right_key is not in right.

    std::invalid_argument

    if a suffixed name still clashes with another column (for example left already has "a" and "a_x").

    Example
    dm::dstruct::DataFrame people;
people.add_column("id", std::vector<double>{1, 2, 3});
people.add_column("name", std::vector<std::string>{"ann", "bob", "cy"});
dm::dstruct::DataFrame pets;
pets.add_column("id", std::vector<double>{1, 1, 3});
pets.add_column("pet", std::vector<std::string>{"cat", "dog", "fish"});
std::print("{}\n", people.join(pets, "id", "id").nrows());   // 3: ann twice, cy once
const auto all = people.join(pets, "id", "id", dm::dstruct::DataFrame::JoinType::Left);
std::print("{}\n", all.nrows());   // 4: bob kept with a null pet
const auto lonely = people.join(pets, "id", "id", dm::dstruct::DataFrame::JoinType::Anti);
std::print("{}\n", lonely.get_column<std::string>("name").at(0));   // bob
