    class datamunge::dstruct

    NullableColumn

    template<typename T>
class NullableColumn
    #include <datamunge/dstruct/dataframe.hpp> source

    One typed DataFrame column: a contiguous std::vector<T> plus a validity mask, in the style of an Arrow array or pandas' nullable dtypes.

    DataFrame stores NullableColumn<double> (numeric) and NullableColumn<std::string> (string) columns. A null slot holds a default-constructed T in values() and a 0 in validity(); use is_null(), optional_at() or materialize() when nulls matter. Columns borrowed from a DataFrame via DataFrame::get_column() are references into the frame.

    Template parameters
    T

    Element type: double or std::string inside a DataFrame.

    Example
    const auto tooth = dm::datasets::tooth_growth();
const auto& len = tooth.get_column("len");   // const NullableColumn<double>&
std::print("{} {}\n", len.size(), len.values()[0]);   // 60 4.2
const auto lens = dm::c(len.values());   // copy into a dm::Vector<double>
    References

    • Apache Arrow columnar format (validity bitmaps): https://arrow.apache.org/docs/format/Columnar.html

    • pandas nullable integer data type: https://pandas.pydata.org/docs/user_guide/integer_na.html

    push_back

    #source
    void push_back(const T & value)

    Appends a valid value.

    Like std::vector::push_back, this may reallocate, invalidating references from values()/validity()/at(). For a std::string column pass a std::string, not a string literal (ambiguous with the optional overload). Growing a column that lives inside a DataFrame breaks the frame's equal-length invariant; use DataFrame::append_row() there instead.

    Parameters
    value

    Value to append.

    Example
    dm::dstruct::NullableColumn<std::string> col;
col.push_back(std::string("a"));
col.push_null();
std::print("{} {}\n", col.size(), col.is_null(1));   // 2 true

    values

    #source
    const std::vector< T > & values() const

    Borrows the raw values, including placeholder values in null slots.

    The vector has size() elements in row order. A null slot holds T{} (0.0 or ""), so check validity()/is_null() first when the column may contain nulls – or use materialize() to get std::optionals. The reference is valid while this column lives and is not modified; wrap it as dm::c(col.values()) to get an owning dm::Vector.

    Returns

    A read-only reference to the underlying value storage.

    Example
    const auto iris = dm::datasets::iris();
const auto& species = iris.get_column<std::string>("Species").values();
std::print("{}\n", species.front());   // setosa
const auto widths = dm::c(iris.get_column("Sepal.Width").values());
    See also

    materialize(), validity(), DataFrame::get_column()

    validity

    #source
    const std::vector< std::uint8_t > & validity() const

    Borrows the validity mask: one byte per slot, 1 = valid, 0 = null.

    This is a byte mask rather than Arrow's packed bitmap. The reference is valid while the column lives and is not modified.

    Returns

    A read-only reference to the mask, size() elements long.

    Example

    std::vector<std::optional<double>>{1.0, std::nullopt});
std::print("{} {}\n", col.validity()[0], col.validity()[1]);   // 1 0

    materialize

    #source
    std::vector< std::optional< T > > materialize() const

    Copies the column out as std::optionals, with std::nullopt for each null.

    O(size()) time and a full copy; use values() plus validity() to avoid the copy.

    Returns

    One optional per slot, in row order.

    Example
    const auto penguins = dm::datasets::penguins();
const auto sex = penguins.get_column<std::string>("sex").materialize();
std::print("{} {}\n", sex[0].value(), sex[3].has_value());   // male false
