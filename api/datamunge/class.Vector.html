    Vector

    template<typename T>
class Vector : public datamunge::VectorExpressionTag
    #include <datamunge/vector.hpp> source

    An owned std::vector<T> with R-style selection and recycling (R's atomic vector).

    Numeric binary operations recycle the shorter operand to the longer length, including partial cycles without a warning. An empty operand gives an empty result. Storage access and operator[] use C++ zero-based indexing; select() is one-based. Concurrent reads are safe; callers synchronize mutation of a shared instance.

    Vectors are usually built with dm::c(), dm::seql(), dm::runif() or dm::rnorm() rather than constructed directly. They are ranges (begin()/end()), so std::print("{}", v) prints [a, b, c] (strings quoted), and they convert implicitly to const std::vector<T>& for APIs such as dm::Plot. Free arithmetic and math functions build lazy double-valued expressions for numeric inputs. auto y = x + 1 retains a read-only expression; Vector<> y = x + 1 computes an owned, mutable snapshot. Compound assignments remain eager and alias-safe.

    Template parameters
    T

    Element type; defaults to double for existing numeric workflows.

    Example
    dm::Vector<double> x{1.5, 2.5, 3.5};
x[0] = 10;                                     // zero-based storage access
std::print("{} {}\n", x, x.size());            // [10, 2.5, 3.5] 3
std::print("{}\n", x.select({1, 3}));          // [10, 3.5]   (one-based)
std::print("{}\n", x * 2.0);                   // [20, 5, 7]

    select

    #source
    template<typename I>
Vector select(const std::vector< I > & indices) const

    Selects a copy using one-based numeric indices or a recycled logical mask (R's x[i]).

    Positive indices retain order and duplicates; zero is omitted. Negative indices exclude positions and may only be mixed with zero. Fractional indices truncate toward zero. Negative indices beyond size() are ignored. Logical masks recycle to size(); a longer mask may only select positions that exist. An empty index list returns an empty vector.

    A common use is mapping a dm::factor() code vector through a palette to get one color per observation.

    Template parameters
    I

    Arithmetic index type, or bool for a logical mask.

    Parameters
    indices

    One-based positions (positive to keep, negative to drop) or a mask.

    Returns

    A new owned vector; this vector is unchanged.

    Throws
    std::invalid_argument

    For non-finite indices or mixed positive/negative indices.

    std::out_of_range

    For a selected position beyond size() (there is no NA sentinel).

    Example
    const auto x = dm::c(10, 20, 30, 40);
std::print("{}\n", x.select(std::vector<double>{1.9, 0, 3}));   // [10, 30]
std::print("{}\n", x.select(std::vector<bool>{true, false}));   // [10, 30]

const auto palette = dm::c("red", "green", "blue");
const auto codes = dm::factor(dm::c("b", "a", "b", "c"));        // [2, 1, 2, 3]
std::print("{}\n", palette.select(codes));   // ["green", "red", "green", "blue"]

    operator+=

    #source
    Vector & operator+=(const Vector & rhs)

    Adds rhs in place, recycling both inputs to the longer length; empty inputs give empty.

    The result length is the longer of the two lengths (this vector may grow), or zero if either is empty. Safe when rhs aliases *this (e.g. x += x).

    Parameters
    rhs

    Vector added element-wise, recycled as needed.

    Returns

    *this.

    Example
    auto x = dm::c(1, 2, 3, 4);
x += dm::c(10, 20);
std::print("{}\n", x);                       // [11, 22, 13, 24]
