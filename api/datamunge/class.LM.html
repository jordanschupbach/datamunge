    #source
    template<class T>
LM(const std::vector< double > & y, const BasicMat< false, T > & predictors, bool intercept = true)

    Fit directly from a response and dense numeric predictor matrix. Copies predictors to the canonical double-precision model. Adds an intercept by default; matrix columns must exclude it and remain in the same order for prediction.

    Template parameters
    T

    Floating-point matrix scalar, converted to double.

    Parameters
    y

    Finite response values, one per predictor row.

    predictors

    Dense predictors with n > p after adding any intercept.

    intercept

    Add a constant coefficient, default true.

    Throws
    std::invalid_argument

    For invalid shapes or nonfinite data.

    std::runtime_error

    For rank deficiency.

    Example
    const dm::LM fit(dm::c(1, 3, 5, 7), dm::Mat<>{{0}, {1}, {2}, {3}});
std::print("{:.0f}\n", fit.predict(dm::Mat<>{{4}})[0]); // 9

    stats::LM

    #source
    template<class T>
LM(
    const std::vector< double > & y,
    const BasicMat< true, T > & predictors,
    bool intercept = true,
    linalg::SparseLinearRegressionOptions options = {{1e-12, 1000}, true})

    Fit directly from a response and CSR predictors using native sparse regression. Keeps the design compressed. The native PCG normal-equation solve uses sparse products; covariance is a dense coefficient-sized matrix. Inputs are owned and converted to double. Normal equations square the design's condition number.

    Template parameters
    T

    Floating-point matrix scalar, converted to double.

    Parameters
    y

    Finite response values, one per predictor row.

    predictors

    CSR predictors, excluding any requested intercept; requires n > p.

    intercept

    Add a constant coefficient, default true.

    options

    Solver settings: relative residual tolerance 1e-12, at most 1000 iterations, Jacobi preconditioning by default.

    Throws
    std::invalid_argument

    For invalid shapes, nonfinite data or invalid tolerance.

    std::runtime_error

    For rank deficiency or failure to converge.

    Example
    const dm::LM fit(dm::c(1, 3, 5, 7), dm::SpMat<>{{0}, {1}, {2}, {3}});
std::print("{:.0f}\n", fit.predict(dm::SpMat<>{{4}})[0]); // 9
    See also

    stats::LM, linalg::SparseLinearRegressionOptions

    std::vector< double > predict(const DataFrame & newdata) const
    #source
    template<bool S, class T>
std::vector< double > predict(const BasicMat< S, T > & newdata) const

    Predict a matrix-fitted model from dense or CSR columns in training order. Adds the fitted intercept automatically. CSR input is visited by stored entries; prediction does not allocate a dense predictor grid.

    Template parameters
    S

    Sparse-storage selector.

    T

    Floating-point scalar, converted to double when necessary.

    Parameters
    newdata

    Finite predictors with the training column count, excluding the intercept. Empty rows and a different storage policy from fitting are valid.

    Returns

    One fitted mean per row.

    Throws
    std::invalid_argument

    For formula-fitted models, wrong columns or nonfinite values.

    Example

    See the dense and sparse matrix constructors' prediction examples.
