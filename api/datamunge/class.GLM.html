    GLM

    class GLM
    #include <datamunge/datamunge.hpp> source

    SWIG-friendly facade for datamunge::stats::GLM — a generalized linear model (gaussian, binomial, poisson, or Gamma family with its canonical link, matching R's glm() defaults) fit by iteratively reweighted least squares.

    Parameters
    family

    One of "gaussian" (identity link), "binomial" (logit link), "poisson" (log link), or "Gamma" (inverse link).

    weights_column

    Optional column name enabling prior weights; pass "" (the default) for none.
