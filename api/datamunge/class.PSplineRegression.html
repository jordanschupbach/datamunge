    PSplineRegression

    class PSplineRegression
    #include <datamunge/pspline_regression.hpp> source

    A P-spline regression curve y ≈ Σ_j β_j B_j(x) (Eilers & Marx). dm::PSR for short.

    Minimizes ||y - Bβ||² + λ ||D_d β||², where D_d is the order-d difference matrix on the coefficients (d = 2 by default). Uniform knots continue past both ends of the data without repeated boundary knots. When d <= degree+1, polynomials of degree < d go unpenalized: λ → ∞ gives the least-squares line for d = 2. A rich basis can include functions with no data under them if the data identify the penalty nullspace. Without an explicit λ, it is chosen by minimizing generalized cross-validation, GCV(λ) = n·RSS / (n − edf)².

    The polynomial-nullspace claim requires uniform spacing; it need not hold for irregular supplied knots. A positive lambda identifies a rich basis only when the design identifies the penalty nullspace. No values are dropped. The class owns its fit and permits concurrent const reads. Sparse assembly and dense Cholesky cost O(n(p+1)^2+K^3); GCV repeats this work. Very large lambda can make the equations numerically singular.

    Example
    const dm::PSR fit({0,1,2},{0,1,0},3,1.0,1,2);
std::print("{:.6f} {:.6f}\n",fit.predict({1})[0],fit.effective_df()); // 0.428571 2.142857
    References

    • P. H. C. Eilers and B. D. Marx (1996). Flexible smoothing with B-splines and penalties. https://doi.org/10.1214/ss/1038425655

    #source
    PSplineRegression(const Vector<> & x, const Vector<> & y, std::size_t n_basis)

    n_basis cubic B-splines with equally spaced knots over the range of x; λ chosen by GCV. Searches log10(lambda) on [-8,8] in steps of 0.5, then uses golden-section refinement around the best grid point. Singular candidates score infinity. This bounded refinement does not guarantee a global continuous minimum. Penalty order is two.

    Parameters
    x

    Nonempty finite coordinates spanning a positive-width interval.

    y

    Finite responses matching x.

    n_basis

    Basis count K, at least four.

    Throws
    std::invalid_argument

    For invalid data or basis size.

    std::runtime_error

    If all candidate systems fail numerically.

    Example
    const dm::Vector<> x=dm::seql(0,1,30);
const dm::PSR fit(x,dm::sin(6*x),10);
std::print("{}\n",fit.lambda()>0); // true
    References

    • G. H. Golub, M. Heath and G. Wahba (1979). Generalized cross-validation as a method for choosing a good ridge parameter. https://doi.org/10.1080/00401706.1979.10489751

    gcv(), smoothing_path()

    penalty_order

    Positive difference order smaller than the resulting basis, default two.

    smoothing_path

    #source
    static dstruct::DataFrame smoothing_path(
    const Vector<> & x,
    const Vector<> & y,
    std::size_t n_basis,
    const Vector<> & lambdas,
    std::size_t degree = 3,
    std::size_t penalty_order = 2)

    Summarizes a lambda grid on one uniform extended basis, without automatic selection.

    Singular candidates are reported as exceptions, not omitted. Work is the grid length times the cost of a fit. Input is not mutated; rows preserve the supplied lambda order.

    Parameters
    x

    Nonempty finite coordinates spanning a positive-width interval.

    y

    Finite matching responses.

    n_basis

    Basis count at least degree+1 and greater than penalty_order.

    lambdas

    Nonempty finite nonnegative multiplier grid.

    degree

    Spline degree, default three.

    penalty_order

    Positive difference order, default two.

    Returns

    Owned numeric columns lambda, edf, rss, roughness, objective, gcv, loo_cv.

    Throws
    std::invalid_argument

    For invalid data/options or an empty lambda grid.

    std::runtime_error

    If any system is singular or non-finite.

    std::overflow_error

    If difference weights or the penalty overflow.

    Example
    const auto path=dm::PSR::smoothing_path({0,1,2},{0,1,0},3,{0.1,1,10},1,2);
std::print("{:.6f}\n",path.numeric_column("edf").values()[1]); // 2.142857
