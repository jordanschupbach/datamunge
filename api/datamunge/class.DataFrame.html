    #source
    template<bool S, class T>
explicit DataFrame(const BasicMat< S, T > & matrix, std::vector< std::string > names = {})

    Copy a native dense/CSR matrix into the canonical DataFrame storage. C++ convenience overload; generated languages use their numeric-column APIs.

    Template parameters
    S

    Sparse-storage selector.

    T

    Floating-point scalar, converted to double.

    Parameters
    matrix

    Source facade matrix, unchanged.

    names

    Unique nonempty column names; default empty uses matrix.colnames().

    Throws
    std::invalid_argument

    For invalid names or an unrepresentable matrix shape.

    Example
    const dm::DataFrame data(dm::Mat<>{{1, 2}, {3, 4}}, {"x", "y"});
std::print("{} {}\n", data.nrows(), data.ncols()); // 2 2
    See also

    Example
