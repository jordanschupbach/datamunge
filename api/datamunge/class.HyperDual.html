    HyperDual

    class HyperDual
    #include <datamunge/datamunge.hpp> source

    SWIG-friendly facade for datamunge::autodiff::HyperDual – a second-order forward-mode dual number carrying two independent derivative directions plus their exact mixed second partial, for computing Hessian entries.

    A hyper-dual number value + eps1·ε₁ + eps2·ε₂ + eps1eps2·ε₁ε₂ (ε₁² = ε₂² = 0).

    Seed input i with eps1 = 1 and input j with eps2 = 1 (both on the same input for a diagonal entry); the result's eps1eps2() is then the exact ∂²f/∂xᵢ∂xⱼ.

    Parameters
    value

    Real part, the function value.

    eps1

    First derivative along the first seed direction (default 0).

    eps2

    First derivative along the second seed direction (default 0).

    eps1eps2

    Mixed second derivative part (default 0; leave 0 for inputs).

    Example
    const dm::HyperDual x(3.0, 1.0, 1.0);
std::print("{}\n", x.multiply(x).eps1eps2());  // d²(x²)/dx² = 2
