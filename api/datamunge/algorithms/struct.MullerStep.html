    MullerStep

    struct MullerStep
    #include <datamunge/algorithms/muller.hpp> source

    Actual residual inspection and, when needed, its quadratic proposal. quadratic=false means complete coefficients/discriminant are unavailable; spacing fields can retain an attempted coincident-node check, while unused coefficient fields are zero placeholders and next=x2. updated=false means no callback at next was performed. A final cap check records at_limit=true without fabricating a new quadratic iteration.

    Example
    auto t=dm::algorithms::muller_trace([](double x){return x*x-2;},0,1,2);
std::print("{} {}\n",t.steps.front().a,t.steps.front().b); // 1 4
