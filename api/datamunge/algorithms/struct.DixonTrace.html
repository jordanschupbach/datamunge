    struct datamunge::algorithms

    DixonTrace

    struct DixonTrace
    #include <datamunge/algorithms/dixon.hpp> source

    Owned actual collection, tested dependencies and logical elimination work. No replay: the same kernel implements dixon_factor(). Collection stops at base_size+1 relations or the candidate budget. All-row GF(2) elimination uses dynamic 64-bit word vectors, so bases and relation sets can exceed 64 bits. Only dependencies visited up to the first proper factor are captured. Captured scalar cells equal base.size()+sum(exponents.size()+3) over relations +sum(relation_indices.size()+exponent_sums.size()+4) over dependencies. The optional cap excludes vector objects and transient elimination storage. Scratch space is O(k*k), in addition to captured output; no shared mutation.

    Example
    const auto t = dm::algorithms::dixon_factor_trace(77, 3, 10);
std::print("{} {} {}\n", t.factor, t.rank, t.collection.scanned); // 7 1 10
