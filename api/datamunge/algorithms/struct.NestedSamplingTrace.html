    NestedSamplingTrace

    struct NestedSamplingTrace
    #include <datamunge/algorithms/nested_sampling.hpp> source

    Owned actual initialization, every proposal, replacement and final contribution. Capture counts2d+6 initial scalar/bound units; each initial/proposal/final record1+d; each iteration1+4d; each returned posterior record2+d. Ordinary result storage and transient live/walk arrays are not peak-RAM claims.

    Example
    auto t=dm::algorithms::nested_sampling_trace([](const auto&){return 0.;},{0.},{1.},2,0);std::print("{}\n",t.final_live.size()); // 2
