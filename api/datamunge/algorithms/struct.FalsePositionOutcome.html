    FalsePositionOutcome

    struct FalsePositionOutcome
    #include <datamunge/algorithms/root_finding.hpp> source

    Owned result, terminal reason, actual work and true-versus-weighted bracket state. For a trial stop, a/b and their values/weights describe the bracket used to compute the returned estimate, before its terminal update. Endpoint zero collapses that state to the zero endpoint; same-sign rejection keeps original inputs, default RootResult and infinite radius. Input order is retained, so a need not be less than b. Radius is the rounded maximum estimate-to-endpoint distance, possibly infinity for a full-width interval; not an outward-rounded certified error bound. Small residual does not imply small coordinate error. No callback or input reference is retained; independent calls share no state.

    Example
    const auto o=dm::algorithms::false_position_work([](double x){return x-1;},0,2);
std::print("{} {} {}\n",o.result.root,o.evaluations,dm::algorithms::false_position_stop_name(o.stop)); // 1 3 zero callback
