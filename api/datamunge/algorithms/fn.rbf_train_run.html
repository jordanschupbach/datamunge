    function datamunge::algorithms

    rbf_train_run

    #include <datamunge/algorithms/rbf_network.hpp>
    #source
    RBFTrainingRun rbf_train_run(
    const std::vector< std::vector< double > > & X,
    const std::vector< double > & y,
    std::size_t num_centers,
    double ridge_lambda = 1e-6,
    double width = 0,
    std::size_t kmeans_iters = 20,
    std::uint64_t seed = 0,
    const RBFTrainingOptions & options = {})

    Fit a checked native Gaussian-basis closed-form regression baseline. Validates finite nonempty rectangular inputs and matching finite targets, finite nonnegative ridge and finite width. K=min(requested,n); K0 is an explicit intercept-only baseline without Lloyd. Initializes centers with the historical mt19937_64 random-sample stream and executes exactly the requested Lloyd passes, retaining empty-cluster centers. A positive width is used directly; nonpositive finite width selects the historical maximum-center-distance/sqrt(2K) heuristic, falling back to1. Forms actual bias-first Gaussian design and ridge normal equations, penalizing the bias too. Uses widened arithmetic and checked partial-pivot elimination, throwing on an exact singular system instead of silently dropping its coefficients. Time O(passes*n*K*d+n*K^2+K^3), O(n*K+K^2) working storage; inputs unchanged, outputs owned. This is an independent closed-form comparison for reports whose demonstrated neural fitting uses explicit tensor optimization.

    Parameters
    X

    Finite nonempty rectangular rows with positive dimension.

    y

    Finite scalar targets, one per row.

    num_centers

    Requested centers, capped by n; zero selects intercept-only.

    ridge_lambda

    Finite nonnegative regularization, default1e-6.

    width

    Positive explicit sigma; nonpositive finite selects heuristic, default0.

    kmeans_iters

    Actual fixed Lloyd passes, default20.

    seed

    Native initial-center seed, default0.

    options

    Input, work, matrix and history policies.

    Returns

    Owned actual baseline model and selected training work.

    Throws
    std::invalid_argument

    Input shape/value, ridge or width invalid.

    std::length_error

    Input/work/matrix/history policy exceeded.

    std::domain_error

    Actual normal system is singular.

    std::overflow_error

    Unrepresentable geometry or coefficient.

    Example
    auto r=dm::algorithms::rbf_train_run({{0},{1}},{2,4},0,0);
std::print("{}\n",r.model.bias); // 3
