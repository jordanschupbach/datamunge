    LamportClock

    class LamportClock
    #include <datamunge/algorithms/lamport_clock.hpp> source

    Own one process's nonnegative signed64 scalar Lamport logical clock. Starts0. Internal/send events increment once; receive commits max(current,message_stamp)+1. Scalar order respects happened-before when the caller records every local event and attaches actual send stamps to receives. Converse false: ordered timestamps need not imply causality. This class does not authenticate messages, model a network, synchronize threads or produce a unique total order across processes. Pair with process ids externally if needed. All transitions O(1), no allocation; invalid/overflow failures leave state unchanged. Copies own values, independent objects share no mutable state.

    Example
    dm::algorithms::LamportClock a,b;const auto stamp=a.send();
std::print("{} {}\n",stamp,b.receive(stamp)); // 1 2
    References

    • Lamport(1978), Time, Clocks, and the Ordering of Events in a Distributed System, Communications of the ACM21(7),558–565, https://doi.org/10.1145/359545.359563.
