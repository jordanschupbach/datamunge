    FlashsortWork

    struct FlashsortWork
    #include <datamunge/algorithms/flashsort.hpp> source

    Actual work and class occupancy from one native Flashsort, without a history. Min/max comparisons count two ordered tests per element after the first; classifications counts every actual value-to-class call, including leader searches. permutation_writes counts carried-value exchanges, including cycle closure. Insertion comparisons count predecessor>key evaluations (including false ones), shifts count successful predecessor moves, and placements count final key stores. Loop-bound/finite-validation tests and allocations are excluded. n<=INT_MAX keeps these whole-run uint64 counters representable. No timing claim.

    Example
    std::vector<int> a{2,0,1};
const auto w=dm::algorithms::flashsort_work(a);
std::cout << w.class_count << ' ' << w.permutation_writes; // 2 3
