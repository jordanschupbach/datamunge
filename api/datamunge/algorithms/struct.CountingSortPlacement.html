    CountingSortPlacement

    struct CountingSortPlacement
    #include <datamunge/algorithms/counting_sort.hpp> source

    One actual right-to-left assignment using a predecremented end cursor. Events appear in execution order, with input_index descending. The chosen output slot is cursor_before-1. No snapshot or report-side replay is needed.

    Example
    const auto t=dm::algorithms::counting_sort_trace({2,0,2},0,2);
const auto& p=t.placements.front();
std::print("{} {} {}\n",p.input_index,p.cursor_before,p.output_index); // 2 3 2
    References

    • Pat Morin, Open Data Structures (C++), Section 11.2: https://opendatastructures.org/ods-cpp/11_2_Counting_Sort_Radix_So.html
