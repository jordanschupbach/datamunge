    CipollaTrace

    struct CipollaTrace
    #include <datamunge/algorithms/cipolla.hpp> source

    Owned actual prime-field path, candidate tests, bit states and full-range root result. The ordinary, unsigned-result and traced calls share a kernel without replay. input_n is the caller's uint64; normalized_n is input_n modulo the validated prime. residue_euler is zero when the p=2/zero paths skip its computation. a,w,final_element and both record arrays stay zero/empty off the extension path. No shared state or input mutation. Trace storage is O(T+log p) for T actual candidates; no allocation is reserved from the modulus magnitude.

    Example
    const auto t=dm::algorithms::cipolla_sqrt_trace(10,13);
std::print("{} {} {}\n",t.a,t.w,t.steps.size()); // 2 7 3
