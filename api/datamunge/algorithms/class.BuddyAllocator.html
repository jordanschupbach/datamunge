    BuddyAllocator

    class BuddyAllocator
    #include <datamunge/algorithms/buddy_allocator.hpp> source

    Model a binary buddy arena using offsets, ordered free sets and live maps. Does not allocate arena payload bytes or return pointers. Both dimensions must be positive powers of two, with minimum<=total. Allocation chooses the smallest adequate nonempty order, then its lowest offset, retaining the left child when splitting. Free coalesces only true same-order buddies. Unknown frees are no-ops. Positive oversize/exhausted requests return -1; nonpositive requests throw. Ordinary and traced calls share kernels. Metadata allocation failure leaves state unchanged; snapshots own their data. Copies are independent offset models. Concurrent mutations need external synchronization. For H orders and B current blocks, operations have conservative O(H log(B+1)) ordered-container cost, not a constant-cost-per-order guarantee. Metadata storage is O(H+B).

    Example
    dm::algorithms::BuddyAllocator a(1024,32);
const int off=a.allocate(30);
std::print("{} {}\n",off,a.internal_fragmentation()); // 0 2
    References

    • K. C. Knowlton (1965), A fast storage allocator, Communications of the ACM 8(10), doi:10.1145/365628.365655; author bibliography: https://www.kenknowlton.com/pages/29papers.htm.

    • C++ associative-container requirements, https://eel.is/c++draft/associative.reqmts.

    int order_for_size(int size) const

    Find the smallest power-of-two class fitting a positive request safely. The order may exceed max_order() for an oversized request; block_size() only accepts arena orders. Uses widened multiplication, never an overflowing shift.

    Parameters

    void free(int offset)

    Free a current live offset and maximally coalesce its same-order buddies. Unknown/interior/negative/already-free offsets are no-ops, preserving historical behavior. A reused live offset names its current allocation. Metadata failure leaves state unchanged. Does not access or release any backing payload bytes.

    Throws

    Free once and record actual XOR buddy tests and successful merges. Shares the free() kernel without replay or whole-arena snapshots. Unknown offsets return released=false and no probes. Metadata failure leaves state unchanged, including failures while reserving the trace.
