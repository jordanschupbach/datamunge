    struct datamunge::algorithms

    FermatOutcome

    struct FermatOutcome
    #include <datamunge/algorithms/number_theory_extra.hpp> source

    Owned result and actual work counts of bounded Fermat splitting. For odd n, start_a is the exact ceiling root; last_a and last_b are the last actual trial and its exact floor root of a squared minus n. Trials count square tests, including a hit; increments count moves between tested a values, hence trials-1. An even input has zero trials, increments and a/b metadata. Returned_factor matches fermat_factor(); cofactor is n/returned_factor when a square or even branch completes, and zero at TrialLimit. Proper_split requires both factors greater than one. Results own their scalars and share no state.

    Example
    const auto f=dm::algorithms::fermat_factor_work(5959);
std::print("{} {} {}\n",f.returned_factor,f.cofactor,f.trials); // 59 101 3
    See also

    FermatStop, FermatTrace, fermat_factor_work()
