    DStarLiteGrid

    class DStarLiteGrid
    #include <datamunge/algorithms/d_star.hpp> source

    Persistent D* Lite for a rectangular four-neighbor unit-cost occupancy grid. Owns g/rhs labels and an indexed binary heap with at most one entry per vertex. Planning runs backward from a fixed goal; Manhattan priorities and a checked movement modifier let changed edges/new starts reuse prior state. Cell bounds must fit int and total cells<=INT_MAX. A shortest simple route has at most N-1 edges; backups at N or more are saturated to infinity, retaining every possible optimum and bounding integer labels. Priorities use exact uint64_t arithmetic; modifier headroom of4*N is reserved before moving the start. Blocked goal has rhs=infinity; unblocking restores its zero boundary. Blocked endpoints yield no route. No diagonals, weighted terrain, moving goal, sensor inference or automatic movement are included. Copying owns an independent full planner. Concurrent mutation of one instance needs synchronization. Each repair can touch the whole grid; there is no guaranteed speedup over fresh search. Heap operations are O(log N), backup degree<=4, persistent storage O(N), plus caller-requested trace.

    Example
    dm::algorithms::DStarLiteGrid p({{false,false},{false,false}},{0,0},{1,1});
(void)p.repair();
std::print("{}\n",p.repair().work.pops); // 0
