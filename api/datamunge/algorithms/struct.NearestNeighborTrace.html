    NearestNeighborTrace

    struct NearestNeighborTrace
    #include <datamunge/algorithms/nearest_neighbor_interpolation.hpp> source

    Owned nodes/query and actual binary-search/nearest-choice observations. Capture units are both node arrays, query/result scalar records and actual search-step records:2n+2+steps. Empty result index0 is a placeholder. Route0=empty,1=lower endpoint,2=upper endpoint,3=interior nearest choice. Distances are meaningful only for route3 and use widened arithmetic.

    Example
    dm::algorithms::NearestNeighborInterpolant m({0,2},{10,20});auto t=m.trace(1);
std::print("{} {}\n",t.selected,t.value); // 0 10
