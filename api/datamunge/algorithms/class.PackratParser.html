    PackratParser

    class PackratParser
    #include <datamunge/algorithms/packrat_parser.hpp> source

    Owned byte PEG interpreter memoizing completed named-rule/position results. Complete grammar validation covers every node/operator/child arity/reference and start name before parsing. Direct/indirect left recursion at an active identical(rule,position) throws rather than recursing forever; right recursion remains subject to actual depth/work limits. Predicates do not consume input; ordered choice never revisits a successful child after a later sequence fails. Empty repetition stops on no progress, preserving original nullable behavior. Uses ordered std::map memo, not constant-time lookup. Only named rules are memoized: repeated greedy expression scans can still be quadratic. Therefore no general linear-time/linear-space packrat bound is promised by this API. Each parse owns its copied input, clears old memo/counters and uses no caller references/callbacks. A failed attempt clears incomplete memo and returns no trace, retaining explicit partial last-attempt counters/completed=false. Copies own grammar/input/cache; concurrent calls on one instance need caller synchronization. Zero disables optional policies, not the finite native stack.

    Example
    dm::algorithms::PackratParser p(dm::algorithms::packrat_anbn_rules(),"S");std::print("{} {}\n",p.parse("aabb"),p.rule_calls()); // true 3
    References

    • B. Ford(2004), Parsing Expression Grammars: A Recognition-Based Syntactic Foundation, https://bford.info/pub/lang/peg/. This native named-rule-only map cache has no general linear-time guarantee or left-recursive extension.
