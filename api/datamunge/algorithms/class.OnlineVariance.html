    OnlineVariance

    class OnlineVariance
    #include <datamunge/algorithms/online_statistics.hpp> source

    Owned finite double Welford state, atomically accepting observations and Chan merges. Finite inputs only; nonfinite/unrepresentable state or count overflow throws before any state mutation. Normal safe double operation order is retained; unsafe intermediates use long double before a checked finite double commit. This reduces cancellation, but does not guarantee offset-independent accuracy, exact M2, or recovery of signal lost when original inputs were rounded. Empty/singleton sample variance and empty mean use historical0 conventions. O(1) work/state per add/merge, no references/callbacks/shared mutable state. Distinct instances can run independently; simultaneous mutation needs caller synchronization.

    Example
    dm::algorithms::OnlineVariance s;s.add(1);s.add(3);std::print("{} {}\n",s.mean(),s.sample_variance()); // 2 2
    References

    • B. P. Welford(1962), Note on a Method for Calculating Corrected Sums of Squares and Products, doi:10.1080/00401706.1962.10490022.

    • T. F. Chan, G. H. Golub and R. J. LeVeque(1983), Algorithms for Computing the Sample Variance: Analysis and Recommendations, doi:10.1080/00031305.1983.10483115. Native finite-state guards/widened fallback are explicit extensions.
