    struct NthRootRun
    #include <datamunge/algorithms/nth_root.hpp> source

    Actual finite root approximation and selected seed/update work.

    Example
    auto r=dm::algorithms::nth_root_run(27,3);std::print("{:.6f}\n",r.value); // 3.000000
