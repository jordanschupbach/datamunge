    struct datamunge::algorithms

    LLLWork

    struct LLLWork
    #include <datamunge/algorithms/lll.hpp> source

    Actual selected floating Gram-Schmidt, integer row-operation and outer-loop work. Excludes complete guards, copies/allocation/capture, property-summary comparisons, elapsed time and CPU instruction counts.

    Example
    const auto a=dm::algorithms::lll_analyze({{1,0},{3,1}});
std::print("{}\n",a.work.size_reductions); // 1
    References

    • A. K. Lenstra, H. W. Lenstra Jr. and L. Lovasz(1982), Factoring Polynomials with Rational Coefficients, Mathematische Annalen261,515–534, https://doi.org/10.1007/BF01457454.

    See also

    lll_analyze(), lll_trace()
