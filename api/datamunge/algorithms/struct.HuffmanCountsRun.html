    struct datamunge::algorithms

    HuffmanCountsRun

    struct HuffmanCountsRun
    #include <datamunge/algorithms/huffman_coding.hpp> source

    Owned exact-weight construction result for an integer-symbol alphabet. All uint64 counts are accepted without restricting their sum to uint64. Exact totals/costs use decimal strings to avoid exposing an arithmetic backend. Zero-count lengths are0; a lone positive symbol uses length1. For m>=2, weighted_bits equals merge_cost; for m=1 they are count and0 respectively.

    Example
    const dm::algorithms::HuffmanCountsRun r;std::print("{}\n",r.active_symbols); // 0
