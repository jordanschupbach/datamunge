    KabschAnalysis

    struct KabschAnalysis
    #include <datamunge/algorithms/kabsch.hpp> source

    Owned same-execution paired fit, normalized covariance/key matrix and actual observations. Normalize each input set by its max(1,absolute coordinate), then center in long double. Covariance is the mean outer product in those normalized units. Divide it by covariance_scale to build the dimensionless Horn key matrix; scale zero uses an all-zero key. Eigenvalues are descending and quaternion is the actual normalized principal eigenvector, scalar-first. No second fit or iteration replay. Eigen residual/gap are additional diagnostics, not exact certificates of rank, uniqueness or convergence in exact arithmetic. All vectors own data.

    Example
    const auto a=dm::algorithms::kabsch_analyze({{0,0,0}},{{1,2,3}});
std::print("{} {}\n",a.aligned.size(),a.result.rmsd); // 1 0
