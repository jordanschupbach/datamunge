    MontgomeryContext

    class MontgomeryContext
    #include <datamunge/algorithms/montgomery.hpp> source

    Precompute one odd modulus for carry-safe Montgomery arithmetic. R=2^64. Setup computes nprime=-n inverse modulo R using five Newton refinements from the odd seed n, plus R and R squared modulo n. Setup and arbitrary-input reduction use remainder operations; only the reduced-domain REDC kernel avoids division. All inputs/results use unsigned64-bit words, with full128-bit products and an explicit129th sum bit. No constant-time guarantee. Methods do not mutate the context and are independently callable.

    Example
    dm::algorithms::MontgomeryContext c(3233);
std::print("{} {}\n",c.multiply(123,456),c.power(123,17)); // 1127 855
    References

    • P. L. Montgomery (1985), Modular multiplication without trial division, Mathematics of Computation44,519–521, doi:10.1090/S0025-5718-1985-0777282-X.

    power_trace

    #source
    MontgomeryPowerTrace power_trace(
    std::uint64_t base,
    std::uint64_t exponent,
    std::size_t max_steps = 64) const

    Capture actual binary powering in the Montgomery domain. Same producer as power(), without replay. For n>1, REDC count is 2+bit_width(exponent)+popcount(exponent), including exponent zero. For n=1 all counts are zero. History uses O(log exponent+1) space.

    Parameters
    base

    Arbitrary base, retained unreduced.

    exponent

    Arbitrary exponent, retained in the result.

    max_steps

    Complete bit-record cap, default64; zero disables.

    Returns

    Owned actual states, residue and REDC count.

    Throws
    std::length_error

    If effective bit width exceeds a nonzero cap, before powering.

    std::bad_alloc

    If history allocation fails.

    Example
    auto t=dm::algorithms::MontgomeryContext(17).power_trace(3,2);
std::print("{} {}\n",t.result,t.reductions); // 9 5
