    TokenBucket

    class TokenBucket
    #include <datamunge/algorithms/token_bucket.hpp> source

    Own one mutable caller-clock token bucket. Configured finite capacity/rate and actual stored tokens/time. Construction starts full at time0; operations require caller serialization and never read a wall clock.

    Example
    dm::algorithms::TokenBucket b(2,1);
std::print("{}\n",b.allow(0)); // true
    See also

    consume()

    Leaky bucket as an admission meter

    TokenBucket()Create a full checked token bucket on a caller-supplied monotone clock. Capacity and rate must be finite nonnegative. Starts with capacity tokens at time0. Times use caller-selected common units and must be finite, nondecreasing and at least0. No wall clock is read. Mutable instance has no internal locking; caller serializes operations. Token quantities are double with rounding; this is not an exact rational admission certificate.

    TokenBucket

    #source
    TokenBucket(double capacity, double rate)

    Create a full checked token bucket on a caller-supplied monotone clock. Capacity and rate must be finite nonnegative. Starts with capacity tokens at time0. Times use caller-selected common units and must be finite, nondecreasing and at least0. No wall clock is read. Mutable instance has no internal locking; caller serializes operations. Token quantities are double with rounding; this is not an exact rational admission certificate.

    Parameters
    capacity

    Finite nonnegative maximum banked tokens.

    rate

    Finite nonnegative added tokens per time unit.

    Throws
    std::invalid_argument

    Nonfinite or negative capacity/rate.

    Example

std::print("{}\n",b.stored_tokens()); // 2
