    PreflowEvent

    struct PreflowEvent
    #include <datamunge/algorithms/push_relabel.hpp> source

    One actual residual push or height relabel with immediately used state. For relabels, to=from, amount and residual fields are zero, and input is the size_t maximum sentinel. Height/excess fields refer to actual current vertices. Forward=false identifies an original-edge cancellation arc.

    Example
    std::print("{}\n",dm::algorithms::push_relabel_trace(2,{{0,1,9}},0,1).events[0].amount); // 9
