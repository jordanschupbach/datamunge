    FlowCertificate

    struct FlowCertificate
    #include <datamunge/algorithms/dinic.hpp> source

    Numerical primal/dual checks for a public maximum-flow result. Feasibility and cut equality are tested separately. A nonzero tolerance gives numerical agreement, not an exact proof; every error and the signed gap remain visible.

    Example

    See max_flow_certificate().
