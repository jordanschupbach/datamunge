    KarnEstimator

    class KarnEstimator
    #include <datamunge/algorithms/karn.hpp> source

    Educational Jacobson/Karels RTT smoother with Karn's ambiguity and backoff rules. Clean first sample R sets SRTT=R,RTTVAR=R/2,RTO=3R. Subsequent clean samples update RTTVAR=.75*oldvar+.25*abs(oldSRTT-R), then SRTT=.875*oldSRTT+.125*R, RTO=SRTT+4*RTTVAR. Retransmitted ACKs do nothing; timeouts double current RTO. No timestamp exception, clock granularity, RFC minimum/maximum, TCP sender, packet sequence tracking or scheduling is modeled. Therefore not a complete RFC6298 implementation. Preserves original ordinary-double operation order. Local owned state, no allocation/shared state; mutation requires external synchronization if one instance is used concurrently. Failed updates leave all state unchanged; copied instances evolve independently.

    Example
    dm::algorithms::KarnEstimator k;k.on_ack(.2,false);k.on_timeout();
std::print("{:.1f}\n",k.rto()); // 1.2
    References

    • RFC6298 sections2-5, https://www.rfc-editor.org/rfc/rfc6298.html; this teaching variant omits granularity and recommended RTO clamps.
