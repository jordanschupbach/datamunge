    struct datamunge::algorithms

    FloodFillWork

    struct FloodFillWork
    #include <datamunge/algorithms/flood_fill.hpp> source

    Owned scalar measurements of one actual iterative fill. Each discovered cell is painted when pushed and popped once. Neighbor slots include outside probes; in_bounds_neighbors counts actual value reads. A preexisting replacement-valued cell is a barrier, not a traversal bridge.

    Example
    dm::algorithms::FloodFillWork w{};
std::cout << w.filled; // 0
    See also

    flood_fill_work(), FloodFillTrace
