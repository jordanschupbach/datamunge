    LeakyBucket

    class LeakyBucket
    #include <datamunge/algorithms/leaky_bucket.hpp> source

    Lazy leaky-bucket meter, algebraically dual to a token bucket with complementary storage. Starts empty at time0 and therefore allows an immediate burst up to capacity. This is an admission meter, not a shaping queue; accepted arrivals have no delayed release schedule. Capacity must be positive finite, rate nonnegative finite; timestamps finite, nonnegative and nondecreasing, amounts finite and nonnegative. Same-time arrivals preserve caller order. O(1) per event, no borrowed input/shared global state; concurrent mutation requires synchronization.

    Example
    dm::algorithms::LeakyBucket m(2,1);
const bool first=m.add(0,2), second=m.add(1,1);
std::print("{} {}\n",first,second); // true true
    References

    • RFC2697(1999), https://www.rfc-editor.org/rfc/rfc2697; token meters are a related contract, not this implementation's exact parameterization.
