    HalleyTrace

    struct HalleyTrace
    #include <datamunge/algorithms/halley.hpp> source

    Owned chronological actual inspections and producing run; no replay or truncation. One record per f call, including final budget check, is admitted before that callback. Default cap one million records, zero disables it. Record counts are not bytes, capacities or peak RAM. Copying is deep; no retained callable state.

    Example
    const dm::algorithms::HalleyTrace t;
std::print("{}\n", t.steps.size()); // 0
