    GenerationalHeap

    class GenerationalHeap
    #include <datamunge/algorithms/generational.hpp> source

    Owned fixed-age graph with an exact maintained set of old-to-young reference slots. Construction validates once and indexes young ids and every boundary slot. Only checked existing-field replacement is permitted; ages, roots, object ids and field counts stay fixed. set_reference maintains the slot invariant as a modeled write barrier. It is not a concurrent/runtime collector: collect only proposes retention/reclamation, with no age changes, copying or deallocation. Copies own all data. Concurrent collect calls are safe absent concurrent writes.

    Example
    dm::algorithms::GenerationalHeap h({3,{{0},{},{}},{0},{}},{1,0,0});
h.set_reference(0,0,2);
std::cout << h.collect().survivors[0]; // 2
    References

    • Ungar (1984), https://doi.org/10.1145/800020.808261 , §8.1 store-side remembered set; this fixed-age graph model indexes exact slots and performs no copying/tenuring.

    Validate/copy a graph and build a young index and exact boundary-slot set. O(N+E+R) setup with sorted hinted slot insertion; retained graph/index storage is O(N+E+R). Sizes are ignored. No caller mutation; failed construction returns no object.

    Parameters

    Valid dense graph with fixed roots and field counts.

    generations

    Exact binary ages, fixed for the model's lifetime.

    Throws

    Invalid graph or ages before copying/indexing.

    std::length_error

    Actual validation/work/container capacities overflow.

    collect

    #source
    YoungCollection collect() const

    Collect a sparse young-only analysis from validated maintained boundary slots. No old field scan, whole-graph revalidation, full comparison, dense N-vector, age change or mutation. Young roots precede ordered remembered-slot targets; the same young traversal kernel is used as minor_gc. O(Y+R+W+E_y) work and temporary/output storage, with E_y fields of retained young objects.

    Returns

    Owned ascending survivor/freed ids and actual per-call work.

    Throws
    std::length_error

    Actual work/container capacities overflow.

    Example

std::cout << r.work.remembered_fields << ' ' << r.work.full_objects; // 1 0
