    LL1Parser

    class LL1Parser
    #include <datamunge/algorithms/ll1_parser.hpp> source

    Own a checked grammar, its actual FIRST/FOLLOW predictive table and explicit cell-conflict witnesses. A symbol is nonterminal exactly when used as a production lhs. Grammar start must be a defined nonterminal; lhs/rhs symbols cannot be empty or "$"; epsilon is an empty rhs vector, not a literal empty token. All production indices must fit int. FIRST/FOLLOW use finite monotone insertion fixed points; build work is grammar dependent, not a claimed constant-time preprocessing step. Retain earliest production per table cell and record actual conflicting later indices. is_ll1() means this indexed construction has no conflicts, including duplicate-rule IDs; conflicted models are inspectable but parsing throws. Parsing consumes complete finite string tokens, no lexing/backtracking/error recovery. Explicit action budget separates incomplete computation from a syntax rejection. Owned model has no borrowed grammar lifetime/shared state; independent const inference is safe when no caller mutates the object.

    Example
    const dm::algorithms::LL1Parser p({{{"S",{"a"}}},"S"});
std::print("{} {}\n",p.is_ll1(),p.recognize({"a"})); // true true
    References

    • Lewis and Stearns(1968), Syntax-Directed Transduction, Journal of the ACM15(3),465–488, https://doi.org/10.1145/321466.321477; explicit FIRST/FOLLOW table construction here.
