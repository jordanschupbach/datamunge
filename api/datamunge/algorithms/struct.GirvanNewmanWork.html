    GirvanNewmanWork

    struct GirvanNewmanWork
    #include <datamunge/algorithms/girvan_newman.hpp> source

    Selected actual operations of a betweenness or community run.

    Every call owns fresh counters. Counts exclude sorting comparisons, allocation, hash internals, validation checks and arithmetic FLOPs. source_slots counts n vertex slots per source, not bytes or the number of separate arrays. Component passes include the terminal pass; rounds counts scored/deleted batches only. These selected operations are not wall time or a complete cost model.

    Example
    const dm::algorithms::GirvanNewmanWork w{};
std::cout << w.rounds << " " << w.bfs_pops; // 0 0
