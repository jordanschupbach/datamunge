    CosineLSH

    class CosineLSH
    #include <datamunge/algorithms/lsh.hpp> source

    Own an immutable finite index with seeded Gaussian hyperplanes and insertion-order buckets. Input data are copied, fixing the historical borrowed-pointer lifetime hazard and stale buckets after caller mutation. Bit agreement has probability1-theta/pi for nonzero vectors and an isotropic continuous plane; finite sampled Gaussian arithmetic is the implementation. Zero vectors use cosine0 and nonnegative sign bits. Query still initializes N dense marks: O(N+L*k*d+V+C*d), with V actual member visits and C distinct candidates. There is no worst-case sublinear guarantee. Copies own all data/planes/buckets; const queries share no mutable state.

    Example
    dm::algorithms::CosineLSH index({{1,0},{0,1}},1,0,7);
std::print("{}\n",index.query({0,1})); // 1
    References

    M. Charikar(2002), Similarity Estimation Techniques from Rounding Algorithms, https://doi.org/10.1145/509907.509965.

    Validate complete finite rows before owning a seeded Gaussian-plane index.

    Parameters
    data

    Rectangular finite rows; nonempty data require positive dimension. Zero vectors are allowed operationally.

    num_tables

    Number of tables, including zero for a deliberately empty candidate index.

    bits_per_table

    Bits in0..64; zero puts every row in key0 of each table.

    seed

    Seed for mt19937_64, consumed table/bit/coordinate order by normal_distribution.

    Throws
    std::invalid_argument

    On malformed/nonfinite data or a signature width above64.

    std::length_error

    For unrepresentable allocation geometry.

    Note

    Seeded normal samples depend on the standard-library distribution implementation.

    query_top_k

    #source
    std::pair< std::vector< std::size_t >, std::size_t > query_top_k(
    const std::vector< double > & q,
    std::size_t k,
    std::size_t minimum_candidates,
    std::size_t table = 0) const

    Probe occupied buckets by Hamming distance and rerank their candidates by cosine.

    Equal-distance buckets use ascending signature. Entire buckets are visited, so the number scored can exceed the requested minimum. Equal cosine scores use ascending catalog row ID.

    Parameters
    q

    Finite query with the catalog dimension.

    k

    Number of neighbors requested.

    minimum_candidates

    Desired minimum candidate count before stopping.

    table

    Table to probe, default zero.

    Returns

    Neighbor IDs in rank order and actual number of cosine evaluations. The candidate minimum is raised to k and capped at catalog size.

    Throws
    std::invalid_argument

    Invalid query dimension or nonfinite coordinates.

    std::out_of_range

    Table outside the index.

    Example
    dm::algorithms::CosineLSH index({{1,0},{0,1}}, {{1,0}});
const auto [ids, scored] = index.query_top_k({0,1},1,1);
std::print("{} {}\n", ids.front(), scored); // 1 2

    query_trace

    #source
    LSHQueryTrace query_trace(const std::vector< double > & q, std::size_t max_entries = 1000000) const

    Capture actual projections, bucket lookups and candidate visits without query replay.

    Parameters
    q

    Complete finite dimension-matched query.

    max_entries

    Optional logical capture limit, one million by default; zero disables it.

    Returns

    Independent actual records; planes/data stay in the immutable index, not copied into the trace.

    Throws
    std::invalid_argument

    For malformed complete query.

    std::length_error

    Before each record/copy if capture admission would exceed its cap.

    Note

    Counts d query coordinates, each projection, each table probe plus bucket member, and each candidate visit. Excludes scalar fields, capacities, analysis, index/runtime copies, seen marks and bytes. Complete trace or exception.

    Example
    dm::algorithms::CosineLSH index({{1,0},{0,1}},1,0,7);
std::print("{}\n",index.query_trace({1,0}).analysis.examined); // 2
