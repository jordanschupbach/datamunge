    KnapsackNode

    struct KnapsackNode
    #include <datamunge/algorithms/branch_and_bound.hpp> source

    One DFS entry, its exact bound, incumbent transition and incoming decision. Nodes are in visit order. Root parent/item_index are size_t maximum. A node's level counts decided positive-profit items in KnapsackTrace::item_order.

    Example
    const auto trace=dm::algorithms::knapsack_branch_and_bound_trace({10,8,5},{2,3,3},5);
std::print("{} {}\n",trace.nodes.front().level,trace.nodes.front().bound.integer_upper); // 0 18
    See also

    KnapsackTrace, KnapsackNodeState

    Fields

    parentEarlier node index, or size_t maximum for the root.
    item_indexOriginal item decided by the incoming edge; root has no incoming item.

    levelNumber of active decisions already fixed on entry.
    weightFeasible total weight on entry, in [0,capacity].
    valueFeasible total value on entry, checked against the legacy int range.
    boundExact relaxation components; at a leaf this equals the node's value.
    incumbent_beforeBest feasible value before considering this node's own partial selection.
    incumbent_afterBest feasible value after that strict-improvement update, before descendants.
    stateWhether this node branches, is pruned or is a leaf.
