    FNVBucketProfile

    struct FNVBucketProfile
    #include <datamunge/algorithms/fnv_analysis.hpp> source

    Counted bucket occupancy and distinct-key integer-hash collisions. All fields own their values. Bucket pairs count unordered INPUT RECORD pairs sharing a bucket, including duplicates. Hash pairs count unordered DISTINCT byte-key pairs with equal full-width integer hashes. These are different events. Numeric dataframe columns convert counters to double, exact up to 2^53.

    Example
    const auto p = dm::algorithms::fnv_bucket_profile({"a", "a"}, 16);
std::print("{} {}\n", p.bucket_pairs, p.hash_pairs); // 1 0

    summary

    #source
    dstruct::DataFrame summary() const

    Summarize finite observed occupancy, without a randomness certificate.

    Returns

    One owned row: bits, keys, distinct_keys, bytes, buckets, occupied, max_load, mean_load, bucket_pairs, hash_pairs and iid_expected_bucket_pairs. The last is n(n-1)/(2B) under an explicit independent-uniform null, not an FNV guarantee. Empty profiles use zero for undefined mean/reference quantities.

    Example
    const auto p = dm::algorithms::fnv_bucket_profile({"a", "b"}, 4);
const auto n = p.summary().nrows(); // 1
