    SummedAreaTable

    class SummedAreaTable
    #include <datamunge/algorithms/summed_area_table.hpp> source

    Own a checked integral image for constant-time rectangle sums. Complete finite rectangular grid validation and an optional actual prefix history. Object owns table storage. Const queries are independently readable, with no shared mutable state. Build is linear; inclusive queries use four reads.

    Example
    dm::algorithms::SummedAreaTable s({{1,2}});
std::print("{}\n",s.rect_sum(0,0,0,1)); // 3

    Build an owned checked zero-bordered integral image. Validates every finite rectangular row before allocation. Empty rows/columns are retained as empty geometry with a zero border; no nonempty rectangle can be queried. Computes input+above+left-diagonal in double, rejecting nonfinite intermediates. O(rows*cols) build time/storage, optional actual per-cell records. Subsequent reads are const and have no shared mutation. Cancellation/rounding may differ from direct summation; only exact small integer examples promise exact equality.

    Parameters
    grid

    Complete borrowed finite rectangular row-major input.

    options

    Zero-border cell/capture budgets; defaults1million and capturefalse.

    Throws
    std::invalid_argument

    Ragged or nonfinite grid.

    std::length_error

    Complete table or actual record capacity/budget exceeded.

    std::overflow_error

    Actual prefix arithmetic is nonfinite.

    Example
    dm::algorithms::SummedAreaTable s({{1,2},{3,4}});
std::print("{}\n",s.rect_sum(0,0,1,1)); // 10
