    struct datamunge::algorithms

    FPGrowthWork

    struct FPGrowthWork
    #include <datamunge/algorithms/fp_growth.hpp> source

    Actual build, insertion, header, parent-walk and DFS counts. Counts exclude validation, allocation, sort comparisons, hashing internals and capture copies. Weighted counts contribute one visit per stored item, not weight visits. Root creation is counted through trees_built; nodes_created excludes roots. Peak node records include only trees resident in active DFS frames, excluding temporary child/conditional buffers and retained history.

    Example
    dm::algorithms::FPGrowthWork x{};
std::cout << x.nodes_created; // 0
