    DoomsdayYear

    struct DoomsdayYear
    #include <datamunge/algorithms/doomsday.hpp> source

    Owned actual year terms of Conway's Doomsday rule. Uses astronomical year numbering, including zero and negative years, and floor division for centuries. All weekday codes are Sunday=0 through Saturday=6. The dozen decomposition is an equivalent mental-arithmetic identity evaluated alongside the direct offset, not a second weekday solver. Default fields are an uncomputed placeholder, not the terms of year zero. O(1), no allocation, input references or shared mutable state.

    Example
    const auto y=dm::algorithms::doomsday_year_trace(2025);
std::print("{} {} {}\n",y.century_anchor,y.year_in_century,y.doomsday); // 2 25 5
    References

    • S. W. Graham (1995), The Doomsday Rule (notes on Conway's method), https://people.se.cmich.edu/graha1sw/pub/doomsday/Doomsday.pdf
