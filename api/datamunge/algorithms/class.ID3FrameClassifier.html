    ID3FrameClassifier

    class ID3FrameClassifier
    #include <datamunge/algorithms/id3_diagnostics.hpp> source

    ID3 with frozen categorical encoding of named numeric or string DataFrame columns. All predictor values are categories, including numeric columns: no thresholds, scaling or ordering assumptions. Dictionaries are learned only on training rows, assigning nonnegative codes in first-occurrence order. New levels map to -1 and use the native local-majority fallback. Nulls and nonfinite numeric predictors are rejected, rather than silently omitted or imputed. Labels are numeric ints. Models own their tree/schema/dictionaries. Const inference has no shared mutation.

    Example
    const auto f=dm::datasets::titanic().select({"Sex","Pclass","Survived"});
const dm::algorithms::ID3FrameClassifier m(f,{"Sex","Pclass"},"Survived",2);
std::print("{}\n",m.predict(f).size()); // 891
