    struct datamunge::algorithms

    GeohashBit

    struct GeohashBit
    #include <datamunge/algorithms/geohash.hpp> source

    One actual coordinate comparison and axis-endpoint update. bit_in_symbol is zero-based 0..4 before the group count increments. symbol_value is the actual accumulator after shifting in this bit. longitude=true selects the longitude interval. Exact equality to midpoint chooses upper. No input is borrowed and no event is reconstructed from a final key.

    Example
    const auto t=dm::algorithms::geohash_encode_trace(42.6,-5.6,1);
std::cout << t.bits[0].longitude << ' ' << t.bits[0].upper; // 1 0
