    class datamunge::algorithms

    Rc4

    class Rc4
    #include <datamunge/algorithms/rc4.hpp> source

    Historical RC4 raw-byte stream state with canonical KSA and PRGA. RC4 has known key-stream biases and is prohibited in TLS by RFC7465; this class is for historical/conformance study, not a modern security construction. A fresh nonempty raw byte key initializes the256-byte identity permutation then256 KSA swaps. Copies duplicate raw state; mutating a shared instance needs synchronization. Constant state storage; constructor O(256), each next O(1). Owns no key/history pointer after construction.

    Example
    dm::algorithms::Rc4 stream("Key");
std::print("{:02x}\n",unsigned(stream.next())); // eb
    References

    • RFC6229 RC4 test vectors, https://www.rfc-editor.org/rfc/rfc6229; RFC7465, https://www.rfc-editor.org/rfc/rfc7465

    See also

    rc4_trace(), next_step()

    Members

    Constructors

    Rc4()Initialize from raw key bytes and optionally append the actual256 KSA records. Validates a nonempty key before any modulo/index operation. Embedded NUL and high bytes are supported. For keys longer than256 bytes the classic256-iteration KSA reads only the first256 bytes, as before. Optional caller history is appended synchronously and is never retained by the stream; allocation failure may leave a caller vector partially appended.

    Functions

    next()Consume one canonical PRGA byte through the actual-step producer. Advances i/j, swaps the actual permutation entries and reads one actual output byte. Constant work/storage, no allocation.
    next_step()Consume one PRGA byte and return its actual accumulator/swap/lookup record. This is the same producer used by next(); it never replays a previous transition. The returned scalar record owns its values and consumes exactly one output byte. Constant work/storage, no allocation.
    state()Copy the actual permutation and accumulators without advancing the stream. Copies256 bytes and two accumulators, with no allocation; a snapshot is raw state, not a fresh key or independent stream.
