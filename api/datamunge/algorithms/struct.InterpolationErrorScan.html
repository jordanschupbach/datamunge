    InterpolationErrorScan

    struct InterpolationErrorScan
    #include <datamunge/algorithms/cubic_spline.hpp> source

    Owned finite-query error census for two scalar functions, with sampled extrema only. Predictions and references are evaluated once each per query, in that order. Empty input has has_samples=false and zero max/RMS/index placeholders. Worst index is the first maximum absolute error, including first-zero ties. A grid maximum is not a certified supremum between queries. RMS uses scaled differences to avoid squaring large errors directly. All arrays are owned.

    Example
    const auto e=dm::algorithms::interpolation_error_scan([](double x){return x;},[](double){return 0.;},{-2,0,2});
std::print("{} {}\n",e.max_abs_error,e.worst_index); // 2 0
