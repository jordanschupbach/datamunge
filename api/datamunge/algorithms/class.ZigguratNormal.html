    ZigguratNormal

    class ZigguratNormal
    #include <datamunge/algorithms/ziggurat.hpp> source

    Reusable 128- or 256-layer Ziggurat sampler for the standard normal distribution.

    Tables use f(x)=exp(-x*x/2), zero-based strips from the tail to the peak, and separate uniform draws for the horizontal coordinate and strip index. Construction uses O(layers) storage/time. Sampling has expected O(1) cost and unbounded rejection-loop worst case. Const methods share no mutable state; callers must not share a mutable engine between concurrent calls. Pseudorandom sequences depend on the standard library's uniform distributions.

    Example
    const dm::algorithms::ZigguratNormal sampler(256);
std::mt19937_64 rng(42);
const double z = sampler.sample(rng);
    References

    • G. Marsaglia and W. W. Tsang (2000), The Ziggurat Method for Generating Random Variables, Journal of Statistical Software 5(8), https://doi.org/10.18637/jss.v005.i08

    • J. A. Doornik (2005), An Improved Ziggurat Method to Generate Normal Random Samples, https://doornik.com/research/ziggurat.pdf (separate index and coordinate draws).

    table

    #source
    dstruct::DataFrame table() const

    Inspect the envelope boundaries and exact per-proposal fast-path probabilities.

    For layer i>0 the rectangle has width outer=x[i] and height f(inner)-f(outer), with inner=x[i+1]. Row zero describes the base proposal with outer=V/f(r), inner=r, lower=0, upper=f(r). Its rectangle_area is the area of that proposal rectangle, equal to the combined area of the physical base rectangle and normal tail.

    Returns

    Owned columns layer, outer, inner, lower, upper, rectangle_area, fast_fraction; O(layers) time/storage.

    Example
    const auto table = dm::algorithms::ZigguratNormal().table();
const auto rows = table.nrows(); // 256
    References

    • J. A. Doornik (2005), https://doornik.com/research/ziggurat.pdf, section 2.

    diagnostics

    #source
    dstruct::DataFrame diagnostics(std::size_t count, std::uint64_t seed = 2024) const

    Count actual proposal, wedge, tail and retry paths over a seeded run.

    Returns one row: layers, draws, proposals, fast, wedge, tail, rejected, tail_trials, fast_per_proposal, expected_fast_per_proposal and expected_acceptance. fast+wedge+tail==draws and proposals==draws+rejected. Tail rejection attempts are counted separately in tail_trials.

    Parameters
    count

    Number of returned samples, positive.

    seed

    Local engine seed, default 2024; same sequence as draw(count,seed).

    Returns

    Owned counts and theoretical probabilities; O(count) expected time.

    Throws
    std::invalid_argument

    If count is zero.

    Example
    const auto d = dm::algorithms::ZigguratNormal().diagnostics(1000);
const double n = d.double_at("draws", 0); // 1000

    simulate_measurements

    #source
    dstruct::DataFrame simulate_measurements(
    const dstruct::DataFrame & frame,
    const std::string & mean_column,
    const std::string & se_column,
    std::size_t count = 100000,
    std::uint64_t seed = 2024) const

    Simulate independent Gaussian measurement replicates around tabulated estimates.

    For each row generate Y*=mean+standard_error*Z; this is a conditional measurement model, not a fitted hierarchical or posterior distribution. Retains all input columns and appends mc_mean, mc_sd (sample sd), mc_positive, normal_positive and mc_positive_se. The last is the theoretical Bernoulli Monte Carlo SE using the exact normal probability. O(rows*count) expected time and O(rows) output plus copied input storage.

    Parameters
    frame

    Input measurements, borrowed and unchanged.

    mean_column

    Numeric finite means, no nulls.

    se_column

    Numeric finite non-negative standard errors, no nulls.

    count

    Replicates per row, at least two; default 100000.

    seed

    Local engine seed; default 2024. Rows consume successive draws.

    Returns

    An owned augmented frame. Zero scale gives deterministic replicates.

    Throws
    std::invalid_argument

    If data/count is invalid or an output column already exists.

    std::out_of_range

    If either named column is absent.

    Example
    const auto schools = dm::datasets::eight_schools();
const auto simulated = dm::algorithms::ZigguratNormal().simulate_measurements(
    schools, "effect", "std_error", 1000);
const auto rows = simulated.nrows(); // 8
