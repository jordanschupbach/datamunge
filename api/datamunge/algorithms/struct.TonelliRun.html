    struct datamunge::algorithms

    TonelliRun

    struct TonelliRun
    #include <datamunge/algorithms/tonelli_shanks.hpp> source

    Own TonelliRun values for one independent native execution. Fields describe actual producing values or policy units. In-class initializers define defaults. Containers own their values; constructing a record alone performs no algorithm work and retains no caller storage or shared mutable state.

    Example
    dm::algorithms::TonelliRun r{};
(void)r;
