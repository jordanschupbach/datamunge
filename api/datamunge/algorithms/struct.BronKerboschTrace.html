    struct datamunge::algorithms

    BronKerboschTrace

    struct BronKerboschTrace
    #include <datamunge/algorithms/bron_kerbosch.hpp> source

    Owned maximal cliques, actual frames, histogram and logical search counters. Clique members are sorted; outer order is deterministic depth-first discovery order, preserving the historical implementation. The empty zero-vertex graph emits one empty clique. Counts describe this library's vector/matrix search, not wall time or a general optimal-time guarantee. Nodes add O((n+1)*C) retained vertex storage for C calls; ordinary enumeration allocates no diagnostic records.

    Example
    const auto trace=dm::algorithms::bron_kerbosch_trace(3,{{1},{0,2},{1}});
std::print("{} {}\n",trace.cliques.size(),trace.clique_size_counts[2]); // 2 2
