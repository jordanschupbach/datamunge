    EasterRangeSummary

    struct EasterRangeSummary
    #include <datamunge/algorithms/computus.hpp> source

    Owned first-tie extrema and 35 date counts for an inclusive year range. Bins zero through 34 mean March 22 through April 25 on a fixed March axis. Counts describe deterministic Gregorian ecclesiastical rules over the selected years, not an astronomical forecast or a random-sampling probability model. Earliest/latest compare month/day, not chronology; equal dates keep the first ascending year. Storage is constant, with no per-year records or allocation. Default storage alone is not a valid summary.

    Example
    const auto s=dm::algorithms::computus_gregorian_summary(2000,2040);
std::print("{} {} {}\n",s.earliest_year,s.latest_year,s.spread_days); // 2008 2038 33
