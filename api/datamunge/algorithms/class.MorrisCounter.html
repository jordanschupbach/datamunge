    MorrisCounter

    class MorrisCounter
    #include <datamunge/algorithms/approximate_counting.hpp> source

    A probabilistic (Morris) counter with a tunable base for accuracy/space trade-off.

    Members

    Constructors

    MorrisCounter()

    Functions

    increment()Process one event: increment the exponent with probability \(a^{-c}\).
    add()Process events events at once, with the same distribution as calling increment() that many times.
    exponent()The stored exponent \(c\) (this, in bits, is all the counter occupies).
    base()The base \(a\).
    register_bits()Bits needed to store the current exponent, \(\lceil\log_2(c+1)\rceil\) (0 for \(c=0\)).
    estimate()Unbiased estimate of the number of events seen: \((a^{c}-1)/(a-1)\) ( \(2^c-1\) for base 2).

    Parameters
    base

    The base \(a>1\). Base 2 is the classic counter; values closer to 1 (e.g. 1.08) shrink the variance at the cost of more bits in \(c\).

    Throws
    std::invalid_argument

    if base is not greater than 1.

    add

    #source
    void add(std::uint64_t events, std::mt19937_64 & rng)

    Process events events at once, with the same distribution as calling increment() that many times.

    Instead of one coin per event it draws the geometric waiting time until the next increment, so the cost is proportional to the number of increments, about \(\log_a n\), not to events.

    Number of events to add.
