    OnlineCovariance

    class OnlineCovariance
    #include <datamunge/algorithms/online_statistics.hpp> source

    Owned atomic paired Welford covariance and marginal variance states. Finite pairs only; the complete paired update and both marginal additions are validated on copies before mutation, including count/finite-state guards. Historical safe double covariance order is retained with widened fallback. Empty/singleton sample covariance and zero-spread correlation return0. Computed correlation uses centered moments with widened divisions; no universal accuracy, exact unit range after rounding or statistical independence claim. O(1) work/state, no retained caller references or shared mutable state.

    Example
    dm::algorithms::OnlineCovariance c;c.add(1,2);c.add(3,6);std::print("{}\n",c.correlation()); // 1
    References

    • B. P. Welford(1962), Note on a Method for Calculating Corrected Sums of Squares and Products, doi:10.1080/00401706.1962.10490022.

    • T. F. Chan, G. H. Golub and R. J. LeVeque(1983), Algorithms for Computing the Sample Variance: Analysis and Recommendations, doi:10.1080/00031305.1983.10483115. Native finite-state guards/widened fallback are explicit extensions.
