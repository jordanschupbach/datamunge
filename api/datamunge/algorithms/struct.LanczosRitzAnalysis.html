    LanczosRitzAnalysis

    struct LanczosRitzAnalysis
    #include <datamunge/algorithms/lanczos_analysis.hpp> source

    Owned actual native tridiagonal eigensystem and explicit full-matrix Ritz diagnostics. values are descending native Jacobi approximations; coefficients[j][i] is mode i's coefficient of actual basis vector V[j]. vectors[i] is the formed full Ritz vector. Residuals explicitly evaluate A*y-theta*y, rather than using only terminal_beta*last_coefficient, which omits reorthogonalization/roundoff defects. Orthogonality/projection errors are observed widened maxima, not exact certificates or evidence the supplied result originated from A.

    Example
    const std::vector<std::vector<double>> A={{2}};
const auto a=dm::algorithms::lanczos_ritz_analysis(A,dm::algorithms::lanczos_iteration(A,{1},1));
std::print("{} {}\n",a.values[0],a.residual_norms[0]); // 2 0
