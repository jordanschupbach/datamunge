    KalmanFilter

    class KalmanFilter
    #include <datamunge/filter/kalman_filter.hpp> source

    Owned fixed-model linear covariance Kalman filter with optional full RTS smoothing. Models x_k=F*x_(k-1)+w and z_k=H*x_k+v with caller-supplied Q/R covariance. Inputs are copied; predict/update mutate this instance, independent copies evolve separately. Concurrent mutation requires synchronization. Shape checks do not establish finite values, covariance PSD, noise independence or valid probability assumptions: those remain caller preconditions. Uses explicit LU inverses and simplified covariance updates, not a Joseph/square-root method. Under a valid linear Gaussian model the mean is conditional MMSE; floating output is approximate. No universal realized-error or numerical PSD guarantee.

    Example
    dm::filter::KalmanFilter k({{1}},{{1}},{{1}},{{3}},{0},{{4}});
k.predict();k.update({2});std::print("{}\n",k.state()[0]); // 1.25
    References

    • Kalman(1960), A New Approach to Linear Filtering and Prediction Problems, https://doi.org/10.1115/1.3662552.

    • Rauch,Tung,Striebel(1965), Maximum likelihood estimates of linear dynamic systems, https://doi.org/10.2514/3.3166.

    Constructors

    KalmanFilter()Copy a fixed linear model and initial state, validating matrix dimensions. No finite/covariance-definiteness checks are added; the caller supplies statistically valid finite matrices and invertible required innovation/prediction covariances.     Functions

    predict()Predict x=F*x and P=F*P*F^T+Q once, mutating the current state. Matrix arithmetic is ordinary floating point; nonfinite results propagate. O(n^3) dense work/O(n^2) temporaries; no rollback guarantee on exceptions.
    update()Correct from z using innovation covariance, LU gain and simplified posterior covariance. Computes y=z-H*x,S=H*P*H^T+R,K=P*H^T*S^-1, then x+=K*y and P=(I-K*H)*P. Requires finite statistically valid inputs/invertible S; shape validation alone does not ensure those properties. Rounding may lose symmetry/PSD; not Joseph form. Mutates state without rollback guarantee.
    state()Copy the current state mean without another filter update.
    covariance()Copy the current covariance without recomputing a filter update.
    filter()Predict then correct every observation in order, owning actual posterior states. Empty input returns empty and leaves state unchanged. Ends at the final posterior, so repeated calls continue this instance rather than restarting. O(T) dense filter steps plus O(T*n^2) owned output; input remains unchanged. A later invalid measurement can follow already committed predictions/updates; failure does not roll the whole sequence back.
    smooth()Execute one actual forward pass and an RTS backward pass on the full sequence. Owns actual prediction/posterior arrays during execution, then returns causal and smoothed means/covariances. No repeated-prefix runs. Leaves this filter at its final forward posterior. Empty input returns empty unchanged. Exact-model conditional covariance reduces; realized error need not decrease on every sequence. Ordinary matrix arithmetic can lose symmetry/PSD. O(T) dense steps/backward solves, O(T*n^2) intermediate/output storage.
