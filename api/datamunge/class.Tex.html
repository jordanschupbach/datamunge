    Tex

    class Tex
    #include <datamunge/tex.hpp> source

    An owned TeX fragment with nonmutating mathematical composition helpers.

    Construction copies raw TeX bytes, including embedded NULs; it does not parse, validate or escape them. Methods return independent values and preserve the source. Labels and delimiters are raw TeX too; text() escapes literal prose. Compose in math mode, then call display() or inline_math() at the document boundary. Requires amsmath for annotations, text and matrix environments. Const operations may run concurrently; ordinary C++ rules apply to assignment. Allocation failures propagate as std::bad_alloc throughout this value type.

    Example
    const auto x = dm::Tex("x").underset("i").superscript("2");
std::print("{}\n", x.display());
    References

    • American Mathematical Society, User's Guide for the amsmath Package, sections 4.10-4.14: https://www.latex-project.org/help/documentation/amsldoc.pdf

    delimit

    #source
    Tex delimit(std::string_view left = "(", std::string_view right = ")") const

    Enclose the fragment in automatically sized paired delimiters.

    Parameters
    left

    Raw TeX left delimiter, default "("; e.g. "[", "\\langle" or ".".

    right

    Raw TeX right delimiter, default ")"; e.g. "]", "\\rangle" or ".".

    Returns

    Fragment wrapped in left/right commands. Delimiters are not validated; the caller supplies a valid pair. Spaces separate command names from content.

    Example
    std::print("{}\n", dm::Tex("x+y").delimit().superscript("-1"));

    display

    #source

    Wrap the completed fragment for Markdown/MEPML display mathematics.

    Returns

    Independent string with double-dollar delimiters on their own lines. Call once after composition; existing delimiters are not detected or removed.

    Example
