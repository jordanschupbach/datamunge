    DAG

    class DAG
    #include <datamunge/causal/dag.hpp> source

    An owned directed acyclic graph indexed by node numbers from zero.

    Example
    const dm::causal::DAG graph(3, {{0, 1}, {0, 2}, {1, 2}});

    Checks graphical conditional independence by ancestral moralization.

    Parameters
    x

    First endpoint index.

    y

    Distinct second endpoint index.

    given

    Distinct conditioning nodes, excluding x and y.

    Returns

    True when all paths are blocked given the supplied set.

    Throws
    std::invalid_argument

    Invalid indices, repeated nodes or endpoint conditioning.

    Example
    const dm::causal::DAG g(3, {{0, 2}, {1, 2}});
std::print("{}", g.d_separated(0, 1)); // true

    #source
    bool is_backdoor_adjustment(
    std::size_t exposure,
    std::size_t outcome,
    const std::vector< std::size_t > & given) const

    Checks Pearl’s back-door criterion for one exposure and one outcome.

    Parameters
    exposure

    Treatment node.

    outcome

    Distinct outcome node.

    given

    Candidate adjustment set of distinct non-endpoint nodes.

    Returns

    True when the set excludes exposure descendants and blocks all back-door paths.

    Throws
    std::invalid_argument

    Invalid endpoints or adjustment indices.

    Example
    const dm::causal::DAG g(3, {{0, 1}, {0, 2}, {1, 2}});
std::print("{}", g.is_backdoor_adjustment(1, 2, {0})); // true

    backdoor_adjustment

    #source
    std::optional< std::vector< std::size_t > > backdoor_adjustment(
    std::size_t exposure,
    std::size_t outcome,
    std::size_t max_size = 4,
    std::size_t max_sets = 10000) const

    Finds a minimum-cardinality back-door adjustment set by bounded search.

    Parameters
    exposure

    Treatment node.

    outcome

    Distinct outcome node.

    max_size

    Maximum number of adjustment nodes to try, default four.

    max_sets

    Maximum number of candidate sets evaluated, default 10000.

    Returns

    First minimum-cardinality set in index order, or nullopt if none within max_size.

    Throws
    std::invalid_argument

    Invalid endpoints or a zero search budget.

    std::length_error

    If the search budget is exhausted before a result is known.

    Example
    const dm::causal::DAG g(3, {{0, 1}, {0, 2}, {1, 2}});
std::print("{}", g.backdoor_adjustment(1, 2)->front()); // 0
