    struct datamunge::optim

    OptimizationRun

    struct OptimizationRun
    #include <datamunge/optim/analysis.hpp> source

    Result of a recorded optimizer call; no convergence certificate is inferred. exception is empty on normal return. A nonempty exception retains the last mutated coordinates and preceding callback evidence. value is the returned scalar (NaN on failure); checked_value and gradient_norm are post-run checks, excluded from fitting counters. A small smooth-gradient norm is inappropriate for proximal or constrained stationarity; use their mapping/KKT conditions.

    Example
    dm::optim::OptimizationRun r;
std::print("{}\n",r.exception.empty()); // true
