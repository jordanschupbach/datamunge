    LeastSquaresObjective

    class LeastSquaresObjective : public datamunge::optim::DifferentiableSeparableFunction
    #include <datamunge/optim/analysis.hpp> source

    Full-sum linear least squares with inspectable per-row components. evaluate/gradient are sums. SGD and SAGA use mean component gradients; SVRG uses the full gradient divided by n as its mean snapshot. All share the same unpenalised minimizer, but a step size must name its loss convention.

    Example
    dm::optim::LeastSquaresObjective f({{1},{1}},{1,3});
std::print("{}\n",f.num_functions()); // 2
