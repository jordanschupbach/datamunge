    NelderMeadOptions

    struct NelderMeadOptions
    #include <datamunge/optim/nelder_mead.hpp> source

    Configuration for NelderMead; fields retain their documented native defaults. Supply finite values in the supported ranges. Controls are copied at construction; validation, stopping and loss scaling belong to optimize().

    Example
    dm::optim::NelderMeadOptions o;
std::print("{}\n",o.max_iterations); // 2000
