    RBFGaussianProcessSurrogate

    class RBFGaussianProcessSurrogate : public datamunge::optim::BayesianSurrogate
    #include <datamunge/optim/rbf_gaussian_process_surrogate.hpp> source

    Exact Gaussian-process regression surrogate with the squared-exponential kernel \(s\exp(-\lVert x-x'\rVert^2/2\ell^2)\).

    fit() Cholesky-factors \(K+\sigma_n^2I=LL^\top\) once and solves for \(\alpha=(K+\sigma_n^2I)^{-1}(y-m)\); predict() then needs one forward substitution per point: mean \(m+k_*^\top\alpha\) and variance \(s-\lVert L^{-1}k_*\rVert^2\).

    The two-argument constructor keeps the original fixed setup: zero prior mean, unit signal variance, no normalisation or fitting, expected improvement. The options constructor adds value normalisation, marginal-likelihood fitting of the hyperparameters and other acquisitions. The kernel is isotropic, so the inputs should be on comparable scales.

    Example
    dm::optim::RBFGaussianProcessSurrogate gp(1.0, 0.0);
gp.fit({{0.0}, {2.0}}, {1.0, -1.0});
const auto p = gp.predict({1.0});
std::print("{:.4f} {:.4f}\n", p.mean, p.sd);  // 0.0000 0.5933
