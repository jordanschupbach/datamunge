    class datamunge::optim

    MOEAD

    class MOEAD
    #include <datamunge/optim/moead.hpp> source

    Approximate a multi-objective minimum using neighboring scalar subproblems. Weights use the largest Das-Dennis lattice fitting max(requested,m); exactly requested for two objectives. Neighbors use Euclidean weight distance; equal distances retain the standard sort's unspecified tie arrangement. Tchebycheff uses max(w,1e-6)*abs(f-ideal); weighted_sum uses sum(w*(f-ideal)). No global archive or convergence guarantee. Final non-dominated extraction is quadratic in population size, so the complete optimizer is not merely O(N*T). Fixed seed repeats on the same standard library; callbacks and shared variation operators remain observable. Const calls share no optimizer state, but the callback is mutable and responsible for its own concurrency behavior.

    Example
    dm::optim::MOEAD solver;
std::print("{}\n",solver.options().population_size); // 100
    References

    • Q. Zhang and H. Li (2007), MOEA/D: A multiobjective evolutionary algorithm based on decomposition, IEEE Transactions on Evolutionary Computation11,712–731, doi:10.1109/TEVC.2007.892759.

    std::vector< ParetoPoint > optimize(
    MultiObjectiveFunction & function,
    const std::vector< double > & lower_bound,

    Run the canonical solver and return its actual final non-dominated subset. At least two finite objectives of fixed shape are required. First callback is a discarded dimension probe, then N initial evaluations and N per sweep. No partial front on failure; earlier callback effects remain. Bounds/options validate before callbacks, objective shape afterward. Setup uses O(N^2*m) distance work with O(N^2 log N) comparator overhead, stored neighborhoods O(N*T). Each sweep costs O(N*(n+T*m)) excluding callbacks and shared variation details. Final dominance extraction O(m*N^2). No universal timing guarantee.

    Parameters
    function

    Mutable objective, all components minimized, exceptions propagate.

    lower_bound

    Nonempty finite lower bounds.

    upper_bound

    Matching finite strictly higher bounds with finite widths.

    Returns

    Owned actual final front, including identical non-dominated duplicates.

    Throws
    std::invalid_argument

    If bounds/options or fixed objective shape is invalid.

    std::domain_error

    If an objective result is nonfinite.

    std::overflow_error

    If variation/scalarization arithmetic is unrepresentable.

    std::length_error

    If population/objective count exceeds1000000 or evaluation count overflows.

    MOEADTrace trace(
    MultiObjectiveFunction & function,
    const std::vector< double > & lower_bound,

    Capture actual setup, offspring and scalar decisions of the same producer. No replay or callback/RNG changes. Online quota admission returns no partial trace; earlier callbacks can already have occurred when a quota fails. Storage is proportional to admitted entries, in addition to ordinary driver storage.

    Parameters
    function

    Mutable fixed-shape finite objective, exceptions propagate.

    lower_bound

    Nonempty finite lower bounds, retained by value.

    upper_bound

    Matching finite upper bounds, retained by value.

    max_entries

    Actual capture-unit cap, default1000000; zero disables.

    Returns

    Owned complete execution and final front.

    Throws
    std::invalid_argument

    If bounds/options/objective shape is invalid.

    std::domain_error

    If objective values are nonfinite.

    std::overflow_error

    If arithmetic is unrepresentable.

    std::length_error

    If geometry/count or actual capture quota is exceeded.

    std::bad_alloc

    If allocation fails.

    Example

std::print("{}\n",t.evaluations); // 4
