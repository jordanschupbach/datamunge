    Histogram

    class Histogram : public datamunge::graphics::RPlot
    #include <datamunge/plot/histogram.hpp> source

    An owned histogram plot with equal-width bins and chainable heading setters, like R's hist(x, breaks = bins).

    Supports the same rendering, export, and plot layers as RPlot (show(), save(), to_svg(), | dm::legend(), ...). Bins span [min, max] of the data in equal widths; bin intervals include their left edge, and the maximum value is included in the final bin. Bars show counts. A new histogram is titled "Histogram" with axis labels "x" and "Frequency".

    Every chainable setter and layer verb inherited from RPlot (set_col(), size(), abline(), ...) is retyped to return Histogram&, so a whole chain can be stored as a Histogram.

    Example
    const auto iris = dm::datasets::iris();
dm::Histogram hist = dm::Histogram(iris.get_column("Sepal.Length").values())
                         .set_title("Iris Sepal Length Distribution")
                         .set_xlab("Sepal Length");
hist.show();

    Histogram

    #source
    explicit Histogram(
    std::vector< double > data,
    std::size_t bins = 10,
    std::string label = "",
    graphics::RGB color = {96, 165, 250})

    Bins a copy of finite observations; defaults to ten bins and a frequency axis.

    Bin width is (max - min) / bins; constant observations use a unit-wide range starting at their value. The data are copied (or moved from an rvalue) only for binning; the plot keeps bin centers and counts, not the raw observations.

    Parameters
    data

    Finite observations; NaN and infinities are rejected, not dropped.

    bins

    Number of equal-width bins (default 10).

    label

    Series label; nonempty adds a row to the automatic legend.

    color

    Bar fill color (default light blue {96, 165, 250}).

    Throws
    std::invalid_argument

    If data is empty or non-finite, bins is zero, or the bin range is not a finite positive width.

    Example
    const auto x = dm::rnorm(0, 1, 500);
auto hist = dm::Histogram(x, 25, "N(0, 1)", dm::RGBA{220, 38, 38, 0.6});
std::print("{} {}\n", hist.series()[0].x.size(), hist.y_label_text());  // 25 Frequency
hist.save("normal_hist.png");
