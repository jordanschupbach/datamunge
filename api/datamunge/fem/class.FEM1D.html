    class datamunge::fem

    FEM1D

    class FEM1D
    #include <datamunge/fem/fem1d.hpp> source

    Solve steady or transient one-dimensional divergence-form problems with P1 Galerkin FEM. Models -(p*u')'+q*u=f and u_t-(p*u')'+q*u=f on a caller-supplied mesh. Requires at least two finite strictly increasing nodes, finite coefficient/ boundary/source data and finite assembled arithmetic with nonzero Thomas pivots; those mathematical/geometry preconditions are not fully validated. Positive p, nonnegative q/Robin data and adequate constraints give the usual coercive model. Piecewise-constant p/q can be scalar or one per element. Results own their values; input mesh/data are unchanged. Calls share no mutable global state, while callback side effects/concurrency belong to the caller.

    Example
    const auto r=dm::fem::FEM1D::solve_builtin(dm::fem::make_uniform_mesh1d(0,1,2),{1},{0},"constant",{1},{},{});
std::print("{}\n",r.value_at(1)); // 0.125
    References

    • MFEM, Weak Formulations: https://mfem.org/fem_weak_form/ . This native implementation uses P1 intervals, three-point Gauss-Legendre loads and a tridiagonal direct solve.

    See also

    Mesh1D, FEM1DResult, FEM1DTimeSeries

    Used in reports

    Finite Elements: Nodal Values, Whole Fields and Actual Time Levels

    Members

    Static functions

    solve()Solve the steady P1 system for -(p*u')'+q*u=f with endpoint boundary data. Follows FEM1D's mesh/coefficient/finite-arithmetic/nonsingular-pivot preconditions. Uses three-point Gauss-Legendre quadrature of f times each local basis, natural boundary terms and symmetric Dirichlet elimination, then Thomas elimination. O(N) work/storage for N nodes; invokes the source three times per element. No callback pointer is retained. Independent calls share no mutable state.
    solve_builtin()Solve the steady system using an owned named spatial source, without a director callback. Shares the live-source solver and its mathematical/precondition/storage contracts. Sources: zero=0 (params unused); constant=c ({1}); linear=m*x+c ({1,0}); polynomial=sum(params[i]*x^i) (empty gives0); sine=A*sin(w*x+phase) ({1,1,0}). Missing trailing parameters use those defaults; extra parameters are ignored except polynomial, which uses all entries. Name matching is exact/case-sensitive.
    solve_transient()Integrate u_t-(p*u')'+q*u=f with P1 space and actual backward-Euler time intervals. Shares FEM1D's spatial/finite-arithmetic/nonzero-pivot preconditions. Source and boundary data represent a time-independent model; the live callback is actually reevaluated three times per element at every time advance, not cached. Stores initial u0 as supplied, then imposes boundary data at later solves. Nominal step dt is shortened at t_end; actual positive time differences enter the mass term. Stops once t_end is reached, avoiding a duplicate rounded last time even when ceil(t_end/dt) overestimates the number of advances. O(S*N) work/output storage for S advances/N nodes, O(N) assembly temporaries; no optional trace or quota. Backward Euler is unconditionally stable for the coercive semidiscrete model, not a guarantee of arbitrary-step accuracy or finite arithmetic for arbitrary parameters. Input arrays remain unchanged; callback exceptions/side effects/concurrent safety belong to caller.
    solve_transient_builtin()Integrate the same backward-Euler model with a named source and no callback subclass. Uses the same private source construction as solve_builtin() and the same actual time loop as solve_transient(); no second solver or per-language glue. Names/defaults: zero=0; constant=c ({1}); linear=m*x+c ({1,0}); polynomial=sum(params[i]*x^i) (empty0); sine=A*sin(w*x+phase) ({1,1,0}). Extra entries ignored except polynomial; exact case-sensitive names. Source objects are local and synchronous; results own values, not callback aliases. All spatial/time/initial-state, complexity and stability contracts follow solve_transient(); ordinary output has no optional history/quota.

    Solve the steady P1 system for -(p*u')'+q*u=f with endpoint boundary data. Follows FEM1D's mesh/coefficient/finite-arithmetic/nonsingular-pivot preconditions. Uses three-point Gauss-Legendre quadrature of f times each local basis, natural boundary terms and symmetric Dirichlet elimination, then Thomas elimination. O(N) work/storage for N nodes; invokes the source three times per element. No callback pointer is retained. Independent calls share no mutable state.

    Assemble, impose boundary conditions and solve the canonical steady P1 system.

    Parameters
    mesh

    Borrowed mesh with at least two finite strictly increasing nodes.

    p

    Borrowed diffusion coefficient: length1 or one per element.

    q

    Borrowed reaction coefficient: length1 or one per element.

    f

    Borrowed spatial source; evaluate() may have caller-owned side effects.

    left

    Left endpoint condition, with outward normal -1.

    right

    Right endpoint condition, with outward normal +1.

    Returns

    Owned original nodes and computed nodal values.

    Throws
    std::invalid_argument

    If p/q are empty or have the wrong lengths.

    std::bad_alloc

    If assembly/result storage cannot be allocated; callback exceptions propagate.

    solve_transient

    #source
    static FEM1DTimeSeries solve_transient(
    const Mesh1D & mesh,
    const std::vector< double > & p,
    const std::vector< double > & q,
    ScalarField1D & f,
    const BoundaryCondition1D & left,
    const BoundaryCondition1D & right,
    const std::vector< double > & u0,
    double t_end,
    double dt)

    Integrate u_t-(p*u')'+q*u=f with P1 space and actual backward-Euler time intervals. Shares FEM1D's spatial/finite-arithmetic/nonzero-pivot preconditions. Source and boundary data represent a time-independent model; the live callback is actually reevaluated three times per element at every time advance, not cached. Stores initial u0 as supplied, then imposes boundary data at later solves. Nominal step dt is shortened at t_end; actual positive time differences enter the mass term. Stops once t_end is reached, avoiding a duplicate rounded last time even when ceil(t_end/dt) overestimates the number of advances. O(S*N) work/output storage for S advances/N nodes, O(N) assembly temporaries; no optional trace or quota. Backward Euler is unconditionally stable for the coercive semidiscrete model, not a guarantee of arbitrary-step accuracy or finite arithmetic for arbitrary parameters. Input arrays remain unchanged; callback exceptions/side effects/concurrent safety belong to caller.

    Advance the actual backward-Euler system with finite controls and unique terminal time.

    Parameters
    mesh

    Borrowed valid mesh with at least two finite increasing nodes.

    p

    Borrowed scalar/per-element diffusion coefficient.

    q

    Borrowed scalar/per-element reaction coefficient.

    f

    Borrowed spatial callback, reevaluated at every advance.

    left

    Fixed left condition, with outward normal -1.

    right

    Fixed right condition, with outward normal +1.

    u0

    Borrowed finite initial nodal values, exactly one per mesh node.

    t_end

    Positive finite final time, in time units.

    dt

    Positive finite nominal time step in the same units; may exceed t_end.

    Returns

    Owned nodes, initial state and strictly advancing slices ending at t_end.

    Throws
    std::invalid_argument

    For fewer than two nodes, wrong coefficient/u0 lengths or nonpositive/nonfinite time controls.

    std::length_error

    If frame counts, vector capacities or total scalar count cannot be represented.

    std::overflow_error

    If rounded time products cannot advance before t_end.

    std::bad_alloc

    If output/assembly storage cannot be allocated; callback exceptions propagate.

    Example
    struct Zero final:dm::fem::ScalarField1D{double evaluate(double) override{return 0;}} source;
const auto t=dm::fem::FEM1D::solve_transient(dm::fem::make_uniform_mesh1d(0,1,2),{1},{0},source,{},{},{0,1,0},.5,.5);
std::print("{} {:.6f}\n",t.num_steps(),t.value_at(1,1)); // 2 0.142857
    References

    • Arnold (2012), Numerical Analysis of Partial Differential Equations, chapter5 section2. https://www-users.cse.umn.edu/~arnold/8445.f12/notes.pdf . Native load quadrature, fixed data and rounded/shortened time grid are implementation choices.

    static FEM1DTimeSeries solve_transient_builtin(

    Integrate the same backward-Euler model with a named source and no callback subclass. Uses the same private source construction as solve_builtin() and the same actual time loop as solve_transient(); no second solver or per-language glue. Names/defaults: zero=0; constant=c ({1}); linear=m*x+c ({1,0}); polynomial=sum(params[i]*x^i) (empty0); sine=A*sin(w*x+phase) ({1,1,0}). Extra entries ignored except polynomial; exact case-sensitive names. Source objects are local and synchronous; results own values, not callback aliases. All spatial/time/initial-state, complexity and stability contracts follow solve_transient(); ordinary output has no optional history/quota.

    Invoke the actual transient loop with the same local named-source visitor as steady solves.

    Parameters
    mesh

    Borrowed valid finite increasing mesh, with at least two nodes.

    p

    Borrowed scalar/per-element diffusion coefficient.

    q

    Borrowed scalar/per-element reaction coefficient.

    source

    Exact name zero, constant, linear, polynomial or sine.

    source_params

    Borrowed positional parameters; omitted trailing values use the defaults above.

    left

    Fixed left boundary condition using outward normal -1.

    right

    Fixed right boundary condition using outward normal +1.

    u0

    Borrowed finite initial values, exactly one per spatial node.

    t_end

    Positive finite final time.

    dt

    Positive finite nominal time step; final interval is shortened as needed.

    Returns

    Owned initial state and actual strictly advancing backward-Euler slices.

    Throws
    std::invalid_argument

    For an unknown source, malformed coefficient/u0 lengths, fewer than two nodes or nonpositive/nonfinite time controls.

    std::length_error

    std::overflow_error

    If rounded time products cannot advance.

    std::bad_alloc

    If parameters, output or assembly storage cannot be allocated.
