    namespace datamunge

    datamunge::fem

    Native mesh-based P1 finite-element models and owned scalar-field solutions.

    datamunge/fem/fem1d.hpp

    Classes

    BoundaryCondition1DOwned endpoint data for Dirichlet, outward-conormal Neumann or Robin conditions. Dirichlet uses value as u; Neumann uses it as p*du/dn; Robin uses it as the reference value in p*du/dn+alpha*(u-value)=0. Alpha zero gives zero conormal. For coercive diffusion/heat models use nonnegative Robin alpha and sufficient constraints/reaction to remove the constant nullspace. Unsupported enum values and nonfinite data are outside the solver's preconditions, not fully validated.
    FEM1DSolve steady or transient one-dimensional divergence-form problems with P1 Galerkin FEM. Models -(p*u')'+q*u=f and u_t-(p*u')'+q*u=f on a caller-supplied mesh. Requires at least two finite strictly increasing nodes, finite coefficient/ boundary/source data and finite assembled arithmetic with nonzero Thomas pivots; those mathematical/geometry preconditions are not fully validated. Positive p, nonnegative q/Robin data and adequate constraints give the usual coercive model. Piecewise-constant p/q can be scalar or one per element. Results own their values; input mesh/data are unchanged. Calls share no mutable global state, while callback side effects/concurrency belong to the caller.
    FEM1DResultOwned nodal P1 steady solution, with checked scalar accessors for language bindings. The continuous finite-element field is the piecewise-linear interpolant of these values; nodal agreement alone does not imply agreement between nodes. Copies own their arrays, with no mesh/callback alias. Public edits can break array consistency; accessors check the actual requested vector bounds.
    FEM1DTimeSeriesOwned initial state and actual strictly advancing backward-Euler time slices. Solver output has one u row per time and one value per spatial node. Initial time zero/u0 are retained as supplied; later rows satisfy imposed boundary data. Times retain rounded nominal-step products with a shortened final interval; an already reached endpoint is not appended twice. Copies retain no mesh/source alias. Public edits may break consistency; accessors check actual vector bounds.

    Types and constants

    BCTypeenum Select an endpoint value or an outward-conormal natural boundary condition. The conormal p*du/dn uses -u' at the left and +u' at the right. Physical diffusive outward flux is its negative; these are different sign conventions.

    datamunge/fem/fem2d.hpp

    Classes

    FEM2DGalerkin finite-element solver for the 2D Poisson equation -k * (u_xx + u_yy) = f(x, y) on a triangular mesh, using piecewise-linear (P1) Lagrange elements and Dirichlet boundary conditions only (this "basic" 2D solver does not offer FEM1D's Neumann/Robin options). Internally assembles a sparse stiffness system and solves it with the conjugate-gradient solver (datamunge::linalg::cg) – the assembled matrices themselves are never exposed, matching this codebase's rule that linalg's sparse/dense matrix types are never SWIG-bound.
    FEM2DResultThe nodal solution of a 2D FEM Poisson solve.

    datamunge/fem/mesh1d.hpp

    Classes

    Mesh1DA 1D finite-element mesh: a strictly increasing sequence of node coordinates. Element i spans [nodes[i], nodes[i+1]] for i in [0, num_elements()) – no separate connectivity array is needed since consecutive nodes are always the two endpoints of one linear (P1) element. nodes is a public field for direct C++ construction, but (matching datamunge::ode::ODESolution's t/y fields – a swig-jse R-backend codegen bug hits plain vector<double> struct field getters) is not exposed to language bindings; node_at()/num_nodes() are the cross-language-safe accessors.

    Functions

    make_uniform_mesh1d()Builds a uniform mesh of num_elements equal-length elements on [a, b]. Throws std::invalid_argument if num_elements is 0 or b <= a.

    datamunge/fem/mesh2d.hpp

    Classes

    Mesh2DA 2D triangular finite-element mesh: shared vertex coordinates plus a triangle connectivity list. Reuses datamunge::geometry's Point2D and (Delaunay-oriented, always-counterclockwise) Triangle index type directly rather than duplicating them. nodes/triangles are public fields for direct C++ construction, but – same rationale as Mesh1D::nodes – are not exposed to language bindings; node_at()/ triangle_at()/num_nodes()/num_triangles() are the cross-language-safe accessors.

    Functions

    boundary_nodes()Node indices lying on the mesh's outer boundary: every node incident to a boundary edge (an edge belonging to exactly one triangle). Works generically for both a structured rectangular mesh (the domain's four sides) and an unstructured Delaunay mesh (the convex hull), returned in ascending order with no duplicates.
    make_mesh2d_from_points()Builds a mesh over the convex hull of an arbitrary point cloud via Delaunay triangulation (datamunge::geometry::delaunay_triangulation) – useful for unstructured domains a structured grid does not fit.
    make_rectangular_mesh2d()Builds a structured rectangular mesh on [x0, x1] x [y0, y1]: nx * ny grid cells, each split into two counterclockwise triangles, for a total of nx*ny*2 triangles and (nx+1)*(ny+1) nodes, ordered row-major (x fastest, then y). Throws std::invalid_argument if nx or ny is 0, or if x1 <= x0 or y1 <= y0.

    datamunge/fem/source_function.hpp

    Classes

    ScalarField1DA user-supplied scalar source-term function of one spatial variable, f(x). Director-enabled extension point (same pattern as datamunge::ode::RHS and datamunge::optim::ArbitraryFunction elsewhere in this codebase): subclass and override evaluate() in C++, or, via SWIG directors, in any binding with director support. Bindings without director support must instead use FEM1D::solve_builtin()'s fixed set of named source terms.
    ScalarField2DA user-supplied scalar source-term function of two spatial variables, f(x, y). Same director-enabled pattern as ScalarField1D; FEM2D::solve_builtin() is the fallback for bindings without director support.

    Select an endpoint value or an outward-conormal natural boundary condition. The conormal p*du/dn uses -u' at the left and +u' at the right. Physical diffusive outward flux is its negative; these are different sign conventions.
