    class datamunge::game

    Scene

    class Scene
    #include <datamunge/game/scene.hpp> source

    Owned authoring scene with validated, transactional entity edits and prefabs. IDs are never reused within a snapshot. Scene copies are separate snapshots; references must not be retained across replacement. Methods are single-writer.

    Example
    dm::game::Scene scene;const auto id=scene.create({});
std::print("{}\n",scene.alive(id)); // true
