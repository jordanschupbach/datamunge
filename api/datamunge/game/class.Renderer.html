    class datamunge::game

    Renderer

    class Renderer
    #include <datamunge/game/render.hpp> source

    Native offscreen Vulkan renderer retaining its own or a shared compute context. Procedural box/sphere/crystal intersections, GGX metallic/roughness lighting, geometric shadow rays, HDR/ACES presentation, screen-space AO and bitmap overlays run without NVRHI or a window. Frame shading/composition runs on the selected Vulkan device; capture is an explicit host readback. Single-writer. Shader arithmetic is float32. Geometry/lens values that overflow or underflow required positive float32 fields are rejected before drawing.

    Example
    if(dm::compute::probe({dm::compute::Backend::Vulkan,0}).available){
  dm::game::RenderConfig config;config.width=32;config.height=24;
  dm::game::Renderer renderer(config);
  dm::game::Scene scene;dm::game::RenderView view;renderer.draw(scene,&view);
  const auto image=renderer.capture();
}
    References

    • GGX/material and ACES conventions follow the frozen VSim scene/tonemap shaders. This native implementation uses exact procedural intersections and shadow rays.

    See also

    RenderConfig, RenderView, image::write_png()

    set_overlay

    #source
    void set_overlay(std::string title, std::string status = {}, std::string controls = {})

    Prepare source-compatible title/status/control bitmap overlays for subsequent draws. Text uses native uppercase 5x7 glyphs; unknown bytes use '?'. Empty title disables overlays, and targets below 200x180 omit them. Composition remains on the GPU.

    Parameters
    title

    UTF-8 title, at most 1024 bytes; empty by default disables the HUD.

    status

    UTF-8 status, at most 1024 bytes; may be empty.

    controls

    UTF-8 controls, at most 1024 bytes; may be empty.

    Throws
    std::invalid_argument

    Invalid UTF-8, NUL or excessive text length.

    std::runtime_error

    Native transfer failure.

    Example
    if(dm::compute::probe({dm::compute::Backend::Vulkan,0}).available){
  dm::game::RenderConfig c;c.width=16;c.height=16;dm::game::Renderer
  renderer(c);renderer.set_overlay("Courier","Ready","Move / Jump");
}
