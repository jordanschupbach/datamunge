    struct datamunge::linalg

    QRDecomposition

    template<typename T = double>
struct QRDecomposition
    #include <datamunge/linalg/qr.hpp> source

    The factorization \(A=QR\) returned by qr(): \(Q\) is n x n orthogonal and \(R\) is n x m upper trapezoidal (zero below the diagonal).

    Template parameters
    T

    Floating-point type.

    Example
    const dm::linalg::DenseMatrix<double> A(3, 2, {1, 0, 1, 1, 1, 2});
const auto f = dm::linalg::qr(A);
const auto x = f.solve(std::vector<double>{1, 3, 5});  // least squares: y = 1 + 2t
std::print("{:.3f} {:.3f}\n", x[0], x[1]);             // 1.000 2.000

    r_inverse

    #source
    DenseMatrix< T > r_inverse() const

    The inverse of the leading m x m block of R, by back substitution.

    For a full-rank tall A, \((A^\top A)^{-1}=R^{-1}R^{-\top}\), so this gives the unscaled covariance of least-squares coefficients without forming \(A^\top A\) (which would square the condition number).

    Returns

    The m x m upper-triangular matrix \(R_{1:m,1:m}^{-1}\).

    Throws
    std::runtime_error

    If R is rank-deficient (see is_full_rank()).
