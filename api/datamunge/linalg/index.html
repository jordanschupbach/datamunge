    #source
    enum class LeastSquaresMethod

    Algorithm used by least_squares().

    EnumeratorValueDescription
    NormalEquations

    Cholesky factorization of \(X^\top X\): about \(np^2+p^3/3\) flops, error grows like \(\kappa^2\).

    HouseholderQR

    Householder QR of \(X\): about \(2np^2-2p^3/3\) flops (plus forming Q), backward stable.

    SVD

    One-sided Jacobi SVD: slowest, backward stable, handles rank deficiency (minimum-norm solution).

    #source
    template<class Storage = datamunge::Dense, class T = double>
using Mat = datamunge::Mat< Storage, T >

    Alias for dm::Mat<Storage, T>; defaults to dense storage and double scalars. Supports float, double and long double. Products and solves require equal scalar types; constructing another Mat<Storage, T> explicitly converts scalar/storage type. Expression evaluation preserves the scalar and storage kinds until an inverse action yields dense output.

    Template parameters
    Storage

    dm::Dense (default) or dm::Sparse storage policy.

    T

    Floating-point scalar (default double).

    Example
    using dm::la::Mat;
Mat<> X = {{1, 0}, {1, 1}, {1, 2}};
Mat<dm::Dense, double> y = {{1}, {3}, {5}};
auto beta = dm::solve(X.t() * X) * X.t() * y;
std::print("{:.0f} {:.0f}\n", beta(0, 0), beta(1, 0));  // 1 2
