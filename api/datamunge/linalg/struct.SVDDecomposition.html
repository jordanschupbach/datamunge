    SVDDecomposition

    template<typename T = double>
struct SVDDecomposition
    #include <datamunge/linalg/svd.hpp> source

    The thin SVD \(A = U\,\mathrm{diag}(s)\,V^\top\) returned by svd().

    Template parameters
    T

    Floating-point type (float, double or long double).

    Example
    const dm::linalg::DenseMatrix<double> A(3, 2, {3, 0, 0, 4, 0, 0});
const auto f = dm::linalg::svd(A);
std::print("{} {} {}\n", f.s[0], f.s[1], f.condition_number());  // 4 3 1.3333333333333333

    solve

    #source
    std::vector< T > solve(const std::vector< T > & b, T rcond = T{-1}) const

    Minimum-norm least-squares solution \(x = V\,\Sigma_r^{+}\,U^\top b\).

    Singular values at or below rcond * s[0] are treated as zero, so for a rank-deficient matrix the result is the solution of smallest Euclidean norm among all minimizers of \(\lVert Ax-b\rVert_2\).

    Parameters
    b

    Right-hand side of length m.

    rcond

    Relative cut-off; a negative value selects default_rcond().

    Returns

    The solution of length n.

    Throws
    std::invalid_argument

    If b.size() != m.

    reconstruct

    #source
    DenseMatrix< T > reconstruct(std::size_t k) const

    The rank-k truncation \(A_k=\sum_{j\le k} s_j u_j v_j^\top\).

    By the Eckart-Young theorem this is the best rank-k approximation of \(A\) in both the spectral and Frobenius norms, with errors \(s_{k+1}\) and \((\sum_{j>k}s_j^2)^{1/2}\).

    Parameters
    k

    Number of singular triplets to keep (clamped to the number available).

    Returns

    The m x n matrix \(A_k\).
