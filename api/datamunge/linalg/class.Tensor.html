    class datamunge::linalg

    Tensor

    class Tensor
    #include <datamunge/linalg/tensor.hpp> source

    A dense, row-major, N-dimensional array that can hold double, bool, or string elements (chosen at construction, not compile time).

    Structural operations (reshape, transpose, slicing, concatenation, ...) work for every dtype. Arithmetic, comparisons, reductions, and linear algebra require a numeric-like dtype (Float64 or Bool); String tensors support only structural ops and element access via string_at/set_string.
