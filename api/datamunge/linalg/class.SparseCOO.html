    spmv_tiled

    #source
    void spmv_tiled(
    const std::vector< T > & x,
    std::vector< T > & y,
    std::size_t block_rows = default_block_rows) const

    y = A * x — row-strip tiled to keep the active slice of y in L1 cache.

    Requires compress() to have been called (entries must be sorted by row). block_rows controls the strip height; defaults to fill a 32 KB L1 cache. Pass a larger value (e.g. 256*1024/sizeof(T)) to target L2 instead.

    Writes into a caller-provided buffer so the same allocation can be reused across repeated calls (e.g. in an iterative solver).
