    #include <datamunge/info.hpp>
    #source
    std::string info(const dstruct::DataFrame & frame)

    Describes a DataFrame, like pandas' DataFrame.info() or R's str().

    The first line gives the size ("DataFrame: 60 rows x 3 columns"), followed by an aligned table with one line per column: index, name, type ("numeric" or "string"), non-null count, null count and a summary. Numeric columns show min/mean/max over their non-null values (blank if every value is null); string columns show the number of distinct values, where nulls, if any, count as one extra distinct value (like dplyr::n_distinct()). The result has no trailing newline.

    Parameters
    frame

    Frame to describe; it is not modified.

    Returns

    A multi-line description.

    Example
    const auto tooth = dm::datasets::tooth_growth();
std::print("{}\n", dm::info(tooth));
// DataFrame: 60 rows x 3 columns
// #  Column  Type     Non-null  Nulls  Summary
// 0  len     numeric        60      0  min: 4.2, mean: 18.8133, max: 33.9
// 1  supp    string         60      0  distinct: 2
// 2  dose    numeric        60      0  min: 0.5, mean: 1.16667, max: 2
    See also

    DataFrame::describe_numeric(), DataFrame::null_count(), DataFrame::n_distinct()

    #source
    template<typename T>
std::string info(const Vector< T > & values)

    Describes a Vector<T>: element type, length, a preview and a summary, like R's str().

    Two lines: "Vector<type> of length n", then the first 6 values (followed by "..." when there are more) and a summary that depends on T – min/mean/max for arithmetic types (NaNs are skipped and counted separately), true/false counts for bool, the number of distinct values for strings. An empty vector shows just "[]".

    Template parameters
    T

    Element type.

    Parameters
    values

    Vector to describe.

    Returns

    A two-line description with no trailing newline.

    Example
    std::print("{}\n", dm::info(dm::c(1.0, 2.0, 3.0, 4.0)));
// Vector<double> of length 4
//   [1, 2, 3, 4]  min: 1, mean: 2.5, max: 4
